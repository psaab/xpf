1. **BLOCKER — closing both sockets does not guarantee the full-disconnect transition.**  
   The plan assumes that closing both connections necessarily causes both nodes to observe “all fabrics down” and cold-re-prime ([plan.md:645](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/docs/research/6751-nopat-admission/plan.md:645), [plan.md:655](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/docs/research/6751-nopat-admission/plan.md:655)). In reality, each receive loop removes its connection independently through a deferred callback ([sync_conn_read.go:14](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn_read.go:14)). `handleDisconnect` clears only one slot per invocation, and executes full cleanup only if both slots happen to be nil at that instant ([sync_conn.go:483](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn.go:483), [sync_conn.go:496](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn.go:496)).

   A reconnect can be installed after the first old slot is removed but before the second removal. `installConn` then observes a nonempty registry, so it neither records a full-disconnect edge nor arms `needColdPrime` ([sync_conn.go:244](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn.go:244), [sync_conn.go:278](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn.go:278)). When the second old connection finally exits, the replacement keeps `connected == true`; cleanup never runs. With sticky `outboundBulkAcked`, survivor re-drive is also suppressed ([sync.go:479](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync.go:479), [sync_conn.go:572](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn.go:572)). The sender therefore need not retry the aborted bulk.

   The underlying recovery path is otherwise valid: genuine all-fabrics-down clears pending ACK and receive-bulk state ([sync_conn.go:551](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn.go:551)); a genuine empty→connected edge arms cold-prime; reconnect performs an unconditional bulk ([sync_conn.go:139](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_conn.go:139)); and `BulkSync` allocates a fresh epoch ([sync_bulk.go:65](/home/ps/git/kimi-xpf/.claude/worktrees/6751-research-nopat-admission/pkg/cluster/sync_bulk.go:65)). The missing guarantee is reaching that path on both endpoints.

   Required revision: specify an atomic, generation-fenced cluster-abort transition—not merely two `Close()` calls. It must prevent replacement installs between old-generation detachments, invalidate stale receive handlers even if `Close` errors, reset bulk/quarantine/capability state exactly once, and ensure the peer executes the same transition. Add a test that installs a reconnect between the two old disconnect callbacks.
