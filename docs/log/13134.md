# Keep Junos-host exemptions scoped to effective unit policy (#13134)

- **Issue**: #13134 (source finding D2-02).
- **Cause**: For a distinct unit-0 VLAN or tunnel netdev, `junosHostZoneExemptNetdevs` included the physical ingress carrier using `InterfaceHostInboundEffective` on the bare interface name. A unit-0 `host-inbound-traffic` override replaces the zone-level set, but the bare name resolved the broader zone set and leaked IKE and ident-reset exemptions. The exemption walk also failed to exclude lifeline refs.
- **Change**: Resolve the physical carrier contribution against `unit0Name`; skip lifeline refs both for ordinary rows and the distinct-unit-0 physical contribution. Keep unit-0 ingress coverage and evaluate exemption metadata using the same effective policy that applies on that unit.
- **Regression coverage**: `TestJunosHostExempt13134DistinctUnit0UsesUnitOverride` rejects leaked IKE/ident-reset on a narrowed VLAN unit-0 physical carrier; `TestJunosHostExempt13134DistinctUnit0GrantReachesPhysical` preserves unit-0 grants; `TestJunosHostExempt13134LifelineUnitDoesNotContaminateParent` rejects lifeline-derived exemptions. Updated the existing distinct-unit-0 countercase to assert the unit override governs exemption metadata.
- **RED evidence**: Before the fix, `go test ./pkg/config -run '^TestJunosHostExempt13134' -count=1` failed: narrowed unit 0 leaked `[ge-0-0-1]` into both exemption lists, and the lifeline row leaked `[fxp0]` into both.
- **Validation**: `go test ./pkg/config -run 'TestJunosHostExempt13134|TestJunosHostCollapse12838|TestJunosHost.*12839|Test.*Lifeline' -count=1` passed. `go vet ./pkg/config/` passed. `git diff --check` passed. `go test ./pkg/config/ -count=1` did not complete: the package's `TestSchemaSpellingDifferentialGate` hit its 10-minute test timeout while running bcrypt-heavy generated cases; the captured stacks were in `hashAPIAuthSecrets` / `bcrypt`, not this change.
- **Risk**: Exemption metadata for distinct unit-0 physical carriers now follows the replacement unit policy rather than a separate bare-interface lookup. Lifeline units cannot add exemption metadata to their own/shared carrier.
