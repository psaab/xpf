- **Timestamp**: 2026-10-13 (review fold, PR #12672)
  - **Action**: Review found the child-only rendering correct only for grouped set trees. `NewParser` (Store.Load, load, HA sync) keeps the destination on the context node after `to-zone`, so hierarchical `from-zone [ A C ] to-zone B` and `to-zone D` both named the `policy` keyword as their destination and stayed identical. Grouped `to-zone [ ]` rendered the policy tail as `[ policy p1 ]`, and `to-zone E [ B D ]` named only `E`. The detector now reads the tokens after `to-zone` on the node when present, else every statement path of the body, and ends a destination at the policy keyword. Authored `[ ... ]` runs keep their brackets, so `E [ B D ]` and `[ B D ] E` are named in full and an empty list names no zone.
  - **File(s)**: `pkg/config/compiler_zone_pair_shape_9246.go`, `pkg/dataplane/userspace/zone_pair_destination_reason_12510_test.go`
