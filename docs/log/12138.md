# #12138 — declare the manual churn ignore kind

- **Issue**: #12138 — the ignored-cell census rejects an ignored test whose reason does not declare its kind.
- **Branch**: `fix/12138-census-ignore`

## Why

The existing manual release-mode shared-session churn measurement used a free-text `#[ignore]` reason. The ignored-cell census requires each reason to start with `MEASUREMENT:` or `#<issue>:` and therefore counted this cell as undeclared. Declaring it as a measurement satisfies the census; the prefix does not schedule or run the measurement.

## What

Changed the existing ignore reason in `userspace-dp/src/afxdp/session_glue/pbr_install_table_9752_tests.rs` to `MEASUREMENT: manual loaded shared-session churn (#11299)`. The test remains ignored and manual.
