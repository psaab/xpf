# #15062: top-level `interfaces <name> { ... }` compiles phantom interfaces (A01-01)

- **Timestamp**: 2026-10-18
  - **Action**: Reproduced on origin/master (897d3ce94f base, re-anchored at
    43a7851561). AST dump + CompileConfig probe:
    - `interfaces ge-0/0/0 { unit 0 { family inet { address 10.9.9.1/24; } } }`
      → phantom interface `unit`, no units; braced form → `ge-0/0/0` unit 0
      with the address.
    - Same for `interfaces fxp0 { ... }` (day-0 shape) and the packed-tail
      spelling `interfaces ge-0/0/0 unit 0 { ... }` (phantom `family`).
    Mechanism: parser builds Keys=["interfaces","ge-0/0/0"] with the body as
    Children; `compileSections` dispatches on `node.Name()` and ignores
    Keys[1:]; `compileInterfaces` then names an InterfaceConfig after each
    body child. The scoped compact fold cannot name an operator-chosen
    interface name (#8879 bound), and the 8879 cell asserted only err==nil.
  - **File(s)**: none (probe removed)

- **Timestamp**: 2026-10-18
  - **Action**: Fix, following the #9620 routing-instance pattern. New
    `normalizeElidedInterface15062` folds a top-level elided `interfaces`
    node into the braced shape inside `normalizeCompactStanzas` (hooked in
    `normalizeCompactNodes` when the `interfaces` child is exactly
    `schemaInterfaces`, covering the root and `groups` bodies but not
    class-of-service `interfaces`). The body moves under a synthesized
    `<name>` node verbatim; a packed tail past the name stays on that node
    for the interface compiler's schema expansion. Not rewritten: braced
    form, bare leaf `interfaces <name>;`, and top-level apply statements
    (`interfaces apply-groups G;`, #9685 — keyword sits in Keys[1]).
    Because every compile core and SchemaValidate (via
    normalizeCompactForValidation) normalize first, strict commit,
    lenient load, node-aware compile and configstore.CheckText all see
    the braced shape; ValidateInterfaceName now gates the elided name too.
  - **File(s)**: pkg/config/compact_normalize_interfaces_15062.go,
    pkg/config/compact_normalize_8662.go
