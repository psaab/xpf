# #18573 — a RETH address removed by commit stays on the RG owner

- **Timestamp**: 2026-10-30
- **Action**: Root cause in code (worktree `/var/worktrees/fix-18573`, base
  `714664cf78`).
  - `directAddVIPs` / `directRemoveVIPs` (`pkg/daemon/daemon_ha_vip.go:200`
    and `:246` at the base) both iterate `vrrp.RethVIPsForRG(cfg, rgID)` of
    the active config at call time. Nothing records what was installed.
  - `reconcileDirectVIPOwnership` (`daemon_ha_vip.go:152`), driven every 2 s
    from `reconcileRGState` (`daemon_ha.go:1678`), calls the same pair. An
    owner only ever adds the new set; demotion only removes the new set.
  - `reconcileInterfaceAddresses` skips RETH netdevs
    (`pkg/dataplane/compiler_iface.go:1325-1333` for VLAN subs, `:1646` for
    bare members), so nothing else deletes it.
  - Legacy VRRP mode is not affected: `updateVIPs`
    (`pkg/vrrp/instance_vipupdate.go`, #10780) applies the delta in place and
    deletes the removed VIPs.
- **Action**: Second consequence (coordinator, issue comment 2026-10-31).
  - The userspace snapshot row addresses are the kernel listing merged with
    the configured ones (`buildLinkSnapshot` + `mergeInterfaceAddressSnapshots`,
    `pkg/dataplane/userspace/interfaces.go`), sorted by string.
  - `pick_interface_v4` (`userspace-dp/src/afxdp/forwarding_build/interfaces.rs`)
    takes the designated primary, else the first non-link-local in row order.
  - After `.11` -> `.43`, `.11/24` sorted first, and interface SNAT used the
    deleted address.
- **Action**: Fix.
  - New `pkg/vipstamp`: raw RTM_NEWADDR with `IFA_PROTO = 0xbf`, a raw
    RTM_GETADDR dump that decodes it (netlink v1.3.1 has no field), and
    `Leftover` (stamped, and not in `config.AddressIdentitiesByNetdev` for its
    netdev).
  - `pkg/config`: `PrefixIdentity`, `AddressIdentitiesByNetdev` (RETH VIPs
    under the install naming plus enabled plain-unit addresses).
  - `pkg/daemon`: `reconcileDirectVIPAddrs` behind `directAddVIPs` /
    `directRemoveVIPs`. Deletes leftovers on every pass; owner adds + adopts
    unstamped configured VIPs; non-owner removes configured VIPs; re-asserts
    after deletes; degrades to the old add/remove-all on a dump failure;
    queues an interface-link snapshot refresh for each changed netdev.
  - `pkg/dataplane/userspace`: the builder drops leftovers from the LIVE
    listing (base and unit rows) before the configured merge.
