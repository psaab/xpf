# Issue #12833: compile every ALG block and reject packed typos

- **Root cause**: `algDisabled` used `FindChild(proto)`, so only the first same-protocol ALG child contributed its `disable` state. Strict schema validation also ignored tokens packed onto the ALG/protocol container nodes; a known-protocol typo such as `ftp desable;` therefore passed `SchemaValidate` without validation.
- **Fix**: inspect every matching protocol child and OR its disable state; add an ALG node validator that checks packed tokens for wired ALG classes, naming any token other than `disable`. Unsupported ALG classes remain opaque, preserving the existing accepted-only advisory contract. The existing closed-world walk continues to reject unknown braced children.
- **Regression coverage**: multiple protocol blocks including second/third disables, both orderings, unsupported-protocol blocks, packed typo forms, the braced-typo control, valid packed forms, and lenient compilation.
