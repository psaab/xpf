# #16551 — Junos AS-path translator: `<AS>{0}` binds to last digit; `B{m}` on nullable group demands separator for empty copy

- **Timestamp**: 2026-10-24
  - **Action**: Fixed two quantifier mistranslations in
    `parseTermWithOperator` (`pkg/config/aspath_junos_translate.go`).
    (a) `{0}` / `{0,0}` were emitted as `wrapped + "{0}"` where `wrapped`
    is often not a single ERE atom (multi-digit AS number, the `.` token
    `[0-9]+`, a range fragment ending in a character class), so the
    interval bound only the last character: `65000{0}` matched the
    unrelated AS 6500. The zero cases now attach `{0}` to `grouped`,
    the base parenthesised as one atom. (b) `{m}` / `{m,}` / `{m,n}`
    with m>=1 on a nullable single-token base (e.g. `(65000?){2}`)
    demanded a `" <term>"` separator for every non-first copy even when
    that copy was empty, rejecting paths Junos accepts such as the
    single token `65000`. Single-token nullable bases are now emitted
    as 0..hi present tokens joined by single spaces (stripping the
    whole-path `^$` null marker that can never match inside a
    repetition); multi-token nullable bases keep the copy form because
    collapsing them to a token count would admit cross-copy mixes.
    Regression cells live in
    `pkg/config/aspath_translate_16551_test.go`: the three reported
    mismatch rows, zero intervals on AS/range/set/`.` bases, exact and
    ranged repetitions of nullable groups in isolation and in
    concatenation, plus controls pinning previously-correct shapes
    (`65000{2}`, `65000{0,1}`, `(65000 65001){0,1}`, `.{0,2}`,
    multi-token nullable repetition, `12{0,2} 34`). RED evidence: with
    the translator fix reverted the new tests fail on exactly the
    reported rows (`65000{0} 65001` matching `6500 65001`,
    `(65000?){2}` rejecting `65000`, and siblings); post-fix all pass
    together with the #15007 translator suite.
  - **File(s)**: `pkg/config/aspath_junos_translate.go`,
    `pkg/config/aspath_translate_16551_test.go`, `docs/log/16551.md`
  - **Risk**: Repetitions of multi-token nullable groups (e.g.
    `(65000 (65001?)){2}` with a partially-empty copy) keep their
    pre-existing separator behaviour — out of the reported scope and
    unchanged. No other translator shapes change output.
