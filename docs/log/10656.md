# #10656 — reject unknown tagged VIDs on unit-less zoned ports

- **Issue:** #10313's unknown-VID rule only recognized physical ifindexes carrying logical VLAN units. A nonzero tagged VID miss on a zoned unit-less port therefore fell back to the physical interface and inherited its own zone.
- **Implementation:** Treat every nonzero `(physical ifindex, VID)` miss in `ingress_logical_ifindex` as unknown, regardless of whether that bind has logical units. Recycle it at the common ingress boundary before destination classification, ARP/NDP learning, decapsulation, cache/session lookup, and policy. Exact configured VID matches and VID 0 retain their normal logical/physical resolution. The pre-routing scope still retains the physical interface name while suppressing the fallback zone; a valid fabric zone override remains authoritative. The obsolete `ingress_vlan_parents` set is removed.
