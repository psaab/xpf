# #10656 — reject unknown tagged VIDs on unit-less zoned ports

- **Issue:** #10313's unknown-VID rule only recognized physical ifindexes carrying logical VLAN units. A nonzero tagged VID miss on a zoned unit-less port therefore fell back to the physical interface and inherited its own zone.
- **Implementation:** Reject nonzero `(physical ifindex, VID)` map misses regardless of whether a bind has logical units. When XDP delivers directly on a configured VLAN child's ifindex, the parent-keyed resolver has no child key, so admit only that child's configured VID from its egress binding; other VIDs remain unknown. Recycle unknowns at the common ingress boundary before destination classification, ARP/NDP learning, decapsulation, cache/session lookup, and policy. Exact parent+VID matches and VID 0 retain normal resolution. The pre-routing scope retains the physical interface name while suppressing the fallback zone; a valid fabric zone override remains authoritative. The obsolete `ingress_vlan_parents` set is removed.
