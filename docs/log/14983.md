# Issue #14983 — api: fix positional multi-leg rebind self-collision and partial-rebind auth desync (D36-03)

- **Issue:** Two coupled defects in the multi-leg (#14583) management listener reconcile. (1) `Server.reconcileLegsLocked` (`pkg/api/listener.go`) matched desired addresses to live legs **positionally**: on a pure reorder `[A,B] -> [B,A]` it tried to bind B while the old B leg was still serving B, and A while the old A leg still served A — a self-inflicted `EADDRINUSE` on both legs that no retry could clear, so the swap never converged. (2) The daemon's auth gates (`managementReconciler.reconcileTo`, `publishNilDirectionLocked`, `mgmtEndpoint.everyLiveLegNamedBy` in `pkg/daemon/management.go`) judged sanction/loopback-ness from the **recorded fingerprint** `m.cur`, whose fields advance only on a whole-plane success — after a positional swap or a partial rebind the fingerprint could skip or mis-order a still-serving leg, withholding a converged grant (absorbing empty intersection) or, in the general shape, judging nil-auth safety against legs that are not the ones serving.
- **Scope narrowing honored:** the refuted "unauthenticated remote mutation" sub-leg is **not** claimed: in the reachable production shapes the pre-fix nil gate's whole-plane fingerprint retention already published deny-all (pinned as a control, see below), so no unauthenticated off-loopback exposure is asserted. The surviving legs fixed here are the self-collision and the grant/fingerprint desync.
- **Fix:**
  - `pkg/api/listener.go`: `reconcileLegsLocked` now matches legs **by address** — any serving leg already on a desired address is adopted into that slot (socket kept, no bounce), displaced legs are retired only after all slots resolve (a later slot may still adopt them), surplus legs retire in a final sweep, and duplicate desired addresses are rejected before any leg is touched. New `Server.ServingLegAddrs` exposes the requested address of every serving leg on both planes.
  - `pkg/daemon/management.go`: the sanction gate (`liveLegsSanctionedLocked`) and the nil-direction loopback gate (`liveAllLoopbackLocked`) read the live serving legs (fingerprint fallback only when no server exists); `syncCurFromLiveLocked` resyncs `m.cur` from the serving legs after each HTTP/HTTPS reconcile — exact desired fingerprint on success, converged-plus-retained union on partial failure, previous fingerprint retained as retry debt for a plane that bound nothing.
- **Files:** `pkg/api/listener.go`, `pkg/api/listener_swap_14983_test.go` (new), `pkg/daemon/management.go`, `pkg/daemon/management_swap_14983_test.go` (new), `pkg/api/README.md`, `pkg/daemon/README.md`, `docs/log/14983.md`.
