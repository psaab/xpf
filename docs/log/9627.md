# #9627 -- a group-inherited self-repeating run escaped the #9027 gate beside an inline leaf

- **Timestamp**: 2026-09-10
  - **Action**: Mechanism traced; the issue's "suspected" wording is now
    verified by code reading. The #9027 gate (multi_leaf_self_repeat_9027.go)
    runs on the group-expanded tree and scans each leaf's Keys for an unquoted
    repeat of the keyword.
    - With no inline leaf, the group's node is copied whole and the repeat
      survives, so the gate refuses it (row 2).
    - With an inline leaf of the same name, mergeLeafListInto (ast_groups.go)
      unions the group's members, reading them through firewallMatchValues.
      That reader skips any token equal to the keyword, quoted or not, so the
      merged node never carries the repeat and the gate has nothing to refuse
      (row 3).
    - The same skip silently dropped a QUOTED value named `export`. Row 4's
      "accepted" was that drop, not the quote being honoured.
  - **File(s)**: none
- **Timestamp**: 2026-09-10
  - **Action**: Fix. mergeLeafListInto reads members across both AST shapes,
    with quote provenance.
    - An unquoted self-repeat is appended to dst's Keys whatever dst's shape and
      never deduplicated. The gate scans Keys, so a block-form inline leaf
      cannot hide it either.
    - A quoted one is an ordinary member and keeps its quote bit. The mask stays
      nil or one bit per key.
    - #6673 still holds: the union keeps the group's own quote and never mints
      a quote a value did not have.

    Tests, group_union_self_repeat_9627_test.go:
    - the issue's rows: an inline run and a group-only run refused as controls,
      a group run beside an inline leaf refused, a quoted repeat and a no-repeat
      config accepted;
    - the lenient warning;
    - the quoted value's survival and its quote bit after ExpandGroups;
    - the block-form inline leaf.

    The #9027/#9029, apply-groups leaf-list and multivalue-leaf suites pass.
    docs/config-schema.md gains a #9627 paragraph in the #4070 union section.
