# #12790 — reject dangling QNH tails on static-route interfaces

## Why

A packed route such as `next-hop 10.0.0.1 interface ge-0/0/1.0 qualified-next-hop`
left the incomplete QNH keyword fused onto the interface child. The static-route
normalizer only extracts a complete, unquoted QNH clause, so the dangling form
was ignored. Quoting the keyword likewise kept the entire tail on the interface
child. The compiler reads only the interface value, silently dropping both
forms without a strict error or tolerant warning.

## What

Added a shared static-route AST check for `qualified-next-hop` tokens remaining
in the packed tail of a `next-hop` interface child. Strict compilation and
`SchemaValidateWithDefinitions` reject the dangling or quoted tail; tolerant
compilation retains load behavior and records a #12790 warning. The existing
normalizer continues to split complete, unquoted QNH clauses, which remain
accepted.

Regression coverage verifies strict compiler/schema rejection and tolerant
warnings for both reported forms, and verifies the complete packed form remains
accepted.

## Validation

- RED before the fix: focused regressions failed because strict compile returned
  nil for both the dangling and quoted forms.
- `go test ./pkg/config -run '^(TestStaticRouteInterfaceQualifiedNextHopTail12790|TestPackedStaticRouteNextHopInterfaceChildKeepsQNH_12755|TestPackedStaticRouteNextHopAndQualifiedNextHop_12648|TestPackedStaticRouteRejectsIncompleteQualifiedNextHop_12648|TestPackedRouteQualifiedNextHopNormalizerStaysInStaticRoutingScope_12648)$' -count=1` — passed; covers strict compiler/schema rejection, tolerant warnings, and compiler/schema acceptance of valid clauses.
- Mutant checks: skipping either strict rejection return makes its case fail with nil; disabling the schema gate likewise returns nil and fails its schema assertion.
- `go build ./...` — passed.
- Full `go test ./pkg/config -count=1` — did not pass: output reported failures in
  the inventory census, API-auth expiry checks, packed forwarding-instance
  control, and slot-escape census, then the Go test timeout fired at 10 minutes
  in `TestSchemaSpellingDifferentialGate` during API-auth bcrypt hashing. These
  failures are not attributed to this change; no full-suite pass was established.

## Risk

The check is scoped to static-route `next-hop` interface children and only flags
remaining `qualified-next-hop` tail tokens. Complete clauses extracted by the
existing normalizer are unaffected.
