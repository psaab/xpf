# #17839 — Judge neighbor description pipe gate on rendered form

- **Timestamp**: 2026-10-25
  - **Action**: The #16776 vty pipe gate in `renderBGP16125`
    (`pkg/frr/protocols_render_bgp.go`) judged the raw stored neighbor
    description but rendered `sanitizeFRRValue(description)`, which
    maps control bytes (`< 0x20`, `0x7f`) to spaces. A tolerant-path
    description such as `uplink |\tprimary` contains no `"| "` raw, so
    it passed the gate, rendered as `uplink | primary`, and was
    silently refused by FRR's vty pipe hook while frr-reload.py
    exited 0 — the exact silently-dropped-line defect #16776 exists
    to remove, reachable on precisely the lenient-load / peer-sync
    paths the strict commit gate does not cover. The gate now judges
    `renderedDescription := sanitizeFRRValue(n.Description)` (computed
    once) and renders that same string, so the predicate and the
    emitted bytes cannot disagree. The strict commit gate
    (`validateBGPNeighborDescriptionPipeStrict16776`) is unchanged:
    raw `"| "` is still refused at commit.
  - **File(s)**: `pkg/frr/protocols_render_bgp.go`,
    `pkg/frr/community_pipe_16776_test.go`, `docs/log/17839.md`.
  - **Validation**: New `TestNeighborDescriptionPipeRenderedForm17839`
    discriminates all three directions: raw-safe→rendered-unsafe
    (`uplink |\tprimary`, `uplink |\x7fprimary`) descriptions are
    omitted on the tolerant render path while the neighbors
    themselves still render; raw-unsafe `uplink | primary` stays
    omitted (and is rejected at strict commit by the pre-existing
    `TestNeighborDescriptionPipeStrictAndLenient16776` in
    pkg/config); rendered-safe values (`uplink\tprimary` →
    `uplink primary`, `uplink |primary`, `plain peer`) keep their
    descriptions. The fixture self-checks that the raw input has no
    `"| "` and the sanitized form does, so the test cannot pass
    vacuously; reverting the gate to the raw string turns it RED.
    `go test ./pkg/frr/ -run TestNeighborDescriptionPipe -count=1 -v`
    PASS; `go test ./pkg/frr/ -count=1` ok; `go vet ./pkg/frr/` and
    gofmt clean.
  - **Risk**: None at the strict gate (untouched). On tolerant paths
    a control-bearing description whose sanitized form contains
    `"| "` now loses only its description line (with the existing
    warning) instead of silently never installing; the neighbor
    statement itself is unaffected.
