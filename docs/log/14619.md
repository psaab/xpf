# Issue #14619 — current helper publishes zone_counter_layout_version=0 when quiet

## Defect

`refresh_status` stamped `zone_counter_layout_version = 0` whenever the
sparse zone-traffic snapshot was empty and overflow was off (and the
same for the flood twin). The snapshot drops all-zero rows, so fresh
boot, post-`clear security zones statistics`, and an idle HA secondary
all reached that state routinely. Every Go surface renders version 0
as "the running dataplane helper predates per-zone accounting …
upgrade the helper" (#7087 contract in `pkg/zonecounters`), so a
current helper told the operator to upgrade it for every zone. The
publisher's "omit when no data" comment contradicted the Go contract;
#7087's operator-facing contract wins.

A second, weaker sub-case: with >63 configured zones the global
overflow bit is set, so a slotted-but-idle zone was told it is "not
being counted at all".

## Fix

- `userspace-dp/src/server/helpers/status.rs`: stamp
  `ZONE_COUNTER_LAYOUT_VERSION` / `FLOOD_COUNTER_LAYOUT_VERSION`
  unconditionally on every refresh, and publish the new slotted sets.
  Pre-#3651 helpers never set the field, so 0/absent keeps its meaning.
- New wire fields (Rust + Go, `omitempty` / `Vec::is_empty`):
  `zone_counter_slotted_zone_ids`, `flood_counter_slotted_zone_ids` —
  zone ids holding a live hot-path slot (`slotted_zone_ids()` on both
  slot maps, exposed via the coordinator).
- `pkg/zonecounters`: new `UnavailableLineForZone(version, overflow,
  slotted)` — version 0 still wins (pre-dating helper), slotted ⇒ idle,
  overflow && !slotted ⇒ EXHAUSTED, otherwise idle. `UnavailableLineFor`
  is unchanged for callers without slot knowledge.
- `pkg/cli` + `pkg/grpcapi` zone renderers now call the per-zone form
  with a `zoneCounterSlotted` status probe (fails false; without
  overflow that still renders idle, never a manufactured "uncounted").
- `pkg/api/metrics_descriptors_zone.go`: documented that (a)/(c) are
  now distinguishable on the wire; the unpopulated gauge still counts
  zones without samples by design.

NOT changed: the sparse snapshot (all-zero rows still dropped), the
Go offset-replacement sync loop, screen/flood CLI wording (it does not
consume the layout version), and cold-path layout versioning (separate
field, separate consumer contract).
