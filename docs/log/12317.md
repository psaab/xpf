## Change

`MergeHostInboundTraffic` now unions the compiler-retained service/protocol exclusions along with the positive tokens, then reapplies the combined exclusions. A positive alias from either interface scope can no longer restore a tuple excluded by the other. The local duplicate-host-address gate mirror and the hand-built `ZoneConfig` fallback use the same rule; compiled resolver stamps already flow through the shared merge. Zone/interface replacement remains unchanged (#6515).

The regressions assert exact TCP ports on both address families: the cross-scope cases must deny TCP/22, retain TCP/830 through the independent `netconf` service, and preserve unrelated HTTP/80. Coverage includes strict and lenient physical-alias/unit-exclusion and reversed-scope combinations, zone/interface replacement controls, a hand-built legacy resolver control, and same-stanza controls.
