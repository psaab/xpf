# #17197 — R4-Q51-02: Stage-11 IKE transit-DNAT discriminator calls production DNAT

- **Timestamp**: 2026-10-27
  - **Action**: Deleted the hand-kept Stage-11 mirror
    (`ipsec_destination_matches_transit_dnat`) and extracted the
    production pre-routing DNAT decision into a single pure verdict
    both the poll loop and Stage 11 call.

    Defect was live on `origin/master` (8064ca090e):
    `poll_stages.rs:2267-2332` re-derived the pre-routing ingress
    scope, read the raw `meta.fabric_ingress_ifindex`, and consulted
    only the dynamic DNAT tier via the collapsing
    `lookup_with_counter_scoped`. Production (`poll_descriptor/mod.rs`)
    had since gained static-first ordering (#6473), the persistent
    tier, `Poisoned` drops (#14947) and ambiguous-provenance
    fail-closed handling (#16045), none of which the copy modelled.

    Fix:
    - New `poll_descriptor/prerouting_dnat.rs`:
      `prerouting_dnat_verdict(forwarding, meta, flow, scope,
      packet_icmp, suppress, now_ns) -> PreroutingDnatVerdict
      { Static | Persistent | Dynamic | Poisoned | Denied | None }`.
      Pure, `#[inline]`, allocation-free; hit counters and the
      persistent lease key are returned, never applied.
    - The session-miss poll loop calls the verdict and applies the
      side effects at its existing sites (counter charged at
      committed install / at the poisoned drop, lease held in
      `persistent_lease_hold_outer`).
    - Stage 11 builds the scope with the same
      `prerouting_ingress_scope{,_ambiguous}` (ambiguous arrivals via
      the ambiguous constructor, validated V2 scope ifindex
      otherwise), claims only on `None` or a translate-to-self
      verdict, and never claims `Poisoned`/`Denied`.
    - `PreroutingIngressScope` and the scope constructors widened
      `pub(super)` -> `pub(in crate::afxdp)`; no other visibility
      change.

    Acceptance: `grep -n 'fn ipsec_destination_matches_transit_dnat\|dnat_table\.'
    userspace-dp/src/afxdp/poll_stages.rs` → 0.

    Verification (named hermetic tests only,
    `cargo test -p xpf-userspace-dp --bin xpf-userspace-dp <name> -- --exact`):
    - `prerouting_dnat_stage11_parity_17197` (new): iterates
      {unambiguous, ambiguous} × {no rule, unscoped dnat, scoped
      dnat, scoped dnat-to-self, poisoned dnat, static-nat,
      persistent lease} and asserts the Stage-11 claim equals
      "production verdict is None or translate-to-self" — passes.
      The poisoned, static-nat and ambiguous scoped-dnat-to-self
      rows are the pre-fix RED rows.
    - Regressions passing: `stage_ipsec_ambiguous_scope_parity_16047`,
      `flow_backed_poisoned_dnat_counts_drop_16483`,
      `acquire_persistent_inbound_hold_with_snat_takes_hold_16619`,
      `prerouting_dnat_scope_uses_logical_vlan_unit_zone_5802`.
