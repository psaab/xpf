# #18874 — Repair IKE proposal fixtures missing `dh-group`

- **Timestamp:** 2026-11-06
- **Action:** Added `dh-group group14` to the three successful-compile IKE/IPsec proposal fixtures. The fixture repairs cite first-bad commit `e1e74b35193f428a9a09b7bb6b9cb965474db62d` (`config: require dh-group on referenced IKE proposals (#14588) (#14798)`), which introduced the strict check. Added test-only pre-shared keys where the existing #14139 gate required them after the DH-group omission was repaired. Documented the fixture contract in the config module README.
- **File(s):** `pkg/config/ike_policy_chain_ref_test.go`, `pkg/config/parser_security_test.go`, `pkg/config/README.md`, `docs/log/18874.md`.

## Why

`TestIKEGatewayLegacyDirectProposalAccepted`, `TestIKEOrphanGatewayDanglingPolicyAccepted`, and `TestIPsecGatewaySetSyntax` expected `CompileConfig` to accept a rendered VPN whose referenced IKE proposal had no DH group. The strict gate added in `e1e74b35193f428a9a09b7bb6b9cb965474db62d` correctly rejects that configuration because strongSwan cannot load an IKE proposal with no key-exchange method. The legacy direct-proposal case also needs its `dh-group` on the IPsec proposal that is rendered as IKE. The orphan case remains about an unused gateway: its separate healthy referenced tunnel now has a complete, valid IKE policy.

## What

Added `dh-group group14` to the legacy direct-proposal fixture, the healthy referenced IKE proposal in the orphan-gateway fixture, and the IKE proposal in the parser syntax fixture. No assertions or expected errors changed. The existing #14139 PSK-presence check then exposed that these otherwise-successful VPN fixtures also lacked a key; supplied test-only `fixture-secret` values through the VPN or IKE policy without changing the tested behavior. Added the #18874 fixture doctrine to `pkg/config/README.md`: referenced IKE proposals must configure a DH group; orphan IKE proposals are outside that rendered-reference check; ordinary ESP proposals may omit `dh-group` for no-PFS, except when used as a legacy direct-proposal fallback rendered as IKE.
