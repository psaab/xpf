# Follow-up #13999 — use shared-link MTU for IPv6 validation

The #13936 IPv6 minimum-MTU gate initially checked the IPv6 unit's own MTU
or its interface MTU fallback. Untagged logical units share the physical
link, however, and `planPhysDesired` applies the MTU from the lowest-numbered
referenced untagged unit when one is configured. An IPv4 sibling's low MTU
could therefore lower the link below 1280 while an IPv6 sibling with no
family MTU passed validation.

The gate now uses the same referenced-sibling selection as the parent-link
planner for zoned untagged units, preserving explicit unit MTU checks for
unreferenced units and tagged-child MTU semantics. Regression coverage zones
both sibling units and confirms the low shared-link MTU rejects; the
unit-overrides-interface control now zones the unit so the override is active.
