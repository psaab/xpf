# #16469 — console `canonicalForms` no longer eats the keyword after `show route`'s `<destination>` placeholder

- **Timestamp**: 2026-10-24
  - **Action**: Fixed the #15942 regression in `pkg/cli`'s
    `canonicalForms` (consumed by `canonicalPrefix` for audit): the
    top-level placeholder arm set `awaitValue` unconditionally, so a
    declared keyword child beside a placeholder (`table`/`protocol`/
    `instance` with `RequiresValue`, and plain `fib`/`terse`/`detail`/
    `summary` beside `show route`'s `<destination>`) was eaten as the
    placeholder's value, minting no selector form and no extended
    base/full form. Anchored `deny-commands "^show route table$"` /
    `"^show route protocol$"` / `"^show route instance$"` therefore
    silently stopped denying on the console (remote still denied via
    the optopic registry charge), and `^show route$` wrongly denied
    the distinct `show route summary` command. Both placeholder arms
    (top-level and the pending-after-value arm) now peek the next
    canonical token against the node's declared children: only a
    non-keyword token fills the placeholder; a keyword falls through
    to the normal arms, so the selector arm mints `show route table`
    and plain keywords extend base/full. Because minting the selector
    form made it a tier-denying truncated form that
    `EvaluateForms`' core-exception geometry cannot see, a narrow
    `selectorExceptionAllowed` rescue preserves the pre-existing
    deny-with-exceptions idiom (`allow "^show route table
    public-vrf$"` beside `deny "^show route table"`, the #9628 piped
    cell): it fires only when a selector form is tier-denied, no tier
    deny stands on the executed/base/full forms, and the executed
    command is affirmatively allow-decided. New cells in
    `pkg/cli/placeholder_keyword_selector_16469_test.go` pin the
    selector denies (table/protocol/instance), the `^show route$`
    selector doctrine (denies bare/value/selector spellings, not
    `summary`/`fib`/`terse`/`detail`), the forms themselves, and a
    cross-surface census over every operational-tree node with a
    placeholder child beside keyword children asserting console ==
    remote (optopic registry charges) — Options nodes excluded from
    the addressable-spelling arm (their keywords mint no form by
    #15973's ruling) but included in the base-spelling arm.
  - **File(s)**: `pkg/cli/command_regex_leaf_16158.go`,
    `pkg/cli/placeholder_keyword_selector_16469_test.go`,
    `debian/changelog`, `docs/log/16469.md`
  - **Validation**: new tests fail on pristine origin/master (selector
    forms `[]`, `^show route table$` allowed, `^show route$` denying
    `show route summary`) and pass with the fix (3 tests). Targeted

    `go test ./pkg/config/ -run 'TestLoginRegex|...'`,

    'TestArgumentScoped|TestAnchoredDenyAgrees|...'`. Full
