# #18853 — keep declared tagged RETH devices in the Kea belt

- **Timestamp**: 2026-11-02 (`wt-17474`, base `fed39c4bc1`)

## Why

`FilterKeaInterfaces15206` receives daemon-resolved DHCP interface names and
fails closed when a name is not in its active-config device allowlist. The
allowlist previously contained only each interface's parent device. A valid
RETH unit 80 with VLAN ID 180 resolves to a kernel name such as
`ge-0-0-2.180`, but that name was absent while the base `ge-0-0-2` was present;
the belt then dropped a declared DHCP device as if it were phantom. This is
separate from the two master-RG daemon cells reported by #18853: both are green
on base `fed39c4bc1` in a repeated named run, and no `daemon_ha.go` change is
being attributed to them.

## What

- Include each non-nil declared unit's resolved kernel name in
  `usableKeaDevices15206`, for both authored and Linux interface spellings.
- Add `TestKeaBeltKeepsDeclaredTaggedUnit15206` with a declared RETH unit 80 /
  VLAN ID 180: its resolved `.180` device must survive while undeclared
  `reth1.7` is still dropped with one warning.
- Update `pkg/dhcpserver/README.md` to document the declared-unit allowlist and
  the #18853 case.

## Validation

- **RED mutant**: disabling the unit-name allowlist made
  `TestKeaBeltKeepsDeclaredTaggedUnit15206` fail: the valid `.180` device and
  phantom were both dropped (`Interfaces: []`).
- **GREEN**: after restoring the unit allowlist,
  `env -u GOTMPDIR TMPDIR=/tmp go test ./pkg/dhcpserver -count=1 -run
  '^TestKea.*15206$'` passed, including the new tagged-unit cell and all
  neighboring #15206 cases.
- `env -u GOTMPDIR TMPDIR=/tmp go test ./pkg/daemon -count=3 -run
  '^(TestFilterDHCPConfigForMasterRGs_TaggedRethUnitMatches|TestTaggedRethGroupIsRGScoped9407)$'`
  passed. These existing master-RG cells are green on this base and are not
  claimed as fixed by the Kea-belt change.

## Risk

Only declared unit kernel names are added to the allowlist. Unknown or
undeclared DHCP group devices remain fail-closed and continue to produce a
warning.
