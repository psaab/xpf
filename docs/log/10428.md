# #10428 — DHCP HA memfile fallback preserves IPv4 hardware address

- **Timestamp**: 2026-09-18
- **Finding**: GEMINI-049-093 / #10428. A DHCPv4 memfile row containing both
  `client_id` (Option 61) and `hwaddr` was packed into the DDNS owner key
  `cid:<client-id>`. The fallback then unpacked that lossy key and seeded
  `lease4-add` without the mandatory `hw-address` field.
- **Change**: retain the two v4 memfile columns separately on `ddnsLease`,
  keep `Identity` client-id-preferred for DDNS ownership stability, and have
  `readSyncLeasesViaMemfile` copy the retained fields directly into
  `SyncLease`. The obsolete lossy `splitV4Identity` path is removed.
