# #12596 — retain interface sampling in compact spellings

- **Timestamp**: 2026-10-13
- **Base**: `master` `c49e22437`
- **Action**: Normalize brace-elided and packed interface sampling heads and leaves before strict compilation.

## Red before

`CompileConfig` and `configstore.CheckText` accepted the braced control with `SamplingInput=true` and `SamplingOutput=true`, but silently compiled the issue spellings to false flags: `family inet sampling { input; }`, `family inet { sampling input; }`, and `family inet { sampling { input; } sampling output; }`. The reverse mixed sibling order also dropped input. Inet6 had the same elided-head and packed-leaf losses. No strict error or diagnostic disclosed the missing configuration.

The AST showed the forms that the compiler reader could not see: the parser stores `family inet sampling` on the family node's own `Keys`, stores packed `sampling input`/`output` on the sampling node's `Keys`, and leaves a packed sampling sibling as a distinct family child. The compiler's `FindChildren("sampling")` loop only read braced sampling siblings. Strict CheckText and direct CompileConfig share `normalizeCompactStanzas` before compilation.

## Change

- Admit only the interface-family pairs `inet sampling`/`inet6 sampling` and sampling-direction pairs `sampling input`/`sampling output` in the existing schema-guided compact normalizer. This converts elided container/leaf keys into the child nodes the existing compiler union reader consumes; forwarding-options sampling is not in these interface-specific pairs.
- Add config-compiler and strict `CheckText` regressions for braced control, elided family, packed input/output, both mixed sibling orders, both address families, and unit-plus-family elision.
- Remove the four completed sampling rows from both the divergence inventory and the permanent-exclusion register. Update the family-only and packed-opt-in measurements plus the multisite/blind-pair ratchets for the newly admitted schema pairs.

## Risk

Persisted hierarchical text configurations using these spellings now set the sampling flags they already declared, rather than silently disabling them. The compiler and schema are unchanged; normalization remains limited to these specific family and sampling pairs. No live dataplane traffic validation was performed.
