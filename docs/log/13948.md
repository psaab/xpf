# Issue #13948 — Gate pre-policy RX neighbor learning to on-link sources

## Why

The pre-policy RX source-learn path could cache a routed source address with the upstream router's source MAC before policy admission. A denied-traffic source flood could fill bounded dynamic-neighbor capacity and serialize workers on the map's bulk learn lock, competing with legitimate on-link hosts. The post-admission source-learn twin already rejects off-link sources (#13644).

## What

- Apply the existing VLAN-resolved `src_ip_on_link_for_ingress` predicate to the pre-policy frame learn before any dynamic-neighbor map access.
- Preserve the established synthetic fabric source-MAC exemption (#12051); the gate runs after reading the frame's source MAC and only excludes non-synthetic off-link sources.
- Add v4/v6 on-link and off-link controls, an unrelated-ingress control, plus a 10k distinct off-link-source flood assertion for zero map growth and zero learn-cap drops.
- Update the two existing synthetic-ingress controls to use connected test prefixes, preserving their intended learn/skip assertions under the new on-link rule.

## Validation

- **RED:** with only the new on-link gate removed, `pre_policy_neighbor_learn_rejects_off_link_sources_13948` failed because the off-link v4 address was installed with the source MAC.
- **GREEN:** `cargo test --manifest-path userspace-dp/Cargo.toml --bin xpf-userspace-dp pre_policy_ -- --nocapture` passed 3 tests, including the 10k source flood.
- Full userspace binary suite after the final test correction: 8147 passed, 4 failed, 8 ignored. Failures were `tunnel_flow_cache_keys_mac_change_shard_on_outer_neighbor_not_logical_ifindex` (test shard-hash precondition), `fixture_pkt_len_is_the_full_frame_length_6883` (stale resolver-enqueue fixture), `worker_loop_orders_expiry_teardown_before_poll_10419`, and `additive_wire_exhaustive_literals_only_ever_decrease_7689` (StaticNATRuleSnapshot literal count). An earlier full-suite run had 8148 passed, 3 failed, 8 ignored; no source tests in this change failed.

## Risk

Pre-policy learning no longer warms dynamic neighbors from off-link transit sources; these addresses are not valid neighbor identities on the ingress link. Packet forwarding and policy decisions are unchanged. On-link learning and synthetic fabric source handling remain intact.
