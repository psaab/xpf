# #16439 — `debug-log`-only regression cells ran in no gate

## Defect

Every `cargo test` invocation in the tree ran default features, so
regression cells that discriminate only under `--features debug-log`
were dead in every `make test` leg:

- `accumulate_carries_policy_revoked_sessions_10021` lives in
  `userspace-dp/src/afxdp/worker/loop_body/debug_report.rs`, whose
  module is declared `#[cfg(feature = "debug-log")]` in
  `worker/loop_body/mod.rs` — the cell is absent from the
  default-feature test binary entirely (probe on this branch: a
  default-feature `--list` does not contain it; with the feature,
  Cargo lists 9377 tests including it).
- The discriminating assertions of
  `direct_tx_tuple_mismatch_recycles_frame_exactly_once` (#4041) and
  of the two #9782 no-false-mismatch cells sit inside
  `if cfg!(feature = "debug-log")`, so they compiled but never
  executed their oracle branches in any leg.

The only `debug-log` recipe was the compile-only
`build-userspace-dp-debug-log` (deliberately not a gate), and CI runs
only `cargo check`. A regression reintroducing the #4041 duplicate
`push_front` in the debug-log arm of `tx/dispatch/mod.rs`, or dropping
`policy_revoked_sessions` from `DbgCounters::accumulate`, left
`make test` green while a lab debug-log build aliased TX frames or
lost the revocation counter.

## Fix

One new leg, Leg 3 of `make test-rust` — no new make target, no CI
change (CI still does not run the Rust suite; see
`docs/ci-gate-contract.md`):

- `Makefile`: `DEBUG_LOG_CELLS_16439` names the four cells exactly;
  Leg 3 builds the `xpf-userspace-dp` bin test binary with
  `--features debug-log`, greps `--list` output requiring each cell
  exactly once (`grep -c -F -x`), and only then runs them with
  `--exact`. A rename, deletion, or feature-gate change matches
  nothing and fails the leg before any cell runs — 0-passed can
  never read as green. Dev profile (matching Leg 2), not
  `--release`: the feature, not the profile, gates these cells.
- Roster (all four discriminating cells, not only the two named in
  the issue's abbreviated fix direction):
  - `afxdp::worker::loop_body::debug_report::policy_revoked_sessions_fold_tests::accumulate_carries_policy_revoked_sessions_10021`
  - `afxdp::tx::dispatch::tests::enqueue_failure::direct_tx_tuple_mismatch_recycles_frame_exactly_once`
  - `afxdp::tx::dispatch::tests::enqueue_failure::direct_tx_pat_translation_is_not_a_tuple_mismatch_9782`
  - `afxdp::tx::dispatch::tests::segmentation::segmentation_pat_translation_survives_expected_ports_9782`
- `pkg/docsref/debug_log_leg_16439_test.go`:
  `TestDebugLogLeg16439` censuses the leg at Go-test speed — the
  Makefile variable equals this registry in order, the recipe line
  carries `--features debug-log`, `--bin xpf-userspace-dp`,
  `-- --list`, `grep -c -F -x`, `--exact $(DEBUG_LOG_CELLS_16439)`
  in list-then-run order, every cell is still a `#[test] fn` in its
  source file, the gate-contract row names Leg 3, and this log
  names the full roster. Its mutation table (dropped variable,
  dropped cell, dropped feature flag, widened exact, dropped list
  census, renamed consumer) must each fail validation.
- `docs/ci-gate-contract.md`: the `make test-rust` row now names
  Leg 3 (#16439).
- RED-on-revert comments in `debug_report.rs` and
  `enqueue_failure.rs` now cite `make test-rust` Leg 3 as the
  enforcing gate instead of a manual `--features debug-log` run
  nothing performed; the `build-userspace-dp-debug-log` header no
  longer claims the feature is unwired into `test`.

NOT changed: the production (non-debug-log) build, the opt-in
status of `build-userspace-dp-debug-log` in `all`/`build`, CI, and
`userspace-dp/debug-leg.tests` (Leg 2's default-feature registry;
the debug-log cells are not default-feature tests and do not
belong there).

## Tests

- Probe + targeted run (pinned 1.98.1,
  `GOCACHE`/`CARGO_TARGET_DIR` under `/var/worktrees/.cache`):
  `cargo test --features debug-log --bin xpf-userspace-dp -- --list`
  lists 9377 tests including all four roster cells; the default
  listing omits the debug_report cell. The four cells run
  `--exact --test-threads=1`: 4 passed, 0 failed.
- `TestDebugLogLeg16439` passes on this branch; each of its six
  Makefile mutations plus the contract/log/Rust-source absences
  validate as failures inside the test itself.
- RED-on-revert: deleting the `policy_revoked_sessions` accumulate
  line reds cell 1; restoring the #4041 duplicate `push_front` in
  the debug-log arm reds cell 2 (pool length grows, offset appears
  twice); a false tuple mismatch reds cells 3–4.

## Risk

`make test-rust` gains one dev-profile `--features debug-log` build
of the bin test binary (~4 min cold on this host, seconds warm via
the shared `CARGO_TARGET_DIR`) and four single-threaded cells
(<1 s). No production artifact changes: `debug-log` remains opt-in
outside this test leg, and the shipped helper is still built by
`build-userspace-dp` without the feature. Renaming any roster cell
now fails the Go census immediately instead of silently narrowing
the executed oracle.
