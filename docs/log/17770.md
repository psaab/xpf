# #17770 — Report observed unmanaged SSH state

- **Timestamp**: 2026-10-28
  - **Action**: The CLI and gRPC renderers no longer infer that sshd is running when `system services ssh` is absent. Both use the shared `pkg/sysservices` probe of systemd's `sshd.service` state and shared row formatter: loaded+active is `running`, loaded/masked+inactive/failed is `stopped`, and an unavailable, missing, or unexpected state is `unknown`. The base-image-defaults explanation is retained only for observed `running`. Added hermetic running/stopped/unknown renderer cases and unit tests for state classification and formatting. The probe is read-only and bounded to two seconds; xpf still does not own sshd enablement.
