# #17770 — Report observed unmanaged SSH state

- **Timestamp**: 2026-10-28
  - **Action**: The CLI and gRPC renderers no longer infer that sshd is running when `system services ssh` is absent. Both use the shared `pkg/sysservices` probe of systemd's `sshd.service` state and shared row formatter: loaded+active is `running`, loaded/masked+inactive/failed is `stopped`, and an unavailable, missing, or unexpected state is `unknown`. The base-image-defaults explanation is retained only for observed `running`. Added hermetic running/stopped/unknown renderer cases and unit tests for state classification and formatting. The probe is read-only and bounded to two seconds; xpf still does not own sshd enablement.
  - **File(s)**: `pkg/sysservices/listeners.go`, `pkg/sysservices/sshd_state.go` (new), `pkg/sysservices/sshd_state_test.go` (new), `pkg/cli/cli.go`, `pkg/cli/cli_show_system.go`, `pkg/cli/cli_show_ssh_observed_17770_test.go` (new), `pkg/cli/cli_show_ssh_unmanaged_16737_test.go`, `pkg/grpcapi/server.go`, `pkg/grpcapi/server_show_system.go`, `pkg/grpcapi/server_show_ssh_observed_17770_test.go` (new), `pkg/grpcapi/server_show_ssh_unmanaged_16737_test.go`, `docs/feature-gaps.md`, `pkg/daemon/README.md`, `docs/log/17770.md`.
  - **Validation**: RED before implementation: the named gRPC regression test failed to compile because `SSHDState` and the shared probe/test seam were absent. GREEN: targeted `pkg/grpcapi` tests (`TestShowSystemUnmanagedSSHReportsObservedState17770` and the #16737 unmanaged/managed controls), targeted `pkg/cli` equivalents, and `pkg/sysservices` state/formatter tests passed. `go build ./pkg/cli/ ./pkg/grpcapi/` passed.
  - **Risk**: Hosts without a queryable systemd `sshd.service` (or with an unexpected unit state) now report `unknown`, not an assumed state. The probe does not start, stop, or otherwise manage sshd.
