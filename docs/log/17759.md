# #17759 — configured but uninstalled secondary address freezes IP-monitor debt

- **Timestamp**: 2026-10-28
- **Branch**: `fix/17759-campaign`
- **Issue**: `cluster: configured-but-uninstalled secondary address counts as measurable; DOWN debt frozen`
- **File(s)**: `pkg/cluster/monitor.go`, `pkg/cluster/ip_monitor_demoted_unmeasurable_16734_test.go`, `docs/feature-coverage.md`, `debian/changelog`

## Defect

`probeSourceFor` treated any nonempty `secondary-ip-address` as measurable without confirming it was assigned to the resolved local target interface. When the configured address was not installed, the source bind failed on every probe; not-completed outcomes therefore preserved an old DOWN state and its election debt indefinitely.

## Change

For secondary sources, measurability now requires netlink to confirm the configured address is present on the resolved interface. A clean address list without it, or a typed `LinkNotFoundError` followed by a clean `LinkList` that also omits the interface, confirms absence; a not-completed probe then releases stale DOWN state and reconciles away its debt. Other link/list/address errors—including interrupted partial dumps—are inconclusive and preserve the prior neutral behavior. Primary and unbound probe behavior is unchanged.

The #16734 global-threshold test covers an uninstalled address, clean confirmed missing interface, and an address present only on another interface; confirmed absence releases weight-0 debt. Generic link lookup/list failures, an interrupted partial link dump, generic/interrupted partial address-list failures all retain pre-existing DOWN debt. The measurable-abort test also pins an inconclusive lookup as measurable, guarding `present || !verified`.

## Risk

`defaultNlHandle` creates the pinned vishvananda/netlink `Handle`. On supported kernels, `LinkByName` uses the direct `RTM_GETLINK`/`IFLA_IFNAME` request; if the kernel rejects it, the legacy dump fallback can hide `ErrDumpInterrupted` when it reports typed not-found. Therefore a typed not-found is accepted only if a separate `LinkList` returns cleanly and also omits the interface; interrupted or failed confirmation remains neutral. In v1.3.1 `AddrList` returns partial records with `executeErr`, including `ErrDumpInterrupted`; `installedAddress` treats all non-nil address-list errors as inconclusive, and the regression pins partial data plus that error. Residual bound: if a kernel returns an incomplete/stale list without reporting a dump error, one local per-target debt could release for a cycle; election keeps a weight-positive node secondary while a live primary exists (no dual-primary path), and the next completed DOWN probe re-dampens. No netlink-mutating test ran.
