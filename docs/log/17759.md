# #17759 — configured but uninstalled secondary address freezes IP-monitor debt

- **Timestamp**: 2026-10-28
- **Branch**: `fix/17759-campaign`
- **Issue**: `cluster: configured-but-uninstalled secondary address counts as measurable; DOWN debt frozen`
- **File(s)**: `pkg/cluster/monitor.go`, `pkg/cluster/ip_monitor_demoted_unmeasurable_16734_test.go`, `docs/feature-coverage.md`, `debian/changelog`

## Defect

`probeSourceFor` treated any nonempty `secondary-ip-address` as measurable without confirming it was assigned to the resolved local target interface. When the configured address was not installed, the source bind failed on every probe; not-completed outcomes therefore preserved an old DOWN state and its election debt indefinitely.

## Change

For secondary sources, measurability now requires netlink to confirm the configured address is present on the resolved interface. A confirmed absence—including a typed `LinkNotFoundError` for the interface—makes the not-completed probe unmeasurable, so the existing poll-cycle release clears stale DOWN state and reconciles away its debt. Other link/address-query failures are inconclusive, so the monitor preserves the prior neutral behavior. Primary and unbound probe behavior is unchanged.

The #16734 global-threshold test covers configured-but-uninstalled addresses and a missing interface as confirmed absence; both release weight-0 debt. A transient address-list error is a control that preserves the existing debt. The measurable-abort control explicitly lists the installed source and continues to require neutral handling. Feature coverage and the Debian changelog describe the updated boundary.
