# #16543: `<*>` group never binds to a bare named OSPF interface or BGP neighbor leaf

- **Timestamp**: 2026-10-24
- **Problem**: `set groups AUTH protocols ospf area 0.0.0.0 interface <*> authentication md5 1 key K` + `apply-groups AUTH` + bare `set protocols ospf area 0.0.0.0 interface ge-0/0/0.0` compiled `OSPFInterface{AuthType:"", AuthKeyID:0}` and FRR emitted no message-digest lines — the adjacency ran unauthenticated on a clean commit. The BGP neighbor-level path (`neighbor <*> authentication-key` + bare `neighbor 192.0.2.2;`) was the same, ending with an empty `AuthPassword` and no `neighbor X password`. Root cause: the wildcard arm in `mergeNodes` (`pkg/config/ast_groups.go`) visited only non-leaf destinations except zones (`zoneLeafTakesWildcard9801`, #9801); #15032 promoted only packed interface leaves ("Bare leaves have no tail and stay for #9838"). Measured RED on `origin/master` (3027e34128): bare rows compiled `auth=""`/`pw=""` where braced/attr controls compiled `md5/1/K`.
- **Fix**: Generalize #9801 schema-driven. New `pkg/config/group_merge_bare_leaf_16543.go`: `bareInstanceLeaf16543` admits a bare leaf iff its identity is fully consumed by its schema slot (keyword + declared args via `consumeNodeKeys`, incl. compound keys) AND that slot is a container (`children != nil || wildcard != nil`) — exactly the slots `namedInstances`/`bracketedGroupInstances8794`/`FindChildren` compile an instance from (OSPF/OSPFv3/IS-IS interface, BGP neighbor, RA interface, LLDP interface, policies, etc.). Bracketed tails (value lists) and packed tails (extra keys past identity) stay untouched for the packed paths. `promoteBareInstanceLeaf16543` flips `IsLeaf=false`; the wildcard arm in `ast_groups.go` (`bare16543` beside the zone check) then merges the cloned group body in, honoring the #9862 growth-detect unchanged. The #9838 exclusion is literal (`isBareLeaf9838Slot`: ancestor is exactly top-level `interfaces`/`routing-instances`), so `TestBareLeafWildcardGroup9838` refusals stay byte-identical. NOT changed: compiler leaf handling, the #9838 gate, packed-leaf promotion (#15032), zone macro handling (#13112), any non-wildcard merge arm.
- **File(s)**: `pkg/config/group_merge_bare_leaf_16543.go` (new), `pkg/config/ast_groups.go`, `pkg/config/group_merge_zone_leaf_9801.go` (scope comment), `pkg/config/group_merge_bare_leaf_16543_test.go` (new), `pkg/frr/bare_leaf_wildcard_16543_test.go` (new), `pkg/config/README.md`, `docs/log/16543.md`
- **Validation**: RED on pristine base with only the new tests added: `def-bare-wild` OSPF/BGP, RA/OSPFv3/IS-IS/LLDP bare rows, flat-set row, and expanded-tree container row all fail with the unauthenticated values above. GREEN after the fix: `go test ./pkg/config/ -run 16543 -count=1` (6 tests: OSPF def/ctl/exact, BGP def/ctl, RA+OSPFv3+IS-IS+LLDP instances, flat-set, #9838 slots, expanded-tree container) and `go test ./pkg/frr/ -run 16543 -count=1` (FRR emits `ip ospf authentication message-digest` + `message-digest-key 1 md5 K` and `neighbor 192.0.2.2 password K` for def-bare-wild == ctl-attr-wild; no-group controls render no auth). Targeted suites `9801|9831|9838|9855|9862|9802|15032|Wildcard|BareLeaf` pass except pre-existing failures verified identical on unmodified `origin/master` (`TestTunnelEndpointIDWildcardApplyGroupsSingleInterfaceClean`, `TestWildcardTypedLeafKeyValidatorInventory_6844`, `TestInterfaceVLANBounds9899`, `TestGroupCanonicalWireGuardPeerKeepsKeywordOverride9859` — all degenerate-key/schema-inventory drift unrelated to this change). `go vet ./pkg/config/ ./pkg/frr/` clean; `gofmt` clean on all touched Go files.
- **Risk**: Behaviour delta is the fix itself: bare named-instance spellings now receive wildcard group content their braced spellings already received. Configs that relied on a bare OSPF/BGP instance escaping a `<*>` auth template will now be authenticated (the intended Junos outcome; a peer not expecting MD5 will fail to form until it is configured, which is the visible-correct direction for a configured security control). The schema gate (container slot + exact identity consumption + no bracketed keys) keeps scalar/multi leaves, bracket lists, and packed tails on their existing paths.
