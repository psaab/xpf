# Issue #15675 — source NAT pool `port` handling (V6-02)

## Claim
`security nat source pool <name> port`: empty/hierarchical `port range` silently defaulted to 1024-65535; `port no-translation` + `port deterministic` compiled without exclusivity; `port no-translation` pools charged 64,512 port slots/IP in the aggregate budget; `port <N>` / `random-allocation` rejected by SchemaValidate.

## Fix
- `setPortRange`: empty explicit range records non-empty `"<empty>"` sentinel in `PortRangeInvalidSpec` (strict rejects, snapshot marks pool unusable; raw fields keep unstamped default per #5457/#6688 lenient contract). Flat `port range;` (grouped bare `range` child) handled via deferred grouped-range pass that also preserves #13212 later-wins across grouped range leaves and #6688 tail rejection.
- Hierarchical `port { range { <low> to <high>; } }`: endpoints arrive as children of `range`; flattened and parsed.
- `validateSourceNATDeterministicStrict`: rejects `PortNoTranslation && Deterministic != nil` ("mutually exclusive"); lenient path downgrades to warning via existing uniform gates. `deterministicSourceNATFields`, `deterministicNAT64V6Fields`, and `pkg/nat poolParams` guard/suppress on `PortNoTranslation` for tolerated loads.
- `SourceNATPoolPortRange`: returns `0,0,true` for no-translation pools; `sourceNATAggregateReferencedCharges` charges `portCap=0` for them (address count still charged). Deterministic consumers unaffected (guarded/rejected before use; NAT64 snapshot keeps its fixed default range — no translated-port window is consumed by address-only pools on that path, deterministic mode-2 suppressed).
- Schema: `port` gains `random-allocation` / `no-random-allocation` children and a numeric wildcard (`port <N>` compiles as [N,N], strict-validated; unknown tokens fail closed at strict compile as invalid range). Compiler records `PortRandomAllocation` + authored marker; `no-random-allocation` is accepted-only with a `ValidateConfig` advisory (allocator seeds random offset), mirroring port-overloading doctrine.
- Axis sweep (#6812) registers the two new pool fields as fixture-constant.

## Regression
- `pkg/config/compiler_nat_source_pool_port_15675_test.go`: empty flat + hierarchical range fail-closed, hierarchical range block compiles 5000-6000, no-translation+deterministic strict reject/lenient warn + controls, zero port charge + control, `port 5000`/random/no-random SchemaValidate+compile+advisory, unknown keyword fail-closed.
- `pkg/dataplane/userspace/nat_source_det_notranslation_15675_test.go`: deterministic fields suppressed for no-translation (mode1+mode2) with controls.
