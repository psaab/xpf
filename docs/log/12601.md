# #12601 — reject packed nameless policy terms

## Why

A hierarchical `policy-statement { P term { ... } }` packs the policy name and
term keyword into one parser key run. The policy compiler sees only `P` as a
property and skips the term subtree, including `then local-preference 200
accept`. The existing typed #12521 check cannot reject a term the compiler
never placed in the typed policy, so strict compile and `CommitCheck` accepted
a config with an authored action silently dropped.

## What

The strict pre-walk now runs `ValidatePolicyNamelessTermsAST12521` against the
group-expanded tree, before policy compilation loses the packed shape. It uses
the existing #12521 diagnostic; tolerant compilation remains unchanged. Added
regression cases for action, match/action, and empty nameless term bodies, plus
a named-term control. Updated `docs/config-schema.md` to describe the packed
strict-path check.

## Validation

- RED: before the strict pre-walk gate,
  `go test ./pkg/config -run TestPolicyStatementMissingNameNestedShapeRejected12601 -count=1 -v`
  failed because the packed nameless term committed cleanly.
- GREEN: after the gate,
  `go test ./pkg/config -run 'TestPolicyStatementMissingNameNestedShapeRejected12601|TestPolicy.*Nameless.*12521|TestPolicyNamed.*12521' -count=1`
  passed.
- `go test ./pkg/configstore -run TestCommitCheckRejectsPackedNamelessPolicyTerm12601 -count=1` passed; it verifies the strict `CommitCheck` entry point rejects the packed case.
- `go build ./...` passed.
- `go test ./pkg/config ./pkg/configstore ./pkg/frr -count=1` did not pass: config tests reported inventory/spelling fixture disagreements and API-auth expiry errors before the 10-minute timeout; FRR integration cases failed because the environment cannot `setgroups` (`Operation not permitted`). These are outside the changed policy validation; the configstore package passed in this run.

## Risk

Strict compilation now rejects this previously accepted malformed spelling.
Tolerant load behavior and correctly named terms are unchanged.
