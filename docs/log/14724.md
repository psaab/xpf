# #14724 — eventengine latch, budget, and groups-priority leaks (D19-02)

## Issue
`evaluateEvent` arms `rt.onLatched` on a trigger-on crossing, but several
terminal non-commit exits never released it: the cooldown-stale drop and
the permanent-rejection return in `runAction`, and the classify-reject /
empty-plan continues in `HandleEvent`. A transient `commitFn` returning
`(nil, err)` therefore wedged a policy forever under a sustained fault.
`applyOnce` reserved a global-budget slot before `commitFn` and never
refunded it on failure — the `ErrClusterReadOnly` retry loop reserved
again per iteration — so a flapping standby could burn all 4 slots/60s
and starve healthy policies. `criticalConfigPath` checked only `path[0]`,
so `set groups <g> security …` classified ordinary and could be evicted
from a full queue. Shutdown abandons (worker gate / in-flight retry)
were left unreleased deliberately: process-terminal, no next event.

## Fix
- `pkg/eventengine/engine.go`: `releaseEdgeLatch` on the stale drop, the
  permanent-rejection return, and both `HandleEvent` pre-enqueue
  continues. Cooldown-stale is safe: the sibling commit armed the 30s
  cooldown, which still throttles re-fire; removed/redefined releases
  are revision-guarded no-ops.
- `reserveGlobalCommit` now returns the reserved timestamp;
  `refundGlobalCommit` removes the newest matching ring slot (double
  refund / pruned slot = no-op; cursor not rewound). `applyOnce`
  refunds on `(nil, err)` and standalone commit failure; promoted
  commits (incl. committed-with-debt) keep the slot. The
  `ErrClusterReadOnly` sentinel is preserved across the commit wrap so
  the standby action defers instead of rejecting.
- `pkg/eventengine/evaluate.go`: `criticalConfigPath` unwraps a leading
  `groups <name>`; `apply-groups`/`apply-groups-except` alone stay
  ordinary (no target subtree named).
- This reverses #6810's deliberate classify-reject/empty-plan
  keep-the-latch decision: deterministic rejections now re-attempt and
  re-count `rejected` per sustained event — counted churn accepted over
  a silently wedged latch. The #6810 pin test now documents the reversal
  and points to the #14724 successor cell.
