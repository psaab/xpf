# Issue #14440 — Unit-tunnel braced-scalar `source` / `destination` / `mode` silently dropped

## Why

The interface-level tunnel reader in `compileInterfaces`
(`pkg/config/compiler_interfaces.go`) had a raw pre-pass (#13215) that
reads `nodeVal` over `tunnelNode.Children` before
`tunnelRunChildren9156` flattens a braced scalar `source { 10.0.0.1; }`
into an empty `[source]` leaf plus a stray `[10.0.0.1]` sibling. The
unit-level tunnel reader iterated ONLY the flattened children, so its
`v != ""`-guarded leaves (`source`, `destination`, `mode`,
`keepalive`, `keepalive-retry`) read empty and were silently skipped.
Because a unit tunnel is built as `ifc.Tunnel.cloneForUnit(...)`, the
dropped unit leaves inherited the interface tunnel's source,
destination and mode: traffic addressed to the unit's peer was
encapsulated to the interface peer, and a braced
`mode { wireguard; }` flipping to inherited `gre` discarded the
WireGuard keys/peers and sent plaintext GRE to the wrong peer
(fail-open misdelivery + encryption loss). Interface-level braced
`keepalive { N; }` / `keepalive-retry { N; }` dropped the same way —
the #13215 pre-pass covered only source/destination/mode — losing
dead-peer detection. Silent on strict and lenient; no tunnel gate
reads the braced-scalar endpoints (the GRE-dup gate reads the
already-wrong compiled endpoints).

## What

- `pkg/config/tunnel_flat_run_9156.go`: new shared
  `applyTunnelBracedScalars14440(tc, tunnelNode)` — reads the raw
  tunnel children via `nodeVal` for `source`, `destination`, `mode`,
  `keepalive`, `keepalive-retry` (numeric arms via `strconv.Atoi`,
  mirroring the flattened-loop arms). `key`/`ttl` are deliberately not
  handled: their braced forms still fail `parseInterfaceNumeric9899`
  in the flattened loop (strict error / lenient quarantine).
- `pkg/config/compiler_interfaces.go`: the interface-level inline
  #13215 pre-pass is replaced by the shared helper (now also covering
  braced keepalive/keepalive-retry), and the unit-level reader calls
  the same helper after `cloneForUnit`, so only leaves the unit itself
  authored override inherited values. The flattened
  `tunnelRunChildren9156` loops are unchanged and re-assert flat
  spellings idempotently.
- `pkg/config/tunnelid.go`: `astTunnelModeWireguard` now matches via
  `nodeVal(prop) == "wireguard"` instead of `Keys[1]`, so the
  tunnel-endpoint collision gate's single-endpoint selection stays
  identical to the compiled outcome for the braced
  `mode { wireguard; }` spelling it previously missed.
- Regression tests
  (`pkg/config/compiler_interfaces_unit_tunnel_braced_14440_test.go`,
  `TestUnitTunnelBracedScalars14440`): unit braced scalars overriding
  an inherited interface tunnel (incl. inherited `key` and retained
  WireGuard peers), braced-vs-flat DeepEqual for unit and interface
  tunnels, standalone-unit braced `mode { wireguard; }`, inheritance
  control (unit authoring no tunnel leaves still inherits), and a
  flat-spelling control.

NOT changed: flat spellings at both levels, `key`/`ttl` handling,
`cloneForUnit` inheritance, `wireguard` / `routing-instance` /
`clear-dont-fragment-bit` arms, and the `skipUnit9899` /
`skipIface9899` quarantine flow.

## Validation

- RED (pre-fix, worktree at `origin/master` 6925ba685 with only the
  test file added): `TestUnitTunnelBracedScalars14440` fails — unit
  Source/Destination inherited (10.0.0.1/10.0.0.2 instead of
  10.0.1.1/10.0.1.2), unit Mode `gre` instead of `wireguard`,
  unit/interface braced keepalive/keepalive-retry 0, standalone unit
  Mode `gre` with empty endpoints; inheritance and flat controls pass.
- GREEN (post-fix): the new test plus the existing #13215 test
  (`TestCompileInterfacesWireguardRunAndDHCPv6PackedChildren`) pass;
  full `go test ./pkg/config/ -count=1` and `go vet ./pkg/config/`
  run for the final head (see PR).

## Risk

The pre-pass only supplies values the flattened loop would otherwise
read as empty; flat spellings compile identically before/after
(pinned by DeepEqual and flat controls). A unit that authors no
tunnel leaf still inherits the interface tunnel unchanged.
Residual: braced `key { N; }` / `ttl { N; }` remain strict-error /
lenient-quarantine by design (out of scope, unchanged).
