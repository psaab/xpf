# #9506 S4 evidence

## Scope

This lane implements the Go authority and kernel host-input surface from the r6 S4/T12 plan:

- immutable permit records with OPEN/CLOSING/CLOSED epochs, coupled watch publication, emission gates, terminal reservation, and the shared terminal commit lease (r6 §2.2, §3.2, §3.5; retained r5 §12.3);
- queue allocator identity `(generation,family,hook,owner,STN,ifindex)`, a 128-handle cap, epoch checks, quarantine, and rotation staging/rollback (r6 §3.5/T12);
- an iifname-only host-input overlay with a canonical master set and content marker carrying generation, permit epoch, close-request sequence/key, watch generation, and state;
- netlink install plus exact marker/rule/set readback before publication;
- separate full-revocation conntrack filtering/debt for every local destination, including addresses outside the ordinary host-inbound deny views, and the close/retire protocol: old-set conntrack ACK, empty candidate install/readback, then pointer clear.

The production S4 supervisor loop is joined to daemon shutdown and runs bounded maintenance at 5 ms. Its RTNL link subscription classifies updates against the immutable topology snapshot: relevant xfrmi/master/outlet changes revoke immediately, while proven-irrelevant noise takes the census-only path and leaves an unchanged permit untouched. The census resolves every xfrmi master and the daemon-owned `xpf-usp1` outlet, producing SAFE/UNSAFE/UNKNOWN readiness; bridge/VRF/l3mdev attachment, outlet enslavement, incomplete kinds, unresolved masters, and missing outlet identity never open the permit. The overlay owner resolves positive master indexes at reconciliation time and serializes install/retire through `applySem`; unresolved positive indexes fail closed. Candidate conntrack failures retain the verified DROP and exact retry debt; a differing old-set ACK failure blocks replacement. Cold-start readback failure retains the candidate fence rather than falling back to the ordinary table.

## Measurements / invariants

- Supervisor maintenance cadence: `5ms`, joined to the daemon `WaitGroup`.
- Queue allocator capacity: `128` active/quarantined handles (the plan’s 32 tunnels × 4 provenance classes bound).
- Overlay marker: SHA-256 content marker truncated to 12 bytes (`xpf_hif_...`), over sorted/deduplicated masters and all authority fields.
- Conntrack debt retries use the existing joined 30-second owner; verified candidate rules remain installed while retry debt is outstanding.
- Terminal ACCEPT/DROP is reserved once per `(gate, queue, queue epoch, packet)`; sink errors remain uncertain/terminal and are not replayed.

## S5 handoff / STOP boundary

STOP for this lane is intentional at the Rust/capture boundary. The following remain for the S5 owner and are not represented as complete by this Go PR:

1. Rust q0 full-frame writer and the physical REINJECT ACK/commit point; Go only supplies the immutable lease/epoch authority and terminal accounting.
2. `CaptureOrigin` parsing and provenance preservation through slowpath/fragment handling, including the staged worker/capture evidence required by r6 §8–§9 and the r5 §4.2 commit table.
3. nfqueue capture pipeline wiring, per-flow FIFO/fragment slots, owner-homogeneous batching, bounded handoff/capture queues, and real T12/G2 live cells across `pkg/nfqueue`, `userspace-dp`, and capture-origin paths.
4. The live kernel/HA validation cells that require the isolated userspace cluster; this lane only proves deterministic Go seams and package tests.

S5 must consume the permit epoch, queue epoch, overlay marker/readback, and old-set conntrack ACK contracts above; it must not reopen the Go authority or bypass the iifname-only host fence.
