# Issue #14987 — cli: enforce configuration and command regex gates on CLI config read, diff, commit, rollback, and load (D37-02)

- **Timestamp**: 2026-10-18
  - **Action**: Residual of closed #14707 (do not reopen). On base `5b3b02a61f` the gRPC/REST config reads and the CLI `show configuration` / config-mode `show [path]` arms already adjudicated `*-configuration` + path/format-scoped `*-commands` via the shared `AuthorizeConfigShow*` decision, and `load`/`rollback <N>` (config verb) already refused restricted classes (#9892). Measured survivors on the CLI (probe driving the real dispatchers, since removed): (1) `show system rollback 1` (and `| display set`, and `run show system rollback 1` from config mode) served the whole earlier tree — including the denied `security` subtree — to a `deny-configuration "^security"` class and to a `deny-commands "^show configuration$"` class, because `dispatchOperational` charged only the literal `show system rollback` spelling and no `*-configuration` arm existed for that spelling; (2) `show system login` / `root-authentication` / `configuration rescue` rendered config subtrees/whole text with the same gap; (3) config-mode `show system host-name | display set` was ALLOWED for `deny-commands "display set"` — root-caused to a suffix-spelling bug in the shared gate: the CLI strips `display ` (`displaySuffix14707` → `"set"`) while gRPC/REST pass `ConfigShowDisplaySuffix` output (`"display set"`), and `authorizeShowCommand` concatenated verbatim, so the CLI matched `… | set`, which the deny never fires on (the gRPC/REST `display set` cells in #14707 pass because they use the other spelling); (4) config-mode `show | compare [rollback <N>]` was adjudicated as a path render (edit path only), not as the candidate-diff whole-tree render it is. Fix: `pkg/config/authz_config_read_14707.go` — `authorizeShowCommand` normalizes a bare format word to `display <fmt>` at the one place the matched string is built; new `AuthorizeConfigShowSystemPath` (per-path `*-configuration` + real-spelling `*-commands` with bare `show configuration` alternate) and `AuthorizeConfigShowRescue` (whole-tree refusal + real spelling). `pkg/cli/permissions_config_read_14707.go` — `checkConfigShowRegex` routes a `| compare` pipe to `AuthorizeConfigShowCompare`; new `checkShowSystemConfigRead` mirrors `handleShowSystem` token-exactly (bare rollback = timestamp list, ungated; `compare N` / `N compare` = candidate compare; `| display set` wins over compare; malformed shapes render nothing and stay ungated). `pkg/cli/cli_dispatch.go` — `dispatchOperational` calls `checkShowSystemConfigRead` for resolved `show system …` (covers `run …` re-entry). NOT changed: `commit` / config-mode `rollback <N>` / `load` adjudication (candidate paths gated as written; whole-candidate replacements already refuse restricted classes; config-mode verbs carry no operational command on any surface per `AuthorizeConfigMutation` doc — no `*-commands` charge added), coarse prices, redaction, store renderers, gRPC/REST request decoding.
