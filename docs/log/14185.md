# Issue #14185 — DHCPv6 IA_NA address validation

- **Timestamp**: 2026-10-16
  - **Action**: `selectIANAAddress` (`pkg/dhcp/dhcpv6.go`) now validates
    every IAADDR candidate before ranking: it discards
    preferred-lifetime > valid-lifetime candidates (RFC 8415 §21.6 MUST),
    refuses non-global-unicast / special-purpose classes via the IA_PD
    policy `config.DelegatedIPv6PrefixRefusalReason` on the `/128`
    (loopback, link-local, multicast, unspecified, ULA, documentation,
    IPv4-compatible/mapped, site-local), and refuses addresses
    overlapping the protected configured-prefix set
    (`Manager.protectedIPv6Prefixes`, #10856 parity). Each refused
    IAADDR is skipped independently so a usable sibling is salvaged;
    refusal never synthesizes a withdrawal, so the #5927
    present-but-0 invalidation semantics are unchanged. The signature
    now takes non-variadic `expectedIAID *[4]byte` and
    `protected []netip.Prefix`; `parseV6ReplyChecked` passes the Manager
    snapshot. Regression tests in
    `pkg/dhcp/dhcpv6_iana_validation_14185_test.go` cover every refused
    class (sibling salvage + solo rejection + parse-level failure),
    pref>valid (including the pref=0xFFFFFFFF/valid=1s ranking trap and
    the pref==valid infinite control), protected overlap (direct and
    Manager-installed), and GUA controls. Existing reply-driven fixtures
    that used documentation-space `2001:db8::` IA_NA addresses (now
    refused by design, as with the #10856 IA_PD migration) moved to GUA
    `2606:4700::` space. README IA_NA contract updated.

## Validation

- RED (pristine `origin/master` 43ebebd38 + only the new test file,
  protected-overlap cell via the Manager path so it compiles on the
  old signature): every refused class selected the bad address over
  the longest-pref sibling, solo refused-class replies parsed, the
  pref>valid candidate won with a 1s valid lifetime, and a
  protected-overlapping IA_NA was installed. GUA control passed.
- GREEN (this branch): the four `14185` tests pass; full
  `go test ./pkg/dhcp -count=1` passes; `go test -race` on the
  IANA/ParseV6Reply/14185 subset passes; `go vet ./pkg/dhcp` and
  `gofmt -l` on touched files are clean.

## Risk

- Behaviour delta: a server offering only ULA, documentation, or
  otherwise special-purpose IA_NA space — or an address inside the
  operator's own configured prefixes — now yields no usable IA_NA and
  the acquire/renew loop retries, exactly as an IA_PD-only refusal
  already did. No pin/allowlist exists (#12533 tracks one); refusing
  is the fail-closed direction for an address bound on the firewall
  itself.
- NOT changed: Advertise/Reply matcher paths (`v6AdvertiseMatches`,
  `v6ReplyMatches`) validate transaction/server/IAID/status only, as
  before; address validation lives at the single parse site every
  committed lease flows through. IA_PD extraction is untouched.
