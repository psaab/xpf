# #17892 — Identity-free declined v4 leases lack Kea's mandatory hw-address

- **Timestamp**: 2026-10-26
- **Action**: Preserved identity-free declined lease pre-seeding through Kea's control-socket backstop by supplying a parseable all-zero `hw-address` when a declined IPv4 row has no hardware address. Client-ID-only declined rows need the same field because Kea's IPv4 lease parser requires `hw-address` independently of `client-id`; the real client ID and declined `state=1` are retained. Active rows and declined rows with a real hardware address remain unchanged.
