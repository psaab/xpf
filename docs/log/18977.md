# Issue #18977 — validate throughput-gate identity before judging

- **Timestamp:** 2026-11-05
- **Action:** Promoted the ephemeral loss-throughput comparator to `test/incus/compare-gate.sh`. It validates identity before verdict computation, checks parser exit status, selects records by `node0=`/`node1=` prefix, rejects duplicate keys, and requires each record hostname to match the corresponding distinct node ref sourced from `cluster-env.sh`. Each record must contain `running_sha`, `helper_sha`, `deb_version`, and `source_sha`; both nodes' running/helper hashes must match staged manifests in the pinned deb, with deb version and source SHA matching the pinned inputs. `XPF_GATE_ID` is required. The ledger emitter must succeed before the gate prints its verdict, so invalid identity, unset gate ID, or an emitter refusal cannot print `verdict=` or leave an unjudged shard. `PR_RUNTIME_VERSION` remains positional for invocation compatibility and is currently unused; the pinned deb version and source SHA are checked via `PR_DEB_VERSION` and `PR_SHA`.
- **File(s):** `test/incus/compare-gate.sh`, `test/incus/compare-gate-selftest.sh`, `test/incus/HARNESSES.unreached`, `scripts/run-selftests.sh`, `docs/log/18977.md`.
- **Validation:** `bash -n test/incus/compare-gate.sh`, `bash -n test/incus/compare-gate-selftest.sh`, and `bash -n scripts/run-selftests.sh` passed. `bash test/incus/compare-gate-selftest.sh` passed all 23 cases, including FAIL/PASS/VOID shards, header-prefixed identity, incident and malformed identity, duplicate key/wrong host, deb-version/source mismatches, unset gate ID, emitter refusal, and RED-on-revert. `bash test/incus/harness-census-selftest.sh` passed all 30 cases; its real-tree census reported 71 runnable harnesses, 45 reached, and 26 declared unreached. `bash scripts/selftest-census.sh` reported that this selftest is registered; it exited 1 for two other entries: unregistered `test/incus/connectivity-mtr-selftest.sh` and odd-name `test/fabricsegment/selftest-fabricsegment-kernel_18719.sh`.
