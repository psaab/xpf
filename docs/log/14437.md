# #14437 — DR18-H1 OSPFv2 two-interfaces one packed run

## Mechanism
Inside a braced area, `interface ge-0/0/0.0 authentication simple-password "SECRET" interface ge-0/0/1.0 cost 10;` arrives as ONE childless node whose Keys carry the whole run. The OSPFv2 area loop (`compiler_protocols.go`, `FindChildren("interface")`) sees one interface, and `packedBodyChildren` (`compact_tail.go`) bails out whole at the second `interface` token — declared at no open level of the per-interface call — returning `node.Children` (empty). IF1 compiles with `AuthType==""`/`AuthKey==""` (pkg/frr activates it unauthenticated) and IF2 never becomes a node. Strict-accepted; the fully-elided spelling folds to the same node. Same bailout in the OSPFv3 loop (availability only — no v3 auth leaf). Measured on base: packed → 1 interface, auth empty, cost 0; braced twin → 2 interfaces, simple/SECRET + cost 10.

## Fix
- New `pkg/config/compiler_protocols_ospf_packed_interfaces_14437.go`: `splitPackedSiblingInterfaceNodes14437` splits a childless packed run at each subsequent unquoted `interface` head (no OSPF interface-body child takes a bare `interface` value, so the split is sound; quoted `interface` tokens stay body tokens), preserving per-fragment KeysQuoted/KeysBracketed, never mutating the input. It also splits the normalizer's child-carried fused tail (e.g. a v3 `cost`-first run reshaped to head + fused child), whose leading segment joins the head fragment. Braced/Children-carrying and single-head nodes pass through as the identical slice/pointer.
- `pkg/config/compiler_protocols.go`: both the OSPFv2 (line 101) and OSPFv3 (line 778) area interface loops wrap their `FindChildren("interface")` result with the split, before the existing `bracketedGroupInstances8794` + find-or-create (#8436) + `packedBodyChildren` (#7653) path.
- `compact_tail.go` bailout NOT changed — it stays all-or-nothing for genuinely unmodelled grammar; the fix is caller-side. Single-interface packed auth (#7653) and same-name merge (#8436) unchanged (pinned).
