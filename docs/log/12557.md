# docs/log/12557.md — #12557 (temp-OK owner-write-fail resurrects MAC-form claim)

- **Timestamp**: 2026-10-13
- **Action**: Carry pre-temp interface names out of `breakNameCollisions` and use them when neutralizing unknown-original positional links.
- **Base**: `origin/master` at `c94ed75eb`
- **Files**: `pkg/daemon/linksetup.go`, `pkg/daemon/device_map.go`, `pkg/daemon/collision_break_premise_7205_test.go`, `pkg/daemon/linksetup_originalname_12156_test.go`, `docs/log/12557.md`

## Why

On the #12156 unknown-original target-change path, phase 1 can successfully rename the unknown NIC from its old logical name to `xpf-tmp-N`. Phase 2 then used that transient key to remove the NIC's own managed `.link`; the actual retained MAC-form link remained at the pre-temp name. If the known owner's replacement link write failed (for example, because the recovered `OriginalName=` contains a glob rejected by #10089), the old MAC-form claim survived and udev could restore the unknown NIC under the owner's identity on next boot. Issue #12557 reports this single-fault shape as 100/100 wrong on both PR head and master.

## What

- `breakNameCollisions` now returns a `preTemp` mapping for successfully temp-renamed desired sources, keyed by their transient name. It still carries the desired target and original-name metadata as before.
- Positional naming uses this mapping to neutralize the durable link for the pre-temp interface name, while continuing to neutralize the target's stale link. The device-map caller and direct helper tests accept the additional return value.
- Added a deterministic single-fault regression that allows all temp renames to succeed, refuses the known owner's globbed link write, and asserts both old and stale links are absent. Added a helper-level assertion for the pre-temp carry.

## Validation

- **Issue-reported RED baseline**: #12557 records the `TestCHSingleFaultTempOKOwnerWriteFail` probe as 100/100 wrong on PR head and origin/master.
- **Regression assertion**: `TestCHSingleFaultTempOKOwnerWriteFail12557` reproduces the temp-OK/owner-write-fail path and asserts the MAC-form file cannot survive. The helper carry regression also verifies the original interface name follows the temp key.
- **Full daemon package GREEN**: `go test ./pkg/daemon` passed (`ok`, 561.354s).
- `gofmt -d` on all modified Go files produced no output; `git diff --check` passed.

## Risk

The additional return value is internal to the shared collision helper. The device-map caller ignores the pre-temp mapping because its stranded/unmapped cleanup already uses the original `presentNIC` name. Positional cleanup remains limited to managed `.link` files and retains the established unknown-first-before-owner-write ordering.
