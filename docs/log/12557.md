- **Timestamp**: 2026-10-13 (review fold 2026-10-13, rebased on `master` `a7354b535`)

- **Files**: `pkg/daemon/linksetup.go`, `pkg/daemon/device_map.go`, `pkg/daemon/collision_break_premise_7205_test.go`, `pkg/daemon/linksetup_originalname_12156_test.go`, `pkg/daemon/README.md`, `docs/log/12557.md`

## Why

On the #12156 unknown-original target-change path, phase 1 can successfully rename the unknown NIC from its old logical name to `xpf-tmp-N`. Phase 2 then used that transient key to remove the NIC's own managed `.link`; the actual retained MAC-form link remained at the pre-temp name. If the known owner's replacement link write failed (for example, because the recovered `OriginalName=` contains a glob rejected by #10089), the old MAC-form claim survived and udev could restore the unknown NIC under the owner's identity on next boot. Issue #12557, filed from the review of the #12156 PR (#12372), reported this single-fault shape as 100/100 wrong on #12372's head and on master.

## What

- `breakNameCollisions` now returns a `preTemp` mapping for successfully temp-renamed desired sources, keyed by their transient name. It still carries the desired target and original-name metadata as before.
- Positional naming uses this mapping to neutralize the durable link for the pre-temp interface name, while continuing to neutralize the target's stale link. The device-map caller and direct helper tests accept the additional return value.
- `TestCHSingleFaultTempOKOwnerWriteFail12557` lets every temp rename succeed, refuses the known owner's globbed link write, and runs two NIC orders: the unknown NIC is the first temp-renamed NIC in one and the second in the other. Each case requires exactly one error (the #10089 refusal of the owner's write), all four renames, and no surviving unknown or stale-target link. `TestBreakNameCollisionsCarriesPreTempName12557` asserts the exact carry for two temp-renamed sources and none for a source that keeps its name.
- The `linksetup.go` phase-2 header, the `breakNameCollisions` doc comment and the `pkg/daemon/README.md` ordering note describe the carry.
