# #15077 — session-plumbing probes charged to `show version` locked restricted classes out of the cli

- **Timestamp**: 2026-10-18
- **Action**: `GetStatus` and `GetConfigModeStatus` were charged to the canonical command `show version` in `methodCanonicalCommand` (and their REST twins `GET /api/v1/status`, `GET /api/v1/config/status` in `restRouteCommand`), so a class with `deny-commands "show version"` (or an `allow-commands` list naming anything else) was refused the cli's own session plumbing: `cmd/cli` calls `GetStatus` before every dispatched command and `GetConfigModeStatus` at every config-mode prompt, so every member of such a class was locked out of SSH management as "cannot reach xpfd" while `show version` itself (ShowText topic `version`) stayed denied. Removed both charges: the probes are now named in `methodsWithoutCanonicalCommand` / `restRoutesNoCommand` as session plumbing and exempted from the operational regex gates (`isSessionPlumbingMethod` on gRPC, `restNoCommandExempt14146` on REST), governed by the coarse PermView price alone. The cli startup probe now reports a `PermissionDenied` as an authorization denial instead of a reachability failure.
- **File(s)**: `pkg/grpcapi/authz_command_table.go`, `pkg/grpcapi/authz_command_gate_7172.go`, `pkg/grpcapi/authz_methods.go`, `pkg/api/authz_command_regex_9952.go`, `cmd/cli/main.go`; tests `pkg/grpcapi/authz_probe_15077_test.go` (new), `pkg/api/authz_probe_15077_test.go` (new), plus narrowed updates to `pkg/grpcapi/authz_command_gate_7172_test.go`, `pkg/api/authz_command_regex_14146_test.go`, `pkg/api/authz_command_regex_14712_test.go`, `pkg/grpcapi/config_mode_status_authz_10019_test.go`; `docs/system-login.md`, this log.
- **Validation**: New 15077 cells RED on the pre-fix mechanism (`GetStatus`/`GetConfigModeStatus` denied under a `^show version$` deny through `authorizeRPCContext`; REST twins refused under deny/allow-list), GREEN post-fix with `show version` (ShowText topic `version` / `GET /api/v1/show-text?topic=version`) staying denied and neighbouring commands admitted. Retargeted pre-existing cells whose assertion depended on the wrong charge (`TestInvalidRegexDenies7172`/`TestEmptyDenyPatternDeniesEverything7172` now use `GetInterfaces`; `TestHeadFollowsGetCommandVerdict14712` deny arm moved to the topic route). Targeted subsets and full `pkg/grpcapi` + `pkg/api` suites run before push.
- **Risk**: A class that deliberately used `deny-commands "show version"` to also block the liveness/config-mode facts loses that incidental coverage; the facts disclose no version banner and remain behind the coarse view permission. Commit of such a class is silent before and after — the fix removes the lockout, it does not add a commit warning (out of scope; the coarse price still governs).
