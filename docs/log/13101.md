# Issue #13101 — compile Junos host and wildcard zone policies (D4-02)

- **Issue:** Deep-review D4-02 found `compilePolicies` rejected valid zone-pair policies addressed to `junos-host` and wildcard `any` from/to zone references because `assignZoneIDs` only assigned IDs to configured zones. `CompileUserspaceShim` invokes `CompileConfig`, so these valid policies aborted shim compilation before reconciliation.
- **Fix:** `compilePolicies` now maps `to-zone junos-host` to the reserved host zone ID (`config.ZoneIDReservedMin`) and maps `any` to wildcard ID zero only when no legacy zone definition named `any` exists. Configured `any` zones retain their stable IDs. Unknown zones and unsupported host-originated `from-zone junos-host` remain rejected. The ordinary configured-zone ID assignment and policy-rule/name/scheduler accounting are unchanged.
