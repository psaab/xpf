- **Timestamp**: 2026-10-27
- **Action**: Deleted the dead `fabric_fwd` write path. `refreshFabricFwd{,1}` in `pkg/daemon` previously resolved the peer MAC through a daemon copy of the resolver and wrote `FabricFwdInfo` via `SetFabricForwarding` → `UpdateFabricFwd{,1}` into the Go-created `fabric_fwd` shim array map; nothing has read that map since #1476 (grep-proven: 0 hits in `userspace-dp/src` + `userspace-xdp/src`, not in `userspaceMapPins()`, no Go `Lookup`). Renamed log lines (`cluster: fabric peer resolved`).
