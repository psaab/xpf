# #18885 — test: TCP timeout mirror regex misses #18657's pub(crate) const

Branch `fix/18885-campaign`, worktree
`/var/worktrees/campaign-drive/wt-18885`, based on origin/master
`5e65228f29`. Class A, cause group `G56-ct-slice-pubcrate-18657`.

## What broke

#18657 (`19e5a71d55`) made `DEFAULT_TCP_OPENING_TIMEOUT_NS`
`pub(crate) const` in `userspace-dp/src/session/mod.rs:333`, so the mirror
cell's regex `(?m)^const NAME: u64 = ([0-9_]+);` no longer matched the line
and the cell failed with "constant DEFAULT_TCP_OPENING_TIMEOUT_NS not
found" instead of comparing values.

## Entries

- **Timestamp**: 2026-11-02 (serial lane A 1/5)
  - **Action**: STEP-0 RED on master: named cell FAILED with exactly the
    triage error. Fixed the regex to allow an optional Rust visibility
    prefix — `(?m)^(?:pub(?:\((?:crate|super|self|in [^)]+)\))? )?const `
    — in `pkg/config/flow_tcp_timeouts_6539_test.go`. The prefix is the
    only slack: the line anchor, the exact const name, `: u64 = <digits>;`
    and the value-vs-Go-constant comparison are unchanged, so the cell
    cannot pass vacuously.
  - **Value equality proof** (Rust `session/mod.rs` ↔ Go
    `flow_tcp_timeouts_6539.go`):
    - `DEFAULT_TCP_SESSION_TIMEOUT_NS = 1_800_000_000_000` ns ↔
      `DataplaneTCPEstablishedWindowSecs = 1800`
    - `DEFAULT_TCP_OPENING_TIMEOUT_NS = 20_000_000_000` ns (the
      `pub(crate)` one) ↔ `DataplaneTCPOpeningWindowSecs = 20`
    - `TCP_CLOSING_TIMEOUT_NS = 30_000_000_000` ns ↔
      `DataplaneTCPClosingWindowSecs = 30`
    - `TCP_RST_TIMEOUT_NS = 2_000_000_000` ns ↔
      `DataplaneTCPRSTWindowSecs = 2`
  - **Mutants** (applied, run, reverted; none committed):
    - M1: revert the regex to `^const` → cell FAILs again ("constant
      DEFAULT_TCP_OPENING_TIMEOUT_NS not found") — the base RED restated.
    - M2: drift the Rust const to `21_000_000_000` → cell FAILs on the
      value comparison ("= 21s in Rust, but the Go operator-facing text
      says 20s"), proving the prefix-tolerant regex still finds and
      compares the real constant.
  - **File(s)**: `pkg/config/flow_tcp_timeouts_6539_test.go`,
    `docs/log/18885.md`.
