# #13552 — pkg/cli security-zone detail dispatch selector

- **Timestamp**: 2026-10-15
- **Action**: Replaced the positional `detail`/zone-name ladder in the local
  `show security zones` dispatcher with the command-tree-driven
  `cmdtree.SplitModifiers` used by the `cmd/cli` twin. Zone names now remain
  selectors regardless of whether they appear before or after modifiers;
  ambiguous modifiers and extra zone operands return errors rather than
  widening the display or silently dropping an argument.
- **File(s)**: `pkg/cli/cli_show_security_dispatch.go`,
  `pkg/cli/cli_show_zones_selector_13552_test.go`
- **Regression**: Added end-to-end coverage for `show security zones detail
  trust`, selector/modifier ordering, abbreviations, and extra arguments. The
  focused test failed on pristine master because `detail trust` rendered both
  configured zones; it passed after the dispatch change.
