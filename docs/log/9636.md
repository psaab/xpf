  - The BulkStart switch is `applyPeerIncarnationSwitchLocked` via `sync_conn_read.go`.
  - The only OnPeerConnected dispatch is handleNewConnection's cold-prime branch.
  - Semantics that decide the design:
    - the boot id (`/proc/sys/kernel/random/boot_id`) changes only on an OS boot;
    - the heartbeat boot epoch rises on every daemon start (`heartbeatBootEpoch`).

    So an epoch raise without a boot-id change is an ordinary daemon restart, and a retirement recorded by the epoch arm must be settled by a prime whose boot id did not change.
