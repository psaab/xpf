# #12536 — explicit PREF64 path wraps on tolerant ingress instead of pruning

- **Timestamp**: 2026-10-12
- **Action**: Drop explicit PREF64 lifetimes above the RFC 8781 maximum
  (65528s) at the send sink, before any `time.Duration` conversion.
- **Base**: `origin/master` `c2aa3f8d9` (round 1 was cut on `f9cb48ed8`)
- **Files**: `pkg/ra/sender.go`, `pkg/ra/sender_pref64_wrap_12536_test.go`,
  `pkg/ra/sender_marshal_3895_test.go`, `pkg/ra/README.md`,
  `docs/log/12536.md`
- **Parent**: #12134 (Opus R1 residual R1 on PR #12351)

## Why

Upstream ndp `PREF64.marshal` narrows `round(seconds/8)` to uint16 BEFORE
its `> 8191` check, so explicit lifetimes of 524284s and up wrap instead of
failing: 524284/524288/2^31/2^32 reach the wire as 0 (hosts stop using the
prefix) and 524300 as 16s; MaxInt overflows the Duration multiply and also
lands as 0. Marshal succeeds, so the #3895 probe misses every one. The
strict gate rejects these values, but tolerant ingress (Store.Load /
SyncApply) delivers them verbatim to buildRA. #12134 bounded only the
inherited path (saturate); explicit values wrapped.

## What

- Explicit PREF64 (`NAT64PrefixLife > 0`) over 65528: drop the option
  (warn on every build, keep the RA), checked in integer seconds before
  the Duration conversion. Inherited path unchanged (saturates, #12134).
- 65529–65531, which ndp rounds down to 65528 (what master advertised),
  drop too; 65532–524283 already dropped via the #3895 probe and now drop
  one step earlier. Every strict-invalid explicit value has one outcome.
- PREF64 drops where PIO saturates (#12193): PIO has an in-band infinity
  and dropping a PIO costs SLAAC; PREF64 has none and the probe already
  dropped 65532–524283.
- README: five guards; the probe only catches what ndp refuses to encode;
  new explicit-PREF64 bullet carrying the PREF64-vs-PIO split.

## Risk

- Explicit 65529–65531: master advertised 65528s, now the PREF64 is
  omitted. Strict commit rejects these values, so only tolerant-ingress
  configs see the change.
- Dropping omits rather than withdraws: hosts keep a PREF64 they already
  learned until it expires; hosts that never learned it get none.
- The drop warns on every RA build, like the #3895 probe; bounded by the
  RA interval.
- Explicit 1–3s lifetimes still encode as wire 0 through ndp rounding
  (pre-existing on master, untouched here, no issue yet). No live cluster
  mutated.
