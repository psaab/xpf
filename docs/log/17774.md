# #17774 — userspace-dp: index WireGuard learned PMTU by endpoint IP

- **Timestamp**: 2026-10-29
- **Action**: Replaced the packet-path `peer_endpoints()` collection/scan with a per-engine endpoint-IP index, maintained across peer reconciles and live endpoint adoption. PMTU reads keep the minimum fresh value among peers sharing an IP and preserve unset/expiry behavior; inbound PTB quote matching uses the same index plus canonical endpoint port, avoiding a second all-peer allocation while preserving table order for duplicate endpoints. A per-peer sequence guards the MTU/age pair: writers CAS-claim an odd generation, apply shrink-only MTU CAS, then publish the monotonic aging stamp; readers retry until they observe one stable pair. This also prevents an expired stamp from being refreshed before a stale MTU replacement is committed.
