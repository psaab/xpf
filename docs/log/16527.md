# #16527: `show | compare` hides quoted-grouping change that arms an event command

- **Timestamp**: 2026-10-24
- **Action**: `nodesEqual` and `alignSiblings` in `pkg/config/ast_format.go`
  compared nodes by `KeyPath()` (keys joined with spaces), so a
  `change-configuration commands` entry changing from two quoted members
  (`"set" "system host-name pwned"`, split by `eventMultiWordLeafValues`
  and rejected by `classifyPlan`) to one bare command
  (`set system host-name pwned`, joined and applied) rendered as
  `[no changes]` on plain, redacted, and scoped compares while the
  compiled `ThenCommands` differed. Added `keyProvenanceID` (KeyPath plus
  per-key index/quote/bracket bits, nil provenance reading as all-false)
  as the `alignSiblings` pairing identity and `sameKeyProvenance` (key
  count plus `KeyQuoted(i)`/`KeyBracketed(i)` per key) as a `nodesEqual`
  gate. Rendering already uses `QuotedKeyPath` on both arms, so the old
  quoted members and the new bare command are both visible once the pair
  is no longer considered equal. All-bare / provenance-less trees keep
  their previous identity, so no new diffs appear for them.
- **File(s)**: `pkg/config/ast_format.go`,
  `pkg/config/compare_provenance_16527_test.go` (new), `docs/log/16527.md`
- **Validation**: New tests fail pre-fix (compare empty while compiled
  batches differ `["set" "system host-name pwned"]` ->
  `["set system host-name pwned"]`; `nodesEqual` and `alignSiblings`
  treat differing provenance as equal) and pass post-fix, including
  identical quoted/bare controls, redacted and scoped compares, and
  key-count/bracket unit cells. Broader compare/redact test set passes;
  `go vet ./pkg/config/` is clean. A full `pkg/config` run panics in
  pre-existing `TestDualASTDifferential/interfaces-units-vlans`
  (`reflect.Value.Interface` on an unexported field at
  `dual_ast_differential_test.go:1161`), reproduced identically with
  the fix stashed, and a second full run hits the 200s package timeout
  in unrelated sweep tests; both are base-attributed, not this change.
