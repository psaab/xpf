# #16574 interface-monitor fabric member-interfaces attribution arm unreachable outside `groups`

- **Timestamp**: 2026-10-24
- **Action**: `collectPhysicalInterfaces`
  (`pkg/config/compiler_validate_strict_chassis.go`) gated its whole
  switch on `depth == 0 || childInGroups`, but a fabric
  `member-interfaces` node lives at
  `interfaces > fabN > fabric-options > member-interfaces` (depth 3 at
  top level), so outside `groups` the arm never ran. A monitor naming
  only a fabric member (e.g. `fab0 { fabric-options {
  member-interfaces ge-0/0/0; } }`) was therefore strict-rejected as
  soon as any other physical interface was declared — with refusal
  text claiming a fabric member-interfaces entry was acceptable. The
  shipped #15037 fabric cells carried no other physical interface, so
  the declared set stayed empty and the empty-set fallback in
  `interfaceMonitorNameAttributable` admitted the monitor without the
  arm, masking its loss. The walk now threads parent ancestry and
  mints fabric members only on the exact attributable
  `interfaces > fabN > fabric-options > member-interfaces` path (top
  level or beneath `groups`), reading every spelling through the
  shared `fabricMemberValues`/`plainListValues` reader (Keys-carried
  single/bracket, child-carried block, flat-set child/bracket). A
  `member-interfaces` entry under a non-fabric interface mints
  nothing. New cells in
  `compiler_validate_strict_chassis_ifmon_name_15037_test.go`
  (`TestChassisInterfaceMonitorFabricMemberWithOtherPhysical_16574`)
  declare an unrelated physical interface (`ge-0/0/5`) in flat-set,
  flat-set bracket, dash-spelling, and hierarchical single/block/
  bracket shapes so the empty-set fallback cannot mask the arm, plus
  the non-fabric negative control; deleting the arm turns the commit
  cells red.
- **File(s)**: `pkg/config/compiler_validate_strict_chassis.go`,
  `pkg/config/compiler_validate_strict_chassis_ifmon_name_15037_test.go`,
  `docs/config-schema.md`, `docs/log/16574.md`
- **Validation**: targeted `pkg/config` tests — see PR body for counts
  and the mutant (arm-removed) RED evidence.
- **Residual**: none known; class-of-service and other nested
  `interfaces` references remain non-declarations (unchanged gate),
  and the tolerant (#1960) warn path is untouched.
