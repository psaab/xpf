# #16760 — live counter feed: __be16 session-key ports + live-feed miss counter

- **Timestamp**: 2026-10-25
  - **Action**: `liveFlowCounters` (`pkg/daemon/daemon_flowexport.go`)
    built `dataplane.SessionKey{,V6}` with host-order ports from
    `flowexport.FlowKey` (`parseSrcPort`), but the session maps carry
    `__be16` ports — the Rust helper writes `src_port.to_be()`
    (`userspace-dp/src/afxdp/bpf_map/mod.rs` `bpf_session_key_v4/v6`).
    A BPF hash lookup compares raw key bytes, so every live lookup
    missed: `feedFlowLiveCounters` never called `Touch`, flows stayed
    at their open-time `lastActivity`, and with the default 60s/15s
    timeouts every flow longer than 15s was exported as one 0-packet/
    0-byte inactive record with its real close suppressed (the #15946
    contract this feed exists to satisfy). Converted both ports with
    `userspaceHostToNetwork16` (v4 and v6). Also fixed the v6 address
    parse on the same path: `FlowKey` addresses are the bare
    `net.IP.String()` values `FlowKeyFromClose` stored, and
    `parseHost`'s last-colon strip truncates a bare IPv6 address at
    its final hextet (returns nil), so the v6 arm could never hit
    even with correct ports — now parses with `net.ParseIP` directly.
    Added a live-feed miss counter: `Daemon.flowLiveFeedMisses`
    incremented per tracked key per group on a miss, surfaced via
    `Daemon.FlowLiveFeedMisses()` and the Prometheus counter
    `xpf_flow_export_live_feed_misses_total` (pkg/api plumbing:
    Config/Server/collector-deps fields, descriptor, pre-gate emit;
    family omitted when unwired). R3-A46-04 (#16750, saturating
    deltas / monotonic Touch) already landed separately, so the
    now-hitting feed cannot emit wrapped deltas. Tests:
    `pkg/daemon/daemon_flowexport_livefeed_byteorder_16760_test.go` —
    real `liveFlowCounters` (seam nil) against a byte-keyed fake store
    written through the production (network-order) encoder for v4+v6
    (RED pre-fix), absent-tuple controls, and the miss counter
    (one miss per group, hits uncounted, nil-daemon safe);
    `pkg/api/metrics_flowexport_livefeed_16760_test.go` — metric
    value, NewServer hook retention, omitted-when-unwired.
