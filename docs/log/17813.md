# Issue 17813 — mask credentials in comment-only embedded commands

## Why

The embedded-command redactor treated every successful zero-token lex as an empty command. The config lexer skips `#` line comments and block comments, so a nonempty stored payload such as `# set security ike policy p1 pre-shared-key ascii-text SENTINEL` was returned unchanged. Redacted configuration renders and unsupported-command journal warnings could therefore retain the credential.

## What changed

- Keep only empty and whitespace-only payloads unchanged; replace every other zero-token payload with the existing whole-payload redaction placeholder.
- Preserve that placeholder in joined-tail and block-child AST rewrites, where re-lexing the `##SECRET-DATA##` placeholder itself produces zero tokens. Apply the same preservation to compare fingerprints.
- Treat lexer-discarded comments as a redaction change when the rendered payload differs, removing credentials hidden in comments without churning clean command formatting.
- Re-lex quoted comment-shaped payloads as embedded commands, so an opaque quoted `"# set ..."` token cannot bypass masking.
- Cover trailing and nested comments, quoted values, comment-line prefixes, quoted whole commands, all redacted render surfaces, compare, and the event-engine rejection log.

## Risk

Empty and whitespace-only payloads remain unchanged. Redaction rewrites payloads for masked credentials, discarded comments, and fail-closed malformed or comment-only inputs; commands that merely normalize spacing or quoting remain byte-identical. The live config tree and executable command are not mutated; redaction applies to display, compare, and journal-warning output.

## Quoted whole-command follow-up (2026-10-28)

- **Action**: `redactEmbeddedCommand` now recurses into ANY single quoted token, not only comment-prefixed ones: a quoted whole-command (`"set ... pre-shared-key ascii-text SECRET"`) or a quoted command whose credential trails as a comment (`"set system host-name harmless # pre-shared-key ... SENTINEL"`) no longer survives as one opaque token. Inner masking returns the fingerprinted inner render; an unmasked inner command returns the authored token unchanged (no churn).
- **File(s)**: `pkg/config/ast_redact.go`, `pkg/config/ast_redact_embedded_comments_18379_test.go`.
- **Validation**: two new all-surface cases in `TestRedactEmbeddedCommentPayloads18379` (quoted whole-command credential; quoted command with trailing comment credential) plus the shipped comment payload set pass on Format/FormatSet/FormatJSON/FormatXML/FormatCompareRedacted; `pkg/config` and `pkg/eventengine` named redaction cells pass.
- **Risk**: none beyond the existing display/compare/journal redaction surface; clean quoted commands remain byte-identical.

## Outer-tail guard follow-up (2026-10-28)

- **Action**: The quoted-token shortcut now requires a clean outer lex (`lexOK && !comments`); a credential in a comment or malformed tail after a clean quoted prefix falls through to the outer fail-closed masking instead of leaking. The shipped clean control now authors a genuinely quoted command.
- **Validation**: `TestRedactEmbeddedCommentPayloads18379` tail cases (comment tail, junk tail) pass with the shipped set.
