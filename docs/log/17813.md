# Issue 17813 — mask credentials in comment-only embedded commands

## Why

The embedded-command redactor treated every successful zero-token lex as an empty command. The config lexer skips `#` line comments and block comments, so a nonempty stored payload such as `# set security ike policy p1 pre-shared-key ascii-text SENTINEL` was returned unchanged. Redacted configuration renders and unsupported-command journal warnings could therefore retain the credential.

## What changed

- Keep only empty and whitespace-only payloads unchanged; replace every other zero-token payload with the existing whole-payload redaction placeholder.
- Preserve that placeholder in joined-tail and block-child AST rewrites, where re-lexing the `##SECRET-DATA##` placeholder itself produces zero tokens. Apply the same preservation to compare fingerprints.
- Add regression coverage for helper output, persisted AST redacted formats, compare fingerprints, placeholder re-ingest rejection, joined and block AST forms, and the event-engine rejection log.

## Reproduction and validation

On base `9aa007277d` (current `origin/master` at worktree creation), the named regression cells went RED:

```text
go test ./pkg/config -run '^TestRedactEmbeddedCommentOnly17813$|^TestEmbeddedCommentOnlyRedactedClone17813$' -count=1 -v
FAIL: the helper returned the comment-only payload unchanged; RedactedClone rendered SENTINEL, changed-credential compare lacked a fingerprint, and the redacted placeholder ingest guard accepted the payload.
```

After the fix, the named config redaction cells passed:

```text
go test ./pkg/config -run '^(TestRedactEmbeddedCommentOnly17813|TestEmbeddedCommentOnlyRedactedClone17813|TestEmbeddedNonSetRedactedClone16726|TestEmbeddedNonSetPlaceholderIngestRefused16726|TestEmbeddedRedactedPlaceholderIngestRefused15209)$' -count=1 -v
PASS (1 package)
```

The event-engine warning cell, including the new comment-only command case, also passed:

```text
go test ./pkg/eventengine -run '^TestClassifyPlanLogsRedactedCmd16726$' -count=1 -v
PASS (1 package)
```

## Risk

Only nonempty payloads that lex to zero tokens change render behavior; they now fail closed as a whole payload. Empty and whitespace-only payloads and ordinary tokenized command redaction remain unchanged. The live config tree and executable command are not mutated; redaction applies to display, compare, and journal-warning output.
