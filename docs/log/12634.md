# #12634 — poison unresolved tails on known policy scalar leaves

- **Timestamp**: 2026-10-13
- **Action**: poison and warn when a known `description` or `scheduler-name`
  scalar carries trailing content the policy packed-run expander cannot fully
  resolve. Strict compilation rejects the same content.
- **Files**: `pkg/config/compiler_security_policy.go`,
  `pkg/config/compiler_policy_then.go`,
  `pkg/config/compiler_policy_poison_11013_test.go`, and
  `pkg/config/README.md`.

## Red before

The new targeted tests failed before the fix: all seven unresolved-tail cases
left `LenientContentDropped` false, including braced and flat-set shapes.
The known scalar keyword bypassed #12234's unknown-child predicate, so the
missed scheduler reference could disappear without poisoning the policy.

## Change

- `policyUnresolvedScalarLeafTails` expands policy leaf runs with the existing
  #9792 resolver, then detects extra tokens/children still attached to the
  recognized scalar leaves.
- The tolerant compiler marks policies with those unresolved tails as dropped;
  the strict enforcement gate rejects them and the tolerant path emits a
  #12634 warning.
- Added positive and clean-control cases for braced and flat-set configuration.

## Validation

- `go test ./pkg/config -run 'TestKnownScalarLeaf(UnresolvedTailPoisons|ResolvedRunsStayClean)12634' -count=1` — PASS.
- Overlay mutant disabling the new poison predicate failed all seven unresolved
  cells at the `LenientContentDropped` assertion.
- Complete `compiler_policy_poison_11013_test.go` test set — PASS.
- `go build ./...`, `go vet ./pkg/config`, and `gofmt -l` on touched Go files —
  PASS.
- Full `go test ./pkg/config -count=1` — FAIL: config tests reported failures
  (including `TestInventoryDropShapeMatchesTheLiveCensus8662`,
  `TestSystemConfigSetSyntax`, and `TestPackedRoutingInstanceSurvives8787`),
  then `TestSchemaSpellingDifferentialGate` hit the package's 10-minute test
  timeout. Baseline attribution established on review (GLM R1): differential gate passes solo in ~14.5m on base and head (exceeds the 10m package default - pre-existing, #12806); the other 8 failures are byte-identical base-vs-head.

## Risk

Tolerant loads now quarantine permit policies with unresolvable tails on
`description` or `scheduler-name`; this is the intended fail-closed behavior.
