# #17826 — IPsec chunk decoder must enforce the per-chunk name bound

- **Timestamp**: 2026-10-28
  - **Action**: Enforced `ipsecChunkNamesPerChunk` (4096) inside
    `decodeIPsecSAChunkBody`, before converting/appending each name. An
    over-bound body now returns the named `errIPsecSAChunkTooManyNames`
    error and no names; it is refused whole rather than materialized and
    truncated/refused only by the receiver's later check. The decoder also
    returns named errors for overlong individual names. Removed the now-
    redundant post-decode count check from `handleIPsecSAChunk`. Added named
    `t.Run` boundary controls for 4096/4097 names and a valid-tail refusal,
    plus a large-body receiver cell for refusal accounting and prior-set
    retention.
  - **File(s)**: `pkg/cluster/sync_ipsec_chunk_16758.go`,
    `pkg/cluster/sync_lease_recv.go`,
    `pkg/cluster/ipsec_sa_chunk_16758_test.go`,
    `docs/log/17826.md`
  - **Validation**: RED before the decoder change:
    `go test ./pkg/cluster -run '^TestIPsecSAChunkBodyNameBoundAtDecode17826$' -count=1`
    failed because the pre-fix decoder accepted and returned 4097 names.
    After the change, `gofmt -w` on the three changed Go files,
    `go test ./pkg/cluster -run '^TestIPsecSA' -count=1`, and
    `go test ./pkg/cluster -run '^TestIPsecSAChunkBodyNameBoundAtDecode17826$' -count=1 -v`
    PASS. The verbose run passed named at-limit, over-limit named-error,
    valid-tail refusal, and overlong-name named-error subtests.
  - **Risk**: No wire-format or accepted in-bound behavior changes. The
    existing per-chunk 4096-name refusal now returns a named decoder error
    before allocating strings for the rest of a peer-supplied body.
- **Timestamp**: 2026-10-28
- **Action**: Fenced stale IPsec chunk completions by recording the latest
  committed generation per sender incarnation. A complete assembly older
  than that watermark is dropped before held-set replacement and callback,
  using the existing `IPsecSAStaleIgnored` counter and stale warning. Legacy
  full-set commits also advance the generation fence. Added an interleaving
  regression for G's refused oversized chunk, H's publication, and G's valid
  later-sequenced completion; H remains applied and G emits no callback.
- **File(s)**: `pkg/cluster/sync_ipsec_chunk_16758.go`,
  `pkg/cluster/sync_lease_recv.go`, `pkg/cluster/sync.go`,
  `pkg/cluster/ipsec_sa_chunk_16758_test.go`, `docs/log/17826.md`
- **Validation**: `go test ./pkg/cluster -run '^TestIPsecSA' -count=1` PASS.
- **Risk**: No wire-format changes. Completed chunk generations older than
  the last committed generation for the same incarnation are now refused;
  in-progress newer generations and equal-generation completions retain
  existing behavior.
