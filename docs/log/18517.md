# #18517 — split node drops new flows to the peer-owned WAN

- **Timestamp**: 2026-10-29
- **Action**: Reproduced on the tcp cluster with RG1 (WAN) on fw1 and RG2
  (LAN) on fw0: `LAN host -> 1.1.1.1` 100% loss; fw0 counters +50 RX / +50
  session misses / no TX; helper `Last resolution: discard_route`; helper FIB
  held only `0.0.0.0/0 discard cluster-terminal`, the configured default via
  172.16.50.1 absent.
- **Root cause**: the #15742 peer-owned connected-prefix skip also removed the
  prefix from the #11317 gateway-coverage set, so the configured WAN default
  was filtered as recursive and the cluster-terminal attribution had no row to
  stamp from.
- **Fix**: `gatewayNetworks` covers peer-owned prefixes for the #11317 filter
  only; transit connected rows are unchanged.
