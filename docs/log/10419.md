# Issue #10419: expired conntrack wire state

## Disposition

Fixed the session-expiry ordering leak. The worker now retires a
`MissingNeighborSeed` publication with an origin plus non-zero stable-session-ID
fence, and drains all expiry deltas before polling another packet. Ordinary
origins continue through the existing Close-delta path. This prevents a lookup
from missing the just-expired local row, rematerializing the still-published
shared row, and forwarding one more packet on an expired tuple.
