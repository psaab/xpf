# #15647 — DEGRADED_PATH_REASON_NAMES missing reason 19 land_drop

## Defect
Shim (`userspace-xdp/src/lib.rs:57-58`) defines
`USERSPACE_FALLBACK_REASON_LAND_DROP = 19` with `MAX = 20` (added by
#13953), and Go `degradedPathReasonNames` already carries slot 19, but
the Rust debug-log reader's `DEGRADED_PATH_REASON_NAMES`
(`userspace-dp/src/afxdp/bpf_map/pin.rs`) stopped at index 18
(`tagged_only_local_drop`). `read_degraded_path_stats` sizes its scan
from that table, so LAND drops were counted in the kernel and
invisible to the Rust reader; the #9888 shim-agreement test was red.

## Fix
- Append `"land_drop", // 19` to `DEGRADED_PATH_REASON_NAMES`.
- Regression pin: `degraded_path_reason_names_cover_retained_shim_actions`
  length 19 → 20 plus `DEGRADED_PATH_REASON_NAMES[19] == "land_drop"`.
  The existing `degraded_path_reason_names_agree_with_the_shim_9888`
  auto-enrols shim reasons and independently guards this.
