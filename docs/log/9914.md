## Findings and owning boundaries

1. **F-042 / VRRP advertise interval** — normalize tolerant negative, zero,
   sub-quantum, and over-maximum milliseconds once at the timer/wire boundary.
   The local timer and VRRP `MaxAdvertInt` now share the 10 ms quantum, default,
   and 12-bit ceiling; the v4 and v6 packets still use one interval snapshot.
2. **F-119 / RA LinkMTU** — bind the strict schema to `[1280, 65535]` and
   saturate again in `buildRA` so tolerant load and peer sync cannot advertise
   below the IPv6 minimum or above the configured uint16 ceiling. `0` and
   negative values retain the documented omitted-option behavior.
3. **F-120 / VRRP priority** — route `Manager.UpdateRGPriority` through the
   existing `clampConfigPriority`, preserving explicit address-owner `255`,
   flooring invalid low values to `1`, and capping other high values at `254`.
4. **F-121 / synthesized RETH VRID** — centralize checked `100 + rgID`
   construction, skip synthesized VRIDs outside `1..255`, and retain refused
   desired keys in manager state. `RGVRRPReady` now reports an out-of-range
   RETH VRID as not ready instead of allowing manager election state to diverge
   from the absent VIP-owning instance.
