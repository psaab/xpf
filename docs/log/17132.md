# Issue #17132 — interface-monitor election debt has two producers

- **Defect (STEP-0, live on origin/master 784d53a6cf):** `pkg/cluster` Monitor
  (dampened, transition-only `SetMonitorWeight`) and the daemon apply tail's
  raw per-apply routing sample (`daemon_apply_tail.go`, formerly lines
  421-429) both wrote interface-monitor election debt. Reproduced both
  directions at component level with production dampening defaults
  (Fail/Pass 3, HoldDown 5s): a raw up-sample cleared held debt and 20
  further down polls left weight 255 (fail-open); the mirror stranded
  debt at 155. Confirmed: `FAIL-OPEN: weight=255 want 155`.
- **What:** Deleted the daemon feed (acceptance grep: `SetMonitorWeight(`
  in `pkg/daemon` non-test now lists only `daemon_transit_gate.go`'s
  reserved arm/crash-loop markers). `Manager.UpdateConfig` now defers one
  interface-only `Monitor.PollNow()` after releasing `m.mu` (poll →
  `SetMonitorWeight` takes `m.mu`; #4828/#6550 lock order), so a commit
  is reflected within the apply through dampening only. PollNow runs
  NO ICMP IP-probe sweep on the commit path (the sweep is bounded only
  by waves*800ms+500ms; IP debt stays owned by the 1s loop's full
  cycle) and runs on the monitor lifecycle context counted in `wg`,
  so `Monitor.Stop` (via `Manager.Stop`) cancels and joins it — a
  commit poll racing Stop, and any poll attempted after Stop, leaves
  no weight write (fold of Rev18171Opus F1; the transition callback
  re-checks `ctx.Err()` before `SetMonitorWeight`). `pkg/routing` monitorManager is
  documented display-only (kept: CLI/gRPC `show chassis cluster
  interfaces` consume it; behavior unchanged). The carrier predicate now
  has ONE definition, `pkg/linkstate.Up` (new zero-xpf-import leaf,
  mirroring `pkg/netname`); `cluster.LinkAttrsUp`, routing's and vrrp's
  `linkAttrsUp` are aliases. Fixed contradicting docs in
  `pkg/cluster/README.md` and `pkg/routing/README.md`; updated stale
  #6549 producer comments in `election.go`, `monitor.go`, routing and
  the 6549 tests.
- **#16743 interplay:** closed/fixed separately (pin is a state fact);
  this change removes the raw feed that also erased it — no conflict.
- **Invariants kept:** #5080 (missing local link = down, dampened),
  #8073 (transient netlink error carries forward, display + cluster's
  missing handling untouched), #6549/#6589 (clamps unchanged in cluster;
  routing display clamp kept), #4828/#6550 lock order (PollNow deferred
  outside `m.mu`, after election — debt recomputes on poll transitions
  and `reconcileMonitorDebtsLocked` still handles weight changes under
  `m.mu` first).
