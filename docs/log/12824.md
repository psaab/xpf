# Issue #12824 — repeated dynamic-address names overwrite compiled values

## Why

`compileDynamicAddress` constructed a fresh `AddressBinding` for each `address-name` instance, then assigned it into a map keyed by name. Repeated hierarchical blocks therefore discarded earlier profile fields. In `feed-server`, repeated scalar `feed-name` statements repeatedly assigned the single-feed field, dropping all but the last name. A peeled `feed-name { <name> { path ... } }` container was mistaken for one feed whose name came from its first child; the nested path was discarded.

## What

- Reuse an existing `AddressBinding` for repeated `address-name` blocks, accumulating feed names and preserving fields from the other block.
- Preserve the backward-compatible `FeedName` field for one scalar feed. When a second scalar feed is encountered, promote the first and subsequent names to `FeedEntries`, preserving all declared feeds.
- Handle peeled `feed-name` containers by iterating named feed children and reading each nested `path`.
- Added regressions for repeated address-name blocks, repeated feed-name leaves, and the peeled container with path.

## Validation

- **RED before**: all three new regressions failed on the pre-fix compiler. Repeated binding retained `fail-mode drop` but lost its feed reference; repeated leaves kept only the last scalar `FeedName`; the peeled feed entry had an empty `Path`.
- **Focused after**: `go test ./pkg/config -run '^TestDynamicAddress(RepeatedNamedBlocks|RepeatedLeafFeedNames|PeeledFeedNamePath)12824$' -count=1` — passed.
- Dynamic-address test suite: `go test ./pkg/config -run 'TestDynamicAddress' -count=1` — passed.
- Full config package test: `go test ./pkg/config/ -count=1` — failed after 10 minutes. It reported unrelated config gate failures (including the moved #8939 loser-set measurement, stale inventory rows, and API-auth/web-management tests failing on missing expires dates), then timed out in `TestSchemaSpellingDifferentialGate` while hashing API-auth test credentials. No dynamic-address regression failed.
- `go build ./...` — passed.

## Risk

The change is limited to dynamic-address compilation. Existing single-feed configurations continue to use `FeedName`; configurations declaring multiple feeds now retain all entries. Duplicate feed-name identity validation and runtime fail-closed behavior are unchanged.
- **Review fold**: identical feed re-statements are deduplicated at compile (strict uniqueness no longer rejects idempotent spellings); the peeled loop skips `path` value children; feed-name identity validation now also covers previously-collapsed duplicate scalar spellings.
