# 14629 — #14435 gate exemption accepts filter-first packed unit spelling, family silently dropped

- **Timestamp**: 2026-10-17
- **Action**: Gate fix in `pkg/config/compiler_interfaces_unsupported.go`:
  renamed `unitPackedTailHasFamilyFilter14435` to
  `unitPackedTailHasFamilyBeforeFilter14435` and made it schema-arity-aware.
  The old helper returned true if `family inet|inet6` appeared ANYWHERE in
  the unit Keys tail, so `unit 0 filter input DISCARD-BAD family inet
  { address ...; }` exempted the unit-level filter from the #12090 gate
  while `packedBody` in `compileInterfaces` expanded only the trailing
  family segment — the filter, the addresses and the family were all
  dropped and the unit strict-committed as empty `Unit{Number:0}`
  (no addresses, no filter, no family), lenient also silent: accepted-
  but-dropped fail-open. The new walk consumes the tail by the unit
  schema's own arity (a VALUE spelling `family`/`filter`/`inet`, e.g.
  `description family`, is never a keyword), honours quoted-token
  provenance, keeps the open-levels stack `packedBodyChildren` keeps
  (so `family` after a `tunnel …` run still resolves at the unit level),
  descends through compound `family`, and returns true only
  when an unquoted `family inet|inet6` segment is reached BEFORE any
  unit-level `filter`/`simple-filter` hit; a filter hit first, an apply
  statement, a quoted keyword-position token, or a token outside the
  modelled grammar all return false (do-not-guess, fail-closed for the
  exemption). Both call sites updated: the braced-filter-child exemption
  in `isInterfaceDirectFilterConsumerPath12090` and the packed-tail
  exemption in `isInterfacePackedFilterConsumer12090`. No compiler
  reader change: genuinely consumed spellings (family-first,
  point-to-point-first, tunnel-first, `family inet filter input …`)
  keep compiling identically; only the previously mis-exempted
  filter-first spelling now strict-rejects (#12090, naming `filter
  input`) and lenient-warns.
- **Regression**: `pkg/config/compiler_interfaces_packed_unit_dr17h6_test.go`
  (`TestPackedUnitFilterFirstFamilyRejects14629`): reject cells for
  inet/inet6 braced bodies, output direction, packed family body,
  `simple-filter` first, and filter-first-then-braced-family-filter;
  accept controls for family-first, point-to-point-first, family-packed
  filter, `description family`/`description filter` values (consumed by
  arity, stay accepted), and tunnel-first, each
  asserting no #12090 diagnostic and populated hooks. Pre-fix the
  filter-first spelling strict-compiled to an empty unit (measured);
  the new reject cells fail there and pass after the fix.
