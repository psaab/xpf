# #16477 — harness census self-test must not assume the pinned scratch parent exists

- **Timestamp**: 2026-10-24
  - **Action**: `test/incus/harness-census-selftest.sh` created its work
    dir with `mktemp -d "${TMPDIR:-/var/worktrees/.cache/tmpdir}/..."`
    with no `mkdir -p`, no status check and no `set -e`
    (`set -uo pipefail` only). On a GitHub runner (TMPDIR unset, no
    `/var/worktrees`) mktemp failed, `WORK` stayed empty, every fixture
    landed at `/<name>`, and the self-test reported `passed=6
    failed=24` — so the only CI job guarding harness registration
    (`CI tests / Harness census and self-test`) has been red on every
    PR since 99e8f3f26d (#14837), carrying no signal and blocking the
    documented require-once-green promotion. The script now creates
    the pinned parent when TMPDIR is unset and exits 2 with a FATAL
    line if mktemp still fails or yields no directory. Same audit
    applied to the other unchecked templated-`mktemp -d
    "${TMPDIR:-/var/worktrees/...}"` sites CI can reach (via the
    workflow or the shellcheck-covered self-test list):
    `harness-ledger-mutation-selftest.sh`,
    `harness-result-selftest.sh`, `ignored-cell-census-selftest.sh`,
    `selftest-census-selftest.sh`, `miri-census-selftest.sh` (both
    sandbox sites), `private-rg-selftest.sh`,
    `private-rg-fullcycle-selftest.sh` and
    `wire-gate-hermetic-selftest.sh`; bare-`mktemp -d` sites in
    `go-skip-census-selftest.sh` / `go-buildtag-census-selftest.sh`
    now fail loudly instead of running fixtures at `/<name>`.
    `scripts/proto_regen_check.sh` / `scripts/proto-regen-check-selftest.sh`
    keep their `mkdir -p "$SCRATCH/..."` (which already creates the
    pinned parent) and now check its status. Every CI job in
    `.github/workflows/test.yml` now exports a runner-local
    `TMPDIR=${{ runner.temp }}` (plus runner-local `GOTMPDIR`/`GOCACHE`
    for the Go job and `CARGO_TARGET_DIR` for the Rust job), because
    the Makefile `?=` pins point at `/var/worktrees/.cache/...`,
    which a clean runner cannot create (`mkdir: Permission denied`
    in the proto/tooling/go job logs) — with TMPDIR set, the Makefile
    pin yields and Python `tempfile`, bare `mktemp`, `go install` and
    cargo all use runner-local scratch. The census job's byte-exact
    allowlist in the self-test is updated to match (env block added,
    #16465 rust-census steps added — the expectation had already
    drifted from the workflow, failing the wiring cell on master —
    and the workflow comment em-dashes replaced with `--` so the
    printable-ASCII check the allowlist enforces actually passes).
    `scripts/scratch-pinning-selftest.sh` now asserts the eight
    templated-mktemp self-tests create the pinned parent and fail
    loudly, so the pattern cannot silently regress.
