# #15218 — shim build provenance (A31-01)

## Defect
`pkg/dataplane/build-userspace-xdp.sh` computed `SHIM_BUILD_DIGEST`
only over file contents, then ran cargo with the ambient environment.
An unpinned install (`XPF_SHIM_ALLOW_UNPINNED_INSTALL=1`) or a pinned
build under ambient `RUSTFLAGS` / `CARGO_ENCODED_RUSTFLAGS` installed
a gate verdict labelled `PASS` recording neither the toolchain, the
pinned bit, the bpf-linker version, nor any codegen-env digest — and
both consumer gates (the #4977 freshness gate via
`ComputeUserspaceXDPManifest`, and the release retention gate
`scripts/dist/retain_shim_verdict.py`) accepted it, because neither
knew provenance exists. The unpinned refusal text also pointed at a
"PR reproducibility gate" that no workflow implements.

## Fix
- Recipe: scrub `RUSTFLAGS`/`CARGO_ENCODED_RUSTFLAGS` for the cargo
  invocation (`env -u …`), compute the scrubbed-env digest
  (SHA-256 of `RUSTFLAGS=\nCARGO_ENCODED_RUSTFLAGS=\n`), thread
  toolchain / pinned bit / bpf-linker / digest into `shimverify`
  through both the root and sudo verifier invocations. Unpinned
  installs now announce `OVERRIDDEN`-style provenance labelling and
  the refusal names the real local gates.
- `cmd/shimverify`: gate verdict is schema 2 and carries a
  `provenance` block; a verdict write with missing/malformed
  provenance env fails closed.
- Freshness gate (`pkg/dataplane/userspace_xdp_manifest.go`): the
  manifest adopts a verdict's build digest only when provenance is
  present, pinned to the `rust-toolchain.toml` channel, carries the
  pinned bpf-linker (`ShimPinnedBPFLinkerVersion`), and matches the
  well-known scrubbed-env digest (`WellKnownCodegenEnvDigest`).
  Otherwise the object reads as stale.
- Retention gate (`scripts/dist/retain_shim_verdict.py`): requires
  schema 2 and validates the same provenance against the pin files
  before any release upload.
- Committed artifacts regenerated in lockstep: the tracked object's
  bytes are unchanged (`d52f02d8…`, measured 873042 insns / 12.70%,
  still the #14954 OVERRIDDEN exception); the verdict gained schema 2
  + provenance and the manifest's build digest moved with the recipe
  hash. (The manifest also picks up four source hashes that were
  already drifted on master — freshness was red on `origin/master`
  before this change; those inputs' contents are untouched here.)
