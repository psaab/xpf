# #17822: top-exit cursor restore crossed configuration sessions

- **Timestamp**: 2026-10-28
- **Action**: STEP-0 confirmed #17822 was open and the defect remained on
  `origin/master` after #17517. The local `dispatchTopUp15082` restore used
  store-global `InConfigMode()` before writing a process-global edit cursor.
  After the inner local exit released its lock, a foreign gRPC/REST session
  could acquire configuration mode before the wrapper restore, making that
  global predicate true and receiving the local session's stale cursor.
  The restore now runs only while this CLI still records ownership and calls
  `SetEditPathForSession(localConfigSessionID, ...)`, which checks the active
  holder and applies the cursor under the store mutex; prompt restoration is
  likewise conditional on that successful owned-session write. The local
  top/up fixture now acquires under `localConfigSessionID`. The remote
  `cmd/cli` copy was left unchanged: its restore uses the `configMode` and
  `editPath` fields on its `ctl` object, not `configstore`'s global
  mode/cursor.
- **File(s)**: `pkg/cli/cli_dispatch.go`, `pkg/configstore/store_lock.go`, `pkg/cli/top_up_prefixed_15082_test.go`, `pkg/cli/top_exit_foreign_resurrection_17822_test.go` (new), `docs/log/17822.md` (this file).
- **Validation**: RED-on-revert reproduced with the former store-global guard: `go test ./pkg/cli -run '^TestLocalTopExitRestoreDoesNotResurrectIntoForeignSession17822$' -count=1` failed with `local top-exit resurrected [routing-instances RI1] into foreign session (#17822)`. With the session-scoped guard, the named affected CLI cells passed: the full `top_up_prefixed_15082_test.go` suite, both existing #16702 cells, and all three #17822 cells (`go test ./pkg/cli -run 'Test(TopDeleteExecutesAndRestoresCursor15082|UpDeleteExecutesAndRestoresCursor15082|TopUpBareNavigationUnchanged15082|TopUpInvalidTrailingFailsClosed15082|TopUpQuotedValueSurvives15759|TopShowComparePipeSurvives15759|TopBracketListSurvives15759|LocalTopExitDoesNotRestoreStaleCursor16702|LocalTopSetStillRestoresCursor16702|LocalTopExitRestoreDoesNotResurrectIntoForeignSession17822|ForeignTopExitRestoreDoesNotResurrectIntoLocalSession17822|TopExitRestoreStillWorksForOwnSession17822)$' -count=1`). `go vet ./pkg/cli ./pkg/configstore` passed and the changed Go files were gofmt'd. Test commands used campaign `GOCACHE`/`GOTMPDIR` under `/var/worktrees/.cache`.
- **Risk**: The Store still has one global edit cursor; this change prevents only a top/up restore from writing it after its caller's ownership has been lost or handed off. Other cursor operations and navigation semantics are unchanged. The symmetric foreign-to-local rejection and same-session restore control are covered by the new cells.
