## Defect

`make docs-check` exited 1 on master. Its phrase-2 leg ran `grep -rnF -- "manifest.Managed" docs/`, and all 5 hits were in generated history archives quoting the symbol while recording its removal: `docs/issues/pr-history.md` (3) and `docs/issues/issue-history.md` (2). No live doc carries it. `docs-check` is standalone, so a red that cannot be fixed would hide a real reintroduction.

## Change

- The phrase-2 matches are filtered by path prefix: `docs/issues/`, `docs/log/` and `docs/reviews/` are dropped. A prefix filter rather than `grep --exclude-dir`, which matches a directory base name at any depth and would also skip a nested `docs/guide/log/`.
- `DOCS_CHECK_ROOT` points the guard at a fixture tree; unset, it scans the repo as before.
- `scripts/docs/check-upgrade-docs-selftest.sh` (new) builds six fixture trees. It is registered with `run_bash` in `scripts/run-selftests.sh` and added to its `bash -n`/shellcheck list. The #7296 selftest census globs `test/incus/*-selftest.sh` only, so the explicit registration is what reaches it.
