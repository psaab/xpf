# #16640: apply-time route rebuild drops the Compile build's ip-monitoring overlay

- **Timestamp**: 2026-10-25
- **Action**: `rebuildDerivedSectionsAfterRevalidate` rebuilt `snap.Routes`
  with `routeOverlayForSnapshot(snap)`, which returned nil for every fresh
  Compile snapshot (its `Config` is not yet `m.lastSnapshot.Config`). The
  overlay the full build applied was therefore discarded whenever apply-time
  revalidation moved or dropped a row — on HA nodes on every Compile, because
  the peer-fabric row is dropped — so the helper FIB routed the overlaid
  prefix (typically the WAN default) via the failed primary next hop from
  the Compile publish until the commit-tail `reconcileRouteLeakSnapshot`
  republish restored it, spanning `applyFRRFull`/`applyRoutingRules`.
- **Fix**: record the overlay a snapshot was built with on the snapshot
  itself. `ConfigSnapshot.builtRouteOverlay` (unexported; never on the wire
  or in the content hash) is stamped by the full builder from its
  `routeOverlay` argument (cloned), re-recorded by the two partial
  publishers that rebuild Routes from an explicit overlay
  (`PublishRouteOverlaySnapshotWithLatch` from `desiredOverlay`,
  `RefreshInterfaceRowsForLink` from `m.routeOverlay`), and re-recorded by
  the apply-time rebuild itself from the overlay it used.
  `routeOverlayForSnapshot` now returns the recorded build overlay when
  present; a snapshot with no recorded build (hand-built) falls back to the
  previous retained-config identity check, so a foreign hand-built snapshot
  still never re-applies a moved `m.routeOverlay`. NOT changed: the rebuild
  trigger, the route builder, and the commit-tail republish.
- **File(s)**: `pkg/dataplane/userspace/protocol.go` (field),
  `pkg/dataplane/userspace/builder.go` (record at build),
  `pkg/dataplane/userspace/manager_overlay.go` (`routeOverlayForSnapshot`
  + record at overlay publish),
  `pkg/dataplane/userspace/manager_link_refresh.go` (record at link refresh),
  `pkg/dataplane/userspace/apply_snapshot_identity_9520.go` (record at rebuild),
  `pkg/dataplane/userspace/overlay_rebuild_16640_test.go` (new),
  `docs/log/16640.md`
- **Validation**: see PR. New
  `TestRebuildAfterRevalidatePreservesCompileOverlay16640` drives the real
  `prepareSnapshotForApply` with a dropped interface row: the fresh-Compile
  cell (built with overlay `10.0.0.253`, manager overlay since moved to
  `10.0.0.99`) keeps `10.0.0.253`; the retained-config control keeps the
  current overlay; a foreign hand-built snapshot keeps its authored route.
