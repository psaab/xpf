# #9679 — remove_shared_session deletes a colliding session's shared aliases

- **Timestamp**: 2026-09-11
- **Action**: Delete each shared NAT reverse alias and forward-wire alias only while it still names the removed session
- **File(s)**:
  - `userspace-dp/src/afxdp/shared_ops.rs`: `remove_shared_alias_owned_by`, used by `remove_shared_session` for all three aliases
  - `userspace-dp/src/afxdp/session_glue/tests.rs`: 1 cell with a control
  - `docs/session-sync-architecture.md`

## Re-verified at origin/master 5f28e89ac

- `publish_shared_session` inserts into `shared_nat_sessions` at `reverse_session_key` and `reverse_canonical_key`, and into `shared_forward_wire_sessions` at `forward_wire_key`, without conditions. It counts a displaced entry with a different forward key.
- `remove_shared_session` derives the same three keys from the removed entry and `remove`s them with no ownership check.

## Design

- **The fix.** `remove_shared_alias_owned_by(aliases, alias, owner)` removes only when the stored entry's `key == owner`, and the owner-RG index entry is removed only with it. A same-session republish stores the same key, so an owned alias is still removed.
- **Residual, unchanged.** When the removed session had displaced the survivor at publish, the survivor's alias was overwritten at that publish, and removal cannot restore it. That is the #1760 single-value-map limitation, and the displacement counter already makes it observable.

## Validation

- **New cell** in `session_glue/tests.rs`: `removing_a_displaced_session_keeps_the_survivors_shared_aliases_9679`. It has two collision pairs:
  - interface-SNAT hosts on the same port and destination, which share the reverse-wire and forward-wire aliases;
  - identical 5-tuples in two routing domains, which share the domain-zeroing keys.

  For every slot a pair shares, removing the displaced session leaves the survivor's alias, and removing the owner clears it. The cell asserts that the pairs together cover all three slots. A first draft assumed the SNAT pair also shared the reverse-canonical slot, and it failed on that construction assertion: the canonical key keeps each original client address. That is why the cell derives the shared slots instead of asserting them.
