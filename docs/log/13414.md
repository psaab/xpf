# Issue #13414 — native VLAN host-inbound policy

- **Base / STEP-0**: `dd607606a` (`origin/master`). The new regression failed on pristine base: the valid-native case returned `ge-0-0-0` in the unzoned ingress set and placed the parent IPv4/IPv6 addresses in the unzoned address sets. The defect is the #13150 fan-up-row classifier treating a base row as unzoned without checking its configured native VLAN.

Keep unresolved and ambiguous parent rows unzoned; route a valid native parent row's host-inbound addresses and netdev claim through the matching unit's effective zone policy and override. Tagged unit ingress continues to use the same view.
