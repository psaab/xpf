# Issue #10333: WG interop gate measured green

## Disposition

Closed by the final measured `test-wg-interop` run after product issue
[#10409](https://github.com/psaab/xpf/issues/10409) landed and the P5
fragment oracle was hardened. The gate recorded `12` passed cells and `0`
failed cells with matching binaries on both firewalls. The
`test-wg-interop` declaration was removed from
`test/incus/LEDGER_COVERAGE.unreached`.

P5 now captures verbose IPv4 headers and correlates each offset-zero ICMP
echo request with a non-first fragment bearing the same IPv4 ID. The final
run observed five complete request fragment sets; the accepted clean-drop
outcome does not require an oversized echo reply to return.

No product files were changed in the #10333 worktree.
