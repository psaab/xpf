# #12312 — canonicalize static source protocol for QNH map attachment

- **Issue**: #12312 — accepted `from protocol static` spelling variants could skip the qualified-next-hop metric map attachment.
- **Branch**: `fix/12312-campaign-pub`
- **Worktree**: `/var/worktrees/campaign-pub/wt-12312`
- **Base**: `a11e59eac398970413aac11b6bd27318bead06c8`

## Why

`policyHasStaticSource11447` compared the stored source token to the exact lowercase string `static`, while strict validation accepts case- and whitespace-normalized source-protocol tokens. A matching static policy could therefore miss the QNH policy map in the managed-section redistribution attachment.

## What

- Routed the QNH static-source predicate through `config.CanonicalSourceProtocol`, sharing the routing-protocol domain's alias, case, and whitespace normalization.
- Added a compile-to-managed-section regression for canonical, uppercase, mixed-case, trailing-space, and surrounding-space tokens. It verifies that the actual `redistribute static route-map` line names the synthesized QNH policy map and that this attached map carries the metric; a connected-only control does not attach a QNH policy map.

## Validation

### RED before the fix

At base `a11e59eac`, a throwaway probe showed the raw predicate returned false for `STATIC`, `static `, and ` Static ` even though `CanonicalSourceProtocol` returned `static`. Compile-to-managed-section checks showed `STATIC` and ` Static ` attached the ordinary `P-static-xpf-redist` map instead of the synthesized `xpf-qnh-policy-...` map. The set-command parser trims trailing-only whitespace (`static `) before the predicate, so that spelling already attached in this particular compile path.

### GREEN after the fix

- `go test -v ./pkg/frr -run '^TestQualifiedNextHopMetricPolicyAttachesForStaticProtocolSpellings12312$' -count=1` — PASS for all five spellings and the connected-only control.
- `go test -v ./pkg/frr -run '^Test(QualifiedNextHopMetric|QNH|ResolveRedistribute|Redistribute|.*ISIS|GenerateProtocols_ISIS)' -count=1` — PASS; one live FRR LSDB test skipped because root/network namespaces are unavailable.

The selected QNH, redistribution, and IS-IS tests passed.

## Risk

The change only broadens QNH static-source recognition to the same protocol spellings already accepted by strict validation. Non-static sources retain their existing behavior; the regression includes a connected-only control. No live cluster mutation was performed.
