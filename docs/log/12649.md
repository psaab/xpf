# #12649 — align QNH spelling regression with metric-overlay policy

## Why

The spelling regression from #12312 still correctly tests attachment for canonical, case-variant, and quoted-whitespace static protocol values. Its assertion that the integrated route-map contains `set metric 10`, however, predates #12071's shared-map safety policy. Since #12071, the integrated map must be metric-free: FRR copies shared route-map actions to daemons that may drop unsupported QNH match clauses. The configured QNH metric is instead applied in the ospfd-only overlay.

The failure is therefore stale test intent, not a production regression. The #12308 gateway merge is not the cause: the issue reproduction reports failure both before and after #12308, and the renderer policy responsible for the output is #12071.

## What

- Kept the #12312 spelling and connected-only coverage.
- Changed the test to assert that each accepted static spelling attaches the synthesized QNH map, that the integrated map contains no QNH metric action, and that the `ospfd` overlay contains `set metric 10` for that attached map.
- Compared every spelling's rendered managed section to canonical static output as before.

## Validation

- **RED before**: `go test ./pkg/frr -run '^TestQualifiedNextHopMetricPolicyAttachesForStaticProtocolSpellings12312$' -count=1 -v` failed all five spelling cases because the attached integrated map correctly had no metric action.
- **GREEN after**: focused spelling test and related QNH renderer tests passed: `go test ./pkg/frr -run '^(TestQualifiedNextHopMetricPolicyAttachesForStaticProtocolSpellings12312|TestQualifiedNextHopMetricReachesStaticRedistribution11447|TestQualifiedNextHopMetricDoesNotOverrideAuthoredPolicyMetric11447|TestQualifiedNextHopMetricGatesIGPsByMatchCapability12071)$' -count=1 -v`.
- `go test ./pkg/frr -count=1` ran; only the three environment-dependent FRR tests failed because `privs_init` could not `setgroups` (`Operation not permitted`): `TestFamilylessIPv6NeighborWithoutPolicyIsV6Only11564`, `TestFRRLoadInet6OnlyNeighborIPv4Deactivation11374`, and `TestFRRLoadBGPClasslessRIBSuppression11426`.

## Risk

This is a regression-test correction only; production QNH rendering is unchanged. The test now pins the current metric-free shared-map and ospfd-overlay behavior alongside all #12312 protocol spellings. No live FRR or cluster mutation was performed.
