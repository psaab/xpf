# #12908 — IPv6 link-local `http-get` RPM probes bypass strict commit validation and runtime `%zone` scope attachment (D10-06)

- **Timestamp**: 2026-10-14
- **Action**: both `#9026`/`#2494` link-local scope gates parsed the probe
  target as a bare literal — `validateRPMLinkLocalZoneStrict`
  (`pkg/config/compiler_services.go`) split the raw target at the first `%`
  and handed the rest to `net.ParseIP`, and `probeHTTP` (`pkg/rpm/rpm.go`)
  never called the shared `resolveLinkLocalZone9026` guard at all. An
  http-get target carries its host inside a URL, so `http://[fe80::1]/`
  failed IP parsing at commit (gate skipped: strict commit ACCEPTED an
  unprobeable target) and reached `http.Client` at runtime, whose dial error
  (`connect: invalid argument`, no packet leaves the box) was wrapped as
  `HTTP GET failed` — a plain error this package counts as PATH LOSS:
  `SuccFail` increments, the test can transition, and `services
  ip-monitoring` can inject a preferred route off a measurement that never
  ran. The schemeless bare form was even miscarried: `http://fe80::1` makes
  Go's URL machinery treat `fe80:` as the host and `1` as the port, so the
  probe attempted a DNS lookup of `fe80::` per cycle. The tolerant/strict
  doctrine was inverted end to end on exactly the probe type the shared
  `#9026` guard was never wired into.
- **Fix**: `config.FindTargetIPLiteral` (new,
  `pkg/config/compiler_services.go`) extracts the IP-literal host and
  `%zone` from every target form the runtime accepts — bare literal
  (`fe80::1%ge-0/0/3`), schemeless bracketed (`[fe80::1%25ge-0/0/3]:8443`),
  full URL (`http://[fe80::1%25ge-0-0-3]/hb`) — returning the literal's byte
  span for in-place rewriting; userinfo is stripped, the URL path separator
  cut is applied only to schemed unbracketed authorities so a Junos slash
  zone (`ge-0/0/3`, legal in the bare and bracketed forms) is never
  truncated. The commit gate now uses it, so the URL form is rejected
  exactly like the bare form (and the operator error names both spellings).
  `probeHTTP` resolves the zone through the same shared
  `resolveLinkLocalZone9026` as TCP/ICMP before any request
  (`scopeHTTPTargetZone12908`, new `pkg/rpm/http_linklocal_12908.go`): an
  unscopeable literal returns `ErrProbeSetup` (the test HOLDS — no counters,
  no transition, mirroring a leniently loaded icmp/tcp test), and a scoped
  literal is rewritten with the resolved kernel zone in RFC 6874 `%25` form,
  preserving scheme, port and path — which also repairs a URL whose raw
  slash-zone spelling could never have parsed. Strict commit rejects;
  tolerant load still downgrades to a warning (`#1960` no-brick) and the
  runtime hold keeps the doctrine fail-closed.

    `TestRPMLinkLocalURLFormNoScopeStrictRejects12908` (three scopeless

    `TestRPMLinkLocalURLFormScopedAccepted12908` (valid `%25` zone and
    destination-interface derivations accepted),

- **Risk**: strict commit now rejects URL-form scopeless link-local targets
  that were previously accepted — they were silently dead probes feeding
  ip-monitoring failover, which is the point; the tolerant load path still
  boots them with a warning and the runtime holds their state. A scoped
  literal whose zone names an absent/down interface dials and fails as
  ordinary loss — matching `probeTCP`. Redirect `Location` hosts are not
  zone-resolved (attacker-controlled, bounded by the `#10726` redirect
  limit); the guard covers the configured target.
