# #14655 — Local-origin GRE TX drops portless protocols

## Defect
`build_local_origin_tunnel_tx_request` (`userspace-dp/src/afxdp/tunnel.rs`)
dropped every locally originated packet whose protocol has no ports:
`parse_session_flow_from_bytes` returns `None` by design (#3067) for
OSPF (89), PIM (103), ESP (50), VRRP (112), IGMP, and non-query
ICMP/ICMPv6 (ND/RA/MLD, PMTUD and other errors) via `parse_flow_ports`.
The only rescue was the #14119 non-first-fragment arm; every other
flowless packet hit `parse_local_origin_session_flow_failed` and was
dropped. The wire path forwards these flowless, so the local-origin
path was the outlier — e.g. an OSPF adjacency over a `gr-` interface
received peer Hellos (inbound decap delivers to TUN) but could never
send one, making adjacency failure total.

## Fix
- `frame/inspect.rs`: new `local_origin_flowless_eligible(frame, meta)`
  — admits a session-less packet only when its L4 header is complete
  inside the IP-declared datagram end (#2361; verified L3, #9900
  idiom): portless protocols need ≥1 L4 byte; ICMP/ICMPv6 need the
  full fixed 8-byte header and a non-identifier-bearing type
  (identifier-bearing queries are flow-bearing, so their `None` means
  truncation); TCP/UDP and No-Next-Header (59) are never eligible.
  Truncated/uninspectable packets still fail closed.
- `tunnel.rs`: the flowless rescue arm now also fires for eligible
  portless packets, recovering only the L3 source identity (never
  ports). The zone and source-ownership gates below still apply
  before transmission; flowless packets mint no TunOrigin session
  and seed no IKE exchange (both keyed on `flow`).

## Tests
New in `frame/tests_native_gre_ecn.rs` (all through
`build_local_origin_tunnel_tx_request`):
- `local_origin_tunnel_portless_protocols_transmit_without_session_14655`:
  OSPF (multicast dst), PIM, ESP, VRRP, ICMP Redirect transmit GRE-
  encapsulated verbatim, with no session, no flow key, no IKE seed.
- `local_origin_tunnel_icmp_errors_and_icmpv6_nd_transmit_without_session_14655`:
  ICMP types 3/11/12/5 and ICMPv6 types 133–137/2/3 transmit flowless.
- `local_origin_tunnel_portless_nonlocal_source_fails_closed_14655`:
  nonlocal OSPF still fails at the source-ownership gate (control).
- `local_origin_tunnel_truncated_icmp_fails_closed_14655`: ICMP header
  past the declared datagram end still fails closed (control).
- `local_origin_tunnel_ipv6_overlimit_chain_fails_closed_14655`:
  9-hop-by-hop chain still fails closed at `local_origin_packet_meta`
  (control, #4743).
