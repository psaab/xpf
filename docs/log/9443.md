# #9443: the api.Config hooks built in startHTTPServer had unbound assignments

- **Timestamp**: 2026-09-11T02:55Z
- **Action**: Moved the `api.Config` construction out of `startHTTPServer` into `Daemon.apiServerConfig`, and bound every func-typed hook assignment with one reflection cell.
- **File(s)**:
  - `pkg/daemon/daemon_run_servers.go`
  - `pkg/daemon/api_server_config_hooks_9443_test.go` (new)

## Mechanism (origin/master `1820ffac3`)

`startHTTPServer` built the `api.Config` literal inline (lines 318-654) and handed it to `newManagementReconciler`. Nothing calls `startHTTPServer` or `runServers` from a test, so the ASSIGNMENT of each hook in that literal was unbound. #9165 measured the gap: deleting `SyslogDropsFn: d.syslogDropStats,` passed `go build ./...` and `go test ./...`. The hook's function and `api.NewServer`'s field copy were both covered. Only the one line naming the function in the literal was invisible.

## Change

- **Extraction.** The `#2114` comment, the `apiDP` live-indirection setup and the literal moved VERBATIM into `func (d *Daemon) apiServerConfig(eventBuf *logging.EventBuffer) api.Config`. The only edit is `apiCfg := api.Config{` becoming `return api.Config{`. `startHTTPServer` now does `apiCfg := d.apiServerConfig(eventBuf)`, and everything after the literal is unchanged.
- **The cell.** `TestAPIServerConfigBindsEveryHook_9443` builds the config from a zero `Daemon`. Every hook is a closure or a method value, and nothing in the literal dereferences a nil manager at construction: the two `d.store` hooks are pointer-receiver method values. The cell walks every func-typed `api.Config` field (50 at this head) and fails on any left nil that is not a documented injection seam.
- **The seams.** Nil is the production default for three fields, each verified at its reader:
  - `ListenFunc`: nil selects `net.Listen` (#5866).
  - `PeerLookupFn`: nil selects `pkg/authz`'s kernel lookup (#5278).
  - `PeerLocalityFn`: nil selects the fresh local-address enumeration.
- **The seam list checks itself.** The cell also fails if a listed seam becomes set, or if a listed field no longer exists, so the list cannot rot into an excuse.
- **Coverage.** A precondition requires at least 40 func fields, so a shrunken reflection scope cannot pass by checking nothing. A new hook added to `api.Config` and not wired in `apiServerConfig` now fails this cell too.

No docs change is needed. `pkg/daemon/README.md` does not describe how the HTTP server's config is assembled; the contract lives on the method's doc comment and in this cell.
