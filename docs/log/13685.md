# #13685 — Protocol-qualify reverse static NAT port lookups

Outbound ICMP Echo/Query parsing stores its identifier in `src_port`. A reverse
static-SNAT lookup previously used that value against the port-specific map
without checking the packet protocol, so an identifier colliding with a TCP/UDP
service port could select the service's static mapping and counter. The lookup
now consults the port-specific tier only when the known protocol carries
rewritable TCP/UDP ports; whole-address entries remain protocol-agnostic.
Production decision, policy-revalidation, and fragment-association paths pass
the packet protocol. Regression coverage checks ICMP/ICMPv6 and SCTP misses,
TCP/UDP matching, and fallback to a whole-address rule.
