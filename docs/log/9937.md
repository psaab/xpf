## Why comment-only (M1 sharing alternative, per acceptance)

Acceptance allows removing the duplication instead. Sharing in the
api-imports-from-grpcapi direction would be cycle-free (that edge already
exists via `dhcp.go`; grpcapi imports zero api symbols, so the reverse
would cycle) and would not break the diag budget (both `diagLimiter` vars
alias `diagcmd.DefaultLimiter`; the formula is pure; no test seam touched;
no new build edge). Cost: exported API surface for one consumer, forcing
one shape where two already diverge (api inlines the ceiling check,
grpcapi delegates to `clampDiagTimeout`), plus touching exec paths
(reboot/halt, diag) for a comment cohort. Comment-only states the truth and
leaves the layering choice to a deliberate refactor.
