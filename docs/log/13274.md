# #13274 — bridge and mark unsupported userspace global counters

- **Issue**: #13274 — D1-02 global counters were not bridged from helper binding status.
- **Branch**: `fix/13274-campaign-pub`
- **Base**: `origin/master` `802eda508`
- **Files**: `pkg/dataplane/userspace/manager_counters.go`, `pkg/dataplane/userspace/legacy_dataplane.go`, their counter tests, this log.

## Why

The userspace status poll accumulated flow-cache hits/misses, host-local
accepted traffic, and fabric redirect unsendable drops from each binding, but
did not transfer them to the global-counter offsets read by `/metrics` and
`/api/v1/stats`. Those exported counters therefore returned confident zeroes
under userspace forwarding. Several other legacy indices do not have a
corresponding userspace status field; leaving the untouched BPF shim values
readable would also misrepresent absence of a measurement as a measured zero.

## What

- Sum per-binding `FlowCacheHits`, `FlowCacheMisses`, `LocalDeliveryPackets`,
  and `FabricRedirectUnsendableDrops`, and push cumulative deltas into
  `GlobalCtrFlowCacheHit`, `GlobalCtrFlowCacheMiss`, `GlobalCtrHostInbound`,
  and `GlobalCtrFabricFwdDrop` respectively.
- The legacy adapter reports `ErrCounterNotPopulated` for flow-cache flush,
  flow-cache invalidation, TC egress, and successful fabric redirect. These
  have no source in the userspace binding status protocol. In particular,
  `FlowCacheEvictions` is NOT reported as a flush: eviction and explicit
  `invalidate_all` are distinct events.
- `/api/v1/statistics/global` returns the available measurements with a
  `unavailable_counters` field for unsupported indices rather than failing the
  entire response. Genuine counter read failures remain HTTP 500. This preserves
  useful sourced values while marking exact unsupported fields non-authoritative.

- `gofmt -l` on the changed Go files and `git diff --check`: clean.

## Risk

`/api/v1/statistics/global` retains the available counters and names unsupported
ones explicitly; real read failures still fail the request. Prometheus omits
unsupported series and increments its existing counter-read-error metric.
