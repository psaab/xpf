# 12253 — tunneled PBR revalidation fixture routes

- **Timestamp**: 2026-10-08

- **Base**: `a714c90d472a3c3d98a3799831cfef3ec311a61c`

## Why

The blue and green PBR fixtures supplied routes in `blue.inet.0` and
`green.inet.0` but omitted those tables from `ConfigSnapshot.forwarding_tables`.
The builder consequently refused the default-instance WAN/tunnel egresses in
those forwarding-instance tables. The route lookups were dead: both tunnel
checks returned endpoint id 0, and the native check returned `NoRoute`. These
were fixture-liveness failures, not failures of the session-hit revalidation
behavior.

## What

Marked `blue.inet.0` in the blue tunnel fixture and `green.inet.0` in both green
retarget fixtures. This allows the configured default-instance WAN gateway and
tunnel interfaces to be used by those forwarding-instance route tables. No
production code or test assertions changed.
