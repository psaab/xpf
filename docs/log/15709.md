# Issue #15709: system ntp peer/trusted-key and top-level syslog silent drops

- **Timestamp**: 2026-10-19
- **Problem**: `system ntp peer`/`trusted-key`, `system ntp server <addr> source-address`, and top-level `system syslog console`/`source-address`/`time-format`/`archive`/`log-rotate-frequency` committed clean with zero enforcement and zero #4231/#9414 advisory. Probe on pre-fix: `ntp peer` dropped (NTPServers=[server only], Warnings=[]), `trusted-key` silent, per-server `source-address` absorbed as a second bogus server (`NTPServers=[192.0.2.1 source-address 10.0.0.1]`), syslog console/source-address/time-format/archive/log-rotate-frequency produced empty Syslog and no warnings.
- **Fix (schema)**: `pkg/config/schema_system.go` models `ntp peer` (multi, valueList, same modifiers as server plus source-address), `trusted-key`, `authentication-key`, `boot-server`, `source-address` under `ntp`; per-server `source-address` under `server`; and top-level `syslog console` (wildcard facility/severity), `source-address`, `time-format`, `archive`, `log-rotate-frequency` under `syslog`.
- **Fix (compiler)**: `ntp peer` compiles to `SystemConfig.NTPPeers`/`NTPPeerOptions` (generalized `ntpSourceValues`/`ntpSourceModifierNames` over server/peer), rendered by daemon as chrony `peer <addr> iburst` lines in the same sources file. Peer/server `key` stripped to NTPServerKeyIDs (#14596 belt). `trusted-key` ids retained in `NTPTrustedKeyIDs` with a not-enforced advisory. Per-server/peer `source-address` and `routing-instance` recorded on the option and warned as not bound. Top-level syslog `source-address` stored as `DefaultSourceAddress` and inherited by hosts without their own (own wins); `console`/`time-format`/`archive`/`log-rotate-frequency` recorded in `TopLevelInert` and warned via the #9414 skipped-modifier machinery (`system syslog top-level <kw>: accepted but NOT applied`). New typed fields are `json:"-"` so the golden/API surface is unchanged for configs not using them.
- **Daemon**: `renderChronyPeers` + `applySystemNTP` appends peer lines to chrony sources.
