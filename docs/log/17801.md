# #17801 — capture exporter groups before remove-all teardown

- **Timestamp**: 2026-10-26 (`fix/17801-campaign`)
- **Action**: Removed premature empty-bundle publication from v9 and IPFIX remove-all reconciliation so teardown can capture and stop every exporter group.

## Why

Both empty-config reconcile branches stored an empty bundle before calling their teardown helper. The helper then captured that already-empty bundle and fell back to the legacy family-wide cancellation handles, which point only at the last published exporter. Other per-group workers remained uncancelled.

## Change

- `pkg/daemon/daemon_flowexport.go`: let `teardownV9Locked` and `teardownIPFIXLocked` capture the live bundles before unpublishing them.
- `pkg/daemon/daemon_flowexport_mixed_16752_test.go`: added v9/IPFIX multi-group lifecycle tests that retain each worker completion handle, exercise two add/remove cycles, assert retained failed siblings keep running across a partial build failure, and verify remove-all terminates every group.

## Validation

- RED with the old pre-teardown stores restored: `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/daemon -run 'TestRemoveAllExporterGroupsJoins' -count=1` — both new tests failed on v9 and IPFIX worker completion (`v9=false IPFIX=false`).
- GREEN with the fix: `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/daemon -run 'Test(ReconcileFlowExporter|ReconcileIPFIX|Partial|Mixed|SessionClose|Telemetry|ExporterTeardowns|FlowExport|Sampling|RemoveAllExporterGroups)' -count=1` — passed.
- `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/daemon -count=1` — package run failed in unrelated DNS rollback, DHCP, HA event-stream, nft netlink parity, ownership, and factory-reset tests (including a configstore nil-pointer panic). The focused flow-export suite above passed.

## Risk

Removal now cancels and joins every live v9 and IPFIX group instead of only the last group's worker. Partial-build retention behavior and exporter configuration are unchanged.
