# #12054 — reject inert `except` under `any-service`

- **Timestamp**: 2026-10-08 (fold 2026-10-09: protocols arm + independent gate)
  - **Why**: `system-services any-service` is a packet-wide full-admit, not a subtractable union. The compiler kept `any-service` after `ssh except`, and strict compilation accepted the stanza while the generic breadth advisory omitted the discarded exclusion. A `protocols ... except` under a retained `any-service` is inert for the same reason (runtime admits before protocols are consulted).
  - **What**: The independent `validateHostInboundFullAdmitExceptStrict` gate rejects `any-service` with retained system-service OR protocols exclusions, naming the distinct known excluded token(s) per kind. The tolerant path downgrades each offending stanza to its OWN warning via the dedicated `lenientHostInboundFullAdmitExcept` flag (unknown-token diagnostics preserved); the compiled service set remains `[any-service]` for persisted-config compatibility. Updated the host-inbound service matrix to document this distinction from `all` exclusions.
  - **File(s)**: `pkg/config/compiler_validate_strict_zones.go`, `pkg/config/compiler_opts.go`, `pkg/config/compiler_uniformgates_cluster_zone.go`, `pkg/config/compiler_host_inbound_except_12054_test.go`, `docs/host-inbound-service-matrix.md`.
  - **Validation**:
    - STEP-0 on base `a714c90d4`: a throwaway scenario logged strict `err=<nil>`, lenient tokens `[any-service]`, and no lenient warning containing `ssh` (only the generic full-admit advisory).
    - RED before fix: `go test ./pkg/config -run '^TestHostInboundExcept12054' -count=1 -v` failed both assertions: strict compile returned nil and lenient warnings omitted `ssh`.
    - GREEN after fix: the same command passed strict-fail and lenient-warn tests for hierarchical zone, flat-set zone, and per-interface cases; all preserved `[any-service]` on the tolerant path.
    - `go build ./pkg/config` passed; `go test ./pkg/config -run '^TestHostInboundExcept(12054|10292)' -count=1` passed, covering the complete #12054 regression file and existing #10292 exception suite.
    - `go test ./pkg/config` failed in broader existing gates (`TestInventoryDropShapeMatchesTheLiveCensus8662`, `TestMultiLeafSelfRepeatIsRefused9027`, `TestLegitimatelyNamedObjectIsAccepted9029`, `TestElidedQuotedValueKeepsItsQuote8921`, `TestSystemConfigWebManagementEnhanced`, `TestSystemConfigSetSyntax`, `TestPackedRoutingInstanceSurvives8787`, and `TestSlotEscapeCoverage`); the same selected failures reproduced on a clean worktree at base `a714c90d4`. The full package run also hit its 10-minute timeout during `TestSchemaSpellingDifferentialGate`.
  - **Risk**: Lenient load intentionally preserves the full-admit `any-service` runtime behavior and only warns; strict commit blocks the unsupported exclusion. An operator must remove `any-service` or replace it with an expressible service list if the exclusion is intended to constrain admission.
