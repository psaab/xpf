# #19133: `make test-rust` leg 1 reports every test target

- **Timestamp**: 2026-11-16
- **Action**: Leg 1 of `make test-rust` (`cargo test --release --bins
  --tests -- --test-threads=1`) now passes `--no-fail-fast`. Without it cargo
  stops at the first red test binary. The `xpf-userspace-dp` unit binary is
  red on master, so leg 1 never ran any `userspace-dp/tests/*` target, and a
  new red there was invisible for as long as any unit cell was red. The
  attribution pass found 6 such red targets hidden on master.
- **Action**: `scripts/test-rust-leg1-selftest.sh` (registered in
  `scripts/run-selftests.sh`; `make test-rust-leg1-lib`) takes leg 1's
  command from the real recipe (`make -n test-rust`, continuation lines
  joined, the single `test --manifest-path userspace-dp/Cargo.toml --release`
  line). It runs that command, with only the manifest path swapped, on a
  fixture crate: a bin with a deliberately red unit cell, and a deliberately
  red `tests/` target that cargo runs after it. Cells:
  - both failures must be reported and the command must exit nonzero;
  - mutation: the same command without `--no-fail-fast` must hide the
    `tests/` failure, so the fixture can see the defect.
  It SKIPs (77) without cargo or the pinned toolchain.
- **Validation** (runner VMs via `scripts/vm-test-run.sh`; tcp:xpf-testrunner):
  - GREEN on the branch: 4 passed, 0 failed; shellcheck clean.
  - RED at master (master's Makefile copied in on the runner): the
    "both" cell fails (unit=yes, tests=no: cargo stops after `--bin
    leg1-fixture-19133`) and the mutation cell finds no flag to remove.
- **Residual (not changed)**: legs 2 and 3 run as later recipe lines, so a
  red leg 1 still stops make before them. They are curated debug-profile
  reruns. Running every leg and failing at the end would need a restructured
  recipe; left for a decision.
  - **File(s)**: `Makefile`, `scripts/test-rust-leg1-selftest.sh`,
    `scripts/run-selftests.sh`, `docs/testing.md`, `docs/log/19133.md`

- **Timestamp**: 2026-11-16
- **Action**: Closed the residual above in the same branch (team-lead): a red
  leg still stopped make before the legs after it, which is the same masking
  class. Each leg line of the `test-rust` recipe now ends in `|| echo "Leg N:
  ..." >> <file>`, a per-run file keyed by make's PID (each recipe line is
  its own `sh -c` whose parent is make), so a failed leg records itself and
  make continues. The recipe's last line prints "test-rust: FAILED legs:"
  with each failed leg and exits 1, or prints "every leg passed". The two
  prerequisites (`lint-rust-baseline`, `check-userspace-dt-needed`) still
  stop make; they are not legs.
- **Action**: The selftest now runs the whole recipe from `make -n test-rust`
  (prerequisites excluded with `-o`), line by line the way make does,
  stopping at the first nonzero line, with only the manifest swapped to the
  fixture. On the fixture, leg 1 is red by construction, and leg 2's oracle
  census fails closed because the fixture holds none of the oracle's cells.
  Cells:
  - both: leg 1 reports both fixture failures;
  - every leg: the recipe reaches its end, names leg 1 AND leg 2, and exits
    nonzero;
  - mutation: no `--no-fail-fast` hides the tests/ failure;
  - mutation: a leg 1 that does not record its failure stops the recipe
    before leg 2.
