# #16438 — Degraded shim drops every host-bound fragmented UDP datagram when any WG tunnel is configured

## Defect

`is_degraded_local_or_control` ran `wg_fragment_stays_on_helper`
before `should_fallback_early`, `is_local_destination` and
`degraded_general_local_pass_applies`, without the
`protocol == PROTO_FRAGMENT_NO_L4` restriction the healthy path
applies at its `wg_fragment` binding. The predicate matches any
fragmented UDP (`17/17` head or `255/17` tail) whenever `WG_RX` is
armed, so with one WireGuard tunnel configured every host-bound
fragmented UDP datagram — IKE with certificates, NAT-T, large
DNS/RADIUS replies, including interface-NAT addresses — was dropped
as degraded transit instead of reaching the kernel. Fail-closed,
bounded to degraded windows (helper down/restarting, binding not
ready, heartbeat stale, ctrl disabled).

## Fix

- `userspace-xdp/src/lib.rs`: gate the degraded WG exclusion on
  `parsed.protocol == PROTO_FRAGMENT_NO_L4`, mirroring the healthy
  path. Only tails are excluded; a head (UDP, with ports) now falls
  through to the local/control arms (`should_fallback_early`,
  local destination, interface-NAT, WG steer, session
  PASS_TO_KERNEL), so a fragmented UDP head to a local address with
  WG_RX armed is kernel-passed in degraded mode. Tails keep
  dropping with their head — a lone tail has no port and was never
  kernel-reassemblable; the head decides the datagram.
- NOT changed: the raw `wg_fragment_stays_on_helper` predicate
  (its healthy-path head row remains load-bearing — heads reach
  the worker via `wg_worker_claim`/session-miss and must not take
  kernel-pass arms), the healthy path, native-GRE degraded
  exclusion, and the worker reassembly pool.

## Tests

- `tests_wg_outer_frag_15102::wg_fragment_shim_truth_table_15102`:
  head row relabelled healthy-path; new `degraded_wg_excluded_16438`
  composition mirroring the degraded call site pins: fragmented
  UDP head armed → not excluded, WG tail armed → excluded, whole
  UDP / unarmed tail / GRE tail → not excluded by the WG arm.
- Existing 15102 reassembly cells (v4 decap-once, v6 pool) unchanged
  and green.

## Validation

- `cargo test --bin xpf-userspace-dp -- wg_fragment_shim_truth_table_15102` — targeted run (see PR).
- Shim verifier (`cmd/shimverify`) should be re-run by main on a
  host where master passes; the change adds one compare to an
  already-outlined cold path.
