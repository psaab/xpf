# Issue #10439: REST show-text nil config slots

## Disposition

Fixed the REST `/show-text` renderer so present-but-nil map values and
firewall-term slice entries are skipped instead of dereferenced. The guarded
families are schedulers, SNMP communities and trap groups, DHCP relay server
groups and relay groups, firewall filters and terms, dynamic-address feed
servers, address-book addresses and sets, applications, and NetFlow v9
templates. The existing #5221 application-set guard remains unchanged.
Valid siblings continue to render in deterministic key order.

## RED-then-GREEN regression evidence

`Commit`, inject a present-but-nil value into the live `ActiveConfig`, and call
the real `showTextHandler`. The test-only `recover` converts an unexpected
handler panic into a hard failure; it is not the production correctness
mechanism.

## Scope

regression file `pkg/api/show_text_nil_slots_10439_test.go`. This evidence log
is the only documentation change. No other packages or config/dataplane code
was changed.
