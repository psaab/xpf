# 14989 — Stream flow-session brief output instead of buffering the full table in tabwriter (D37-04)

## Summary

`show security flow session brief` in `pkg/cli` rendered through a
`text/tabwriter.Writer` (`newSessionBriefWriter`, `pkg/cli/cli_show_flow.go`).
`tabwriter` buffers the ENTIRE table until `Flush`, so over a full session
table every row was heap-buffered before any byte reached the terminal or
pager — defeating streaming/pagination for the largest operational table.
Scope narrowing (binding, from the issue): `pkg/cli` only; the `cmd/cli`
leg is narrowed/stale (it already prints fixed-width rows directly via
`fmt.Printf` in `cmd/cli/show_flow.go:printSessionEntries`) and is NOT
changed.

## Fix

`pkg/cli/cli_show_flow.go` only:

- `newSessionBriefWriter` now returns a `*sessionBriefWriter`, a thin
  pass-through `io.Writer` wrapper. Header and each row are written to the
  underlying writer (`os.Stdout`) as they are printed during the
  `IterateSessions`/`IterateSessionsV6` walk and the peer-session loop.
- `printSessionBriefHeader`/`printSessionBriefRow` emit the fixed-width
  layout already used by `cmd/cli` `printSessionEntries` and
  `showTopTalkers` (`%-5s %-22s %-22s %-5s %-20s %-3s %-5s %5s %s`), so no
  whole-table alignment pass is needed. Values longer than their field
  overflow without truncation (Go `%-Ns` semantics), preserving the
  long-value guarantee `TestSessionBriefWriterPreservesLongValues` pins
  (IPv6 endpoints, long zone-pair names, packet counts).
- `flushSessionBriefWriter` is retained as an explicit end-of-table no-op
  so local and peer call sites keep their shape; rows are already emitted.
- The now-unused `text/tabwriter` import is removed. No other file uses
  tabwriter for this table.

NOT changed: `cmd/cli` (already streaming, per narrowing), the
`diagcmd.SessionWalkLimiter` admission budgets (the local CLI walk is a
separate surface; changing admission was not the cited mechanism), the
non-brief detailed/summary/top-talkers renderers, and peer session
fetching/sorting.

## Regression (RED → GREEN)

- `TestSessionBriefWriterStreamsBeforeFlush14989`
  (`pkg/cli/cli_show_flow_brief_stream_14989_test.go`): writes the header
  and a row through `newSessionBriefWriter` into a `bytes.Buffer` and
  asserts the bytes are ALREADY in the buffer before
  `flushSessionBriefWriter` — the exact D37-04 buffering mechanism.

  writer before flush". GREEN after the fix. Also asserts no tab

  `TestPeerSessionBriefNATFlag13247`, and the full `pkg/cli` suite

## Risk

Column alignment for the brief table is now fixed-width rather than
computed from the widest row in the whole table: rows whose fields exceed
the fixed widths shift later columns right on that row only (never
truncate). This matches the existing `cmd/cli` brief and top-talkers
output. No admission, filtering, or session-walk behaviour changes.
