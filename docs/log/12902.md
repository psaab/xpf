- **Timestamp**: 2026-10-14
- **Action**: Both `show security policies` dispatchers (`pkg/cli/cli_show_security_dispatch.go` handleShowSecurity and `cmd/cli/show_security.go` handleShowSecurity) selected the view by testing `args[1]` only, while their validators (`validatePolicyZoneFilter` / `validatePolicyZoneSelectors`) admitted `brief`/`detail`/`hit-count`/`global` at ANY unconsumed position — so a trailing keyword (`from-zone X to-zone Y detail|hit-count|brief|global`) or a second keyword (`brief global`, `detail global`) was validated and then silently DISCARDED: the operator got the standard, unscoped view and a success return (D9-12). The #9478 value-slot census site strings now name the new walk.
