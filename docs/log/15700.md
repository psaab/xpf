# Issue #15700: DDNS show surfaces ignore v6 policy, omit gRPC orphans, blank non-RFC2136 targets

- **Timestamp**: 2026-10-19
- **Problem**: `show dhcp-server dynamic-dns` (CLI `pkg/cli/show_services_ddns.go` and gRPC `pkg/grpcapi/server_show_dhcp_lldp_snmp.go`) read only `DHCPServer.DynamicDNS` (v4), so a `dhcpv6-local-server dynamic-dns` (`DynamicDNSv6`) config printed `not configured` and never reached shared counters/owned records. The gRPC `show services dynamic-dns` lacked the CLI's `Orphaned` alarm + `Orphaned records:` counter. Both surfaces printed `update-server=<blank>` for dyndns2/duckdns/cloudflare/route53/generic providers whose target is not `UpdateServer`.
- **Fix**: Both `showDHCPDynamicDNS` twins now collect `DynamicDNS` and `DynamicDNSv6`, return `not configured` only when both are nil, render each non-nil family via a per-family helper (`DHCP Dynamic DNS (IPv4):` / `(IPv6):`, with `applies to <other> by inheritance` when only one family is configured, matching the reconcile-time single-family inheritance in `pkg/ddns`), then always render shared counters/alarms/owned records. Both `showServicesDynamicDNS` twins render a backend-appropriate target via `ddnsProviderTarget` (`update-server` rfc2136, `server` dyndns2/duckdns, `zone` cloudflare, `hosted-zone-id` route53, `url-template` generic; URL values via `config.RedactURL`). gRPC Surface A adds the `st.Orphaned > 0` alarm block and `Orphaned records:` counter line mirroring the CLI.
- **Regression (RED→GREEN)**: New `pkg/cli/cli_show_ddns_15700_test.go` (v6-only via store commit, both-families, provider targets incl. credential redaction) and `pkg/grpcapi/server_show_ddns_15700_test.go` (v6-only, orphan alarm/counter, provider targets). RED pre-fix: v6-only printed `not configured`, orphan assertions failed, providers printed `update-server=` blank. GREEN post-fix with neighbouring 15174/9497/6468 redaction+escape suites.
- **Not changed**: Config compile, reconcile inheritance, backend resolution, and counter semantics are untouched — display only.
