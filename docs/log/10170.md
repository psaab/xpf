## Review fold

- **Authority skew**: matched-scope narrowing now requires canonical CIDR and exact RG agreement; omitted, moved, duplicate, mixed, malformed, unserved, and generation-mismatched scopes retain the conservative union. Filtered DHCP config and its authority scopes share one captured master-RG map through commit, transition, retry, and clear paths.
- **Proof minting**: asynchronous and synchronous cluster-commit workers publish per-family proof only from their own successful Kea branches; inactive cluster units and shutdown-latched late applies cannot claim `Served && Applied`. Snapshot emission also rejects same-generation results whose CIDR/RG/Served state differs from current ownership. The receive path admits sequence numbers before decode but advances only after a valid replacement.
- **Safety/documentation**: removed the unused subnet-ID export, restored the `Apply`/cluster-generation and residence-aging rationale, refreshed the LFC and cluster authority contracts, and added fail-on-revert coverage for proof minting, mixed groups, moved RGs, malformed metadata, shutdown fencing, mastership changes, and sequence reuse.

Production calls those methods directly, so a fake or implementation that silently falls back to legacy apply paths cannot leave the proof channel untested.
