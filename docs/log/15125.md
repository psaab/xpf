# #15125 — firewall policer missing limits + `policer`/`if-exceeding` closedWorld

- **Issue**: #15125 (A85-06) — a `firewall policer` with no
  `bandwidth-limit`/`burst-size-limit`, or with a misspelt
  `if-exceding`/`bandwith-limit`, passed strict commit; the helper then
  built a fail-closed meter dropping every policed packet.
- **Files**: `pkg/config/schema_cos.go`,
  `pkg/config/compiler_validate_strict_cos.go`,
  `pkg/config/compiler_uniformgates_filter.go`,
  `pkg/config/compiler_opts.go`,
  `pkg/config/policer_missing_limits_15125_test.go`,
  `pkg/config/dup_block_merge_9209_test.go`,
  `pkg/config/instance_name_blind_ratchet_9091_test.go`,
  `docs/config-schema.md`, `debian/changelog`, `docs/log/15125.md`.

## Why

`compileFirewall` defaults a policer to `ThenAction: "discard"` and sets
the limits only from recognised `if-exceeding` children; there was no
missing-limit check. #5299 validated the limit values when present, but
nothing required their presence, and the policer schema was open-world,
so a typo'd container/leaf was silently dropped. The missing limit
compiled to 0 and the dataplane lowers a 0 rate/burst to a fail-closed
meter (`None` → `fail_closed(true)`), dropping all policed traffic with
a green commit.

Measured on base (probe, since removed): no-limit, single-limit, empty
`if-exceeding`, `if-exceding`, and `bandwith-limit` spellings all
compiled clean strict (SchemaValidate nil, CompileConfig nil) with
`BandwidthLimit`/`BurstSizeLimit` 0 as applicable; lenient emitted no
warning.

## What

- `validateFirewallPolicerLimitsStrict` (single-rate twin of
  `validateThreeColorPolicersStrict`): strict-reject a policer with
  `BandwidthLimit == 0` or `BurstSizeLimit == 0`, naming the policer
  and missing leaf; wired in `runUniformGatesFilter` after the
  #9882/#8445 then-action gates.
- `lenientPolicerMissingLimits`: tolerant load / peer-sync downgrades
  to a `cfg.Warnings` entry (#1960 no-brick; 0-limit behaviour
  unchanged, now diagnosed).
- `closedWorld: true` on `policer` and `if-exceeding` (leaf-complete
  grammar); the policer `then` node is `closedWorldOpaque` because its
  grammar is compiler-owned (#9882 gate, block-form values).
  `/firewall/policer` moves blind → armed in the #9091 ratchet.
- Neighbour fixture: `TestSiblingContainerMergeIsScopedToFoldedBlocks9209`
  (two intentionally single-limit policers) now compiles leniently.

NOT changed: three-color policers (already gated), limit value
validation (#5299), dataplane fail-closed lowering (the backstop).

## Risk

previously committed as blackholes; persisted/peer-synced copies boot
with a warning. Full policers unchanged.
