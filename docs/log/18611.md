## Why

The Go skip census had accumulated unbanked drift, and the early census steps in the CI job used GitHub Actions' default `success()` condition. One failed census therefore prevented later census/self-test steps from reporting their own failures.

The real filter setup remains unmocked: success or a filter-stage error is accepted, but any earlier error or failure to reach membership is fatal. This verifies receiver wiring without an unnecessary filter seam. The remaining AF_UNIX socket-creation skip is a real fixture-availability gate.
- The 16 demotion/helper-exit skip sites all use fixed direct-mode fixtures. `newDemotion18701` wraps `newActuationDaemon`, whose `fenceStartupClusterSet` keeps the production default `private-rg-election` enabled, making `isNoRethVRRP()` true; the two-RG helper builds the same fixed store. - The final tree measures 658 total (139 priv-absent, 18 priv-present, 500 other, 1 unparsed). Against the existing floors it banks only the 46-net increase: +17 priv-absent and +29 other. The 47 remaining newly counted sites are itemized below; a new IFNAMSIZ-constrained CLI interface gate replaces the previous dash-interface reason, so that replacement is net zero.
- Add `if: ${{ !cancelled() }}` to every census and self-test step in the CI census job. The byte-pinned literal and its admitted-`if` comment are synchronized so the self-test accepts only this exact fail-through condition.
