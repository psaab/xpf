## F5 — limit-session must exclude worker-local replicas

### RED

A baseline-only probe installed a `SessionOrigin::WorkerLocalImport` replica and required the logical count to remain zero:

```text
cargo test --manifest-path userspace-dp/Cargo.toml --bin xpf-userspace-dp session_limit_worker_replica_red_10310 -- --nocapture
```

## F7 — policer burst must hold at least one MTU packet

### RED

The new validator regression was applied to the baseline package and run before the validator change:

```text
go test ./pkg/config -run '^TestPolicer10310_RejectsSubPacketBurst$' -count=1
```

The baseline failed as intended: values `1`, `100`, and `1499` were accepted, so all three subtests reported `expected rejection below one 1500-byte packet`.

### GREEN

`ValidatePolicerBurstSize` now rejects any parsed burst below `1500` bytes and accepts exactly `1500` bytes. The regression passed:

```text
go test ./pkg/config -run '^TestPolicer10310_RejectsSubPacketBurst$' -count=1
```

Result: `ok github.com/psaab/xpf/pkg/config 0.006s`.
