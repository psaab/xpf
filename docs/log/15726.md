# Issue #15726: duplicate physical/unit-0 interface rows

- **Timestamp**: 2026-10-19
- **Action**: canonicalized interface row identity in `pkg/api` and `pkg/grpcapi`. Added `canonicalInterfaceName` (unit-0 refs collapse to their base via `SplitInterfaceUnitRef` + `CanonicalLogicalUnit`, declared dotted names preserved) and `interfaceZoneMap` (zone map keyed by canonical name). `allInterfaceNames` in both packages now returns canonical names, so `reth0` + `reth0.0` yield one row. Wired the canonical zone map into REST `interfacesHandler`, `ifaceStatsHandler`, `writeInterfacesDetail`, and gRPC `GetInterfaces`. Non-zero units (e.g. `reth0.50`, VLAN units) unchanged; Prometheus collector benefits via the same `allInterfaceNames` (extra dedupe by ifindex remains harmless).
