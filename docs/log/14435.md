# 14435 — `unit <n> point-to-point …` / `tunnel …`-first packed line drops the whole `family` subtree (DR17-H6)

- **Timestamp**: 2026-10-17
- **Action**: Reader fix in `compileInterfaces` (`pkg/config/compiler_interfaces.go`):
  the unit loop now unpacks the unit node's own Keys tail once via
  `packedBody(unitInst.node, schemaForPath("interfaces", "x", "unit"))`
  into `unitNode`, and every unit read (description, point-to-point,
  tunnel, vlan-id, inner-vlan-id, and the `FindChildren("family")` loop)
  uses `unitNode`. `unit 0 point-to-point family inet { ... }` is one
  node whose Children are the family's contents, not a `family` child,
  so the old reads found nothing and the unit compiled with no
  addresses and no `FilterInputV4/V6`/`FilterOutputV4/V6` while still
  getting a zoned snapshot row (fail-open); the `tunnel ...`-first form
  dropped tunnel + family the same way. `packedBody` returns the
  original node when there is no tail, so the braced twin and the bare
  `unit 0 point-to-point;` leaf are unchanged. Companion gate fix in
  `pkg/config/compiler_interfaces_unsupported.go`: the #12090
  unsupported-filter gate rejected the (now consumed) braced `filter`
  child under a packed unit node — `isInterfaceDirectFilterConsumerPath12090`
  now accepts that exact shape (filter child under a `unit` ancestor
  whose Keys tail carries `family inet|inet6`, braced-filter shape
  checked), and `isInterfacePackedFilterConsumer12090` accepts the
  `p == 0` unit-tail case via new helper
  `unitPackedTailHasFamilyFilter14435`. Without this the packed form
  was strict-rejected by #12090 instead of silently dropped; unit-level
  `filter` without a family tail (e.g. `unit 0 filter input f;`) still
  rejects.
- **Regression**: `pkg/config/compiler_interfaces_packed_unit_dr17h6_test.go`
  (`TestPackedUnitPointToPointFirstFamily14435`,
  `TestPackedUnitTunnelFirstFamily14435`,
  `TestPackedUnitFamilyControls14435`): packed point-to-point-first and
  tunnel-first forms (with real `firewall family inet/inet6 filter`
  definitions so the undefined-filter gate passes) compile addresses +
  input/output filters + `PointToPoint`/`Tunnel` identically to braced
  twins; controls cover the braced twin, bare `unit 0 point-to-point;`
  (no family invented), family-first packed form, and packed inet6.
  RED on `origin/master` (all three fail — strict `#12090` rejection of
  the packed filter), GREEN after the fix. Related suites green:
  `TestPackedUnit|TestFilterKeyword|TestPackedCompoundFamilyFilter|TestInterfaceMplsAny|PackedUnitFamily|12090`.
  Broader `TestCompile.*Interface|TestPacked|TestFilter` run shows one
  failure (`TestPackedTailCredentialChildControlsKeep10707_14412`,
  IS-IS #14399 sibling) confirmed identical on stashed base —
  pre-existing, not this change.
