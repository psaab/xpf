# Issue #15708: syslog file/user packed expansion, coalescing, and empty-selector render

- **Timestamp**: 2026-10-19
- **Problem**: `system syslog file <name>` and `system syslog user <user>` lacked the #6684 `packedBodyChildren` expansion and #9854 same-name coalescing that `host` already had. Compact spellings (`file messages any any;`, `file authlog authorization info;`, `user * any emergency;`) compiled with empty selectors, and repeated blocks overwrote earlier selectors at render because `syslogDropinContents` keyed by drop-in filename. Empty selector lists rendered `*.*`, logging everything to disk/user terminals. Packed tails were also not validated (`packedTail` unset), so a bogus severity in compact form committed clean.
- **Fix (compiler)**: In `pkg/config/compiler_system.go`, file and user loops now pass `packedBodyChildren(fileInst.node, schemaForPath("system","syslog","file"))` / `packedBodyChildren(userInst.node, schemaForPath("system","syslog","user"))` into `hoistAndSplitRun8939`, matching `host`. Files coalesce by `Name` and users by `User` via new `syslogFileCoalesce15708`/`syslogUserCoalesce15708` records: exact `(Facility,Severity)` pairs deduplicate in first-seen order, selectors union, and `ArchiveConfigured`/`ArchiveKnobs` merge (knobs re-sorted/deduped). First-seen destination order preserved.
- **Fix (schema)**: `host`, `file`, and `user` nodes in `pkg/config/schema_system.go` set `packedTail: true`, so `SchemaValidate` (`schema_walk.go`) validates packed `<facility> <severity>` tails at commit time (bogus severity rejected in compact spelling as in braced).
- **Fix (daemon)**: `renderSyslogSelectorList` in `pkg/daemon/daemon_system.go` returns `"", false` for `len(sels)==0` instead of `"*.*", true`, so a modifier-only stanza (e.g. `file messages { archive { size 10m; } }`) is omitted rather than fabricating an unfiltered `*.*` sink. This supersedes the #7187 empty-wildcard rule; `TestEmptySelectorListStillRendersWildcard7187` updated accordingly, `pkg/config/types_system.go` comment and `pkg/logging/README.md` empty-selector note corrected.
