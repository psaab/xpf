# Issue #13933: publish FIB bumps to userspace_ctrl

## Change

`Manager.BumpFIBGeneration` now applies the helper's returned status to the
shim maps after an accepted route-only bump, overriding the response's stale
FIB generation with the confirmed generation. The shim copies
`userspace_ctrl.fib_generation` into packet metadata; leaving that field stale
caused the helper to reject redirected transit as `FibGenerationMismatch`.

A regression checks that a successful bump publishes its confirmed generation
to `userspace_ctrl`, and that a helper refusal does not publish speculative
state.

## Validation

- The new route-only test failed before the fix: no `userspace_ctrl` write
  occurred (`successful route-only bump wrote nothing to userspace_ctrl`). The
  focused pair passes after the fix:
  `go test ./pkg/dataplane/userspace -run 'TestBumpFIBGeneration(PublishesRouteOnlyGenerationToUserspaceCtrl|HelperRefusalDoesNotPublishStaleCtrlGeneration)13933' -count=1`.
- `go build ./pkg/dataplane/...` passed.
- `go test ./pkg/dataplane/... -count=1` failed in unrelated existing tests,
  including contract snapshot/protocol goldens, zone parity, and Unix-socket
  setup (`bind: invalid argument` for temporary socket paths under the long
  `GOTMPDIR`). Rerunning with a short `TMPDIR` did not change Go's test temp
  base; the same unrelated failures persisted. The affected focused cells
  pass.
