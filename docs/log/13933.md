# Issue #13933: publish FIB bumps to userspace_ctrl

## Change

`Manager.BumpFIBGeneration` now applies the helper's returned, confirmed
status to the shim maps after an accepted route-only bump. The Rust helper
updates `last_fib_generation` before refreshing the status response, but the
shim's userspace_ctrl row is not written on the route-only path. The shim
copies `userspace_ctrl.fib_generation` into packet metadata; leaving that
field unchanged caused helper metadata validation to reject redirected
transit as `FibGenerationMismatch`.

A regression injects a nonzero shim generation bump, seeds the ctrl map with
a distinct prior generation, and verifies the ctrl row advances to the
accepted generation. Helper refusal leaves the prior generation untouched.

## Validation

- The success regression failed on the base branch because the route-only bump
  never wrote `userspace_ctrl`. The strengthened cell also failed when the
  publication call was removed: ctrl remained at FIB generation 41 after the
  injected bump to 42. Focused success/refusal cells pass with the fix:
  `go test ./pkg/dataplane/userspace -run 'TestBumpFIBGeneration(PublishesRouteOnlyGenerationToUserspaceCtrl|HelperRefusalDoesNotPublishStaleCtrlGeneration)13933' -count=1`.
- `go build ./pkg/dataplane/...` passed.
- `go test ./pkg/dataplane/... -count=1` failed in unrelated existing tests,
  including contract snapshot/protocol goldens, zone parity, and Unix-socket
  setup (`bind: invalid argument` for temporary socket paths under the long
  `GOTMPDIR`). Rerunning with a short `TMPDIR` did not change Go's test temp
  base; the same unrelated failures persisted. The affected focused cells
  pass.
