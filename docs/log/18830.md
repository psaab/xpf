# #18830 — Keep ICMP identifiers unchanged under producible DNAT

- **Action**: Rebuilt `icmp_port_handling_unchanged_with_dnat_ports` around an address-only ICMP DNAT decision (`rewrite_dst_port: None`) while preserving the forward query identifier `0x1234` and asserting that the reverse wire key still carries that identifier. #17088 unified NAT key generation in `nat_applied_key`; its ICMP arm applies `rewrite_src_port.or(rewrite_dst_port)` to the identifier. A hand-built ICMP decision with `rewrite_dst_port: Some(8080)` therefore changes the identifier and is not a production-reachable DNAT shape: dynamic DNAT gates port rewrites on `has_l4_ports`, and static ICMP DNAT selects the whole-address bucket with no mapped port. The address-only fixture keeps the intended proof—DNAT changes the destination address without treating an ICMP identifier as an L4 port.
