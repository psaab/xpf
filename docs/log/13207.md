# #13207 — preserve HA validation VOID and completion gates

- **Finding:** D10-15 found that fabric-path counter parsers returning status 2
  bypassed `void()` in `validate_phase_fabric_path`, and a duplicate throughput
  `elif` allowed incomplete iperf3 runs to pass on throughput alone. It also
  identified multi-cycle final-phase and CLI-duration default errors.
- **Fix:** Map blind/rewound fabric, WAN, and status-summary counter evidence
  to VOID and return normally; use one status-delta adapter for all eight
  status-summary reads. Remove the unconditional throughput branch, so an
  incomplete run passes only when `iperf_effectively_completed_local` validates
  its observed duration. Keep the final failover phase non-final because
  failback follows it, and compute default iperf duration after CLI parsing.
- **Regression:** Extend `test/incus/ha-assurance-selftest.sh` with truncated
  iperf throughput, blind status-summary counters, and `--cycles 3` duration
  cases. Add fabric interfaces to its shared fixture to exercise the actual
  fabric-path consumer.
- **RED:** On pristine `origin/master` (`dd607606a`), the added truncated-run
  assertion failed: expected `FAILED=1`, got `FAILED=0` for `completed=false`,
  `observed_end_sec=2`, and `avg_gbps=5.0`.
- **GREEN:** `timeout 120 bash test/incus/ha-assurance-selftest.sh` passed,
  including all existing HA assurance cases and the new regressions.
  `bash -n scripts/userspace-ha-failover-validation.sh
  test/incus/ha-assurance-selftest.sh` passed. CLI parsing probe returned the
  expected 185-second default for `--cycles 3`.
- **Static checks:** ShellCheck reports pre-existing diagnostics in these
  files (SC2154 for values populated by the sourced metrics parser and many
  SC2317/SC2329 source-only test reachability notices); no new behavioral
  checks were waived. The live loss-cluster validation was not run.
- **Scope:** Changes are limited to the HA validation script, its existing
  selftest, and this issue log. No live dataplane behavior changes; validation
  verdicts now reject incomplete evidence rather than certifying it.
