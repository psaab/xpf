# #15019 — config: AAA `secret` leaves render in cleartext and `system accounting` commits silently (A13-02)

- **Timestamp**: 2026-10-18
  - **Action**: RED first. New cells in `pkg/config/aaa_secret_15019_test.go`
    fail on `origin/master` (530d56a0e4):
    - `system radius-server <addr> secret <s>`, `system tacplus-server <addr>
      secret <s>`, and `system accounting destination radius server <addr>
      secret <s>` all render the planted secret verbatim through
      `RedactedClone` (Format/FormatSet/FormatJSON/FormatXML/Inheritance and
      `FormatCompareRedacted`), in flat-set and hierarchical spellings.
    - `system accounting ...` (with and without a `secret`) is accepted by
      strict `CompileConfig`/`CompileConfigForNode` with no error and no
      lenient warning; the packed `system accounting order radius;` spelling
      is likewise accepted.
  - **Action**: Fix, scoped to the cited mechanism.
    - `secretIndices` (`pkg/config/ast_redact.go`): the generic `secret`
      case now also fires under a `radius-server`, `tacplus-server`, or
      `accounting` ancestor (`isAAASecretPath`, `pkg/config/secret.go`),
      alongside the existing api-auth named-key gate. Ancestry (not exact
      position) is the gate, so flat-set and hierarchical spellings mask
      identically. This automatically covers `RedactedClone`,
      `FormatCompareRedacted`, embedded change-configuration commands, and
      the symmetric `checkRedactionPlaceholder` ingest guard (re-ingesting a
      redacted AAA export is now rejected instead of committing
      `##SECRET-DATA##` as the literal shared secret).
    - `isSecretLeaf` (`pkg/config/secret.go`): same AAA gate, so
      schema-walk diagnostics redact the value instead of echoing it.
    - `systemAAAWarningsOrError10831` (`pkg/config/compiler_system.go`):
      `accounting` joins `unimplementedSystemAAALeaves10831` — strict
      compiles refuse it with the existing local-only message, tolerant
      Load/SyncApply warns. The gate also judges a statement packed onto
      the `system` node's own Keys (`system accounting order radius;`),
      which the direct-children walk cannot see.
  - **Action**: Preserved neighbouring behaviour (controls in the new cells
    and existing suites):
    - A `secret` leaf outside the AAA/api-auth contexts (e.g. under
      `system login user`) stays visible — the redaction stays scoped, not
      blanket.
    - `system host-name` and other local system config still compile;
      the #10831 radius-server/tacplus-server/authentication-order cells
      (strict refusal, lenient warning, applied-group refusal) stay green.
    - The live tree is never mutated by `RedactedClone`.
  - **Action**: Docs: `docs/feature-gaps.md` gains a `system accounting`
    row recording the strict refusal (#15019, extending #10831).
