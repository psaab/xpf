- **Timestamp**: 2026-09-21
  - **Action**: drove the issue from the source-grounded contract plan through implementation. The five surfaces were REST (`R`), direct gRPC (`G`), local interactive CLI (`L`), remote show CLI (`S`), and remote clear CLI (`C`). The plan fixed the canonical grammar before code: names are case-insensitive, numeric values are `0..255`, name whitespace is trimmed, signed/space-padded numerics are invalid, and absent/empty protocol is a wildcard.
  - **Evidence**: REST previously returned HTTP 200 with an empty list for malformed protocol filters; gRPC rejected only some invalid forms; REST and local matching could not resolve valid Lenient names such as `sctp`; and protocol 0 was indistinguishable from an absent local peer-clear filter.
