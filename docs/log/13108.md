# #13108 — reject packed zone runs that hoist interface policy

## Why

The #9792 resolving-run reader at `compileZones` split a packed zone leaf run
at the `interfaces` container keyword. For example,
`description d1 interfaces ge-0/0/0.0 host-inbound-traffic;` was split into zone
siblings, so the interface-level host-inbound token was compiled as a
zone-wide `HostInboundTraffic` entry. At the same time, the strict packed-tail
and non-empty interface validators inspected the raw children and did not see
the embedded `interfaces` stanza. This allowed ambiguous packed input through
commit with zero warning and could widen host-inbound admission across the
zone.

## What

- `packedOrNestedLeafRun9792` now declines to split a packed continuation when
  it encounters a body-owning container keyword; only leaf continuations are
  eligible for flat-run expansion.
- The zone validators recognize a packed `interfaces` container embedded in a
  sibling leaf run and report a clear rejection (or warning on tolerant load)
  directing the operator to explicit blocks. The validators run on both strict
  and lenient paths through their existing gates.
- Added production-entry tests for strict rejection, tolerant warning/no
  zone-level host-inbound hoist, and positive controls for explicit per-interface
  blocks and ordinary packed leaf runs.

## Validation

- **RED on pristine origin/master `d8d98b525`:**
  `go test ./pkg/config/ -run TestZoneResolvingRun13108 -count=1 -v` failed because
  strict compilation accepted the packed resolving run and lenient compilation
  hoisted an empty `HostInboundTraffic` object to zone scope. Positive control
  passed.
- **GREEN after fix:**
  `go test ./pkg/config/ -run TestZoneResolvingRun13108 -count=1 -v` passed all
  three regression tests.
- `go vet ./pkg/config/` passed.
- `go build ./...` passed.
- Full `go test ./pkg/config/ -count=1` was terminated by Go's default 10-minute
  timeout. Re-running the complete suite with
  `go test -timeout=20m ./pkg/config/ -count=1` passed (`pkg/config` in 1022s).
- The suite measured the #7484 census effect: zone `tcp-rst` moved from blind
  to compared, tightening the floor `788 -> 789`, flag blind ceiling `195 -> 194`,
  and the recorded site list.

## Risk

Only resolving-run expansion that encounters a body-owning container is
withheld. Existing explicit block syntax and leaf-only resolving runs retain
their prior behavior. An ambiguous packed interface run is now rejected at
commit and warned on tolerant load; it remains uncompiled at zone scope, rather
than silently broadening host-inbound policy.
