# Issue #13079 — session lookup auxiliary snapshots

## Why

The D5-07 source finding identified repeated `SessionTable` lookups of an already resolved session during flow-session resolution and descriptor installation. The hit path fetched the same session ID, source-NAT static state, leak incarnation, handshake state, and timeout through separate keyed lookups. Besides repeated hashing/probing, this multiplied work on packet hot paths.

## What

Added compact auxiliary session data to `SessionLookup`, populated from the resolved record and the separate leak-incarnation map, and an install snapshot API that reads ID, source-NAT state, timeout, and handshake state in one primary-table lookup. Resolver and descriptor-install paths now reuse those snapshots rather than re-probing the session table for each field. The auxiliary hit snapshot deliberately excludes the policy-counter `Arc`; leak incarnations remain separately stored. Added regression coverage for lookup auxiliary values, leak incarnation, and the single-probe install snapshot.

- **Base:** `8e26b24d8` (`origin/master`), branch `fix/13079-campaign-pub`.
- **RED-before:** on a pristine-base worktree with the issue regression copied in, the target test failed to compile because `SessionLookupAux`, the lookup `aux` field, and `installed_session_info` did not exist on base.
- **GREEN-after, target:** `cargo test --bin xpf-userspace-dp single_probe_install_and_lookup_carry_aux_fields_13079` passed (1 test) with final changes.
- **Session module:** `cargo test --bin xpf-userspace-dp session::tests::` passed (241 tests) with final changes.
- **Full bin suite:** `cargo test --bin xpf-userspace-dp` reported 7,886 passed, 8 ignored, 1 failed. The single failure was `protocol::tests::wire_invariant_default_specimens`, whose generated fixture differs only by the unrelated `ipsec_inner_permit_forward_armed_total: 0` metric in three specimens.
- **Formatting:** `cargo fmt --all -- --check` reports pre-existing unrelated workspace formatting differences.

## Risk

The per-packet auxiliary value is copied and excludes reference-counted policy-counter state, preserving the #5445 counter-ownership behavior. No packet-policy, leak-incarnation storage, or wire-format behavior is intentionally changed. The full-suite fixture drift and workspace formatting failures are unrelated to this issue and should be resolved separately.
