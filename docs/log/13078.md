# Issue #13078 — D5-05 duplicate expiry probes

## Why

D5-05 identified local session and forward-NAT miss paths that repeated index lookups to distinguish an expired record from an absent record. Repeating probes adds work on packet-path misses; treating an expired local record as absent would also risk resurrecting a stale shared replica.

## What

Added explicit `Live` / `IdleCrossed` / `Absent` results for local exact, forward-wire, and reverse-NAT probes. The reverse-NAT matcher tracks stale eligible candidates while walking its index once, preferring any later live candidate. Shared-scope lookup now uses this classification instead of doing a second timeless lookup. Expired local records remain fail-closed and do not fall through to shared state. Added a regression test for live, idle-crossed, and absent classification.

## Validation

`CARGO_TARGET_DIR=/var/worktrees/.cache/cargo-13078 GOTMPDIR=/var/tmp cargo test --manifest-path userspace-dp/Cargo.toml expiry_probe_classifies_live_idle_crossed_and_absent_13078` — passed (1 test; 14 suites filtered). `cargo test --no-run` also compiled the test targets successfully before the final small test addition.

## Risk

The change preserves matching and strict-expiry semantics; stale candidates continue to block shared fallback. The regression exercises outcome classification, not an instrumented count of map accesses.
