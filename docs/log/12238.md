# Issue #12238 — weekday scheduler flag supersession

## Why

Repeated hierarchical weekday blocks merged `AllDay` and `Exclude` with sticky OR. A later Monday 09:00–17:00 window therefore retained an earlier Monday all-day or exclude flag; the scheduler runtime checks those flags before time boundaries, widening or closing the weekday window incorrectly.

## What

Weekday merges now let explicitly stated later flags replace both flag values. A later complete time window (both boundaries) clears prior all-day/exclude flags. Partial time fragments continue to add boundaries without disturbing flags, preserving complementary-fragment behavior. Added regression coverage for the acceptance cell, both flag contradictions, reverse-order flag supersession, partial fragments, and a distinct-weekday control.
