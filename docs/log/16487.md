# #16487 — seconds-only legacy archive names invisible to the snapshot recognizer

- **Timestamp**: 2026-10-24
  - **Action**: `isXPFConfigArchiveSnapshot` accepted only the sequenced
    `config-<ts>.<seq>.conf` shape and the pre-sequence nanosecond
    `config-<ts>.conf` shape. Archives written by 2026-02-14..06-28 builds
    (`config-YYYYMMDD-HHMMSS.conf`, seconds only) matched neither, so the
    #10825 Load-time api-auth purge silently skipped them — cleartext
    REST credentials survived — and `rotateArchives` never counted or
    pruned them, so retention exceeded max-archives forever. Recognizer
    now accepts an exact `20060102-150405` stamp when no dot is present.
    The no-dot split plus explicit length guards also close a latent
    false positive: `time.Parse` accepts a variable-length trailing
    fraction, so a foreign `config-<stamp>.1.conf`-style name could
    previously be mis-recognized; the nanosecond branch now requires
    exactly nine fractional digits and the sequenced branch requires a
    nine-digit-fraction stamp before its 20-digit seq.
  - **File(s)**: `pkg/configstore/store_persist.go`

- **Timestamp**: 2026-10-24
  - **Action**: The Load sweep now tightens any recognized snapshot it
    preserves (already-hashed or malformed) from a pre-#4056 0644 to
    0600, tighten-only (`Perm()&^0o600 != 0`), before api-auth
    classification so malformed snapshots are tightened too; chmod
    failure warns and retries on a later Load. Symlinks and
    non-regular entries are still preserved untouched.
  - **File(s)**: `pkg/configstore/store_persist.go`

- **Timestamp**: 2026-10-24
  - **Action**: Added `archive_seconds_only_16487_test.go`
    (recognizer accept/reject table, mixed-shape rotation pruning
    seconds-only peers first, newest-seconds-only retention) and
    extended the #10825 owned-archive fixture with a cleartext
    seconds-only snapshot at 0644 (must be purged) and an
    already-hashed seconds-only snapshot at 0644 (must survive with
    bytes intact, tightened to 0600). RED proof: neutralizing the
    seconds-only recognizer branch fails all four cells; neutralizing
    the chmod fails the fixture with `mode = 0644, want 0600`.
  - **File(s)**: `pkg/configstore/archive_seconds_only_16487_test.go`,
