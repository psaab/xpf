# #16540: fairness-eval PASSes when every flow delivers zero bytes

- **Timestamp**: 2026-10-24
- **Problem**: `starved_flow_count` short-circuited on
  `total_bytes == 0` (`return 0`), `compute_observed_cov` returned
  0 on a zero mean, and Gate 3 (aggregate throughput) only runs
  under `--expect-saturation`, which no harness passes. A run that
  blackholed the class for the whole steady-state window therefore
  scored 0 starved / CoV 0 and returned PASS (exit 0) — a false
  green on the CoS fairness merge gate. Automation keyed on
  `verdict` would accept it; only a human noticing `avg_mbps ~ 0`
  would catch it.
- **Fix**: In `starved_flow_count`, treat `total_bytes == 0` (with a
  non-empty flow set) as every flow starved — 0 is the canonical
  starved case under the contract's `< 1% of mean` definition
  (`docs/fairness-regimes.md` Gate 1), it just cannot be expressed
  arithmetically when the mean is 0. Seeded streams with an empty
  bucket vec (absent from every interval) likewise count. An empty
  flow set still returns 0. The verdict layer now names this shape
  explicitly ("no throughput in steady-state window: all N flow(s)
  delivered zero bytes") when every seeded stream is starved,
  instead of the generic below-1% wording. NOT changed: the harness
  does not gain `--expect-saturation` (that would re-scope every
  shaped-class sweep to the structural-cap gate, a wider operator
  decision than this false-green fix), and Gate 2/Gate 3 semantics
  are untouched.
- **File(s)**: `userspace-dp/src/fairness.rs`,
  `userspace-dp/src/fairness_tests.rs`,
  `userspace-dp/src/fairness_eval/verdict.rs`,
  `userspace-dp/tests/fairness_eval_blackbox.rs`,
  `docs/fairness-regimes.md`, `docs/log/16540.md`
- **Validation**: New black-box case D
  (`all_zero_throughput_fails_gate1_case_d16540`) was RED pre-fix
  (exit 0 / PASS on an all-zero 6-stream 60s window) and passes
  post-fix (exit 1, `starved_flow_count == 6`, Gate 1
  no-throughput reason). New unit cells pin the all-zero and
  all-empty-buckets shapes. Existing black-box cases P/Q
  (balanced PASS, single-starved Gate 1 FAIL, Gate 3 cells) are
  unchanged and still pass.
