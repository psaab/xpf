# #11437 — construct PTB replies from same-RI interface primaries

- **Timestamp**: 2026-10-02

  ICMPv4/v6 PTB source. When absent, select a family-matched connected primary

  addresses. Count replies that cannot be built and expose the counter through
  userspace status and Prometheus.
