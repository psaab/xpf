## Keep dispatch tests on the production path

The six enqueue-failure tests construct `PendingForwardRequest` directly, bypassing the XDP shim that stamps `flow_src_addr` and `flow_dst_addr` from the packet. Their shared request fixture left both fields zeroed, which the final-TX #11074 source-martian backstop correctly interpreted as `0.0.0.0` and rejected before the tests reached their intended dispatch paths. That caused unrelated failures in mirror accounting, enqueue-failure handling, oversized-frame recycling, direct-TX frame accounting, and PAT translation.

Each affected fixture now copies the IPv4 endpoints from the wire frame into metadata, following the existing `ptb.rs` and `nat64_fragment_11353.rs` fixture pattern. No production guard, assertion, or expected outcome changed.
