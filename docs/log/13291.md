# Issue #13291: export HA split-brain counters to Prometheus

## Why

The userspace status response already carries the split-brain refusal count and replica-delete drop/repair counters, but the Go metrics bridge discarded these fields. Operators therefore could not observe peer deletes refused for locally owned sessions or replica-delete queue loss/repair through Prometheus.

## What

- Add Prometheus descriptors, `Describe` registration, and zero-inclusive emission for `peer_delete_refused_local_owned`, `session_delete_replica_dropped`, and `session_delete_replica_drop_repaired`.
- Add a regression test covering metric values and descriptor registration. HA transition queue drop/stale counters are already exported by the existing #13280 emitter and are unchanged.

## Validation

- RED on pristine master: `go test ./pkg/api -run '^TestUserspaceHASplitBrainCountersEmit13291$' -count=1` failed because 14 metrics were emitted instead of the expected 17.
- GREEN: `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/api -run 'TestUserspaceHASplitBrainCountersEmit13291|TestUserspaceOperationalAndHACountersEmit13280' -count=3` passed.
- GREEN: `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/api` passed.
- `gofmt -w` on the touched Go files and `git diff --check` passed.

## Risk

Additive Prometheus counters; existing HA processing and wire protocol behavior are unchanged.
