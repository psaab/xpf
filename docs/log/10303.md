# #10303 — deterministic stable RETH link-local in host-inbound daddr sets

- **Date**: 2026-09-18
- **Branch**: `fix/10303-rethll`
- **Baseline**: `8966710325646decfa4ec65dc3ad8ea794f23cbb`
- **Issue**: after RETH failover or cold boot, the daemon-derived
  `fe80::bf72:<cluster>:<rg>` RA router address was absent from host-inbound
  destination sets until a live address snapshot happened to contain it. The
  host-inbound chain therefore fell through to `policy accept`.

## RED — pre-fix hermetic cells

The regression tests were added before the implementation. At baseline,
`go test ./pkg/dataplane/userspace -run 'TestStableRethLL' -count=1 -v`
failed in the two acceptance paths:

- **Failover / BACKUP render**:

  ```text
  BACKUP render: zone lan V6Addrs = [2001:db8:61::1], want containing stable LL fe80::bf72:7:1
  BACKUP render: zone wan V6Addrs = [2001:db8:50::8], want containing stable LL fe80::bf72:7:1
  zone wan: BACKUP addrs = [172.16.50.8 2001:db8:50::8], MASTER addrs = [172.16.50.8 2001:db8:50::8 fe80::bf72:7:1]
  zone lan: BACKUP addrs = [10.0.61.1 2001:db8:61::1], MASTER addrs = [10.0.61.1 2001:db8:61::1 fe80::bf72:7:1]
  --- FAIL: TestStableRethLLInViewsOnBackupRender10303
  --- FAIL: TestStableRethLLBackupEqualsMasterRender10303
  ```

  This proves the pre-fix BACKUP render depended on the live snapshot while
  the simulated MASTER render contained the live LL.

- **Cold boot / fence render**:

  ```text
  fence: zone lan V6Addrs = [2001:db8:61::1], want containing stable LL fe80::bf72:7:1
  fence: zone wan V6Addrs = [2001:db8:50::8], want containing stable LL fe80::bf72:7:1
  zone-less fence: UnzonedV6 = [2001:db8:61::1], want containing stable LL fe80::bf72:7:1
  unzoned v6 = [2001:db8:62::1], want containing unzoned RG's stable LL fe80::bf72:7:2
  --- FAIL: TestStableRethLLInFenceScope10303
  --- FAIL: TestStableRethLLInFenceScopeZoneless10303
  --- FAIL: TestStableRethLLInUnzonedAddrs10303
  ```

  This proves the pre-fix cold-boot fence and unzoned residual scope also
  depended on the live address snapshot.

## Change

- `stableRethLinkLocalTargets` derives the same deterministic stable LL bytes
  as `cluster.StableRethLinkLocal`, using configured RETH ownership and IPv6
  units rather than netlink/live snapshots.
- `BuildZoneHostInboundViews` unions the stable LL into the effective zone
  daddr group alongside configured VRRP VIPs, for MASTER and BACKUP renders.
- `BuildUnzonedHostInboundAddrs` and `forEachFirewallLocalAddr` include the
  stable LL for unzoned and zone-less cold-boot fence scope.
- The target walk mirrors daemon LL placement: base/native unit, IPv6-bearing
  non-zero units, and explicit unit-0 link-local suppression.

## Live versus hermetic evidence

No live HA lab was available in this worktree, so no physical failover, live
host-service probe, or live `nft list ruleset` dump was run. The failover and
cold-boot acceptance cells are hermetic: they construct the MASTER/BACKUP,
empty-live-snapshot, zone-less, and cold-boot-fence states and inspect the
actual production view/payload builders. The rendered payload checks are the
hermetic equivalent of the requested LL host-service probes and nft daddr
checks; live-cluster evidence remains intentionally unclaimed.
