# 10312 — native routing-instance member resolution

- **Timestamp**: 2026-09-18
- **Problem**: an interface member of a routing instance could enter the forwarding path without a PBR routing-instance term. The miss path then resolved in MAIN (`inet.0`/`inet6.0`), allowing a tenant-connected destination to select the WAN default. Reverse session construction also used an unstamped MAIN lookup instead of the forward ingress member's instance.
- **Change**: native RI resolution now has explicit `Default`, validated per-family `Table`, and terminal `Unresolvable` outcomes. Forward PBR fallback uses the native table when no term matches; an unresolvable nonzero domain drops instead of falling through to MAIN. Reverse session, HA-synthesized reverse, and the transit poll session-miss constructor derive the reply target and install stamp from the forward ingress domain. The existing explicit TUN `_in_table` paths remain zero-stamped, and directional PBR table stamps are not inherited by reverse resolution.
- **Files**: `userspace-dp/src/afxdp/forwarding/mod.rs`, `userspace-dp/src/afxdp/forwarding/pbr.rs`, `userspace-dp/src/afxdp/forwarding/tests_ri_native_10312.rs`, `userspace-dp/src/afxdp/shared_ops.rs`, `userspace-dp/src/afxdp/poll_descriptor/mod.rs`, `userspace-dp/src/afxdp/session_glue/pbr_install_table_9752_tests.rs`.
- **Follow-up files**: `userspace-dp/src/afxdp/session_glue/mod.rs`, `userspace-dp/src/afxdp/session_glue/commands/upsert_synced.rs`, `userspace-dp/src/afxdp/session_glue/leak_revoke_9951_tests.rs`, and `userspace-dp/src/afxdp/forwarding/README.md`.
