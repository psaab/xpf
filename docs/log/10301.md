## Attribution contract

`journal.Entry.Principal` is additive to schema v2. `Journal.Log` normalizes every new value: missing/blank values become the explicit `unknown` sentinel, controls become `?`, and over-long values are UTF-8-safe truncated with a marker. `Tail` applies the same normalization to old v1/v2 rows that have no field, without rewriting the append-only file.

Transport-bound commit authorities carry a formatted source/user/class label. The bearer-like config session is represented only by a short SHA-256 prefix, never persisted verbatim. REST and gRPC commit and commit-confirmed handlers pass the already-authorized principal into the authority; direct/legacy callers remain explicitly `unknown`. Destructive REST/gRPC system actions use the same path. Autonomous store actions use fixed `system:<subsystem>` labels.

The unary gRPC authorization interceptor stores the admitted principal in the
handler context. Journal attribution consumes that exact value; a missing
admission context is `unknown`, never a re-resolution against a later active
configuration snapshot. The regression changes the login class between
authorization and handler execution and still records the admitted class.
