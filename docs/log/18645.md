## Risk

- After 2026-11-30 the loss v4/v6 split-holder instruction (env lines and
  matrix row) is expired. A PR that touches either file reds until it is
  re-checked, and the keeper's sweep reports it to the parent for filing.
  Untouched PRs only see a NOTE.
- PR mode needs a git diff. If the merge-base cannot be computed (a
  shallow CI checkout, or a missing base), the census fails CLOSED and
  treats every file as touched. The CI commit therefore checks out with
  `fetch-depth: 0` and passes the PR's base SHA.
- Allocator: with today's lab the first allocation is about `0.0.26911`.
  Each allocation probes six nodes read-only (about 2 s, at most 15 s per
  node). A hand-picked build deployed after the counter exists is folded
  in by the next probe; `--claim` refuses one at or below the counter.
- Stray debs on disk only warn; the hand-built `0.0.99999` in
  `fzdiag2-src` is reported on every allocation until someone removes it.
- The spend cap lowers the effective lane cap from `2*nproc - 6`. Item 9
  no longer holds three standing gate lanes; a gate slot is dispatched
  when the counter says it is due. Only the user raises the cap.
