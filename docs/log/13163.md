# #13163 — expand predefined app-sets in dataplane policies

- **Source**: deep-review finding D4-04, validated by three-way adversarial research.
- **Files**: `pkg/dataplane/compiler.go`,
  `pkg/dataplane/compiler_predefined_appset_13163_test.go`.

## Why

`compilePolicies` recognized only user-defined application-sets in both
zone-pair and global policies. A predefined set such as `junos-cifs` was
therefore lowered to application ID 0 (wildcard) as one rule, even though
userspace expands that set to two policy rule slots. The wildcard broadened
policy matching, while the missing slot shifted subsequent policy-name and
schedule attribution.

## What

Use `config.ResolveApplicationSet` in both compiler loops so predefined sets
are expanded with the same user-set-first lookup semantics as configuration
and userspace. The regression exercises zone-pair and global policies,
checks constituent application IDs and rule counts, and verifies that the
following policy retains the expected `PolicyNames` slot.

## Validation

- RED on pristine `origin/master` (`58b5d5b15`):
  `go test ./pkg/dataplane -run '^TestCompilePoliciesPredefinedAppSetParity13163$' -count=1`
  failed because only three policy rules were emitted instead of five; the
  predefined `junos-cifs` rules had collapsed to wildcard entries.
- GREEN focused regression: same command, passed after the fix; `go vet ./pkg/dataplane/...` and `gofmt -d pkg/dataplane/compiler_predefined_appset_13163_test.go` were clean.
- Full `go test ./pkg/dataplane/... -count=1`: `pkg/dataplane`,
  `pkg/dataplane/runtime`, and `pkg/dataplane/userspace/format` passed;
  `pkg/dataplane/userspace` failed on unrelated secure-tunnel /
  zone-quarantine expectations, protocol snapshot golden drift, and
  Unix-socket test paths exceeding the platform limit. No baseline attribution
  was made.

## Risk

Only application-set recognition in dataplane policy compilation changes.
Explicit `any`, leaf applications, and user-defined application-set lookup
remain unchanged; predefined sets now compile to their actual leaf IDs.
