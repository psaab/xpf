# #17764 — Repeated heartbeat restarts preserve cold-boot grace

## Timestamp

2026-10-28T19:48:16-07:00

## Action

The grace deadline propagated by a replacement receiver is now the later of
its own `startedAt + seenThenLostGrace()` deadline and its inherited hold.
`StopHeartbeat` and `RestartHeartbeat` both use the same `heartbeatReceiver.graceEnd`
helper, so another comms or ordinary heartbeat restart cannot shorten a
cold-boot floor inherited earlier in the same boot epoch. Never-seen receivers
still clear the comms-restart seed/hold.

## File(s)

- `pkg/cluster/heartbeat.go` — added `heartbeatReceiver.graceEnd`.
- `pkg/cluster/heartbeat_manager.go` — preserve the maximum grace deadline at
  both comms-restart stashing and `RestartHeartbeat` inheritance.
- `pkg/cluster/heartbeat_comms_restart_16745_test.go` — add two-restart
  comms and ordinary-restart regressions, with stale-peer, expired-hold,
  never-seen, and resumed-peer controls.
- `pkg/cluster/README.md` — document the inherited-floor rule across repeated
  restarts.

unseeded.
