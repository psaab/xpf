# #14371 — Hostname peer-address voids the pre-auth peer reserve

- **Timestamp**: 2026-10-16
  - **Action**: Fixed DR3-H4: `isPeerRemote` compared the connection's remote
    IP against `peerIPOf(peerAddr)`, which is literal-only
    (`netip.ParseAddrPort`/`ParseAddr`), so a hostname `peer-address` /
    `fabric-peer-address` / `fabric1-peer-address` resolved to the invalid
    Addr and the genuine peer was treated as a non-peer in `beginSetup`
    (limit 6 = 8 − 2 instead of 8). A sustained pre-auth flood therefore
    denied the peer's session-sync reconnect, voiding the #5303 reserve,
    while heartbeat (`ResolveUDPAddr`) and the sync dial (`DialContext`)
    resolved the same hostname and the cluster otherwise worked silently.
  - **File(s)**: `pkg/cluster/sync_admission.go`, `pkg/cluster/sync.go`

- **Timestamp**: 2026-10-16
  - **Action**: Fix (spec option (a), resolve-at-construction; NOT the
    commit-time hard-reject, so hostname configs remain valid):
    `SessionSync.peerIPs` caches the union of resolved IPs for
    `peerAddr`+`peerAddr1`, populated by `refreshPeerIPs()` in both
    `NewSessionSync` and `NewDualSessionSync` (comms restart reconstructs
    the SessionSync, which is the refresh point). Literals keep exact prior
    semantics via `parseAddrIP` and never touch DNS; hostnames are resolved
    once via `lookupPeerHostIPs` (default resolver, 5s bounded context,
    all v4+v6 answers, unmapped). `isPeerRemote` consults the cache;
    a zero-value SessionSync falls back to the literal comparison. No DNS
    per connection or under `preAuthMu`. Unresolvable hostname: no reserve
    entry (prior non-peer behaviour) plus a loud `slog.Warn` naming the
    peer address; never panics. Cap math, `finishSetup`,
    `closeSetupConns`, `notePreAuthRejected`, outbound bypass, and
    `shouldInitiateFabricDial` unchanged. Documented limitation: cached
    answers go stale on peer IP change until comms restart (same posture
    as heartbeat startup resolution); DNS rebinding still cannot pass the
    HMAC handshake and the general cap still bounds total cost.
  - **File(s)**: `pkg/cluster/sync_admission.go`, `pkg/cluster/sync.go`
