# #16202 — per-family descriptor table for metrics init and Describe

- **Timestamp**: 2026-10-24
- **Issue**: `pkg/api` kept three handwritten registration surfaces in
  agreement by inspection: the ~36 `initXDescriptors()` calls in
  `newCollector`, the 630 `ch <- c.` lines in `Describe`, and the 648
  `*prometheus.Desc` struct fields. Every new metric was three edits,
  and a missed Describe line is the #1635 checked-collector scrape
  error.
- **Change**:
  - New `pkg/api/metrics_descriptor_table.go`: a statically allocated
    `collectorDescFamilies` table (37 rows). Each row binds a family's
    `init*Descriptors` to the struct field indexes that init assigns
    (resolved once at package init via `reflect`, panicking on a typo).
    `newCollector` and `Describe` both iterate the table; `Describe`
    allocates nothing per call (pinned by
    `TestDescribeDoesNotAllocate16202`). The ~150 `metrics_*` collector
    files and `Collect` are untouched — the table cannot guarantee
    Describe covers Collect, so that leg stays explicit (below).
  - `Describe`'s hand enumeration and the seven per-family
    `describe*` helpers (admission, authz, silent-skips, learned-route,
    REST-conn, SNMP, dataplane-safety) are deleted; their fields are in
    the global/REST/SNMP/dataplane-safety family rows. The duplicate
    `eventActionQueueDepth` send the old enumeration carried is gone
    (it was described twice). Dataplane-safety keeps its `sync.Once`
    laziness inside its init.
  - New `TestCollectorDescriptorTableAgreement16202`: table rows cover
    every struct Desc field exactly once; each family's init assigns
    exactly its row's fields; `Describe` sends exactly those fields by
    pointer identity, no nils, no duplicates. Red-verified by dropping
    a row entry, duplicating an entry across families, and no-op-ing an
    init. The #1726 pedantic canary continues to gate Collect-side
    agreement, and the described-name set is byte-identical to base
    (648 names, sorted comparison).
  - **Files**: `pkg/api/metrics_descriptor_table.go` (new),
    `pkg/api/metrics_descriptor_table_test.go` (new),
    `pkg/api/metrics_descriptors.go`, `pkg/api/metrics.go`, and the
    seven helper files above (describe helpers removed only).
