# #15157 — BGP originated routes leak to neighbours without an export policy (B08-02)

- **Timestamp**: 2026-10-19
- **Action**: #14586 originates the routes a neighbour's export policy
  selects via router-global `redistribute <proto> route-map
  <policy>-<proto>-xpf-redist`, so they enter the shared BGP RIB of the
  instance. A neighbour whose export chain is absent, or ends without a
  final reject, advertised them (absent attachment permits under
  `no bgp ebgp-requires-policy`, and the #2998 trailing permit admits
  redistributed routes) — contrary to the Junos default export (active
  BGP routes only). Fix in `pkg/frr`: (1) new
  `bgp_default_export_15157.go` — when any #14586 origination exists in
  an instance, every neighbour/AF with an empty effective export
  attaches the generated `xpf-default-export-xpf-chain` map (permit
  `match source-protocol bgp`, deny rest), with a render-side collision
  belt mirroring #7625; (2) the #2998 no-default trailing permit of
  export maps carves to the same BGP-only pair — single maps via
  `renderRouteMapForPolicyExport15157` (per-instance set from
  `collectBGPExportCarved15157`) and composed chains via
  `renderComposedRouteMapExport15157` (export-direction,
  originating-instance only). Import maps keep the plain permit;
  explicit accept/reject defaults are untouched; instances without
  origination render byte-identically (full `pkg/frr` suite green).
- **Validation**: New `pkg/frr/bgp_default_export_15157_test.go`
  (9 cells: no-export v4+v6 attachment + definition, single-tail carve,
  composed fall-off carve, import control, no-origination control,
  explicit-default control, all-export control, collision refusal, VRF
  instance). RED on `origin/master` (6 fail: no attachment, plain
  tails, no collision refusal, no instance map; 3 controls pass),
  GREEN after the fix. Neighbouring suites `14586` included in the run.
  Full `go test ./pkg/frr -count=1` green (3 FRR-binary-dependent cells
  skipped per package convention). Live zebra/bgpd run.sh cells are
  lab-bound and not exercised here — the render-level assertions pin
  exactly the route-map attachments/definitions the leak rode.
- **Risk**: Fail-closed only in the affected direction: a neighbour
  that previously leaked originated routes now advertises only
  BGP-sourced routes until it gets an explicit export — the Junos
  default. A composed chain shared as an import name in one instance
  and an export in an originating instance carries the carved tail for
  both (one FRR object, one tail; chosen fail-closed for export).
