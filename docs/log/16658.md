# 16658 — eventengine: stop deferred worker spinning on stale wakeAt after drain

- **Timestamp**: 2026-10-25
- **Action**: The #15021 deferred worker seeded each iteration's wake from
  the stored `pending.wakeAt`; the cooldown/budget candidate loops could
  only lower it and `drainDeferred` never cleared it. After the first
  deferred edge or budget deferral fully replayed, the stored wake lay in
  the past, the timer delay clamped to zero, and the worker spun on
  zero-length timers — taking `pendingMu` and `e.mu` via `drainDeferred`
  on every pass, burning ~a core — for the rest of the daemon's life.
  The worker now recomputes `wake` from zero on every iteration as the
  minimum over the cooldown anchors of the cooldown holds actually
  parked plus, only when a budget hold is present, the budget expiry
  (`budgetWakeAtFn` override preferred, else the oldest slot's expiry),
  and stores `pending.wakeAt = wake` unconditionally — zero when both
  maps are empty, in which case no timer is armed and the worker blocks
  on `pendingWake`/`stopCh` until the next park nudges it. `deferBudget`
  still stores its per-hold expiry hint for `wakeAtLocked` observers;
  it is now only a hint and can never seed a timer, since the worker
  overwrites it from current parked state each iteration.
- **File(s)**: `pkg/eventengine/engine.go`,
  `pkg/eventengine/engine_deferred_wake_spin_16658_test.go` (new),
  `pkg/eventengine/README.md`, `docs/log/16658.md`
- **Validation**: New `TestDeferredWorkerNoTimerSpinAfterCooldownReplay16658`
  (real-clock: commit, park a cooldown edge, worker replays it at ~30s,
  then zero timers in a 1s idle window and `wakeAt` zero) and
  `TestDeferredWorkerNoTimerSpinAfterBudgetReplay16658` (deterministic:
  budget hold against already-expired slots drains on the first pass,
  then zero timers in 1s idle) — both FAIL on pre-fix code at the stale
  `wakeAt` assertion and PASS after. `go vet ./pkg/eventengine/` clean,
  gofmt clean. Deferred-family suite
  (`-run 'Deferred|15945|16641|16848|Cooldown|Budget'`): 26 PASS,
  including the #15021, #15945, #16641, #16848 replay tests and the
  #10871 budget test. Budget spin test also PASS under `-race`.
  Full `pkg/eventengine` suite: only the 9 pre-existing
  `multivalue_leaf_runtime_6673` failures, byte-identical on pristine
  master (base-attributed, unrelated to this change).
- **Risk**: The wake for a parked budget hold now prefers the
  `budgetWakeAtFn` test override in the worker (previously only
  `deferBudget` consulted it when storing the hint); production has the
  override nil and takes the oldest-slot expiry exactly as before.
  Fake-clock tests keep the existing 20ms timer cap, so their replay
  cadence is unchanged. No queue, budget-cap, cooldown, or commit-path
  semantics change.
