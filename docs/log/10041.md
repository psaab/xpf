# Issue #10041 — deferred tick debt-generation convergence

## Context

Read the complete #10041 issue body and comments before implementation. The body
had no comments and did not withdraw, narrow, mark-shipped, or contradict the
requested repair directions.

The verify-first check found that the coherent repair is already present on
master through the earlier landed fixes:

- #9824 rebases a compiled snapshot above the helper high-water before a
  deferred or synchronous publish.
- #9642 adopts a retained generation when a content-conflict retry may have
  landed but its response was lost; the digest gate makes the retry
  identity-aware.
- #10064 skips retaining a same-generation resampled tick copy while preserving
  the retry-debt latch and its consumers.

This issue lane therefore adds fail-on-revert regression coverage rather than
changing already-converged production behavior.

## Change

Added `deferred_tick_debt_10041_test.go` with a helper-model fixture that tracks
helper-installed generation, content digest, fabric rows, lost responses, and
fail-closed control state independently from Go's retained bookkeeping. The
three issue entry traces are pinned end to end:

- `TestDeferredTickEqualityLandingConverges10041`: r2 reserve → lost
  unallocated worker-arm republish → deferred compiled apply. The compiled
  generation must rebase strictly above the helper and admit on the first
  service tick.
- `TestDeferredTickResampleNoOpWritebackConverges10041`: r3-main resamples
  beta into a lost tick copy, performs the alpha no-op writeback that clears the
  helper digest and partial debt, then exercises the conflict → lost retry.
- `TestDeferredTickTickDriftConverges10041`: r3-short resamples beta then alpha
  across ticks, loses the conflict retry response, and clears the remaining
  partial debt only after the identical retry re-offer succeeds.

Each cell asserts the observable contract for its own trace: helper content is
correct, and all generation/debt gates plus ctrl converge. The two r3 cells
additionally pin manager-adopts-possibly-landed-retry and fail-closed ctrl
while the response is unknown; the equality cell instead pins non-adoption
(rebase-over convergence) with no mid-trace ctrl read.

## RED then GREEN

- **Equality RED (reverted #9824 target):** In an isolated worktree based on
  `81fbf36ab` with the #9824 apply-time rebase hunk reverted,
  `go test ./pkg/dataplane/userspace/ -run
  '^TestDeferredTickEqualityLandingConverges10041$' -count=1 -v` failed at
  `deferred compiled generation = 8, want helper+1 = 10`. The helper had
  installed the unallocated generation 9 while Go retained generation 8.

  worktree before the #9642 retry-debt adoption,
  `go test ./pkg/dataplane/userspace/ -run
  'TestDeferredTickResampleNoOpWritebackConverges10041' -count=1 -v` failed
  with `helper=9 manager=8 retained=8` after the conflict retry landed.
- **Tick-drift RED (pre-#9642):** The same pre-#9642 run of
  `TestDeferredTickTickDriftConverges10041` failed with
  `helper 9 manager 8 retained 8 partial 2`; the helper was ahead while the
  retained generation stayed below it.

- **GREEN:** The three cells passed together with
  `go test ./pkg/dataplane/userspace/ -run
  'TestDeferredTick(EqualityLanding|ResampleNoOpWriteback|TickDrift)Converges10041'
  -count=1 -v` (3/3).
- **Stability:** The same three cells passed with `-count=5` (15/15), and with
  `-race -count=1` (3/3).
