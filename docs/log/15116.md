# #15116 - flowless packets linearly scanned static-NAT and DNAT tables (A77-01)

- **Timestamp**: 2026-10-19
- **Action**: Every flowless packet (non-first fragment, non-TCP/UDP
  protocol, ICMP error) ran `flowless_pre_routing_destination_nat` /
  `flowless_destination_nat_rule_possible` in
  `afxdp/poll_descriptor/frag_assoc.rs`, whose possibility probes scanned
  the whole NAT tables: `StaticNatTable::flowless_l4_translation_possible`,
  `flowless_l4_dnat_translation_possible` and
  `flowless_non_tcp_udp_port_map_possible` iterated every `(ip, port)` key
  in `dnat` (and `snat`), and `DnatTable::flowless_l4_rule_possible` /
  `flowless_non_tcp_udp_port_map_possible` iterated every exact entry and
  every prefix slot. An unauthenticated peer sending proto-253 or IPv4
  non-first fragments to any address therefore drove per-packet cost
  proportional to NAT rule count. Fixed by building per-destination
  secondary indexes in `from_snapshots` (the only constructor of either
  table): `StaticNatTable.dnat_by_dst: FxHashMap<IpAddr, Vec<(Option<u16>,
  usize)>>` and `DnatTable.entries_by_dst: FxHashMap<IpAddr, Vec<(u16,
  u16, usize)>>` plus `prefix_slots_by_family` (prefix slots grouped by
  address family; prefix count is operator-bounded and unrelated to
  host-rule count). Indexes are rebuilt wholesale from the finished maps
  after dedup-replacement inserts, so they cannot drift from the entries
  they index; probes now visit only the packet destination's entries and
  its family's prefix slots, evaluating the identical per-entry
  predicates (scope, source, ICMP, port-range, `off`, mapped-port) in the
  same order-insensitive `any` semantics. No behaviour change outside the
  cited probes; fail-closed `Untranslatable` outcomes are preserved
  exactly for matching destinations.
- **Validation**: New regression
  `nat::tests_flowless_index_15116::flowless_probes_do_not_scale_with_table_size_15116`
  builds 10-entry and 10 000-entry static and DNAT tables, asserts
  hit-on-last-rule / miss-elsewhere correctness for all four probes, and
  asserts the 10k/10 per-call time ratio is under 2x for each probe
  (best-of-3, miss destination so the pre-fix scan walks the whole
  table). RED on base (linear scan), GREEN after the fix. Existing
  `flowless_*` / DNAT / static-NAT suites stay green (see PR).
- **Risk**: Index memory is O(installed entries), built once per config
  snapshot; no per-packet allocation. Tables constructed only via
  `from_snapshots`, so no stale-index path. Residual: prefix-slot scan is
  still linear in configured DNAT prefix count (bounded, unrelated to
  the host-rule amplification in A77-01).
