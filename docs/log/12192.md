# Issue #12192 — skip dead workers during session-upsert fan-out

## Why

Session replication attempted an `UpsertSynced` command for every sibling queue, including queues whose worker supervisor had already marked dead. A full abandoned queue therefore followed the generic bounded-push drop path instead of being skipped and counted as a dead-worker shed.

## What

The worker command queues now retain a generation-scoped association between each queue Arc and the same runtime atomics used by its worker supervisor. Session-upsert fan-out checks that liveness before acquiring the queue, skips dead workers, and increments the shed metric; live siblings still receive the replica, and the enqueue metric counts only live queue attempts. Queue identity, rather than a reusable worker ID, selects the liveness slot. Replica conversion is lazy so an all-dead fan-out does not clone a session entry.
