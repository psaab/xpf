# Issue #18933 — event-stream fallback cell: sync pair precondition rot under the #18038 runner

- **Timestamp:** 2026-11-03T05:36:07Z
- **Action:** Root-caused the deterministic `session sync pair never connected`
  failure (pkg/daemon/daemon_ha_userspace_stream_live_test.go, the
  `connectedSyncPairForDrainTest` gate) to a runner-environment change, not a
  production defect, and restored the fixture's transport precondition.
  - **Mechanism (firsthand):** #18038 (93bcd70d37, 2026-11-02) created
    `scripts/testguard-run.sh` with `unshare -Urp --fork --mount-proc` →
    `unshare -nm` (scripts/testguard-run.sh:56,61), so every named test now
    runs in a private network namespace whose `lo` is DOWN and unaddressed
    (verified inside the wrapper: `ip addr show lo` → `<LOOPBACK> … state
    DOWN`, no `inet`; `ip route show table local` → "FIB table does not
    exist"). In that namespace `net.Listen("tcp","127.0.0.1:0")` still
    succeeds, so the helper's reserve-port dance and both `SessionSync.Start`
    listeners bind green — but the production dial
    (`SessionSync.fabricConnectLoop`, pkg/cluster/sync_conn.go:1496) fails
    `connect: network is unreachable` on every 1 s retry for the full 20 s
    deadline (captured with a temporary Warn log on the dial error, 20
    consecutive ENETUNREACH lines), and `fabricConnectLoop` swallows dial
    errors (sync_conn.go:1497-1499), so the test only ever sees the pair's
    own timeout. The same defect reddened every cell using the helper
    (full-resync 6743 x2, demotion 10387 x1 sampled, this cell); the two
    sibling event-stream artefacts named in #18933 pass because their
    fixtures use unix sockets, not loopback TCP.
  - **Fix (test-side):** `connectedSyncPairForDrainTest` now calls
    `ensureLoopbackForSyncPairTest` first: a listen+dialed probe declares
    127.0.0.1 routable (a bare bind is not proof — that asymmetry is what
    hid the rot), and only an unroutable loopback triggers
    `netlink.LinkSetUp("lo")`, which installs 127.0.0.1/8 and its local
    routes (verified in the wrapper's exact namespace shape: UP alone
    restores dialability; the address then exists and AddrAdd would return
    EEXIST). No-op wherever loopback already routes. Registered the file as
    a netlink mutation source in the #18038 census (netlink floor 43→44).
