# Issue #13632: gate disabled-control parsing on ingress authority

## Change

`degraded_ctrl_disabled_action` now checks `USERSPACE_INGRESS_IFACE_FLAG_ADJUDICATED`
before parsing any frame bytes. An unadjudicated interface takes the
ctrl-disabled transit DROP, so raw-L3 source octets cannot select a parse
failure or local/control kernel-pass exemption. The flag read is reused for
the tagged-only VID-0 check.

This deliberately preserves disabled-control fail-closed behavior instead of
copying the enabled #8279 `cpumap_or_pass` disposition: forwarding attached
transit from a disabled helper to the kernel would bypass policy while the
previous snapshot is reported as retained. The enabled #8279 branch keeps its
own pass disposition. Rust source-order regression coverage pins this distinct
branch/order, and a privileged raw-L3 packet test exercises the false
local-destination exemption. Existing local/control datapath fixtures seed an
adjudicated ingress row so they continue to test those paths.

## Risk

The policy-preserving behavior is intentionally stricter than the armed #8279
path: any unadjudicated frame is dropped while ctrl is disabled; ARP/LLDP direct
kernel handling remains available on adjudicated interfaces.
