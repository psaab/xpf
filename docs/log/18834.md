# #18834 — isolate parallel test tuple gates

- **Timestamp**: 2026-11-05
- **Branch**: `fix/18834-lane`
- **Issue**: #18834 — parallel test cells interfere through the process-global tuple gate.
- **Action**: Keep `GLOBAL_TUPLE_GATE` process-global in non-test builds. Under `cfg(test)`, `global_tuple_gate()` clones a gate owned by the calling test-harness thread. Independent tests no longer contend on the same canonical tuples or clear fence; explicit `Arc<TupleGate>` handles still share a gate across threads for deliberate intra-test contention. No assertions changed.
