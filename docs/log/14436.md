# #14436 — DR17-H7 interface-instance packed tail

## Mechanism
`ge-0/0/0 bandwidth 1g unit 0 family inet { address 10.0.0.1/24; filter { input F; } }` parses to ONE node `Keys=[ge-0/0/0, bandwidth, 1g, unit, 0, family, inet]`, `Children=[address, filter]`. At the original audit master only `bandwidth` was rescued (`packedBody(ifLeaves).FindChild("bandwidth")`), so the interface was created but `child.FindChildren("unit")` found nothing — no unit, address, or filter compiled. The unit's zone fanned up to a zoned base row with `FilterInputV4=""`. Independently verified RED on pristine master by two sibling reviewers: strict rejected via #12090 (filter body has no recognised consumer ancestors), lenient compiled with `Units` empty and `Bandwidth=1e9`.

## What changed on master meanwhile
- #14442 (merged) introduced `ifBody := packedBody(ifLeaves, interfaceSchema)` and routed interface-level reads + unit enumeration through it, and changed the bare-leaf skip to `child.IsLeaf && bandwidthNode == nil && len(ifBody.Children)==0`. Modelled packed leaves (`mtu 9000;`) therefore now compile instead of being skipped.
- #14435 / DR17-H6 (merged, PR #14565) fixed the packed unit tail.
The branch was rebased over both; conflicts kept `ifBody` and both filter exemptions (#14435 unit-packed + #14436 instance-packed).

## Fix (residual delta over current master)
- `pkg/config/compiler_interfaces.go`: expand the RAW child as well (`packedBody(child, ...)`) and merge top-level statements it alone synthesises into `ifBody`, keyed by statement name so no unit is ever processed twice. This covers the shape where `expandResolvingRun9792` rewrote Children and `packedBody(ifLeaves)` has no tail left.
- `pkg/config/compiler_interfaces_unsupported.go` (#12090 gate): accept the packed instance's braced filter body (`isInterfacePackedInstanceFilterConsumer12090`, pointer walk over the `packedBody` expansion incl. split `family { inet { ... } }`) and its token form (`isInterfaceInstancePackedTailFilterConsumer12090`, schema-level token walk). mpls/any filters still reject. Second-loop gate parity: the H9/H10/#10293 checks now iterate `packedBody(iface)` children, plus a raw-Keys scanner (`packedIfaceTailHasMac14436`) for an interface-level `mac` whose unknown token blocks expansion.
- `pkg/config/compiler_interfaces_qinq.go`, `pkg/config/compiler_interfaces_vlanmap.go`: expand the packed instance (and packed unit, for QinQ) before collecting, so `inner-vlan-id` and `input-vlan-map` packed tails reject like braced twins (#5879/#6178).
- NOT changed: unit-tail internals (#14435), #14442's skip semantics, sibling raw-unit collectors that only warn/dedup (unit-alias, wireguard plaintext warn, tunnel endpoints).

## Bare-leaf criterion reconciliation
The issue text ("bare-leaf form still skipped unchanged") predates #14442. Post-#14442 master semantics, which this PR preserves: a modelled packed leaf (`ge-0/0/0 mtu 9000;`) compiles with MTU 9000; an unknown bare leaf (`ge-0/0/0 frobnicate 7;`) is still skipped (fail-closed). The regression test asserts both.
