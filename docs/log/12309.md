# Issue #12309 — Cached-neighbor provenance and lifecycle gate

- **Base**: `a714c90d472a3c3d98a3799831cfef3ec311a61c`.
- **Action**: Restrict absent-neighbor cached fallback to `ForwardFlow` sessions with a valid forwarding-generation stamp current for the hit. Static/config neighbor removal is caught by generation revalidation; runtime changes still require a zero per-shard MAC-change epoch. Peer-synced and reverse matches are strict on absence, and connected directed broadcasts are explicitly excluded before the absent-binding gate.
