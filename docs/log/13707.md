# #13707 — isolate slow-path rate limiting by outlet

`SlowPathReinjector` charged trusted, adjudicated, and delegated queues to one
shared token bucket. A delegated transit flood could consume tokens needed by
trusted control-plane punts and adjudicated reinjects. Successful rate
admissions also remained charged when a bounded queue rejected the packet.

The reinjector now maintains independent dual packet/byte token buckets for
`Trusted`, `Adjudicated`, and `Delegated` queue classes. Failed queue sends
refund their reservation for both ordinary enqueue paths and leased
adjudicated submissions. The README describes the per-outlet contract.

Regression tests exhaust delegated tokens while asserting trusted and
adjudicated packets remain admissible, and assert repeated queue-full refusals
do not drain the trusted bucket.
