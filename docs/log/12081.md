## Change

The 7796 selftest leg runs Go tests verbosely, pins `-json=false` so inherited `GOFLAGS=-json` cannot corrupt its text scan, and requires each of its four kernel cells to appear as RUN and not SKIP. Any nonzero Go test result fails, even when `ip` is absent. When `ip` is absent, the leg returns SKIP (77) only after all four cells ran and the only skips were the two readback cells; other missing or skipped-cell shapes fail. The two hermetic 7796 cells still run but are not part of the kernel-cell pin.

## RED then GREEN proof

- **RED-before:** With `ip` absent from a hermetic PATH, the unmodified leg exited **0** and printed only `ok github.com/psaab/xpf/pkg/routing`. Running its Go predicate with `-v` showed `TestRuleDSCPRoundTripsThroughKernel7796` and `TestDSCPZeroIsDistinctFromNoDSCP7796` both SKIP because `ip` was missing.
- **GREEN (A, ip absent):** With a symlink-farm PATH lacking `ip`, the updated leg ran and then returned **77** for the readback-only skips. The committed probe selftest also pins a canned case where all four named cells run and only the readback cells skip.
- **GREEN (C, Go-hidden ip):** With `ip` on the leg's PATH but hidden from Go, the two actual readback cells skipped; the leg named both as FAIL and exited **1**. The temporary `GO` launcher is not part of the repository.
- **GREEN (ip present):** `sh test/routing/selftest-rule-dscp_7796.sh` ran under `unshare -rn`, exited **0**, and printed `PASS: all four 7796 kernel cells ran and passed`.
- **RED then GREEN (`GOFLAGS=-json`):** The pre-fold script exited **1** with four `did not run` diagnostics. The folded invocation passes `-json=false`; `GOFLAGS=-json sh test/routing/selftest-rule-dscp_7796.sh` exited **0**.

The leg also retains its existing SKIP behavior when the required namespace capability is unavailable.
