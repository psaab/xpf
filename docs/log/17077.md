## Why

The #9167 shared Go/Rust verdict corpus — the only cross-language guard on the hand-mirrored simulator — could not express unknown zones, ICMP type/code, omitted selectors, feeds, or lenient/quarantine configs. Its row grammar was fixed at 9-10 positional fields: the Rust half panicked on a zone outside the snapshot and passed `None` for ICMP unconditionally; the Go half compiled strictly and reported `ContentRejected` as an error. Post-corpus drift fixes, including the expressible #13705 (transit frag + reject), added no rows, so the README's "Drift is loud" covered only the original tier-order cases (R4-Q45-03).

## What

- Grammar: optional trailing `key=value`/flag tokens on `q` rows — `frag`, `icmp=T[/C]`; `-` for an omitted protocol/port selector; `content-rejected` as an expected action (policy must be `-`); `feed <name>=<cidr>[,...]` case lines (empty RHS = present-but-empty overlay); a `lenient` case flag. A `-` protocol row must expect the default verdict: Go asserts that verdict with `Protocol=""`, Rust asserts the underspecified classification (no app-constrained rule decisive for unknown protocol 255).
- Go half (`policy_verdict_corpus_9167_test.go`): parser carries ICMP type/code, nil (omitted) ports, feed overlay, lenient flag; `Match` is driven with `ICMPType/ICMPCode/FeedOverlay`; unknown zones pass through to the existing `UnzonedIngress/UnzonedEgress` arms; `content-rejected` rows assert `Result.ContentRejected`. Presence pin `TestPolicyVerdictCorpusPins17077Cases` for all nine new cases.
- Generator (`policy_verdict_corpus_gen_9167_test.go`): parses `lenient`/`feed` lines, builds address books and policies with the feed overlay (`buildAddressBookTableWithFeeds`/`buildPolicySnapshotsWithAddressBook`), compiles lenient cases with `CompileConfigLenient`, and emits the post-quarantine snapshot (`quarantineCollidingZones`) the dataplane receives. Snapshots regenerated.
- Rust half (`policy_verdict_corpus_9167.rs`): mirrors the grammar; a zone absent from the snapshot maps to id 0 instead of panicking; `icmp=` threads into `packet_icmp` for both evaluators; omitted ports evaluate flowless (`l4_present=false`); `-` protocol rows assert no app-constrained rule is decisive for protocol 255; `content-rejected` cases assert `parse_policy_state_with_counters` refuses the snapshot; the host arm's matched-vs-default identity uses the counter index so an unmatched zone-0 rule no longer aliases the default. Presence pin `policy_verdict_corpus_pins_17077_cases`.
- New cases (one per cited drift class): `transit-fragment-reject-13705`, `unknown-zone-egress-11067`, `unknown-zone-ingress-8318`, `unknown-zone-junos-host-global-11369`, `icmp-type-code`, `omitted-selectors`, `feed-overlay-12965`, `lenient-quarantine-5649` (zzq17760/zzq8100 StableZoneID collision), `content-rejected-3727` (unrepresentable `destination-port 70000`, lenient-loaded). Corpus header's KNOWN GRAMMAR LIMIT/REMAINING INEXPRESSIBLE and the README "Measured" section list what stays inexpressible (NAT/scheduler per #10511; flow label/DSCP/TCP flags/TTL/IP options; session state; ingress-interface host-inbound scoping).
