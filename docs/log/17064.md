## STEP-0 (verified at origin/master a60e77bda3)

All eight loops live, grep census `netlink.*Subscribe|ErrorCallback|ResubBackoff`:

1. SNMP link traps — `daemon_flow.go:monitorLinkState/runLinkStateSubscription`, `defaultLinkStateSubscribe` (ErrorCallback), backoff const `linkStateResubBackoffDefault`.
2. Fabric — `daemon_ha_fabric.go:monitorFabricState/runFabricStateSubscription`, `defaultFabricLinkSubscribe/defaultFabricNeighSubscribe` (**no ErrorCallback**), const `fabricStateResubBackoffDefault`.
3. Neighbor — `daemon_neighbor_listener.go:neighborListener/runOneSubscription`, Neigh opts ListExisting+1MiB+ErrorCallback, literal `2 * time.Second` backoff, 60s safety ticker in-loop.
4. Route — `daemon_route_listener.go:routeListener/runOneRouteSubscription`, Route opts ListExisting:false + `routeListenerErrorCallback` (#8915), catch-up `routeListenerCatchUp` (#9010), literal 2s.
5. RPM pins — `daemon_rpm.go:probePinRetryLoop`, Link+Addr WithOptions+onError fan-in, conditional subscribe (verifyFn!=nil), independent per-socket retry timers, 30s ticker that can end the loop, `linkStateResubBackoffDefault` reuse.
6. Transit gate — `transit_gate_link_watch_9848.go`, `defaultLinkStateSubscribe`, reassert BEFORE loop on success AND failure, backoff field.
7. RxVLAN audit — `rxvlan_audit_11446.go`, package-var `rxVlanAuditLinkSubscribe`, audit on subscribe/fail/close + 10s ticker in-loop.
8. IPsec topology — `ipsec_topology_owner_9506.go`, **bare `netlink.LinkSubscribe`, no ErrorCallback, subscribe error discarded without log** (the headline defect), poll/note ordering + `ipsecTopologySubscribed` flag sequencing.

## Why

Eight copies of the same lifecycle; the "closed channel means dropped events" fix landed copy-by-copy (#3950/#4031/#8915/#9010), fabric + IPsec never reported receive errors, IPsec never logged subscribe failure, 2s backoff spelled 3 ways. One helper owns subscribe/done-close/error-logging/backoff/ctx-exit; per-owner event + gap semantics stay as callbacks.

## What

- New generic `nlWatch[U]` in `pkg/daemon/nlwatch.go`: `Run(ctx)` (resubscribe loop + stoppable-timer backoff, `nlWatchBackoffDefault` single 2s const), `runOne` (one lifetime: Enabled gate, subscribe, log subscribe-failure + close done, OnGap, select ctx/Watch/update, `!ok`→OnChannelClosed→retry, receive error → Name log + OnReceiveError), `runPairNL` (two-socket variant: subscribe A→B, OnGap once both live, either close tears down both), `nlWatchBackoffWait`, and `defaultNLSubscribe[U]` — the default subscriber table, the **only** non-test `netlink.*Subscribe*` calls (Link/Addr plain, Route ListExisting:false, Neigh ListExisting:true+1MiB — each owner's historical options preserved).
- Migrated all 8 owners, preserving per-loop resync semantics:
  - SNMP: OnGap=resync(prevOper, seeded) then seeded=true — first seed silent, later catch-ups emit.
  - Fabric: `runPairNL(link, neigh, triggerFabricRefresh)` — subscribe order link→neigh, gap only when both live, sibling teardown, shared backoff. Seam signatures widened to 3-arg (receive-error callback now wired — new visibility).
  - Neighbor: default Neigh subscriber (ListExisting/1MiB), safety ticker as Watch arm, no OnGap (ListExisting replay, as before).
  - Route: OnGap=`routeListenerCatchUp` (#9010, incl. first subscribe), OnReceiveError=`routeListenerErrorCallback` (#8915: counter + Mark; its duplicate Warn removed — nlWatch logs `watcher=route`). Named `routeListenerCatchUp`/`routeListenerErrorCallback` kept as the seams cells drive.
  - RPM: pair via two nlWatch lifetimes in goroutines forwarding to the original single select (ticker/retry/error fan-in ordering + rpmMu-only-on-ticker preserved); conditional subscribe via `Enabled`; per-socket `OnGapOnlyOnRestore` verifies all pins on successful restoration but not a clean initial subscribe (a success after failed subscribe attempts also counts as restoration); `OnReceiveError` and the periodic ticker retain their verify behavior; ctx exit clears `rpmPinRetryActive` (also ticker-done path clears itself, double-clear is same-value). This preserves the original behavior: initial subscribe does not verifyAll — only error fan-in / restored / ticker do.
  - Transit gate: OnGap=OnGapOnFailure=reassert+resync (stage string unified to "link-subscribe"; reassert ignores stage for behaviour), `runTransitGateLinkSubscription` kept delegating to `watch.runOne`.
  - RxVLAN: audit as OnGap+OnGapOnFailure+OnChannelClosed, 10s ticker recreated per lifetime as Watch arm (phase reset per resubscribe, as original), `runRxVlanAuditLinkSubscription` kept.
  - IPsec: new `ipsecTopologyLinkSubscribe` seam + `defaultIpsecTopologyLinkSubscribe` (WithOptions+ErrorCallback — **subscribe failure and receive errors now logged**, the defect fix); exact poll/note/Store ordering preserved (failure poll→note→poll via Subscribe wrapper; success poll→Store(true)→poll; close Store(false)→note→poll; flag cleared on every exit).
- Deleted: `linkStateResubBackoffDefault`, `fabricStateResubBackoffDefault`, neighbor/route 2s literals, all eight hand-rolled loops, duplicate `defaultLinkStateSubscribe`/`defaultProbePin*Subscribe` definitions (now once in nlwatch.go).
- Kept `pkg/vrrp` out of scope (separate package/lifecycle; acceptance grep is pkg/daemon-scoped).

## Risk

- Control-plane only; one indirect call per event (negligible vs recvmsg).
- Log lines change shape: per-owner messages replaced by `netlink receive error watcher=<name>` / `netlink subscription closed, resubscribing watcher=<name>` / `netlink subscribe failed watcher=<name>` (route keeps its counter+Mark, RPM keeps verifyAll fan-in). The receive-error line makes no resubscribe claim: ErrorCallback also fires on non-terminal paths (NLM_F_DUMP_INTR, NLMSG_ERROR, wrong portid) where the library keeps receiving; only the channel-close line claims a resubscribe. Operators gain fabric/IPsec receive-error visibility previously absent.
- RPM pair now runs two extra goroutines forwarding events (buffered 64) — event handling still serialized on the original single select goroutine; verify calls unchanged.
- Transit-gate reassert stage string unified ("link-subscribe-failed" → "link-subscribe"); the stage is a label in `reassertTransitGate`, behaviour identical.
