# #13686 — align DNAT proxy-ARP withdrawal with prefix lookup precedence

## Why

`match_prefix_lpm` probes exact protocol/port buckets before wildcard buckets. A `/24` TCP:443 translation therefore wins against a more-specific `/26` `PROTO_ANY` exemption, but `off_prefix_scope_superset` previously treated the wildcard exemption as a superset and withdrew the `/26` hosts from firewall-local registration. Packet lookup translated those addresses while proxy-ARP/ND no longer advertised them, blackholing on-segment traffic.

## What

- Require prefix-scoped `off` and translate candidates to have the same protocol/port key before allowing scope/prefix precedence to withdraw an address. Wildcard buckets that are probed later can no longer suppress proxy-ARP for a translation in an earlier bucket.
- Added regressions for the mismatched `PROTO_ANY` off versus TCP:443 translate (both configuration orders), plus a same-bucket control proving a winning longer-prefix off still withdraws its hosts. The tests inspect `destination_ips_scoped()` directly and pin packet lookup outcomes.
