# Issue #15947: dataplane admission defects (single-claim residual)

- **Timestamp**: 2026-10-22
- **Action**: PR #15968 landed the validated arms of H26-02, H26-04,
  H27-03, H28-01, H28-02, H29-01, H29-02, H29-04 arm 1, H30-01 and
  H30-03 arm 1. This change takes the one remaining single-claim
  residual, H29-04 arm 2 narrowed by the research: on the flow-cache
  hit path the deferring probe charged the session and locally
  completed the handshake *before* the cached output-filter/policer
  verdicts, so a packet then dropped had already been counted and had
  promoted the session (its HA Update was merely withheld, never
  undone). `SessionTable::rollback_dropped_probe_hit` now un-charges
  the canonical entry, drops the withheld Update, and restores both
  halves to their pre-completion pending state on the opening expiry;
  the cached drop arm in `flow_cache_hit.rs` invokes it. A retransmitted
  completing ACK re-probes and, if admitted, publishes exactly once.
  Fold (Opus review of #16312): the first rollback reconstructed state
  from packet flags and was not a true inverse. It now restores exact
  pre-probe snapshots (ProbeUndo) captured under the producer's
  canonical key: accounting target incl. the reverse-only fallback,
  counters, observed flags/ToS, both halves' Booleans/timestamps/
  durations, and SYN-pressure index membership; emit and rollback
  both resolve translated-alias identities canonically.
  Fold 2 (Opus): keepalive is preserved — rollback restores every
  snapshot field EXCEPT last_seen_ns/expires_after_ns, so a dropped
  cache-served packet still refreshes liveness exactly as the
  pre-fusion path did; it must not charge, complete, or publish,
  but liveness is not rewound. Perf wording corrected: snapshots
  are taken per deferring probe hit (bounded 64), so the admitted
  flow-cache path pays the snapshot too until its verdict; the
  statement is per-hit snapshot cost, not "admitted unchanged".
  Fold 3 (Opus): duration class corrected — rollback restores the
  snapshot expires_after_ns DURATION (opening/zone-override) while
  keeping the probe-refreshed last_seen, so deadline = kept stamp +
  opening duration; regression cells pin 20s-vs-1800s and a 7s zone
  override against the established stamp.
