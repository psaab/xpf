# #16616: rib-group peer returns required no import-rib authorization

- **Timestamp**: 2026-10-25
  - **Action**: The #11062 peer-return rules installed, for every tenant
    leaking its interface routes into `inet.0`, a destination-scoped return
    (`to <peer-prefix> iif|oif vrf-<self> lookup <peer-table>`, priorities
    1001-1999) to *every other* tenant leaking into main, and the AF_XDP FIB
    mirrored each as an `A.inet.0 -> B.inet.0` NextTable row. Two tenants
    following the textbook shared-services pattern (`import-rib
    [ <self>.inet.0 inet.0 ]` each) were therefore reachable from each
    other in VRF context (VRF-bound sockets/daemons, non-AF_XDP slaves,
    slow-path reinjects) with no import-rib authorizing it, contradicting
    `docs/rib-group-route-leaking.md`'s own contract that B's routes go
    into `b.inet.0` and `inet.0` only.
    Fix: a return is now installed (kernel) and mirrored (FIB) only when
    the source instance's own interface-routes rib-group for that family
    names the peer's rib (`<peer>.inet.0` / `<peer>.inet6.0`) in its
    import-rib list — the VRF->VRF import case — and the peer leaks into
    main for that family. Added `ribGroupImportsInstanceRib` in
    `pkg/routing/rules.go` (gating `ribGroupPeerReturnPrefixes`) and
    `ribGroupReturnAuthorized` in `pkg/dataplane/userspace/routes.go`
    (gating the live-rule mirror, so a stale rule from an older binary
    cannot republish an unauthorized row; the kernel `clear()` sweep is
    unchanged and still removes the stale rule itself). Both sides fail
    closed: no matching group/rib means no return. The VRF->VRF *forward*
    leak remains Phase-2 deferred (warned, not installed); naming a peer
    rib authorizes only this destination-scoped return to the peer's
    leaked connected prefixes. Main->tenant still resolves via the
    30000-band per-prefix leak rules; tenant->tenant without the peer-rib
    import now hits the #9819 miss terminator.

    rib-group storage must update both, as with the existing
    `ribGroupLeaksIntoMain` mirrors. No Rust/FIB wire change.
