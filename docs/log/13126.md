# Reject invalid Router Solicitations and incomplete socket setup (#13126)

- **Issue**: #13126, source finding D10-09 (deep-review; validated by the three-way research gate).
- **Cause**: `rsReceiver` discarded the parsed `*ndp.RouterSolicitation` after checking its type. `validRSReceive` therefore validated the IPv6 hop limit and source address but could not enforce RFC 4861 §6.1.1's requirement that an RS sourced from `::` contain no Source Link-Layer Address option. Separately, `openConn` logged and ignored errors enabling hop-limit control messages, joining `ff02::2`, and installing the RS-only ICMPv6 filter, then started a sender with incomplete receive setup.
- **Change**: Keep the parsed solicitation and pass it into `validRSReceive`. Reject a nil solicitation and, for the unspecified source only, any `ndp.LinkLayerAddress` option with `Direction == ndp.Source`. Make `openConn` fail closed on any required RS receive setup error: close the partially configured connection, clear `s.conn`, and take the existing failed-open shutdown path.
- **Regression coverage** (`pkg/ra/rs_receive_validation_5095_test.go`, `pkg/ra/rs_unspecified_slla_13126_test.go`, `pkg/ra/socket_setup_fail_closed_13126_test.go`): Predicate matrix covers unspecified source with/without SLLA and with TLLA, link-local source with SLLA, invalid source scope/hop limit, and missing solicitation/control message. End-to-end test parses an RS containing SLLA and confirms it does not trigger an RA. Injected failures for hop-limit setup, group join, and ICMP filter verify `openConn` fails and closes/releases the connection.
- **RED evidence**: On pristine `origin/master` at `55ab81ef0` with the regression added, `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/ra -run '^TestRSUnspecifiedSourceSLLAEndToEnd13126$' -count=1` failed: `RS from :: with SLLA triggered 1 RA reply(ies); RFC 4861 §6.1.1 requires 0 (#13126)`.
- **GREEN evidence**: `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/ra/... -count=1` passed; `go vet ./pkg/ra/...` passed; `gofmt` was applied to the touched Go files.
- **Blast radius / risk**: Invalid unspecified-source solicitations no longer solicit an RA. Valid link-local and unspecified-source/no-SLLA solicitations retain existing behavior. If the socket cannot be configured for safe RS reception, that sender now stays down until a later reconcile rebuilds it rather than emitting periodic RAs with broken receive setup. Existing failed-open retry/reconcile behavior is reused.
