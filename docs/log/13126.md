# Reject unspecified-source Router Solicitations with SLLA (#13126)

- **Issue**: #13126, source finding D10-09 (deep-review; validated by the three-way research gate).
- **Cause**: `rsReceiver` discarded the parsed `*ndp.RouterSolicitation` after checking its type. `validRSReceive` therefore validated the IPv6 hop limit and source address but could not enforce RFC 4861 §6.1.1's requirement that an RS sourced from `::` contain no Source Link-Layer Address option. Such an RS passed validation and triggered a multicast Router Advertisement.
- **Change**: Keep the parsed solicitation and pass it into `validRSReceive`. Reject a nil solicitation and, for the unspecified source only, any `ndp.LinkLayerAddress` option with `Direction == ndp.Source`. Existing hop-limit and source-scope checks remain unchanged; other option directions and link-local RS behavior remain accepted.
- **Regression coverage** (`pkg/ra/rs_receive_validation_5095_test.go`, `pkg/ra/rs_unspecified_slla_13126_test.go`): Predicate matrix covers unspecified source with/without SLLA and with TLLA, link-local source with SLLA, invalid source scope/hop limit, and missing solicitation/control message. End-to-end test parses an RS containing SLLA and confirms it does not trigger an RA.
- **RED evidence**: On pristine `origin/master` at `55ab81ef0` with the regression added, `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/ra -run '^TestRSUnspecifiedSourceSLLAEndToEnd13126$' -count=1` failed: `RS from :: with SLLA triggered 1 RA reply(ies); RFC 4861 §6.1.1 requires 0 (#13126)`.
- **GREEN evidence**: `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/ra/... -count=1` passed; `go vet ./pkg/ra/...` passed; `gofmt` was applied to the touched Go files.
- **Blast radius / risk**: Only Router Solicitation admission changes: malformed unspecified-source solicitations no longer solicit an RA. Valid link-local solicitations and valid unspecified-source solicitations without SLLA retain existing behavior. No periodic RA, socket setup, or packet-generation behavior changed.
