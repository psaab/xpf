# 10002 — drop malformed chassis RG/node identities on tolerant load

- **Code commit**: `68e9cfacd` (`fix(config): drop non-numeric chassis identities (#10002)`)

## Change

The tolerant chassis compiler no longer lets a non-numeric or explicitly
quoted-empty `redundancy-group <id>` fall through an `Atoi` failure to the zero
default. The malformed RG instance is dropped. Likewise, a non-numeric or
explicitly quoted-empty RG-scoped `node <id>` statement is ignored before it
can overwrite node 0's real priority. The existing AST identity gate still
rejects these tokens on strict commit and records warnings on tolerant load,
with the warning explicitly naming the tolerant drop/ignore, so legacy or
peer-synced configs continue to boot without allowing malformed identities to
alter valid records.

Numeric zero spellings continue to merge as the legitimate zero identity.
Negative redundancy-group handling from #9723 remains a tolerant drop, while
the pre-existing negative RG-scoped node behavior is unchanged. The schema
notes and the #8436/#7484 harness fixtures were updated to describe and retain
coverage for the numeric identity slots.
