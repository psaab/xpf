# #15649 — Show-surface renderer divergence (no SSOT): CLI/gRPC/REST (Cohort C1: V2-02, V10-04, V11-04, V12-04, V17-04)

## Issue

- Independent CLI/gRPC/REST renderers with hardcoded literals diverged by construction:
  - V2-02 local `show security policies detail` omitted `then count` + live Session statistics; standard view omitted `count`.
  - V10-04 `alarm-without-drop` omitted from screen inventory (`ScreenChecks`); local `show security screen` silently widened on unknown args.
  - V11-04 flow timeouts disagreed: CLI ICMP `30s` vs Rust `60s`, gRPC/REST bare `0s`/omitted unset TCP rows, stale `#5804` GRE text (`remain 5-tuple keyed`, superseded by #7188), omitted flow fields on gRPC/REST.
  - V12-04 (narrowed) `show security policies detail` / `show security applications` bypassed `ResolveApplication`/`ExpandApplicationSet` for raw user/term/set/predefined members.
  - V17-04 (narrowed) gRPC/REST `show services flow-monitoring` returned `No flow monitoring configured` for IPFIX-only configs, omitted IPFIX template bindings; un-resolvable collectors could read as installed.

## Root cause

- Three renderers per object, each spelling defaults/annotations/expansion itself; no shared formatter, so fixing one surface left the others divergent.

## Fix

- Rebase note: V12-04 CLI/gRPC resolver expansion landed first via #15652 (#15797); rebase keeps master's implementation for `printAppDetail`/`showApplicationsFiltered`/CLI set-member detail and retains this PR's `ApplicationSetExpandedMembers` summary expansion on CLI/gRPC/REST set listings plus the remaining V2-02/V10-04/V11-04/V17-04 SSOT work.
- New SSOT `pkg/config/show_ssot_15649.go`: `RenderFlowTimeouts` (TCP via `TCPSessionTimeoutDataplaneDefault`+`AnnotateTCPSessionTimeout`, UDP/ICMP `60s (default)` constants mirroring Rust, unified MSS/flow-options sections, GRE via `GREAccelerationLine()` = #7188 wording), `PolicyDetailStats` (count + packets/bytes + unpublished/quarantine/disabled dispositions), `ExpandedApplicationNames`/`ResolvedApplication`/`ApplicationSetExpandedMembers` (wrapping `ResolveApplication`/`ExpandApplicationSet`), `RenderFlowMonitoring`/`HasFlowMonitoring` (v9+IPFIX templates, sampling flow-server template bindings, inline-jflow source, `FlowServerExcludedReason` NOT-INSTALLED suffix).
- Surfaces delegate: CLI `showFlowTimeouts`, `showFlowMonitoring` (+ sampling section retained), policy detail/standard count; gRPC `showFlowTimeouts`, `showFlowMonitoring`, `showPoliciesDetail` (shared stats adapter), forwarding-options IPFIX binding; REST `flow-timeouts`, `flow-monitoring`, applications set expansion.
- V10-04: `ScreenCheckAlarmWithoutDrop` added to `ScreenChecks` (structured REST/gRPC inventory now exposes audit mode; text surfaces already render `ScreenAlarmModeLine` via #15175); CLI `handleShowScreen` rejects unknown/trailing args instead of widening to all-profiles listing.
- Existing tests updated where labels/wording intentionally unified: gRPC/REST TCP-timeout labels (`TCP established timeout:`), GRE #5804 test now asserts #7188 SSOT wording.
