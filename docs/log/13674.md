# #13674 — purge translated synced hits completely

A transient translated peer-synced hit purge removed the shared entry and
local session but left a kernel BPF conntrack row, sibling worker replicas,
and flow-cache slots behind. The purge now deletes the conntrack mirror,
replicates an identity-conditional delete only when the captured shared-session
identity is still current, and returns the key for the worker's all-binding
flow-cache invalidation path. Pool-release behavior remains unchanged.

Regression coverage asserts kernel conntrack deletion, identity-conditional
sibling delete replication, and flow-cache invalidation-key collection for a
translated synced hit.
