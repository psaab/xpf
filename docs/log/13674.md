# #13674 — purge translated synced hits completely

A transient translated peer-synced hit purge removed the shared entry and
local session but left a kernel BPF conntrack row, sibling worker replicas,
and flow-cache slots behind. The purge now deletes the conntrack mirror with
the live IPv4/IPv6 conntrack descriptors, replicates a `DeleteSynced` when
shared authority is removed, and returns the purged key for flow-cache
invalidation. Pool-release behavior remains unchanged.

Regression coverage asserts kernel conntrack deletion, sibling delete
replication, and flow-cache invalidation-key collection for a translated
synced hit.
