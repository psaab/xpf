## PR B — product change (Junos implicit final discard)

- **Timestamp**: 2026-11-01
  - **Action**: Design. The synthetic final term is built in the Go
    snapshot builder (`appendImplicitDiscard`), not in Rust: adding a field
    to Rust `FirewallFilterSnapshot` touches 392 struct literals in 43
    files, while a Go-built ordinary term reaches every Rust evaluator
    (input, live and cached TX, metered lo0, #7212 static verdict, #2620
    replay) with zero Rust production change. The in-memory marker
    `FirewallFilterSnapshot.ImplicitDiscard` is `json:"-"`, so the wire
    shape is unchanged; the #8892 shape walk moves by exactly that one
    line (707 -> 708 fields, measured on the 3966cff11f base), recorded as
    a v77 STANDS entry, no protocol bump.

    sdifname, `fib saddr type local`, pkttype host, ct status), and the
    kernel delivers it to the input hook. Only the prerouting pass differs
    (wire traffic shows iifname fxp0 first), and carrying that to the
    input hook needs a packet mark or a new own-source anti-spoof drop on
    every interface, both outside this PR. So IPv6 gets no exemption and
    the docs say a lo0 inet6 filter without a catch-all must accept that
    traffic itself. Real-kernel cell: IPv4 VRF-local and default-table
