## PR B — product change (Junos implicit final discard)

- **Timestamp**: 2026-11-01
  - **Action**: Design. The synthetic final term is built in the Go
    snapshot builder (`appendImplicitDiscard`), not in Rust: adding a field
    to Rust `FirewallFilterSnapshot` touches 392 struct literals in 43
    files, while a Go-built ordinary term reaches every Rust evaluator
    (input, live and cached TX, metered lo0, #7212 static verdict, #2620
    replay) with zero Rust production change. The in-memory marker
    `FirewallFilterSnapshot.ImplicitDiscard` is `json:"-"`, so the wire
    shape is unchanged; the #8892 shape walk moves by exactly that one
    line (707 -> 708 fields, measured on the 3966cff11f base), recorded as
    a v77 STANDS entry, no protocol bump.
  - **File(s)**: `pkg/dataplane/userspace/filters.go`,
    `pkg/dataplane/userspace/protocol_policies.go`,
    `pkg/dataplane/userspace/snapshot_shape_version_8892_test.go`
- **Timestamp**: 2026-11-01
  - **Action**: Refined the catch-all predicate to the inverse of Rust
    `continue_term` and exported it as `config.FirewallFilterHasCatchAll`
    (modifier-only and routing-instance unconstrained terms now count; an
    authored `then { ...; next term; }` does not). One predicate drives the
    commit warning, the snapshot term, the lo0 kernel drop and the show
    surfaces. Reworded the #3295 warning to say unmatched traffic is
    discarded and counted, with the `then accept` remedy.
  - **File(s)**: `pkg/config/compiler_validate_warn_firewall.go`,
    `pkg/config/compiler_validate_warn.go`,
    `pkg/config/compiler_filter_nocatchall_3295_test.go`,

    `pkg/config/compiler_filter_implicit_discard_18728_test.go`
- **Timestamp**: 2026-11-01
  - **Action**: lo0 kernel mirror. Each family's lo0 filter without a
    catch-all ends in `meta nfproto <f> iifname != { lo, control, fabric }
    counter name "xpflo0implicit_<family>" drop`, in the text oracle and
    the netlink builder (parity cells incl. a multi-name exemption). The
    exemption list is `config.Lo0ImplicitDiscardExemptNetdevs` (positive
    non-fxp0 lifelines); an empty list refuses the netlink plan. The
    implicit counters live outside the operator `xpflo0_` namespace and
    are skipped by the Prometheus `then count` series. An empty or
    match-nothing lo0 filter now installs (drop-all except exempt) instead
    of being refused as an empty shell; the #9940 cells were rewritten to
    that outcome.
