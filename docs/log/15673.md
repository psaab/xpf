# Issue #15673: Address-book dns-name / range-address / wildcard-address forms

- **Timestamp**: 2026-10-19
- **Action**: implemented the modelled Junos address value forms across both
  stanza shapes (hierarchical braces and flat `set`): `range-address <low> to
  <high>` expands natively via `expandAddressRange` into
  `Address.ExpandedPrefixes` (oversized ranges recorded in
  `Address.OversizedRange`, strict-rejected, lenient-unusable);
  `wildcard-address <ip>/<wildcard-mask>` expands to the single
  wildcard-derived CIDR (non-contiguous masks stay unimplemented);
  `dns-name <fqdn> [ipv4-only|ipv6-only]` is modelled in
  `Address.DNSName`/`DNSFamily` with the live resolution in
  `Address.DNSAddresses`, refreshed at apply time and by a periodic daemon
  goroutine (`pkg/daemon/daemon_dnsaddr.go`) that republishes on change.
  Resolvers (policy strict mirror, userspace book table, NAT expansion,
  junos-host projection, representability, capabilities) now consume
  `Address.UsableValues()` so multi-prefix entries publish every prefix.
- **Action**: removed the `a.Value == ""` sole-form bypass in
  `validateAddressUnimplementedFormsStrict` and the warn validator's
  prefix-only condition, so a sole unsupported/future form (or a non-CIDR
  wildcard) is deterministically strict-rejected and lenient-warned by name.
  Mixed prefix+form entries still reject via the recorded form: modelled
  forms applied to an entry already carrying a value (or a prefix applied
  after a modelled form) are recorded in `UnimplementedForms`.
- **Action**: `mergeAddressNode` no longer returns early on a `description`
  node — children (and nested children under CIDR/description children,
  gated on `len(sub.Children) > 0` classification in `classifyAddressChild`)
  are always inspected; `parseAddressBookEntries` now records hierarchical
  leaf names (`nested.Keys[0]`, `IsLeaf` included) of unknown book stanzas
  into `UnknownBookEntries.Names`/`CollidingNames`.
- **Regression**: `pkg/config/address_forms_15673_test.go` (sole future-form
  and non-contiguous-wildcard strict reject + lenient warn, range expansion
  hier+flat, oversized range, wildcard expansion, dns-name modelled with a
  stubbed resolver incl. ipv4-only/ipv6-only and unresolvable match-none,
  described-node sub-stanzas, unknown-stanza leaf quarantine) and
  `pkg/dataplane/userspace/address_forms_15673_test.go` (wire book rows and
  NAT/capability resolvers publish all prefixes).
