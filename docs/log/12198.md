## Change

- Kept client ownership scoped to each harness's pidfile and target/port/stream tuple; startup, liveness, and cleanup no longer use global `pgrep`/`pkill` matches.
- Added shared smoke verdict logic that captures one JSON log, gates parsed metrics, checks completion and aggregate intervals, then runs the JSON failover oracle once per recorded transition timestamp. Each stream transition receives its own PASS/FAIL cell; failed or missing log capture fails closed.
- Required all-RG node-role predicates for whole-cluster primary/secondary decisions. The active/active split assertions remain redundancy-group-specific.
- Added hermetic multi-transition telemetry coverage and per-harness `--selftest` entrypoints; registered the helper with shell syntax and harness censuses. Updated the result adapter to recognize the shared verdict output.
