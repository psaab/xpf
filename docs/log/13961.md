# 13961: detect unreachable Rust source files

The #13065 conflict merge left `selectors.rs`, `settle.rs`, and `waterfill.rs` in `userspace-dp/src/afxdp/cos/queue_service/` even though `queue_service/mod.rs` no longer declares them. Cargo never compiles or tests these duplicate implementations; they have also missed the later #13063 V_min-skip changes. Removed the dead files rather than re-declaring a second implementation.

Added `scripts/rust-source-census-13961.py`, which walks `.rs` files under the Rust source root, traverses module and literal `include!` references starting from `main.rs` and each `src/bin/*.rs` crate root, and fails with the unreachable paths. `make test` invokes the census through `rust-source-census-13961`. Reopened #13065 for the separate work of restoring its original module split.

Validation:
- RED on pristine master: `python3 scripts/rust-source-census-13961.py userspace-dp/src` failed and named exactly the three queue-service orphan files.
- GREEN after removal: the same command passed with 749 reachable Rust source files from two crate roots.
- `make rust-source-census-13961` invoked the census successfully (the direct script invocation passed immediately before this target invocation).

Risk: The census statically parses Rust module syntax and literal `include!` references; future module-resolution constructs must be added to its resolver.
