# #10286 — related ICMP errors admitted only for NAT'd sessions

## Problem

The flowless `allow-embedded-icmp` path matched a quoted live session through
`try_embedded_icmp_nat_match_from_frame`, but `try_reverse_embedded_icmp_error`
returned `NotHandled` whenever the session had no NAT rewrite. An ICMPv4
Fragmentation Needed or ICMPv6 Packet Too Big quoting a permitted untranslated
flow therefore fell through to the reverse arrival-zone pair and was dropped
by default deny, black-holing PMTUD and traceroute for ordinary un-NAT'd
traffic. A quote without a live session still has to remain ordinary flowless
traffic and be denied by that policy.

## Fix

- Keep the existing embedded-session lookup and per-session error-budget gate
  for both translated and untranslated quotes.
- Let the existing builders queue an untranslated quote unchanged (apart from
  checksum refresh) and mark the queued disposition as RELATED.
- For that RELATED disposition, preserve HA, route, CoS, and output checks,
  but skip only the reverse flowless zone-policy pair. NAT-translated and
  NAT64 queued errors continue through the existing policy gate unchanged.
- Keep queued frames `flow_key = None`, so ICMP errors never seed a session.

## RED -> GREEN proof

The new tests drive the real flowless `poll_binding_process_descriptor` path
with `allow_embedded_icmp`, a default-deny WAN-to-LAN reverse pair, and a live
permitted session:

- v4 Fragmentation Needed RED before the implementation: **0** queued forwards
  (the error was dropped by flowless reverse-pair policy); GREEN afterward:
  **1** prebuilt RELATED forward.
- v6 Packet Too Big RED before the implementation: **0** queued forwards;
  GREEN afterward: **1** prebuilt RELATED forward.
- The unsolicited v4 control with no live session remains denied and recycled,
  proving the new admission is session-gated.

The v4 and v6 GREEN assertions verify the error type/code, unchanged quoted
addresses and source port, client egress, no session creation, no descriptor
recycle, and no policy-deny event. Existing NAT reversal, NAT64 translation,
policy-deny, HA, FabricRedirect, and budget cells remain in the same suite.
