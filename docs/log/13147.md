# #13147 — fail closed for disabled and quarantined tunnel endpoints

- **Action**: prevent disabled tunnels from entering the endpoint snapshot; reject WireGuard early-admission entries without a live zone; scrub tunnel endpoint zone references removed by zone quarantine.

## Red before

On pristine `origin/master` (`662ee842d551fe7bfd02d3bde4159e69196fcae0`), `go test ./pkg/dataplane/userspace -run '^TestTunnelEndpointsDisabledUnzonedQuarantine13147$' -count=1` failed because the disabled GRE tunnel still appeared in `TunnelEndpoints` with zone `vpn`.

## Change

- `buildTunnelEndpointSnapshots` skips endpoints whose interface snapshot is administratively disabled.
- `buildUserspaceWGZoneMaps` requires a nonzero resolved endpoint zone before admitting the listener port.
- `quarantineCollidingZones` clears quarantined zone names from tunnel endpoint snapshots as it does for interfaces.
- Added regression coverage for disabled GRE/WireGuard, unzoned WireGuard admission, quarantine scrubbing, and a healthy zoned WireGuard positive control.

## Validation

- **GREEN**: `go test ./pkg/dataplane/userspace -run '^TestTunnelEndpointsDisabledUnzonedQuarantine13147$' -count=1` passed.
- `go vet ./pkg/dataplane/...` passed.
- `go build ./pkg/dataplane/...` passed.
- Full `go test ./pkg/dataplane/userspace` was run and failed in existing tests `TestContractSnapshotGolden9821`, `TestCapFlagIsWiredEndToEnd9054`, `TestPoisonedZoneOverrideAbsentFromKernelHostInboundView12834`, `TestBareZoneBindOnlyTunnelHostInbound13100`, `TestBareZoneBindOnlyTunnelInheritsPhysicalOverride13100`, `TestSnapshotShapeIsPinnedToProtocolVersion8892`, and `TestGroupOnlyZoneNameDoesNotQuarantineLiveZone12247`. The tests report golden/snapshot drift and unrelated contract assertions; they were not verified against pristine master.

## Risk

Disabled endpoints are omitted at snapshot construction; a zone removed by quarantine becomes empty on any retained tunnel endpoint, and WireGuard admission independently requires a resolvable nonzero zone. Existing enabled, zoned tunnel behavior is covered by the positive control.
