# #12656 — reject silent interface-family policer bindings

- **Issue**: #12656 — `family mpls|any policer input|output` and bindings with no xpf consumer committed without diagnostics.
- **Files**: `pkg/config/compiler_interfaces_unsupported.go`, `pkg/config/compiler_interface_policer_family_12656_test.go`, `debian/changelog`, `docs/log/12656.md`.

## Why

`compileInterfaces` populates interface-family hooks only for `inet` and `inet6`. The existing #10293 guard rejected `policer input|output` only while iterating those two known families. Consequently, policer bindings under `mpls` or `any` were not examined. Flat-set ASTs store the family token and remaining binding tail on the AF node; braced ASTs use a compound `family <af>` node with `policer` children. A packed AF such as `family foo filter input f` likewise evaded the #12090 filter-keyword walk because `foo` was not in its family-token list.

## What

- Reject `policer input|output` under interface families `mpls` and `any` with a #12656 diagnostic naming interface, unit, family, and binding.
- Reject filter or policer input/output bindings packed below an unrecognized family token with a #12656 diagnostic stating that xpf has no consumer for the binding.
- Keep tolerant compile behavior warning-only, following the existing unsupported-interface gate pattern. Existing inet/inet6 bindings and existing filter rejection gates are unchanged.
- Regression tests cover both directions and flat/braced ASTs for `mpls` and `any`, packed unknown-family filter/policer bindings, and a braced unknown-family filter with exactly one warning.

## Validation

- RED: `go test ./pkg/config -run 'TestInterface(UnsupportedFamilyPolicers|UnknownFamilyBindings)Rejected12656' -count=1` failed on all 10 cells because strict compilation accepted the bindings.
- GREEN: the focused regression run passed after the gate was added.
- Related gates: `go test ./pkg/config -run '12090|12091|10293|12656' -count=1` passed.
- Mutants: removing the `mpls` arm made all four mpls cells fail; removing the `any` arm made all four any cells fail; disabling the unknown-family check made both `foo` cells fail. Restored each gate and reran the related gates successfully.
- Full `go test ./pkg/config -count=1` exceeded the 300-second command deadline.

## Risk

Strict commits now reject the reported silent no-op bindings; tolerant loads remain bootable and surface warnings. No dataplane behavior or supported inet/inet6 binding behavior changes.
