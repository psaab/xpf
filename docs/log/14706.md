# #14706 — VRRP recordMasterAdvert learns from rejected lower-priority adverts

## Defect

`recordMasterAdvert` (`pkg/vrrp/instance_rx.go`) was called by
`handleBackupRx`/`handleMasterRx` before any priority decision and
unconditionally overwrote `lastMasterPriority`, `lastMasterSeen`, the
per-family learned master source, and `masterAdverInterval` (floor-clamped
only, wire max 4095 cs = 40.95 s) for every non-zero advert.

Those fields feed `shouldPreemptObservedMaster` /
`preemptingLiveLowerMaster` (`effective > lastMasterPriority`, staleness
from the learned interval), the #10719 unknown-source detector's known
source, and `masterDownInterval()` (Backup watchdog, preempt-hold
staleness, `ResignRG`'s `3*masterDownInterval` safety timeout). A rogue
lower-priority advert after a real priority-200 master therefore:

1. lowered the #2082 sync-hold preempt bar — a Backup(100, preempt) that
   heard Master(200) then one Priority-100 rogue advert passed
   `effective > lastMasterPriority` on sync-hold release (dual-master);
2. refreshed `lastMasterSeen`, keeping the bogus master "live";
3. became the learned master source, so a follow-up priority-255/0
   advert from the same rogue IP was silent to the #10719 detector;
4. inflated `masterAdverInterval` to 40.95 s, stretching the master-down
   horizon to ~122.85 s.

RFC 5798 §6.4.2/§6.4.3 discard a lower-priority advert; the local gate
must only learn from the advert accepted as current master. VRRP has no
authentication, so any L2 speaker can send such adverts.

## Fix

- `pkg/vrrp/instance_rx.go`: `recordMasterAdvert` now records only an
  accepted advert — no retained master, a same-source advert (including
  that master's own demotion), priority >= the retained master's,
  priority-255 (source still subject to the #10719 carve-out), or any
  advert once the retained record is stale under the interval learned
  from that same master (`observedMasterStaleLocked`, lock-held replica
  of the preempt helpers' staleness math). A rejected lower-priority
  advert from a different source returns without touching priority,
  seen-time, source, or interval. The first lower-than-local master is
  still recorded (current master for preempt/hold-time). The learned
  interval is masked to the 12-bit wire field and capped at
  `maxLearnedMasterAdverInterval` (40950 ms, the largest interval the
  advertise-interval normalizer can emit); the #4548 floor is unchanged.
  Source recording is factored into `learnMasterSource` /
  `sameAdvertSource` / `advertSourceFamily` preserving the family and
  priority-255 semantics. NOT changed: `handleBackupRx`/`handleMasterRx`
  election/timer decisions, `warnUnknownMasterAdvert` ordering (still
  before recording), the preempt helpers, or any timer code.
- `pkg/vrrp/instance.go`, `pkg/vrrp/README.md`: comments/docs updated
  from "every non-zero advert" to the accepted-master rule.

## Tests

- `TestRejectedLowerAdvertDoesNotClobberObservedMaster14706`: Backup(100)
  hears Master(200, 1 s, .2), record aged 500 ms, then rogue
  (100, 4095 cs, .3) — priority/source/interval/seen unchanged and
  `shouldPreemptObservedMaster()` stays false.
- `TestRejectedLowerAdvertDoesNotPrimeUnknownSourceDetector14706`: rogue
  Priority-1 advert does not become the learned identity; follow-up
  rogue Priority-255 still counts/warns once.
- `TestRejectedLowerAdvertDoesNotClobberObservedMasterMasterRx14706`:
  same preservation through `handleMasterRx`, state stays MASTER.
- `TestAcceptedMasterLearningPreserved14706` controls: first lower
  master (incl. `preemptingLiveLowerMaster`), same-source demotion,
  higher new master, and stale replacement all still learn.

## Risk

Election handling is untouched; only the retained record's writers are
gated. A held lower master keeps refreshing `lastMasterSeen` because
its first advert is recorded and its repeats are >= the retained
priority (or same-source), so the #4584 watchdog and #2850 hold paths
are preserved. Residual: an accepted advert can still advertise the
wire-maximum 40.95 s interval (now capped, not inflated by rejected
adverts) — that is the RFC-learned cadence of the accepted master.
