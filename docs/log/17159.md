# #17159 — Count per-queue TX ring-full submit stalls on the non-exact CoS submit path

- **Timestamp**: 2026-10-27
- **Action**: `count_tx_ring_full_submit_stall` was called only at the four
  exact direct-service sites in `cos/queue_service/service.rs`.
  The non-exact CoS submit handlers (`submit_local` / `submit_prepared`)
  hold the queue identity (`root_ifindex`, `queue_idx`) and receive a typed
  ring-full `TxRetryReason` (`TxRingInsertFailed` /
  `PreparedTxRingInsertFailed`) on their `Err(TxError::Retry(..))` arms but
  never counted, and `cos/tx_completion.rs` justified the gap with two false
  statements (the handlers do not carry queue identity; Retry failures are
  counted in `tx_submit_error_drops` — a Retry never touches that counter,
  only the Drop arm does).
  Fix (STEP-0 verified live on `origin/master` 3abae28d24: only the four
  exact call sites existed):
  - `userspace-dp/src/afxdp/cos/queue_service/submit_local.rs`: in the
    `Err(TxError::Retry(reason))` arm, when `reason` is
    `TxRingInsertFailed | PreparedTxRingInsertFailed`, call
    `count_tx_ring_full_submit_stall(binding, root_ifindex, queue_idx,
    items.len() as u64)` before restoring items. `items` at that point is
    the full staged survivor set returned by `transmit_batch`, so its
    length is the stalled packet count. No new copy of the duplicated
    ring-commit epilogue: the queue-less `tx/transmit` primitives stay
    untouched and both CoS callers call the single existing helper.
  - `userspace-dp/src/afxdp/cos/queue_service/submit_prepared.rs`: same
    call in the Retry arm (`items` holds the staged survivors).
  - `userspace-dp/src/afxdp/cos/tx_completion.rs`: rewrote the
    `count_tx_ring_full_submit_stall` header comment — removed the false
    "do not carry queue identity" / "`tx_submit_error_drops` instead"
    claims; documented all six callers (four exact sites + the two
    non-exact handlers) and that a Retry never bumps
    `tx_submit_error_drops`.
  - `userspace-dp/src/afxdp/types/cos.rs`: updated the
    `tx_ring_full_submit_stalls` field doc from "exact-drain path" scope
    to both paths.
  - `userspace-dp/src/afxdp/cos/queue_service/tests/submit.rs`: added
    three hermetic guard tests (see Validation).
- **File(s)**: `userspace-dp/src/afxdp/cos/queue_service/submit_local.rs`,
  `userspace-dp/src/afxdp/cos/queue_service/submit_prepared.rs`,
  `userspace-dp/src/afxdp/cos/queue_service/tests/submit.rs`,
  `userspace-dp/src/afxdp/cos/tx_completion.rs`,
  `userspace-dp/src/afxdp/types/cos.rs`, `docs/log/17159.md`.
- **Validation**: STEP-0 on `origin/master` (3abae28d24): `grep
  count_tx_ring_full_submit_stall` found only the four exact sites in
  `service.rs` (162/337/529/698) plus the helper — defect live.
  Named hermetic exact runs only (`cargo test --manifest-path
  userspace-dp/Cargo.toml --bin xpf-userspace-dp -- --exact <full path>`,
  no broad suites):
  - `submit_local_counts_tx_ring_full_submit_stall_on_ring_full` — fills
    the 64-slot test TX ring via a committed prepared batch (never
    reaped), then submits 3 local items; the real `transmit_batch`
    returns `TxRingInsertFailed`. Asserts the typed retry reason, the
    binding-level `dbg_tx_ring_full` premise bump, queue
    `tx_ring_full_submit_stalls == 3`, `tx_submit_error_drops` unmoved,
    and the 3 items restored to the queue head. PASS.
  - `submit_prepared_counts_tx_ring_full_submit_stall_on_ring_full` —
    same ring-full setup, 2 prepared items via `transmit_prepared_queue`
    / `finalise_prepared`. Asserts queue stalls == 2, drops unmoved,
    items restored. PASS.
  - `submit_local_no_free_frame_retry_does_not_count_stall` — negative
    gate: a `NoFreeTxFrame` retry must NOT count (stalls stay 0), so the
    reason gate cannot be widened silently. PASS.
  Mutant check: deleting the `count_tx_ring_full_submit_stall` call from
  both Retry arms makes both positive tests RED on the stall assert
  (0 vs 3 / 0 vs 2) while the negative gate stays green; restoring the
  fix makes all three PASS again. FAIL-ON-REVERT is by assertion, not
  build break (documented in the test header).
