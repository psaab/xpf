# #17238 — route GRE-inner IPv6 through the shared #14954 verdict

- **Timestamp:** 2026-10-27
- **Branch:** `fix/17238-campaign`

## Why

`classify_native_gre_inner_ipv4` called the host-executed `gre_inner_fragment_or_length_rejected` four times, but `classify_native_gre_inner_ipv6` called no `gre_classify` verdict: it hand-rolled a terminal-first-header bail, an inline `l4_span_len > payload_len` check, and its own LAND compare. The v6 host cells executed `gre_inner_classify_allowed`, which rustc reported as never used in production, so a regression in the v6 production checks could not fail any host test. The `gre_classify` doc claimed v6 computed its fragment input from the shared walk (production runs no walk and rejects every non-terminal first header, atomic Fragment included), and the test header described the same wrong composition.

## What

- v6 now calls `gre_inner_fragment_or_length_rejected(eh_class(protocol) != EH_CLASS_TERMINAL, 0, 40 + payload_len, 40, l4_span_len)` — the exact call the fix direction prescribes — replacing the hand-rolled length compare. The verdict is identical for every reachable input (terminal: `40 + payload >= 40 + span` iff `payload >= span`; asserted `payload_len != 0` beforehand; non-terminal: rejected either way; span 0: vacuous either way).
- Added `gre_inner_land(&[u8;16], &[u8;16])` to `gre_classify` and routed both classifiers' LAND compares through it. `rg -c 'src_addr == .*dst_addr' userspace-xdp/src` now totals 1 (the `land` module's outer-packet compare; the inner compare in `gre_classify` is spelled `inner_src_addr == inner_dst_addr`).
- Deleted `gre_inner_classify_allowed` (the unused wrapper). Both remaining `gre_classify` items (`gre_inner_fragment_or_length_rejected`, `gre_inner_land`) have production callers in both classifiers and host execution; rustc reports no never-used `gre_classify` item.
- Corrected the `gre_classify.rs` doc (fragment input is the terminal-first-header bail, not the walk) and the test-header doc (v6 composition, walk leg guards the worker's walk).
- Rewrote the host cells to compose exactly as production: `v4_allowed` = scalar-per-arm + `gre_inner_land`; new `v6_allowed` = jumbogram miss + scalar with v6 constants + `gre_inner_land`, using `eh_class` for the fragment input and `ipv6_declared_end` for the declared end. Added v6 UDP boundary, port-less ESP terminal, NoNext (59, NONEXT) miss, Fragment/Hop-by-Hop miss, and jumbogram rows.
- Regenerated the shim object/manifest/gate-verdict through the verifier gate (source change requires it).
