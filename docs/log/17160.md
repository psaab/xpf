- **Timestamp**: 2026-10-27
- **Action**: aggregate `Clear()`'s release outcomes instead of returning a
  constant nil; delete dead/stub entry points; fold the five open-coded
  "retire a live sender" copies into `retireSenderLocked`.
- **Files**: `pkg/ra/ra.go`, `pkg/ra/sender.go`, `pkg/ra/README.md`,
  `pkg/ra/clear_error_17160_test.go`, `pkg/ra/sender_stop_test.go`,

## Defect live on origin/master (3abae28d24)

- `clearLocked` returned nil on both paths (`return nil` early and at the
  end); per-entry `releaseDrain` failures were only logged, so
  `Manager.Clear() error` was constant nil and the daemon shutdown branch
  `if err := d.ra.Clear(); err != nil` (daemon_run_shutdown.go) was
  unreachable — the #6777 shape left behind in Clear.
- `sender.withdrawAndStop` unused; `sender.stop` test-only (4 test call
  sites); `Manager.WithdrawInterfaces` had no non-test caller;
  `cfgForName` was a stub returning nil, called once in
  `claimGracefulLocked`.
- "Retire a live sender" (delete from `senders` → `drainEntry` tombstone →
  `signalStop`) was open-coded five times in ra.go.

## Change

- `clearLocked` aggregates per-entry `releaseDrain` errors with
  `errors.Join` and returns them; `Clear()` therefore surfaces a failed
  goodbye claimed by a racing graceful Withdraw (the only failure a pure
  Clear can produce). The #6777 retry debt already retained by
  `finishDrainDecision` is unchanged, so a later Apply retries.
- `retireSenderLocked(name, s, mode, goodbyeWanted, restartEpoch)` is now
  the single tombstone-install site for live senders (Apply removal, Apply
  changed-config restart with its #4961 `startIfaceEpoch`, ClearInterfaces-
  WithoutGoodbye, claimGracefulLocked, clearLocked). The WithdrawOnce
  standalone claim (nil sender, `goodbyeClaimed: true`) is a different
  shape and stays inline. `grep -c 'm.draining\[name\] = &drainEntry{'
  pkg/ra/ra.go` is now 0 (the literal lives once, inside the helper).
- Deleted `Manager.WithdrawInterfaces` (no production caller), the
  `cfgForName` stub (its one call site now leaves `e.cfg` nil with a
  comment, exactly what the stub produced), and `sender.withdrawAndStop`.
  `sender.stop` moved to `sender_stop_test.go` (test-only helper).
- The #4961/#8597 cells that exercised the deleted entry point now call
  `withdrawInterfacesForTest`, a test-file helper preserving its exact
  semantics; test names, assertions, and the #4961 per-interface-epoch /
  #8597 supersession contrast are unchanged.
- README updated: removed the `WithdrawInterfaces` API entry, documented
  Clear's joined return.

## Risk

Bounded to pkg/ra lifecycle plumbing. All five folded sites pass the same
fields they open-coded before (restart keeps `startIfaceEpoch`, graceful
sites keep `goodbyeWanted: true`), preserving #2033 claim-once /
held-across-emit and #4961 per-interface fencing. `Clear()` can now return
non-nil at daemon shutdown where it previously could not; the sole caller
already logs that branch as a warning and proceeds with shutdown, so no
behavior changes beyond the warning becoming reachable. Deleting
`WithdrawInterfaces` removes an exported method with no in-tree caller;
out-of-tree callers would fail to compile rather than silently change
behavior.
