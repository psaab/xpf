# #16141 — CoS string types + tunnel-mode consts

- **Timestamp**: 2026-10-24
- **Issue**: W2.12 part B (data-model P9a + P9c-consts). Seven bare
  `LossPriority string` decls (six in `types_cos.go`, one on
  `FirewallFilterTerm`), bare scheduler `Priority string`, and
  `TunnelConfig.Mode string // "gre" or "ipip"` (stale comment — the
  real schema set is `TunnelModeNames={gre,ip6gre,wireguard}`).
- **Change**:
  - `pkg/config`: new string-underlying types with consts —
    `LossPriority` {Unset, Low, MediumLow, MediumHigh, High} with
    `Valid()`, `SchedulerPriority` {Unset, Low, MediumLow,
    MediumHigh, High, StrictHigh} with `Valid()`, and `TunnelMode`
    {Unset, GRE, IPIP, IP6GRE, WireGuard}. Fields retyped on all six
    CoS entry structs, `FirewallFilterTerm.LossPriority`,
    `CoSScheduler.Priority`, and `TunnelConfig.Mode` (stale comment
    fixed). Uint8 enums rejected (numeric JSON / #11798 marshal-slip
    class); AddrFamily enum deferred; TunnelConfig struct split
    rejected (applied record built by the daemon) — pinned by a
    reflection test that Key/TTL/MTU/RIListMember/WgPeers stay.
  - Writers migrated compiler-first: CoS compiler (7 loss sites +
    scheduler priority), firewall compiler (both `loss-priority`
    spellings), interface/tunnel compilers (typed defaults
    gre/ipip, `TunnelMode(v)`), flat-run tunnel reader.
    `TunnelModeNames` is now derived from the consts so the schema
    list cannot drift from them.
  - Validators retyped: `cosLossPriorityValues`/`cosSchedulerPriorityValues`
    keyed by the typed values; `CoSSchedulerPriorityValid` delegates
    to `SchedulerPriority.Valid()`; tunnel validators/readers
    compare against the consts across pkg/config, pkg/routing
    (`buildKernelTunnelLink`, `needsIP6GREEncapLimitNone`),
    pkg/dataplane, pkg/daemon.
  - Snapshot boundary keeps plain strings: `string(...)` conversions
    in `pkg/dataplane/userspace` (cos.go, interfaces `tunnelModeOf`,
    tunnels.go) and format renderers, so wire JSON is unchanged.
- **Validation**:
  - New decisive file `pkg/config/cos_tunnel_typed_16141_test.go`:
    field-by-field marshal-diff vs pre-change bytes (incl. empty
    defaults), pre-change payload round-trip, reflection type pins
    for all 9 fields + no-split pin, `Valid()` typo rejection,
    compiler-writes-constants (CoS high/strict-high, tunnel
    ip6gre typed, ip-* default stays `TunnelModeIPIP` on lenient).
  - `snapshot_shape_version_8892_test.go`: digest/golden unchanged —
    v70 STANDS ledger entry added (measured, not argued).
  - `go build ./...` and `go vet ./...` clean; `pkg/routing` and
    `pkg/firewallshow` suites pass.
- **Risk**: Low (maintenance). Wire JSON unchanged (string
  underlying types); empty-string defaults preserved; fail-closed
  strict gates and tolerant downgrades keep their exact behavior,
  now typed.
