# #15785 — OpenStack config-2 / Cloud-Init cidata day-0 config drives

G25-04: `scripts/image/xpf-day0-config` probed only `LABEL=xpf-config` +
`TYPE=iso9660` and tried only `xpf.conf`/`juniper.conf` at the volume
root, so OpenStack `config-2` / Cloud-Init `cidata` vfat config drives
and the vSRX cloud paths were undiscoverable. Worktree
`fix/15785-campaign`, base `origin/master f7c921ce29`.
