# #12848 — Preserve dotted lifeline interface identity

`LifelineBaseName` previously truncated at the first dot, so a configured lifeline
`hb.1` was keyed as `hb` and unrelated dotted siblings could inherit its
host-inbound deny exemption. `HostInboundLifelineSet` now retains declared
interface names, including ordinary names as non-lifeline precedence markers.
Matching gives exact/longest declared names priority and recognizes only one
valid logical-unit suffix. This prevents both a lifeline `hb.1` from promoting
`hb.2` and a lifeline parent `hb` from promoting a separately declared ordinary
`hb.1` (or its units); malformed multi-dot suffixes do not inherit the parent's
role.

`HostInboundLifelineIngressNetdevs` also includes configured unit-less lifeline
interfaces so the daemon's gap fence has the same ingress coverage as lifeline
address withholding. The gap list adds a bare physical netdev only when its
interface has no units; a unit-bearing interface contributes only its lifeline
unit netdevs.

- `go test ./pkg/config ./pkg/dataplane/userspace -run 'Lifeline.*12848' -count=1`
  failed: `hb.1` promoted `hb`, `hb.2`, `hb.10`, and `ge-0/0/0.200`; the
  ingress-netdev list omitted the unit-less `hb.1` lifeline.

GREEN after the fix:

- `go test ./pkg/config ./pkg/dataplane/userspace -run 'Lifeline.*12848|BuildZoneHostInboundViewsDoesNotPromoteDottedSiblings12848' -count=1`:
  passed after declared-name precedence and unit-suffix validation were added.
- `go test ./pkg/daemon -run '^TestCompiledDottedLifelineOwnershipAndGapFence12848$' -count=1`:
  passed. This strictly compiles a config with distinct dotted interface
  declarations, a unit-less dotted control link, a unit-qualified dotted fabric
  link, and ordinary dotted siblings. The production userspace view builder
  feeds the rendered host-inbound deny fence; it retains sibling addresses but
  excludes the configured fabric address. The production ingress-netdev builder
  yields Linux names `fxp0`, `ge-0-0-0.100`, and `hb.1`; the rendered gap fence
  scopes the shared-address exception to those lifelines, not the sibling names.
- `TMPDIR=/home/ps/g go test ./pkg/dataplane/userspace -count=1`: passed in
  197.646s.
- Regressions verify both collision directions, reject malformed
  `hb.2.0`/`hb.2.bad` when only `hb` is a lifeline, check rendered lifeline
  markers and host-inbound deny-view ownership, and verify ingress-netdev
  inclusion/exclusion behavior.
