# #15278 — NAT cohort: NAT64 pre-pass abort, undefined interface/RI scopes, hierarchical static target RI, bare second pool (D02-01..D02-04)

- **Timestamp**: 2026-10-19
- **Action**: close four MATERIAL config defects in one cohort.

## Why

- D02-01: NAT64 rule-set with no `prefix` passed strict commit, then `compileNAT64` in the #4960 pre-pass/real pass returned invalid-CIDR and aborted every dataplane compile.
- D02-02: NAT rule-set `from/to interface` and `from/to routing-instance` scopes naming undefined interface/RI committed clean, leaving the rule-set inert with no signal (#12245 zone axis only covered zones).
- D02-03: static-NAT translation-target `routing-instance` nested under hierarchical `prefix { }` / `prefix-name { }` lost its #4292 accepted-only advisory (and `show security nat static` annotation via `ThenRoutingInstance`).
- D02-04: #7013 residual — second NAT pool written as bare value (`pool A B`, `pool [ A B ]`, `pool { A; B; }`) committed clean and silently resolved to A, even when B undefined.

## What

- `pkg/config/compiler_validate_strict_nat.go`: `validateNAT64PrefixStrict` now rejects empty prefix (strict) / warns (lenient) naming the rule-set; new `validateNATUndefinedScopeStrict` + offenders + `NATUndefinedScopeRuleSetNames` for source (from/to), destination (from), static (from) interface/RI scopes. Interface defined = configured logical unit, lo0.0, materialized secure-tunnel unit, or implicit tunnel unit 0; RI defined = `default` or a configured `routing-instances` entry.
- `pkg/config/compiler_uniformgates.go`, `compiler_opts.go` (`lenientNATUndefinedScope`), `types.go` (`LenientNATUndefinedScopeRuleSets`): wire scope gate dead-last after zone gate; tolerant warns per offender and records rule-sets.
- `pkg/dataplane/compiler_nat.go`: `compileNAT64WithStaging` warn-skips empty-prefix rule-set on both passes, mirroring `buildNAT64Snapshots`.
- `pkg/config/compiler_nat_static.go`: RI extraction also scans target child's children (grandchildren) for `routing-instance` (child FindChild + grandchild Keys/Name), covering `prefix { <ip>; routing-instance VR; }` and `prefix-name { <name>; routing-instance VR; }`.
- `pkg/config/compiler_nat_then_occurrences_7013.go`: `scanRun` counts a bare non-keyword token right after a consumed pool value as a further pool (keywords pool/off/interface/persistent-nat excluded); `addPoolNode` counts further leaf children in `pool { A; B; }` and bare flat-set child `pool PD` -> `PD2`.
- Tests: `pkg/config/nat_cohort_15278_test.go` (new), `pkg/dataplane/nat64_no_prefix_15278_test.go` (new); fixture updates in `compiler_nat_scope_3079_test.go` (define scoped interfaces/RIs), `compiler_nptv6_scope_reject_5818_test.go` (define scoped interface/RI so #5818 gate keeps priority), `compiler_nat_pool_overlap_5144_test.go` (empty-prefix overlap predicate now exercised leniently, strict rejection asserted).
