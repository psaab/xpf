# #13181 — preserve shared-ifindex egress and zone RG state

## Why

`populate_egress` keyed runtime egress state by Linux ifindex but overwrote the full entry for every snapshot row. Shared-ifindex units could therefore erase an earlier row's primary address family or silently replace its redundancy-group owner. Separately, `populate_zone_to_rgs` used `ifindex_to_zone_id`, which includes inherited trunk-parent ingress aliases, and inspected only the single last-written egress row. That could omit member RGs or attribute an unzoned parent RG to a child zone.

## What

- Merge primary IPv4/IPv6 values across shared-ifindex rows instead of clearing a previously collected family.
- Reject snapshots where one runtime ifindex carries conflicting nonzero redundancy groups, rather than choosing an arbitrary HA owner.
- Build `zone_to_rgs` only from consistent snapshot member rows whose egress-zone ledger confirms the row zone, excluding inherited parent aliases and unzoned shared-index aliases.
- Add regressions for shared-ifindex address merging, all member RGs, inherited-parent exclusion, conflicting RG/MTU/VLAN rejection, unzoned aliases, and missing egress-zone ledger entries.

## Validation

- RED on pristine `origin/master`: the historical combined regression, then named `shared_ifindex_units_merge_primaries_and_zone_rgs_13181`, failed because IPv4 primary was `None` instead of `Some(10.0.0.1)`; the parent-inheritance control passed on master.
- GREEN: `cargo test forwarding_build::tests` passed (232 tests); `cargo test iface_tunnel` passed (4 tests); `cargo test stamped_fabric` passed (30 tests).
- A full `cargo test` attempt before the final compatibility fixes reported 7,861 passed and 60 failed (8 ignored). It exposed four interface-tunnel primary-address conflicts and four stamped-fabric fixture failures; the tunnel guard and fixture ledger were corrected, then all related focused suites passed. The full suite was not rerun after those fixes.
- Earlier `cargo clippy -- -D warnings` reported four lints in untouched `build.rs`; `cargo fmt -- --check` reported repository-wide formatting differences.

## Risk

The change is limited to forwarding-state construction. Snapshots with conflicting nonzero HA ownership or incompatible egress attributes on one admitted runtime ifindex are rejected rather than installing order-dependent state; absent address families and unknown MTUs merge without erasing known values.
