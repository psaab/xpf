# #13181 — preserve shared-ifindex egress and zone RG state

## Why

`populate_egress` keyed runtime egress state by Linux ifindex but overwrote the full entry for every snapshot row. Shared-ifindex units could therefore erase an earlier row's primary address family or silently replace its redundancy-group owner. Separately, `populate_zone_to_rgs` used `ifindex_to_zone_id`, which includes inherited trunk-parent ingress aliases, and inspected only the single last-written egress row. That could omit member RGs or attribute an unzoned parent RG to a child zone.

## What

- Merge primary IPv4/IPv6 values across shared-ifindex rows instead of clearing a previously collected family.
- Reject snapshots where one runtime ifindex carries conflicting nonzero redundancy groups, rather than choosing an arbitrary HA owner.
- Build `zone_to_rgs` from consistent snapshot member rows, corroborating any populated egress-zone ledger and excluding inherited parent ingress aliases.
- Add regressions for shared-ifindex address merging, all member RGs, inherited-parent exclusion, conflicting-RG rejection, and the same-RG positive control.

## Validation

- RED on pristine `origin/master`: `cargo test shared_ifindex_units_merge_primaries_and_zone_rgs_13181 -- --nocapture` failed because IPv4 primary was `None` instead of `Some(10.0.0.1)`; the parent-inheritance regression passed on master as a positive guard for the existing behavior.
- GREEN: `cargo test forwarding_build::tests` passed (229 tests). Full `cargo test` completed with 7,918 passed and one unrelated `protocol::tests::wire_invariant_default_specimens` fixture-drift failure (8 ignored); no forwarding-build regressions failed.
- `cargo clippy -- -D warnings` stops on four lint errors in `build.rs`, which this change does not modify. `cargo fmt -- --check` reports repository-wide formatting differences.

## Risk

The change is limited to forwarding-state construction. Snapshots with conflicting nonzero HA ownership on one ifindex are now rejected, preserving the prior live forwarding state; ordinary shared-ifindex rows with matching or zero RG values retain one merged egress entry.
