## Member 1: overflow as an executed oracle

`make test-rust` ran tests only with `--release`, where `overflow-checks` is off, so a wrap failed a test only if the test asserted the exact wrapped value.

### Measurements (worktree `fix/9499-rust-overflow-miri-gates`, based on `fbc51cc02`)

- **Whole suite with overflow checks** (`CARGO_PROFILE_RELEASE_OVERFLOW_CHECKS=true cargo test --release --bins --tests`): 11 result lines, 5877 passed, 0 failed. No existing test wraps.
  - A first attempt with `RUSTFLAGS="-C overflow-checks=on"` failed to link with `duplicate symbol: crc32`. `RUSTFLAGS` replaces `userspace-dp/.cargo/config.toml`'s `rustflags` and so drops its `--allow-multiple-definition` link argument. Use the profile variable, not `RUSTFLAGS`.
- **Debug-profile filtered leg** (`cargo test --bins --tests -- --test-threads=1 frame nat session checksum`): build 213 s cold, run 65 s, 2489 passed, 0 failed.

### The planted mutant

No deterministic test drove a sequence-number `wrapping_add` across `u32::MAX`; only a proptest strategy weights toward it. The new cell `reject_rst_v4_for_syn_at_seq_max_wraps_ack_to_zero_9499` sends a SYN with `seq = u32::MAX` into `build_reject_rst_frame` and asserts the RST `ack` wraps to 0.

The mutant is `parsed.seq.wrapping_add(seg_len)` changed to `parsed.seq + seg_len` in `afxdp/frame/tcp.rs`:

| run | result |
|---|---|
| A: `--release`, original | cell ok |
| B: `--release`, mutant | cell **ok**, because the unchecked `+` wraps to the same value |
| C: `--release` with overflow checks, mutant | cell **FAILED**, `attempt to add with overflow` |
| E: `--release` with overflow checks, original | cell ok |
| debug filtered leg, mutant | cell **FAILED**, `attempt to add with overflow` (2484 passed, 1 failed, 90 s incremental) |

The file was restored after each run and verified equal to HEAD.

### Choice of leg

A second `--release` build with overflow checks costs a full optimised compile on every fresh worktree. The debug-profile leg gives the same oracle for the named modules (the issue's first remedy option), with debug assertions on as well, for about 4.5 minutes cold. It is filtered to `frame nat session checksum` and carries a comment to widen the filter rather than drop the leg.
