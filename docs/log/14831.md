# Stop the session-miss TE arm double-queueing TE + Live forward (#14831)

- **Issue**: #14831 (found while implementing #14643).
- **Cause**: On the session-miss arm in
  `userspace-dp/src/afxdp/poll_descriptor/mod.rs`, when
  `build_local_time_exceeded_request` successfully built a Prebuilt
  Time Exceeded for a TTL=1/hop-limit=1 packet, the arm rolled back
  the source-NAT and NAT64 allocations, pushed the prebuilt request
  onto `scratch_forwards`, and set `recycle_now = false` — but then
  fell through to the trailing Live-forward tail. That tail checks
  only the forwarding disposition (`ForwardCandidate`), so it counted
  the packet as forwarded (`dbg.forward`, `forward_candidate_packets`,
  per-zone traffic), built a second `Live` forward request via
  `build_live_forward_request_from_frame`, queued it on
  `scratch_forwards`, and reached the flow-cache seed tail. The Live frame was
  only refused later at rewrite for TTL<=1, so there was no wire leak,
  but the packet occupied TX queue state and was accounted as a
  forward. `recycle_now = false` only suppresses the UMEM recycle
  epilogue; it does not consume the descriptor. The flow-cache sibling
  returns `FlowCacheOutcome::Consumed` and the session-hit TE arm
  `continue`s; the miss arm did neither.
- **Change**: After queueing the prebuilt TE on the miss arm, `continue`
  to the next descriptor, mirroring the session-hit TE arm. The queued
  reply retains sole ownership of the original descriptor's recycle;
  neither the Live-forward tail nor the recycle epilogue runs.
  No session install, no flow-cache
  seed, no Live forward, no forward accounting for the consumed
  packet. The suppressed-TE arm (#14643) and all non-expiring packets
  are unchanged.
- **Regression coverage**
  (`userspace-dp/src/afxdp/tests_txn_flow_cache.rs`):
  new `txn_ttl1_buildable_te_queues_no_live_forward_14831` drives the
  real descriptor path (`txn_run_descriptor_checked`, nat_snapshot
  with pool SNAT, ifindex 24) with a fresh TE bucket and a TTL=1 TCP
  SYN, asserting exactly one queued request and that it is
  `PendingForwardFrame::Prebuilt`, zero `Live` requests,
  `dbg.forward == 0`, `dbg.tx == 0`, no sessions, and a fully
  rolled-back SNAT pool. The #14643 control in
  `txn_ttl1_suppressed_te_installs_no_session_14643` is also
  strengthened to assert no `Live` request and exactly one queued
  request on its buildable-TE control (replacing the stale
  out-of-scope comment).
- **RED evidence**: With the production change reverted, both the new
  #14831 cell and the strengthened #14643 control fail at
  `buildable TE must not also queue a Live forward`: actual Live count
  1, expected 0. Command: `cargo test --manifest-path
  userspace-dp/Cargo.toml --bin xpf-userspace-dp txn_ttl1 --
  --test-threads=1` (0 passed, 2 failed).
- **GREEN evidence**: With the fix restored, both TTL regression cells
  pass, along with the existing flow-cache TTL/accounting tests.
  `cargo test --manifest-path userspace-dp/Cargo.toml --bin
  xpf-userspace-dp afxdp::tests_txn_flow_cache:: -- --test-threads=1`
  reports 52 passed, 4 failed. The four failures are unrelated flowless
  DNAT cells, reproduced with this production fix reverted:
  - `flowless_dnat_fragment_cold_missing_neighbor_parks_translated_12905`
  - `flowless_non_first_fragment_dnat_off_precedence_stays_fail_closed_11435`
  - `flowless_non_first_fragment_dnat_vip_forwards_translated_11435`
  - `flowless_static_snat_candidate_does_not_preempt_address_dnat_11435`
  Baseline attribution used the same command with filter
  `afxdp::tests_txn_flow_cache::flowless_` (14 passed, same 4 failures).
- **Build prerequisite**: Base `13905b0650` has two stale allocator call
  sites fixed separately by #14802. All executed tests above used its
  corrected zone arguments in `policy_revalidation.rs` and the trailing
  scope argument in `nat/tests_det_flip_14625.rs`, temporarily applied
  for compilation and removed before commit. Those changes are not part
  of this PR. Re-run the transaction tests after integrating #14802.
  Test environment: `TMPDIR` and `GOTMPDIR` =
  `/var/worktrees/.cache/go-tmp`, `GOCACHE` =
  `/var/worktrees/.cache/go-build`, `CARGO_TARGET_DIR` =
  `/var/worktrees/.cache/cargo-14831`. No live dataplane probe was run.
- **Blast radius / risk**: Only buildable-TE packets on the
  session-miss ForwardCandidate arm change behavior: they now queue
  exactly the prebuilt TE instead of TE + Live. The Live request was
  always refused at rewrite, so no wire-visible forwarding is lost.
  Session-hit, flow-cache-hit, suppressed-TE, and all other miss-arm
  packets are untouched.
