# Issue #17156 — server module docs describe a structure that no longer exists

- **Issue:** Fifteen files under `server/handlers` and `server/helpers` (plus `lifecycle.rs`) still claimed their bodies were byte-identical to the pre-#1345 / pre-#6234 split sources, the `handlers/mod.rs` header listed an outdated dispatcher shape, and `server/README.md` said in the present tense that `sync_session` dispatches through the same `Arc<Mutex<ServerState>>` — false since #7209 (a7729e8daa) moved it off-lock and #9629 added the session-socket fast paths.
- **STEP-0 (defect live on origin/master `946d575fc4`):** `grep -rn 'byte-identical|byte-for-byte' userspace-dp/src/server` returned the 15 header claims (handlers: binding, forwarding, ha, inject_packet, neighbors, queue, rebind, session_deltas, snapshot, stop_workers, sync_session, mod.rs; helpers: mod, persistence, session_sync, status) plus `lifecycle.rs`; `grep -n '7209|9629|off-lock' server/README.md` had no off-lock subsection; `grep -rn 'dispatches through th' userspace-dp/src/server` hit `handlers/mod.rs:271`, `helpers/planning.rs:80`, and `tests.rs:5351`.

## What

1. Replaced every byte-identity header claim with a plain provenance note ("split out of handlers.rs in #1345" / "#6234 split …") with no identity claim: the 11 per-verb handler files, `helpers/mod.rs`, `helpers/persistence.rs`, `helpers/session_sync.rs`, `helpers/status.rs`, and `lifecycle.rs`.
2. Rewrote the `handlers/mod.rs` header as an accurate phase list — decode, the off-lock session verbs (#7209 `sync_session`, `list_sessions_by_policy`, #9629 session `ping`/`update_ha_state`, session-socket refusal), the locked match (including inline `scheduler_heartbeat`, `fib_dump`, `clear_flood_counters`, `clear_filter_counters`), the deferred waits, encode/flush, then persist — and fixed the stale inline comments at the old L157/L235/L263-271/L276 (`handle_request` → `handle_stream`, removed the "dispatches through this same mutex" clause).
3. Rewrote the README #5862 bullet in the past tense (and `handle_request` → `handle_stream`), and added a #7209/#9629 bullet naming `sync_session`, `list_sessions_by_policy`, session `ping`, and session `update_ha_state` as served without the `ServerState` mutex.
4. Applied the same past-tense fix to the identical stale clauses in code comments: `handlers/binding.rs`, `handlers/forwarding.rs`, `handlers/queue.rs` settle-wait blocks, `handlers/sync_session.rs` ("used to dispatch"), `helpers/planning.rs`, and `server/tests.rs` (two doc blocks + assert message), so no present-tense mutex claim remains.

No runtime code changes; comments and docs only.
