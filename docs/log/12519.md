# PR #12587 — pin 9812 kernel leg to text output

## Why

An inherited `GOFLAGS=-json` makes `go test -v` emit JSON output records.
The 9812 kernel leg scans for plain-text `=== RUN` lines, so it reported
its four kernel cells as not run.

## What

The kernel leg passes `-json=false` to `go test`. Its probe now checks the
flag in the actual `go` argv using a fake executable that exits 23 when the
flag is absent. The probe unsets `GO` before using fixture PATHs, preventing
an inherited absolute path from bypassing that fake. The source-grep guard
is removed; the seven-fixture count and surrounding descriptions are current.

## Validation

- Probe file: 7/7 passed, including with inherited `GO=/bin/false`.
- M1 (pin removed): RED, 6/1. M2 (pin moved to a comment): RED, 6/1.
- M3 (flag reordered): GREEN, 7/7.
- The leg passed all four named kernel cells with `GOFLAGS=-json`,
  `GOFLAGS=-json=true`, a `GOENV` file setting `GOFLAGS=-json`, and plain
  settings.
- `bash -n` and `git diff --check` passed. gofmt/vet are not applicable
  to these shell-only changes.

## Risk

Routing test behavior is unchanged. Hosts without usable netns capability
retain the existing SKIP (77) behavior. R1 is a separate exposure filed by
the parent: `test-memlock-guards` and `test-shim-run` scan `^=== RUN`
without `-json=false`, so 26 and 48 cases respectively falsely report
did not run under `GOFLAGS=-json` (false-red direction).
