# #19196: whole-lane idle sweep for the test runners

- **Why**: lanes were never reclaimed, and the "6 h sweep" did not exist.
  udp:xpf-testrunner4 reached 100% (62 lanes) and udp3 99% on 2026-11-17,
  and a Go link failed with ENOSPC (a VOID control in #19185). team-lead
  removed 51 stale lanes by hand and specified this fix.
- **Action**:
  - `scripts/runner-lane-sweep.sh` (installed as
    `/usr/local/sbin/xpf-lane-sweep`). For each `/work/<lane>`:
    - remove it only if nothing under it, at any depth, changed for
      `--idle-s` (6 h): one `find -newermt`, so the NEWEST file decides;
    - AND no process has its cwd or an open fd at or under it (every
      `/proc/*/cwd` and `/proc/*/fd/*`);
    - skip symlinks, non-directories and lanes with a mount point;
    - rename aside, re-check users under the new name (renaming back if one
      appeared), then `rm -rf --one-file-system`;
    - log to stdout (journal) and `/var/log/xpf-lane-sweep.log`.
    - `--lane <name> --idle-s 0` handles one lane with no idle requirement,
      but still checks users.
  - `scripts/provision-testrunner.sh` (every scope) pushes the script and
    writes `xpf-lane-sweep.service` (oneshot, nice 19, idle IO) and
    `xpf-lane-sweep.timer` (OnBootSec=15min, OnUnitActiveSec=1h), then
    enables the timer.
  - `scripts/vm-test-run.sh --cleanup-on-success`: after a command that exits
    0, it runs the sweep for that lane as root on the runner. A failing run
    keeps its lane and says so.
  - `scripts/run-selftests.sh` registers the new selftest; `docs/testing.md`
    documents both.
  - Stacked on #19080's `--with-git` commit (`02afca2ed8`), which also
    changes `vm-test-run.sh`.
- **Validation** (udp:xpf-testrunner2 via `scripts/vm-test-run.sh`):
  - `runner-lane-sweep-selftest.sh` **9/0** on a fake /work: active kept,
    idle removed, a lane idle except one deep new file kept, a cwd user kept
    and an fd user kept (both named in the log), a symlinked lane skipped
    with its target intact, nothing left aside.
    - `--lane --idle-s 0` removes a free lane and keeps a used one.
    - Five mutants KILLED: no cwd check, no fd check, no idle check, a
      top-level-only age, symlinks followed.
  - `provision-testrunner-selftest.sh` 11/0: the new cell checks the units.
  - `vm-test-run-selftest.sh` 76/0, with four new cells: cleanup after
    success, a failing command keeps its lane with its status, a used lane
    is kept, and the "cleanup on any status" mutant.
  - shellcheck clean.
  - Fixed during validation:
    - the sweep selftest's background users inherited a
      command-substitution pipe, so each cell waited 300 s;
    - a `wait` on a killed holder returned 143 under `set -e`;
    - a mutant copy could not find the sweep beside it.
- **Not done here:** installing it on the live runners. After landing, run
  `scripts/provision-testrunner.sh --runner <r> --toolchains-only` per runner.
