# Issue #9736: routing-instance leaf arity

## Result

Routing-instance leaves that consume a fixed number of values now reject packed
trailing tokens before commit or direct compilation can silently discard them.
The check covers brace-elided, true one-line-braced, and flat `set` statements.

The accepted `vrf-target` grammar is explicit rather than a blind keyword walk:
plain target values, a single `export`/`import` target, hierarchical blocks,
bracketed target lists, repeated statements, and equivalent `set` spellings
remain valid. Packed block headers such as `vrf-target junk { target:65000:1; }`
and bracket directions without targets are rejected. The `routing-options` body
remains the deliberate open-world boundary, including `bogus-kw`.

## Implementation

- `pkg/config/schema_routing.go` declares the RI fixed-value leaves and attaches
  AST-aware validators to `description`, `route-distinguisher`, `vrf-target`,
  and `vrf-table-label`.
- `pkg/config/schema_walk.go` adds an AST-node validator hook. It supplies the
  resolved parent schema so the validator can reuse #9792's exact declared-leaf
  ownership predicate without creating a schema initialization cycle.
- `pkg/config/compiler_routing_children_9323.go` extends the existing
  routing-instance closed-world prewalk to inspect declared fixed-arity leaves,
  while preserving the #9323 first-keyword and #9814 typed `instance-type`
  verdicts.
- `pkg/config/schema_routing_instance_9736.go` contains the RI grammar
  validators and defers only fully declared nested leaf runs owned by #9814.
- `pkg/config/leaf_run_differential_gate_9156_test.go` keeps node-validated RI
  leaves out of the untyped-head inventory.
- `pkg/config/routing_instance_arity_9736_test.go`,
  `pkg/configstore/routing_instance_trailing_tokens_9736_test.go`, and
  `pkg/configstore/routing_instance_block_list_9736_test.go` provide direct
  compiler/schema, SetPath, block/list, and CheckText parity coverage.
