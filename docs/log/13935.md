# #13935 — reverse session-matched ICMP errors without the optional knob

- **Timestamp**: 2026-10-16
- **Base**: `master` `19186da9d` (test baseline `ad0ded0df`)
- **Action**: Remove the default-off `allow_embedded_icmp` gate from same-family
  flowless ICMP-error reversal. The reversal still requires a matching live
  session; misses continue through normal flowless enforcement.

## Change

- Classify same-family ICMP errors without consulting `allow_embedded_icmp`
  before calling the shared session-matching reversal path, covering both
  IPv4 and IPv6.
- Extend the existing real flowless poll-path SNAT PMTUD fixture to exercise
  the default-off setting and assert the reversed forward reaches the client.
- Keep unmatched packets on the existing flowless enforcement path.
