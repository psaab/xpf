# #19040: scratch defaults must honour a set TMPDIR

- **Timestamp**: 2026-11-17 (G5)
- **Action**: Verified on tcp:xpf-testrunner3 as the `runner` user (TMPDIR
  set by `vm-test-run.sh`, no `/var/worktrees`). At master `06c743e22e`:
  - `debug-leg-census-selftest.sh` failed 13 of 14 cells (`mkdir:
    cannot create directory '/var/worktrees'`, then fixtures written to
    `/`);
  - `make test-ha-assurance-lib` failed ("valid interval no VOID");
  - `scratch-pinning-selftest.sh` failed, among other things, on "cannot
    create scratch dirs" and the long canary root.
  The cause is the #14833 pin (99e8f3f26d): sites ran
  `mkdir -p /var/worktrees/.cache/tmpdir` unconditionally, and some forced
  `TMPDIR=/var/worktrees/.cache/tmpdir mktemp`, overriding the lane's
  TMPDIR.
- **Action**: One rule for the whole class: create the workstation default
  only when `TMPDIR` is unset, and never override a set one.
  - Shell sites (13 files: the debug-leg, dist, docs, go-test-json and
    mutate selftests, grow-root, miri-leg, mutate, refactoring-audit-refresh,
    and the userspace HA / native-GRE validation scripts) use
    `{ [ -n "${TMPDIR:-}" ] || mkdir -p /var/worktrees/.cache/tmpdir; } &&
    mktemp …`, and `TMPDIR="${TMPDIR:-/var/worktrees/.cache/tmpdir}"` where
    one forced it.
  - `run-selftests.sh`'s `sh -n` leg writes its stderr under TMPDIR.
  - The Makefile recipes (`audit-structs`, `audit-check`,
    `cos-fairness-eval`) use the exported `$$TMPDIR`.
  - 13 sites already used the guarded form.
- **Action**: Census. `scratch-pinning-selftest.sh` now fails on any tracked
  shell or Makefile line that creates the default or forces `TMPDIR` to it
  without the TMPDIR-unset guard on the same line. Its own scratch-root
  creation is guarded the same way (TMPDIR / GOCACHE / CARGO_TARGET_DIR),
  and its long canary root sits under TMPDIR when set. It is still 139
  octets, over the 107-octet bound.
- **Action**: The other reds that kept `scratch-pinning-selftest.sh` red, in
  the same scratch class:
  - **Stale check, proven:** "Makefile CARGO_TARGET_DIR default missing".
    #18839 (cd42a4572d) moved the literal behind `CARGO_TARGET_DIR_SHARED
    := /var/worktrees/.cache/cargo` with the same value. The check now
    reads the effective default through make, with the variable unset.
  - `go-test-json-selftest.sh`: three `${TMPDIR:-/tmp}` defaults now
    default to `/var/worktrees/.cache/tmpdir` (created at the top when
    TMPDIR is unset).
  - Five COS/fairness recipes made their artifact dirs under a hardcoded
    `/tmp`. The audit had excused them only because an earlier forced
    `TMPDIR=` line in the Makefile set its "pinned" flag, and this change
    removed that line. They now use `$$TMPDIR`.
