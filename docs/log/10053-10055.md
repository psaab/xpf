# Issues #10053, #10054, and #10055 — group merge fixes

## Context

The complete bodies and all comments for #10053, #10054, and #10055 were read before implementation. All three issues were open with no comments; none withdrew, narrowed, marked the defect shipped, or contradicted the requested change.

The three defects share the group-merge expansion path but have independent revert-safe fixes:

- #10053 loses per-member contributor ownership when nested groups union a leaf-list. `apply-groups-except` then excludes or retains the entire union instead of the members contributed by the excluded group.
- #10054 consumes a nested `<*>` group wildcard while an inner group is pre-expanded. The wildcard is copied into an empty intermediate clone and later pruned, so it never fans out against real destinations.
- #10055 treats a valid bracketed multi-value tail on a packed group leaf as an unexpandable tail. Packed-leaf promotion therefore bails and drops the group's higher-priority value.

## Change

### #10053

- Added parallel per-member contributor metadata for flattened leaf-list values, including collapsed `Keys` values and child-node values, with quote and bracket masks kept aligned.
- Preserved metadata through node cloning and leaf-list union. Duplicate members union their group ownership; uncertain inline/authored ownership remains conservative and survives group exclusion.
- Filtered leaf-list members before node adoption or union so nested `apply-groups-except` removes only members owned solely by an excluded group.

### #10054

- Added a nested-expansion mode that defers wildcard destination matching while an inner group is being pre-expanded.
- Kept #9862 contributor exclusion pruning active before a wildcard is carried outward.
- Retained normal direct wildcard matching and #9802 unmatched-wildcard/empty-shell pruning once real destination nodes are available.

### #10055

- Made packed-tail consumption recognize a contiguous bracketed run as one schema-valid multi-value leaf tail.
- Kept the existing bailout for genuinely unexpandable shapes, including an unbracketed leftover token after a multi-value leaf.
- Preserved inline-peer precedence and the existing packed-leaf fallback behavior.
