# Issue #15714: elided-container descendant delete/deactivate

- **Timestamp**: 2026-10-19
- **Problem**: `deletePath` (`pkg/config/ast_edit.go`) removed the whole node returned by `findElidedNodeForPath` whenever the remaining path was a prefix of that node's packed `Keys`, and `setInactiveAtPath` toggled the whole node when the path exactly exhausted those keys. For a brace-elided node that starts with a named container — `interface ge-0/0/0.0 passive;` under an OSPF area, `security-zone trust host-inbound-traffic { ... }`, `unit 0 family inet address 10.0.0.1/24;` — the address `... interface ge-0/0/0.0 passive` therefore deleted/deactivated `interface ge-0/0/0.0` itself (and, for a node with a braced body, the whole body) instead of only the descendant `passive`. Measured pre-fix probe on the hierarchical spellings: delete of `passive` left `protocols ospf area 0.0.0.0` with no interface; delete of `host-inbound-traffic` left `security zones` empty; delete of `family inet` left `interfaces ge-0/0/0` with no unit; deactivation marked the enclosing `interface`/`security-zone`/`family` chains inactive. Junos brace-elision is only spelling, so the enclosing container must survive active with its other content.
- **Fix**: New classifier `elidedContainerDescendant15714` (`pkg/config/elided_delete_8992.go`) identifies the descendant shape: the elided node encodes exactly one statement (`findElidedNodeForPath` already proved that), its `Keys` are longer than the addressed path, its first schema step resolves to a container (declares children or a wildcard), and that step (`1 + effectiveArgs15752`, plus a compound-key token) consumes fewer keys than the path still addresses. In `deletePath` and `setInactiveAtPath`, when the classifier fires the node is braced in place with the existing `braceCompactStatement12508` (head = the first step's keys, that step's schema, head provenance sliced from the node's own masks via `sliceBoolElided15714`), converting the packed tail plus any authored braced body into real children, and the ordinary schema descent then deletes/toggles only the descendant. This also re-binds an authored body that `packedBodyChildren` would otherwise re-home under the deepest packed node (the `host-inbound-traffic { system-services ... }` case).
- **Failure atomicity**: The pre-brace node shape is saved; if the braced descent refuses (`ErrPathNotFound`-wrapped or `path not found`-prefixed, via `errIsPathRefusal15714`), `restoreBracedElided15714` restores the original elided spelling so a refused edit leaves the candidate byte-identical rather than silently re-shaped. Successful edits intentionally keep the braced spelling of that one container, the same rewrite `SetPath` already performs on compact leaves (#12508).
- **Not changed**: Whole-statement addresses are untouched — when the path exactly exhausts the node, or ends at the container head, the classifier returns `0` and the existing whole-node delete/toggle runs (pinned by controls). The safety refusals are untouched and still fire first in their current order: packed-run refusal in `deletePath` (#8992/#8932), bracketed-group guidance (#9799), and `refusePackedMemberToggle` in `setInactiveAtPath` (#9793, which runs before the elided match, so single-statement container descendants are never refused as packed members). Interface-family editing (#12661) still runs before the elided match on both verbs, so its elided-sibling refusal is preserved; repeated-sibling schemas (#12714) still skip the elided shortcut. No compiler, schema, or render code changes.
- **Residual**: A descendant address that the schema cannot resolve past the braced container stays a refusal (now against the braced shape, restored to the original spelling) instead of Junos silently succeeding on unmodelled grammar — the conservative direction, unchanged from the pre-fix not-found behaviour for genuinely absent descendants.
- **Triple-review fold (PR #15915, head after eef99687f2)**: B1 — `braceCompactStatement12508` built its expansion from a key-only temporary node, discarding the node's authored braced `Children`; on deactivate/activate of `security-zone trust host-inbound-traffic { system-services { ssh; } protocols { ospf; } }` (and `unit 0 family inet { address ...; }`) the body vanished, and on delete of the NAT `rule r1 match ... { then { ... } }` descendant the sibling `then` body vanished. Root fix: the helper now seeds `packed` with `Children: n.Children` so `packedBodyChildren` attaches the body under the deepest packed statement or as a sibling root (#14415); this also hardens its pre-existing non-leaf caller. Regression: deactivate cases now assert body survival across the deactivate+activate round trip (zone + family), the zone delete case asserts `system-services/ssh/ospf` are dropped WITH the addressed statement, and `TestElidedBodySurvivesDeleteOfSiblingPacked15714` pins the NAT sibling-body delete. M3 — both #15714 call sites now restore the saved pre-brace shape on ANY error from the braced descent (was: only `ErrPathNotFound`/`path not found`-class), and `errIsPathRefusal15714` is removed. M2 — duplicated `Co-authored-by` trailer kept only once in the commit history going forward. Neighbour failure set identical to the pre-fix committed set (32 entries, timing-only diffs).
- **Re-review fold (PR #15915, head after 4edb2bbafa)**: the preserved braced body was marked `IsLeaf=true` by `markPackedBodyLeaves` (schema for `system-services`/`protocols` declares no children), so `Format()`/`FormatSet()` emitted only the key path and dropped `ssh`/`ospf` on reload — raw-traversal assertions passed while serialization lost the values. Fix: a node carrying any children is never marked leaf (`len(node.Children) == 0` added to the leaf condition); serialized flat packed statements keep values on Keys and are unaffected. Regression now asserts through the real serializers (`assertSerializedBody15714`: FormatSet suffix + Format→re-parse) for zone/family toggles and the NAT sibling-body delete; zone case was RED on 4edb2bbafa, GREEN after. Neighbour failure set still identical to base (32 entries).
