# Issue #12258 — GRE local-delivery residuals

## Why

The four residual cells used untagged (VID 0) GRE frames on ifindex 11, whose base fixture also contained a tagged-only `reth0.80` child. The fixture omitted `native_vlan_id`, so the production `unknown_ingress_vlan` gate correctly rejected VID 0 before GRE decapsulation. The resulting local-delivery, host-inbound, and Stage-11 IPsec assertions never exercised their intended inner-packet paths.

## What

Added a test-only GRE fixture variant that explicitly selects native VLAN 80 for the untagged parent, preserving the production VLAN gate. The two host-inbound cells now key their GRE-only interface override by the resolved logical ingress ifindex. The existing untagged delivery helper uses the native-VLAN fixture; tagged delivery remains unchanged. No production code or `debian/changelog` was changed.

## Validation

- **Base:** `a714c90d472a3c3d98a3799831cfef3ec311a61c` (`origin/master`), branch `fix/12258-gre-local`.
- **RED-before:** on the clean base, `CARGO_TARGET_DIR=/var/tmp/cargo-12258 cargo test --bin xpf-userspace-dp tests_gre_local_delivery:: -- --nocapture` reported 50 passed, 5 failed. All four target cells failed at their reported assertions: both inner-echo cells had `dbg.local == 0`, the SA cell had 0 delegated packets, and the untagged delivery channel was empty. `/dev/shm/cargo-12258` could not be created because `/dev/shm` was full; validation used the required `/var/tmp/cargo-12258` fallback.
- **GREEN-after, per cell:** each of the four issue cells passed individually with `-- --exact --nocapture` and the `/var/tmp/cargo-12258` target directory.
- **Full affected module after change:** `CARGO_TARGET_DIR=/var/tmp/cargo-12258 cargo test --bin xpf-userspace-dp afxdp::tests_gre_local_delivery:: -- --nocapture` reported 54 passed, 1 failed. The remaining `poll_descriptor_junos_host_permit_established_hit_counts_once` failure (`ACK #1` expected session hit 1, observed 0) was also reproduced individually on the unmodified base, so it is same-base-attributed and outside these four cells.

## Risk

The change only repairs fixture ingress identity; it does not relax VID-0 rejection on tagged-only interfaces or alter forwarding behavior. The full module retains one independently reproduced base failure noted above; no live-cluster mutation was performed.
