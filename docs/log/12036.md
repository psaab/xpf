# #12036 — Resolve forwarding-instance interface-only routes

- **Timestamp**: 2026-10-05
- **Action**: Normalize scalar `next-hop <ifname>` and braced `next-hop { interface <ifname>; }` forms to interface-only `@interface` members, then authorize their default-instance domain-0 egress only in exactly marked forwarding-instance tables. Foreign-instance interfaces, unmarked tables, nonzero routing domains, and malformed `address@interface` members remain unresolved.
- **File(s)**: `pkg/config/compiler_routing.go`, `pkg/dataplane/userspace/routes.go`, `pkg/dataplane/userspace/protocol.go`, `pkg/dataplane/userspace/fbf_snapshot_test.go`, `pkg/frr/fbf_table_render_test.go`, `userspace-dp/src/afxdp/forwarding_build/fib.rs`, `userspace-dp/src/afxdp/forwarding_build/tests.rs`, `userspace-dp/src/afxdp/types/forwarding.rs`, `userspace-dp/src/protocol/snapshot.rs`, `userspace-dp/src/protocol/control.rs`, `userspace-dp/src/afxdp/forwarding/README.md`.

## Route scope

Both the scalar `next-hop st0.0` spelling and braced `next-hop { interface st0.0; }` compile to `NextHopEntry{Interface: "st0.0"}` and the Go snapshot producer emits `@st0.0`; FRR renders the interface-only device route into the forwarding instance table (for example, `ip route 0.0.0.0/0 st0.0 table 100`). Rust resolves it only when the exact table is marked as a forwarding instance and the interface belongs to the default instance in routing domain zero. For a secure tunnel with ifindex 30 and no endpoint ID or neighbor MAC, lookup returns `MissingNeighbor`, retains egress ifindex 30, and remains slow-path eligible for kernel XFRM processing.
