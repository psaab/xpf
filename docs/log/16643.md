# #16643: helper-down scheduler/overlay transitions folded into the retained snapshot

- **Timestamp**: 2026-10-25
- **Issue**: `UpdatePolicyScheduleStateWithLatch` and
  `PublishRouteOverlaySnapshotWithLatch` returned "converged" while the
  helper was down (crash / restart backoff) without writing their content
  into `m.lastSnapshot`. The supervisor restart replays `m.lastSnapshot`
  verbatim (`syncSnapshotLocked`), so a closing-window permit stayed
  enforced (or an opening-window deny never engaged) and an ip-monitoring
  failover route was missing from the restarted helper's FIB until the
  next scheduler/ipmon transition or commit.
- **Fix**: both helperless arms now fold the desired content into the
  retained snapshot before returning success. The scheduler arm clones
  the retained snapshot and runs
  `rebuildScheduledPolicySectionsWithLatchLocked` (which also enforces
  the #6480/#5680 hybrid guard; a refusal returns a retryable error so
  the scheduler keeps `republishPending`). The overlay arm rebuilds
  routes with the desired overlay (plus scheduler sections when a
  scheduler state is carried), mirroring the helper-up ordering —
  including stashing the desired overlay across
  `prepareSnapshotForApply` so its derived-section rebuild cannot
  resurrect pre-overlay routes. The fold bumps the retained generation
  (`m.generation` follows) but deliberately does NOT advance
  `publishedSnapshot`, `lastSnapshotHash`, or the applied identity: the
  helper accepted nothing, so the restart tick still sees unpublished
  work and `syncSnapshotLocked` replays the folded content; the
  applied/show scheduler state commits only when that publish lands.
  The #3780 "no snapshot ever published" nil arms are unchanged.
- **File(s)**:
  `pkg/dataplane/userspace/manager_compile.go` (scheduler fold),
  `pkg/dataplane/userspace/manager_overlay.go` (overlay fold),
  `pkg/dataplane/userspace/helper_down_fold_16643_test.go` (new:
  scheduler + overlay defect cells with modelled restart replay through
  real `syncSnapshotLocked`, helper-up controls, #3780 nil-arm cell),
  `docs/log/16643.md`
- **Validation**: see PR. Targeted cells assert the retained snapshot
  carries `inactive=true` / the overlay route immediately after the
  helper-down call, that published/applied bookkeeping stays at 0, and
  that the restart republish sends exactly that content. Fail-on-revert:
  restoring either early `return nil` / `return false, nil` reds its
  defect cell.
