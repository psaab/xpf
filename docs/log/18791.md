# #18791: a restart grace on the #18697 unexpected-exit election debt

- **Timestamp**: 2026-11-01
- **Action**: Implemented the coordinator-approved design.
  - **The grace.** An unexpected helper exit raises election debt only if the
    replacement has not armed within `helperExitGrace` (2.5 s). A second exit
    while the episode is open, an exit within 30 s of the previous one, or the
    exit of an already-wedged generation gets no grace. The wedge verdict is
    unchanged.
  - **The wake.** The deadline wakes the transit gate through the existing
    supervisor observer.
  - **The demotion path.** The daemon's VIP-first demotion also keys on
    `HelperExitedUnexpectedly`, so a peer request inside the grace releases
    the VIPs first.
  - **The hand-off order.** Fixed per seat AE on #18717: load, reset, then
    clear, instead of passing `Swap(false)` as an argument.
- **Data behind the grace value** (`docs/log/18707.md`, udp):
  - Local recovery, measured as the first forwarded ping, came 1.58-1.77 s
    after SIGKILL (7 samples).
  - The exit is observed about 0.5 s after SIGKILL, so the replacement arms
    within about 1.3 s of where the grace is measured from.
  - 2.5 s gives about 1.9x headroom at host load 15-28. Grace length does
    not affect the dual-primary risk: the two-Manager cell has 0 dual for
    both debt schedules.
- **Black-hole cost:** a truly dead or slow helper keeps its traffic on the
  dying node for up to 2.5 s longer before the RG move begins.
