# #16519: parse node budget was per-block again after the #15195 fix

- **Timestamp**: 2026-10-24
- **Action**: The #15195 fix (8ac8a61868) made `parseStatements`
  (`pkg/config/parser.go`) charge keys as well as nodes, but it did so
  with an assignment — `p.nodes = before + 1 + len(node.Keys)` — that
  reset the counter after each statement and discarded every unit the
  statement's children had charged while `parseStatement` recursed into
  its `{ ... }` body. The #8597 budget (`maxParseNodes` 200_000,
  documented in `parser.go` and `pkg/config/README.md` as parser-wide,
  ~37 MB of live AST) was therefore per-block in effect: three sibling
  blocks of 160_002 units each (480_006 units in total) parsed with no
  budget error on the pre-fix tree, on every hierarchical ingress
  (HA `SyncApply`, load/merge, commit, persist, rollback, `CheckText`).
  Replaced the assignment with `p.nodes += 1 + len(node.Keys)` and
  dropped the now-dead `before` capture, so descendant charges already
  accumulated in `p.nodes` during the recursion persist and only the
  node's own `1+len(Keys)` is added. No other budget site changed:
  `parseKeys` still only reads `p.nodes` as its stop condition, and the
  flat SetPath/replay charges (`store_command.go`) are untouched.
- **File(s)**: `pkg/config/parser.go`,
  `pkg/config/parse_node_budget_16519_test.go` (new), `docs/log/16519.md`
- **Validation**: New regression cells in
  `parse_node_budget_16519_test.go` — sibling blocks aggregating past
  the budget, the same aggregate nested under one outer block, and a
  single under-budget block control (parses clean,
  `NodeCount() == 160_002`). Pre-fix: the two aggregate cells FAIL with
  `errs=[]` (480_006 units accepted, no budget ParseError) and the
  control passes; post-fix all three pass. The existing `*_15195`
  (key-dense statement/block-header, normal-keys control) and `*_8597`
  (heap bound, probe control, diagnostic-cap interaction, real-config
  headroom, nested-statements) cells were re-run in the same targeted
  run — see the PR body for counts.
