- **Timestamp**: 2026-11-03
  - **Action**: Deleted `validateClusterAuthKeyStrict`
    (`pkg/config/compiler_validate_strict_cluster_auth.go:68`), the
    `(cfg *Config) error`-shaped wrapper whose body was exactly
    `return validateClusterAuthKeyStrictWithCurrent(cfg, nil, nil)`.
    Production dispatches `validateClusterAuthKeyStrictWithCurrent`
    (`compiler_uniformgates_cluster_zone.go:679`, with
    `opts.currentClusterPrimary16025` / `opts.currentClusterAccepted16858`),
    so the wrapper had no production caller and
    `TestEveryStrictCommitGateIsWired` (#4422 canary) correctly reported it
    as a dead gate at master.
  - **File(s)**: pkg/config/compiler_validate_strict_cluster_auth.go, docs/deadcode-allowlist.txt, docs/log/18974.md
  - **Why delete, not exempt**: the wrapper is not a compatibility seam.
    It is unexported (no external package can call it), and at this head it
    has ZERO callers of any kind — no test calls it either. #16025 (which
    split the current-state params out into `WithCurrent`) migrated the
    last direct callers; what remained was a wrapper that only the
    deadcode census (#17154, `docs/deadcode-allowlist.txt` LEGACY-DEBT
    row) and the wiring canary could see. A permanent canary exemption
    would hide real unwired gates inside it.
  - **Test migration**: none required. `grep -rn
    "validateClusterAuthKeyStrict(" --include="*.go"` finds only the
    definition; every other mention in the tree is a comment, a doc, or a
    string literal naming the gate conceptually (they all still resolve to
    `validateClusterAuthKeyStrictWithCurrent`, which carries the gate).
  - **Doc survival**: the wrapper's 60-line doc block (the
    three-mechanisms fail-open explanation, the STRICT-caller inventory,
    the #1960 lenient downgrade, and the #5078/#6881 session-sync
    dual-accept exception) moved onto
    `validateClusterAuthKeyStrictWithCurrent`, merged with its parameter
    paragraph. Nothing was lost; the final paragraph notes that docs and
    comments predating the #16025/#17888 split still name the gate by its
    short name.
  - **Allowlist**: removed the matching
    `validateClusterAuthKeyStrict` LEGACY-DEBT row from
    `docs/deadcode-allowlist.txt` in the same change, per the
    `scripts/go-deadcode-gate.sh` contract ("the allowlist only shrinks,
    in the same change that deletes the function"). This IS the
    per-package follow-up that row tracked.
