# #15257 — RA packed-header group fan-out (A88-03, #14343 family)

## Why

`protocols { router-advertisement { interface ge-0/0/0 managed-configuration default-lifetime 0 { prefix 2001:db8::/64; } } }` committed strict-clean but compiled four RA entries: the real `ge-0/0/0` plus phantoms named `managed-configuration`, `default-lifetime` and `0`, each sharing the braced body. `compileRouterAdvertisement` iterates `bracketedGroupInstances8794(node.FindChildren("interface"))`, which fans out every `Keys[1:]` token of a braced node; the parser gives this mixed spelling `Keys=[interface ge-0/0/0 managed-configuration default-lifetime 0]` with `Children=[prefix …]`, indistinguishable from a bracketed group to that helper. The real interface compiled correctly via `packedBodyChildren` (#14420), so the phantoms were silent config-integrity noise: `pkg/daemon`/`pkg/ra` key RA senders by the raw name and would start senders on nonexistent interfaces. This is the RA residual of #14343 (zones only) and #14420 (packed no-brace opening only).

## What

- New `pkg/config/compiler_validate_ra_packed_header_15257.go`: `validateRAInterfacePackedHeaders15257` walks `protocols > router-advertisement > interface` on the group-expanded tree; `raUnbracketedHeaderToken15257` mirrors `zoneUnbracketedHeaderToken14343` — an unbracketed `Keys[2:]` token that is a declared RA-interface child (direct `children` map lookup on `raInterfaceSchema8939()`, not the wildcard-falling `resolveSchemaChild`) marks the header as packed, not a group. Bracketed members keep colliding names; the bracket-stripped Format group (`interface ge-0/0/0 ge-0/0/1 { … }`) keeps fanning out.
- `pkg/config/compiler_prewalk.go`: gate wired beside the #9656 zone gate, warnings appended in source order after `zoneGroupWarnings`.
- `pkg/config/compiler_opts.go`: `lenientRAInterfacePackedHeader15257` (true only in `lenientCompileOpts`) — strict refuses naming the token and the correct spellings; tolerant load/peer-sync warns and compiles as before (#1960).
- Regression `TestRAInterfacePackedHeaderPhantomFanout15257` in `pkg/config/ra_interface_packed_header_15257_test.go`: strict rejection, lenient warning, other-stateful variant, bracketed-group / bare-group / braced / packed-no-brace (#14420) controls.
