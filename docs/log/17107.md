# #17107 — descriptor-driven sync stats: MalformedRecordsDropped reaches the snapshot, FormatStats deleted

- **Timestamp:** 2026-10-27
- **Branch:** `fix/17107-campaign`
- **File(s):** `pkg/cluster/sync_stats.go` (new), `pkg/cluster/sync.go`, `pkg/cluster/status.go`, `pkg/cluster/sync_stats_complete_17107_test.go` (new), `pkg/cluster/sync_test.go`, `pkg/cluster/active_fabric_preferred_13544_test.go`, `pkg/cluster/sync_stats_visibility_13230_test.go`

## Action

- Added `MalformedRecordsDropped` to `SyncStatsSnapshot` (was the one SyncStats counter with no snapshot field; 19 non-test `.Add` sites counted into the void).
- One ordered descriptor slice `syncStatFields []syncStatField{name, label, get, mode}` in `pkg/cluster/sync_stats.go` (mode `RenderAlways|RenderNonzero|RenderNever`, no per-call reflection): `Stats()` loads every uint64 snapshot field through it (`loadSyncStat`/`setSyncStatUint`), and `status.go` renders through it (`renderSyncStatRows17107`). Derived snapshot fields (PeerBootIncarnation, GenGuardSessionCap, Connected, ActiveFabric, bulk/config timestamps, BulkSyncSessions, LastConfigSyncSize, LastFenceSeq, LastFenceAckAt) are `RenderNever` with a reason in `syncStatNotRendered`.
- All 11 previously-unrendered snapshot fields now render when nonzero (DeletesDropped, DeletesStaleIgnored, InstallsStaleIgnored, SessionsStaleConfigIgnored, IPsecSAStaleIgnored, DHCPLeasesStaleIgnored, PreAuthRejected, PreAuthHandshakeFailed, FencesSent, FencesReceived, plus MalformedRecordsDropped); GenGuardSessionCap/ActiveFabric stay off the counter table with documented reasons (capacity input / fabric identity, both exposed via `Stats()`).
- `show chassis cluster statistics` (FormatStatistics, FormatDataPlaneStatistics) and FormatInformation render `Malformed records dropped: N` when nonzero; the conditional config/fabric counters single-source their labels from the descriptors (statistic-table wording unified to the FormatInformation labels, e.g. `Pre-key authentication evictions`).
- Deleted `SessionSync.FormatStats` (acceptance: `grep -n 'func (s \*SessionSync) FormatStats'` returns nothing). Its two test callers now point at the status renderer / descriptor render: `TestFormatStats` → `TestSyncStatsDescriptorRender17107`, and the #13544 fabric test asserts `Stats().ActiveFabric` via `fabricStr17107`.
