# #14088 — align Rust local selector projection with Go

- **Opened**: 2026-10-16.
- **PR branch**: `fix/14088-work`.
- **Action**: Match the Go local destination projection's exclusions for every tunnel egress and every mixed-egress route.

## Defect

Rust recomputed a tunnel row's local-selector destination projection from route legs, skipping only the row's own logical ifindex. Go skips all tunnel ifindexes and any unicast route with mixed egress. Rust could therefore derive destinations from a second tunnel's route or non-tunnel mixed ECMP and reject the otherwise valid inventory row as `SELECTOR_PROJECTION_MISMATCH`.

## Change

`PMechInventory::from_snapshot` now derives the complete positive logical-ifindex set from all tunnel rows and passes it to local projection recomputation. That projection skips all tunnel legs and routes with more than one distinct next-hop ifindex, using the same predicate as Go's `pmechRouteHasMixedEgress`. The existing BTreeSet-based canonical ordering and deduplication are unchanged.

Rust regressions cover a route through a second tunnel and a non-tunnel mixed-ECMP route; both assert that the local projection remains empty and the valid tunnel row stays usable.
