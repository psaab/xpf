# #16863 — Partial-frame completion timeout must close the conn, not abandon it

- **Issue**: R3-B06-03. In `DrainReinjectCompletions`
  (`pkg/nfqueue/reinject_socket.go`), the mid-frame read-timeout arm
  (partial header/body consumed, then stalled) set `s.complete = nil`
  and `s.completeBuf = nil` and returned an error, but never called
  `s.complete.Close()` — contrary to its own comment ("Close and
  surface the error so Poll fails pending work closed ...; Rust
  releases the batch for redelivery on the next connection") and to
  every sibling error arm (non-timeout read error, invalid length,
  empty message, unexpected type, decode failure), which all close
  before clearing. The abandoned fd leaked until GC, and the Rust
  single-client inline completion server kept waiting on the old
  stream until its 100 ms timeout, so completions ready in that
  window missed their 5 ms Go ack deadline and were dropped
  (fail-closed) and the replacement conn waited in the backlog.
- **Change**:
  - Add `_ = s.complete.Close()` before clearing `s.complete` /
    `s.completeBuf` in the partial-frame timeout arm, matching the
    sibling arms exactly. No other arm changed; the zero-byte idle
    timeout still preserves the conn (#14678).
  - Strengthen `TestDrainReinjectCompletionsPartialFrameTimeoutIsError`
    (#14678 cell): the server goroutine now keeps its end open (no
    deferred close/return), and after the drain error the test asserts
    the peer observes EOF within 300 ms — merely clearing the local
    pointer (the old `client.complete != nil` assertion) cannot pass
    this. Add `TestDrainReinjectCompletionsBadLengthClosesConn16863`
    as the positive control: the sibling invalid-length arm already
    closes, and its peer must keep observing EOF.

## Residuals

- The optional Rust-side cell (time-to-serve a second client after an
  abandoned vs closed first client) was not added; the Go EOF
  assertion directly proves the stream is released, which is the
  mechanism the Rust 100 ms stall depends on. No Rust change needed.
- No lab/cluster smoke run (per lane instructions).
