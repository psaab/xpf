## A85-01 — screen Junos spellings

Junos places the sweep detector at `icmp ip-sweep` and the null-flag check at
`tcp tcp-no-flag`; xpf accepted only `ip ip-sweep` / `tcp no-flag` and the
strict unknown-leaf gate rejected the Junos spellings with "the dataplane does
not enforce it" — steering the operator to delete an implemented protect.
Now both placements/spellings compile onto `IP.IPSweepThreshold` /
`TCP.NoFlag` (schema leaves added so packed/flat spellings normalise; hint
text in `validateScreenUnknownStrict` names both; legacy spellings kept as
aliases, control-tested). Docs note added to syn-cookie-flood-protection.md.

## A85-04 — port-mirroring silent acceptance

`port-mirroring` was open-world and `compilePortMirroring` read only
`instance/input{rate,ingress/interface}/output/interface`: unknown statements
compiled to no mirror, `family`/`egress` to an unscoped ingress mirror, the
instance-less global form to an empty table, and a zero-ingress instance to a
never-firing entry — all green. Now: `closedWorld: true` on the subtree
(ratchet #9091 moves `/forwarding-options/port-mirroring/instance` blind →
armed), grammar completed (`input rate`, `ingress interface`, `output
interface` modelled; `family`/`egress` declared so the compiler gate names
them), and a compiler shape gate rejects strict / warns lenient
(`lenientPortMirroring15256`, #1960) for unknown statements at every level,
`family`, `input egress`, the global form, and zero-ingress instances.

hierarchical child reader missed them, which would have false-fired the new
zero-ingress gate on shipped flat-set configs). Neighbour control
(rate + ingress + output) commits clean.
