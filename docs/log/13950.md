# #13950 — preserve preferred gateway over less-preferred discard row

- **Timestamp**: 2026-10-16
  - **Action**: IPv4 and IPv6 route selectors now ignore a discard row encountered after a preferred same-prefix route has been retained as a cold-path fallback. This lets later drivable gateway rows be checked for liveness and preserves the preferred gateway if none is live; a discard still wins when it is the first/preferred row. Added parity coverage for preferred drivable gateway vs less-preferred discard, preferred discard vs less-preferred gateway, discard-only routes, and unresolved gateway fallback.
  - **File(s)**: `userspace-dp/src/afxdp/forwarding/fib.rs`, `userspace-dp/src/afxdp/forwarding/tests_lpm_parity_9522.rs`
  - **Validation**: RED-on-base: with the selection logic reverted to origin/master behavior, `cargo test --manifest-path userspace-dp/Cargo.toml --bin xpf-userspace-dp forwarding::tests_lpm_parity_9522::less_preferred_discard_does_not_shadow_drivable_gateway_13950` failed for IPv4 (`DiscardRoute` instead of `MissingNeighbor`). After the fix, `cargo test --manifest-path userspace-dp/Cargo.toml --bin xpf-userspace-dp forwarding::tests_lpm_parity_9522` passed all 34 tests.
  - **Risk**: None identified; same-prefix route preference and live-route selection remain unchanged except that a less-preferred discard no longer preempts a preferred route fallback.
