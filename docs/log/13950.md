# #13950 — preserve preferred gateway over less-preferred discard row

- **Timestamp**: 2026-10-16
  - **Action**: IPv4 and IPv6 route selectors now skip a later discard row only when a prior same-prefix gateway has an actually drivable next-hop. A missing/invalid next-hop does not suppress the discard; the scan continues after a drivable but unresolved gateway so a lower-preference live gateway can still be selected. A discard remains terminal when preferred over any drivable route.
