# #16870 — Family-less, policy-less IPv4 BGP neighbour never gets the default-export route-map

- **Issue**: R3-B08-02, residual of #15157. The generated Junos
  default-export route-map (`xpf-default-export-xpf-chain`: permit
  `match source-protocol bgp`, deny rest) was defined whenever any
  neighbour needed it (`bgpUsesDefaultExport15157` iterates all
  neighbours), but its IPv4 attachment is rendered only inside the
  `address-family ipv4 unicast` block for `inet4Neighbors`. The AF
  classifier in `renderBGP16125` admitted a family-less IPv4 neighbour
  only for declared `family inet`, a global/per-neighbour policy, or
  an AF attribute (`route-reflector-client`, `allow-as-in`,
  `remove-private-as`, `default-originate`). A plain family-less,
  policy-less IPv4 peer (Junos implicitly means `family inet unicast`)
  landed in no set, so FRR default-activated it in IPv4 unicast with
  no `route-map out` — and, under `no bgp ebgp-requires-policy`,
  advertised routes another peer's export originated into the shared
  RIB. That is exactly the #15157 cross-peer leak, in the common
  config shape, committing strict with zero warnings.
- **Change**:
  - `pkg/frr/protocols_render_bgp.go`: feed
    `bgpNeighborNeedsDefaultExport15157` (origination in the instance
    AND no effective export attachment) into the IPv4 AF-classification
    predicate, alongside `policyDefault`/`hasAFNeighborAttributes`.
    Definition and attachment now derive from one predicate. The
    existing `!FamilyInet6 && !hasUnrenderableFamily && !isIPv6Peer`
    guards are unchanged, so IPv6 peers, cross-family/unsupported-SAFI
    fail-closed shapes, and IPv6-only neighbours are unaffected; the
    IPv6 AF loop already classified its neighbours independently.
    `renderBGP16125` is shared by the default instance and every VRF,
    so the fix applies per routing-instance too.
  - No change to `bgpNeighborNeedsDefaultExport15157` semantics:
    ghost-emptied chains still resolve to the stronger #7625 deny and
    do not get the default map; instances with no origination render
    byte-identically.
