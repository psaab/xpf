- **Change**:
  - `pkg/fwdstatus/builder.go`: added `fwdstatus.NewAccessor(dp
    MapStatsSource, backend any, status func() (userspace.ProcessStatus,
    error)) DataPlaneAccessor`, the named `CrashReporter` and
    `StatusProvider` interfaces, and the single shared `accessor` /
    `userspaceAccessor` concrete types with
    `var _ CrashReporter = userspaceAccessor{}` (plus DataPlaneAccessor/
    StatusProvider assertions). Only the userspace flavour carries
    Status/CrashReporter; a nil backend returns a nil accessor (the
    #6743 publication check), and crash methods assert on `backend`.
    Build now asserts the named interfaces instead of anonymous ones.
    `fakeCrashDP` in fwdstatus_test.go gained the (empty) History half
    so it completes CrashReporter.
  - `pkg/cli/cli_show_chassis.go`, `pkg/grpcapi/server_show_forwarding.go`:
    deleted both `forwardingStatus*DataPlane` adapter sets; each surface
    now supplies only a thin `*MapStatsSource` (IsLoaded + projected
    GetMapStats), the single `mgmtview.Probe` resolution, and its
    existing `userspaceDataplaneStatus` func to `NewAccessor`.
  - `pkg/cli/runtime.go`, `pkg/grpcapi/runtime.go`: removed the now-dead
    per-package crash-provider interface declarations
    (`cliUserspaceCrashProvider`/`cliUserspaceCrashHistoryProvider`,
    `userspaceCrashProvider`/`userspaceCrashHistoryProvider`).
  - `pkg/fwdstatus/README.md`: documented the named CrashReporter and
    the shared NewAccessor.
  - `pkg/fwdstatus/accessor_17128_test.go` (new): one adapter test
    covering crash state and history end to end through Build, the
    non-userspace flavour carrying neither Status nor CrashReporter,
    the empty-cell nil, and unknown crash state when the backend lacks
    the crash methods.
  - Build-failure rendering (the one intentional difference): left
    per-surface — CLI returns `fmt.Errorf("build forwarding status:
    %w")`, gRPC renders `"FWDD status:\n  (build failed: %s)\n"`.
    That is the caller-visible error contract of each surface, not
    adapter behaviour, so it stays with the callers of Build.
