# #10848 — Persist anti-rollback floors for binary and kernel channels

- **Timestamp**: 2026-10-26
  - **Action**: Added a durable per-channel anti-rollback high-water
    floor: the highest Debian package version each forward channel
    (binary, kernel) has ever verified-committed on this host,
    persisted outside the versioned runtime and every journal under
    /var/lib/xpf. The binary Run checks the floor in its INIT phase
    and the kernel channel checks it in its Arm preflight; an older
    forward target is refused there (pre-STOP/pre-apt) naming both
    versions. The ordinal is the Debian package version (dpkg
    ordering via compareDebianVersions); the git-describe self-report
    is never an ordinal. Absent floor = not enrolled (first verified
    commit establishes it); once enrolled, a candidate with no
    package-version ordinal refuses. Also: publish-generation and
    postrm/distribution touch-ups that carry the floor file's
    lifecycle (see diff).
