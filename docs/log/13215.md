# Issue #13215: Preserve interface compiler values across AST shapes

## Why

`compileInterfaces` read interface-level tunnel endpoints from the expanded
AST, where brace-elided expansion separates a braced scalar's value from its
keyword. It also read WireGuard peers from the pre-expanded tree and ignored
brace-elided DHCPv6 option children. Valid configuration therefore committed
with tunnel endpoints, peers, or DHCPv6 prefix-delegation / RA-update settings
silently absent.

## What

- Retained interface tunnel `source`, `destination`, and `mode` values from
  the original braced child nodes before `tunnelRunChildren9156` expansion.
- Collected WireGuard peer instances from the same expanded child list used
  for tunnel-wide options and expanded packed peer bodies before reading
  peer options.
- Used schema-driven `packedBody` for `prefix-delegating` and
  `update-router-advertisement` children.
- Removed the three newly equivalent DHCPv6 entries from the #2419 compact /
  braced divergence inventory and #8690 permanent-exclusion register.
- Added a regression test covering all three input shapes, with meaningful
  non-default mode and WireGuard peer allowed-prefix assertions.

## Validation

- RED on pristine `origin/master` (`4b3a2b004`):
  `go test ./pkg/config -run '^TestCompileInterfacesWireguardRunAndDHCPv6PackedChildren$' -count=1`
  failed for all three cases: WireGuard peerless tunnel error, DHCPv6 values
  zero/empty, and tunnel source/destination empty.
- GREEN: `go test ./pkg/config -run '^TestCompileInterfacesWireguardRunAndDHCPv6PackedChildren$' -count=1`
  passed (`ok .../pkg/config 0.011s`).
- GREEN: `go test ./pkg/config -count=1 -timeout=30m` passed
  (`ok .../pkg/config 425.892s`).
- GREEN: `go build ./...` and `go vet ./pkg/config` both exited 0.
- GREEN: `gofmt -l pkg/config/compiler_interfaces.go
  pkg/config/compiler_interfaces_13215_test.go` printed no files.

## Risk

The change is limited to preserving already-supported compiler inputs across
AST representations. Strict and lenient validation policy is unchanged.
