One change closes both issues. They touch the same lines of the same four scripts, and the selftest that guards one also guards the other.

## Re-verified at origin/master a075f82ec

- **#9691 (shaped port):**
  - The four client lines have no `-p` (`test-double-failover.sh:122`, `test-chained-crash.sh:248`, `test-active-active.sh:130`, `test-stress-failover.sh:166`), so they measure 5201.
  - `cos-iperf-config.set` maps 5201 to `iperf-100m`, a `transmit-rate 100m exact` class on the `reth0.80` output filter.
  - `test-failover.sh` already uses `IPERF_PORT=5211` (#7673).
- **#9690 (no throughput cell):**
  - `test-double-failover.sh` and `test-chained-crash.sh` parse `Gbits` only, into the literal `0`, and their verdict block has a PASS arm, a `!= "0"` FAIL arm and no else.
  - `test-active-active.sh` parses `Gbits` only and reports a sub-Gbit run as "0 Gbps".
  - `test-stress-failover.sh` hand-converts `Mbits`, and its cell text ("throughput: …") is not the `iperf3 throughput … Gbps` cell the ha-smoke ledger adapter reads.
- **The guard:** the selftest's wiring and port-agreement cells read `test-failover.sh` only.

## Change

- **Every sibling smoke:**
  - sources `iperf-throughput-lib.sh`;
  - defaults `IPERF_PORT` to 5211;
  - passes `-p ${IPERF_PORT}`;
  - judges throughput with `iperf_throughput_verdict "$MIN_THROUGHPUT" "$sum_line"` and a `case` with a `*) fail` catch-all, exactly as `test-failover.sh` does.
- **Script-specific notes:**
  - `test-double-failover.sh` and `test-chained-crash.sh` keep their "control socket disrupted" completion arm, fed by `iperf_sum_rate_gbps`.
  - `test-active-active.sh` now emits the throughput cell whether or not the run completed.
  - `test-stress-failover.sh` keeps reading the last interval `SUM` line, because its client is killed before a sender summary.
- **Selftest:** the WIRING and #7673 port-agreement cells loop over `test-failover.sh` and the four siblings. Each smoke must:
  - source the lib and call the total verdict;
  - have a catch-all;
  - carry no inline Gbits parse in either the `grep -oP` or the `grep -oiE` spelling;
  - pass `-p ${IPERF_PORT}`;
  - use a default port whose CoS term, class and scheduler carry no transmit-rate.
