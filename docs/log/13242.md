# #13242 — declare every emitted Prometheus descriptor

- **Timestamp**: 2026-10-15
- **Finding**: D6-02 identified two route-listener counters and the userspace
  worker session-volume high-water gauge emitted by `Collect()` but omitted
  from `xpfCollector.Describe()`. Checked/pedantic Prometheus registries reject
  these metrics as having unregistered descriptors.
- **RED**: Added both route-listener callbacks and a reported worker high-water
  value to `TestCollectorDescriptorCoverage`. Before the production change,
  `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp
  go test ./pkg/api -run '^TestCollectorDescriptorCoverage$' -count=1` failed
  as expected: pedantic `Gather()` reported three emitted descriptors as
  unregistered.
- **Fix**: Added the missing descriptors to `Describe()`. Strengthened the
  coverage canary to reflect over every `*prometheus.Desc` field and verify it
  appears in the declaration set; changed `describedSet` to drain concurrently
  so growing the descriptor list cannot block on a fixed channel capacity.
- **GREEN**: `go test ./pkg/api -run
  '^(TestCollectorDescriptorCoverage|TestVRFOverlapAdmittedEmittedWhenDataplaneUnloaded_7991)$'
  -count=1` passes the new coverage canary. The selected VRF test fails on an
  unrelated duplicate metric name in this change and also fails identically
  on pristine `origin/master` (`9836528`), so it is base-attributed.
  `go vet ./pkg/api` and `go build ./pkg/api` pass. The full `go test ./pkg/api
  -count=1` run has the same pristine-master VRF failure.
- **Files**: `pkg/api/metrics.go`, `pkg/api/metrics_descriptor_coverage_test.go`.
