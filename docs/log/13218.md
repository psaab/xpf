# Issue #13218: Preserve compact nested statements when editing repeated containers

`SetPath` converted a compact `groups` leaf into a container by putting its
entire packed tail in one leaf child. Nested DHCPv6 client settings then no
longer had the shape expected by `packedBody`, silently dropping settings such
as the update-router-advertisement interface and prefix-delegation length.
The same issue affected compact forwarding-options sampling instances.

The bracing helper now expands the packed tail against the repeated container's
schema using the shared packed-body parser, preserving nested structure and
key provenance. The deep repeated-sibling schema check also guards its optional
forwarding-options schema before dereferencing it.

Regression tests cover group DHCPv6 update-RA and prefix-delegation preservation,
compact sampling instance preservation, the equivalent non-group DHCPv6 edit,
and the nil schema guard.
