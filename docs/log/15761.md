# Issue #15761 — `stripInactiveNodes` and `packedBodyChildren` drop `Node.BracketedClosed`

## Claim (narrowed, verified at origin/master 320c26c08c)

`stripInactiveNodes` (pkg/config/inactive.go) copied Keys/KeysQuoted/KeysBracketed
but omitted BracketedClosed (and leafMemberGroups9862 /
duplicateBlockMergeMarkers9023 that cloneNodes in ast.go copies).
`packedBodyChildren` (pkg/config/compact_tail.go:226) and
`groupPackedLeafUnmodelledTail` (pkg/config/ast_groups.go:1622) called
setKeysBracketed without the closed argument, so BracketedClosed defaulted false.
Routing-policy #11779 consumers (compiler_routing.go) key on BracketedClosed:
a closed `from protocol [ ospf bgp ]` read as unclosed => malformed, strict
reject / tolerant reject.

## Live verification (pre-fix, this worktree)

- RED `TestStripInactivePreservesBracketedClosed15761`: `no node with
  BracketedClosed=true found in term subtree; strip dropped the close bit`.
- RED `TestStripInactiveSyncsCloneFields15761`: BracketedClosed=false,
  duplicateBlockMergeMarkers9023=[], leafMemberGroups9862 len 0.
- RED `TestPackedBodyPreservesBracketedClosed15761`: no packedBodyChildren
  output carries BracketedClosed=true.
- RED `TestGroupPackedLeafUnmodelledTailClosedBit15761`:
  tail.BracketedClosed=false, tail keys=[unit 0 frobnicate 7].

All four failed pre-fix (stash of the three source files) and pass post-fix.

## Fix

- `pkg/config/inactive.go` stripInactiveNodes: copy `BracketedClosed: n.BracketedClosed`,
  `leafMemberGroups9862: cloneLeafMemberGroups9862(n.leafMemberGroups9862)`,
  `duplicateBlockMergeMarkers9023: append(...)` — field-for-field in sync with cloneNodes.
- `pkg/config/compact_tail.go:226` packedBodyChildren:
  `setKeysBracketed(..., node.BracketedClosed)`.
- `pkg/config/ast_groups.go:1622` groupPackedLeafUnmodelledTail:
  `setKeysBracketed(..., s.BracketedClosed)`.

setKeysBracketed's closed logic: only sets BracketedClosed=true if closed arg
true AND at least one bracketed token in the slice, so unbracketed spans stay false.
