# #15668 — `security zones functional-zone management` rejected / silently dropped

## Defect
The closed-world `security zones` schema modelled only `security-zone`,
and `compileZones` read only `security-zone` children. Junos's
`functional-zone management` stanza was therefore rejected at strict
commit (`unknown keyword "functional-zone"`) and silently dropped on
the tolerant load / HA sync path (no zone, no warning), stranding
non-`fxp0` management interfaces in the unzoned `junos-host` catch-all
drop instead of their authored host-inbound treatment.

## Fix
- `pkg/config/schema_security.go`: model `functional-zone management`
  (closed-world) with the children the zone compiler consumes for it —
  `description`, `screen`, `host-inbound-traffic`, `interfaces`
  (wildcard, with per-interface `host-inbound-traffic`). `tcp-rst` /
  address-book are deliberately not modelled.
- `pkg/config/compiler_security_zones.go`: extract the per-zone body
  compiler into `compileZoneBody15668` (verbatim move) and funnel every
  `functional-zone management` body (braced, compact-header, and
  flat-set shapes) into `sec.Zones["management"]`, compiled first so a
  literal `security-zone management` merges find-or-create (#4818).
  Unknown children ride the existing #11575 strict-reject /
  tolerant-quarantine channel.
- `pkg/config/compiler_validate_strict_zones.go`: the tree-level
  packed-tail (#6735) and interfaces-non-empty (#6525) gates now also
  walk the management body. All compiled-config gates (unknown token,
  undefined screen/interface, membership conflict, reserved name) apply
  automatically via `Zones["management"]`.

## Validation
- RED pre-fix: `TestFunctionalZoneManagement*` failed — SchemaValidate
  rejected `functional-zone`, strict compile silently produced no
  `management` zone, all six strict-gate subtests accepted.
- GREEN post-fix: `go test ./pkg/config/ -run TestFunctionalZoneManagement`
  passes (schema strict+flat, compile strict+lenient+flat, six strict
  gates with lenient warnings, merge/conflict behaviour).
- `go test ./pkg/config/ -run 'Zone|HostInbound'`: failure set identical
  to base `d316277cb4` (11 pre-existing failures, timing-only diff).
- Full `./pkg/config/` suite exceeds the lane tool timeout on this box
  (1442 test files); zone/host-inbound/schema subsets run instead.
