# #13660 — gate unsolicited kernel IPv6 neighbor updates

The AF_XDP RTM_NEWNEIGH monitor applied the #10704/#11069 solicitation gate
only to IPv4. Its IPv6 arm unconditionally replaced a live dataplane binding
with any usable-state kernel notification, allowing an unsolicited neighbor
advertisement accepted by the host NDP stack to redirect IPv6 traffic. The
IPv6 arm now uses the same one-shot probe evidence and atomic replacement gate,
including NUD_PERMANENT authority and kernel-backed marking. Refusals use the
existing NA counter/report path; first sightings, same-MAC updates, removal,
and probe-confirmed failover remain supported.

Regression coverage exercises unsolicited replacement refusals and accounting,
router flags, first sighting, same-MAC refresh, one-shot and expired probe
proof, NUD_PERMANENT replacement, unusable-state removal, DELNEIGH, and malformed
payloads. The test failed on pristine master by returning `Upserted` for an
unsolicited differing IPv6 MAC.
