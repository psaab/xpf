# #18722: idle established TCP sessions are never reaped

- **Timestamp**: 2026-11-01
- **Action**: Found by the Rust known-failure triage (seat V). On master
  5927babf07, `seed_lifecycle_expires_on_app_window_not_default_10267` is
  red: its default-timeout control, a completed and answered TCP pair, is
  not reaped past its window.
- **Root cause**: `opening_companion_keeps_alive` (#16223 round 2, merged in
  a936a6f802 / PR #16217) kept any idle-crossed row on
  `promoted_and_served()` and re-stamped it to `now_ns`. The proof is
  cumulative, and `node_served_evidence` counts the expiring row itself, so
  an answered established flow re-stamped itself on every GC pass.
- **Action**: The fix scopes the arm to opening rows and requires the
  node-wide served packet total (`NodeServedEvidence::served_packets`) to
  advance past a per-row baseline (`SessionEntry::node_served_seen`).
  Rejected alternatives:
  - excluding the row's own pair (a shared mirror is indistinguishable from a
    sibling's serving row);
  - a time stamp on `SyncedSessionEntry` (269 literal sites);
  - the opening gate alone (an opening replica can still pin itself through
    its own ct-slice-promoted shared row).

- **Live control (udp, deployed xpf 0.0.29565+g84d00b08dd8d, contains
  a936a6f802)**:
  - Setup: established-timeout 60 s set for the run (restored on exit), 20
    TCP flows to a silent listener, then a tc egress drop on the client
    before killing it, so no FIN or RST leaves.
  - All 20 sessions stayed on BOTH nodes for 241 s (four windows).
  - A second run 5 minutes later found those 20 still present beside its own
    20 (40 per node), unchanged at its end.
  - node1 held the ESTABLISHED rows (Timeout 60), node0 the OPENING replicas
    (Timeout 20). Those are the two shapes the cells pin.

- **Contract**:
  - An idle completed row reaps one window after its last packet.
  - An idle opening replica is kept at the window-1 check (it still sees the
    last advance) and reaped at the window-2 check. This is the zero install
    baseline; #18739 seeds the baseline at install to make it one window.
