# Issue #10491 — symmetric VRRP VIP errno classification

## Scope

The VRRP VIP add path now checks the wrapped errno with `errors.Is(err,
unix.EEXIST)` before applying the narrow `file exists` strerror fallback. The
remove path remains unchanged; its existing `EADDRNOTAVAIL` taxonomy is pinned
with the same annotated-error and pinned-netlink fixture shapes.

The production change is limited to `pkg/vrrp/instance_vip.go`. The new
`pkg/vrrp/vip_errno_10491_test.go` drives the existing link, address-add, and
address-delete seams without kernel or cluster access.
