# #14687 — RBAC bypass via incomplete typed-leaf / dynamic-subcommand validation

- **Timestamp**: 2026-10-17
  - **Action**: Re-anchored the packet on current master. `Canonicalize`
    returned `CanonicalOK` unconditionally at loop exit: a trailing typed
    leaf (`show firewall filter secret family`), a dangling mandatory
    dynamic selector (`show firewall filter`, `show security screen
    ids-option`, `show security screen statistics zone`, `show route
    table`, `show security policies from-zone …`), and an unfilled
    childless placeholder (`show chassis cluster data-plane flows`) all
    judged a string the dispatcher widened or dropped. Measured pre-fix
    with a probe test: all nine dangling lines canonicalized OK.
  - **Action**: Fix in `pkg/cmdtree`:
    - New `Node.RequiresValue` (opt-in, honoured only in Canonicalize):
      a dynamic node whose bare form has no handler — the dispatcher
      widens to a broader listing when the value is missing. Marked on
      `show firewall filter`, `show route table/protocol/instance`,
      `show security policies from-zone/to-zone/policy`,
      `show security screen ids-option`, `show security screen statistics
      zone`, and `test security-zone interface`. Optional dynamic nodes
      (`show security zones`, `show interfaces`, CoS classifier/scheduler-map/
      rewrite-rule, session/log option dynamics) stay unmarked: their bare
      forms really list everything.
    - End-of-walk refusal in `Canonicalize`: trailing `parentTyped`,
      an unfilled `RequiresValue` dynamic, or an unfilled childless
      placeholder under a non-root keyword node now return
      `CanonicalUnknown`, so the RBAC gate fails closed. Root-level
      `ping`/`traceroute` and placeholders with children (`show route`)
      stay complete: the gRPC/REST authorization tables charge those
      argument-free paths and the typed RPCs carry values in fields.
    - Dispatchers error instead of widening on the same dangling
      selectors (local `pkg/cli` firewall/screen, remote `cmd/cli`
      firewall/screen), including a dangling trailing `family`.
  - **Action**: The gRPC topic-table validity test exempts prefix-form
    topics (`route-table:` etc.), `route-instance` (value in `req.Filter`)
    and the flows path (value in the topic) from the Canonicalize arm
    only — those pack their value outside the command path; the keyword
    arm still proves every word is a real node.
