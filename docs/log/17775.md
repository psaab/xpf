# #17775 — userspace-dp: exercise WG PTB learning through RX poll path

- **Timestamp**: 2026-10-29
- **Action**: Added a named regression that pushes a valid, VLAN-80 ICMPv6 Packet-Too-Big frame through the native RX descriptor/poll path. It verifies that the poll hook learns 1400 for the quoted WireGuard peer, that `post_transform_inner_mtu` drops from 1420 to 1320, and that the next forwarded 1320-byte inner encapsulates while 1321 bytes is rejected by the WireGuard MTU guard.
- **File(s)**: `userspace-dp/src/afxdp/frame/wg_tests.rs`, `debian/changelog`, `docs/log/17775.md`.

The guard was restored; the named test was rerun after restoration.
- **Risk**: Uses one PTB and an isolated peer, so the test is deterministic and does not exercise concurrent shrink-only updates; that separate behavior remains in sibling issue #17774's scope. No live reduced-MTU underlay was exercised.
