## Harness contracts

The three rows use the #9531 wire-gate ledger adapter and emit exactly one
`WIRE_GATE` summary. Each gate has a `--selftest` path and a `--fixture` path.
The adapter requires the complete metric set rather than accepting a headline
without the supporting offered/observed counts.

- **#10028 `wire_zone_matrix`**: six ordered cells under default-deny and the
  same six under default-permit, with 64-byte and 1400-byte probes plus a
  same-pair control leg. A deny leak, permit loss, duplicate capture frame,
  incomplete identity set, or checksum failure is fail-closed; capture-blind
  controls are VOID.
- **#10029 `wire_hostinbound_deny`**: TCP SYN cells for SSH (22) and HTTPS
  (443) must not expose a reply. Temporary TCP netconf (830) is the same-TCP
  near-miss control and is captured on the outside endpoint. A temporary
  listener on both DUT nodes makes SYN-ACK/RST observable.
- **#10030 `wire_conntrack_lifecycle`**: create and session-list witness a
  TCP flow, observe it through the configured idle window, then keep the
  lifecycle application permitted while sending raw ACK/PSH bursts for the
  expired and never-created tuples. A separate full TCP heartbeat control and
  same-destination-port SYN burst supply the same-window capture and session
  witness. Source ports are randomized per run to avoid TIME-WAIT collisions.

The live matrix owns the VLAN-50 DMZ fixture and exact route snapshots. It
requires the complete `dmz` zone to be absent before mutation, replays any
pre-existing route, and verifies exact post-restore policy/zone/application
snapshots as well as route output. All three live scripts restore their
owned state before returning, including the negative-control runs.

### #10030

The gate intentionally observes between the configured 10-second
`inactivity-timeout` and the live default TCP timeout. The lifecycle
application remains permitted for the post-expiry probes, so a policy deny
cannot explain the drops; the expired/fresh raw tuples and the SYN control
all target the same destination port. The baseline exposed a product defect
on the current loss image:


The deliberate `APP_TIMEOUT=300` broken fixture requires a current-head
wrapper rerun after the sibling-cluster handoff; no broken-pair result is
claimed here.

Independent manual proof recorded in #10267 configured
`inactivity-timeout 300`, observed `Timeout: 20` in `show security flow
session`, and observed `Total sessions: 0` at t+45. The fresh-tuple
midstream leak is tracked separately in #10270. No product code was changed in
