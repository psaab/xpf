# #17186 — R4-Q06-06: CoS exact-TX settle/restore helpers carry six unreachable queue-gone None arms

- **Timestamp**: 2026-10-27
- **Defect (live on origin/master 59e7f8b)**: `cos/queue_service/settle.rs`
  carried six `let Some(queue) = queue else` arms (restore ×2, settle ×4)
  with three contradictory frame-ownership policies for a queue that
  cannot disappear: each `service_exact_*` fn resolves the queue by
  `get_mut` for the scratch build, then only ring/stamp calls run before
  the settle/restore helpers re-resolved the same
  `(root_ifindex, queue_idx)` as `Option`. Two arms recycled all offsets
  including the kernel-owned `..inserted` prefix (double-use hazard if
  ever reached), three `.clear()`ed popped `PreparedTxRequest`s (leaking
  their `PreparedTxRecycle`s), and T-7 (2798ebec) had fixed the two local
  flow-fair arms on the false premise that the prepared flow-fair arms
  "match their FIFO sibling" — the FIFO prepared scratch holds copies
  (`ExactPreparedScratchTxRequest`), the flow-fair one holds the popped
  requests themselves. `grep -c 'let Some(queue) = queue else'
  cos/queue_service/settle.rs` was 6.

## What

- `settle.rs`: all six helpers now take `queue: &mut CoSQueueRuntime`
  (not `Option<&mut _>`); the six None arms are deleted, making the
  impossible state unrepresentable. `grep -c 'let Some(queue) = queue
  else' settle.rs` == 0 and no `Option<&mut CoSQueueRuntime>` remains
  there. The committed-prefix ownership logic (kernel-owned prefix →
  `in_flight_untracked_tx` / `remember_prepared_recycle`, remainder →
  `free_tx_frames` / push-front restore) is unchanged in the Some path.
- `service.rs` (the four `service_exact_*` fns): each settle/restore
  site resolves `&mut CoSQueueRuntime` once via `get_mut` + `let-else`
  and passes it in. Restore sites (Drop / inserted==0, before any
  submit) return `NoProgress` on the unreachable miss, exactly as the
  old None arms did (plus the release the FIFO Drop arm already did).
  Settle sites (after `writer.commit()` + `outstanding_tx += inserted`)
  roll `outstanding_tx` back with `saturating_sub(inserted)` on the
  unreachable miss rather than leaking the gauge. Passing `&mut queue`
  alongside `&mut binding.tx_pipeline.*` / `&mut binding.scratch.*`
  required splitting the other whole-binding borrows at those sites
  into disjoint-field helpers (all behaviour-preserving wrappers kept
  for existing callers):
  - `tx/rings.rs`: `reap_tx_completions_fields`,
    `recycle_completed_tx_offset_fields`, `maybe_wake_tx_fields`
    (whole-binding `reap_tx_completions` / `maybe_wake_tx` kept).
    The ENOBUFS/SENDTO_ERR logs in the fields form drop the
    slot/ifindex/queue fields they no longer carry.
  - `tx/stats.rs`: `record_tx_commit_fields`,
    `record_tx_kick_batch_fields` (wrappers kept).
  - `binding_state`: `skip_binding_debug_state` (cadence-counter
    advance; the fields reap path has no whole binding to publish).
  - `cos/tx_completion.rs`: `count_tx_ring_full_submit_stall_on_interfaces`,
    `apply_direct_exact_send_result_fields`,
    `refresh_cos_interface_activity_on_cos`,
    `publish_cos_exact_backlog_on_cos` (wrappers kept).
    `refresh_cos_interface_activity_on_cos` does not publish the exact
    backlog (needs the binding slot, which `WorkerCos` does not carry);
    whole-binding callers still publish on the next drain pass.
  - `cos/token_bucket.rs`: `release_cos_root_lease_on_cos` (wrapper kept).
  - `tx/cos_classify.rs`: `cos_queue_dscp_rewrite` now takes
    `Option<&CoSQueueRuntime>`; `submit_local` / `submit_prepared`
    resolve the queue the same way `service.rs` does.
  - `settle.rs`: `subtract_direct_cos_queue_bytes` now takes
    `&mut FastMap<i32, CoSInterfaceRuntime>`; on `dropped_bytes == 0`
    it no longer refreshes interface activity — its four callers in
    `service.rs` already refresh on that branch themselves.
- Tests: the two T-7 queue-gone tests
  (`settle_local_scratch_flow_fair_recycles_offsets_when_queue_gone`,
  `restore_local_scratch_flow_fair_recycles_offsets_when_queue_gone`)
  are deleted with the arms they pinned (the `None` argument no longer
  compiles). Every other settle caller (`Some(&mut root.queues[0])` →
  `&mut root.queues[0]`) in `queue_service/tests/{drain,sojourn}.rs`,
  `queue_ops/tests/{admission,bench}.rs` is updated; those tests are
  the regression guard: they drive partial inserts and assert the
  committed prefix lands in `in_flight_*`, the remainder is recycled /
  restored, and sojourn samples exactly the committed prefix once.

## Risk

Low-medium. The settle/restore ownership logic is untouched; the
change is signature + call-site plumbing. The field-split helper
variants are mechanical extractions of the same bodies (wrappers
preserve every existing caller byte-for-byte, including test callers
in `tx/rings.rs`, `worker/lifecycle.rs`, `tx/transmit/*`,
`tx/drain/*`). Two deliberate, documented deltas: refresh-on-cos
defers exact-backlog publish to whole-binding callers, and
`subtract_direct_cos_queue_bytes(.., 0)` no longer refreshes (callers
already do). The unreachable settle-miss path now rolls back
`outstanding_tx` instead of the old arms' offset recycling, which
would have double-owned kernel frames.
