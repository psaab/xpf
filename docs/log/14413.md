- **Timestamp**: 2026-10-16
  - **Action**: `show event-options` (gRPC `server_show_events.go`, CLI `cli_show_routing.go`) printed compiled `ThenCommands` verbatim, and `RedactedClone()` never inspected the `commands` leaf: a quoted embedded command (`commands "set security ike policy p1 pre-shared-key ascii-text SECRET"`) lexes to ONE AST token, so no token equals `pre-shared-key` and `secretIndices` never fired — the live PSK (executed by the event engine on fire, after #9939 plant-class adjudication) rendered in cleartext on every PermView surface (`Format`/`FormatSet`/`FormatJSON`/`FormatXML`, both show sites, `FormatCompareRedacted`). Added ONE shared render-time helper `RedactEmbeddedChangeConfigCommand` in `pkg/config/ast_redact.go`: it lexes the command with the real config lexer (`lexConfigMutationLine9938`, never `strings.Fields`), requires a `set` verb (classifyPlan's mint direction; `delete` carries no value), and masks tokens via the EXISTING `secretIndices`/`urlLeafIndices` sets — no second credential list — replacing values with `SecretDataPlaceholder` (qualifiers like `ascii-text` kept, gated `key`/`password`/`community` keep their AST context rules, URL userinfo/query redacted via `RedactURL`). Wired into both `showEventOptions` loops and into `redactNodes`/`fingerprintCompareNodes` via `redactEmbeddedCommands14413`/`fingerprintEmbeddedCommands14413`, which locate the `change-configuration commands` pair on the flattened path and handle every compiler-accepted shape: quoted packed leaf, bracket list, `commands { … }` block children, flat-set children, and the unquoted joined tail (KeysQuoted provenance decides grouping exactly as `eventChangeConfigCommands` does; a clean tail is left byte-identical). Compare clones fingerprint masked tokens with the existing `\x00xpf-sha256=` suffix so secret-equality survives in diffs.
