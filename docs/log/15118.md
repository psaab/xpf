# #15118 (A77-03): scoped DNAT/static-NAT destinations no longer LocalDeliver every packet

## Defect

Every non-`off` DNAT/static-NAT destination was registered firewall-local
(`local_v4`/`local_v6` + table attribution) keeping only the rule's
`from routing-instance`. The FIB local-delivery shortcut runs before the
route lookup, so *untranslated* traffic to the same address — a different
protocol, port, source, or ingress zone than any rule matches — was
LocalDelivered instead of routed. An ordinary scoped idiom such as a
`udp/53` DNS redirect to a transit resolver silently blackholed `tcp/443`
and ICMP to that real host's address from every zone.

## Fix

Registration is unchanged: NAT externals stay in `local_v*` for
proxy-ARP/ND, inject-source ownership, anti-poison and Stage-11 metadata
(`local_nat_to_self_*`), so the proxy/ownership set and the local-delivery
set no longer need to be the same query — the delivery decision is now
scoped at resolution time.

- `DnatTable::nat_local_match_possible` / `StaticNatTable::nat_local_match_possible`
  (`userspace-dp/src/nat/destination.rs`, `static_nat.rs`) reuse the real
  match gates: DNAT exact/wildcard-port/protocol-any/prefix tiers with
  zone, interface, routing-instance, source-address and L4 (port/ICMP)
  constraints; static NAT port + source + from-scope gates. `off` and
  poisoned DNAT outcomes never claim local delivery.
- `nat_destination_claims_local` + `lookup_forwarding_resolution_for_nat_flow`
  (`afxdp/forwarding/fib.rs`): an untranslated flow to a NAT-registered
  address is claimed only when a rule could match it; otherwise
  `lookup_forwarding_resolution_without_nat_local` suppresses just that
  address's NAT registration and the packet follows the FIB (interface
  addresses on the same IP stay local).
- Wired into the session-miss resolution (`poll_descriptor/mod.rs`, only
  when no DNAT/static/NPTv6/NAT64 translation fired — translated packets
  still resolve their translated target, so DNAT-to-self via #9529 is
  unchanged) and the flowless base resolution (untranslated NAT-local
  destinations suppress the shortcut; flowless local/interface-NAT arms
  are untouched).
