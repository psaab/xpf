# #13151 — D3-05 shared-netdev zoned and unzoned units

## Defect

Netdev-scoped host-inbound rules cannot distinguish logical units sharing a
Linux netdev. `buildZoneHostInboundViewsFromSnaps` skipped unzoned and
quarantined unit snapshots before registering their netdev signatures, so the
zoned sibling incorrectly received an uncontested ingress claim. In the VRF
case, the unzoned-ingress builder could also emit the same raw slave in
`unzonedVRFSlaves`, placing a blanket `sdifname` drop ahead of the zone's own
rules.

## Fix

Register unzoned and quarantined unit snapshots as empty-policy signatures,
which contests the shared netdev against the zoned unit. Also treat a raw
netdev corresponding to an interface in a zone view as claimed by the view,
even if contention intentionally removes it from `IngressVRFScopes`; this
prevents the earlier unzoned VRF blanket-drop from shadowing the
address-qualified zone policy. The existing ambiguity path owns the contested
scope and keeps its deny behavior.

## Regression and validation

`TestSharedNetdevZonedUnzoned13151` covers main-table and VRF shared-netdev
cases. Both subtests failed on pristine `origin/master`: the main-table case
observed the uncontested `ge-0-0-0` claim; the VRF case observed
`ge-0-0-0` in `unzonedVRFSlaves`. After the fix, the focused test passed:

```text
go test ./pkg/dataplane/userspace -run '^TestSharedNetdevZonedUnzoned13151$' -count=1
ok   github.com/psaab/xpf/pkg/dataplane/userspace
```

`go vet ./pkg/dataplane/userspace/` passed; `gofmt -l` and `git diff --check`
reported no issues. The full package command
`go test ./pkg/dataplane/userspace/ -count=1` did not pass: its output includes
Unix-socket `bind/connect: invalid argument` failures under the shared
`/var/worktrees/.cache/go-tmp` path, golden/contract and zone-ingress test
failures in unrelated files, and the new regression test passed in the focused
run. Those full-package failures have not been independently attributed to
this change.

## Scope

No nftables rule shape or policy semantics changed outside shared-netdev
contention; no unrelated zone admission paths were modified.
