# Issue #12910: screen-probe.sh could not read the labeled witness metric

- **Timestamp**: 2026-10-14
- **Action**: added `screen_probe_extract_metric <metric>` to `test/incus/screen-probe-lib.sh`: a label-aware Prometheus text extractor that matches a sample family by exact name or name followed by `{`, sums the family across its label sets, and prints nothing when the family is absent or any sample is non-integer (fail-closed, same direction as `screen_probe_delta`). The live `metrics()` in `test/incus/screen-probe.sh` now pipes the scrape through it instead of the exact `$1 == m` awk test.
- **Why**: the exporter declares `xpf_screen_drops_by_reason_total` ONLY with a `reason` label (`pkg/api/metrics_descriptors_global.go`), so a sample line's first field is the metric name WITH its label block attached and the exact-match test could never fire. Every witness sample was empty, so every live verdict was VOID while the counter counted — a permanently unreadable instrument. Summing the label sets (rather than selecting one label) preserves the witness invariant "some per-reason counter moved" without reintroducing the wrong-label trap.
- **Regression**: `test/incus/screen-probe-selftest.sh` gained a bounded Prometheus text fixture (labeled per-reason series, aggregate, a longer prefix-sharing distractor name, comment lines) with direct extractor cells, plus the issue's decisive end-to-end check: a labeled witness increment fed through the extractor into `screen_probe_verdict` renders DROPPED/PASSED polarity, and a vanished family renders VOID.

## RED -> GREEN proof

- **RED**: at origin/master cbfd9969b with only the new selftest cells added, `bash ./test/incus/screen-probe-selftest.sh` failed 18 checks and exited 1 — the extractor cells got `''` (`screen_probe_extract_metric: command not found`), the polarity cells rendered `VOID the witness counter is unreadable (before='' after='')` for a fixture whose witness incremented, the exit-contract cells got 127, and all four live-wiring static cells failed.
- **GREEN**: after the fix, `make test-screen-probe-lib` passes all 43 checks and exits 0.
