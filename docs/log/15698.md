# Issue #15698: `system services dns` childless schema breaks SetPath, DeletePath, FormatSet round-trip, and `hasDNSProxyChild` commit-warning detection for dns-proxy

- **Timestamp**: 2026-10-19
- **Problem**: `pkg/config/schema_system.go` modelled `system services dns` as
  `{children: nil}` while its Junos `dns-proxy` subtree was unmodelled. The
  flat-set path therefore collapsed
  `set system services dns dns-proxy forwarders 1.1.1.1` onto a single leaf
  node `Keys=["dns-proxy", "forwarders", "1.1.1.1"]` under a container
  `dns` node. `DeletePath` for any sub-path of that statement refused with
  the #8992 packed-run error ("present in an ELIDED spelling packed
  together"), so the stanza was undeletable piecemeal, and the FormatSet
  round-trip left residue. Separately, a bare `set system services dns`
  leaf beside a braced dns container shadowed the proxy from the compiler:
  `FindChild("dns")` returned the bare leaf first, `hasDNSProxyChild` saw
  no children, and `DNSProxyConfigured` (and its commit warning) never
  fired for that shape.
- **Fix (schema)**: In `pkg/config/schema_system.go`, model `"dns"` as a
  container with a `"dns-proxy"` child (`interface`, `default-domain`,
  `forwarders` as a wildcard value-container, `view <name>` with
  `default-domain`/`forwarders`, and `cache-size`) so `SetPath`,
  `DeletePath`, and tab-completion treat `dns` and `dns-proxy` as
  containers. Bare `set system services dns` still terminates at the `dns`
  node as a flag leaf; `FormatSet` still emits it.
- **Fix (compiler)**: In `pkg/config/compiler_system.go`, iterate over
  `svcNode.FindChildren("dns")` (instead of `FindChild("dns")`) and check
  both `node.Keys[1:]` and `node.Children`/`child.Keys[1:]` in
  `hasDNSProxyChild`, so the bare-leaf-beside-container shape and packed
  shapes record `DNSProxyConfigured` and emit the commit warning.
- **Regression check**: RED on pre-fix — `SetPath` built the packed leaf,
  `DeletePath` errored with the ELIDED message, and the bare+proxy tree
  compiled with `DNSProxyConfigured=false`. GREEN post-fix with the three
  new cells in `pkg/config/dns_proxy_schema_15698_test.go`. No new failures
  in the flat-set inventory: `TestCompactBlockEquivalenceInventory2419`
  reports 30 pre-existing NEW compact-blind sites both pre- and post-fix,
  none under `dns`.
- **Not changed**: The DNS proxy runtime remains unimplemented
  (`docs/next-features/dns-proxy.md`); the accepted-but-not-served warning
  behaviour is unchanged. No `closedWorld` was added to the `dns`
  subtree — the issue's grammar list is the modelled subset and closing
  the subtree would false-reject unmodelled Junos dns-proxy keywords.
  The #7484 spelling-gate ceilings (162/51/197) are base-pre-broken from
  unrelated drift (measured base 175/68/220 vs this change's 179/68/219),
  so the gate's three ceiling bumps caused by the four new
  `system services dns dns-proxy *` blind leaves (`cache-size`,
  `default-domain`, `interface`, `view <*> default-domain`, whose values
  the compiler only records as a presence flag) are recorded as
  follow-up rather than silently bumped here.
