# 12657 — cover the XFRM tracked-name orphan-sweep skip

- **Timestamp**: 2026-10-13
- **Action**: added an in-package LinkDel-counting regression test for the tracked-name guard in the XFRM orphan sweep
- **Files**:
  - `pkg/routing/xfrm_orphan_sweep_tracked_12657_test.go`

## Why

The XFRM restart orphan sweep in `xfrmManager.Apply` must skip names already
owned by `x.xfrmis`; the tracked removal/retry pass is responsible for those
links. The existing `TestXfrmOrphanReapRemoveWhileDown11443` started with a
fresh manager and only tested orphan cleanup, so removing the tracked-name skip
at `xfrm.go`'s sweep did not fail the package suite (PR #12578 Opus R1 residual,
mutant M2).

## What

Added `TestXfrmOrphanSweepSkipsTrackedNames12657`. It records every `LinkDel`
attempt, including failed attempts, and puts one tracked-undesired xfrmi, one
true orphan, one tracked-desired xfrmi, and two foreign links in the kernel
fixture. An injected failure on the tracked name proves that only the tracked
delete pass attempts its deletion; the orphan is deleted exactly once and the
tracked-desired and foreign links receive no delete attempts. No production
code change or netlink seam was needed.

## Validation

- RED mutant probe: temporarily removed the tracked-name guard in
  `pkg/routing/xfrm.go`; `go test ./pkg/routing/ -run
  TestXfrmOrphanSweepSkipsTrackedNames12657 -count=1` failed, observing
  `st0.5` twice (`calls=[st0.5 st0.9 st0.5]`, expected one attempt). The
  temporary production mutation was restored; `git diff -- pkg/routing/xfrm.go`
  was empty.
- GREEN targeted test: `go test ./pkg/routing/ -run
  TestXfrmOrphanSweepSkipsTrackedNames12657 -count=1` passed.
- Full package: `go test ./pkg/routing/ -count=1` passed.
- Static analysis: `go vet ./pkg/routing/` passed.

## Risk

Test-only change. It exercises the existing sweep against tracked, orphan, and
foreign link names without changing runtime behavior.
