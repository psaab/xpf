    `redundancy group %d not found`; Batch keeps per-member supersede skip
    (#5246/#8000), ForceSecondary keeps its own commit body (Weight=0,

    ForceSecondary now reserves every configured RG (incl. disabled, matching old
    snapshot scope) but runs barrier only for active RGs. Single path error
    strings unchanged (not found / already in progress singular vs batch plural
    preserved in reserveLocked). Acceptance grep now = 1. One `revalidateLocked`
    called by all three entry points.
