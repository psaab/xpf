# #13298 — expose cumulative conntrack GC telemetry

- **Timestamp**: 2026-10-15
- **Base**: `master` `f59c739af`
- **Source finding**: deep-review D5-09 (`review-work.AYgyxCmMxC`), validated by three-way research.
- **Action**: Preserve cumulative GC totals across sweeps, count iteration/deletion/session-count synchronization errors, and export GC health and counters to Prometheus.

## Red before

`TestGCStatsCumulative13298` failed to compile on pristine master because `GCStats` had no cumulative sweep/deletion/error fields. The source finding also reproduced overwritten per-sweep counts and silent error drops in the iteration, batch deletion, and session-count map-update paths.

## Change

- Keep existing `GCStats` last-sweep fields intact and accumulate monotonic totals for completed sweeps, expired deletions, deadline saturation, persistent-NAT expirations, and the iteration, delete, and session-count synchronization errors.
- Check and log session-count publisher errors instead of discarding them; retain exact-deletion accounting and callbacks on partial delete errors.
- Expose GC duration, last-sweep timestamp, cumulative counters, bounded operation-error series, and aggressive-aging state on `/metrics`, registered in `Describe()`.
- Emit GC metrics independently of dataplane load so they remain available during degraded or config-only operation.

## Validation

- RED: pristine `f59c739af`, `go test ./pkg/conntrack -run '^TestGCStatsCumulative13298$' -count=1` fails because `GCStats.SweepsTotal`, `ExpiredDeletedTotal`, and error totals are undefined; the same test fails on the revert check.
- GREEN: `go test ./pkg/conntrack ./pkg/api -count=1` passes; `go build ./...` and `go vet ./...` pass; `go test -race ./pkg/conntrack -count=1` passes. `gofmt` applied to changed Go files.

## Risk

Prometheus gains bounded `op` values (`iterate`, `delete`, `session_count_sync`) and additional conntrack GC series. Existing last-sweep statistics remain unchanged for callers. No wire protocol or dataplane forwarding behavior changes.
