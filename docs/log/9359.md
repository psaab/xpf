# #9359: `_6829` syslog cells fail intermittently in a full-tree run

- **Timestamp**: 2026-09-10
  - **Action**: Measured the reported flake, with a positive control.
    Instrument: the pkg/daemon test binary at 3d81b3703, run through
    test2json and scored per cell by test name.
    - Positive control, a network namespace with no route
      (`unshare -rn`): both cells failed 20 of 20, with "dial udp
      192.0.2.10:514: connect: network is unreachable" and then "want
      exactly one installed client, got 0".
    - Isolated, both cells x500 in the host namespace: 0 of 500 each.
    - Full pkg/daemon, 10 sequential runs: 0 of 10 each.
    - Full pkg/daemon, 10 rounds of 3 concurrent copies (load 14-65):
      0 of 30 each.
    - Full-tree make test, observational: 0 failures in 3 runs. That
      cannot refute the reported ~1 in 7: (6/7)^3 = 0.63.
  - **File(s)**: none (measurement only)
- **Timestamp**: 2026-09-10
  - **Action**: Isolated the variable. Same user and network namespace,
    loopback up, same binary, full pkg/daemon:
    - with a default route via lo (192.0.2.10 routable): 19 top-level
      failures, all user-namespace artefacts (systemd-resolved,
      sethostname);
    - with no route: 21 failures, exactly those 19 plus the two `_6829`
      cells.
    Every other syslog cell that asserts an installed client already
    dials 127.0.0.1. So routability of the off-box collector is the one
    variable that turns red exactly the reported pair and nothing else.
    It is sufficient for the report. That the observers' runs actually
    lost the route is not shown.
  - **File(s)**: none (measurement only)
- **Timestamp**: 2026-09-10
  - **Action**: Fix. Both cells, and every subtest that needs an installed
    client, point at a loopback UDP sink the test owns
    (loopbackSyslogSink9359) instead of 192.0.2.10/.11:514. Their
    client-count fatals print the captured warnings, so a construction
    failure names its cause. After the fix, the no-route namespace runs
    both cells 20 times with 0 failures (before: 20 of 20).
  - **File(s)**: pkg/daemon/syslog_selector_render_5797_test.go,
    docs/log/9359.md
