# 13689 — Break equal-tier static NAT block ties by prefix length

## Boundary

Static NAT block rules were selected by context tier alone. When overlapping
rules shared a tier, the first installed block won even when a later block had
a longer prefix. DNAT prefix lookup already ranks context tier first and then
longest prefix, with first-seen order reserved for equal-tier/equal-length
ties.

## Fix

- Preserve the existing static NAT context-tier precedence.
- In the forward block scan, select longer external prefixes among equal-tier
  matches; in the reverse scan, select longer internal prefixes.
- Keep first-seen order for equal-tier/equal-length matches. Exact host-entry
  lookup remains ahead of block scanning.
