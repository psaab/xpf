## Why

The wording is only true on the lenient arm, where the unknown keyword is
warned about and skipped and the committed config silently lacks the subtree.
On the strict arm the commit is refused, so nothing commits, renders, or takes
effect — the message describes an outcome the gate itself prevents. An
operator reading the refusal is told their bad config committed.
