# #16761 — cluster README no longer tells operators to keep config sync off until #6629

- **Timestamp**: 2026-10-25
- **Action**: `pkg/cluster/README.md` "Generating and distributing the key"
  still described the config-sync stream as "HMAC-authenticated but not
  encrypted", told operators the cleartext PSK crosses the control segment
  on the restore re-sync, and advised leaving
  `configuration-synchronize` off on a keyed cluster "only once #6629
  lands" — backed by a controlled single-node outage procedure to delete
  the stanza on both nodes and paired manual config management
  afterwards. #6629 (sealed config payload, ephemeral X25519 per
  connection) and #15041 (no cleartext fallback on authenticated
  connections) have both landed, and the same README's later "Config sync
  and the PSK (#6629)" section already stated the current posture, so the
  operator contract contradicted itself.

  Rewrote the section to the current posture: out-of-band key
  provisioning is retained, but its rationale is now bootstrap trust on
  the first (still-unkeyed, active-MITM-open) connection rather than
  passive-observer confidentiality; same-vintage peers seal the payload
  (#6629, forward-secret per connection), authenticated connections have
  no cleartext fallback at all (#15041), and cleartext plus the latched
  `Config cleartext` alarm applies only against a pre-#6629 peer, with
  PSK rotation after the mixed-version window closes. Deleted the
  delete-on-both-nodes outage procedure, the paired-manual-management
  cost paragraph, and the "until #6629 lands" gate; the section now says
  `configuration-synchronize` may stay enabled on a keyed cluster, keeps
  the active-MITM-on-unkeyed-link and never-sever-the-control-link
  caveats, and notes the retired procedure buys nothing over
  same-vintage sealing. Also fixed the Recovery row-3 cross-reference
  that pointed at the deleted procedure ("Same stop-one-node shape
  documented above for `configuration-synchronize`") to describe the
  shape inline. No code changed.
