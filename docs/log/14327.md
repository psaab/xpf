# #14327 — Degraded local pass short-circuits the native-GRE inner gate

## Defect
`is_degraded_local_or_control` (userspace-xdp/src/lib.rs) returned `true`
from an unconditional `if destination_is_local { return true; }` before
the #10651 native-GRE arm. A native-GRE frame's outer destination is the
local tunnel endpoint by construction, so during any degraded window
(helper restart, RG transition, stale/missing heartbeat, unready
binding) every outer-local native-GRE frame passed straight to the
kernel (`cpumap_or_pass`) without `native_gre_inner_pass_steers_to_kernel_typed`
ever classifying the inner packet. The #10651 arm was reachable only
when `destination_is_local == false`, where its typed predicate is
`false && _ == false` by construction — dead for its only true case.
Inner transit the healthy path keeps in userspace (inner action !=
PASS_TO_KERNEL) was decapsulated and forwarded by the kernel with no
zone policy.

## Fix
- `userspace-xdp/src/gre_classify.rs`: new host-executable predicate
  `degraded_general_local_pass_applies(is_native_gre, destination_is_local)`
  = `destination_is_local && !is_native_gre`, in the existing core-only
  module so the host test runs the real decision (not a source model).
- `userspace-xdp/src/lib.rs`: `is_degraded_local_or_control` computes
  `native_gre` once (`protocol == PROTO_GRE && NATIVE_GRE flag`), gates
  the general local pass through the new predicate, and reuses
  `native_gre` for the #10651 arm (same condition, no second flag read).
  Native-GRE frames — local or not — now reach the typed inner gate;
  only inner PASS_TO_KERNEL with a local outer passes to the kernel.
  Every other local packet keeps the degraded local pass unchanged.
  NOT changed: the subsumed NDP arm above (cosmetic, already covered by
  the local pass for non-GRE; for GRE the protocol check excludes it),
  the ESP/interface-NAT arm (non-native tunnel disposition), and the
  healthy path.

## Regression
- `userspace-dp/src/afxdp/frame/tests_shim_gre_classify_10651.rs`:
  new `degraded_native_gre_local_outer_requires_inner_pass_14327`
  composes both host-executed predicates exactly as the shim does
  (general local pass, then the typed #10651 gate) over
  (native GRE, local outer, inner 0/REDIRECT/PASS_TO_KERNEL) plus
  non-local and non-native controls: inner != PASS returns false
  (drop/degraded-transit), inner == PASS returns true.
- RED: on pristine origin/master the test fails to compile
  (`degraded_general_local_pass_applies` absent); restoring the
  pre-fix guard semantics (`destination_is_local` alone) flips the
  first two rows red. GREEN with the fix (see PR Validation).
