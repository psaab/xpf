# #13205 — align QEMU validation with host access and scenario needs

## Why

The direct-QEMU boot leg checked only whether `/dev/kvm` existed, although
`bake.py` treats read/write access as the capability boundary. A present but
inaccessible device therefore bypassed the skip and failed while starting QEMU
with KVM acceleration. Separately, a Q-only run still created an Incus network
and imported the multi-GB image even though that scenario uses direct QEMU.

## What

- `scripts/image/validate.py` now checks `/dev/kvm` with
  `os.access(path, os.R_OK | os.W_OK)` and reports the access result when the
  optional boot leg is skipped. The boot leg remains a tolerated skip because
  `bake.py` explicitly supports TCG bake hosts.
- `main()` bypasses Incus setup/import for a Q-only run. It explicitly calls
  `verify_signatures()` in that branch because import previously performed
  signature verification as a side effect. Runs with any non-Q scenario retain
  the existing Incus flow.
- `scripts/image/test_validate_skip_ledger_7347.py` adds coverage for the
  inaccessible-KVM skip, Q-only Incus bypass with signature verification, and
  non-Q Incus behavior.

## Validation

- **RED on pristine master (`dd607606a`)**: the new KVM access test failed
  because the skip reason reported `kvm=True` rather than the access result;
  the Q-only test failed because `ensure_network` and `import_image` were
  called. The Q-only failure verifies the extra Incus setup was present before
  the fix.
- **GREEN**: `python3 scripts/image/test_validate_skip_ledger_7347.py` — 17
  tests passed.
- **GREEN**: `for f in scripts/image/test_validate*.py; do python3 "$f" ||
  exit; done` — all validation test modules passed.
- **GREEN**: `python3 -m py_compile scripts/image/validate.py
  scripts/image/test_validate_skip_ledger_7347.py`.

## Risk

The KVM-accelerated boot leg now skips on hosts that have `/dev/kvm` but lack
read/write permission, matching the preflight capability check. Q-only runs
still verify artifact signatures, but no longer require or mutate Incus state.
Other scenario combinations keep their existing Incus validation path.
