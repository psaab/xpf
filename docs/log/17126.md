# #17126 — R4-Q15-02: reconcile tail open-coded in forwarding/binding/queue handlers

- **Timestamp**: 2026-10-27
- **STEP-0 — defect live on current origin/master?** Yes, at `16db8c584e`.
  `grep -c 'reconcile_status_bindings(guard)' userspace-dp/src/server/handlers/{forwarding,binding,queue}.rs`
  gave 1/1/1: `forwarding.rs:56-72`, `binding.rs:57-70`, `queue.rs:64-77` each
  hand-wrote the same tail — on `Err`: `ok=false`, `format!("<verb> reconcile
  failed: {err}")`, `restore_binding_arm_state(prior)`, `refresh_status`, return
  without persist; on success: arm the 2 s settle, `refresh_status`,
  `persist_state = true`. #6750 had unified only the capture/restore step
  (`BindingArmSnapshot`); the tail stayed in three copies. `rebind` and
  `update_ha_state` were re-verified as correctly excluded: rebind commits no
  requested state (it clears runtime bits `refresh_status` re-derives), and
  HA applies through `afxdp.update_ha_state`, not this reconcile.
- **Fix.** New `helpers::finish_binding_reconcile(guard, response, verb, prior,
  settle, persist_state, settle_wait)` in `userspace-dp/src/server/helpers/status.rs`
  (next to `capture/restore_binding_arm_state`) owning the whole tail: reconcile,
  on `Err` report `"<verb> reconcile failed: {err}"` + restore prior + refresh +
  no settle/no persist; on success settle (if owed) + refresh + persist. The
  three handlers keep only their commit (the requested bits written into
  `guard.status`) and their settle rule, expressed as the `settle` argument:
  forwarding settles only when arming; binding/queue reach the helper only when
  the registration changed, so they pass `settle = true` and then `return`
  (preserving the original early-return shape — the trailing refresh+persist
  for the unchanged case stays in the handlers). Added imports:
  `ControlResponse` + `std::time::Duration` in `status.rs`. Handler imports of
  `reconcile_status_bindings` / `restore_binding_arm_state` removed where now
  unused. `userspace-dp/src/server/README.md` records the helper in the
  `reconcile_status_bindings` bullet.
- **Acceptance, measured:** `grep -c 'reconcile_status_bindings(guard)'` over

- **New test:** `faulted_reconcile_three_verbs_share_the_finish_tail_17126`
