# #17065 — single RT_FLOW field mapper for logEvent and DecodeRawEventRecord

- **Timestamp:** 2026-10-27
- **Branch:** `fix/17065-campaign`
- **Files:** `pkg/logging/ringbuf.go`, `pkg/logging/map_raw_event_parity_17065_test.go`, `pkg/logging/README.md`, `pkg/dataplane/userspace/eventstream.go`, `pkg/dataplane/userspace/eventstream_gate_17065_test.go`

## Why

Since #16127 unified only the wire parser, `logEvent` and
`DecodeRawEventRecord` still hand-mapped the same RT_FLOW frame into
`EventRecord` twice (the pair diverged in production in #2511), and the
userspace event stream paid a full decode (392 B / 18 allocs per frame)
on every frame whose record it then discarded in favour of the raw
payload.

## What

- Extract `mapRawEvent(evt, data, policyDenyStamped) EventRecord` in
  `pkg/logging/ringbuf.go` holding every wire-derived rule (type
  gating, #2853/#3056 close slot reuse, the [144:152] block, #4915
  session id, stamped-deny RuleID/PolicyName). `DecodeRawEventRecord`
  is parse + `mapRawEvent`; `logEvent` is parse + `mapRawEvent`, then
  name resolution, ElapsedTime, EventSeq and the SessionID ordinal
  fallback as explicit post-steps. Exactly one `rec.TOS =` remains in
  non-test `pkg/logging`.
- Explicit decision on open ToS/flags: read from the wire (the producer
  writes 0 there on creates today, so no observable change).
- Preserved intentional divergences: the decoder zeroes non-close
  session counters (unified mapper never sets them off-close), the
  live path resolves/stamps names, EventSeq, ElapsedTime, and falls
  SessionID back to the ordinal when the mapper left 0.
- Add `ValidRawEvent(data) bool` (length + parse, 0 allocs) and use it
  at the `eventstream.go` gate: a record is decoded only when
  `onDataplaneEvent` will consume it or pending frames are queued;
  otherwise (raw callback installed — the production wiring — or no
  consumer) only validity is checked and the zero record is never read.

## Validation

- Named hermetic cells only: `TestMapRawEventParity17065` (14 golden
  frames: open/close at 144/152/160/168, deny plain+stamped, screen,
  filter; both entry points field-identical on all wire-derived
  fields), `TestValidRawEvent17065` (gate/verdict agreement + 0
  allocs), `TestEventStreamGateValidatesWithoutDecode17065`,
  `TestDispatchRawSkipsRecord17065`,
  `TestDispatchQueuedFrameDecodesOnFlush17065` — all pass.
- Benchmarks: `BenchmarkValidRawEvent17065` and
  `BenchmarkEventStreamGate17065` report 0 B/op, 0 allocs/op.
- Full `pkg/logging` suite passes. Eventstream-focused cells pass
  (socket cells need a short GOTMPDIR; the long-path unix-socket
  `invalid argument` failure is environmental). One unrelated
  full-suite failure, `TestRetryDebtRetryConvergesAndSteadies9642`,
  fails identically on clean master — pre-existing, not caused here.
- NOT-EXAMINED: cluster/smoke gates (no dataplane forwarding change;
  record content is field-identical by the parity pin).

## Risk

Bounded to record construction and the event-stream gate. The one
behaviour-adjacent change is reading open-frame ToS/flags from the
wire (0 on every real producer frame). The gate decodes queued frames'
records eagerly exactly as before, so pending-queue delivery is
unchanged; raw-path accounting and ACK behaviour are pinned by the
dispatch cells.
