# #15156 — IGP export chain and BGP origination rendered one redistribute per policy per source (B07-01)

- **Timestamp**: 2026-10-19
- **Action**: An IGP `export [ P1 P2 ]` chain (OSPF/OSPFv3/RIP/IS-IS), and
  the #14586 BGP origination across several neighbours' policies, emitted
  one `redistribute <proto> route-map <policy>-<proto>-xpf-redist` line
  per policy for one source. FRR keeps one route-map per (router, AF,
  source), so only the last line took effect: `export [ NO-RFC1918
  STATICS ]` originated RFC1918 statics the reject policy was written to
  block. Fixed by composing per source: exactly one `redistribute` per
  (router, AF, source) — bare-token sources stay bare, a single-policy
  source keeps `<policy>-<proto>-xpf-redist`, and a multi-policy source
  names `<P1>-<P2>-xpf-chain-<proto>-xpf-redist`, whose per-source
  filtered terms run in chain order (IGP) or sorted OR-union order
  (BGP), terminal actions stay terminal, `next policy` jumps to the
  next member, explicit defaults terminate, and fall-off-the-end is
  deny (the protocol default; fail-closed for BGP origination).
  `redistChainMapCollision15156` (in `ApplyFull`) fails the apply
  closed if a composed name collides with an operator policy-statement
  or another generated map. NOT changed: single-policy and bare-token
  renders (byte-identical), per-peer `route-map out` composition
  (#5277), and QNH metric maps for single-policy/bare static entries;
  a composed multi-policy static entry keeps its composed map without
  the QNH metric overlay (deferred residual, fail-closed direction:
  routes still filtered, metric unapplied).
- **File(s)**: `pkg/frr/redistribute.go` (composed naming, chain entry
  resolution, composed-map rendering, collision guard, chain resolvers),
  `pkg/frr/protocols_render.go` (OSPF/OSPFv3/RIP/IS-IS chain call sites),
  `pkg/frr/manager.go` (collision guard + composed-map emission),
  `pkg/frr/redistribute_chain_15156_test.go` (new),
  `pkg/frr/frr_test.go` + `redistribute_afi_9510_test.go` +
  `redistribute_family_9667_test.go` (chain-aware expectations/censuses),
  `pkg/frr/README.md`, `docs/log/15156.md`

## Risk

Composed redistribute maps are new generated route-maps in FRR's
global namespace; the collision guard fails the apply closed rather
than merging. Single-policy configs see no change. The QNH metric
overlay deferral for composed multi-policy static chains is the one
known residual: filtering is unaffected, only the qualified-next-hop
metric is unapplied for that shape.
