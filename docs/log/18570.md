- **Timestamp**: 2026-10-30 17:00 PDT
- **Action**: Bound the sync-recency suppression of the heartbeat timeout
  with a sync-channel liveness probe. A peer that proved heartbeat-ack
  support must answer a probe sent while its heartbeats were already late:
  `checkTimeout` pre-arms the probe one tick before the timeout
  (`prearmPeerLivenessProbe`), and `syncSuppressesPeerTimeoutLocked`
  suppresses a timeout tick only if a sync frame arrived after the

  the next probe. `SessionSync.RequestLivenessProbe` writes from a goroutine
  (one in flight) so nothing blocks under `Manager.mu`.
