# #13199 — remote destination NAT pool identity and filtering

- **Finding:** D10-03 reported that `cmd/cli` keyed destination NAT pools by
  translation address while `GetNATRuleStats` identifies actions by configured
  pool name. This caused every summary hit count to be zero, showed the address
  as the pool name, and made `destination pool <name>` ignore its selector.
  Summary rendering also swallowed stats RPC failures.
- **Fix:** Add the configured `pool_name` as an additive field on
  `NATDestInfo`, populate it from `rule.Then.PoolName`, use it to join hit
  counters and render names, and sort summary/detail rows deterministically.
  Carry the optional pool selector to the destination-pool renderer, report
  unmatched names, and return stats RPC errors instead of printing fabricated
  zero hits. When talking to an older daemon that does not send `pool_name`,
  the client falls back to the translated address.
- **Regression:** `cmd/cli/show_nat_13199_test.go` covers named-pool hit joins,
  deterministic ordering, pool filtering and unknown-pool errors, and stats
  RPC error propagation. `pkg/grpcapi/nat_view_10437_10438_test.go` verifies
  the server fills `pool_name` from the configured rule.
- **RED:** On pristine `origin/master` at `f7492bd5c`, temporary
  `TestIssue13199PristineSummaryRegression` failed as expected: the summary
  rendered `192.0.2.10/32` in the Pool column and `0` hits despite a
  `pool web-pool` stats response with 42 hits. A separate
  `TestIssue13199PristineFilterRegression` failed because `destination pool
  web-pool` printed the unrelated `mail-rule`.
- **GREEN:** `go test ./cmd/cli/ -run 'TestShowNATDestination' -count=1 -v`
  passed all three CLI regression tests. The full CLI suite passed with the
  pre-existing `TestTreeIsGofmtClean` gate excluded; that gate fails on
  pristine master too. `go test ./pkg/grpcapi -count=1` passed. `go build
  ./cmd/cli ./...` and `go vet ./cmd/cli/` passed.
- **Scope:** No local `pkg/cli` renderer changes; this finding concerns the
  remote `cmd/cli` path and its gRPC projection.
