## Bisect instruction

### A. Bisect the build breakage itself (demonstrated probe)

The only classifier this audit demonstrates endpoint-relative for this
series is `go build ./pkg/cluster/` itself: it passes (exit 0) at the
pre-series base and fails at a broken commit. Bisect for the build
breakage with a broken commit — not the compiling tip — as the bad
endpoint:

```sh
# Use a writable TMPDIR if the system temp directory lacks space:
export TMPDIR=/path/with-space
git bisect start
git bisect bad  55864e1f0f646e8903b3a8418aa8266859eef546   # last broken commit (does not build)
git bisect good dc2b0ee66f287ac66dbab0dc8af99c309ced9892   # pre-series base (builds)
git bisect run sh -c 'go build ./pkg/cluster/ >/dev/null 2>&1'
```

commands above report `5aa58afe110958366c5293e02f457546e81b8777 is the
first bad commit` — the start of the contiguous broken run. No `125`
skip is needed for this probe: a build failure *is* the bad verdict.

### B. Bisect a future regression (bring your own endpoint-checked probe)

For any other regression, the reader must supply a regression-specific
probe and demonstrate it at both endpoints *before* starting: it must
exit 0 at the chosen good endpoint and exit non-zero (a genuine test
failure, not a build failure) at the chosen bad endpoint. `git bisect
run` trusts the declared endpoints and does not re-run the probe
against them, so an endpoint that passes the probe silently corrupts
the search.

In particular, do **not** use `go test ./pkg/cluster/ -run 16880
-count=1` as a bad-tip oracle at `be4cbf62e0`: that predicate passes
(exit 0) at the series tip, so it classifies the supposed bad endpoint
as good.

```sh
export TMPDIR=/path/with-space
# Replace MyRegressionTest with the exact regression test/probe.
# Demonstrate it first at both endpoints:
#    git checkout <good-sha> && go test ./pkg/cluster/ -run 'MyRegressionTest' -count=1   # must exit 0
#    git checkout <bad-sha>  && go test ./pkg/cluster/ -run 'MyRegressionTest' -count=1   # must fail for the regression
# 2. Only then bisect, skipping the six non-compiling commits —
#    never judge them good or bad:
```
