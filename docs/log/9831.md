- **Timestamp**: 2026-09-11
- **Action**: Cause. In the leaf branch of `mergeNodes`, `leafListPeer(*dst, key)`
  returns the first leaf, or single-key node, whose `Keys[0]` equals the
  keyword. An inline leaf naming a different zone therefore took the
  inline-wins override, and the group's zone was skipped.
- **Action**: Fix, general to named instances. A named instance is a container
  whose schema declares instance args (`groupNamedInstanceSchema9831`). For
  one, the inline peer is the node naming the same instance, keyword plus
  instance keys (`sameInstancePeer9831`).
  - A different instance is adopted.
  - A same-instance peer keeps the existing #7648 and override path.
  - A group list `security-zone [ zga zgb ];` is now adopted, and the #9656
    zone-statement check then refuses it on strict.
