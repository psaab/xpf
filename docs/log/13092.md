# Issue #13092

- Discovery: deep-review D8-14, source report run `review-work.2e4cldwkh1`.
- Mechanism: dynamic-neighbor status called `ShardedNeighborMap::len`, which used `with_all_shards` and retained all 64 shard mutexes while summing. CoS status collection deep-cloned worker snapshots, traversed binding active-flow rows twice, and cloned their vectors. Go CoS metric emitters accepted the large `ProcessStatus` by value.
- Fix: `len` now acquires/releases one neighbor shard at a time; coordinator aggregation borrows shared `Arc` snapshots; one combined CoS status method loads each binding active-flow Arc once for both API output and queue overlay. Go CoS queue metrics use one pointer-indexed pass, reusing interface and queue label strings across metric families; active-flow count rows retain their separate pass. Status contents and truncation behavior remain unchanged.
- Regression: `len_releases_each_shard_before_waiting_for_the_next` uses a synchronous barrier after shard 62 and proves shard 0 is available while the production `len` traversal waits to acquire shard 63. RED on pristine `origin/master` SHA `0de6898319808d755f54736f6d18022e47f9a455`: test failed with `len held shard 0 while waiting for shard 63` (0 passed, 1 failed). GREEN: same test passed (1 passed, 7916 filtered). A Go parity test compares the combined metric pass against all eight individual emitter outputs across owner, equal-flow, lease, and waterfill sentinel cases.
- Validation: `go test ./pkg/api` passed. Full Rust suite: 7908 passed, 1 failed, 8 ignored; `protocol::tests::wire_invariant_default_specimens` failed due to protocol fixture drift. Confirmed the same test fails on pristine `origin/master` with the same drift, so it is base-attributed and unrelated to these code changes.
- Scope: did not split `coordinator/status.rs`; behavior and required data shape are preserved while removing the all-shard convoy, duplicate active-flow snapshot load/traversal, redundant status deep clones, large emitter argument copies, and repeated CoS queue traversals/label formatting.
