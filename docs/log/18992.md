# Issue #18992 — correct the RETH VLAN test gate premise

## Why

At base `1348368e5c`, `TestRethUnitNumberVsVlanIDStrictReject14573` failed because its assertion expected the #14573 collision to name `reth1.200`, but strict compile refused the untagged non-zero `reth1 unit 100` first under #15034/#16583. The old migration comment incorrectly claimed `vlan-tagging` on the parent made the unit exercise the collision check.

## What

Restored `TestRethUnitNumberVsVlanIDStrictReject14573` as the full strict-pipeline collision cell. Its `tunnel mode gre` stanza is source-less: it satisfies the #15034/#16583 AST exemption without creating a `TunnelNameMap` entry. Unit 100 therefore still resolves by unit number and unit 200 by `vlan-id 100`; both resolve to `ge-0-0-1.100`, which the #14573 check refuses. The separate `TestRethUnitNumberVsVlanIDUnitGatePrecedesCollision14573` retains the same fixture without that stanza and pins the earlier #15034 refusal. `TestRethDuplicateVlanIDStrictReject14573` remains the duplicate-tag collision pin. No production gate or order changed.

The #15034/#16583 predicate (`untaggedNonzeroUnit15034`) only applies to non-zero unit numbers (unit 0 is outside the gate); for those units it requires a positive tag unless the interface is `irb`, a loopback (`lo<N>`), a secure tunnel (`st<N>`), or the interface/unit contains a tunnel stanza. There is no `lt*`, `gr*`, or `ip*` name-family exemption. `reth1` has no class exemption; parent `vlan-tagging` does not tag unit 100. `vlan-id 0` is the untagged sentinel, not a positive tag or exemption; existing `TestUntaggedNonzeroUnitRejected15034` pins both that case and an untagged reth unit. The source-less GRE stanza is a strict-fixture credential only, not a runtime tunnel claim: `TunnelNameMap` includes an interface tunnel only when it has a source or WireGuard mode, so this stanza leaves ordinary member resolution intact; GRE endpoint emission also requires both endpoints. A complete GRE tunnel instead maps both refs to `reth1`, and a per-unit tunnel is skipped by the sub-interface collision pass.
