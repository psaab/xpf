# #17134: type the snapshot `userspace` subtree and move the Phase 0 audit to Go

- **Timestamp**: 2026-10-27
- **Action**: Implemented the named fix. STEP-0: defect was live on
  current `origin/master` (`303ae6adfa`):
  `userspace-dp/src/protocol/snapshot.rs:914` —
  `pub userspace: serde_json::Value`; `shared_umem.rs` read
  `phase0_artifact` / `interface_names` / `artifact` keys no Go build
  emits since #5300; `config_snapshot_populated.userspace` was `null`
  in the #16132 fixture.
- **Change**:
  - Rust: `ConfigSnapshot.userspace` is now the typed
    `UserspaceSnapshot { workers, ring_entries, shared_umem:
    Option<SharedUmemSnapshot { mode, interfaces,
    phase0_artifact_file }> }` (serde defaults, null-tolerant scalars,
    unknown keys tolerated — no `deny_unknown_fields`). Deleted the
    dead Rust Phase 0 audit chain (`:304-557`: `log_phase0_audit`,
    environment comparison, PCI/driver/MTU/queue readers) and its 2
    audit tests; the binding-plan key now hashes the typed fields with
    sorted interfaces instead of canonicalising untyped JSON (dead
    canonical-JSON helpers removed).
  - Go: `sharedUMEMAuditWarnings` now owns the environment audit —
    unified strict passed predicate (`passed == true` or pass status)
    plus kernel/PCI/driver/MTU/queue-topology comparison against the
    live host (seamed via `sharedUMEMLiveEnvFn` for hermetic tests).
    Deleted `normalizeSharedUMEMArtifactInterfaces*` (its only
    remaining effect was a duplicate-name warning) and updated the
    tests that pinned it.
  - Wire fixture: `config_snapshot_populated` now carries a populated
    typed `userspace.shared_umem`; new `userspace_snapshot` /
    `shared_umem_snapshot` specimens map to `config.UserspaceConfig` /
    `config.SharedUMEMConfig` in the Go #16132 gate, plus a nested
    strict-decode cell (`TestWireUserspaceSharedUmemPopulated17134`).
    Drive-by of the same class: `route_snapshot_populated` now pins
    `next_table_route: true` (#16614, was red on master).
  - Docs: `docs/shared-umem-plan.md` and
    `pkg/config/types_system.go` now name the Go compile-time audit as
    the environment-mismatch warner.
- **Acceptance**: `grep -rn '"phase0_artifact"\|"interface_names"\|get("artifact")' userspace-dp/src` returns 0. `ConfigSnapshot.userspace` is a typed struct. `protocol_wire_v1.json` carries a populated `userspace.shared_umem` specimen the Go #16132 cell checks. Go tests show kernel and MTU mismatch warnings for fixture artifacts.
- **Validation**: Named hermetic cells only (`-- --exact` / `-run '^Name$'`); see PR body.
- **Risk**: Rolling upgrade: unknown keys stay tolerated and
  `userspace: null` decodes as default, so older daemons pair with the
  new helper. The audit stays non-gating (warnings only, never changes
  the typed config). The duplicate-after-normalisation artifact error
  is gone by design (#17134 direction (3)).
