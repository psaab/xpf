# #12823 — Inline `default-policy` overrides group choices

- **Timestamp**: 2026-10-13 (`fix/12823-campaign-pub`)

## Why

`default-policy` is represented as a valued leaf for flat-set support, while its Junos block spelling (`default-policy { deny-all; }`) is a single-choice container. Generic recursive group merging appended the group choice to the inline choice. The expanded AST therefore contained two children and strict compilation rejected the valid inline override under #11367; tolerant compilation warned and failed closed even though the author supplied a decisive inline value.

## What

- Keep per-expansion provenance for group-adopted choice blocks so a second
  conflicting group remains a group-vs-group conflict rather than being
  mistaken for inline precedence. This bookkeeping does not reuse #9862's
  exclusion-provenance field. Group conflicts without inline resolution and
  same-tier ambiguity retain existing fail-closed behavior.
- Treat an inline `default-policy` block as a higher-precedence replacement
  for a group block, suppressing the inherited choice before it can create a
  false multi-child ambiguity.
- Add regressions for flat/block inline overrides, equal values, group-only inheritance, conflicting groups with and without inline resolution, same-tier ambiguity, and sibling application isolation. Update config behavior docs.

It covers flat and block overrides, equal values, inherited-only groups, conflicting groups with and without inline resolution, same-tier ambiguity, sibling isolation, and adjacent #11367/#11821/#12821 controls.

## Risk

Only group merging of the Junos `default-policy` block choice changes. Flat
values, other block-value leaves, strict/tolerant same-tier ambiguity, and
unresolved conflicting groups preserve existing semantics. No live dataplane
or cluster was modified.
- **Nested-group fold (review B1)**: OUTER permit + INNER deny nested groups strict-reject / tolerant-deny (pre-marking group-body clones); deep group bodies (>256) no longer panic the marker walk (append-grown path + regression).
