# Issue #13722

## Change

Select the lexically first sampling instance in `buildFlowExportSnapshot`, matching the precedence already used by `pkg/flowexport`. This removes Go map iteration from the reserved FlowExport snapshot field and makes identical configuration builds produce stable collector/rate values and snapshot hashes. Added a regression with 32 competing instances, unique collectors/rates, and repeated builds.

## Residual risk

The wire field is currently decoded and ignored by the Rust helper; deterministic selection nevertheless avoids unstable snapshot content hashes and preserves the documented lexical precedence if the field is consumed again.
