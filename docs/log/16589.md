# #16589: paged idle/display persistent-NAT lease exports

- **Timestamp**: 2026-10-24
- **Action**: `export_idle_leases` and `export_persistent_lease_display`
  built one unpaged JSON response. At a legal idle population
  (measured 361 B/lease at 4 remotes → cap crossed ≈186k; 535 B at 10
  remotes → ≈125k, both below one pool's 262,144 tracked cap) the
  response crossed the 64 MiB control cap, Go's bounded reader refused
  it, and every 30 s idle-lease push delivered NOTHING to the standby
  — after failover every idle subscriber's persistent mapping was
  gone. The SHOW display export failed the same way. Fixed by paging
  both verbs with the #9344 shape:
  - Wire (additive, v70→v71): request `lease_export {paged, cursor,
    max}`, response `lease_export_more` /
    `lease_export_continuation`. `CONFIG_SNAPSHOT_PROTOCOL_VERSION`
    and Go `ProtocolVersion` bumped together to 71 so a pre-paging
    helper — which ignores the request field and answers unpaged —
    is refused by exact equality instead of silently crossing the
    cap; `MinProtocolPersistentNatLeasePaging = 71` gates both Go
    exports before any lease request crosses.
  - Helper: both handlers materialize the population, sort it by the
    full wire identity (the allocator's map order is nondeterministic,
    so raw-order paging would skip/duplicate), and cut one page under
    a count ceiling (8192) AND a serialized byte budget (half the
    cap). An unpaged (pre-#16589) request still gets the single-shot
    answer. Bad/out-of-range cursors refuse.
  - Go: `ExportIdleLeases` / `ExportPersistentLeaseDisplay` follow
    continuations via `pagedLeaseExport16589`, failing closed on a
    repeated/empty-with-more/complete-with continuation, a page
    error, or 2048 pages — a partial population is never returned as
    complete. Small populations stay single-page (one request).
  - Deadlines (#11840 shape): `controlVerbDeadlineFloors9344` gains
    both verbs at five half-cap passes at 10 MiB/s plus one round
    trip (≈19 s), far below the #7675 67 s bound.
  - Acceptance: Rust cells seed 300k remote-less leases (unpaged
    control asserted > cap) and 150k × 4 remotes, paging each with
    every serialized page ≤ `MAX_CONTROL_RESPONSE_BYTES` and exact
    reassembly; Go cells drive both Manager methods over a real
    socket through scripted pages, the fail-closed arms, the
    pre-paging refusal, and the deadline floors.
