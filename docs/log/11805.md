# #11805 — expose local auto-archive degradation

- **Timestamp**: 2026-10-02
- **Action**: Report local automatic archive scan, write, and rotation failures
  through a store latch, journal entry, health field, and Prometheus metrics.
- Archive failures remain non-fatal to config commits because the active config
  has already persisted. A later archive clears the degraded gauge only after
  both its archive write and rotation succeed; the failure counter and journal
  remain historical.
- A commit-time sequence scan failure still skips that archive rather than
  writing a sequence that could cause rotation to discard the wrong snapshot.
  Rotation scan/removal failures now propagate from `writeArchive`, allowing the
  auto-archive owner to report incomplete retention.
