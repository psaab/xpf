# docs/log/12550.md — #12550 (verify retained MAC-form .link identity)

- **Timestamp**: 2026-10-13
- **Action**: Before retaining a MAC-form `Name=<current>` `.link` without `OriginalName=`, compare its `MACAddress=` with the NIC's permanent MAC (falling back to its running MAC only when no permanent MAC is exposed). A mismatch or unreadable observation removes the managed link and reports an error; unreadable identity is distinct from mismatch.
- **Files**: `pkg/daemon/linksetup.go`, `pkg/daemon/bootstrap.go`, `pkg/daemon/linksetup_originalname_12156_test.go`, `pkg/daemon/linksetup_retained_mac_12550_test.go`, `docs/log/12550.md`

## Why

#12156 correctly retained a name-only MAC-form `.link` when a NIC already wore its target name because xpf could not safely invent a kernel `OriginalName=`. It did not verify that the MAC persisted in that file belonged to the NIC currently wearing the name. A stale file could therefore be selected by systemd for a different NIC on a later boot and assign it the trusted logical name.

## What

- Added a cold-path identity reader that prefers `PermHWAddr`, then uses `HardwareAddr` only when the driver exposes no permanent address. MAC addresses are parsed and compared as bytes, so letter case and separator spelling do not affect identity.
- Positional naming and bootstrap now verify retained MAC-form links on the same-name path. A mismatch removes the managed `.link`; an unreadable identity also removes it fail-closed while logging/reporting unreadable separately. A verified match is retained unchanged. Links with a valid `OriginalName=` and name-only links without `MACAddress=` do not enter this check.
- Added regression coverage for mismatch, match/retention, permanent-MAC preference, running-MAC fallback, unreadable identity, bootstrap's protected `fxp0` path, and unchanged handling of `OriginalName=` / no-MAC files. Updated #12156 healthy-retention controls to inject a verified matching identity.

## Validation

- `gofmt` applied to changed Go files.
- `go test ./pkg/daemon -run '12550|12156|6678|7205' -count=1` — PASS.
- `go test ./pkg/daemon -count=1` — PASS (full daemon package; 556.298s).

## Risk

If identity cannot be read, the stale MAC-form link is removed rather than preserved; the next boot will not allow that file to claim the logical name. This may lose boot-time persistence until a later naming pass writes a verifiable link, but avoids silently assigning the name to an unverified NIC. No live systemd daemon or cluster was changed.
