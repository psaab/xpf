# #10009 — termsafe threshold emission escaped a trailing partial UTF-8 rune

- **Issue:** At the #7389 bounded-emission path, `SanitizingWriter` passed the
  whole residual buffer to `SanitizeBlockForDisplay`. When the residual ended in
  a valid UTF-8 rune prefix, the sanitizer correctly treated those bytes as
  invalid at that point and rendered byte escapes. The same valid stream then
  rendered differently depending on the upstream `Write` boundaries.
- **Context read:** Read the complete #10009 body and all comments before
  editing. The issue had no comments; there was no withdrawal, narrowing,
  shipped notice, or contradictory direction.
- **Decision:** Retain only a bounded incomplete UTF-8 suffix at threshold
  emission. `utf8.RuneStart` plus `utf8.FullRune` identifies a valid prefix of
  a rune without treating malformed encodings as incomplete. The complete
  prefix is emitted through the existing sanitizer, while the suffix is copied
  into a fresh at-most-three-byte buffer for the next `Write`. Copying avoids
  retaining a potentially huge backing array from an upstream chunk. Invalid
  encodings remain in the emitted prefix and are escaped immediately. `Flush`
  still sanitizes an uncompleted suffix because end of stream makes it
  truncation, not a fragment awaiting another write.
- **Files:** `pkg/termsafe/writer.go`,
  `pkg/termsafe/writer_10009_test.go`

## RED → GREEN proof

- **RED (before the fix):**
  `go test ./pkg/termsafe -run 'Test(BoundEmissionRetainsPartialRune|BoundEmissionRuneDeliveredByteAtATime|BoundEmissionEscapesInvalidTailImmediately|FlushEscapesTruncatedTail|BoundHeldSuffixCompletedByInvalidByteStaysSafe)_10009'`
  failed the two valid-rune boundary tests. For every 2-, 3-, and 4-byte rune
  split, the pre-fix writer emitted the partial bytes as `\xHH` escapes (for
  example `\xc3\xa9` rather than `é`). The invalid-tail and Flush safety pins
  passed on the old implementation.
- **GREEN (after the fix):** The same selector passed for all five issue test
  functions. The tests cover every split point for `é`, `€`, and `𝄞`,
  byte-at-a-time delivery, malformed/invalid tails at the bound, a held prefix
  followed by an invalid continuation, and Flush-time truncated-rune safety.
