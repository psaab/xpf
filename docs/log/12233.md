## Change

- `compileAddressBook` now assigns all address-set IDs in sorted order before expanding or writing any set memberships. Cross-kind members can therefore resolve through `AddrIDs` regardless of whether their set name sorts before or after the referencing set; deterministic address and set ID assignment is preserved.
- The regression checks both `A { address B; }` and `Z { address B; }` against their exact IDs and final address-membership pairs.
