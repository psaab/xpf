## Change

- Tolerant compilation marks only undefined-scheduler DENY/REJECT policies as `LenientContentDropped`; strict compilation still rejects the reference, and undefined-scheduler permits retain the #11071 inactive behavior.
- Existing lowering emits the `__unsupported__` sentinel so the userspace integrity preflight refuses the snapshot rather than installing the inactive deny. The mirror now reports the scope-qualified policy and scheduler name. Defined-but-off-window rules remain ordinary inactive rules.
- Updated the scheduler downgrade comment and added Go regression cells for DENY, REJECT, permit, defined-off-window, global-policy DENY/REJECT, the defined-scheduler guard under a mixed undefined-permit config, and action-gated scheduler mirror naming.
