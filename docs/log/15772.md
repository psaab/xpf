# #15772 - logical ingress leaves flowless inner addresses zeroed

- **Timestamp**: 2026-10-19
- **Action**: `build_logical_ingress_packet_with_ethernet` in
  `userspace-dp/src/afxdp/logical_ingress.rs` now stamps
  `flow_src_addr`/`flow_dst_addr` from the inner packet's L3 header via
  `parse_packet_source_from_frame`/`parse_packet_destination_from_frame`,
  independently of whether `parse_session_flow_from_frame` returns a
  ported `SessionFlow`. Flowless GRE/WireGuard/IPsec inner traffic
  (ESP/OSPF/other non-TCP/UDP/ICMP-query protocols, non-first
  fragments, ICMP errors) previously kept `0.0.0.0`/`::` in the meta, so
  `l3_enforcement_flow_from_meta` built a synthetic `0.0.0.0`/`::`
  enforcement flow and downstream routing/zone/policy adjudication ran
  on unspecified addresses. This matches the XDP shim contract, which
  always fills the addresses from the L3 header even for fragments.
  Ports remain flow-gated (a flowless packet has no ports); a truncated
  L3 header still leaves the addresses zeroed because there is no
  header to trust.
- **Validation**: New `flowless_addr_15772_tests` in
  `logical_ingress.rs` cover IPv4 ESP/OSPF, IPv4 non-first fragment,
  IPv4 ICMP error, IPv6 ESP, and bare-L3 (IPsec) inner packets, each
  asserting meta addresses equal the inner header addresses and that
  `l3_enforcement_flow_from_meta` yields the real addresses, plus a
  TCP control asserting ported stamping is unchanged. RED pre-fix
  (meta addresses `[0; 16]`), GREEN post-fix. The unrelated
  `flowless_slack_tcp_not_steered_by_port_except_pbr_9894` failure is
  base-attributed: verified failing identically on pristine
  `origin/master` (320c26c) with this change stashed.
- **Risk**: Fail-closed direction only. Packets whose L3 header is too
  short to parse keep zeroed addresses exactly as before. Ported
  TCP/UDP/ICMP-query inner traffic is byte-identical (addresses were
  already stamped from the parsed flow, which reads the same header).
  No change to `l3_session_flow_from_meta`'s refusal to key a session
  on an unspecified address.
