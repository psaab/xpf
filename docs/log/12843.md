# #12843 — D3-06: DHCP host-inbound advisory raw-ref lookup

## Claim (falsifiable)
`validateDHCPServerHostInboundBypassWarnings` (pkg/config/compiler_validate_warn_dhcp_hostinbound.go)
misses the #6460 warning when a DHCP group binds a padded unit ref (e.g. `ge-0/0/1.01`
for canonical `ge-0/0/1.1`), because line 166-167 does a raw `ifZone[ifn]` lookup
while `dhcpHostInboundZoneMap` keys are canonical (`zoneIfaceLogicalKeys` →
`SplitInterfaceUnitRef(...).Literal`). Second subclaim: `dhcpHostInboundZoneMap`
uses names-only `ZoneQuarantineExclusions(znames)` instead of config-scoped
`ZoneQuarantineExclusionsForConfig(cfg)`, so a zone quarantined only via the
recorded runtime name set (`cfg.ZoneQuarantineNames`, e.g. colliding only in a
node0/node1/groups view) is not excluded and the advisory attributes behavior to it.
