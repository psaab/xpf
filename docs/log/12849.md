# Publish all policy rejection reasons (#12849)

- **Issue**: #12849, research D4-01 (High).
- **Cause**: Full snapshot construction and scheduler-only policy republish stamped `Capabilities.PolicyContentRejected` from rule sentinels and address/CIDR checks but omitted the policy-zone and duplicate-identity checks already included by `PolicyContentRejectionReasons`. A helper-rejected snapshot could therefore have no refusal capability, preventing the HA pre-preflight disarm guard from recognizing it.
- **Change**: Both full-build and scheduler-republish stamps now append `collectPolicyZoneRejections` and `collectPolicyIdentityRejections` over the same policy rows they publish. Full build reuses its built zone rows for both the stamp and snapshot; republish uses its already-quarantined `next.Zones`. No policy enforcement or strict/tolerant acceptance doctrine changed.
- **Regression coverage** (`pkg/dataplane/userspace/policy_rejection_stamp_12849_test.go`): full-build stamp includes duplicate-rule-identity and defined-`any` zone rejection reasons; scheduler republish does the same; clean duplicate-free controls remain empty; full-build/scheduler stamps equal the standalone reason mirror.
- **RED evidence**: Before the source change, `go test ./pkg/dataplane/userspace -run 'Test(PolicyContentStampIncludes|SchedulerRepublishStampIncludes).*12849' -count=1` failed all four checks: full-build identity stamp was empty, scheduler identity stamp was empty, and both defined-`any` zone stamp paths were empty despite standalone reasons.
- **GREEN evidence**: The targeted regression command passed after the source change (`ok`, 0.108s). The change surfaced an invalid-zone fixture hidden by the old omission; `feedPolicyCfg` now declares its trust/untrust zone rows, retaining the fixture's intended healthy-feed premise. Its feed representability and scheduler/overlay reject-reason tests passed together (`ok`, 0.092s).
- **Validation**: `go test ./pkg/dataplane/userspace -count=1` passed (`ok`, 167.063s). `go build ./pkg/dataplane/userspace`, `go build ./...`, and `go vet ./pkg/dataplane/userspace` passed. `gofmt` was applied to changed Go files; `git diff --check` passed. No generic repository lint target is defined in the Makefile.
- **Blast radius / risk**: Capability rejection reasons feed existing fail-closed preflight/HA safety decisions and operator status. This change may now correctly cause prior-good/deny-safe behavior on malformed zones or duplicate identities in both snapshot publication paths; healthy snapshots remain unrefused. It adds no new validation arm and uses the existing standalone mirror collectors.
