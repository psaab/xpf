## Why

- A47-02: `SyslogClient` captured `os.Hostname()` at construction and the
  #9326 fingerprint had no hostname term, so after a rename every record
  carried the old device name until a stanza change or restart.
- A47-03: `slogLevelToSyslog` had no debug arm; Debug became Info (6), so
  an `any info` host received the debug firehose mislabelled and a debug
  host could not distinguish them.
- A47-04: `applySystemSyslog` `continue`d on a client build error with no
  retry debt, so the off-box system log stayed off until a later commit.
- A47-05: CLI `reloadSyslog` unconditionally replaced the daemon's client
  set with dialing-constructor clients, paying a dial per stream and
  tearing down healthy connections on every console commit.
- A47-06: `applySyslogConfig` was all-or-nothing; any skipped stream left
  the fingerprint unset and debt armed, so every 30 s tick replaced the
  whole set and re-warmed every healthy TCP/TLS stream forever.

## What

- A47-02: `Send` resolves the hostname on every record through
  `syslogHostnameFn` (production `os.Hostname`), falling back to the
  construction-time name only when the live read is empty; the daemon
  whole-set fingerprint also carries the hostname. Per-client
  `hostnameFn15231` lets tests pin a name without racing a rename.
- A47-03: added `case level < slog.LevelInfo: return SyslogDebug`.
- A47-04: `applySystemSyslog` counts skipped hosts, arms
  `systemSyslogRetryDebt`, and the existing 30 s `syslogStreamRetryLoop`
  (`reassertSyslogOnce`/`rebuildSyslog`) re-drives `applySystemSyslog`
  from the active config until all hosts build. Empty host list clears debt.
- A47-05: when `commitFn` or `applyConfigFn` is wired (daemon-owned),
  `reloadSyslog` only refreshes the zone map and clears local writers,
  preserving the daemon-installed deferred set. Standalone (no callback)
  still builds via `buildSyslogClients` — that is the only owner there.
- A47-06: per-stream fingerprint (`syslogStreamFingerprint15231`) caches
  built clients by stream name; a retry reuses unchanged healthy clients,
  builds only owed/changed streams, installs via a preserving swap that
  closes only non-preserved superseded clients, and warms only fresh
  clients. Teardowns (event mode / zero streams) clear the cache.
- NOT changed: UDP deferred refusal, transport fail-closed handling,
  facility/severity classification, local log writer hostname (event-mode
  file records are a separate surface; the issue's surviving leg is the
  network RT_FLOW stream).

## Risk

- `Send` now calls `os.Hostname()` per record (a `gethostname` syscall,
  no allocation on the clean path beyond the existing frame build). This
  is the issue's suggested per-Send design; the alternative (hostname in
  fingerprint only) would rebuild every client on rename.
- Standalone CLI syslog rebuild behaviour is unchanged; only the
  daemon-wired console path stops rebuilding.
- A permanently unbuildable system syslog host now retries every 30 s
  (one WARN per host per tick), mirroring the #14597 stream debt price.
