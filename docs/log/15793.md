# #15793 — Cached/deferred three-color policer replay inverts multi-term DSCP rewrite precedence

## Defect

`apply_cached_three_color_policers` (`userspace-dp/src/filter/engine/policer.rs`) folded each metered policer's DSCP rewrite with first-wins `.or`:

```rust
action.dscp_rewrite = action.dscp_rewrite.or(decision.dscp_rewrite);
```

The fresh/inline walks use latest-matched-term-wins: `merge_matched_tx_modifiers` (tx_selection.rs) and `merge_matched_modifiers` (eval.rs) assign `acc.dscp_rewrite = Some(rewrite)` per matched term, so the last matched term's policer rewrite is the emitted mark. For a filter with two fall-through three-color policer terms carrying distinct DSCP rewrites, the first packet was marked by the later term while every cached/deferred replay packet (flow-cache hit, deferred generated-reply settle, host-bound session replay — all funnel through `apply_cached_three_color_policers`) kept the first term's mark.

Cross-direction arm checked and NOT changed: `cos_classify.rs` merges output-then-ingress with `.or` (output wins) consistently on both the fresh path (`resolve_cos_tx_selection_internal`) and the cached-descriptor build (`resolve_cached_cos_tx_selection_impl`), matching the documented output-overrides-when-set forwarding-class semantics. No fresh-vs-cached divergence exists there, so it is out of the narrowed live form.

## Fix

- `apply_cached_three_color_policers`: assign the rewrite whenever a metered decision carries one (`if decision.dscp_rewrite.is_some() { action.dscp_rewrite = decision.dscp_rewrite; }`), so the latest replayed policer wins — identical precedence to the inline walks. Drop remains OR-accumulated. Handles iterate in captured term order (`CachedThreeColorPolicers` preserves insertion order), so "latest" at replay is the same term that is latest inline.

NOT changed: the per-term `policer_action.dscp_rewrite.or(term.dscp_rewrite)` precedence (a policer's color rewrite still beats its own term's configured rewrite within one term), and the cross-direction output-over-ingress `.or` merges.

## Regression

`cached_three_color_replay_latest_policer_dscp_wins_15793` (`userspace-dp/src/filter/tests.rs`): builds a two-term filter directly (production snapshot policers carry no DSCP treatments, so runtimes are constructed with per-color rewrites 10 and 46), asserts the fresh runtime walk yields `Some(46)`, then asserts cached capture + `apply_cached_three_color_policers` replay yields the same `Some(46)`.

RED pre-fix: replay returned `Some(10)` (first-wins `.or`). GREEN post-fix (see PR Validation).
