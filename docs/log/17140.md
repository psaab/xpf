# #17140: one RETH VIP walk (RethVIPsByRG) shared by direct and VRRP modes

- **Timestamp**: 2026-10-27
- **Action**: The RETH VIP set was derived by two hand-kept walks —
  `vrrp.CollectRethInstances` and `config.Config.RethVIPsForRG` — that had
  diverged: the VRRP copy canonically deduped (#11482) while the config
  copy appended raw unit addresses, so an alias spelling
  (`2001:db8:61::1/64` vs `2001:DB8:61:0::1/64`) fed the direct path a
  duplicate AddrAdd and a second GARP/NA burst, and the doc claiming
  "one derivation" was false. Fixed by collapsing to one walk:
  - `pkg/config/reth_vips.go`: new `(*Config).RethVIPsByRG()
    map[int]map[string][]string` is the sole walk — it skips nil/disabled
    interfaces and disabled/nil units (#6780/#16590, applied once),
    resolves RETH->physical, builds the VLAN sub-interface name (the only
    place in the repo that does), and applies the #11482 canonical dedupe
    (`dedupeVRRPVIPs`, already in pkg/config) after merging. 
    `RethVIPsForRG(rg)` is now an index into it.
  - `pkg/vrrp/vrrp.go`: `CollectRethInstances` deleted its private unit
    walk; it now iterates `RethVIPsByRG()` in pinned order (RG ascending,
    then sub-interface name — `updateVIPs`/`vipsEqual` is order-sensitive)
    and wraps each entry in an `Instance` with the per-RG scalars (VRID
    via `rethVRID`, priority incl. the #14404 explicit-0 hold, preempt,
    GARP count, advert interval). RG 0 and out-of-range VRIDs are still
    skipped at this caller, as the direct collector is legitimately
    queried for group 0.
  - `pkg/vrrp/reth_rg_ssot_6781_test.go`: re-anchored on
    `pkg/config/reth_vips.go` — asserts the walk routes through
    `RethRGOwners()` and applies `dedupeVRRPVIPs`, that
    `CollectRethInstances` delegates to `RethVIPsByRG()` with no private
    ownership reading / `LinuxIfName` / `.VlanID` / `TaggingEnabled`
    construction, and that both `RethVIPsForRG` spellings stay delegates.
  - `pkg/vrrp/reth_vips_parity_17140_test.go` (new): per-interface set
    equality `{inst.Interface: inst.VirtualAddresses}` vs
    `RethVIPsForRG` entry-for-entry. Alias-tagged and alias-untagged
    cells fail on pre-fix master (direct=2, vrrp=1); disabled-unit,
    disabled-interface and enabled-control cells are unchanged controls.
