# #16827 — unit-less NAT interface scope stored raw and never matched (R3-F10-02)

- **Timestamp**: 2026-10-25
  - **Action**: The #15278 undefined-scope gate admitted `from/to interface ge-0/0/1` (no unit) verbatim, but the Rust dataplane compares the scope by exact equality against the logical-unit config name (`ge-0/0/1.0`), so such a rule-set committed clean and never matched. Fixed by canonicalizing unit-less NAT interface scopes to unit 0 at compile and again at the userspace snapshot builders: `Config.CanonicalNATInterfaceScopeRef` (new, `pkg/config/schema_validators.go`) folds a bare ref on a plain physical interface (no configured non-zero unit), `lo0`, and a materialized `st0.0` binding to `<ifd>.0`; `canonicalizeNATInterfaceScopes` (`pkg/config/compiler_validate_strict_nat.go`) rewrites source from/to, destination from, and static from scopes before the #15278 gate judges them (wired in `runUniformGates`); the three snapshot builders (`pkg/dataplane/userspace/nat_source.go`, `nat_destination.go`, `nat_static.go`) apply the same helper so hand-built typed configs are normalized too. Bare refs that name no unit traffic reaches them on (undeclared interface, stanza with no unit, only non-zero units, or several units) stay bare and are now strict-rejected / lenient-warned by the tightened `natInterfaceDefined15278` instead of being blessed. `snapshotInterfaceNameMatches` is deliberately unchanged — it is only the over-approximating #7717 detection matcher and now reads canonical snapshots.
  - **File(s)**: `pkg/config/schema_validators.go`, `pkg/config/compiler_validate_strict_nat.go`, `pkg/config/compiler_uniformgates.go`, `pkg/config/compiler_nat_iface_egress.go` (egress mirror aligned to the canonical name), `pkg/config/compiler_interface_addr_nat_warning_5837_test.go` (bare cell now pins eligible suppression), `pkg/config/nat_bare_interface_16827_test.go` (new), `pkg/config/README.md`, `pkg/dataplane/userspace/nat_source.go`, `pkg/dataplane/userspace/nat_destination.go`, `pkg/dataplane/userspace/nat_static.go`, `pkg/dataplane/userspace/nat_bare_interface_16827_test.go` (new), `docs/log/16827.md` (this file)

Post-fix targeted: `go test ./pkg/config/ -run 'TestNATBareInterface|TestNATUndefinedInterface|TestNATDefinedInterface'` PASS (bare source/destination/static/lo0 fold to `.0`, unit-spelled and undefined-unit controls unchanged, inert shapes reject + warn + record) and `go test ./pkg/dataplane/userspace/ -run 'BareInterfaceSnapshot16827'` PASS (hand-built bare refs fold; multi-unit bare ref stays bare).
