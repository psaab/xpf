# #17804 — Per-field idle-rearm gate in TouchBidirectional

- **Timestamp**: 2026-10-27
  - **Action**: The idle-rearm gate in `TouchBidirectional`
    (`pkg/flowexport/tracker_15655.go`) now tests progress per field
    (re-arm when any single counter advances past the marker's), instead
    of comparing forward+reverse SUMs. A backwards-racing mirror field
    could hold both sums exactly flat while another field genuinely
    progressed — or, near 2^64, the summed uint64s wrapped outright —
    so the gate read "no progress", the marker never re-armed, and the
    resumed traffic stayed outside the live tracker (no interim exports,
    activity invisible): the #16747 defect shape again. The live-flow
    path already used per-field checks for exactly this reason; the
    gate now matches it (and `Touch`'s two-field shape). #17851 fixed
    the re-arm carry (per-field maxima); this closes the deliberately
    left gate.
  - **File(s)**: `pkg/flowexport/tracker_15655.go`,
    `pkg/flowexport/idle_rearm_gate_17804_test.go`,
    `pkg/flowexport/README.md`, `docs/log/17804.md`.
  - **Validation**: New regressions RED pre-fix and GREEN post-fix:
    net-flat arm (fwd +10/+100, rev −10/−100 → re-arm, forward delta
    exported, reverse clamped, zero-remainder close) and wrap arm
    (fwd pinned at MaxUint64, rev +10/+1000 → re-arm, 0/0/10/1000
    export). Control arms (flat, uniformly regressed, fwd-flat +
    rev-regressed → no re-arm; single-field reverse-byte progress →
    re-arm) pass pre- and post-fix. `go test ./pkg/flowexport/ -count=1`
    ok; daemon `TestFlowLiveFeed*`/`TestSessionClose*` PASS;
    `go vet ./pkg/flowexport/ ./pkg/daemon/` clean; `-race` on the new
    tests PASS.
  - **Risk**: A snapshot with any one advancing counter now re-arms
    where the summed comparison could have refused it; the re-armed
    entry's counters stay per-field maxima (#17851) and all delta/
    remainder arithmetic saturates (#16750), so the widening cannot
    recount traffic — it only stops dropping genuinely resumed flows.
