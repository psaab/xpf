# Issue #13548: Align userspace-shim DNAT validation

`CompileUserspaceShim` reaches `CompileConfig`/`compileNAT` before the userspace
snapshot is built. The legacy shim rejected non-host DNAT match CIDRs even
though `buildDestinationNATSnapshots` carries them as `destination_prefix` and
Rust's `DnatTable` installs them as longest-prefix entries. The shim now accepts
those destination match prefixes while continuing to reject non-host pool
addresses, which the snapshot's Rust `IpAddr` parser does not support.

The shim also assigned destination-NAT hit-counter IDs only after requiring a
pool name. DNAT `off` exemptions have no pool but are published by the snapshot
builder; assigning their per-rule ID lets the snapshot stamp the counter ID
used by Rust.
