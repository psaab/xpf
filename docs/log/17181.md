# #17181 — R4-Q16-04: Pin the xpf-usp1 transit-fence contract and drop the dead Rust mask

- **Timestamp**: 2026-10-27
- **STEP-0**: Defect live on current `origin/master` (82c7b1ed26). `slowpath.rs:45-46`
  declares `ADJUDICATED_TRANSIT_MARK = 0x5846_5001` and the dead
  `ADJUDICATED_TRANSIT_MARK_MASK = 0xffff_ffff` (only the mark reaches
  `load_queue_mark_program` at :294-297; the TC program writes the full word, no
  mask operand exists). Go `transit_barrier.go:35,37` mirrors both values with no
  cross-language test. `pkg/daemon/daemon_transit_gate.go:107` re-declares
  `const armedTransitReinjectIfname = "xpf-usp1"` instead of the #9637-pinned
  `xnft.HostInboundDelegatedIfname`, and the daemon fixtures built their links
  FROM that private constant, so they would follow any drift. Test copy
  `transit_barrier_9852_test.go:205` (`armedTransitReinjectIfname10391`) is a
  third literal. The existing `TestHostInboundReinjectTunName9637` reads neither
  `slowpath.rs` nor the daemon constant, and no Go test reads Rust source for
  the mark.

## Action

- Deleted `ADJUDICATED_TRANSIT_MARK_MASK` from `userspace-dp/src/slowpath.rs`
  (acceptance: `rg ADJUDICATED_TRANSIT_MARK_MASK userspace-dp` = 0).
- Deleted `armedTransitReinjectIfname` from `pkg/daemon/daemon_transit_gate.go`;
  its two comparisons in `armedTransitFenceSpecForIfindexes` and the two in
  `pkg/daemon/ipsec_topology_owner_9506.go` (`ipsecTopologyLinkEventRelevant`,
  `classifyIpsecTopologyLinks`, which gains the `xnft` import — `pkg/daemon`
  already imports `pkg/nftables`, no cycle) now use
  `xnft.HostInboundDelegatedIfname`, the #9637 SSOT already pinned to Rust
  `DELEGATED_SLOW_PATH_TUN` by `TestHostInboundReinjectTunName9637`.
- Daemon fixtures that built links from the deleted constant
  (`ipsec_permit_test.go`, `transit_fence_10302_test.go`,
  `ipsec_vrf_fence_15067_test.go`) now use `xnft.HostInboundDelegatedIfname`
  (`ipsec_permit_test.go` gains the `xnft` import).
- `pkg/nftables/transit_barrier_9852_test.go`: the mark-pinhole fixture uses
  `HostInboundDelegatedIfname` and the test-only `armedTransitReinjectIfname10391`
  literal is deleted. Added `TestAdjudicatedTransitMarkMatchesRust`, which
  regexes `const ADJUDICATED_TRANSIT_MARK: u32 = (0x[0-9a-fA-F_]+)` from
  `userspace-dp/src/slowpath.rs`, strips underscores, parses it, and compares
  it to `xnft.AdjudicatedTransitMark` — the same read-Rust-source pin shape as
  `TestHostInboundReinjectTunName9637` and `pkg/snmp`'s
  `TestReinjectTUNNamesPinnedToRust`.
- `pkg/nftables/transit_barrier.go`: the `AdjudicatedTransitMark` doc now
  states the MUST-stay-equal contract and names the pin, mirroring the
  `HostInboundDelegatedIfname` contract comment.

  mark, or mask semantics change.

  fails `TestAdjudicatedTransitMarkMatchesRust`; Rust TUN rename fails the
  #9637 and snmp pins, and the daemon follows the Go SSOT). The `pkg/snmp`
  literal remains a pinned mirror rather than the SSOT (see Acceptance
