# Issue #10435: networkd VLAN child MTU rendering

## Disposition

Fixed. `generateNetwork` now emits `MTUBytes=<configured>` in a `[Link]` section for managed VLAN/logical interfaces that have no MAC-backed `.link` or `.netdev` writer. Physical interfaces, VLAN parents, bonds, and bridges retain their existing MTU ownership; unmanaged and disabled interfaces still take the early down-only path.
