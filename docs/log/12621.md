# #12621 — retire host authorization after boot-expired FIRST rollback

- **Issue**: #12621 — `Store.Load` rolls back a FIRST commit-confirmed window expired during downtime, bypassing the live rollback callback and leaving host-auth state active.
- **Branch**: `fix/12621-campaign-pub`
- **Worktree**: `/var/worktrees/campaign-pub/wt-12621`

## Why

A downtime-expired FIRST window is reverted inside `Store.Load`. That path publishes #12155 teardown debt, but it does not run `executeConfirmedRollback`, which is the path that writes the #12169 durable host-auth closeout record and retires abandoned host authorization. Bootstrap startup suppresses the ordinary config apply, so the login password and its xpf ownership markers were left live.

## What

- Run `applyBootstrapHostAuthorizationCloseout(nil)` as part of the #12155 recovered FIRST teardown whenever `FirstCommitTeardownOwed` is set.
- Reuse the existing durable #12155 teardown marker as the intent on this path. Keep that debt until host-auth retirement, filesystem teardown, and post-dataplane acknowledgements converge; retry the closeout on the existing degraded/restart path.
- Always reload sshd after the owner pass, even if its xpf drop-in is already absent. This closes the unlink-before-reload crash boundary; a failed reload keeps the #12155 debt for another boot attempt.
- Add a boot-expired FIRST probe that loads a fresh store, verifies no #12169 record exists, drives the recovered teardown, and checks revoked password/ownership markers with debt still durable. The probe fails both the owner reload and forced reload after unlink, reconstructs Store/Daemon from disk, and verifies the next boot forces another reload. The real `Daemon.Run` chain test asserts credentials are revoked and the teardown marker is eventually cleared after completion.

## Risk

Host-auth closeout uses the existing provenance-scoped owner set and empty bootstrap config. A failure returns degraded status and preserves #12155 durable teardown debt for retry; no new closeout record format or independent retry mechanism is introduced.
