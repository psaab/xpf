# #17748 — Reconcile commit-history labels with retained rollback generations

Timestamp: 2026-10-28T19:07:09-07:00

Action: Replaced positional commit-history slot numbering with one-to-one matching of commit-row `ConfigHash` values against the active tree and retained rollback ladder. Matching is newest-first per hash, suppresses the reverted commit row after `auto_rollback`, and leaves unmatched, missing-hash, and unreadable-slot rows unlabeled. The journal tail and store snapshot are paired under `Store.mu`. A changed `config_sync` hash creates a live-slot boundary so an older matching commit row cannot claim a sync-produced generation; a same-hash sync creates no boundary. Added regressions for deep timeout rollback, `SyncApply`, bounded tails, duplicate-content generations including a timeout-reverted duplicate, changed-sync identity, and equivalent-sync control; updated configstore documentation and the original #16721 log.
