# #14999 — binary local-log disk I/O and rotation on the shared EventStream reader (D40-05)

## Defect

`EventReader.logEvent` (`pkg/logging/ringbuf.go`) moved its text local-log
branch off the EventStream reader in #9025 via
`LocalLogWriter.SendFromEventReader`, but the adjacent binary branch still
called the synchronous `LocalLogWriter.SendBinary` directly:

```go
if err := lw.SendBinary(localBinMsg); err != nil { ... }
```

`SendBinary` (`pkg/logging/locallog.go`) takes `lw.mu`, does `file.Write`,
and when `written >= maxSize` calls `rotate()` inline — generation renames,
`fsatomic.SyncDir`, excess removal, and hardened reopen. All of that ran on
the EventStream reader goroutine, which also carries HA session sync
(`EventTypeSessionOpen/Update/Close`), the ISSU drain signal, and
full-resync. Under disk distress (writeback stall, hung device, slow
rotation fsync) one binary audit record parks HA session sync behind local
disk I/O. This is the surviving leg of D40-05; the text leg was already
fixed by #9025, and the syslog client binary leg already had
`SyslogClient.SendBinaryFromEventReader` (#11697).

## Fix

- `LocalLogWriter.SendBinaryFromEventReader(data []byte) bool` — binary
  counterpart of `SendFromEventReader`. Copies the record (queue owns
  immutable bytes; `logEvent` formats per event), enqueues
  `auditItem{binary: ...}` on the same bounded `asyncAuditWriter`
  (4096/writer), returns immediately. Queue-full/retired drops, counts
  `DroppedWrites()`, and rate-limited-warns without holding `lw.mu`
  (#14191 shape).
- `auditItem` gains a `binary []byte` field; `NewLocalLogWriter`'s writer
  callback dispatches binary items to `SendBinary` and text items to
  `Send`, so rotation, wedge recovery (#9118), and #3478 accounting stay
  inside the existing locked write on the writer goroutine.
- `logEvent`'s binary local branch now calls
  `SendBinaryFromEventReader` and logs a drop debug line on refusal,
  mirroring the text branch.
- Direct `Send`/`SendBinary` callers keep the synchronous contract
  (#3478 M04 deliberate error return); a nil-async writer (never
  constructed via `NewLocalLogWriter`) still falls back to the
  synchronous call, matching `SendFromEventReader`.

## Regression (`pkg/logging/locallog_binary_offload_14999_test.go`)

- `TestLocalLogBinaryFromEventReaderDoesNotBlockCaller14999` — wedges the
  writer goroutine in its write callback (proven stall via entered-channel),
  then requires 100 reader-side offers to return promptly. RED on current
  master (method absent; compile failure), and RED when the handoff is
  temporarily reverted to synchronous `SendBinary` (fixture never enters
  the wedged writer — the caller does the write itself).
- `TestLocalLogBinaryQueueOverflowDropsAndCounts14999` — overruns the
  bounded queue with the writer wedged; acceptance is bounded and overflow
  is counted in `DroppedWrites()`.
- `TestLocalLogBinaryFromEventReaderWritesAndRotates14999` — control case:
  legitimate binary records land byte-identical, rotation `.1` is produced
  on the writer goroutine when the cap trips.
- `TestRetiredLocalLogBinaryFromEventReaderCountsDrop14999` — retired
  writer refuses and counts, not silently accepts.
- `TestLocalLogBinaryFromEventReaderCopiesRecord14999` — mutating the
  offered slice after handoff does not corrupt the queued record.

## Validation

- Targeted: `go test ./pkg/logging/ -run 'TestLocalLogBinary|TestRetiredLocalLogBinary'`
  — pass post-fix; pre-fix build fails (no `SendBinaryFromEventReader`),
  sync-revert fails the blocking cell.
- Full: `go test ./pkg/logging/ -count=1` — pass. `go vet ./pkg/logging/` — clean.
- Race: `go test -race ./pkg/logging/ -run 'TestLocalLogBinary|...|TestLocalLogWriterSendBinary'` — see PR.

## Risk

Bounded audit loss under sustained disk stall is now possible on the
binary path where previously the reader stalled instead — the #9025/#3478
trade, drop-and-count over block, applied uniformly. Ordering within one
writer is FIFO-preserved; ordering between direct synchronous callers and
queued reader records is unchanged from the text path's existing semantics.
