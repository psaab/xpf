# 11769 — the five live CoS/fairness GATE harnesses: made runnable, hermetic legs run, lab legs marked SKIP

Issue: https://github.com/psaab/xpf/issues/11769
Diagnosed and fixed at master `ba3ba7dd9` (worktree fresh from origin/master).

## Diagnosis — why each harness was unrunnable at master

All five were driven end-to-end on a lab-less host during diagnosis
(artifacts under `/tmp/11769diag/` on the diagnosing host; scratch only).
No shared-cluster state was touched: `incus` was a PATH stub, `iperf3` a
fixture generator, the metrics endpoint a loopback stub.

| Harness | Verdict-layer run without a cluster? | Blocker at master |
|---|---|---|
| `cos-simul-load-smoke.sh` | yes — reducer/gates 0/1/2/3/8 all exercised over fixture JSON | live `sg incus-admin` legs; no skip pattern, so a lab-less host failed 11 generators and read as a red GATE FAIL |
| `cos-gate1-small-four-alone.sh` | yes — per-class %shape reduction + exit propagation | same |
| `cos-be-contention-harness.sh` | yes — full capture→validator pipeline over a stateful mock (all four cells PASS) | live cluster + #8040 target precheck; no skip pattern before the precheck |
| `fairness-cos-class-sweep.sh` | yes — wrapper→fairness-harness→REAL fairness-eval→equal-flow reducer→jq summary, exit 0 | **`userspace-dp/target/release/fairness-eval` is a build artifact absent from every fresh checkout** — no Makefile recipe builds it, so the sweep exited 2 before doing anything; plus the live cluster |
| `fairness-cos-throughput-headroom.sh` | yes — scenario sequencing/aggregation over stubs | live cluster for both apply arms and the sweep; no skip pattern |

Not stale refs or renames: every referenced script/fixture/env file
(`fairness_cov.py`, `fairness_multi_sample.py`, `fairness_equal_flow_capture.py`,
`cos_be_contention_validate.py`, `apply-cos-config.sh`, `target-services.sh`,
`loss-userspace-cluster.env`) exists at master and ran when driven.

## Fix

1. **Lab-only skip pattern (exit 77 + reason)** added to all five
   harnesses, ahead of any cluster interaction: a host without `incus`
   (or without a working `sg incus-admin` where the harness uses it)
   SKIPs with `… measurement legs are lab-only (#11769)` instead of
   reading as a gate failure. This is the existing convention
   (`test-wire-properties.sh` exit 77; `run_bash`'s 77-SKIP handling).
   In `cos-be-contention-harness.sh` the preflight sits BEFORE the #8040
   target precheck, so a lab-less host skips before anything is spent.
2. **Hermetic self-tests** (new), driving the REAL harnesses:
   - `cos-simul-load-smoke-selftest.sh` — healthy/starved/crashed-
     generator/reverse-aggregate cells both directions + the SKIP cell.
   - `cos-gate1-small-four-alone-selftest.sh` — GATE1 PASS, 90%-of-shape
     FAIL, crashed-generator FAIL (#4240 V-2) + SKIP cell.
   - `cos-be-contention-harness-selftest.sh` — stateful scripted cluster
     (only queues whose generator is running drain; flock-serialized
     registrations), real validator, four PASS cells; exact-collapse-
     under-contention FAIL cell; SKIP cell.
   - `fairness-cos-class-sweep-selftest.sh` — real
     `fairness_multi_sample.py` + `fairness-harness.sh` + REAL
     `fairness-eval` + real equal-flow reducer over a loopback stub
     metrics endpoint and a fixture `IPERF_BIN`; class PASS; 8x-skew
     streams FAIL the gap contract; SKIP cell. Self-SKIPs (77) with the
     build command when fairness-eval is not built.
   - `fairness-cos-throughput-headroom-selftest.sh` — strict →
     surplus-sharing → strict-restore apply sequence (incl. the
     `--symmetric` reverse-fixture flag), summary aggregation, sweep-FAIL
     and apply-FAIL propagation, restore-on-failure, SKIP cell.
3. **`make test-cos-fairness-gates-lib`** (new): builds `fairness-eval`
   with the pinned-toolchain cargo invocation (closing the fresh-checkout
   blocker), then runs the five self-tests. All five are also registered
   in `scripts/run-selftests.sh` (`make selftest`).
4. `test/incus/HARNESSES.unreached` — the five GATE reasons now record
   that each harness's hermetic layer is reached by its self-test while
   the live measurement remains lab-owed. The entries stay: self-tests
   do not confer census reachability, so the owed-measurement debt stays
   visible instead of being greened over.
