# #11056 — hermetic wire-gate legs (default-deny, host-inbound-deny, appmatch-twins)

Issue: the three gates have zero rows in the tracked ledger; green was
hermetic-only over verdict matrices that never touched a probe, a capture, or
the fixture. The live loss-cluster rows stay operator-held
(`plan-deferred-lab`, triage 2026-09-27 / 2026-10-09). This change implements
every leg of those gates that is CODE and proves it hermetically, so the
operator's run measures what it claims.

## What landed

- **Fixture leg** (`pkg/policymatch/wire_gate_fixture_11056_test.go`): the
  CLI fixture is extracted from each shipped gate script, applied to
  `docs/ha-cluster-userspace.conf` through the set/delete replay primitives
  (`config.ParseSetVerbGroupedClosed` + tree edits, mirroring
  `configstore.applyEditLine`), compiled, and evaluated by
  `policymatch.Match` at the gates' exact probe/control tuples. Proves the
  baseline admits every tuple (same-path baseline) and the fixture narrows
  exactly the verdict-bearing legs: probe→default-deny / control→permit,
  twins permit+deny split, host-inbound netconf-only admission.
- **Probe leg** (`wire-gate-hermetic-selftest.sh` part A0): loopback sinks
  prove `wire_probe_burst.py` SENT accounting (offered == observed on a
  lossless path; established AND refused connects both count as offered) and
  `wire_tcp_accept.py`'s ACCEPTED count. Unprivileged.
- **Reduction leg** (`wire-gate-lib.sh` capture-reduction functions): the
  emerge/reply greps the three live gates ran inline are now one library
  implementation (`wire_count_dst_frames`, `wire_has_dst_frames`,
  `wire_count_flag_replies`, `wire_count_bad_cksum`), rewired into all three
  gate scripts, with near-miss cells (prefix port, over-long port, reply-from
  vs frame-to, transport-scoped corruption, missing capture file).
- **Transcripts** (`test/fixtures/wire/`): real tcpdump text and measured
  k=v summaries, generated 2026-10-14 in an isolated 3-netns veth topology
  (prober 10.9.0.1 → nft forward-drop DUT stand-in → sink/capture 10.9.1.2)
  with the real probes, the gates' tcpdump flag sets and burst sizes. Each
  file's header records its provenance; the gates' `--fixture` modes turn
  them into PASS / leak-FAIL / exposed-FAIL / capture-blind VOID.
- **Live pipeline (privileged selftest part B)**: rebuilds the measurements
  fresh — real probes, real nft drop, real tcpdump, same reductions, same
  verdict cores — in all four directions.
- Lab legs stay the existing skip pattern:
  `test/incus/LEDGER_COVERAGE.unreached` still declares all three gates
  (zero rows), now naming the hermetic legs that landed and the
  operator-held live run that remains.
