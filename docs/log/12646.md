# #12646 — make shared base/unit-0 host-inbound precedence order-independent

- **Opened**: 2026-10-13.
- **PR branch**: `fix/12646-campaign-pub`.
- **Action**: ensure a configured unit-row host-inbound set takes precedence over the base-row set when both share an ifindex, independent of snapshot row order.

## Defect

The Rust AF_XDP builder stores host-inbound sets by ifindex, so multiple rows on one netdev overwrite one another. For a non-VLAN unit 0, the base and unit-0 rows share an ifindex. Go currently emits base rows before their units, which happened to make the more-specific unit override the final write. That behavior was incidental: an order change could let the base set replace the unit set and reopen host-bound services.

## Change

Rust now identifies ifindexes with a configured logical-unit row before walking the snapshot. A configured base row does not write the host-inbound table for those ifindexes; a configured unit row supplies the set regardless of whether the base or unit appears first. If there is no configured unit-row override, base-only behavior remains unchanged. A Rust regression exercises both row orders with distinct base and unit token sets and checks allow/deny results. A Go regression pins base-before-unit row emission as the producer contract.

## Validation

- Rust focused regression passed. Reverting the precedence guard to unconditional
  last-writer-wins made the reverse-order case fail on unit-0 SSH; restoring the
  guard made both orderings pass.
- Go focused emitter-order test passed with a stub live ifindex shared by base
  and unit 0.
- Rust `cargo test -p xpf-userspace-dp`: 7,765 passed, 7 ignored, 1 unrelated
  failure in `fib_dump_refuses_over_budget_without_returning_partial_rows_11767`
  (fixture route has no next hops), in 564.43s.
- Go `go test ./pkg/dataplane/userspace -count=1`: failed on unrelated
  `TestStalledSyslogDoesNotParkEventReader11697`, whose session-delta p99
  exceeded its 50ms limit (52.56ms). Earlier full runs also failed that same
  timing assertion (75.47ms and 112.96ms).

## Risk

Only configured base-vs-unit host-inbound writes sharing the same ifindex change: the more-specific unit set wins. Separate ifindexes and base-only host-inbound behavior are unchanged. Multiple configured unit rows aliasing one ifindex retain their existing last-writer behavior.
