# #18839: `make clean` deletes the box-wide shared CARGO_TARGET_DIR

- **Timestamp**: 2026-11-01
- **Action**: `make clean` ended with `rm -rf $(CARGO_TARGET_DIR) userspace-dp/target`. `CARGO_TARGET_DIR ?= /var/worktrees/.cache/cargo` is the box-wide target dir every worktree builds into, so a `make clean` anywhere emptied every other lane's in-flight cargo build. It happened on 2026-11-01 at 15:08:45 PST, and a concurrent `make deb` failed with "could not write output ... No such file or directory".
- **Fix** (Makefile): `clean` always removes `userspace-dp/target`. Make, not the shell, decides what happens to `CARGO_TARGET_DIR`, so `make -n clean` never even names the shared dir unless it would delete it:
  - a per-worktree `CARGO_TARGET_DIR`, with no overlap with the shared dir, is removed;
  - exactly the shared dir is kept, with a note. Only `CLEAN_SHARED_CARGO=1` removes it, after a WARNING on stderr;
  - a parent or child of the shared dir is refused (`make clean` fails), opt-in or not.

  Paths are compared after `realpath` when they exist, so neither a trailing slash nor a symlink hides the shared dir. `CARGO_TARGET_DIR_SHARED` names the default once.
- **Selftest**: `scripts/clean-shared-cargo-selftest.sh` (`make test-clean-shared-cargo-lib`, also in `scripts/run-selftests.sh`). It uses dry runs only. Cells:
  1. default env: the shared path is not named, and `userspace-dp/target` is still removed;
  2. a per-worktree dir is removed;
  3. a trailing slash is kept;
  4. a symlink is kept;
  5. a parent is refused;
  6. a child is refused;
  7. the opt-in removes the shared dir loudly;
  8. the opt-in does not unlock a parent;
  P. positive control: the pre-fix recipe, rebuilt in a temp copy of the Makefile, must name the shared dir.
- **Docs**: `docs/engineering-style.md` has a new short section on the shared build caches: `GOCACHE` and the cargo dir, the `clean` rule, and the related last-writer-wins hazard on `$(CARGO_TARGET_DIR)/release/xpf-userspace-dp`. CLAUDE.md's GOCACHE line is left as it is.
- **File(s)**: `Makefile`, `scripts/clean-shared-cargo-selftest.sh`, `scripts/run-selftests.sh`, `docs/engineering-style.md`, `docs/log/18839.md`
