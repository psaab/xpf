# Issue #12199: Verify RG1 movement in stress failover

- **Timestamp**: 2026-10-07
- **Action**: Added a shared fail-closed stress oracle. Each RG1 failover/failback half-cycle now polls `show chassis cluster status` on both nodes until the requested node is primary for RG1 or the 30-second bound expires; an unchanged/unreadable owner fails the cycle. Request return codes and stderr are retained for diagnosis, with observed ownership—not the request text—as the verdict. A final two-node read requires RG1 back on fw0. `check_streams` now fails when the tail has fewer than `IPERF_STREAMS` rows.
- **Regression**: Added `test-stress-failover-selftest.sh` with fixture-only checks for empty/short stream tails, dead-stream rows, RG1 scoping, unchanged ownership, blind reads, bounded polling, successful movement, request-error reporting, and a complete one-cycle harness run with healthy traffic and a valid final SUM. Registered it with the hermetic runner and declared the sourced library in the harness census.
