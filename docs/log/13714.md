- **Date**: 2026-10-15
- **Issue**: #13714
- **Why**: When a candidate's initial ifindex lookup failed, the planner minted it unregistered and unarmed but still stamped `last_change`. A later replan with the resolved ifindex treated that timestamp as proof of an existing registration and skipped the registration/arm initialization; unchanged forwarding state meant no later arm RPC repaired it, leaving the whole dataplane disabled.
- **What**: `replan_bindings_from_candidates` now considers a prior binding an existing registration only when its previous ifindex was positive. An unresolved prior row is re-registered on recovery and inherits the current global arm state, while still-unresolved rows remain fail-closed. Added tests for armed recovery and double-replan stability, disarmed recovery, and a sibling that remains unresolved.
- **RED-before**: On pristine `origin/master` f4da6b3c8, `cargo test --manifest-path userspace-dp/Cargo.toml replan_after_initial_ifindex_failure_arms_bindings_13714 -- --nocapture` failed at the expected assertion: recovered rows were `(ifindex=11, registered=false, armed=false)`.
- **Validation**: On unmodified `origin/master`, the regression failed at the recovery assertion: recovered rows were `(ifindex=11, registered=false, armed=false)`. After the fix, `CARGO_TARGET_DIR=/var/worktrees/.cache/cargo-13714 cargo test --manifest-path userspace-dp/Cargo.toml --bin xpf-userspace-dp replan_after_initial_ifindex_failure -- --nocapture` — 2 passed, 8067 filtered; the `tests::` filtered suite — 6132 passed, 7 ignored, 1930 filtered. The full unfiltered binary run (8069 tests) reported four failures and stalled before a final summary. Each was independently rerun against pristine `origin/master` fd94c3a7d and reproduced: fragment overlap expected the sibling to pass (0 vs 1); both GRE inner ICMP tests expected LocalDelivery (0 vs 1); the session-hit authority window expired at tick 21. Thus these are baseline failures, not caused by this change.
- **Risk**: A binding that was unresolvable and therefore never registered can now register once its ifindex becomes valid. Existing positive-ifindex rows preserve manual registration and arm state; unresolved rows remain fail-closed.
