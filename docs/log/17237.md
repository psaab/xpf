# Issue #17237 — RFC2136 endpoint single-source (R4-Q40-02)

- **Defect (live on origin/master b01e3c8cba):** `compiler_services.go` DHCP empty-block check omitted `ForwardZone`/`ReverseZone` while the provider twin (`compiler_system_ddns.go`) included them since #15225. A v6 `dynamic-dns` block holding only `forward-zone` or `reverse-zone` compiled to `nil`, so `EffectiveDynamicDNS` made v6 inherit the enabled v4 policy.
- **RED:** `TestQ40DHCPDynamicDNSZoneOnlyBlockDropped17237` on master: forward-zone-only and reverse-zone-only v6 rows failed (`DynamicDNSv6 nil=true`), update-server-only control passed.
- **Fix:**
  - New `config.RFC2136Endpoint` (ten leaves: update-server, forward-zone, reverse-zone, tsig-key, tsig-algorithm, tsig-secret, require-tsig, source-address, destination-interface, routing-instance) with `IsZero()` and `MergeFrom()`, embedded in both `DDNSProvider` and `DHCPDynamicDNSConfig` (field promotion keeps selectors compiling; explicit composite literals migrated to the embedded field, required under go.mod 1.24).
  - One `compileRFC2136Endpoint(props)` used by both `compileDDNSProvider` and `compileDHCPDynamicDNS`; both empty-checks call `IsZero()` — fixing the zone-only drop.
  - `mergeDHCPDynamicDNS` delegates endpoint fields to `MergeFrom` (first-writer-wins, RequireTSIG latches).
  - `pkg/ddns`: `newRFC2136Updater(pol, ep, ...)` and `resolveBindConfig(ep, ...)` take the endpoint; `surface_a.go` no longer builds a `&config.DHCPDynamicDNSConfig{...}` carrier literal; `resolveProviderBindConfig` passes `p.RFC2136Endpoint` directly. Single config posture logic in `endpointUnsignedNonLoopback(ep, backend)`; `ddnsConfigUnsignedNonLoopback`/`providerUnsignedNonLoopback` are nil-guard delegates to it.
  - Census updates: secret census now keys `RFC2136Endpoint.TSIGSecret` (reflection names the embedded Secret once); URL census keeps scanner name `DDNSProvider.UpdateServer` with a note that the field is the embedded endpoint's.
  - `DHCPDynamicDNSConfig.String()` redaction unchanged (promoted `TSIGSecret`/`UpdateServer` selectors); pinned by existing #9497/#2053 tests in the named run below.
- **JSON note:** embedding flattens promoted fields in JSON marshal (encoding/json promotes embedded fields) — shape unchanged for operators; `MarshalJSON` URL redaction unchanged.
- **Tests (named hermetic only):**
  - `go test ./pkg/config/ -run 'TestQ40DHCPDynamicDNSZoneOnlyBlockDropped17237|TestRFC2136EndpointIsZeroCoversEveryField17237|TestRFC2136EndpointMergeFrom17237|TestDHCPDDNS|TestEverySecretFieldIsMapped|TestAST' -count=1` — pass.
  - `go test ./pkg/ddns/ -run 'TestEndpointUnsignedNonLoopback17237|TestNewRFC2136UpdaterFromProviderEndpoint17237|TestDDNSUnsignedNonLoopbackPosture15992|TestRFC2136ExplicitZones15225|TestResolveBindConfig' -count=1` — pass.
  - Full-package runs (`./pkg/config/`, `./pkg/ddns/`) are Main's to run on landing; `go vet ./...` clean except pre-existing `pkg/wireschema` warnings.
- **Acceptance:** probe reports `nil=false` for forward-zone, reverse-zone and update-server v6 rows; reflection test asserts every `RFC2136Endpoint` field is read by `IsZero()`; `grep '&config.DHCPDynamicDNSConfig{' pkg/ddns/surface_a.go` is empty; the substantive unsigned-non-loopback logic lives only in `endpointUnsignedNonLoopback`.
