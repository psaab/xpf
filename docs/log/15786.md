# #15786 — userspace-dp: zero-copy transmit_prepared_queue collateral-destroyed staged batch + orphaned CoS pop snapshots on one invalid frame

- **Timestamp**: 2026-10-19
- **Action**: Per-frame validation drops in the prepared TX path. `tx/transmit/stage.rs` (oversized len), `rewrite.rs` and `verify.rs` (UMEM slice out of range) no longer drain + recycle every staged frame and return `Err(Drop)`; each now removes/recycles/counts ONLY the offender via the new `record_prepared_drop` (`tx/transmit/mod.rs`), recording its ORIGINAL pending position in the new `scratch_prepared_dropped_orig_idx` and the first reason in `scratch_prepared_first_drop_reason`, then continues with the valid survivors. Staged entries carry their original position in the new fixed `scratch_prepared_tx_orig_idx` sidecar; `finalise.rs` pushes each committed entry's original position into `scratch_prepared_committed_orig_idx`. The orchestrator surfaces the first `Err(Drop)` only when the whole batch is invalid (every frame already counted once). `submit_prepared` charges flow-bucket/sojourn accounting by committed identity (not a shifted prefix), removes dropped snapshots positionally (descending, `cos_queue_remove_orphan_snapshot_at`) before any LIFO restore on Ok/Retry/Drop, and no longer double-counts the all-invalid Drop; the backup drain Drop arm likewise only latches the operator message. New scratch fields are pre-sized in `WorkerScratch::pre_sized`.
- **Validation**: `cargo test --bin xpf-userspace-dp --no-run` builds clean (566 pre-existing warnings, none new in touched files — one E0308 in the new test fixture's `build_cos_batch_from_queue` call, a missing `queue_idx`/phase pair copied from the pre-#13065 signature, was caught and fixed). New regressions GREEN (6/6): `prepared_single_oversized_drops_only_offender_15786`, `prepared_single_slice_oob_drops_only_offender_15786`, `prepared_all_invalid_drops_each_once_15786` (transmit level), `prepared_oversized_drops_only_offender_no_orphan_15786`, `prepared_oversized_retry_restore_no_orphan_15786`, `prepared_clean_batch_no_drop_15786_control` (CoS level, real `build_cos_batch_from_queue` batches; the retry variant pre-fills the TX ring to force inserted==0 and asserts the survivor restores with its own pre-pop head finish and an exactly-empty snapshot stack). Adjacent suites GREEN: `afxdp::cos::` 358 passed, `afxdp::tx::` 212 passed, #15172 mirror-orphan 4/4, #4971 3/3.
