# #9855: packed group leaf dropped beside inline leaf — lane log

## Defect (verified on base)

A group's packed named-instance statement is dropped beside an inline leaf
naming the same instance: `host 10.0.0.1 any any;` (group) + `host 10.0.0.1;`
(inline) compiled one host with no facilities; `vrrp-group 1 priority 200;`
(group) + `vrrp-group 1 virtual-address ...;` (inline) compiled priority 100.
Mechanism: `mergeNodes` leaf branch runs the #7648 expansion only against a
container peer (`pkg/config/ast_groups.go:430` at base); a leaf peer takes
the inline-wins override. Union is ineligible (both schemas carry children).
Strict commit accepts all rows. Reproduced on base `9603f2a5f` with
throwaway `parseHierarchical` + `CompileConfig` cells (since removed).
