# #12726 — keep DHCP lease-sync socket fixtures within sun_path

- **Issue**: https://github.com/psaab/xpf/issues/12726
- **Branch**: `fix/12726-campaign-pub`

The #9853 fallback tests used `t.TempDir()` to construct missing control
sockets. In go1.24, the full nested test name is included in that directory;
under `/var/tmp`, the v6 `missing6.sock` path exceeds the 107-byte Linux
`sun_path` limit (the issue reports 108 bytes). Because these fixtures
intentionally dial a socket with no listener, an overlong path still takes
the expected error/fallback path and the bug was silent.

Both #9853 matrices now construct their missing control sockets in the
existing short `MkdirTemp`-based directory helper. `missingSock9853` asserts
each final socket path is at most 107 bytes, so a future long-path regression
fails at fixture setup; it covers v4/v6 in all six stale-generation leaves and
both family leaves of the staggered failover test. Memfile fixture directories
remain `t.TempDir()` because they do not name sockets.

Validation (go1.24.9, `TMPDIR=/var/tmp`): focused #9853 tests pass; complete
`go test ./pkg/dhcpserver/ -count=1` passes; `go vet ./pkg/dhcpserver/`,
`gofmt -l pkg/dhcpserver/lease_sync_test.go`, and `git diff --check` pass.

Risk: test-only fixture-path changes; production behavior is unchanged.
