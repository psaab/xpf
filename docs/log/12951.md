# Pin the zone-ownership arm of the unit-0 collapse gate (#12951)

- **Issue**: #12951, follow-up to #12838 (GLM review F1 of PR #12943).
- **Cause**: No committed test discriminates the `zoneByIface[unit0Name]` zone-ownership clause of the unit-0 collapse gate in `junosHostZoneExemptNetdevs` (`pkg/config/junos_host_deny.go`). The clause is load-bearing: when unit 0 is QUARANTINED (its key claimed by two zones, so `junosHostZoneByInterface` carries no row for it for any zone), a zone holding the bare physical ref keeps its ike / ident-reset exemptions only through the arm's bare-row retention. Every existing #12838 fixture keeps unit 0 owned by the exercising zone, and that zone's unit row inherits the physical override via the #3720 base union, so deleting the arm left the committed suite green while silently withdrawing the bare-ref zone's exemptions (fail-closed).
- **Change**: Test-only. New `pkg/config/junos_host_deny_zone_owner_12951_test.go` adds the discriminating cell: zone `edge` holds bare `ge-0/0/2` (base stanza ike + ident-reset), zone `alpha` additionally claims `ge-0/0/2.0`, quarantining the unit key. Cells cover the same-netdev collapse (vlanID 0) and the distinct VLAN unit-0 netdev (vlanID 100); both assert the bare row survives only via the arm (IKE/ident lists exactly `[ge-0-0-2]`) and the VLAN device stays excluded. A third cell pins the fail-closed side: the quarantined claimant itself resolves no ingress scope and earns no exemptions, guarding against quarantine erosion (sorted-name winner) in the shared zone map. `require12951Quarantine` asserts the conflicted-key exclusion as a precondition so the cell cannot silently degrade into a naive fixture that passes with the arm deleted. No production code changed.
- **Regression coverage** (`pkg/config/junos_host_deny_zone_owner_12951_test.go`):
  - `TestJunosHostZoneOwner12951QuarantinedCollapseKeepsBareRow` — same-netdev quarantined unit-0: bare-ref zone keeps exactly `[ge-0-0-2]` for IKE and ident-reset via the arm.
  - `TestJunosHostZoneOwner12951QuarantinedDistinctUnit0KeepsBareRowOnly` — distinct VLAN unit-0: physical row kept via the arm, quarantined VLAN netdev `ge-0-0-2.100` excluded from exemptions and ingress scope.
  - `TestJunosHostZoneOwner12951QuarantinedClaimantFailsClosed` — quarantined claimant zone (zone-level ike/ident-reset) resolves no ingress netdevs and no exemption lists.
