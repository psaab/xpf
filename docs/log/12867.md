# #12867 — judge zone policy against the original SNAT source

- **Timestamp**: 2026-10-14 (`fix/12867-campaign-pub`)
- **Action**: Zone-policy revalidation of a source-NAT forward-wire alias now judges the pre-SNAT ORIGINAL source selectors instead of the post-SNAT wire tuple the retransmission carries.

## Why

`revalidate_zone_policy_on_session_hit` (stale arm) and its `NoLocalEntry` equivalent `sessionless_zone_policy_verdict` built `PolicyJudgmentInput` from the arriving `flow.src_ip` / `forward_key.src_port`. A source-NAT forward-wire alias — the HA/fabric retransmission of a translated flow — carries the public translated source on the wire, so the re-derivation asked the policy question against the translated tuple:

- a permit written for the internal original source did not match, and a live, admitted session was revoked under an unchanged policy that admits it (fail-closed against the wrong question);
- a permit naming the public translated source matched, keeping the alias flowing although no rule admits the original source (the fail-open the issue reports).

Policy runs after destination NAT and before source NAT (Junos order; the same reason admission passes the pre-translation source), so the judgment source must be the original tuple. The stale arm had already computed the canonical original key (`PolicyRevalidationTarget::Stale`), and the resolver already recovers an identity-checked original (`source_nat_validation_key`, #12187) for the keep-transient sessionless hit.

## Change

`userspace-dp/src/afxdp/poll_descriptor/policy_revalidation.rs`:

- New predicate `arrival_carries_translated_source`: the arrival's forward tuple is this decision's own translated source (translated address plus translated port, or no port rewrite). Mirrors the resolver's own translation test; a port-only translation's original-direction packet therefore reads as NOT translated.
- Stale arm: source selectors come from the canonical key — byte-identical for every ordinary hit (canonical key == packet tuple), original for a wire-alias hit. A row keyed on its own TRANSLATED tuple (fabric wire seed / materialized alias replica) declines: no authenticated original exists locally, the public tuple is not a policy identity, and revoking would assert a deny no walk derived while churning the seed against its shared canonical row; the next packet resolves through the canonical row (the placeholder bypass), where the original selectors are derivable.
- Sessionless arm: uses the resolver's identity-checked original when present; a translated arrival without one fails closed with a keyless drop rather than judging — or borrowing a permit for — the public tuple.
- `resolved.source_nat_validation_key` threaded from the poll site into `revalidate_zone_policy_on_session_hit` (its only consumer is the sessionless arm; a stale entry supplies its own canonical key).

## Validation

- `cargo test --bins policy_revalidation::tests -- --test-threads=1` (userspace-dp): 26 passed, including the new `zone_policy_snat_wire_alias_stale_judges_canonical_source_12867`, `zone_policy_sessionless_snat_alias_uses_original_or_fails_closed_12867`, `zone_policy_port_only_snat_judges_original_port_12867`, and `zone_policy_translated_keyed_row_declines_without_stamping_12867`.
- RED-before: with the judgment behavior reverted to master's (selectors, decline guard, and sessionless fail-closed; signatures kept), all four new tests fail — the canonical-source and original-port assertions return revocations, the fail-closed sessionless assertion forwards under an any-source permit, and the decline assertion receives a revocation.
- Full `cargo test --bins` (userspace-dp): 7832 passed, 0 failed, 8 ignored.

## Risk

Only translated forward-wire alias arrivals change behavior. Ordinary hits (canonical key == packet tuple) are byte-identical. Translated arrivals now judge the original source: original-source permits keep the alias (previously revoked), and public-source permits no longer keep it (previously forwarded). A translated sessionless arrival without an identity-checked original now drops. Rows keyed on their own translated tuple decline instead of judging; they converge to the canonical row on the next packet.
