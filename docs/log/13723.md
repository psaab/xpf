# Issue #13723

## Change

Keep `m.lastBindingIndices` aligned with binding rows that can still exist in the pinned BPF map. If primary or VLAN-alias row application fails after writing any rows, preserve the prior retry inventory and merge in the successful writes before returning the original error. When the binding watchdog repairs a primary or alias row, add that index to the same inventory so later stale-row clearing and fail-closed teardown can reach it. Duplicate indices are retained only once. The existing bindings-map test seam now also reaches the watchdog path, so its primary and alias repair behavior is tested without privileged BPF maps.
