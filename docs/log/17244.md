real consumers: the REST config response marshals the typed Config verbatim (REST

`ConfigFingerprint` sentence each — the fingerprint walk is JSON-tag-blind, and both
bits are behavior-carrying (fallback endpoint / rendered clause), so inclusion is

only: every `json:"-"` tag byte-identical, no field, type, tag, or
`fingerprintIgnore` changes. The issue's acceptance grep returns 0 hits on
`pkg/config/types*.go`.
