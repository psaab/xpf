# #17719: translate aggregated-Ethernet media MTU

- **Timestamp**: 2026-10-29
- **Action**: Removed `ae` from `isMediaMTUExempt16594`. Aggregated Ethernet now follows the existing compile-time media-to-L3 translation, so untagged `ae0 mtu 1514` compiles to protocol MTU 1500. Added a fail-on-revert compiler regression and removed the obsolete `ae` pass-through assertion. Updated the current config-schema guidance and clarified the historical #16594 log.
- **File(s)**: `pkg/config/media_mtu_16594.go`, `pkg/config/media_mtu_16594_test.go`, `docs/config-schema.md`, `docs/log/16594.md`, `docs/log/17719.md`, `debian/changelog`.
- **Validation**: The pre-fix named regression failed because `ae0 mtu 1514`
  compiled to `ifc.MTU=1514`, wanted 1500. Temporarily restoring the `ae`
  exemption as a mutation made the same regression fail with 1514, proving
  it detects this defect. After the fix, all `TestMediaMTU*` config cells
  passed with `GOTMPDIR=/tmp GOCACHE=/var/worktrees/.cache/go-build go test
  ./pkg/config -run '^TestMediaMTU' -count=1`; dataplane MTU and
  no-retranslation controls passed with
  `GOTMPDIR=/tmp GOCACHE=/var/worktrees/.cache/go-build go test
  ./pkg/dataplane -run 'MediaMTU|DoesNotRetranslate' -count=1`; and
  `GOTMPDIR=/tmp GOCACHE=/var/worktrees/.cache/go-build go build
  ./pkg/config/...` passed. No broad package suites were run.
- **Risk**: Authored MTUs on aggregated Ethernet are now reduced by the existing Ethernet overhead (14 bytes untagged, 18 when tagged), matching the media-MTU contract. An existing `ae` value written to mean an L3 MTU will need the corresponding media-MTU spelling; unset values and non-`ae` exemptions remain unchanged.
