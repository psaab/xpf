# #17719: translate aggregated-Ethernet media MTU

- **Timestamp**: 2026-10-29
- **Action**: Removed `ae` from `isMediaMTUExempt16594`. Aggregated Ethernet now follows the existing compile-time media-to-L3 translation, so untagged `ae0 mtu 1514` compiles to protocol MTU 1500. Added a fail-on-revert compiler regression and removed the obsolete `ae` pass-through assertion. Updated the current config-schema guidance and clarified the historical #16594 log.
