    occupied its varbind slot, contrary to the RFC 2863 linkDown/linkUp
    `OBJECTS { ifIndex, ifAdminStatus, ifOperStatus }` clause (#16778

    fault-down, and position-based parsers misread varbind 4. Added

    ifOperStatus, then ifDescr as a trailing additional varbind (RFC 3416
    §4.2.6); v1 emits ifIndex, ifAdminStatus, ifOperStatus, ifDescr.
    Threaded the event-time admin state (`attrs.Flags&net.FlagUp`, via
    the new `linkAdminUp` helper mirroring `buildSNMPIfData`) from
    `applyLinkState` through `emitLinkStateTrap`/`linkStateEmit`,
    `NotifyLinkUp/Down`, `sendLinkTraps`, the builders, and the deferred
    v1 `trapJob` (`adminUp`) so the worker-built v1 packet keeps the
    event-time value. All existing callers migrated to the new arity;
    no compatibility shims.
