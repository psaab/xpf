# Issue #12064 — resample interface link state before route-overlay dedup

## Why

A routes-only overlay inherited `Interfaces` from the last snapshot and checked its content hash before the apply-boundary interface resample. If an interface link flapped while route content stayed unchanged, the overlay dedup returned without publishing the new `LinkUp` state, leaving interface-only ECMP liveness stale.

## What

The overlay now clones the inherited interface rows and samples live `LinkUp` (including parent egress for logical-only rows) before hashing. The RTNL link watcher marks the route coalescer on `RTM_NEWLINK` and `RTM_DELLINK`, while retaining the existing interface-row refresh queue.
