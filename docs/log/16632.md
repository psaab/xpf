# Issue #16632: ip-monitoring per-test UNKNOWN rendering (R3-A49-02)

- **Timestamp**: 2026-10-25
- **Action**: The ip-monitoring policy `Known` predicate was per probe (any test with a verdict), and `FormatStatus` printed one wildcard `* PASS` row whenever no test was failing — so a test held forever without a verdict (setup hold, pin failure, source not local; rpm seeds it `LastStatus: "unknown"`) was reported as passing and never named. Fixed by carrying verdict-less tests into status: the engine now tracks `seenTests` (probe → test → observed with any status, from snapshots in `seedResultsLocked` and from `HandleTransition`), `Status()` computes `PolicyStatus.UnknownTests` (seen minus verdict-known, sorted) and `PassingTests`, and `Known` is true only when at least one test was observed and every observed test has a verdict. `FormatStatus` renders one row per test (PASS/FAIL/UNKNOWN) and a `PARTIAL` policy state for the mixed known/unknown cell (FAIL still wins, wholly-unknown stays UNKNOWN, no-observation keeps the legacy wildcard row). The fbf-steering scraper now accepts `PARTIAL` (not PASS, so PASS-gated callers still refuse). README Known definition updated to the per-test truth model.
- **File(s)**: `pkg/ipmon/ipmon.go`, `pkg/ipmon/display.go`, `pkg/ipmon/mixed_unknown_16632_test.go` (new), `pkg/ipmon/README.md`, `test/incus/fbf-steering-lib.sh`, `test/incus/fbf-steering-selftest.sh`, `docs/log/16632.md` (this file)

Defect cell names `wan-b` as `UNKNOWN` under `Status: PARTIAL` with no `* PASS`; all-known control still renders `Status: PASS`; failing+unknown control still renders `FAIL` and names `wan-b`.
- **Risk**: New `Status: PARTIAL` token — in-repo scraper (`fbf_ipmon_policy_state`) updated and self-tested; external scrapers matching only `PASS|FAIL|UNKNOWN` will treat PARTIAL as unparseable rather than as PASS (fail-closed, the intended direction). No packet-path effect: `evaluateLocked`/overlay logic unchanged, unknown still buckets with pass for FAIL state. Hand-built `PolicyStatus` values without the new fields keep the old wildcard rendering.
