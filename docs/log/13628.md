# Issue #13628: preserve remote annotate comments and authorization paths

## Why

Remote annotate dispatch parsed the operator's comment, then rebuilt a quoted
Set input without escaping embedded double quotes or backslashes. Server.Set
therefore parsed a truncated comment, while the authorization lexer could read
a different token stream and adjudicate a path the operator did not target.
Separately, authorization recognized `annotate ` only with a literal space,
although Server.Set accepts any whitespace separator; a tab could bypass a
`deny-configuration` rule while still reaching the annotate handler.

## What

Add a shared annotate-comment encoder/decoder in `pkg/cliterm`: escape
backslashes and quotes at the remote dispatch boundary, and decode those pairs
when parsing the comment. Preserve unrelated backslash sequences. Route
annotate requests to the authz gate using the same `strings.Fields` verb
recognition as Server.Set, removing the literal-space duplicate branch.
Canonicalize the authorization line from the shared handler parser's path and
comment values, then quote each path token and escape the comment for the authz
lexer. This prevents direct gRPC requests with unescaped embedded quotes from
expanding the path seen by authorization. Regressions cover dispatch wire
encoding, parser round-trips, persisted Server.Set annotations, and
interceptor-to-handler admission for space/tab separators, including embedded
quotes, against denied and allowed paths. No protobuf or store API changes.

## Validation

- RED before the fix: `go test ./cmd/cli -run
  '^TestDispatchConfigAnnotateEmbeddedQuote13628$' -count=1` failed because
the wire input contained unescaped embedded quotes.
- GREEN: focused #13628 regressions in `cmd/cli`, `pkg/cliterm`, and
  `pkg/grpcapi` passed; `go vet ./cmd/cli ./pkg/cliterm ./pkg/cli
  ./pkg/grpcapi ./pkg/config` passed.
- The interceptor regression reproduced the direct-request bypass before
  canonicalization: both space- and tab-separated embedded-quote requests
  reached the handler despite an anchored deny. The expanded regression passed
  after normalization.
- The affected-package test command passed `pkg/cliterm` and `pkg/cli`, but
  `cmd/cli` failed its tree-wide gofmt guard on 14 unrelated files outside
  this change. `pkg/grpcapi` reported two unrelated existing failures:
  `TestGetGlobalStatsScreenDropDetailKeysAreCanonical` (19 vs 15 keys) and
  `TestUngatedFallbackErasesDerivedHelperState10769` (AF_UNIX socket path is
  114 octets, above the 107-octet limit). That combined run timed out at
  360 seconds before the remaining package completed.

## Risk

The annotate Set input remains the existing wire contract. The encoder and
parser deliberately handle only the `\\` and `\"` escapes introduced for
annotate comments; other backslash sequences remain verbatim. Matching the
handler's whitespace verb parsing closes the tab-separated authorization
bypass without changing the handler's accepted syntax.
