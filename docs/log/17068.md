# #17068 — BestEffortKernelKnob lifecycle primitive

- **Timestamp**: 2026-10-27
- **Action**: Added the missing lifecycle primitive for the BestEffortKernelKnob class and migrated every pkg/daemon procfs writer onto it. `pkg/fsatomic/kernel_knob.go` provides `WriteKernelKnob`/`WriteKernelKnobVerified` (read-compare-write, newline-normalised, optional read-back) and the `KernelKnobs` owner registry (`Assert` captures the prior on first assert and refuses a second owner of the same path; `Release` restores captured priors and retains failed restores as retry debt per the #5114 rule; `KeepOnDisable` declares daemon-lifetime posture explicitly). Daemon migrations: `fib_multipath_hash_policy` now asserts on `load-balance consistent-hash` and restores the captured prior on removal (was assert-only — the live instance); RETH/VLAN IPv6 knobs, transit-gate ip_forward, host forwarding posture, and `realHostTunableFS.writeFile` go through `WriteKernelKnob` with warned (no longer silently discarded) errors; no-redirects assert/restore and the #15707 icmpv6 ratelimit repair use the shared writer while keeping their bespoke capture/cap semantics (#16779); transit cleanup uses the verified writer. The fsatomic canary allowlist now contains only the resolv.conf bind-mount fallback for pkg/daemon plus the primitive's own `realKnobFS.WriteFile`. NOT migrated: `reassertTCPloosePosture`'s injected seams (its fault-injection tests model module-load races through them; it is the single verified lifecycle owner of nf_conntrack_tcp_loose) and the non-daemon dataplane/networkd knob writers (outside the issue's daemon census; they keep their canary entries).
