# Issue #13297: Clear all dataplane counter offsets

## Finding

Deep-review D5-03 found that `dataplane.Manager.ClearAllCounters()` did not
clear NAT rule counter offsets and returned on a missing `interface_counters`
map before clearing zone/flood offsets. Thus userspace-only managers retained
stale counter values after a clear-all operation.

## Change

`ClearAllCounters()` now clears the in-memory zone, flood, and NAT offsets
before the fallible map operations, ensuring the clear takes effect even when
the legacy interface map is absent. It also invokes `ClearNATRuleCounters()`
in its BPF-map clearing sequence. Existing raw-helper composition and pinned
missing-interface-map error behavior remain unchanged.

The regression test seeds all three offset families on a mapless manager,
checks the pinned missing-map error remains, and verifies all offset families
are cleared.
