# #9893 — NDP neighbor learning from fragments + missing source check + Override TOCTOU

Work log for issue #9893. See `docs/log/README.md` for why this lives here and
not in the repository-root `_Log.md`.

- **Timestamp**: 2026-09-15
- **Action**: PR opened. `parse_ndp_neighbor_advert` refuses any NA whose IPv6
  chain sighted a Fragment header (RFC 6980 §5 MUST, counted) and any NA whose
  IPv6 source is not on-link unicast (counted); the Override=0 get-then-insert
  becomes an atomic CAS under the shard lock.
- **Base**: `origin/master 9168876e4`. STEP-0 repro (two cells asserting `None`
  for fragmented / bad-source NA) FAILED on base as expected — defect PRESENT.
  Post-fix all 14 new cells green 5/5.
- **Mechanism, verified on base**:
  - `parser.rs:233-235` kept only `(rel_l4, protocol)` from the shared walk;
    `frame/inspect.rs:223-266` walks past Fragment 44 to terminal L4, so the
    sighting was discarded and a non-first-fragment payload parsed as NA-136.
  - `parser.rs:272/275/280/299` were the only gates; source bytes read only
    for the checksum pseudo-header (`:356` pre-fix).
  - `poll_stages.rs:289-299` did `get` (lock 1) then `insert_if_changed`
    (lock 2) — the admitted best-effort TOCTOU.
  - Reachability: shim diverts unfragmented NDP (`lib.rs:729-731`) but stamps
    v6 non-first frag `PROTO_FRAGMENT_NO_L4` (`:1685-1686`), "a guaranteed
    session miss that falls through to the AF_XDP redirect" (`:1671-1672`);
    miss fallthrough `:824-826`; stage probes `parse_ndp` unconditionally
    (`poll_stages.rs:134-138`).
- **Fix**:
  - `parser.rs`: single direct `walk_ipv6_ext_chain(l3_slice, 0)` (same
    one-walk cost); after NA-shape confirm (proto 58 + type 136), refuse on
    `walk.fragment.is_some()` bumping `NDP_NA_FRAG_REFUSED`, then require
    `neighbor_ip_is_learnable(src)` on `l3+8..24` bumping
    `NDP_NA_BAD_SOURCE_REFUSED`. Counters are crate-local `AtomicU64` globals
    (test-visible in #9893; #10097 now carries them through the coordinator
    status reader and Prometheus neighbor-counter surface). NA-shape gating
    keeps ordinary fragmented transit out of the series.
  - `sharded_neighbor.rs`: new `insert_ndp_na_if_override_allows` — single-lock
    CAS returning `None` on Override=0 vs live differing MAC (no
    insert/epoch/cap/generation side effects), else the exact
    `insert_if_changed` body. `insert_if_changed` delegates with
    `override=true` so ARP/RX arms are byte-identical.
  - `poll_stages.rs`: `outline_ndp_na_learn_and_program` uses the CAS;
    `None` returns without learning (frame still transits).
