# #14196 — literal placeholder keyword bypass on CLI

- **Timestamp**: 2026-10-16
  - **Action**: Traced the mechanism at origin/master (805ac16cd). `resolveTreeWord`
    (`pkg/cmdtree/tree.go`) resolved every unique keyword prefix including
    `<placeholder>` keys; `Canonicalize` marked a placeholder filled only on its
    unmatched-word arm. Measured on a base worktree probe: `ping 192.0.2.1 <`,
    `ping 192.0.2.1 <host>` and `ping 192.0.2.1 <h` all canonicalized OK to
    `ping 192.0.2.1 <host>`, as did the traceroute and `show security log`
    equivalents and `show route < exact` -> `show route <destination> exact`.
    The login-class gate judged that polluted string (full form) plus the
    keyword-only prefix (`ping`), so an anchored `deny-commands
    "^ping 192.0.2.1$"` matched neither, while the handler's strict parser
    (`diagcmd.ParsePingOptions`) rejects the surplus word and the executed
    command is the denied target. Audited every `resolveTreeWord` consumer
    (`Canonicalize`, both completion walkers, `LookupDesc`, `SplitModifiers`,
    `nodeAtPath`) and every `Canonicalize` caller: placeholder names are only
    ever offered as end-of-walk completion candidates / typed-leaf hints,
    never legitimately resolved from typed words, so excluding them from
    resolution cannot remove a lawful command. No special-casing of the test
    input: the rule is a property of the resolver.
  - **File(s)**: none (research)
- **Timestamp**: 2026-10-16
  - **Action**: Fix. `resolveTreeWord` now excludes placeholder keys from both
    its exact arm and its unique-prefix arm (when every prefix match is a
    placeholder it still reports those names as matches, so ambiguity/absence
    reporting is unchanged, but never resolves). A literal angle-bracket word
    therefore reaches the existing value-slot arms as operator data: consumed
    once, raw, while its slot is empty; refused once filled, so a restricted
    class fails closed. Documented the rule at `resolveTreeWord`, in
    `Canonicalize`'s header, and in `pkg/cmdtree/README.md`.
  - **File(s)**: pkg/cmdtree/tree.go, pkg/cmdtree/canonicalize.go,
