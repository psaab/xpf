# XDP shim interface-NAT maps keyed by address only (#14644)

## Why

The XDP shim's interface-NAT maps (`userspace_interface_nat_v4` keyed
`u32`, `_v6` keyed `{addr}`) carried no routing domain, unlike the
LOCAL maps scoped by #13929. `is_icmp_to_interface_nat_local` ran
before the domain-scoped `is_local_destination` in the session-miss
arm, and the ESP / non-native-GRE arm used the same address-only
predicate, so ICMP echo, ESP and non-native GRE addressed to another
routing instance's interface-SNAT address were XDP_PASSed and
kernel-forwarded with no zone policy. With address overlap the same
match bypassed policy toward a default-instance host. The Go producer
erased the owner earlier still: `buildNATTranslatedLocalAddressExclusions`
returned address-only sets, so one address owned by two instances
collapsed to a single entry.

## What

- `userspace-xdp/src/lib.rs`: key both interface-NAT maps by
  `(domain, addr)` under new pin names
  `userspace_interface_nat_v4_domain` / `_v6_domain`; pass
  `ingress_domain` into `is_icmp_to_interface_nat_local`,
  `is_interface_nat_destination`, the degraded
  `is_degraded_local_or_control` arms, the redirect-error arm, the
  tagged-only firewall-owned check, and the native-GRE inner
  classifiers (which keep inner destinations on the worker path).
- `pkg/dataplane/userspace/maps_sync.go`: carry the egress row's
  `RoutingDomain` through `buildNATTranslatedLocalAddressExclusions`
  (candidate now records its interface's domain), the
  `WithExclusions` builders, and the desired interface-NAT sets;
  `userspaceLocalV6Key` gains the domain word. Local-map exclusion is
  likewise domain-scoped, so a kernel-enumerated address is excluded
  only in its owning domain.
- Pin-name migration mirrored in `pkg/dataplane/userspace/maps.go`,
  `pkg/dataplane/loader_userspace_shim.go`, the retirement canary,
  and the Rust WG kernel-path reader
  (`userspace-dp/.../wg_control/kernel_path.rs`), whose
  `destination_is_local` now probes the NAT maps in the tunnel's
  domain. Regenerated `userspace_xdp_bpfel.o`, manifest and gate
  verdict via `make build-userspace-xdp`.
- Tests: `shim_ifnat_domain_14644_test.go` (producer distinctness +
  BPF test-run cells), updated 12085/12809/cap/tagged-only/WG test
  fixtures for the scoped key ABI.

NOT changed: the worker-side interface-NAT resolution (#12086, already
table-scoped), RST suppression address sets (derived from the same
entries, address-only by construction), and the native-GRE
outer-local gate (inner IFNAT steering only).

## Validation

- RED on pristine master: a throwaway runtime probe against
  `buildInterfaceNATAddressEntries` failed with `entries=2 want 4`
  (same SNAT address in domains 0 and 100042 collapsed); the final
  `TestInterfaceNATEntriesRemainDistinctAcrossRoutingDomains14644`
  also fails to compile on master (`desiredV4` was `map[uint32]`),
  i.e. the domain dimension does not exist pre-fix.
- GREEN producer: `TestInterfaceNATEntriesRemainDistinctAcrossRoutingDomains14644`,
  12085 matrix/guards, 13929 local-domain, and 13724 kernel-exclusion
  tests pass.
- BPF: `make build-userspace-xdp` verifier PASS at 620456 processed
  insns (37.95% headroom). Privileged BPF test-run cells for
  foreign/same-domain echo, ESP and GRE pass under
  `sudo go test -run TestUserspaceXDPDoesNotPassForeignDomainInterfaceNAT14644`
  (foreign-domain cells take the worker redirect/XDP_DROP in the
  test harness; same-domain cells XDP_PASS).
- Pre-existing failures base-attributed on origin/master (stash
  `--keep-index` rerun, identical): `TestLab12809*` (config compile
  rejection from #14574), `TestLocalClear*13867/13909`,
  `TestAliasTableRefusesOnAReachablePlainSibling`,
  `TestSyncFabricStatePersistsResolvedFabricsIntoLastSnapshot`, and
  `cargo check` for `xpf-userspace-dp` (`persistent_inbound_lookup`
  arity mismatch in untouched files). A first combined privileged
  BPF run also reported one tagged-only and one degraded-ESP cell
  failing under parallel load; both pass when run individually.

## Risk

New pin names intentionally orphan legacy address-only pinned maps,
mirroring #13929; a mixed-version daemon/shim pair fails map lookup
loudly rather than silently sharing the old ABI. Same-domain
echo/ESP/GRE kernel delivery is preserved (BPF controls). The
degraded ctrl-disabled ESP arm now also requires same-domain
ownership, so a foreign-domain ESP under a dead helper drops instead
of passing — the fail-closed direction.
