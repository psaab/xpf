# #18623 — refuse a deferred fresh-bind control-address swap

- **Branch:** `fix/18623-drive`, rebased from `e79d78b2ac` onto current master `281739b000`.
- **Why:** The #18606 preflight only checked that the bound address remained configured. A candidate could keep that address while changing its primary/preferred selection, causing networkd and `selectClusterBindAddr` to choose a different address after a fresh bind. The documented boot-abstention window also lacked an explicit operator-risk/procedure note.

## Change

The preflight now carries configured addresses and family-specific primary/preferred selections for the running and candidate control-link states. If the bound address remains configured but the selectors change, it compares the fresh-bind selection for each state using the candidate peer family and refuses if the candidate would bind a different address. The selection mirrors networkd's address ordering and calls `selectClusterBindAddr`; address-order-only changes and unchanged selectors remain admitted, and removal of the bound address keeps its existing refusal behavior. Existing callers and tests use the state accessor.

Added primary-swap refusal, unchanged-primary admission, preferred-swap refusal, and bound-address-removal coverage, including the running-bind preflight integration test. The HA restart guidance now explains boot-window abstention risk and the paired offline procedure; the daemon README summary was updated. Boot behavior is unchanged.

## Review fold — resolved-netdev identity and parity boundaries

For exact declared interface refs, `controlLinkState18606` folds enabled
untagged units in numeric order. It includes units with no tunnel and tunnel
units whose `Tunnel.Name` equals `config.LinuxIfName(ifc.Name)`; it excludes
only tunnel devices with a different name and tagged child units. This includes
unit 0's base-device tunnel and a nonzero unit that shares an interface-level
WireGuard device. Non-tagged rows keep the first primary/preferred selector per
family and apply the renderer's DHCP-family static-address filtering.

VLAN-parent DHCP filtering is plan-dependent. When the parent has no address
plan, the renderer keeps configured untagged statics even if another unit asks
for DHCP; the preflight now retains those statics too. A planned parent with
`skipAddrs` can still have DHCP-owned families filtered by the renderer. The
preflight has no plan view, so it conservatively does not filter statics on any
tagged parent; this planned-parent shape remains a bounded parity residual.

The unit-0 GRE cell uses configured `gr-0/0/0`, whose Linux spelling is
`gr-0-0-0`. The compiler assigns that bare name to `unit 0`'s `Tunnel.Name` and
copies its addresses into the tunnel config; `routing/tunnel.go` reconciles
those addresses on the named kernel link. The preflight includes the address
because that is the bind device. This does not claim a networkd row owns tunnel
addresses: the dataplane skips rows with an empty hardware address.

An undeclared `.0` ref such as `hb.1.0` resolves to the same parent netdev as
`hb.1`, so it now uses the aggregate state; nonzero unit refs remain single
unit states. Secure-tunnel `st0` and `st0.0` retain their unit-0 per-unit
carve-out. Tests pin the unit-7 swap through `hb.1.0`, secure-tunnel addresses,
tagged-child exclusion, and a no-plan VLAN parent with unit-0 static plus
unit-7 DHCP.

The renderer's non-VLAN fold also iterates numeric unit order, preserving stable
address append and first-per-family selectors. A two-primary unit-0/unit-7
fixture pins the rendered model across repeated compiles and the preflight:
changing only unit 7's selector passes while unit 0 remains the winner, and
changing unit 0's winning selector refuses.

Interface-level `disable` remains an explicit operator shutdown, not a
renumber veto. The sibling endpoint/interface/topology gates do not inspect
`InterfaceConfig.Disable`; #9178 explicitly permits control-endpoint deletion
with a fabric fallback and documents the heartbeat stop as what the operator
asked for. `compiler_iface.go`'s administrative-disable path brings the link
down. A focused cell pins that an interface disable with its static address
retained is still admitted by the live-renumber gate.
