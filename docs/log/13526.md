# #13526 — per-issue acceptance for missing-neighbor forwarding

- **Issue**: #13526 — ensure fragment/session admission side effects are handled when forwarding is parked for neighbor resolution.
- **Branch**: `fix/13526-frag-assoc-followup`
- **Worktree**: `/tmp/wt-13526-fixpr`

## Why

A first fragment accepted into the missing-neighbor seed path commits its session before the neighbor is resolved, but that path did not publish the fragment association. Subsequent fragments therefore could not use the accepted session decision while neighbor resolution was pending. The path also refused new SYN seeds at capacity instead of applying the existing TCP-opening pressure-shed policy used by the regular forward-candidate admission path.

## What

- Install an eligible same-family/plain or same-family address-rewrite fragment association only after a missing-neighbor seed session is successfully committed. The association records the session identity and uses no resolved neighbor MAC.
- Preserve the raw ingress fragment authority when publishing the association; on an authenticated association hit, carry its committed translation through the missing-neighbor fail-closed fence.
- Apply existing TCP opening pressure shedding before refusing a missing-neighbor seed, including the normal session/BPF/NAT cleanup and replication behavior.
- Add regressions for first-fragment association publication, parked translated tails, and SYN admission via pressure shedding.

## Validation

- Pristine-master red comparison: both admission regressions failed at the expected assertions. A source-only revert of the follow-up also failed the app-scoped SNAT-tail assertion (`nat_frag_untranslated_dropped` was 1), proving that the authenticated-hit handling is exercised.
- Rebased branch: `cargo test --manifest-path userspace-dp/Cargo.toml --bin xpf-userspace-dp missing_neighbor_first_fragment_installs_frag_assoc_13526 -- --nocapture` passed, including a following SNAT tail that is parked with its committed rewrite and no untranslated-fragment drop.
- The capacity regression also proves that an established session is preserved and a new seed is refused when no pressure-safe victim exists. The full fragment module passed (36 tests), and `git diff --check` passed.

## Risk

Existing worker housekeeping remains responsible for expiry; this change does not add a packet-path expiry sweep. The seed path uses the existing TCP SYN/opening pressure-shed policy. NAT64 missing-neighbor refusal remains unchanged.
