# 10021 — Export policy-revoked established-session telemetry

## Summary

The userspace dataplane already counted established sessions revoked by live zone
policy in its poll telemetry (`policy_revoked_sessions`), but the debug fold did
not carry that value into the periodic `DBG` report and release builds exposed
no operator metric. The counter now has an always-on per-binding atomic, a
cluster-wide `ProcessStatus` field, and a standalone Go Prometheus series.

The signal counts REVOKED SESSIONS, not dropped packets. It is therefore kept
separate from `Packets dropped` and from the existing packet-oriented policy and
filter counters.

## What changed

- `DbgCounters::accumulate` folds `DebugPollCounters::policy_revoked_sessions`
and the `DBG` line reports `pol_revoked` when `debug-log` is enabled.
- The zone-policy revoke branch increments an unconditional per-binding
`AtomicU64`; `Coordinator` sums live bindings during each status refresh into
`ProcessStatus.policy_revoked_sessions_total`.
- The Rust and Go status structs use the additive JSON key
`policy_revoked_sessions_total`; omitted by an older helper, it decodes as
zero. The Go collector emits
`xpf_userspace_policy_revoked_sessions_total` unconditionally.
- The session README now names the production metric and distinguishes it from
the debug-only report.

## RED-then-GREEN proof

The new Rust and Go tests were first added against the old structs and failed
before implementation:

- Rust release debug-log test compile failed because the live atomic, debug fold,
and `ProcessStatus` field were absent.
- Go `pkg/api` test compile failed because `ProcessStatus.PolicyRevokedSessionsTotal`
and the collector descriptor were absent.

After implementation, these exact release tests each passed one test:

- `afxdp::tests_policy_revocation_8356::a_revoked_session_bumps_the_release_visible_live_atomic_10021`
- `afxdp::worker::loop_body::debug_report::policy_revoked_sessions_fold_tests::accumulate_carries_policy_revoked_sessions_10021`
- `protocol::tests::process_status_policy_revoked_sessions_total_roundtrip_10021`
- `afxdp::coordinator::status::tests::refresh_status_publishes_policy_revoked_sessions_total_10021`
- `protocol::tests::wire_invariant_default_specimens`

The Go collector and descriptor tests also pass with the new metric value and
full descriptor census.
