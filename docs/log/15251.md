# #15251: userspace-dp — PPTP ALG association + Prebuilt mirror cohort (A75-02, A75-04)

## Summary

Two validated Low-severity dataplane defects from the hostile full-firewall
review (`claude-opus-5-5-review-full-firewall-hostile-r2-002.md`, claims
A75-02 / A75-04; 3-way MATERIAL consensus in validator research run
`research-work.AdQvt1jMKw` at base `27b8cba22d`, re-anchored at current
`origin/master`):

- **A75-02** — A PPTP replacement call whose first-learn local install
  collides with a not-yet-applied CDN forget was learned on no worker and
  never retried. The call fell to the documented unassociated
  forward-and-count GRE path on all workers for its lifetime (with
  `gre-performance-acceleration`, flowless GRE). No drop and no
  enforcement loss, but the association was permanently lost.
- **A75-04** — Prebuilt transit frames (embedded-ICMP NAT reversal,
  including the NAT64 cross-family producer) were forwarded but never
  port-mirrored. Analyzer completeness only: transit ICMP errors toward
  NAT'd hosts were missing from the analyzer while the same error for a
  non-NAT flow was mirrored.

## Mechanisms (verified at current master)

### A75-02 — `userspace-dp/src/afxdp/pptp_broadcast.rs`

`drain_pptp_control_inbox_for_worker`'s `CallReply` arm did:

```rust
if let Err(e) = sessions.pptp_mut().install(call, control, seg.captured_ns) {
    debug_log!(...);
    continue;
}
```

On a first-learn `AllocatorCollision` (the drainer's own table still holds
the old call because the CDN forget is queued behind a backlog, or no CDN
has been applied yet) this skipped **both** `broadcast_pptp_install` to
the peers **and** `record_call_install`. The #12133 retry predicate keys
on `unsent_queue_ids` produced by a broadcast; a local first-learn failure
never produced one, so no retry was ever recorded for any worker. This is
the sibling residual of #12133 (fix `19dfbebcbd`).

### A75-04 — `userspace-dp/src/afxdp/tx/dispatch/mod.rs`

`enqueue_pending_forwards_with_dynamic`'s `PendingForwardFrame::Prebuilt`
arm enqueued the already-rewritten frame and `continue`d. Mirror staging
(`stage_sampled_mirror_clone`) and commit
(`commit_staged_mirror_clone`) were reached only by the Live/Owned path
below it. The production transit Prebuilt producers are
`poll_descriptor/embedded_icmp.rs` (`queue_prebuilt_embedded_icmp_error`,
same-family reversal) and `poll_descriptor/nat64_icmp_error.rs` (NAT64,
via the same helper); locally generated errors (`icmp.rs` class, exempt
by issue scope) do not use this arm.

## Fix

- **A75-02** (`pptp_broadcast.rs`, `CallReply` arm only): a local install
  error no longer `continue`s. The arm still broadcasts to every peer,
  and records the install for retry via `record_call_install` with the
  drainer's own queue id added to `unsent` (so the existing own-queue
  retry path — empty queue → direct local install, non-empty → enqueue
  behind the backlog, preserving CDN-before-replacement FIFO — learns it
  once the colliding alias is freed). `complete_call_install_broadcast`
  and the `learned` count are taken only when the local install succeeded
  and every peer accepted. When there is no self queue (test-only drain),
  a `usize::MAX` sentinel is recorded so the retry is retained but never
  misdelivered; production always passes `Some`. No behaviour change on
  the success path or on the CDN/channel-close arms.
- **A75-04** (`tx/dispatch/mod.rs`, Prebuilt arm only): after a
  successful `enqueue_local_request_to_target_or_owner`, stage and commit
  a mirror clone of the rewritten wire frame via the existing
  `stage_sampled_mirror_clone` / `commit_staged_mirror_clone`, honouring
  sampling (ingress mirror sample counter) and the analyzer output filter
  (inside commit / `enqueue_mirror_clone_to_binding`, fail-closed on port
  terms for the flowless `flow_key: None` tuple). Enqueue failure still
  mirrors nothing. Live/Owned mirror behaviour is unchanged; the local
  (device-generated) error path is untouched.

## Regression / RED-GREEN evidence

- `first_learn_collision_backlog_learns_replacement_on_both_workers_15251`
  (`afxdp/session_glue/tests.rs`): old call on both workers, a queued
  (not-yet-applied) CDN forget + backlog on the drainer, then CDN +
  replacement segments. Asserts the peer broadcast reached Q's queue and
  an own-queue retry was recorded despite the local collision, then —
  after the CDN applies and retries/commands drain — both workers resolve
  the replacement and no retry lingers. **RED pre-fix** (no broadcast, no
  recorded retry), GREEN after.
- Control kept green: `own_retry_retains_allocator_collision_until_cdn_frees_alias_12133`
  and the other #12133 FIFO cells.
- `prebuilt_transit_frame_is_mirrored_15251` and
  `prebuilt_nat64_frame_is_mirrored_15251`
  (`afxdp/tx/dispatch/tests/prebuilt_mirror_15251.rs`): drive
  `enqueue_pending_forwards` with a `Prebuilt` request (IPv4 wire frame;
  IPv6/NAT64-variant wire frame) and a mirror config. Assert
  `mirrored_packets=1`, mirrored bytes, and the clone queued on the
  analyzer binding carrying the rewritten frame. **RED pre-fix**
  (`mirrored_packets=0`), GREEN after.

## Validation

- `cargo test --bins -- 15251` in `userspace-dp/` — new cells pass.
- Targeted neighbours: PPTP #12133 cells, dispatch mirror/enqueue-failure
  cells (results recorded at commit time).

## Risk

- A75-02: a first-learn failure now generates a peer broadcast that
  pre-fix never happened. Peers without the colliding alias learn the
  replacement immediately (strictly better than unassociated GRE);
  peers with the alias refuse the queued command exactly as the existing
  #12133 broadcast path does, and the time-fenced CDN
  (`learned_ns <= disconnected_ns`) cannot remove the later association.
  The own-queue retry is bounded by the existing retry interval and is
  cancelled by a later CDN/channel close via the existing fences.
- A75-04: Prebuilt frames now pay one mirror clone copy when sampled,
  identical in cost/shape to the Live path. The analyzer output filter
  still gates the clone; enqueue failure mirrors nothing.
