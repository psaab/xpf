# #17809 — Preserve quoted pipe tokens in config show paths

- **Timestamp**: 2026-10-28
  - **Action**: Configuration-mode `show` now carries the config lexer's
    quoted-token mask through to pipe splitting. A quoted path element whose
    value is exactly `|` remains path data; an unquoted `|` still starts the
    display/compare modifier. The lexer regression now uses the actual quoted
    token `"|"` (and retains the separate `"a|b"` case).
  - **File(s)**: `cmd/cli/shared.go`, `cmd/cli/show.go`,
    `cmd/cli/show_system.go`, `cmd/cli/deactivate_activate_show_lex_16790_test.go`,
    `cmd/cli/show_pipe_modifier_13202_test.go`, `docs/log/17809.md`.
  - **Validation**: `go test ./cmd/cli -run
    '^TestRemoteConfigShowUsesLexedPath16790$' -count=1` failed before the fix
    with `syntax error: missing pipe modifier` for `policy "|"`; the same named
    test passed after the fix. Its cases verify the quoted `|` reaches the
    ShowConfig path, the unquoted `| display set` selects SET output, and the
    existing quoted `a|b` path remains intact.
  - **Risk**: The pipe splitter now depends on aligned quote provenance when
    called from config-mode parsing. Already-tokenized operational show
    callers pass no mask and retain their prior bare-pipe behavior.
