# #17169 — production IPsec-inner submit has no failing test (R4-Q16-02)

- **Timestamp**: 2026-10-27
- **Issue**: #17169 (R4-Q16-02)
- **Base**: `origin/master 7ca6cac490` (branch since behind master; defect re-verified there)

## Defect (STEP-0, verified at base)

Live: `ipsec_inner_v1_enabled` 4 sites (slowpath.rs:683,955,1024,1541); `true`
only in production `new_with_reinject_core`, `false` in cfg(test)
`new_without_worker_with_core`, so every hermetic reinjector ran the 125-line
legacy MTU/limiter/q0 branch production never takes and `submit_ipsec_inner_v1`
(1462-1527) had no test that could fail. `submit_conn_unflagged_routes_q0_writer`
asserted q0 `queued_packets==1`, contradicting "V1 never enters q0".
`decode_submit_batch_into_pool`/`PooledSubmitFrame` were test-only; production
used `decode_submit_batch` + `frame.clone()`.

## Fix

- Deleted `ipsec_inner_v1_enabled` and legacy branch (1544-1667); hermetic constructor now runs same V1 submit (worker-less only in TUN/channel plumbing).
- Deleted `decode_submit_batch`; wired `decode_submit_batch_into_pool` into `MSG_SUBMIT_BATCH` with `submit_ipsec_inner_v1_pooled(slab_id,…)` (no second copy; core refusal releases slab, transport refusal already released, success owned by transport). No-target path validates into scratch pool then SHUTDOWN.
- Rewrote q0 socket test to `submit_conn_unflagged_routes_v1_transport_not_q0`: `queued_packets==0`, transport `worker_pending(0)==Some(1)`. `live_target`/idle/announce hermetic targets publish worker 0.
- Added `v1_submit_reason_map_table_17169`: success, EVALUATOR_UNAVAILABLE→SHUTDOWN, WORKER_QUEUE_FULL→FULL, WORKER_QUEUE_BUSY→FULL, slab-exhausted→FULL, expired-deadline→BAD_LEASE; all assert q0==0.
- Fixes to pre-existing broken pins found while repointing: encoder writes zone/if as u32 (SUBMIT_PMECH_TAIL_LEN stale at 79, real 81); corrected codec expected bytes, data_len offset, and GO vector (inserted 2 zero bytes, len 138→140, tail pins to u32 offsets). Stats test updated: V1 refused submit counts adjudicated_refused, no live descriptor change beyond refused entry.
- #13707 limiter regressions: `enqueue_*` limiter paths are still live via `enqueue_request`/`forward_ipsec_inner_permit`; delegated-flood/queue-full tests unchanged and pass by construction (not deleted).

## Validation (named hermetic only)

- `cargo check` — no `decode_submit_batch`/`PooledSubmitFrame` never-used warning; `rg ipsec_inner_v1_enabled userspace-dp/src` = 0.
- Exact binary `--exact` 14 tests: all passed (v1 table, q0→V1 socket, stats, pooled decode, dry-run refusals, serial/bad-frame/no-target/disconnect socket cells, codec caps/flags/roundtrip/GO-vector).
- Mutant: removing `WORKER_QUEUE_BUSY` from V1 reason map → `v1_submit_reason_map_table_17169` FAILED (reverted, not rebuilt after revert — green run was pre-mutant on identical code except that arm).

## Risk

- Production submit now decodes into transport pool of the *target* reinjector; dry-run rows (Go-unreachable today) release slab after validate. No-target batches allocate a scratch pool per batch (cold refusal path).
- GO-vector correction assumes Rust u32 encoder is authoritative over the stale 138-byte pin; Go encoder should be checked by parent if Go still emits u16 zone.
