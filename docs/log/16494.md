# #16494 — #14833 scratch pin's 28-char GOTMPDIR overflowed sun_path

- **Timestamp**: 2026-10-24
- **Context**: The #14833 scratch pin exported
  `GOTMPDIR=/var/worktrees/.cache/go-tmp` (28 chars) to every make
  recipe and selftest leg. Go 1.26's `testing.TempDir` builds
  `<GOTMPDIR>/<name[:64]><random>/001/<sock>`, so a worst-case
  `control.sock` path is 120 octets — past the 107-octet AF_UNIX
  `sun_path` limit. On a clean tree `make test-go` / `test-race-dp`
  showed 45+ false reds (`bind: invalid argument`) in the helper
  control-socket, event-stream, HA-watchdog, reinject and gRPC
  teardown tests, indistinguishable from dataplane regressions.
  `scratch-pinning-selftest.sh` modelled a 71-byte path
  (`TestMemlockGuard1234567890/0123456789.sock`, no `/001`) that Go
  never produces, so it could not detect the overflow.
- **Fix**: `GOTMPDIR` now defaults to `/wtgt` (5 chars; worst-case
  canary path 97 octets) in `Makefile`, `scripts/run-selftests.sh`,
  and the `test-memlock-guards` recipe (which also sets `GOTMPDIR`
  explicitly beside its `TMPDIR=/wtgt`). All other pins
  (`TMPDIR`/`GOCACHE`/`CARGO_TARGET_DIR` under
  `/var/worktrees/.cache`) are unchanged; an explicit caller
  `GOTMPDIR` still wins (`?=` / `${:-}`). The modelled check is
  replaced by an executed canary, `scripts/sunpath-canary`, which
  reproduces the real TempDir shape (64-byte name + 10-digit random
  stand-in + `/001/control.sock`) and binds it:
  `scratch-pinning-selftest.sh` requires it to pass under `/wtgt`
  and fail under a deliberately long root, so the check reds in
  both directions (root lengthened, or canary stops binding). If
  `/wtgt` cannot be created on an unprivileged host, the positive
  leg SKIPs loudly instead of falling back to a long root.
  `/wtgt` lives at the filesystem root because no path under
  `/var/worktrees/.cache` (24+ chars) can fit the bound — even
  `/var/worktrees/.cache/gt` yields 116 octets.
- **File(s)**: `Makefile`, `scripts/run-selftests.sh`,
  `scripts/scratch-pinning-selftest.sh`, `scripts/sunpath-canary/main.go`
  (new), `scripts/README.md`, `docs/log/16494.md`, `debian/changelog`
- **Validation**: canary binds at 97 octets under `/wtgt`, fails at
  120 under the old root and 116 under `/var/worktrees/.cache/gt`.
  `scratch-pinning-selftest.sh` green with the new pins; RED on
  revert (restoring the 28-char pin in Makefile/run-selftests makes
  it fail naming all three GOTMPDIR/TMPDIR pins). Previously
  failing cells now pass under the short root and fail under the
  old root with the exact issue signatures: `pkg/nfqueue`
  TestReinjectSocketCompletionTimeoutResetsPartialFrame9506
  (`bind: invalid argument` at 001/complete.sock),
  `pkg/grpcapi` TestUngatedFallbackErasesDerivedHelperState10769
  (115-octet validator message), sampled
  `pkg/dataplane/userspace` event-stream/control/DumpFIB/HA-watchdog
  cells, and the two `pkg/daemon` event-stream race cells.
  `selftest-census.sh` still OK (62 invoked). Full `make test-go`
  failure-set equivalence (pinned vs unpinned) not run — it takes
  minutes under campaign load and the packages carry unrelated
  pre-existing fixture rot; the targeted cells above cover the
  pinned-only failure class.
- **Residual**: hosts must be able to create `/wtgt` (root-owned
  `/`); the Makefile `mkdir -p` and the selftest both attempt it and
  the selftest SKIPs loudly when they cannot. Tests that embed
  sockets deeper than `t.TempDir()/001/<name>` (extra subdirectories
  or socket names well over 12 chars) can still overflow — those
  sites carry their own `shortSockDir`-style helpers, unchanged.
  The old `/var/worktrees/.cache/go-tmp` directory is left on disk;
  nothing references it after this change.
