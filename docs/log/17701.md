# #17701 - Make refresh attach admission row-order independent

- **Timestamp**: 2026-10-28
- **Action**: `interfaceOwnerRowForIfindex` prefers the structural base/interface row (`IsUnit == false`) over same-ifindex logical units, independent of ordering; unit-only ifindexes retain their first owning unit row. Refresh reconciliation uses that same resolved owner for both admission and generic/native attach-mode selection, falling back to the first contributing row only when there is no owner. Added regression coverage for admission and attach mode in both row orders, with disabled-base controls.
