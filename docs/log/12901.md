# #12901 - Local CLI `show security policies` standard/brief view defects

- **Timestamp**: 2026-10-14
- **Action**: The standard (non-brief/non-detail) dispatcher view now
  annotates an inverted match with ` (except)` on the flat
  `Source addresses:` / `Destination addresses:` lines (zone-pair and global
  branches, mirroring the detail `#3336` and remote `#3672` renderers), and
  gates the `, log` action token on `PolicyLog.SessionLogModes()` so an EMPTY
  log block (leniently-loaded bare `then log`, `#3060`) no longer describes a
  policy as logging. The `brief` table now computes the zone-quarantine set
  (`#10530`/`#5577`) before reading counters: a quarantined zone-pair rule or
  a quarantine-dropped scoped global (`#12897`) renders the
  `UNAVAILABLE (quarantined zone — live counters unavailable)` Hits
  disposition with the zone qualifier instead of reading its never-published
  counter as `n/a`, and is excluded from the "not yet published by the
  dataplane" note (which then counts only genuinely late live rules).
- **Validation**: Regression `Test_12901_*` in
  `pkg/cli/cli_show_policies_standard_view_12901_test.go` — RED on pristine
  `origin/master` (5f0a5735d: no `(except)`, `, log` on an empty
  `PolicyLog{}`, quarantined brief row `n/a`), GREEN post-fix; full
  `pkg/cli` suite passes.
- **Risk**: Display-only, operator-facing text. Un-inverted rules, rules
  with a real session-log mode, and live brief rows render bit-identically;
  the strict commit path already rejects every newly-gated shape.
