- **Timestamp**: 2026-09-10
  - **Action**: Decision: the pre-flight consults the mirror, so the lists
    cannot drift. A class added to the mirror reaches `commit confirmed` with
    no edit to the gate. Wiring:
    - `rollbackTargetAppliablePreflight(target, feedOverlay)` refuses when
      `PolicyContentRejectionReasons(target, feedOverlay)` is non-empty and
      names the first reason plus the count of the rest.
    - commitConfirmedAndApply passes `d.feedSnapshotsForConfig(rollbackTarget)`,
      the same source the apply path hands the manager (`SetFeedSnapshots` in
      daemon_apply_dataplane.go). Representability is feed-aware. With a nil
      overlay a declared dynamic-address binding is unrepresentable, so a nil
      overlay would refuse every feed-backed box.
    - Consequence, measured and kept: a binding whose feed has no installed
      snapshot yet is omitted by SnapshotForBindings and fails closed in the
      mirror (#5645, policies_lower.go). The helper refuses that snapshot now,
      so `commit confirmed` is refused until the feed is ready. This is the one
      strict-valid refusal; a plain commit is unaffected. The function doc
      comment's earlier "fires only on content a strict commit rejects" was
      false for this case and is corrected.
