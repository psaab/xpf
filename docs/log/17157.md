# Issue #17157 — R4-Q20-04: preWalkResult + derived node identity

- **Issue:** Since 2026-10-03 `compileOpts` (billed as per-call compilation policy) also carried computed inputs (`physicalInterfaces`, `zoneQuarantineNames`, `currentClusterPrimary16025`, `nodeAware`/`stampNodeID` duplicating `compileTree`'s own `nodeID *int`) and two pointer out-parameters (`applicationNameCollisions`, `firewallFilterCollisions`). `runPreWalkGates` therefore returned results two ways: #16001 sites as an ordinary return value, both collision sets written through pointers installed at `compiler.go:911-918` (drifted: 985-992) and written at `compiler_prewalk.go:283-285,314-316`. Field docs also said "Both compile wrappers" though only one wrapper (`compileTree`, #16167) has existed, and described silent degradation when a caller left a pointer nil.
- **STEP-0 (defect live on origin/master `8d8bfaffb9`, worktree branch point):** all cited sites re-verified at drifted lines: `compiler_opts.go:1174,1215` (`*map[string]struct{}` fields), `:3826-3827` (`nodeAware bool` + `stampNodeID int`), `:3832,3840` ("Both compile wrappers"), `compiler.go:985-992,993,1034-1037,860-861`, `compiler_prewalk.go:283-285,314-316`, `compiler_derivations.go:89-91`, and the `"nodeAware"` key in `compiler_opts_lenient_completeness_16166_test.go:68` plus its `opts.nodeAware` assertion at :283. `grep compileExpanded(` shows exactly one production caller (`compiler.go:863`) plus `parser_ast_test.go:4584,4599` passing `compileOpts{}`. The accepted fix direction: `runPreWalkGates` returns a `preWalkResult` struct including both collision sets; derive `nodeAware` from `nodeID != nil`; fix the stale "Both compile wrappers" text. A full `compileInputs` struct is optional and not done.

## What

1. **`preWalkResult` (single result channel):** `runPreWalkGates` now returns `(preWalkResult, error)` — `compiler_prewalk.go`. `preWalkResult{warnings, uncovered16001, applicationNameCollisions, firewallFilterCollisions}` carries every result the phase produces; all 63 error sites return `preWalkResult{}, err`. The two `*opts.<field>` write-throughs are deleted; the collision sets are the validators' own return values (`appCollisionNames`, `fwColliding`) placed into the struct. `compileExpanded` destructures the struct (`compiler.go:989-996`) and its downstream consumers are byte-unchanged. No behavior change: same maps, same order, same first-error slot.
2. **No pointer-to-map fields:** deleted `applicationNameCollisions *map[string]struct{}` and `firewallFilterCollisions *map[string]struct{}` from `compileOpts`. `TestCompileOptsShape17157` reflects over `compileOpts` and fails on any `*map[...]` field, so the out-parameter pattern cannot silently return.
3. **Derived node identity:** deleted `nodeAware bool` and `stampNodeID int`; added `nodeID *int` — `compileTree` stamps `opts.nodeID = nodeID` (its own selector, one unconditional assignment, no copy that could diverge). `resolveDerivedConfig` guards on `opts.nodeID != nil && *opts.nodeID >= 0` and stamps `*opts.nodeID`. This preserves the stamp-before-gates ordering the issue calls load-bearing (`compileTree` :854-862 before `compileExpanded`; stamp inside P5 before the fabric fixup) and the CompileConfig path is unchanged (nil stays nil). The #16166 allowlist `"nodeAware"` entry is DELETED (not reworded); the completeness test's trailing assertion now checks `opts.nodeID != nil`, and `TestCompileOptsShape17157` fails if `"nodeAware"` re-enters the allowlist or either deleted field returns.
4. **Stale docs:** "Both compile wrappers" (×2) → `compileTree`; the `zoneQuarantineNames` doc no longer claims nil "stamps the empty set … pre-#13095 behavior" as a wrapper contract (now: `compileTree` sets it; a direct `compileExpanded` caller sees the same documented fallback); the `physicalInterfaces` doc likewise; the `compileOpts` header contract rewritten (policy + computed inputs in; outputs NOT carried — every phase result returns as a return value); `lenientCompileOpts` doc no longer leans on the value-copy argument for result channels; `compiler_firewall.go`'s "compileExpanded stamps it" now reads "returns it in preWalkResult; compileExpanded stamps it"; `compiler_derivations.go` guards rewritten for `opts.nodeID`. Out of scope per the fix direction: `physicalInterfaces`/`zoneQuarantineNames`/`currentClusterPrimary16025` remain computed inputs on `compileOpts` (typed, non-pointer-to-map), and `nodeID *int` itself is a pointer (required — presence is the signal; it is not a pointer-to-map and not an out-parameter).
