# #13684 — avoid double address selection for persistent NAT

Address-only source-NAT matching selected a round-robin pool address before
checking `persistent_nat`, then a fresh address-only persistent lease selected
its own address. This advanced the family counter twice per fresh subscriber,
skewing pool selection and potentially leaving addresses unused. The IPv4 and
IPv6 match paths now defer selection to the lease allocator for real persistent
flows; synthetic and non-persistent paths retain their existing selection.

End-to-end regressions cover fresh IPv4 and IPv6 persistent subscribers and
assert that both addresses in a two-address pool are selected.
