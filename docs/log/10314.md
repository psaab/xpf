# 10314 — stop fabric anti-loop redirects and reject foreign L2 unicast

- **Timestamp**: 2026-09-18
- **Action**: Separate physical fabric-link arrival (parent or overlay) from validated fabric stamps, suppress fabric redirects on every HA/session/cache path for fabric arrivals, and reject unmatched unicast destinations before link learning, decapsulation, or L3 forwarding.
- **Files**: `userspace-dp/src/afxdp/forwarding/fabric.rs`, `userspace-dp/src/afxdp/forwarding/ha.rs`, `userspace-dp/src/afxdp/poll_descriptor/{flow_cache_hit.rs,flow_cache_hit_tests.rs,mod.rs}`, `userspace-dp/src/afxdp/session_glue/mod.rs`, `userspace-dp/src/afxdp/forwarding/tests.rs`, `userspace-dp/src/afxdp/tests_fabric_zone_stamp.rs`.

### Cell 4 — cached FabricRedirect fast path

With the cache invalidation predicate removed, the direct flow-cache regression failed because a parent/overlay arrival served the cached redirect:


After threading `fabric_link_ingress` through `stage_flow_cache_hit`, the same command passed. It now falls through to slow-path HA resolution without enqueuing the cached fabric redirect.

### Cell 5 — destination-MAC acceptance

Before the L2 gate, the descriptor regression for a wrong unicast destination queued one forward (`queued 1`). The post-fix descriptor cell passes with no forward and no session seeded. The helper regression also verifies fail-closed behavior when no local MAC is configured while broadcast remains accepted.

The gate runs on the original Ethernet frame before ARP/NDP classification, decapsulation, source-neighbor learning, or L3 flow resolution. Group destinations remain accepted; only unmatched unicast is rejected.
