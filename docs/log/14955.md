# Issue #14955: stop early-passing exact-local fe80::/10 unicast

- **Timestamp**: 2026-10-18
  - **Action**: `ipv6_early_pass_to_kernel` in `userspace-xdp/src/early_filter.rs`
    now returns only `is_ipv6_multicast(dst)`; the `(is_local && is_ipv6_link_local)`
    arm is removed so exact-local fe80::/10 unicast no longer passes to the kernel
    in `should_fallback_early` before `USERSPACE_SESSIONS`, `wg_worker_claim`,
    and native-GRE inner classification. `should_fallback_early` in
    `userspace-xdp/src/lib.rs` drops the now-dead early ownership lookup.
    Session-miss `is_local_destination`, degraded local-control, the pre-early
    WireGuard steer, and multicast early pass are preserved.
  - **File(s)**: `userspace-xdp/src/early_filter.rs`, `userspace-xdp/src/lib.rs`,
    `userspace-dp/src/afxdp/frame/tests_shim_early_filter_10640.rs`,
