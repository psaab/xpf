# #10313 — unknown tagged VLAN must not inherit a sibling zone

- **Issue:** A tagged frame whose `(physical ifindex, VID)` pair was absent from the configured logical-ingress map fell back to the physical parent. On an agreed-zone trunk that parent inherited a sibling unit's zone, while the missing-parent snapshot shape left the `from interface` name empty.
- **Implementation:** `ForwardingState` now records physical parents that carry logical VLAN units. An exact-map miss on a nonzero tagged VID is recognized as an unknown ingress identity. The common poll boundary recycles those frames before destination classification, ARP/NDP learning, decapsulation, cache/session lookup, screen evaluation, and policy/NAT. The pre-routing scope independently keeps the real physical parent for interface/routing-instance matching while returning an empty zone. When only a tagged unit row survives snapshot construction, its structurally-known dotted name supplies the parent config identity. Untagged ports and exact known-VLAN resolution retain their existing fallback.
