# Issue #13693

## Change

Allow a different subscriber's generation-accepted lease import after a clear while preserving per-key tombstones for cleared keys; raw imports remain fenced. Preserve the index-based import path and expired-idle reclamation from rebased `origin/master`. During clear, active leases are deindexed when they become revoked draining shells; idle leases are deindexed exactly once by `remove_persistent_lease`.

## Residual risk

The Go batch gate rejects older generations but accepts equal-generation batches. Thus an old equal-generation batch for an un-tombstoned key can still bypass the global fence through the generation-authorized importer. Filed separately as [#13867](https://github.com/psaab/xpf/issues/13867), with reproduction evidence and acceptance criteria.
