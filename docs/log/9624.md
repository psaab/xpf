# #9624: two IPsec VPNs can render the same swanctl SA name

- **Timestamp**: 2026-09-11T03:43Z

- **Action**: research.
  - A child name is `<vpn>-<sanitizeChildName(selector)>`. Runes outside
    [A-Za-z0-9._-] become '-', with an FNV disambiguator only when two selectors of the
    SAME VPN share a base (#5122). There is no cross-VPN disambiguation.
  - A VPN with no selector renders connection `<vpn>` AND child `<vpn>`.
  - The issue's collisions reproduce from that derivation. VPN a with selector b-c and
    VPN a-b with selector c both render `a-b-c`. VPN blue with selector red and VPN
    blue-red (no selector) both render `blue-red`.
  - `ipsec.BuildSANameIndex(...).Collisions()` already computes the colliding names
    from the real render, but only the daemon's attribution warning uses it.
  - `pkg/config` cannot import `pkg/ipsec`, which imports `pkg/config`.
- **Action**: placement decision, option (i).
  - Rejected: a daemon commit pre-flight reusing `Collisions()`. Those pre-flights run
    on commit and commit confirmed (`daemon_apply_commit.go`), but NOT on
    `commit check` (gRPC CommitCheck -> store.CommitCheck) or `xpfd check-config`. So
    `commit check` would pass what `commit` rejects.
  - Chosen: move the pure name derivation into a leaf package imported by BOTH the
    renderer and the compile gate. The in-process CLI commit (store.Commit /
    store.CommitCheck) and check-config (CheckText -> compileTreeStrict) both reach the
    strict compile gates, so the gate covers every commit path plus the lenient
    load / peer-sync path.
- **Action**: implementation.
  - New leaf package `pkg/ipsecname` (imports only rendersafe). It provides
    `SwanctlValue`, `ChildBase` and `Disambiguator` (moved verbatim from pkg/ipsec),
    plus `ChildNames(vpn, selectors)` (the #5122 bases/counts/used logic, independent of
    input order) and `SANames(vpn, selectors)` (connection and child names in swanctl
    spelling, deduplicated).
  - `pkg/ipsec` `effectiveTrafficSelectors` now takes child names from
    `ipsecname.ChildNames`. `sanitizeChildName` and `childNameDisambiguator` are
    removed (no test called them), as is the hash/fnv import. pkg/ipsec: 305 passed
    after the move.
  - `validateIPsecSANameCollisionsStrict` (pkg/config) maps each SA name from
    `ipsecname.SANames` to the VPNs rendering it. The first name with two or more owners
    (sorted) fails, and the message names the VPNs and the SA name. Every configured VPN
    takes part, including one the renderer would skip (conservative).
  - The gate is registered in `runUniformGatesIPsecEvent` right after the endpoints gate,
    with the strict/lenient pattern and a new `lenientIPsecSANameCollision` opt. Both
    anchors are away from #9623's end-of-function insertion, to avoid a textual conflict.
  - **File(s)**: `pkg/ipsecname/ipsecname.go` (new), `pkg/ipsec/policy.go`,
    `pkg/config/compiler_validate_strict_ipsec_sa_collision_9624.go` (new),
