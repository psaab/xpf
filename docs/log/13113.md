# Ignore non-zone tokens in stable zone-ID collision checks (#13113)

- **Issue**: #13113, source finding D1-09 (deep-review; validated by the three-way research gate).
- **Cause**: `validateZoneIDCollisionAST` combined post-expansion names and the pre-expansion group scan without filtering wildcard group templates or reserved context names. Reserved tokens are skipped as ID claimants by `QuarantinedZoneNames`; wildcard templates are patterns, not concrete installed zones. A group `security-zone <*>` template therefore collided with concrete `z65162` (both fold to 15527), and reserved `any` collided with concrete `z63256` (both fold to 29700), incorrectly rejecting strict commits or warning/quarantining the real zone on lenient loads.
- **Change**: Add a shared collision-candidate predicate that excludes `reservedZoneNames` and Junos wildcard patterns (using `groupKeyPattern`). Apply it to both the runtime-name set and each pre-expansion group scan before constructing the collision map. Keep the returned runtime-name set unchanged so reserved-name exclusion and reporting continue to use their existing path.
- **Regression coverage** (`pkg/config/zoneid_wildcard_reserved_13113_test.go`): public strict and lenient compiles cover universal and glob wildcard group templates and reserved-name cases; ensure concrete colliders are neither rejected/warned nor quarantined; retain a real concrete-collision control.
- **RED evidence**: On pristine `origin/master` at `34b6e8c` with the regression test copied in, `go test ./pkg/config -run '^TestZoneIDCollisionIgnoresWildcardAndReserved13113$' -count=1` failed: strict compile rejected `"<*>"`/`z65162` and `any`/`z63256`; lenient compile emitted collision/quarantine warnings for both. The final test also expects strict `junos-host` definition to be rejected for its unrelated reserved-name reason.
- **GREEN evidence**: The focused regression passes. `go vet ./pkg/config/...` passes; `go test ./pkg/dataplane/... -run '^$'` compiles the dependent dataplane packages; gofmt and `git diff --check` pass. The unconstrained full `go test ./pkg/config/... -count=1` attempt timed out after 600 seconds amid concurrent campaign runs. Retrying with `GOMAXPROCS=1` and `-p=1 -timeout=30m` passes: `ok github.com/psaab/xpf/pkg/config 1517.475s`.
- **Blast radius / risk**: Collision adjudication now considers only names that can claim an installed stable zone ID; it does not change runtime-name metadata, reserved-name validation, or actual concrete-zone collision handling.
