## Evidence ledger

1. `userspace-dp/src/afxdp/poll_descriptor/embedded_icmp.rs:518-535` resolves `(ingress_ifindex, ingress_vlan_id)` to a logical interface and queries `ifindex_to_zone_id`. The missing logical-unit zone previously fell back to raw `meta.ingress_zone`, which is not authority for the actual interface's zone.
2. Both same-family embedded ICMP (`embedded_icmp.rs:146-150`) and NAT64 error arms (`nat64_icmp_error.rs:102-106,174-178`) call the shared helper. The result drives `related_admit` (`embedded_icmp.rs:181-188`; NAT64 `nat64_icmp_error.rs:153-160`) and finalized forwarding resolution (`icmp_embed/builders.rs:610-634`). Thus a sibling zone can match a quoted session's expected arrival zone and admit an error under RELATED instead of zone-policy evaluation.
3. The common ingress boundary drops unknown VLAN identities before the packet reaches these consumers (`poll_descriptor/mod.rs:639-665`). This does not refute the finding: a configured, known logical child can be unzoned while its physical parent / sibling has a zone. For that known child, the authoritative map lookup is absent and zone 0 is required.
4. RED reproduction on unmodified behavior: `cargo test --manifest-path userspace-dp/Cargo.toml unzoned_logical_unit_resolves_zero_not_shim_zone_12866 -- --nocapture` failed with `left: 7`, `right: 0`. Fixture maps `(parent=10, VID=100)` to unzoned logical ifindex 20 and carries shim zone 7. This demonstrates the exact stale-zone inheritance in the helper.
5. Minimal fix: make absent map entries resolve to `0`; preserve authenticated `ingress_zone_override`, logical interface's own configured zone, and physical fallback zone for ordinary untagged ingress. Regression boundaries cover all four behaviors.

## Risk and coverage

- Linux kernel/NIC datapath: the XDP ingress metadata and configured VLAN identity establish the scenario; this fix is in userspace userspace-datapath zone resolution after ingress validation. No kernel/XDP ABI change.
- Network/firewall architecture: fail closed to zone 0 only when the resolved logical interface lacks an authoritative zone; preserve authenticated fabric override and ordinary physical lookup.
- Rust systems/HPC: one existing `HashMap` lookup and its `unwrap_or` default only; no new allocation, copy, loop, or packet-path computation.
- Test/reliability: direct helper regression demonstrates exact identity distinction; related-admission condition is explicitly zone equality, so zero cannot inherit a positive parent/sibling zone.
- Residual risk: behavior of actual packet ingress remains bounded by existing known-VLAN descriptor guard; this report uses a unit-level fixture for the helper, not live AF_XDP traffic.
