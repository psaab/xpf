- **Action**: Folded the #18703 review (seats AA and AB, both MINOR) and
  the coordinator's deadline decision. Each finding was checked against
  the code before folding.
  1. **The crash window (AA).** `--crash-slack` was the minimum
     exec RTT over three probes. That is a lower bound, not a limit on
     when the sysrq ran (checked: `_failover_clock_offset` keeps the
     minimum-RTT sample). Replaced it with `failover_epoch_after`, read
     after the sysrq exec returns or is reaped. The exec dies with the VM,
     so this window is seconds wide and only says where to look for the
     aggregate's stop. With no stop in it there is no precise crash anchor:
     the clock-only anchor is capped at ±0.25 s.
  2. **Precision honesty (AA).** The ±0.05 s is now called a design budget.
     `crash_stop_after_epoch_s` records the stop's distance from the
     mapped `failover_epoch`. The "close" flag now names a stream when a
     3 s or 10 s line, widened by the anchor's uncertainty, falls inside
     the interval it resumed in. That is the in-interval read's error
     band (checked: 2s91's stream 11 resumes in `[60.0, 61.0)`, which
     holds 57.603 + 3).
  3. **Fallback (AA).** With no precise anchor, the cell takes the integer
     verdict at the anchor and ±1 s, and is VOID when those disagree.
  4. **Provenance (AB).** Builds and full source paths are in the fixture
     table above (checked against each cell's `versions.txt`). The PR body
     already read 0.97.
  5. **Policy (coordinator).** FAIL when a stream has not resumed within
     10 s, COST when it resumed after 3 s, PASS otherwise. The policy is
     opt-in (`--straggler-cost`): test-failover passes it, and
     ha-smoke-iperf-lib.sh keeps the old verdict byte for byte. test-failover
     scores the oracle's COST lines with its existing `cost` cell.
