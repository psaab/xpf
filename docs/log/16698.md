# #16698: load classifier routes hierarchical `show` output to flat replay

- **Timestamp**: 2026-10-25
- **Action**: `ClassifyLoadContent` (`pkg/config/authz_config_load_9892.go`)
  classified a load body as flat whenever ANY uncommented line satisfied
  `IsFlatLoadLine`, with no brace-depth or hierarchical-context check. A
  hierarchically authored unquoted event-options change-configuration
  command (`commands { set system host-name pwned; }`) is stored with no
  quote provenance, so `Format`/`ShowCandidate` renders it bare at line
  start; reloading that own output via `load override` or `load merge`
  then failed with `line 1: is not a set/delete/deactivate/activate/annotate
  command`. The classifier now tracks brace depth over the comment-free
  text (quoted braces are data to the real lexer, so the scan tracks
  quotes with readString's escape rule) and routes flat only when a
  flat-verb line's first token sits at depth 0. A verb-led line at
  depth > 0 is a hierarchical value; a verb-led line at depth 0 after a
  block has closed still routes flat (and flat replay still fails loud
  on the hierarchical lines, as before). The shared predicate keeps the
  authorization gate and the store routing identical (#10305), so
  `LoadMutationLines` now renders such bodies hierarchically and every
  leaf, including the event-options leaf, is adjudicated.
- **File(s)**: `pkg/config/authz_config_load_9892.go`,
  `pkg/config/load_classify_hier_event_16698_test.go` (new),
  `pkg/configstore/load_hier_event_16698_test.go` (new),

- **Validation**: New tests are RED pre-fix and green post-fix:
  `TestClassifyHierEventCommandNotFlat16698`,
  `TestClassifyBraceDepthControls16698`,
  `TestLoadMutationLinesHierEvent16698` (pkg/config) and
  `TestShowLoadRoundTripEventCmd16698` (override byte-identical,
  merge carries the same leaves and its result reloads) plus the quoted
  control `TestShowLoadRoundTripEventCmdQuoted16698` (pkg/configstore).
  Pre-fix the unquoted case classified flat and both store paths failed
  at line 1. Classifier/gate regressions green: `go test ./pkg/config/
  -run '16698|10734|10305|9892|14145|14572|15718|14981'` and the
  targeted store load suites (`TestLoadOverride*|TestLoadMerge*|
  TestLoadSet*|TestShowLoad*|...`) pass; `go vet` clean on both
  packages. Two `CheckText` cells (#9524, #16244) and one WireGuard
  tunnel cell fail identically with the fix stashed — base-attributed
  at 5e0e91811b, unrelated to this change.
- **Residual**: A flat script whose quoted value spans multiple lines
  and contains a lone `"` can desynchronise the depth scan's quote bit
  from the real lexer in the same way the pre-existing comment scanner
  already could; the store's hierarchical parser then rejects the body
  loudly, so the failure stays fail-closed. `Format` quoting of
  flat-verb values (the issue's alternative fix direction) is
  deliberately not changed.
