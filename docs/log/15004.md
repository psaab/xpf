# Issue #15004 — config: fix — Zone names containing -> alias two zone pairs onto one stable rule id; a strict-clean commit is refused whole by the helper (A07-01)

- **Issue:** `StablePolicyRuleID` is unescaped concatenation
  `fmt.Sprintf("%s->%s/%s", from, to, name)`
  (`pkg/dataplane/userspace/policies_ids.go:108-110`, mirrored by Rust
  `stable_policy_rule_id`), keyed on by `validateDuplicatePolicyNamesStrict`
  consumers and the helper. Zones `a->b`→`c` and `a`→`b->c` (policy `p`) both
  mint `a->b->c/p`; policy names containing `->`/`/` shift a separator
  boundary the same way. The Rust `PolicyCounterStore` shares one counter per
  rule_id and the integrity preflight refuses the WHOLE snapshot on
  `DuplicateRuleId`, so a strict-clean commit applied no new snapshot
  (default-deny after fresh boot) with a misleading diagnosis. The only
  prior zone-name charset gate banned `/` (#3061/#4340).
- **Fix:** `validateStablePolicyRuleIdentityStrict`
  (`pkg/config/compiler_validate_strict_policy.go`) rejects at strict commit
  any security-zone name containing `->` and any zone-pair/global
  security-policy name containing `->` or `/`, making the
  `(from,to,name) → id` map injective without changing the wire format any
  consumer parses. Wired in `runUniformGatesPolicy` after the #3473
  duplicate-name gate. New `lenientStablePolicyRuleIdentity` opt downgrades
  to a `cfg.Warnings` entry on tolerant load/peer-sync (#1960 no-brick);
  the helper still refuses such a leniently-loaded snapshot closed.
  Single `-` names (`allow-web`, `dmz-1`) stay legal.
- **Regression (`pkg/config/compiler_policy_rule_id_alias_15004_test.go`):**
  - `TestPolicyRuleIDArrowZonePairCollisionRejected15004`: the exact
    colliding pair `(a->b,c,p)` vs `(a,b->c,p)` → strict reject naming #15004.
  - `TestPolicyNameArrowAndSlashRejected15004`: policy names `p->q`, `p/q`.
  - `TestGlobalPolicyNameSeparatorRejected15004`: global policy `g->x`.
  - `TestPolicyRuleIDNormalNamesCompileClean15004`: control — ordinary
    hyphenated names and name reuse across pairs/global compile clean.
  - `TestPolicyRuleIDAliasLenientDowngrades15004`: tolerant load warns, boots.
