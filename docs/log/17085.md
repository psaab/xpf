    image seal set, and closed the one real divergence it exposed. `bake.py`
    declares `SYSPREP_ENABLE_OPS` / `SYSPREP_PURGE_PATHS` the SINGLE SOURCE
    for the seal (bake.py:604-619); the new `wipeSealMapping` table in
    `pkg/factoryreset/wipe_seal_10769.go` binds every member of both tuples
