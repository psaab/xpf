# #17977 — Refuse community bracket classes that render a literal pipe-space

- **Timestamp**: 2026-10-27
  - **Action**: `scanCommunityBracket`
    (`pkg/config/community_translate.go`) now refuses a bracket
    expression whose verbatim text spells `"| "` (e.g. `[^| ]`), with
    a remediation hint (`[^ ]` — a community token never contains
    `|`). Previously the class was returned verbatim after passing the
    space analysis, so `bgp community-list expanded X permit
    65000:[^| ]` rendered carrying a literal `"| "`; FRR's vty pipe
    hook (`handle_pipe_action`, raw `strstr`) refuses that line with
    `% Unknown action` while frr-reload.py exits 0 — the list silently
    never installed and a referencing reject term never matched, while
    `communityListMissingAtRender` reported the definition present.
    The #16788 pipe check only inspected `|` outside brackets, so the
    negated class bypassed it. Every consumer funnels through the
    translator, so one refusal closes the strict commit gate
    (`ValidCommunityMember` / `ValidCommunityMemberPipe16776`), the
    tolerant-load warning, and the render belt (whole-definition
    omission + reject-term fail-closed lowering, #10822 posture) at
    once. Classes that render no `"| "` (`[^ ]`, `[|]`, `[^ |]`,
    `[a|b]`, bare `a|b`) stay accepted.
  - **File(s)**: `pkg/config/community_translate.go`,
    `pkg/config/community_bracket_pipe_17977_test.go`,
    `pkg/frr/community_bracket_pipe_17977_test.go`,
    `pkg/frr/community_pipe_16776_test.go`,
    `pkg/frr/pipe_belt_17799_test.go`, `pkg/frr/README.md`,
    `docs/log/17977.md`.
  - **Validation**: STEP-0 on master (61aa231da6): the five
    `[^| ]`-family members returned nil from
    `ValidCommunityMember`/`ValidCommunityMemberPipe16776`/strict
    `CompileConfig`, and the render emitted
    `bgp community-list expanded NEG permit 65000:[^| ]` with the
    reject term left on `match community NEG` (fail-open). New cells
    `TestCommunityBracketPipeSpace17977`,
    `TestCommunityBracketPipeStrictLenient17977` (pkg/config) and
    `TestCommunityBracketPipeRender17977` (pkg/frr) were RED pre-fix
    and PASS post-fix; `go test ./pkg/config/ ./pkg/frr/ -count=1`
    green.
  - **Risk**: Members spelling `"| "` inside a bracket class now
    refuse at commit, warn on tolerant load, and omit at render
    (referencing reject terms lower to deny-all) — fail-closed, no
    widening of any rendered output. Bracket classes without the
    literal `"| "` are unaffected, including `[|]` and `[^ |]` pinned
    as controls.
