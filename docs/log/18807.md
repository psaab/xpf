- **Timestamp**: 2026-11-05
- **Action**: Re-pinned the three stale test guards against the intended
  product changes in #16217 (`a936a6f802`). No product code changed.
- **Root cause**:
  - `tx_inbox.rs` retained the pre-#16242/#18566/#18656/#18560
    `BindingLiveState` layout. The issue's `3072` size was stale: the first
    failing run under rustc 1.98.1 reported size **3136**. After correcting

    `a936a6f802`). The completeness ratchet correctly reported this field as
    unbound. Added it in struct order and removed the stale numeric count from
    the macro documentation.

    did_work`, but rustfmt wraps the intended seed across lines. The product
    expression also includes `pending_timer_fired` as work. The test now joins
    through the statement's semicolon, normalizes whitespace, and pins the full
    expression while retaining the exactly-one-seed assertion.
