# 10017 — SNMP GET absence renders the correct exception class

- **Timestamp**: 2026-09-17
- **Branch**: `fix/10017-snmp-oid`
- **Issue**: `snmp: GET of unknown-class OID returns noSuchInstance instead of noSuchObject`
- **File(s)**: `pkg/snmp/agent.go`, `pkg/snmp/v3.go`, `pkg/snmp/absence_10017_test.go`, `pkg/snmp/README.md`

## Decision

The shared `getOIDValueSnap` lookup now returns a typed absence tag. It classifies
unknown objects as `noSuchObject` and missing/malformed instances of known
scalars/table columns as `noSuchInstance`. The v2c and v3 Get renderers pass
that tag through instead of collapsing every nil value to `noSuchInstance`.
The v3 non-default-context Get path uses the same OID classification, while
GetNext/GetBulk retain `endOfMibView` for an empty context view.

## RED / GREEN proof

`TestV2cAbsenceTags_10017` and
`TestV3AbsenceTags_DefaultContext_10017` each cover these eight cells:

- unknown enterprise OID → `noSuchObject`
- unknown system-group field → `noSuchObject`
- scalar wrong instance → `noSuchInstance`
- scalar bare base → `noSuchInstance`
- ifTable known column with unknown index → `noSuchInstance`
- ifTable unknown column → `noSuchObject`
- ifXTable known column with unknown index → `noSuchInstance`
- ifXTable unknown column → `noSuchObject`

The pre-fix targeted run failed the eight unknown-object cells (four v2c and
four v3); each was encoded as `noSuchInstance (0x81)` instead of the required
`noSuchObject (0x80)`. The eight unknown-instance cells passed before the fix,
which is the preservation control that rejects a blind global tag swap.
`TestV3NonDefaultContextUnknownObject_10017` also failed pre-fix because the
unknown OID was rendered as `noSuchInstance`.

To prove the instance-preservation cells are fail-on-revert tests, the two
known-object `noSuchInstance` returns in `oidAbsenceTag` were temporarily
mutated to `noSuchObject`. The focused mutation run failed all eight
unknown-instance subtests (four v2c and four v3), then the production returns
were restored and the complete targeted command above passed all 20 events.

Mutation command:

```text
go test -json ./pkg/snmp -run 'Test(V2cAbsenceTags_10017|V3AbsenceTags_DefaultContext_10017)/(sysDescr_wrong_instance|sysDescr_bare_base|ifTable_known_col_unknown_idx|ifXTable_known_col_unknown_idx)$' -count=1 | jq -r 'select(.Action=="fail" and .Test != null) | .Test + " FAIL"'
```

Mutation result: the eight instance subtests failed with the swapped
`noSuchObject (0x80)` tag, demonstrating that a blind tag swap is rejected.

Pre-fix command:

```text
go test ./pkg/snmp -run 'Test(V2cAbsenceTags|V3AbsenceTags|V3NonDefaultContextUnknownObject)' -count=1
```

Post-fix command:

```text
go test -json ./pkg/snmp -run 'Test(V2cAbsenceTags|V3AbsenceTags|V3NonDefaultContextUnknownObject|V3NonDefaultContextEmptyView)' -count=1 | jq -r 'select(.Action=="pass" and .Test != null) | .Test'
```

Result: all 16 v2c/v3 matrix subtests passed, along with the two matrix
parent tests and the two v3 context tests (20 passing test events).
