# #17087 — single-source the helper-state sweep in pkg/factoryreset (R4-Q46-02)

- **Timestamp**: 2026-10-27
- **Issue**: #17087 (R4-Q46-02)
- **Base**: `origin/master 33679c37c5`

## Defect (STEP-0, verified at base)

The helper-state erase-and-verify primitive existed twice with identical
executable logic: `sweepHelperStateVerified`/`verifyHelperStateErased` in
`pkg/daemon/reset_handoff_10769.go` and `wipeEraseHelperState` plus the
helper block of `wipeFinalEraseVerification` in
`pkg/factoryreset/wipe_seal_10769.go`, justified by the comment "mirrors
daemon sweepHelperStateVerified, which cannot be shared: daemon imports
grpcapi". That rationale rules out only factoryreset→daemon:
`go list -deps ./pkg/daemon` already contains `pkg/factoryreset` (and
`pkg/daemon` tests already import it), while factoryreset has no edge
back to daemon. A generation-path wrapper was likewise duplicated
(`resetPersistentNatGenerationStatePath`/`sweepResetHelperStateVerified`
vs `wipePersistentNatGenerationStatePath`/`wipeEraseResetState`), with a
small drift: factoryreset errors on an empty generation path in its
final-verify leg, the daemon skips it (unobservable in production, where
the path is the constant
`/var/lib/xpf/persistent-nat-lease-generation.json`).

Differences beyond duplication were exactly: the `zeroize: ` error prefix
(daemon messages are unprefixed), one reserved-alias recovery sentence
per caller, the `wipeSyncDir` test seam vs `fsatomic.SyncDir`, the
final-verification "present at final verification" wording, and the
slog prefix. Baseline named cells passed at base (factoryreset leg of
the STEP-0 run; the daemon leg was interrupted by the harness timeout
after the factory leg printed `ok`, and the same daemon cells pass on
the fixed tree).

## Fix

- New `pkg/factoryreset/helper_state_17087.go` is the single body:
  `SweepHelperState(path, SweepOpts)` and
  `VerifyHelperStateErased(path, SweepOpts)` with
  `SweepOpts{ErrPrefix, ReservedRecovery string; SyncDir func(string) error}`
  (nil `SyncDir` = `fsatomic.SyncDir`), plus
  `ResetStatePaths(helperPath) []string` (helper plus the
  seamed persistent-NAT generation path, deduplicated).
- `pkg/daemon/reset_handoff_10769.go`: the daemon's three functions are
  now one-line delegations. `sweepHelperStateVerified` passes
  `ErrPrefix: "reset handoff: "` and the extracted
  `daemonReservedRecovery` const; `verifyHelperStateErased` passes the
  same recovery with no prefix. ACCEPTANCE grep:
  `grep -c HelperStatePathTouchesReserved pkg/daemon/reset_handoff_10769.go` == 0.
- Generation wrapper: `wipeEraseResetState` loops `ResetStatePaths`;
  the daemon's `verifyResetHelperStateErased`/`sweepResetHelperStateVerified`
  loop `resetStatePathsFor`, which is `ResetStatePaths` with the daemon's
  `resetPersistentNatGenerationStatePath` seam substituted (TestMain and
  the generation test redirect that seam; the shared helper reads the
  factoryreset seam). The daemon seam itself now defaults to the first
  entry of `factoryreset.ResetStatePaths("")`, so both packages resolve
  the same production generation path from one definition. The
  empty-generation-path drift is resolved in favour of skip (the daemon
  behaviour): production never resolves empty.
- `wipeFinalEraseVerification`'s helper block delegates to
  `verifyHelperStateAtFinalVerification`, which keeps the exact
  final-verification wording ("present at final verification", shared
  "cannot be verified" reserved sentence) over the same
  canonical-plus-temps census — that wording is a distinct operator
  surface pinned by tests, not a second sweep body.
- Deleted the misleading "cannot be shared" comment. No shim of the old
  bodies remains: the only surviving per-package names are the one-line
  delegations and the final-verification wording adapter.

Error-wording note: daemon sweep errors now uniformly carry the
"reset handoff: " prefix from `SweepOpts.ErrPrefix` (previously only
the reserved-alias and slog lines did). All test-pinned substrings
("aliases reserved", "cannot be verified", "delete /etc/xpf/.reset-handoff",
"restart xpfd", "commit-confirmed") are preserved verbatim; the reserved
recovery sentences are byte-identical to the previous per-caller text.
