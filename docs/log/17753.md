# #17753: make metric label sanitization injective

- **Timestamp**: 2026-10-28
- **Issue**: `sanitizeMetricLabelValue` escaped invalid bytes as `\xNN` but left valid UTF-8 untouched. A raw `0xff` byte and a valid literal `\xff` string therefore produced the same sanitized label, so same-scope policy series collided and one policy's counters were dropped by the scrape's `ContinueOnError` handling.
- **Fix**:
  - `pkg/api/metrics_emit_15086.go`: encode every raw backslash as `\x5c`, reserving the backslash introducer, while continuing to encode invalid bytes as lowercase `\xNN`. The resulting spelling is unambiguous and byte-for-byte reversible. Valid values without backslashes retain the allocation-free identity fast path.
  - Store rewritten values in both collector and nil-collector paths. Keep `ok` as the UTF-8-validity result and count only invalid-UTF-8 values in `xpf_metrics_invalid_label_values_total`.
  - Use copy-on-write for label slices: clone only at the first rewrite and never mutate caller-owned backing arrays, preserving stable output across repeated emits.
  - Update API sanitizer documentation and descriptor help to describe the reserved escape form and counter semantics.
- **Tests** (`pkg/api/metrics_sanitize_escape_injective_17753_test.go`):
  - `TestSanitizeMetricLabelValueInjective17753` compares invalid bytes and their valid literal `\xNN` lookalikes in one output-uniqueness set, checks byte-for-byte decoding, covers lone/trailing/non-escape backslashes and mixed inputs, and tests all 256 byte values against their literal escape spellings.
  - `TestMetricsScrapeSanitizeLiteralEscapeCollision17753` emits a raw-`0xff` policy and its literal-`\xff` lookalike together; both series must be present, with no gather error.
  - `TestSanitizeLabelValuesRepeatedEmit17753` emits one label slice repeatedly through collector and nil-collector paths; all outputs must match and the caller slice must remain unchanged.
  - **FAIL-ON-REVERT**: removing backslash escaping makes invalid-byte and literal-string spellings collide; mutating instead of cloning makes repeated emits grow an additional `\x5c` per pass.
