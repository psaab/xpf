# docs/log/12156.md — #12156 (preserve MAC-form links when the original name is unknown)

- **Timestamp**: 2026-10-07
- **Action**: Prevent positional naming and bootstrap lifeline setup from persisting a logical name as `OriginalName=` when no kernel original can be established.
- **Base**: `origin/master` `1c384b9a47ff7d6e567fa50632faa75c3995ae87`
- **Files**: `pkg/daemon/linksetup.go`, `pkg/daemon/bootstrap.go`, `pkg/daemon/device_map.go`, `pkg/daemon/device_map_original_name_6678_test.go`, `pkg/daemon/linksetup_originalname_12156_test.go`

## Why

When a `.link` contains `Name=fxp0` and a MAC match but no `OriginalName=`, `recoverOriginalName("fxp0")` returns `fxp0`. The positional and bootstrap paths then overwrote the usable MAC-form link with `OriginalName=fxp0` / `Name=fxp0`, which udev cannot match because it does not present the logical name as the kernel original. The device-map path already had an unknown-original guard (#6678); positional and bootstrap did not.

## What

- Added contextual positional name recovery: a recorded `.link` original remains usable; an interface whose current name differs from its target can use its live kernel name; when current already equals target and no original is recorded, the name is unknown.
- Carried unknown originals through the collision-break map with the existing NUL sentinel, now named `originalNameUnknown` for its shared positional/device-map use.
- Positional naming now skips an unsafe `.link` write with a warning and does not refuse the naming pass; any existing MAC-form `.link` remains unchanged.
- Bootstrap lifeline setup skips the unsafe write and logs the unestablished original. The same guard covers both default-route and appliance-factory first-NIC selection.
- Added positional, default-route bootstrap, appliance-factory bootstrap, genuine pre-rename-name, and recorded-original regression/control cases.

## Risk

If an interface already wears its target name and neither an existing original nor a MAC-form `.link` is available, the code intentionally leaves `.link` persistence unestablished rather than writing an unmatchable file. Verification used isolated Go fixtures; no real udev boot or live-cluster mutation was performed.
