# Issue #16045 — nat/fabric: pre-routing NAT judged under fabric zone vs policy under promoted claimed zone (RN-01)

- **Issue:** For an ambiguous fabric arrival (#15916: claimed zone
  withheld pending the owner-RG gate), pre-routing NAT resolved its
  scope from the LOCAL fabric/logical identity (fabric interface zone /
  config name / routing-instance) and could select a translation under
  that identity. The session-miss policy later promoted the claimed
  zone, so the translated action was keyed to a zone the policy never
  adjudicated — a NAT scope-escape across the promotion boundary.
  Impact claims beyond that were mostly by-design or fail-closed
  (Low, unanimous MATERIAL per the parent research cohort #15985).
- **Fix direction (per the validated refutation):** suppress the
  fabric fallback identity only; do NOT require claimed-zone DNAT to
  fire (that would grant the claimed zone before owner proof and
  violate the #15916 withholding contract).
- **What shipped:**
  - `PreroutingIngressScope` gains `ambiguous_provenance`;
    `prerouting_ingress_scope_ambiguous` resolves the same local
    fabric/logical identity with the flag set (claimed zone and V2
    peer scope ifindex never substituted). The flow-backed miss path
    and the flowless pre-routing path stamp it for ambiguous arrivals.
  - NAT-layer ambiguous-provenance siblings (ordinary matchers
    untouched): pool DNAT `lookup_result_ambiguous_provenance_scoped`
    (scope-constrained translate/poison -> Poisoned fail-closed;
    needs the winner's scope tier, so `DnatOutcome::Translate` now
    carries it), static `match_dnat_ambiguous_provenance_scoped`
    (any eligible constrained entry/block withholds), NPTv6
    `translate_inbound_ambiguous_provenance_result` (constrained ->
    Untranslatable), NAT64
    `classify_ipv6_packet_ambiguous_provenance_scoped` (constrained
    -> MatchUnavailable). The persistent-NAT reader is skipped under
    ambiguous provenance (its lease scope is ingress-keyed).
  - UNSCOPED rules still fire (identity-independent), native
    owner-scope ingress is unchanged, and session-hit revalidation is
    untouched (it re-derives from the recorded admitting provenance).
- **Decisive regression (co-moved owner fixture):**
  `*_16045` in `poll_descriptor/prerouting_scope_tests.rs` —
  fabric-scoped DNAT cannot fire prematurely (RED pre-fix: session +
  forward; GREEN post-fix: poison-drop), native `fabric`-zone ingress
  still translates, claimed-zone DNAT stays withheld, unscoped DNAT
  still translates, plus interface-scoped static, NAT64 and NPTv6
  legs.
- **Validation:** `cargo test --bin xpf-userspace-dp 16045` plus the
  NAT / prerouting / fabric-stamp suites (see PR).
