# Issue #13960 — reject unspecified and this-network transit destinations

## Why

The shared transit destination gate omitted IPv4 `0.0.0.0/8`, IPv6
unspecified `::`, and IPv6 loopback `::1`. With a default route and an
application-any permit, those addresses could pass the post-FIB transit
classification and reach TX. The same predicate also protects final TX
dispatch, so the omission affected both the poll path and its final-TX
backstop.

## What

`transit_dst_is_martian` now rejects all of `0.0.0.0/8`, plus IPv6
unspecified and loopback, while keeping its existing multicast, broadcast,
loopback, and reserved-range behavior. LocalDelivery remains outside the
transit-only check. Regression cells exercise 0.0.0.0, interior and last
addresses of 0/8, `::`, and `::1` through the real routed poll path; the
existing IPv4/IPv6 ordinary-unicast controls remain. The final-TX backstop
has a dedicated 0/8 regression while retaining its existing multicast case.

## Validation

- RED on pristine `origin/master` (`8b4d69350f1ad20cae011eb4f9068b7508bda899`):
  the full destination test module ran 13 tests; 5 new cases failed at the
  expected `debug.tx == 0` assertion (0.0.0.0, 0.1.2.3, 0.255.255.255,
  `::`, and `::1`), while the 8 existing cases passed. The final-TX twin also
  failed independently at its expected "must not reach TX" assertion for
  0.1.2.3. The base test target has an unrelated compile error at
  `coordinator/tests.rs:11773` (`HashSet` now expects `(u32, IpAddr)`); the
  isolated RED worktree used a temporary, uncommitted test-fixture type
  correction to permit the destination tests to execute. That correction is
  not part of this change.
- GREEN after rebasing onto current `origin/master`: `cargo test --manifest-path
  userspace-dp/Cargo.toml --bin xpf-userspace-dp martian_destination_11413
  -- --nocapture` passed 20 tests, including the full #13960 poll-path
  module, its final-TX backstop, and current-master link-local sibling cases.
  The temporary fixture correction was reverted before final commit.
- `cargo build --manifest-path userspace-dp/Cargo.toml --bin
  xpf-userspace-dp` passed with the repository's existing warnings (including
  the libbpf 1.7.0 versus vendored 1.6.3 warning).

## Risk

No live-cluster smoke was run. This intentionally changes only transit
handling; local delivery of DHCP/NDP and other firewall-local traffic is
unchanged.
