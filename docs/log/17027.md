# #17027 — R4-Q02-01: single-source the established-hit zone-policy query

- **Issue:** The established-hit zone-policy query (from-zone, to-zone,
  judged source, post-DNAT destination, ICMP selector, permit predicate)
  was hand-assembled at 4 sites in 2 files
  (`policy_revalidation.rs` `zone_policy_deny_on_session_hit` and
  `session_hit_authority.rs` reverse-owner / forward-owner / foreign).
  The packet-clock (#11285→#12868), live-to-zone (#9384→#13924) and
  pre-SNAT-source (#12867) rules each landed on one file only; #12867
  never reached the authority verdicts, the deny-event emitters kept
  naming the recorded egress zone after #13924, and the
  `session_hit_authority.rs` module doc still described the recorded
  to-zone.

## STEP-0 (verified on origin/master `a60e77bda3`)

All four `evaluate_policy_result_without_counting_at(` sites live in
`policy_revalidation.rs` + `session_hit_authority.rs`; no
`hit_policy.rs`, no production `PolicyQuery` constructor for the hit
path, `resolved.source_nat_validation_key` threaded only into
`revalidate_zone_policy_on_session_hit` (not the two authority
verdicts), and the three `emit_session_hit_policy_deny_event` sites
passing `metadata.egress_zone`. Not fixed / not duplicate.

## What

1. **New `poll_descriptor/hit_policy.rs`** — the single builder
   `hit_policy_query(forwarding, &metadata, decision, from:
   FromZoneSource, source: JudgedSource, wire_dst, wire_dst_port,
   protocol, direction: QueryDirection{ForwardPostDnat|ReverseWire},
   icmp, now_ns) -> PolicyQuery` (via
   `PolicyQuery::without_counting_at`, `PolicyHitCount::Never`) and
   `permits(&PolicyQuery, &PolicyState) -> Result<(),
   PolicyEvaluationResult>` (positive `Permit` spelling, #9381).
   `hit_egress_zone`/`hit_egress_zone_for` moved here as the sole
   to-zone rule (`FabricRedirect` → recorded, else live
   `egress_zone_id`, #7770/#9384). `FromZoneSource` gained a
   `Resolved(u32)` variant (foreign arrival) and is now `pub(super)`.
2. **`policy_revalidation.rs`** — `zone_policy_deny_on_session_hit`
   builds its query through the builder (frame-independent `icmp:
   None` preserved) and its to-zone through `hit_egress_zone_for`;
   its Decline arms (no egress ifindex, `RecordedZone(0)`,
   unresolvable live ifindex) stay local, with a `debug_assert` that
   the builder and ledger walk agree on the to-zone. The three
   #14318 egress-zone rebind blocks also read the judged zone through
   `hit_egress_zone_for`. The now-unused
   `evaluate_policy_result_without_counting_at` import was removed.
3. **`session_hit_authority.rs`** — both `owner_hit_icmp_verdict`
   arms (reverse = explicit `ReverseWire` on wire tuples, #10637;
   forward = `ForwardPostDnat`) and `foreign_hit_verdict` (reverse →
   `ReverseWire`, forward → `ForwardPostDnat`) build through the
   builder and judge through `permits`. The private `hit_egress_zone`
   copy is deleted. Both verdicts take a new trailing
   `judged_source: Option<&SessionKey>`; reverse hits always judge
   the wire source (a reply's source is the responder).
   `HitPolicyDeny` now carries `judged_from_zone`/`judged_to_zone`
   from the query. The stale module doc now describes the live
   to-zone rule with the `FabricRedirect` exception.
4. **`poll_descriptor/mod.rs`** — registers `mod hit_policy`;
   threads `resolved.source_nat_validation_key.as_ref()` into both
   authority verdicts (#17027/#12867 threading); all three
   `emit_session_hit_policy_deny_event` sites pass
   `deny.judged_from_zone`/`deny.judged_to_zone` instead of
   `arrival_zone`/`metadata.egress_zone`/`metadata.ingress_zone`.
   Existing test callers in `session_hit_authority_tests.rs` pass
   `None` for the new parameter (wire source = pre-change behaviour
   for those fixtures).

Per-site behaviour preserved: revalidation `icmp: None` + canonical
source, owner/foreign packet ICMP selector, reverse wire destination,
foreign arrival from-zone, `#16044` knob diversion after evaluation,
and the #9384 revoke gate are all unchanged in shape — only the
query construction (and, for the authority arms, the judged source
when the resolver supplies an authenticated original) is shared.

## Risk

Behaviour-preserving except the intended #12867 completion: owner /
foreign forward verdicts on a resolver-authenticated translated alias
now judge the pre-SNAT original instead of the wire tuple (the
revalidation arms already did), and deny events now name the judged
zones. Reverse authority hits are unchanged (wire source forced).
No hot-path cost: all four sites are `#[cold]` / once-per-generation,
and the builder is a `Copy` `PolicyQuery` construction.
