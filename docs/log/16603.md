# #16603: Prebuilt transit mirror cloned the translated egress frame

- **Timestamp**: 2026-10-25
  - **Action**: The #15251 mirror arm in `enqueue_pending_forwards`
    staged its clone from `PendingForwardFrame::Prebuilt` — the
    already-rewritten egress frame (post-reversal addresses, egress
    MACs/VLAN, decremented TTL, and for NAT64 the other IP family) —
    while every Live/Owned arm mirrors the received bytes, per the
    plan-1376 contract ("full original Ethernet frame"). Added
    `PendingForwardFrame::PrebuiltTransit { frame, ingress_frame,
    ingress_meta }`: embedded-ICMP same-family reversal
    (`try_reverse_embedded_icmp_error`) and both NAT64 arms
    (v4→v6 and v6→v4) now queue the translated wire frame together
    with the received bytes (`packet_frame`, trimmed to the ingress
    descriptor length; GRE-decapped callers pass the inner frame,
    matching `meta`) and the ingress meta derived from it. Dispatch
    normalizes both prebuilt variants into (wire, mirror) parts: the
    wire frame forwards exactly as before (request `meta` still
    describes the wire frame for TX/`expected_*`/CoS), while the
    mirror is staged from the ingress bytes + ingress meta and moved
    (never cloned) into the staged snapshot only when a mirror row
    matches and the sample selects — no-mirror and sampled-out
    dispatches perform no ingress clone. Device-generated
    Time-Exceeded replies stay plain `Prebuilt` and mirror their
    generated wire bytes, the deliberate #15947 choice. The two
    flowless policy sites and the martian backstops handle the new
    variant identically to `Prebuilt` (policy still judges the wire
    frame). Existing `tests_embedded_poll_filter.rs` extractions were
    updated to read the wire frame out of `PrebuiltTransit`.
  - **File(s)**: `userspace-dp/src/afxdp/types/tx.rs`,
    `userspace-dp/src/afxdp/poll_descriptor/embedded_icmp.rs`,
    `userspace-dp/src/afxdp/poll_descriptor/nat64_icmp_error.rs`,
    `userspace-dp/src/afxdp/poll_descriptor/mod.rs`,
    `userspace-dp/src/afxdp/tx/dispatch/mod.rs`,
    `userspace-dp/src/afxdp/tx/dispatch/tests/prebuilt_mirror_15251.rs`,
    `userspace-dp/src/afxdp/tests_embedded_poll_filter.rs`,
    `docs/log/16603.md`.
  - **Validation**: Rewritten 15251 cells assert clone bytes == ingress
    UMEM bytes for IPv4 NAT reversal and NAT64 (v4-ingress and
    v6-ingress), with ingress/wire frames deliberately differing in L2,
    addresses and TTL so mirroring the wrong frame cannot pass;
    `mirrored_bytes` now counts the ingress length. New
    `prebuilt_transit_no_mirror_no_extra_alloc_16603` compares
    `test_alloc::CountingAlloc` counts for a no-mirror dispatch versus
    a sampled-out mirror dispatch and requires equality. The 15947
    sampled-out cell now drives `PrebuiltTransit`.
    `retry_pending_neighbor_mirrors_original_frame_before_rewrite` and
    the 15251 forwarding assertions stay green (see PR for counts).
  - **Residual**: The ingress copy is made once at queue time in the
    poll path (one `Vec` per queued reversal); dispatch itself never
    clones it. Analyzer output-VLAN rewriting (#15114) still applies
    to the clone at enqueue, as for Live arms.
