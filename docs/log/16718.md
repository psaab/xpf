# Issue #16718: CommitDiffSummary allocates a full (n+1)x(m+1) LCS table before every CLI/gRPC commit

- **Timestamp**: 2026-10-25
  - **Action**: `sequenceLineDiffCounts` in `pkg/configstore/store_commit.go` allocated a full `(lo+1)x(ln+1)` `[][]int` LCS table on every `CommitDiffSummary()` — called on every console/gRPC commit in xpfd. At 12k set lines that is ~1.1 GiB and ~2.7s; at 16k ~2 GiB, an OOM risk on the documented 4 GiB appliance, for configs that pass every size gate. Replaced it with: (1) trim the common prefix and suffix (a one-line edit to a large config then has an empty or tiny middle), (2) an exact two-row (linear-memory) LCS length over the remaining middle, using the shorter side as the row axis, and (3) a multiset (multiplicity) fallback via `multisetLineDiffCounts` only when the middle's cell count exceeds `maxExactLCSCells` (1<<22 = 4,194,304), so a pathological full rewrite/reorder of a very large config cannot stall the commit for seconds. The fallback preserves added/removed multiplicities but not order sensitivity for that oversized middle only. Order-aware and duplicate-positional semantics (#15168, #13231) are preserved exactly for all ordinary inputs. NOT changed: `CommitDiffSummary` callers (CLI, gRPC), the summary format string, REST (which never called it), or any commit behaviour.
  - **File(s)**: `pkg/configstore/store_commit.go`, `pkg/configstore/commit_diff_summary_lcs_16718_test.go` (new), `debian/changelog`, `docs/log/16718.md`
  - **Validation**: New tests: exact match against a full-table oracle on 12 hand cases + 200 deterministic random small cases over a 4-symbol alphabet; 50k-line one-line edit allocates 0 bytes in the diff itself (acceptance: <10 MiB) and returns (1,1); identical 50k is free; oversized fallback (3000x3000 middle) gives multiset counts; end-to-end `CommitDiffSummary` at 12k lines allocates 18,405,104 bytes total (clone+FormatSet+diff) vs ~1.1 GiB before. RED evidence: a temporary allocation test against the original implementation measured 1,180,047,352 bytes at 12k lines and failed the 10 MiB bound (removed after verification). `TestCommitDiffSummaryReorder15168`, `TestCommitDiffSummaryDuplicateLines_13231` and `TestCommitDiffSummary` stay green. Commit-focused suite `go test ./pkg/configstore/ -run 'TestCommit|TestSequence|TestStoreCommit|Diff' -count=1` = 92 PASS, 0 FAIL (host load ~90 from sibling lanes; the full package suite exceeded the environment timeout twice under that load and is left to CI).
