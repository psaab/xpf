# Issue #13142 — exempt lifelines and resolve managed routing interface refs (D2-11)

- **Issue:** `validateHostInboundManagedRoutingMismatch` incorrectly rejected
  OSPF/OSPFv3/RIP on host-inbound lifelines, missed bare protocol-interface
  references when zone membership was unit-qualified, and did not resolve
  `interface all` against the zones whose effective host-inbound policy it
  checks.
- **Source:** Deep-review D2-11, Medium severity, EXECUTED/MATERIAL; validated
  by three-way adversarial research. Source report:
  `/var/tmp/deep-review-reports/gemini-4-argon-high-review-zone-enforcement-001.md`
  §93. Probe evidence reproduced false strict rejection on `fxp0.0` and a missed
  gate for OSPF `interface ge-0/0/1` with zone member `ge-0/0/1.0`.
- **What:** The validator now skips interfaces recognized by
  `HostInboundLifelineInterface`, checks `interface all` against sorted resolved
  zone-interface keys, and resolves bare protocol refs to unit zero when the
  zone map contains that unit. Existing effective host-inbound admission,
  quarantine and multi-zone conflict behavior is retained. Added helper and
  end-to-end strict-compile regressions for lifelines and bare references,
  plus coverage for wildcard, admitted, out-of-zone and quarantined cases.
