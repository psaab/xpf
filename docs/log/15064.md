# #15064 — packed CoS instance lines inside braced containers compile to nothing (A01-03)

- **Timestamp**: 2026-10-19
- **Action**: Expand the packed tail of every `class-of-service` named
  instance before its compiler loop reads it, and pair the compiler read
  with `packedTail: true` schema validation. Previously
  `schedulers { be priority high; }`, `traffic-control-profiles { TCP
  shaping-rate 10m; }`, scheduler-map, classifier, rewrite-rule, and
  interface instance lines packed onto the instance's own Keys compiled
  to an instance with an empty body on a clean commit — scheduler
  priority/transmit-rate, TCP shaping-rate, and bindings silently
  dropped while `show configuration` displayed the line.
- **Base**: `origin/master` `162fc049e2`.
- **Files**: `pkg/config/compiler_class_of_service.go`,
  `pkg/config/schema_cos.go`, `pkg/config/schema_walk.go`,
  `pkg/config/compact_block_equivalence_2419_test.go`,
  `pkg/config/cos_packed_instance_15064_test.go`,
  `pkg/config/testdata/compact_block_divergences_2419.txt`,
  `pkg/config/testdata/compact_block_permanent_exclusions_8690.txt`,
  `docs/log/15064.md`.

## Defect

`namedInstances` returns the instance sub-node with its tail still on
Keys (`[be priority high]`, no children), and every CoS loop in
`compileClassOfService` read only `inst.node.Children`. The braced twin
(`[be]` → `[priority high]`) compiled normally. The compact spelling
(`schedulers be priority high;`) was already covered by the #8662
normalizer; the braced-packed spelling (`schedulers { be priority
high; }`) was covered by nothing. The schema gate had the mirror hole:
`walkInstanceChildren` ignored leftover instance Keys, so a bogus packed
value committed unvalidated (#6821's bidirectional contract).

## Fix

- `cosPackedInstanceBody` / `cosPackedInstanceNode`
  (`compiler_class_of_service.go`): take the instance tail via
  `instanceValueTail` (anchors on the instance name, both AST shapes,
  #7568), re-anchor it behind the container keyword, and expand it with
  the schema-driven `packedBodyChildren` (#6683/#6821). Applied at every
  `namedInstances` CoS loop — classifiers (dscp / ieee-802.1 /
  inet-precedence), rewrite-rules (inet-precedence / exp / dscp /
  ieee-802.1), schedulers, traffic-control-profiles, scheduler-maps,
  interfaces — plus the two sub-instance depths the census arm exposed
  (`unit 0 …` / bare `0 …` under an interface, `forwarding-class …` /
  bare class under a scheduler-map). A tail outside the modelled grammar
  declines to the authored children; the authored node is never mutated.
- `packedTail: true` on the twelve CoS instance containers in
  `schema_cos.go`, and `walkInstanceChildren` (`schema_walk.go`) now
  validates the same expansion for a packedTail container's peeled
  instance node, so a bogus packed value rejects exactly as its braced
  twin does.
- NOT changed: `namedInstances` itself (shared by protocols, firewall,
  applications, and chassis, each with its own packed-tail readers), the
  #8662 normalizer scope, and the flat-set `#8939` TCP run (its expansion
  now composes after the packed expansion).

## Census extension (#2419)

`runCompactBlockCensus` gains the `keyword { name leaf value; }` arm the
issue prescribes: for every named-instance site it compiles the
braced-packed spelling (panic-safe; a panicking spelling reads as
unmeasured, never equivalent) and records divergence separately from the
original #2419 set, so the arm can only add signal. Measured at this
commit: 394 cells checked, 336 divergent outside this issue's scope
(other sections, their own mechanisms) — recorded in the report test
only. Inside scope the gate asserts zero CoS divergence. The fix also
closed `class-of-service schedulers xpfarg surplus-sharing`; its stale
inventory + `open` register lines were removed in both files and the site
moved to `filedFixed` so it stays checked in both directions.

## Risk

Strict commits that previously kept only the (empty) packed instance now
compile the union the operator wrote — the Junos semantics. A config
that relied on the drop changes meaning deliberately; that reliance was
the defect. No new rejection is introduced on the compiler path;
previously-unvalidated packed values now reject at the gate with the
same message as their braced twins, which is the #6821 pairing the
schema flag exists to declare.
