# Issue 10227

## Change

- Reserved `SESS_FLAG_CLUSTER_SYNCED` / `SessFlagClusterSynced` as the per-session peer-origin marker.
- Preserved helper `sync_import`, `shared_materialize`, and
  `worker_local_import` origins through both userspace delta converters;
  `worker_local_import` remains local-replica provenance and clears the marker.
- Added a trailing, length-gated high-flags byte to the V4 and V6 session HA payloads; old payloads decode with the high byte clear, and partial install-table tails cannot be read as origin bits.
- Stamped the marker in `PutClusterSyncedV4/V6`, retained it in the BPF mirror projection, and made unmapped-zone bulk reconcile delete only marked rows.
- Kept nil zone ownership unwired (skip reconcile), while an installed empty map is an active all-unmapped snapshot; nil/empty transitions advance the ownership generation.

## Follow-up: replica refresh race and provenance seam

- Added a distinct cluster-origin predicate: `WorkerLocalImport` is a local
  worker replica and clears bit 9, while `SyncImport` and
  `SharedMaterialize` retain the peer stamp.
- Refresh keeps every forward replica refreshable, including packet-receiving
  local replicas, and normalizes only bit 9 from live provenance before each
  V4/V6 full-value write. A sibling read cannot resurrect a cleared stamp.
- Centralized the bit-9 flag flip helper and covered both directions for both
  V4 and V6 values while preserving unrelated flags.
