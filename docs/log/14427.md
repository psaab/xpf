# 14427 — OSPF top level, `passive` first: `passive-interface default` dropped (DR16-H6)

- **Timestamp**: 2026-10-17
- **Action**: Unpacked `ospfNode` itself at the OSPF top loop in
  `compileProtocols` (`pkg/config/compiler_protocols.go`). The claim's
  literal nested spelling (`ospf { passive router-id 1.1.1.1; area ... }`)
  already compiled on current master — `expandFlatRun` splits that child
  node's Keys — so the decisive RED shape is the same packed tail on the
  `ospf` line itself: `ospf passive router-id 1.1.1.1 { area ... }` and
  `ospf passive;`. There the body rides on `ospfNode.Keys`, `Children`
  held only the braced area (or nothing), and the Children-only reader
  dropped `passive`/`router-id`: `PassiveDefault` stayed false while the
  area survived, so FRR omitted `passive-interface default` and ospfd
  formed adjacencies on interfaces the operator made passive. Fix:
  `packedBodyChildren(ospfNode, ospfSchema9408())` before `expandFlatRun`,
  with the IS-IS-interface tail-only fallback for a packed tail ending
  in a leaf beside a braced body (where `packedBodyChildren` declines
  and returns the braced children alone). The routing-instances mirror
  shares `compileProtocols` and is covered. Braced, flat-`set`, and
  inside-braced packed spellings are unchanged; an area-only packed
  line gains its area (identical to its braced twin) but never invents
  `PassiveDefault`/`RouterID`.
- **Regression**: `pkg/config/protocols_packed_top_dr16h6_test.go`
  (`TestOSPFPackedTopPassiveFirst14427`,
  `TestOSPFPackedTopAreaOnlyStaysFailClosed14427`,
  `TestOSPFPackedTopRoutingInstanceMirror14427`): passive-first packed
  tail on the ospf line with braced area, ospf-line-only, single
  `passive` census shape, inside-braced packed control, packed==braced
  deep equality, area-only no-invention control, and the
  routing-instance mirror. RED on `origin/master` (f10109aaf):
  passive-first, line-only, passive-only, and mirror cells failed with
  `PassiveDefault:false, RouterID:""` while the area survived; the
  inside-braced control passed, pinning the defect to the ospf node
  itself. GREEN after the fix; #9408 flat-chain/reference-bandwidth,
  `TestOSPFPassiveDefaultSetSyntax`, and the #2419 census inventory
  gate stay green.
