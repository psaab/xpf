# #17827 — Serialize VRRP preempt enqueue with state transition

- **Timestamp**: 2026-10-28
- **Action**: `triggerPreemptNow` now holds `vi.mu`'s write lock across
  the non-MASTER state check and non-blocking `preemptNowCh` enqueue.
  This linearizes the enqueue with `setState`: a BACKUP kick is either
  queued before a transition can drain it, or the poster observes MASTER
  and drops it. Previously the lock was released after sampling BACKUP
  but before enqueue, allowing a delayed kick to outlive both MASTER-entry
  and forced-resignation drains and trigger a spurious MASTER tenure at
  priority zero. Added a channel-barrier regression that pauses the real
  poster at that gap while `becomeMaster` and forced resignation run; it
  asserts the first post-resignation BACKUP iteration emits no extra
  priority-zero adverts or MASTER event. The existing BACKUP-kick control
  remains covered.
