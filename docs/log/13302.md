# Issue #13302: Export dataplane safety telemetry

- Why: The dataplane safety counters and state were not visible to Prometheus, hiding obsolete registry refusals, outstanding XDP detach debt, retained host divergence, and arm coverage.
- What: Added read-only snapshots for detach debt, host divergence, and a copied, atomic arm-proof report; exported six dataplane safety metric families through the collector. Arm gauges and `driver|generic|skipped` mode series come from the same completed proof snapshot, and unknown/unrun proof state remains absent. Metrics are emitted before the unloaded dataplane return when the published dataplane exposes the optional telemetry capability.
- Validation: The API regression was red on pristine `origin/master` (all six series absent) and is green after the change; manager snapshot tests and `go build ./...` passed. `go test ./pkg/dataplane/... -count=1` hit the existing `TestPartialRepublishRefusesQuarantineOnlySkew12247` fixture failure, reproduced by the same targeted test on pristine `origin/master`.
- Risk: Metrics use bounded labels (`mode` only). Missing or unknown proof state remains absent rather than being represented as a confident zero.
