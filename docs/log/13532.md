# Repeated system blocks lost typed configuration (#13532)

- **Issue**: #13532 — a later `system syslog` block replaced earlier
  destinations; flat system service/SNMP statements could be missed; repeated
  SSH and SNMP blocks could lose earlier fields.
- **Cause**: `compileSystem` reset the syslog struct on every syslog child and
  rebuilt the host coalescing map per block. It searched for only the first
  services/SNMP child, and reset SSH's typed config for each block. `compileSNMP`
  allocated a fresh config for every invocation and kept tolerant-path
  community quarantine state local to one call, allowing a later valid block
  to reopen a community quarantined by an earlier malformed restriction.
- **Change** (`pkg/config/compiler_system.go`, `pkg/config/types_system.go`):
  retain existing syslog/SNMP/SSH typed state across blocks; seed syslog host
  coalescing from already compiled destinations; combine repeated service SSH
  bodies and visit every SNMP block. Preserve compact `system services` and
  `system snmp` bodies, including SNMP scalar keys not represented in its
  schema. Keep SNMP community quarantine sticky in compilation-only state on
  the typed config. Added regression coverage in
  `pkg/config/system_repeated_block_13532_test.go` for repeated roots and
  same-parent blocks, same-address syslog facility union, flat/packed services
  and SNMP, and tolerant fail-closed behavior after a later SNMP block.
  Removed the now-fixed `system services dns` row from
  `pkg/config/testdata/compact_block_divergences_2419.txt`.
- **RED evidence** (pristine master `2908cfc30`, test-only file copied into
  `/var/worktrees/campaign-pub/wt-13532-red`): the full new regression set
  failed. Repeated syslog roots retained only one host, same-address syslog
  lost earlier facilities, repeated syslog children lost the first host,
  packed services were nil, flat SNMP lost its location, repeated SSH blocks
  lost settings, a later SNMP block reopened a quarantined community, and
  repeated SNMP roots lost the earlier location.
- **GREEN evidence**: focused acceptance plus existing shape gates
  `go test ./pkg/config -run
  'TestSystem(Repeated|Packed|Flat).*13532|TestCompactBlockEquivalenceInventory2419|TestElidedSSHRootLoginReachesTheDaemon8690'
  -count=1` passed. Full config suite `go test ./pkg/config -count=1` passed
  (401.497s); repository build `go build ./...` passed.
- **Risk**: no user-visible behavior beyond making repeated blocks merge and
  retaining fail-closed SNMP quarantine across them.
