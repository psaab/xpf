# #15269 — screen/interface show views misreporting control state (B18-01, B18-05, C09-01, C09-02, C09-03)

- **Timestamp**: 2026-10-19
- **Action**: Fix five validated show/state misreports so every surface
  renders what the dataplane enforces, via shared helpers where twins
  exist. No enforcement change.

## Defects & fixes

- **B18-01 (screen SYN-flood detail, CLI + gRPC)**: unset alarm/source/
  destination thresholds rendered `(default)` against 512/4000, but
  `buildScreenSnapshots` publishes 0 and Rust treats 0 as disabled (no
  sketch; alarm `u32::MAX`). New `dpuserspace.SynFloodSubThresholdValue`
  (`disabled` when 0) + `SynFloodSubThresholdDefault` (`512 (not applied)`)
  + `EffectiveSynFloodTimeout` (profile timeout, else flow
  `tcp-session initial-timeout`, else 20s default opening window).
  Both detail renderers use them; Timeout Value is the effective window.
- **B18-05 (interfaces terse, CLI + gRPC)**: gRPC never read unit
  `Disable`; CLI checked it only on the non-RETH branch, so a disabled
  RETH unit showed admin up with its address. New shared
  `config.TerseUnitDisabled` (interface- or unit-level) applied on
  RETH + normal branches of both renderers; disabled units render
  admin `down` with configured/kernel addresses suppressed. Enabled
  control units unchanged.
- **C09-01 (DNAT source match)**: dataplane enforces `match
  source-address` (#2394/#2416) but no DNAT view showed it.
  `natshow.RenderDestRuleDetail` now prints `Source addresses:
  natshow.RuleMatchSource(rule)`; CLI default/rule-set/rule-all views
  print it; proto `NATDestInfo.source_match = 12` (additive, regen)
  populated by gRPC `GetNATDestination`; REST `NATDestInfo.source_match`
  populated by `natDestHandler`; ctl destination view prints `src=`.
  Unscoped rules render `0.0.0.0/0`.
- **C09-02 (daemon syslog zone names)**: `applySyslogConfig` built the
  EventReader zone map with a naive map-iteration loop, so a
  StableZoneID collision loser could claim the id. Replaced with
  shared `config.SyslogZoneNames` (= `SurvivorZoneNames` over
  StableZoneID ids, quarantine-aware, same semantics as CLI
  `syslogZoneNameMap`). Colliding pair z174/z214 resolves to survivor
  z174 deterministically.
- **C09-03 (REST applications text)**: printed only proto/dst-port.
  New shared `config.ApplicationTermSuffix` (src-port, icmp-type,
  icmp-code, timeout never/Ns — the #12903 gRPC set, in gRPC order)
  used by both REST `show_text.go` applications topic and the gRPC
  renderer, so they cannot drift.

NOT changed: dataplane enforcement, snapshot publishing, config
parsing/gates, forwarding behaviour of disabled units (owned by
A28-01), `dst_port` back-compat semantics.
