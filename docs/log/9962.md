- **Action**: Cause. An earlier header block was left behind when its function
  was replaced by prose: R12 was deliberately recorded as a MEASURED GAP rather

  attaches an attribute to the next item, so the R9 function below carried two.

  Deleted the orphaned `#[test]` AND the superseded `///` header above it. The
  R9 header already documents the function fully, and deleting only the
  attribute would have left a `///` block documenting a `//` comment.
