post-unwrap inner TPID behind both 0x8100 and 0x88a8. The armed path requires
XDP_DROP, `qinq_drop`, and `transit_drop`, with `pass_to_kernel` absent; the
degraded path covers the same legacy shapes. Existing single-tagged ARP and
IPv4/UDP controls continue to pin ordinary 802.1Q/802.1ad behavior. The new
rows are inside the existing `TestUserspaceXDPQinQ*` functions, which remain
in the by-name `make test-shim-run` gate. Their shared `RemoveMemlock` skip
predicate lives in unchanged `xdp_shim_decouple_test.go`; the privileged gate
executed these tests locally.
