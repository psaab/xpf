# #14442 — Interface-level leaf-run tail: `disable` as a non-first leaf is dropped

## Mechanism
`compileInterfaces` read interface-level leaves off the raw interface
child (`child.FindChild(...)` over `Children`). A packed tail —
`interfaces { ge-0/0/0 description "uplink" disable; }`, the same run
nested under a braced first leaf
(`{ description "uplink" disable; }`), or a flat-set line
(`set interfaces ge-0/0/0 description uplink disable`, which SetPath
nests `disable` under `description`) — carries the tail on Keys with
no sibling Children. Only the head leaf exposed by the #9792
nested-run expansion was seen: a non-first `disable` vanished, and a
packed interface with no `bandwidth` was skipped entirely
(`if child.IsLeaf && bandwidthNode == nil`). The strict schema walk
rejects the flat-set spelling (scalar `description`, #3332), but
`CompileConfig` / `CompileConfigLenient` directly — the tolerant
load / HA-sync path — dropped it, so an operator's admin-down
compiled to an enabled interface. Two guard defects compounded it:
`packedOrNestedLeafRun9792` required `len(Keys) >= 2` (a value a
flag head such as `disable` never has) and tested the packed
continuation at fixed `Keys[2]`, so a flag-first run
(`disable description uplink`, nested or packed) never expanded.

## Fix
- `pkg/config/compiler_interfaces.go`: compute
  `ifBody := packedBody(ifLeaves, interfaceSchema)` once and route
  every interface-level read (description, mtu, speed, duplex,
  disable, bandwidth, vlan-tagging, flexible-vlan-tagging,
  native-vlan-id, gratuitous-arp flags, encapsulation,
  gigether/aggregated/redundant/fabric options, tunnel, units,
  AuthoredUnits) through it. The IsLeaf skip now also requires
  `len(ifBody.Children) == 0`, so a packed interface whose tail
  exposes any leaf is compiled instead of dropped. Composes with
  the #14441 redundant-ether-options expansion on the rebased head.
- `pkg/config/flat_run_residue_9792.go`:
  `packedOrNestedLeafRun9792` admits a flag head (args:0) carrying a
  nested declared tail, and tests the packed continuation at
  `Keys[1+head.args]` with a bounds check instead of fixed
  `Keys[2]`. Value-bearing heads still require their value token;
  container/wildcard/multi heads, undeclared tails, and the
  `processes { utmd disable; }` opaque-block shape stay refused
  (allDescendantsDeclared9792 unchanged).
- Guard rows in `flat_run_residue_9792_test.go` updated: the
  valueless-flag-head row now expects expansion (#14442), plus new
  undeclared-tail (false) and packed flag-head (true) rows.

## Regression
New `pkg/config/interface_disable_packed_14442_test.go`
(`TestInterfaceDisableNonFirstPacked14442`), exercising the exact
claimed spelling on strict + lenient compile and the flat-set axis:
- RED on the pre-fix head: packed `description "uplink" disable;`
  dropped the interface entirely; braced-packed
  `{ description "uplink" disable; }` gave `Disable=false`;
  flat-set both orders lost one leaf; controls below passed.
- GREEN after fix: all packed orders compile `Disable=true`
  identically (DeepEqual) to the braced twin
  `{ description "uplink"; disable; }`; `disable`-first unchanged;
  mtu+disable both orders give MTU=9000 + Disable=true; packed tail
  carrying `unit 0 family inet address 10.0.0.1/24` keeps the unit;
  no-disable controls stay `Disable=false`.
