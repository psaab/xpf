# #14657 — WireGuard encap blackholes dynamic-only underlay neighbors

## Defect

`wg_encap_frame_with_commit` (`userspace-dp/src/afxdp/frame/wg.rs`)
re-resolves the selected peer's outer underlay route via
`outer_physical_egress_resolution`, which passed `dynamic_neighbors = None`
to the FIB lookup. The encap then requires
`outer_resolution.resolution.neighbor_mac?` — after #13978 removed the
session-neighbor fallback, a next hop learned only into the runtime
`ShardedNeighborMap` (netlink monitor / resolver / RX learn) resolved to
`neighbor_mac = None` and the encap returned `None` on every transit
packet (plain, TCP-segmented, and NAT64 arms). Stage 9 had resolved the
same underlay *with* the dynamic map and said ForwardCandidate, so there
was no MissingNeighbor requeue: a permanent blackhole until a static
snapshot happened to include the neighbor. The decisive check in the
issue — does any daemon path republish `ForwardingState.neighbors` when
`dynamic_neighbors` gains an entry? — is answered no: the static map is
rebuilt only on config snapshot refresh, while dynamic learns land in
`ShardedNeighborMap` asynchronously.

## Fix

Thread `Option<&Arc<ShardedNeighborMap>>` through the WG outer
resolution, mirroring the existing FIB `Option` plumbing
(`lookup_forwarding_resolution_inner` already takes exactly this type):

- `wg.rs`: `outer_physical_egress_resolution_with_dynamic`,
  `outer_physical_egress_ifindex_with_dynamic`,
  `outer_physical_egress_mtu_with_dynamic`,
  `wg_endpoint_physical_outer_mtu_with_dynamic`,
  `wg_selected_peer_outer_with_dynamic`,
  `wg_transit_egress_physical_egress_ifindex_with_dynamic`, and
  `wg_encap_frame_with_commit_and_dynamic` /
  `wg_encap_frame_with_dynamic`. The existing `None` wrappers are kept
  byte-identical for non-worker callers.
- `frame/mod.rs`: `build_forwarded_frame_from_frame_with_dynamic`,
  `build_forwarded_frame_from_frame_with_commit_and_dynamic`,
  `build_nat64_forwarded_frame_with_dynamic`,
  `build_nat64_forwarded_frames_with_dynamic`,
  `build_nat64_forwarded_frames_with_commit_and_dynamic`.
- `frame/tcp_segmentation.rs`:
  `segment_forwarded_tcp_frames_from_frame_with_dynamic`,
  `segment_forwarded_tcp_frames_from_frame_with_commit_and_dynamic`,
  and `encap_tunnel_segment` now takes the map.
- `icmp_ptb.rs`: `post_transform_inner_mtu_with_dynamic` /
  `tunnel_inner_mtu_with_dynamic` (route-MTU/peer-family consistency;
  the neighbor itself is not read there, but the resolution is shared).
- Production wiring: `poll_descriptor/mod.rs` and
  `poll_descriptor/flow_cache_hit.rs` pass `worker_ctx.dynamic_neighbors`
  into `build_live_forward_request_from_frame_with_dynamic`
  (`forward_request.rs`, which resolves the dispatch NIC via
  `resolve_forward_target_ifindex_with_dynamic`);
  `worker/lifecycle.rs` passes it into
  `enqueue_pending_forwards_with_dynamic` (`tx/dispatch/mod.rs`), which
  threads it into the copy-fallback builders, the TCP-segmentation
  fallback, `compute_forwarded_egress_ptb_with_dynamic`, and the NAT64
  egress-MTU helpers; `neighbor_dispatch.rs` (pending-neighbor replay)
  passes its `dynamic_neighbors` into the segmentation and PTB calls.

GRE is untouched: it reads `decision.resolution.neighbor_mac`, which is
resolved upstream with the dynamic map. The #13978 invariant is
preserved — with no dynamic entry (or no map) the encap still fails
closed rather than borrowing the session adjacency.

## Regression cells

- `wg_encap_dynamic_only_neighbor_resolves_outer_dst_mac_14657`
  (wg_tests.rs): dynamic-only next hop (12, 172.16.80.1); asserts
  fail-closed without the map and the dynamic MAC on the wire with it.
- `wg_encap_dynamic_only_neighbor_via_forwarded_builder_14657`:
  same mechanism through `build_forwarded_frame_from_frame_with_dynamic`.
- `wg_encap_dynamic_only_neighbor_via_nat64_builder_14657`:
  NAT64+WG arm through `build_nat64_forwarded_frame_with_dynamic`.
- `wg_segmentation_dynamic_only_neighbor_encapsulates_14657`
  (tcp_segmentation.rs): segmented WG encap, dynamic-only v6 next hop;
  asserts fail-closed without the map and per-segment dynamic dst MAC
  with it.
