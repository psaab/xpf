# #13840 — attribute GRE and session-window master failures

## Attribution on pristine master

Base: `2cae7b02a640315e70f9681f12f2c337b3bd9b0a` (`origin/master`, fresh
worktree).

The three reported tests fail deterministically when run together on this
pristine master: 86 tests run, 3 failed, 0 ignored. The failures are:

- `gre_decap_inner_icmp_echo_denied_by_host_inbound_reads_inner_type`
- `gre_decap_session_hit_host_inbound_reads_inner_icmp_type_5615`
- `c3_forward_control_survives_full_window_per_permit_shape_10591`

Each of these three also fails individually on that pristine base, so the
failures are not caused by suite order.
The GRE failures stop before the host-inbound assertion because native
decapsulation rejects the frame.
The fixtures set outer GRE flags byte to `0x0b`, which encodes Reserved0
bit 1 (`0x0800`, Strict Source Route) plus a lower reserved bit. The recently
merged #13662 correctly rejects that unsupported RFC 2784 bit; the fixture
must use a valid RFC 2784 §2.3 must-ignore bit while retaining the globally
accepted outer ICMP error type. Use `0x03` (wire flags/version word `0x0300`,
within the `0x03f8` must-ignore mask) to represent outer type 3.

The #13663 change is WireGuard-only and not on either failing GRE test path;
#13638 session-hit guards do not account for GRE decapsulation refusal and are
not causal. #13835 fragment retention is unrelated to these tests. The separate
`f035_parked_fragment_overlap_is_rechecked_on_retry_10659` remains a known
master-attributed failure from earlier suite runs.

The c3 failure is not an authority-gate regression or a suite-order effect.
The test admitted a bare SYN and then sent reverse-direction ACKs from the
foreign DMZ zone. Those packets are not owner-authoritative and do not refresh
the session. The unestablished pair correctly reaches its short opening timeout
at tick 21 under #13679. The fixture now drives the admitted pair through the
session TCP state machine's SYN-ACK and final-ACK transitions before observing
the full established-session window; no production timeout behavior is changed.

## Change and validation

Re-pin the two GRE host-inbound fixtures to use the valid must-ignore outer GRE
flag value `0x03`, preserving the mismatch between outer ICMP error type 3 and
inner echo type 8. Re-pin c3 by completing the fixture TCP handshake through
the existing session update path before running its 257-tick permit control and
commit-purge check. No production code changed; #13662 and #13679 behavior is
intentional and remains intact.
