  - No doc or README mentions `no-private-rg-election` at all. `docs/feature-coverage.md` calls RETH
    VRRP "an xpf-to-xpf mechanism between the two chassis of one cluster", with no reservation
    guidance.
  - Found in passing: the `pkg/vrrp/README.md` "RETH ownership modes" table (#6780) still called
    the VRRP-backed mode the "default". That is stale since private-RG election became the
    compiler default. Fixed here, since this PR edits that section.
