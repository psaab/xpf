# #10006 — scheduler equal bounds are always-active but undocumented

## Summary

The scheduler runtime intentionally preserves the historical wraparound
convention: `start-time` equal to `stop-time` enters the `start >= stop`
wraparound branch, making the time-of-day arm active at every time of day.
The behavior is now documented in `pkg/scheduler/scheduler.go`, and
commit-time validation warns
when an effective daily or per-day window uses equal bounds. The warning names
the matching explicit always-active form (`daily all-day` for the daily arm or
legacy fields, and `<weekday> all-day` for a weekday override).

Explicit `all-day` and `exclude` arms retain runtime precedence and do not emit
the equality warning. Windows with `start > stop` retain overnight behavior.

## RED / GREEN proof

- RED baseline: `TestSchedulerEqualWindowWarns` failed in all three equality
  warning cases because the pre-fix commit path emitted no warning; the
  existing equality runtime behavior was already active by design.
- GREEN targeted proof: six scheduler equality/overnight tests passed, and
  `TestSchedulerEqualWindowWarns` passed all eighteen cases (five warning
  cases, normal/overnight/explicit-all-day/exclude/precedence/half-window/
  invalid-value/whitespace negative controls, and multi-arm remediation
  determinism).
- Full affected suites passed after the final implementation:
  `go test ./pkg/scheduler -count=1` and `go test ./pkg/config -count=1`.

## Files

- `pkg/scheduler/scheduler.go` — documents equal bounds as always-active and
  points operators to the matching explicit all-day form.
- `pkg/config/compiler_validate_warn.go` — emits deterministic commit-time
  equality warnings and selects the daily or matching weekday remediation.
- `pkg/scheduler/scheduler_equal_window_10006_test.go` — pins daily and
  per-day equality as active, plus explicit all-day/exclude precedence.
- `pkg/config/compiler_validate_scheduler_equal_window_10006_test.go` — pins
  warning wording/remediation and normal, overnight, all-day, exclude, and
  half-window controls.
