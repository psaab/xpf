        (`attach_coordinator_steering`, `Arc<OnceLock>`); every worker and
        tunnel thread works on a clone that shares it.
    - **Lock order** added: shared sessions, then the registry's holdings
      and row shards. No registry path takes a shared-session lock (the
      closures in `publish_session_rows`, `release_session_rows`,
      `publish_session_map_key`, `delete_live_session_key`,
      `retire_worker_steering_rows`, and `retire_workers` take none).
