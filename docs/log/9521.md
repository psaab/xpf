- **File(s)**: (analysis)

Candidates and why each was taken or not:

- **Stop admitting unsteered ports in the host-inbound filter.** Rejected. The input chain accepts `ct state established` ahead of the WireGuard admit, so a peer answering a handshake xpf initiated rides conntrack past any per-port rule; a zone admitting all host-inbound services (`hostInboundAllowsAll`) accepts the port anyway; and `applyHostInboundFilter` installs no table at all when no enforceable view, unzoned address or junos-host program exists. The fix would also have to be mirrored into the cold-boot fence and the gap fence, in both renderers.
- **Refuse multi-port at commit.** Rejected by the gate's own recorded decision (#1960 no-brick): a box already running such a config could not commit an unrelated change.
- **Do not spawn a control thread for an unsteered endpoint.** Rejected on measurement of the code path: a listener on an interface-mode source-NAT address is not `is_local_destination` in the shim, so its records go to the worker (`is_interface_nat_destination` → XSK), whose decap matches ANY configured listen port (`wg_endpoint_for_listen_port`), and its handshakes reach the kernel socket through `interface_nat_local_resolution_on_session_miss` → LocalDelivery. That tunnel works and is adjudicated today; refusing the thread would break it.
- **Remove the control thread's TUN write for every endpoint.** Rejected: `docs/log/8274.md` "The residual, stated rather than closed" keeps that write deliberately for the steered port on shim-uncovered ingress and for host-inbound over the tunnel. Not re-litigated.
- **Port-set steering (#1434 Increment 2).** Deferred to #9587, filed here so the deferral has an owner: verifier-gated shim change, v6 line-rate sensitivity, loss cluster.
- **Chosen:** the unsteered endpoint's control thread authenticates a transport record and drops the plaintext (`WgKernelTransport::DropUnsteered`, counted `rx_unsteered_transport_drops`). It is the one place every such record converges, it leaves the steered port and the worker path untouched, and it is fail-closed (a snapshot naming no steered port delivers for no endpoint).
