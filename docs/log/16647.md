    config default — never widening to any-remote-host. Grants are carried
    onto the binding as parsed `PermittedRemotes` and rendered in the

    `Lookup` keeps its legacy (src,port,pool) scan for identity-less
    callers while `LookupScoped` matches the full identity, and `All()`
    deep-copies the grants. The converters now populate Protocol and
    RoutingScope from the wire, and the legacy session-store preserve
    (`preservePersistentNATV4/V6`) stamps the session's protocol and
    routing domain. `RenderPersistentDetail` (`pkg/natshow/persistent.go`)
    prints Protocol (when known), Routing scope, and one
    `Permitted remote:` line per grant (`host (any port)` for the
    target-host wildcard). No enforcement path changes: the helper's
    grant checking is untouched, so nothing fail-opens.
