- **Date**: 2026-10-15
- **Issue**: #13303
- **Why**: A dual-family sampling instance is split into `inet` and `inet6` exporter groups, but the flow-export status shapes and all nine Prometheus descriptors used only protocol, instance, and template (plus collector/source for health). Groups sharing those values emitted identical series and caused Prometheus pedantic collection to fail, making `/metrics` return HTTP 500.
- **What**: Added the `inet`/`inet6` family to `ExporterCollectorHealth` and `ExporterBatchStats`, populated it from each group's existing `GroupIsV6` flag in both NetFlow and IPFIX snapshots, and included the family label in every collector-health and batch metric descriptor and emission. Added a pedantic dual-family regression covering both metric groups and updated the collector label-set contract test.
- **RED-before**: On clean master `f59c739af`, the new regression test failed to compile because `ExporterCollectorHealth` and `ExporterBatchStats` had no `Family` field. This exposed the missing family identity in the source snapshot shape.
