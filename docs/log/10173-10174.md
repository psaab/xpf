## Implementation

### #10173 — userspace FIB unit-member alias

Commit `f206e1d6f` adds one userspace-side runtime-key helper used by both
`forEachRoutingInstanceInterfaceKey` and `quarantinedInterfaceKeys`:

* a unit member whose base is Linux-equivalent to a declared stanza is mapped
to the declared stanza key plus the canonical unit suffix;
* same-spelling paths retain their existing key and fanout behavior;
* all pass-0 explicit keys are recorded before pass-1 bare fanout, so an
explicit unit beats a fanned key independent of routing-instance order;
* quarantined unit aliases reach the declared snapshot row and therefore the
sentinel session domain instead of the default domain;
* tunnel rows use the same declared snapshot identity, covering per-unit and
interface-level tunnel forms without inventing tunnel-map keys.

### #10174 — bare member fan-down

Commit `4055b00ee` adds the deliberate bare exception in the consumers that own
Linux-name matching:

* the daemon uses `resolveMemberDeclaredBase` to resolve a bare cross-spelled
member to the first-sorted declared stanza, then fans down that stanza's base
and configured units through the existing structural path;
* the userspace FIB maps the bare alias to the declared stanza and fans down its
unit keys, preserving explicit-before-fanout precedence;
* the existing #9815 `claimedBare` scoping partition is preserved and exercised
for both spelling directions. It already excludes a cross-spelled bare port
from default-instance ingress before this follow-up; no redundant resolver copy
was added to `DefaultInstanceIngressIfaces`.
