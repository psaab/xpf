# #9512 — routing: the learned-route importer drops LinkIndex, so a scope-less IPv6 link-local next hop binds whichever interface comes first

- **Timestamp**: 2026-09-10
  - **Action**: `learnedRouteNextHops` (pkg/routing/fibimport.go) now scopes
    every IPv6 LINK-LOCAL gateway leg to its link.
    - The leg is published as `gateway@<netdev>`, with the kernel name taken
      from the leg's `LinkIndex`: `NexthopInfo.LinkIndex` for each ECMP leg,
      `Route.LinkIndex` for a single route.
    - This is the form the configured-route path already emits
      (pkg/dataplane/userspace/routes.go). The helper already parses it:
      `resolve_ifindex` looks the name up in the Junos-name map, then in the
      `linux_name` map, which the netdev name hits.
    - Names come from `learnedRouteLinkNameFn` (netlink.LinkByIndex). It sits
      behind a per-import cache, so a dump costs one lookup per distinct link,
      and it is indirected for the cells.
  - **Action**: A link-local leg whose link cannot be named refuses the WHOLE
    route, because a scope-less link-local next hop has no correct binding to
    fall back to. The cases are LinkIndex 0 and a failed lookup. ECMP stays
    all-or-nothing, like the existing gateway-less leg rule.
    - The refusal logs one `slog.Warn` naming the destination, table, gateway
      and protocol, deduplicated per (table, destination, gateway). The
      importer runs on every route-snapshot build, so an undeduplicated
      warning would repeat at build rate.
  - **Action**: Deliberately NOT extended to global or IPv4 gateways. A
    scope-less global gateway is legitimate, and the helper's connected-prefix
    inference binds it correctly; the issue names this as the negative control.
  - **Action**: Not done: the issue's optional "consider" item, dropping
    link-local addresses from the helper's `connected_v6`. With every learned
    link-local leg now scoped, the first-match hazard no longer reaches learned
    routes. Removing the entries would change on-link resolution for every
    other consumer of `connected_v6`, and none of those consumers was measured
    here.
  - **Action**: Cells.

    - pkg/dataplane/userspace/routes_learned_linklocal_9512_test.go: scoped
