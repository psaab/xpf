# #18334 — align the #6691 test pin with ProtocolVersion 77

## Why

`ProtocolVersion` and the Rust control-plane version are already 77 after
#17099, but `secureTunnelSnapshotProtocolVersion` still pinned the current
version at 76. Both `TestMixedVersionMatrix_6691` and
`TestSecureTunnelFieldIsNotIgnorableByAPreV5Helper` consume that stale pin.
The matrix's refusal strings classify synthetic errors rather than construct a
v76 peer. The secure-tunnel test's pre-v5 helper is explicitly modeled at
`preSecureTunnelProtocolVersion = 4`.

## Change

- Raised the shared current-version test pin to 77 and noted the #17099 change.
- Preserved the explicit v4 pre-v5 helper fixture; no production protocol value
  or peer-version behavior changed.

## Validation

- `go test ./pkg/dataplane/userspace/ -run 'TestMixedVersionMatrix_6691|TestSecureTunnelFieldIsNotIgnorableByAPreV5Helper|TestSnapshotShapeIsPinnedToProtocolVersion8892' -count=1 -v` — passed all three named tests.
- `go test ./pkg/dataplane/userspace/ -count=1` — failed in other package tests, including Unix-socket bind errors and unrelated golden/fixture/policy/parity failures; the three requested tests passed in the targeted run.
- `git diff --check` — clean before commit.

## Risk

This only reconciles test expectations with the existing v77 protocol. It does
not change Go or Rust wire behavior, and the real pre-v5 peer remains pinned at
its historical v4 version.
