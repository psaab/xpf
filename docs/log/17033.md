# #17033 — single-source the idempotent-reuse holder-recording return

- **Timestamp:** 2026-10-27
- **Branch:** `fix/17033-campaign`
- **File(s):** `userspace-dp/src/nat/allocator/mod.rs`, `userspace-dp/src/nat/mod.rs`, `userspace-dp/src/nat/tests_reenter_17033.rs` (new)

## Why

The idempotent re-entry (`slot.holders |= holder.bit()` + `reuses_total` bump + give-back) was hand-copied at 13 sites in the NAT pool allocator, with the 15-line `#9145` rationale pasted 7 times. Two divergences had already landed: the v4 deterministic copy's comment said "WITHOUT recycling" above a recycling free (stale since #14625 updated only the v6 twin), and `reserve_flow_maybe_persistent_inner` (synced PAT) was the only copy that did not bump `reuses_total`, so the exported `xpf_userspace_source_nat_pool_reuses_total` metric — and the test discriminator built on it — silently excluded synced PAT refreshes while its synced address-only twin counted them.

## What

- Add `ReuseCount { Counted, Uncounted }` and `PortAllocator::reenter_existing_locked(slot, holder, count) -> TranslatedTuple` in `userspace-dp/src/nat/allocator/mod.rs`: the one body that ORs the holder bit, optionally bumps `reuses_total`, and returns the incumbent tuple, with the #9145/#6211 F2 rationale written once in its doc comment.
- Migrate all 13 hand-copied sites to the helper (PAT fast/serialized re-checks, deterministic v4/v6 exhaustion + claimed-port returns, synced PAT, synced address-only, interface identity + `reenter_interface_record_locked`, round-robin address-only, persistent address-only). Callers keep their own give-back (unpublished free, recycling free, or none) after the helper returns.
- Decision on the divergent counter: synced PAT refreshes now pass `ReuseCount::Counted`, matching the synced address-only twin (`reserve_address_only_maybe_persistent`, which counted refreshes all along). No caller currently passes `Uncounted`; a future non-counting path must say so explicitly at its call site.
- Fix the stale v4 deterministic comment: the claimed port is given back through the normal recycling free (#14625), as the v6 twin already said.
- New hermetic cell `synced_pat_refresh_bumps_reuses_total_17033` (`userspace-dp/src/nat/tests_reenter_17033.rs`): installs a synced PAT record, refreshes it from a second worker, and pins `reuses_total` 0 -> 1 -> 2 plus the holder mask `0b11`.
