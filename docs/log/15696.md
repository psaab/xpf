# Issue #15696: RA prefix duplicate PIO merge

- **Timestamp**: 2026-10-19
- **Problem**: `protocols router-advertisement interface <if> prefix <cidr>` could be delivered twice for the same CIDR — hierarchical `prefix P { valid-lifetime 100; } prefix P { no-autonomous; }`, sibling `interface` blocks, or flat `set ... prefix P` followed by `set ... prefix P no-autonomous` (leaf-then-container split in `SetPath`). `compileRouterAdvertisement` appended every occurrence as a new `*RAPrefix`, and `pkg/ra` emits one PIO per entry, so hosts received duplicate conflicting Prefix Information Options (e.g. defaults/A=true vs A=false, different lifetimes).
- **Fix (compiler)**: In `compileRouterAdvertisement` (`pkg/config/compiler_protocols.go`, `case "prefix":`), find-or-create on `ra.Prefixes` by `pfxName`, mirroring the outer `ra` find-or-create. The existing entry is updated in place (present flags/lifetimes overwrite, absent fields keep prior values; defaults only on first creation) and appended only when newly created. This covers hierarchical, sibling-block, apply-groups-expanded, and any residual twin shapes regardless of AST provenance.
- **Fix (ast)**: In `SetPathQuotedGrouped` (`pkg/config/ast_edit.go`), the #15682 leaf-promotion is generalized via `leafPromotableToContainer`: a same-key leaf is promoted to a container only for `feed-name <feed>` under `feed-server` (#15682, unchanged) or for a declared container schema with `args > 0`, non-multi, whose children are all leaf schemas (`children == nil && wildcard == nil`) — the RA `prefix <cidr>` shape. Other twins keep the two-node split, notably policy `then permit` (args:0, no children) whose split the #3114/#3115/#3141 gates (#3377) inspect verbatim; pinned by `TestRAPrefixPromotionKeepsThenPermitSplit15696` and the existing `TestDynamicAddressSetPathKeepsThenActionSplit15682`.
- **Not changed**: Distinct CIDRs stay distinct entries; the RA sender (`pkg/ra`) is untouched (it correctly emits one PIO per compiled prefix — the duplication was upstream); strict validators are untouched.
