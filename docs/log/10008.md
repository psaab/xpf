## Change

`ForwardingStatus` now carries `HeapPercentValid` beside `HeapPercent`, matching
the validity discipline used by the CPU windows and `BufferKnown`. `Build`
sets the flag only after both RSS and a positive cgroup or `/proc/meminfo`
limit are available. `Format` renders an invalid heap measurement as `-`;
valid measurements continue through the existing [0, 100] clamp. In particular,
a valid zero RSS measurement remains `0 percent`.

The regression file `pkg/fwdstatus/heap_valid_10008_test.go` covers both unknown
branches (statm failure and unavailable memory limit) and the measured-zero
branch. Existing formatter fixtures that intentionally provide a heap number
now explicitly mark it valid.
