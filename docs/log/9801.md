- **Timestamp**: 2026-09-11
- **Action**: Measured at master `36dfa8e5a` through `configstore.CheckText`
  and `config.CompileConfigLenient`. The configuration has one `security`
  stanza and a top-level `apply-groups G;`. Readings are scoped to zone `trust`.
  - With `security-zone <*> { tcp-rst; }` applied, the leaf
    `security-zone trust;` compiled `TCPRst=false` and the braced
    `security-zone trust { }` compiled `true`.
  - With `security-zone <*> { screen edge; }` applied, the leaf compiled
