# #10311 neighbor-MISS disposition

## Problem

A MissingNeighbor frame could be parked with the translated `pending_decision` while the shared slow-path chokepoint reinjected the original untranslated `decision`. That produced an untranslated kernel copy and a later translated retry for the same packet.

## Change

- Keep the composed NAT decision for non-buffered MissingNeighbor fallthroughs.
- Suppress the shared slow-path copy when the frame is parked, rejected as a duplicate/capacity overflow, or refused at session-seed admission.
- Exercise interface SNAT, static SNAT, and NPTv6 MISS/retry paths, including a separate-UMEM translated replay.
- Add a duplicate-hop fail-on-revert assertion.
