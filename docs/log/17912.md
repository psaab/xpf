# Issue #17912: Omit quarantined host-inbound views

## Timestamp

2026-10-26T16:02:10Z

## Action

STEP-0 confirmed the host-inbound snapshot builder on origin/master did not omit snapshots tagged with an interface-quarantined zone; the regression failed there with a published zulu view carrying ge-0/0/0 and 10.0.0.1. The builder now omits the default view when every authored identity in a zone is quarantined, ignores snapshot rows that retain a quarantined identity/zone label, and filters a collapsed physical-parent row when its same-netdev unit 0 is quarantined. Config-derived VRRP VIP and stable-RETH address walks also gate on the quarantined logical identity. The real-table unzoned address and ingress builders now route quarantined identities and stale labels without a surviving zone view into the unzoned catch-all. Surviving identities, sibling-zone policy, and unrelated bare-only interfaces remain covered.
