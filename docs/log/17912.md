# Issue #17912: Omit quarantined host-inbound views

## Timestamp

2026-10-26T15:17:32Z

## Action

STEP-0 confirmed the host-inbound snapshot builder on origin/master did not omit snapshots tagged with an interface-quarantined zone; the new regression failed there with a published zulu view carrying ge-0/0/0 and 10.0.0.1. The builder now omits the default view when every authored identity in a zone is quarantined, ignores snapshot rows that retain a quarantined identity/zone label, and continues to publish surviving identities and sibling-zone policy.
