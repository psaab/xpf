# Issue #14322 — persistent-NAT grants must not leak across egress zones

- **Issue:** psaab/xpf#14322 tails the shared-PAT flush lane: persistent-NAT (`permit any-remote-host|target-host|target-host-port`) grants were recorded on one FLAT grant list in `PersistentPermissions`, so a permissive rule's any_remote grant authorized arbitrary remotes inbound on the strict rule's reflexive binding whenever rules shared one pool allocator.
- **Lane:** `fix/14322-campaign` in `/var/worktrees/wt-14322`; base RED worktree `/var/worktrees/wt-14322-base` (never stash).

## Defect

Rules sharing one pool must share one endpoint-independent lease and one translated tuple (#9389) — lease identity holds. The permission grant record did not: `PersistentPermissions { any_remote, remotes }` had no egress-zone separation, and `record_permits`/inbound lookup never saw zones, so a flow admitted by `trust->dmz(any-remote-host)` granted ANY remote inbound via `trust->wan`.

## Fix

Grants bucketed by egress scope, lease/flow keys untouched:
- `nat/allocator.rs`: `PersistentPermissions` becomes `scopes: FxHashMap<u32, PersistentPermissionScope{any_remote, remotes}>`; scope is a deterministic FNV-1a fold of the admitting rule's `(from_zone, to_zone)` (`persistent_egress_scope`, never 0; `0` = unscoped legacy/NAT64). `record` inserts into the call's bucket, `can_record` counts the 1024-remote cap across ALL buckets. Scoped arrival admits only its bucket; unscoped arrival (zone-unknown legacy/NAT64/direct callers) admits any bucket. `allocate_translation*` and `reserve_address_only_persistent` take an explicit `egress_scope: u32`. `persistent_inbound_lookup(..., from_zone, ingress_zone)` folds arrival scope; poll descriptor passes `rule.from_zone` + packet ingress zone.
- Owner index (`add/remove_persistent_address_only_owner`): derived from stored permission buckets (deduped across scopes) instead of `PersistentSourceKey.remote` (always `None` post-#14046); `record_persistent_permission` re-indexes newly-added owner keys. `rollback_idle_lease_import` keys with `remote: None`.
- `nat/idle_lease_sync_8121.rs`: `IdleLeaseRecord.egress_scope`; export emits one record per bucket; import inserts permissions BEFORE lease creation, reclaims expired idle leases inline, and merges buckets (no full owner-index rebuild on re-import).
- Wire/protocol v50: Rust `IdleLeaseWire`/`DisplayLeaseWire` gain `egress_scope: Option<u32>` (handlers reject `None`); `CONFIG_SNAPSHOT_PROTOCOL_VERSION = 50`. Go: `EgressScope *uint32` with `bytesle` present-required; binary encode/decode; `MinProtocolPersistentNatLeaseEgressScope = 50` gate with nil checks at import/display; HTTP handler coherent. `protocol_wire_v1.json` regenerated (adds `egress_scope: 11`).
- Test construction coherence: direct `.remote =` mutations in tests routed through `set_remote_scope` (also forces `egress_scope=0`); stale expected counts updated.
