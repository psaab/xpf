# #13982: keep ICMPv6 Redirects out of host routing

`system no-redirects` previously wrote only `conf/all`. Linux does not use
that setting to disable IPv6 Redirect acceptance on existing interfaces, and
closing the transit gate by writing `ip_forward=0` resets IPv4 redirect
posture. During gate-closed windows, an on-link spoofed Redirect could install
a route exception that steers firewall-originated traffic.

The daemon now applies the configured posture to `conf/all`, `conf/default`,
and each current interface under both IPv4 and IPv6 sysctl roots, then
reasserts it after every transit-forwarding sysctl write. The global host-
inbound admits no longer accept ICMPv6 type 137, including the cold-boot
fence, and the userspace classifier no longer treats Redirects as mandatory
host-inbound control traffic.
