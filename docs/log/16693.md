# #16693: local policy detail view took one counter snapshot per policy and dropped the stats-disabled note / read-failure warning

- **Timestamp**: 2026-10-25
- **Action**: `cliPolicyStats` (`pkg/cli/cli_show_security.go`) constructed
  `dpuserspace.NewPolicyCounterReader` inside the per-policy call, so
  `show security policies detail` took one full `ReadAllPolicyCounters`
  snapshot (Manager mutex, O(C) index + O(P) walk) per policy — the
  O(P*(P+C)) cliff #3965/#4344 removed from hit-count, brief, gRPC and
  Prometheus — even when policy-stats was off and nothing was read. Both
  call sites also discarded the returned `(statsDisabled, readErr)`, so
  the #8177 stats-disabled note and the #3408 read-failure warning the
  gRPC detail renderer prints never appeared on the console.
  `showPoliciesDetail` now builds the reader ONCE, only when some policy
  will actually be read (`anyPolicyNeedsCounterRead`: policy-stats
  enabled or any zone-pair/global policy carries `count`), adapts it via
  `cliPolicyCounterRead` (unpublished-sentinel translation, unchanged),
  and passes it into `cliPolicyStats`. The two call sites accumulate into
  shared `statsDisabledDetail`/`readErr`, and after all policies the view
  prints the byte-identical #8177 note and the gRPC-worded #3408 warning.
  With stats off and no `count` policies no snapshot is taken at all.
- **File(s)**: `pkg/cli/cli_show_security.go`,
  `pkg/cli/cli_show_policies_detail_reader_16693_test.go` (new),
  `docs/log/16693.md`.
- **Validation**: New counting-fake tests (P=100 detail: exactly 1
  `ReadAllPolicyCounters`, 0 per-policy fallback calls, bulk values for
  zone-pair + global rows; hit-count control still exactly 1; stats-off
  with no `count`: 0 snapshots and the byte-identical note counting all
  6 policies; mixed count policy: 1 snapshot, live stats, note counts 5;
  bulk failure and non-bulk fallback failure both print the warning;
  fallback values still render). RED-on-base (production file stashed):
  the snapshot-count, stats-off, note and warning cells FAIL pre-fix;
  fallback-values cell passes both ways (control). Post-fix all 9 tests
  pass. `go vet ./pkg/cli/` clean.
- **Residual**: None. Snapshot gating scans the unfiltered policy set, so
  a zone-pair-filtered detail view whose only `count` policy is filtered
  out takes one (single) snapshot it does not consume — bounded O(P+C),
  not the per-policy cliff.
