- **Timestamp**: 2026-10-27
  - **Action**: Collapsed the duplicated NPTv6 external-prefix ownership surface (#15191 zone-less vs #16015 zoned) onto one representation. Added `Nptv6External { prefix: PrefixV6, from_zone }` with a single `contains(addr, zone)` (zone-blind on `None`, wildcard/exact on `Some`), built once as `Arc<[Nptv6External]>` in `Nptv6State::try_from_snapshots` and exposed via `externals()` / `external_count()` / `owns_external(addr, zone)`. Deleted `external_prefixes`, `external_prefixes_zoned`, the free `nptv6_prefix_contains`, and `nat/source/synced.rs::ipv6_prefix_contains`. `SourceNatRule::nptv6_externals` and `SyncedSourceNatDomains` now carry/borrow the shared externals (`Option<&[Nptv6External]>`, `Copy` preserved); synced callers pass the state's externals and query zone-blind. `wire_nptv6_overlap_peers` takes the shared `Arc` directly (no second `Arc::new` wrap). Added `PrefixV6::from_addr_len` so the snapshot build needs no `IpNet` detour (third containment copy in `PrefixV6::contains` is now the only prefix math).
