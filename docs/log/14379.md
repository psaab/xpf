# Issue #14379 — `urlLeafIndices` has no `target` case: bare `target <url>` RPM spelling bypasses AST redaction

## Mechanism

`pkg/config/ast_redact.go:urlLeafIndices` keyed URL redaction on the leaf
name: `url`/`url-template`/`checkip-url` unqualified, `server`/
`update-server` gated on `dynamic-dns`, `path`/`hostname` on
`feed-server`, `endpoint` on `wireguard`, `archive-sites` special-cased.
There was no `target` case.

The RPM probe target (`services rpm probe <p> test <t> target ...`) is
installed by `compiler_services.go` in three spellings — bare
`target <url>`, `target address <url>`, `target url <url>` (plus the
block/grandchild forms of the latter two, which flatten identically).
Only `target url <url>` contains a `url` token, so only it was redacted.
The bare and `address` spellings (folded scope DR4-H7-ext) flattened to
`[..., "target", <url>]` / `[..., "target", "address", <url>]` and
rendered the credential verbatim through `RedactedClone` on every AST
display surface (REST show/export/search/rollback, gRPC
`ShowConfig`/`ShowCompare`/`ShowRollback`, on-box `show configuration`),
while the typed route redacted the same value
(`RPMTest.MarshalJSON` → `RedactURL`). The #8104 census mapped
`RPMTest.Target` only to the `target url "%s"` spelling, so its
behavioural verdict passed while the other spellings leaked.

## Change

- `pkg/config/ast_redact.go`: add a `target` case to `urlLeafIndices`,
  gated on an `rpm` ancestor (mirroring the `server`/`dynamic-dns`
  gate). All tokens after `target` are claimed: the `address`/`url`
  keyword tokens are not URLs so `RedactURL` returns them unchanged,
  and it is idempotent on the value the `url` case already claimed, so
  `target url <url>` keeps its existing redaction. A credential-free
  value (`target address 10.0.0.1`) is a `RedactURL` no-op.
  `secretIndices` untouched. Because `findRedactedURL` shares
  `urlLeafIndices`, the symmetric commit-ingest guard (refuse a
  re-committed redacted URL) extends to the bare/`address` spellings
  with no separate change, and `FormatCompareRedacted` (via
  `fingerprintRedactedClone`) inherits the fix the same way.

## Risk

- A `target` leaf under an `rpm` ancestor that is not a URL (IP,
  hostname) is fed to `RedactURL`, which is a no-op without a
  credential-bearing component — verified by the credential-free
  controls. Non-RPM `target` leaves are not claimed.
- Behaviour delta: a redacted export's RPM bare/`address` target line
  is now refused on re-commit (previously it would have silently
  installed the `<redacted>` URL) — the intended #6703 symmetry.
