# #17066 — single trap-version dispatch in pkg/snmp

- **Timestamp:** 2026-10-27
- **Branch:** `fix/17066-campaign`
- **File(s):** `pkg/snmp/traps.go`, `pkg/snmp/README.md`, `pkg/snmp/traps_version_3948_test.go`, `pkg/snmp/agent_addr_9123_test.go`, `pkg/snmp/agent_vrf_11427_test.go`, `pkg/snmp/trap_ifadmin_16778_test.go`, `pkg/snmp/trap_target_normalize_13127_test.go`, `pkg/snmp/trap_defer_v1_9917_test.go`, `pkg/snmp/agent_v1_polling_5049_test.go`

## Why

Since #9917, `sendLinkTraps` owned the v1/all/default version switch and
routed v1 to a deferred worker job, but `buildLinkTrapsForVersion` kept its
own v1/all/default switch whose only production callers passed `"v2"` or a
version already routed away. Its v1/all arms and `buildLinkTrapV1` were
production-unreachable while 11 test call sites and `pkg/snmp/README.md`
treated them as the dispatch — a change made there was a silent no-op in
production. The stop-abandon `slog.Warn` block was pasted three times
(two in `trapWorker`, one in `countAbandonedTraps`).

## What

- Replace `buildLinkTrapsForVersion` with
  `trapKindsForVersion(version string) (v1Deferred, v2c bool)` — the sole
  switch on trap-group version in non-test `pkg/snmp`. `sendLinkTraps`
  executes the plan: deferred v1 job (via new `deferredV1TrapJob` helper,
  folding the duplicated job literal) and/or a prebuilt v2c packet via
  `buildLinkTrap`. Dispatch order is preserved (v1 leg before v2c for
  `all`), so emitted traps are byte-identical apart from the pre-existing
  randomized v2c request-id and event-time uptime.
- Delete `buildLinkTrapV1`; tests now call `buildLinkTrapV1WithUptime`
  with an explicit uptime (`0`, or the event-time computation where the
  test already pinned startTime semantics).
- Fold the three stop-abandon blocks into `logTrapAbandonedOnStop(job)`;
  the `SNMP trap abandoned on stop` text now appears once in `traps.go`.
- Update `README.md` trap-version bullet (and the #5049 mention) to name
  `trapKindsForVersion` / `buildLinkTrapV1WithUptime`.
- Add `TestTrapKindsForVersion17066` pinning v1/all/v2/""/bogus plans.

## Risk

Behaviour-preserving refactor: same job order, same builders, same
event-time uptime for deferred v1, same v2c packets. Risk is confined to
readers/tests referencing the deleted helpers, migrated in this change.
