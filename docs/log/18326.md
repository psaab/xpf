# #18326 — reconcile the #8892 snapshot-shape pin at ProtocolVersion 77

## Why

`ProtocolVersion` was already 77 on `origin/master` (raised by #17099), but
`snapshotShapeVersion8892` and its golden still said 76. This is a baseline
reconciliation only: do not change `ProtocolVersion` or the Rust protocol
constant. The pin and golden must represent the current v77 snapshot structs.

## Shape adjudication

The v77 reflection walk contains 1,725 fields and computes
`c86ac9c2071f95370553709fa7d290f61951b76fb87847f8d289899365d6d279`.
The stored v76 golden was `cdcf8bdbce46b5fb42d40b5c432a64e2f080cdab24278253f543925ef8f2bc03`.

The intentional v77 shape changes called out by the issue are included in that
new baseline:

- #17229 removed `UserspaceMapPins.DnatTable` and `DnatTableV6`, retiring the
  userspace BPF DNAT steering pins.
- #18148 widened `PolicySessionRebind.IngressZone` and `EgressZone` from
  `uint16` to `uint32`, matching the full StableZoneID values used by the Go
  helper-JSON session path.

There is also a distinct Go-reflection-only shape change since the v76 source
baseline: #17237 embedded `config.RFC2136Endpoint` in both DHCP dynamic-DNS
family shapes. The walker now records the endpoint field instead of its
leaves, but Go JSON embedding preserves the flattened serialized keys, so this
is not another helper-visible wire change and does not warrant a protocol bump.

The existing v76 golden was already stale relative to the #8892 reflection
shape before this reconciliation; this update records the current complete
shape rather than attributing that prior drift to #18326. No protocol field,
wire behavior, or Rust version constant is changed here.

## Change

- Updated `snapshotShapeGolden8892` to the measured v77 digest above.
- Updated `snapshotShapeVersion8892` from 76 to 77 and documented the
  reconciliation; `ProtocolVersion` remains 77.

## Validation

- On the unmodified `origin/master` worktree, the named shape cell failed
  because `ProtocolVersion` was 77 while the shape pin was 76.
- `go test ./pkg/dataplane/userspace -run '^TestSnapshotShapeIsPinnedToProtocolVersion8892$' -count=1`
  — passed with the reconciled golden.
- A temporary exported field added to a walked snapshot struct made the same
  named cell fail on the changed digest; the field was removed afterward.

## Risk

This does not change the wire or bump the protocol. It aligns the reflection
golden and its version pin with the existing v77 baseline. Future changes to
walked Go types continue to require explicit shape adjudication at the guard.
