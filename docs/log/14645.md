# #14645 — Native GRE outer-fragment reassembly

## Defect
Native GRE could not receive an outer-fragmented datagram: the head
reached the helper and failed decap (`packet_trimmed_len` refuses a
truncated inner), tails went to the kernel on the local arm (TUN anchor
only, no GRE terminator) or were refused on the interface-NAT arm. Silent
loss, no xpf counter.

## Fix
- Shim (`userspace-xdp`): `ParsedPacket.is_fragment` (IPv4 flags/offset;
  IPv6 via new `ExtWalk.fragment_seen`, atomic fragments excluded) and
  host-executed `gre_classify::native_gre_fragment_stays_on_helper`.
  Fragmented native-GRE packets skip session/local/interface-NAT/degraded
  kernel passes and fall through to XSK. Whole GRE and non-native tails
  unchanged.
- Helper (`userspace-dp`): new bounded per-worker `gre_reassembly` pool
  (64 datagrams, 64 KiB/datagram, 32 fragments, 10 s; overlap, oversize,
  capacity, timeout and malformed are counted drops in
  `GRE_OUTER_FRAG_DROPS`), wired into `stage_native_gre_decap`; completed
  datagrams are rebuilt unfragmented (v4 header checksum/length repaired,
  v6 Fragment header removed and next-header patched to GRE) and decapped
  exactly once. Buffered fragments recycle with no other adjudication.
- Counter surfaced Rust -> Go -> Prometheus:
  `gre_outer_frag_drops_total` / `xpf_userspace_gre_outer_frag_drops_total`.

## Tests
`tests_gre_outer_frag_14645`: IPv4 and IPv6 outer split head+tail
reassemble to exactly one byte-identical decapped inner (whole-decap
controls pass, head alone does not decap); shim truth table asserts a
native-GRE local tail stays on the helper (not `cpumap_or_pass`);
overlap is a counted drop. Protocol round-trip + Go metrics wiring added.
