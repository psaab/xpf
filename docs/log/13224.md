# Issue #13224 — complete startup RA goodbye state

## Why

`reconcileRGState` only considered inactive RGs with configured RA interfaces. For an inactive RG with no RA interfaces, it rebuilt all RA configs on every two-second reconcile and never cleared the cold-boot cleanup debt. An RG that booted Active likewise never recorded that cold-boot cleanup was inapplicable, so a later runtime demotion could incorrectly start a cold-boot goodbye.

## What

- Marked startup goodbye complete for active RGs and for inactive RGs whose filtered RA interface list is empty.
- Kept asynchronous goodbye retries unchanged for non-empty inactive RGs; failed withdrawals still retain retry debt.
- Added `TestReconcileStartupGoodbyeDoneEmptyAndActive13224` covering both empty-RA inactive and initially active RG cases.

## Risk
