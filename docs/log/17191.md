# #17191 — One spelling table for the spelling gates + memoised verdicts

- **Timestamp**: 2026-10-27
- **Action**: Consolidated the two independent spelling tables of the schema spelling gates into the single `gateSpellingForms()` table (R4-Q21-05). The differential gate's `gateSpellingsMulti`/`gateSpellingsScalar` variables and the `forms` map inside `spellingVerdicts`, plus `slotEscapeForms()`' own A–E (plus G) literals in the slot-escape gate, are gone. Each `gateSpellingForm` row now carries the name, the differential verdict author (zero/one/two compiled-output probes), the slot-escape commit author, and explicit per-gate parameters (`repeated` for the scalar exclusion, `slotEscapeOnly` for G, `mixedModifierExempt` for F). `gateComparisonSpellings(g)` derives the differential's comparison set (multi/scalar/modifier) from the table, and both `TestSchemaSpellingDifferentialGate` and `gateLeafCompared` consume it — the coverage helper no longer re-implements the compared set selection. `spellingVerdicts` is memoised behind a mutex with a computation counter (`spellingVerdictComputationCount`), so the verdict matrix runs once per (leaf, value pair) per package run across the differential, coverage and members-census callers. F-hier-mixed, previously present only in the differential, is now probed by the slot-escape sweep as well (but stays out of the differential's scalar set via the explicit `scalarExempt` parameter — the pre-#17191 scalar set was {A,B,D}, and a first run that derived scalar as multi-minus-repeated scored F at every scalar leaf and manufactured shape-dependent-drop findings there, e.g. `chassis cluster redundancy-group <*> interface-monitor` A–E=keep/F=drop where F's child is a modifier) (single value rides the identifier slot; two values are identifier + one-per-statement children). G-hier-one-child-multi-token stays slot-escape-only (the differential deliberately does not score it; the walker refuses it at gated leaves, #16535, which is CLOSED — its form is already in both gates as required there). No production code changed.
