## Mechanism and change

- **A44-03** — `clampBindToLoopback` classified family with `net.ParseIP(host)`, which returns nil for a zoned literal `fe80::1%ge-0-0-0`, so the v6 leg clamped to `127.0.0.1` and duplicated the v4 leg; `ReconcileHTTPSAddrs` then rejected the duplicate / never converged and the #6803 owner re-drove forever. Fix: zone-aware classification via `netip.ParseAddr` in both `hostIsLoopback` and `clampBindToLoopback` (zoned/link-local v6 → `::1`), and de-duplication of the clamped set in `clampBindsToLoopback`. Authenticated and genuine-loopback binds unchanged; fail-safe unparseable handling preserved.
- **A44-04 residual** — `s.httpsBindHosts` was captured once from the `NewServer` Config (`effectiveHTTPSAddrs(cfg)`). A server constructed single-stack and later grown via `ReconcileHTTPSAddrs` to dual-stack still minted (fresh durable dir) a cert covering only the construction host. Fix: `ReconcileHTTPSAddrs` updates `httpsBindHosts` to the desired set, and `bindHostsForCertGen` unions configured hosts + the requested `bindHost` + live/requested leg hosts (de-duplicated, deterministic order). A valid durable pair is still loaded as-is (#1916, no TOFU churn); only a fresh mint / out-of-window re-mint sees the widened set.
- **A44-05** — `collectInterfaceCounters` emitted per name from `allInterfaceNames`, which unions config base names (`ge-0/0/0`) with zone unit names (`ge-0/0/0.0`); both resolve via `ResolveKernelIfName` to the same ifindex, double-counting unit-0 interfaces in any sum. Fix: iterate names sorted (deterministic label), resolve, and emit only the first name per ifindex. Read-error accounting (#3464/#13273) unchanged: a missing netdev still bumps the error counter before the dedup check; a duplicate whose first name failed to read does not emit.

NOT changed: `allInterfaceNames` itself (REST `/interfaces`, `/statistics/interfaces` legitimately list both spellings as rows — only the Prometheus counter path double-counts), the durable load-as-is cert contract, positional leg identity, and any non-web-management bind path.

## Risk

- Clamp: a zoned v6 no-auth bind now lands on `[::1]` instead of the duplicate `127.0.0.1` — intended; authenticated zoned binds untouched.
- Cert: widened mint SANs only affect fresh/re-minted durable certs; existing valid pairs are not churned, so no new TOFU break. `bindHostsForCertGen` reads `httpsLegs`/`httpsServers` — all production callers hold `tlsCertificateMu` or `lifeMu` (construction/monitor/reconcile paths); direct test callers are single-threaded.
- Metrics: `xpf_interface_*` for a unit-0 interface now appears once (label = lexicographically first spelling, e.g. `lo` over `lo.0`); sums no longer double-count. Operators alerting on the `.0` label for unit 0 should switch to the base label.
