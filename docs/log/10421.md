# Issue 10421 — VRF miss-terminator startup recovery

## Scope

Keep the existing #9819 reconcile-time installation, then reassert the managed
pref-2000 IPv4 and IPv6 l3mdev-unreachable rules immediately after networkd
activation and again at the end of the core apply after management-VRF rebind.
Retain a startup-tail reassert after the synchronous startup apply returns
because networkd/link activation can finish foreign-rule cleanup after `Apply`
returns.
