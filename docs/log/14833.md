# #14833 — build/test scratch must not use /tmp, /dev/shm, or /var/tmp

- **Issue**: #14833 — repo build/test scratch pinned to /var/worktrees
- **Branch**: `fix/14833-campaign`
- **Worktree**: `/var/worktrees/wt-14833`
- **Base**: `13905b0650`

## Why

User directive 2026-10-17: ALL cargo/rust/go build scratch under
/var/worktrees only. The Makefile `test-memlock-guards` target pinned
`TMPDIR=/tmp` (justified by the 108-byte AF_UNIX `sun_path` limit);
`scripts/mutate-selftest.sh` defaulted to /var/tmp; many scripts and
test harnesses defaulted `mktemp`/`TMPDIR` to /tmp or /var/tmp; and no
aggregate environment stopped Go/Python/cargo subprocesses from falling
back to those roots. /var/worktrees/.cache/go-tmp is 28 chars, so the
sun_path concern does not apply (modelled worst guard socket: 71 bytes).

## What

- `Makefile`: export `?=` defaults `TMPDIR=/var/worktrees/.cache/tmpdir`,
  `GOCACHE=/var/worktrees/.cache/go-build`, `GOTMPDIR=/var/worktrees/.cache/go-tmp`,
  `CARGO_TARGET_DIR=/var/worktrees/.cache/cargo` (caller env wins; dirs
  created at parse). `test-memlock-guards` now uses the go-tmp pin.
  `build-userspace-dp` installs from `$(CARGO_TARGET_DIR)`; `clean`
  removes it too.
- `scripts/run-selftests.sh`: same four defaults exported for all child
  legs (python tempfile, shell mktemp, go test inherit them).
- Retargeted every `${TMPDIR:-/tmp}` / `${TMPDIR:-/var/tmp}` default and
  local artifact default in the audited set (scripts/*, test/incus/*,
  test/mutation/shim-ext-parity-acceptance.sh) to
  `/var/worktrees/.cache/tmpdir`; `/dev/shm` cargo defaults to
  `/var/worktrees/.cache/cargo*`; cluster lock defaults
  (`test/incus/cluster-lock.sh`, `wg-interop.env`, mouse-latency lock)
  moved to the same tmpdir (all consumers read the shared defaults).
- `scripts/mutate.sh`: restored `mkdir -p "$WORK"` after retargeting
  `MUTATE_WORKDIR` (removing it would break per-cell backup/restore).
- `scripts/dist/install.sh`: only creates the pinned dir when TMPDIR is
  unset; a caller-supplied TMPDIR is used as-is.
- New `scripts/scratch-pinning-selftest.sh` (wired into
  `make test-mutate-lib` and `scripts/run-selftests.sh`): audits 50 files
  for forbidden defaults and bare mktemp, asserts the positive pins, and
  models the AF_UNIX socket budget. Remote-VM /tmp, guest /var/tmp, and
  fixture literals are explicitly out of scope.

## Validation

### RED before the fix

New selftest copied onto a pristine HEAD worktree: exit 1 —
`FAIL: forbidden scratch default in Makefile` (`TMPDIR=/tmp`),
`scripts/mutate-selftest.sh` (`/var/tmp`), `scripts/mutate.sh`
(`MUTATE_WORKDIR:-/var/tmp/...`), `scripts/miri-leg.sh`, etc.

### GREEN after the fix

- `sh scripts/scratch-pinning-selftest.sh` — exit 0, 50 files audited,
  modelled socket 71 bytes < 108.
- `make test-mutate-lib` — exit 0 (includes the new selftest).
- Targeted selftests with pinned env, all exit 0: mutate-selftest,
  go-test-json-selftest, check-no-ci-claims-selftest,
  check-upgrade-docs-selftest, harness-census-selftest,
  selftest-census-selftest, ignored-cell-census-selftest,
  with-cluster-selftest (10/10).
- `go test ./pkg/memlockcensus/ -count=1` with
  `TMPDIR=/var/worktrees/.cache/tmpdir GOTMPDIR=/var/worktrees/.cache/go-tmp`
  — ok; Go test temp dirs are created under the pinned go-tmp.
- Privileged `sudo make test-memlock-guards` was started twice and
  terminated by the harness timeout while still in the Go build phase
  (log shows only the package line; no socket/bind failure) — NOT a pass;
  recorded here, not claimed. The sun_path risk is covered by the
  modelled-path check above.
- Pre-existing, base-attributed: `test/incus/cluster-cell-selftest.sh`
  Group 10–12 fails identically on pristine HEAD
  (`PROJECT_ROOT: unbound variable` in its fixture) with and without
  this change; `make test-go` exceeds a 120s probe timeout in
  test-race-dp on this loaded box (not run to completion).

## Risk

- `CARGO_TARGET_DIR` default moves cargo artifacts out of
  `userspace-dp/target` for Makefile-driven builds; direct `cargo`
  invocations are unchanged, and `clean` removes both locations.
- Cluster lock path change is a cutover: all in-tree consumers source
  the same `cluster-lock.sh` defaults; an operator shell holding the
  old /tmp lock during the switch would not exclude a new-path holder
  (dev-box only, no cluster mutation in this change itself).
