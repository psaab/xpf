# #13928 — preserve host-bound packets on VLAN child XDP hooks

## Why

Linux strips the 802.1Q header before generic XDP executes on a VLAN child. The shim then sees the configured child traffic as VID 0; publishing TAGGED_ONLY on that child causes its local-destination guard to drop legitimate host-bound unicast, including traffic to addresses that are not interface-SNAT targets.

## What

Publish TAGGED_ONLY only for the tagged VLAN's bind parent in both the Go shim-map builder and Rust worker snapshot builder. The parent still rejects truly untagged VID-0 local-destination traffic; VLAN-child hooks no longer mistake kernel-untagged, tagged-on-wire traffic for untagged parent ingress. Updated the builder/map regression, added an XDP test-run child-like local-destination control, and covered Rust worker scope parity. Documented the parent/child distinction in the dataplane architecture.
