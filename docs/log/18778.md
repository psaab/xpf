# #18778: make test-go passes no -timeout; a cut-off package reads as an ordinary failure

- **Timestamp**: 2026-11-01
- **Action**: `make test-go` ran both go-test legs with go test's 10m default `-timeout`. At load 35-47, pkg/daemon reaches it after about 3546 tests (seat L, PR #18770), and the package aborts mid-run like the #17282 / #18769 panics.
- **Action**:
  - `GOTEST_TIMEOUT ?= 60m`, passed explicitly as `-timeout $(GOTEST_TIMEOUT)` on both test-go legs.
  - `scripts/go-test-json.sh` watches the passed-through output on both paths. On go test's `panic: test timed out` it prints a VOID banner and exits 3, so a timeout is neither a pass nor an attributable failure. Every line still passes through unchanged.
  - `TestMakefileTestGoRunsAllLegs16467` now requires the timeout on both legs (and its synthetic fixtures carry it).
  - `scripts/go-test-json-selftest.sh` gains a real-timeout case on both paths, plus a control.
- **Validation**:
  - The selftest passes 17/17.
  - Mutant: a watcher that never reports a timeout is KILLED by the three timeout rows.
  - `go test ./pkg/docsref/` passes.
- **File(s)**: `Makefile`, `scripts/go-test-json.sh`, `scripts/go-test-json-selftest.sh`, `pkg/docsref/testgo_aggregate_16467_test.go`
- **Timestamp**: 2026-11-01 (review fold, PR #18779; seat L)
- **Action**:
  - Sticky VOID. A `keep()` helper in the test-go recipe never overwrites status 3, so the recipe ends `Error 3` even if a later leg fails (make itself exits 2; measured: `Error 3`, make rc=2). The #16467 census requires `keep()` before the first leg.
  - `scripts/mutate.sh` passes `GOTEST_TIMEOUT=$((MUTATE_CELL_TIMEOUT*3/4))s`, so go's dump naming the stuck test survives the external kill.
  - The test-race-dp legs get `-timeout $(GOTEST_TIMEOUT)` and run through the new `scripts/go-test-watch.sh`. It takes the full command line, so the recipe keeps the literal `test -race` text that the #16715 / #6743 censuses parse.
  - The watcher is shared (`scripts/go-timeout-watch.awk`). It requires go's real two-line shape (column-0 `panic: test timed out` followed by `running tests:`), names the package from go's `FAIL<TAB><pkg>` line, and says that other packages' failures are still real.
  - New false-positive selftest rows: a failing test printing "timed out" both unindented and indented is not VOID. A go-test-watch.sh row is added. The stale header comment is fixed. `docs/engineering-style.md` now says what a make consumer observes.
- **Mutants**: all KILLED. An over-broad `/timed out/` watcher and a watcher without the `running tests:` lookahead are both killed by the false-positive rows; a watcher that never exits 3 is killed by the timeout rows.
- **Validation**: go-test-json-selftest passes 20/20 and pkg/docsref passes. The pkg/daemon race-gate census still parses the recipe; its one pre-existing ConnectedDrain gap is unchanged from master.

- **Timestamp**: 2026-11-01 (seat AC fold)
- **Action**: the watcher missed three real go-test timeouts. Each shape was measured with go 1.27.2 in a throwaway module before the predicate was written:
  - `-json` with several packages: test2json interleaves packages line by line (582 package switches in a two-package run), so the line after a panic is often another package's. Detection now runs after the leg, over that leg's own slice of the appended side file (offset recorded first), tagged by package (`-v TAGGED=1`).
  - a hung Example: the alarm fires with no test in the running list, so the panic is followed by a blank line and the goroutine dump, with no `running tests:`. The second signal is go's exact sequence: blank line, `goroutine N [running]:`, then `testing.(*M).startAlarm.func1()`.
  - a hung TestMain: the alarm is armed inside `m.Run`, so it never fires. cmd/go kills the binary at `-timeout` + 1m and prints `*** Test killed with quit: ran too long (1m1s).`, then the package `FAIL` line.
  - `mutation_timed_out` (mutate-lib.sh) now calls the same awk. Its old single-signal grep voided a test that merely printed the panic line.
  - The VOID banner names every timed-out package and its shape.
  - The `mutate-selftest.sh` timeout fixture is corrected to go's real output: it had `running tests:` unindented, which no go release prints.
  - Selftest rows added: an interleaved `-json` stream (via a fake go), a clean leg appended after a timed-out one, a hung Example on both paths, a hung TestMain on both paths (run concurrently, about 62 s), false positives for the kill line and a stray alarm frame, and three mutate-lib rows.
