# #13967 — Preserve peer BA classification across fabric transit

## Why

A packet redirected over the HA fabric arrives at the egress node with its
fabric parent ifindex. The V2 scoped source stamp already identifies the peer's
logical ingress unit, but TX BA classification discarded that scope and looked
up the fabric parent's classifier binding instead. Packets therefore fell
through to default queue and loss-priority rewrite; V1 zone-only and unstamped
arrivals still require this documented default fallback.

## What

Validated V2 fabric scope stamps already identify the peer's logical ingress
unit. The receive path now keeps that identity in packet metadata and uses its
classifier binding for BA queue and loss-priority selection, preserving the
direct-ingress result across fresh, cache-seed, and cache-hit paths. Zone-only
V1 and unstamped arrivals still lack a recoverable interface identity; their
egress default treatment remains explicit in the commit-time warning and docs.
