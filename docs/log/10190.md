- **Action**: Kept the allocator key and cross-allocator peer guard unchanged.
  Added the minimal local ownership checks: address-only admission probes the
  exact PAT reverse identity, and PAT admission probes the exact address-only
  reverse identity. The PAT side uses an O(1) `PatReverseKey` count index,
  updated at every PAT live-record insertion and the shared live-record unlink.
  A colliding PAT claim is held while probing so the recycle ring cannot return
  the same rejected port forever; rejected claims are released on success or
  exhaustion. Persistent PAT lease reuse performs the same check before
  reactivating a lease and falls back to an unpinned fresh allocation.

- **Action**: Rejected three broader fixes. Widening `allocator_key()` would
  split the intentionally shared allocator and require lease carry-over
  migration. Widening the same-allocator peer guard would change its deliberate
  skip semantics and over-reject legitimate shared-rule traffic rather than
  model the two ownership domains. Adding a bitmap/cross-occupancy bit would
  conflate PAT's address/port occupancy with the remote-specific address-only
  reverse token and would alter teardown semantics. The local exact-index
  checks close only the missing domain boundary.
