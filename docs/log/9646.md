## Design

- **The preflight.** It runs in `syncUserspaceClassifierMapsLocked` after the test hook and before the ingress-iface sync, so a refusal has written nothing. The desired set is built once and handed to `syncLocalAddressMapsWithSetsLocked`, so there is no second netlink dump. A set of exactly 8192 fits.
- **Carve-outs, and only these two:**
  - **Fail-closed sync** (the same-plan and deferred-startup applies): the maps still hold the enforced plan, so ctrl stays and the apply returns the named error.
  - **Status poll:** it re-syncs the snapshot the helper already enforces every second, so host address growth past the capacity would otherwise drop all transit on the next tick. It keeps maps and ctrl and alarms once per transition, via the latch. A fitting sync clears the latch.
- **Not carved out:** the retain/rollback path (`retainPreviousClassifierPlanLocked`). A refused publish has already mutated the maps, so a failed rollback still fails closed. A new-plan bootstrap programs ctrl disabled first.
- **Drift:** `TestLocalAddressMapCapacityMatchesTheShim9646` parses both shim declarations.
- **Kept:** add-before-prune (`TestSyncLocalAddressMapsAddsBeforeRemovingStale`). The preflight counts the desired set only; a map filled by stale keys still fails its update as before.
