# #13243 - Count destination NAT sessions without an egress-zone clause

- **Timestamp**: 2026-10-15
- **Action**: Indexed active DNAT sessions by ingress zone in both the shared destination-rule renderer and CLI destination summary. Destination rule-sets with an empty `ToZone` now use the ingress-only total; rule-sets with an egress zone retain their exact zone-pair count. Updated the renderer fixture to match compiled destination-NAT configuration and added a CLI regression.
- **Validation**: `TestRenderDestRuleDetailLoadedGolden` was RED before the fix: with a real-shape destination rule-set (`ToZone == ""`) and one active DNAT session, it rendered `0`. It passes with the fix and expects `1`. `go test ./pkg/natshow/ ./pkg/cli/ -count=1`, `go vet ./pkg/natshow/ ./pkg/cli/`, and `go build ./...` pass.
- **Risk**: Low. The from-zone aggregate is used only when the destination rule-set has no egress-zone clause; existing zone-pair behavior and quarantined-counter handling remain unchanged.
