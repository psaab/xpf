# #16749: BGP leaves chained under a valueless flag bypassed strict validation

- **Timestamp**: 2026-10-25
- **Action**: A flat-set run headed by a valueless BGP flag
  (`passive`, `remove-private`, `log-updown`) nested its tail under the
  flag (`passive { hold-time 1; }`), where neither the strict walker
  (childless untyped leaf: no typed/scalar branch) nor the #10707
  advisory walker (continues at a childless leaf) looked. The BGP
  compilers hoist the chain back to the container
  (`expandFlatRun`/`flattenChainedChildren` at BGP top and group,
  `expandFlatRun` at neighbor) and apply it, so
  `set protocols bgp group G passive hold-time 1` committed clean,
  compiled `HoldTime=1`, rendered `neighbor ... timers 1 1`, failed
  frr-reload.py, and degraded every later reload (#14585); chained
  unknown keywords (for example a dropped `authentication-key-chain`)
  drew no signal. Fix: when a valueless childless leaf has children
  inside a BGP top/group/neighbor container, `walkSchemaNode` now
  validates those children at the parent schema
  (`pkg/config/schema_bgp_flatrun_16749.go`) — the compiler's own
  expanded view — so a chained typed leaf strict-rejects with its
  validator's message exactly as the separate-line spelling does, and
  `warnUnknownRoutingLeaves10707` descends the same way so a chained
  unknown keyword warns while a chained known leaf stays silent. A
  hold-time chained at BGP top level has no parent leaf: it is
  explicitly dropped by the compiler and warned by #10707. As the
  #14585 belt, `pkg/frr` now omits the `timers` line (with a warning)
  for a hold-time of 1/2 or above 65535 arriving on the tolerant
  load/sync path instead of rendering a line bgpd refuses. Valid
  chained values (`passive hold-time 9`) commit, compile, and render
  unchanged; compiler hoisting itself is untouched.
- **File(s)**: `pkg/config/schema_bgp_flatrun_16749.go` (new),
  `pkg/config/schema_walk.go` (chained-flag arm),
  `pkg/config/compiler_openworld_10707.go` (chained descent),
  `pkg/config/compiler_protocols.go` (explicit top-level drop),
  `pkg/frr/protocols_render_bgp.go` (timers render belt),
  `pkg/config/bgp_flatrun_flag_16749_test.go` (new),
  `pkg/frr/bgp_holdtime_belt_16749_test.go` (new),
  `debian/changelog`.
- **Residuals**: (1) `TestLeafRunDifferentialGate9156` fails on three
  pre-existing non-BGP rows (dhcp-relay, two PKI rows); measured
  byte-identical on the base commit `af577e83d0`, untouched here. The
  #9156 gate excludes valueless-flag heads from its population by
  design, so the strict-path column for this issue is pinned by
  `TestBGPFlagStrictColumn9156_16749` instead. (2) Chained unknown
  keywords remain warn-only (open-world BGP subtree), not a strict
  rejection, matching the #10707 contract. (3) The packed braced
  spelling (`passive hold-time 1;` on one braced line) stays rejected
  by the pre-existing #8437 fused-statement gate, unchanged.
