# #18816 — GRE 5615 cells follow #14642 suppressed-TE contract

## Contract and cause

PR #14821 / #14642 (`b48ca3993d`) suppresses ICMP Time Exceeded for tunnel-decapsulated inners marked with `TUNNEL_DECAP_INGRESS_FLAG`; the error must not be routed using the synthetic zero-MAC header. The three GRE 5615 cells were stale: each asserted one prebuilt TE, while the intended result is no TE and no queued forward. The session-miss companion behavior is pinned by #14643; the flow-cache-hit arm already drops an expiring packet when its TE is suppressed.

The session-hit arm called `build_local_time_exceeded_request`, but treated `None` as a non-expiring packet and fell through. For a suppressed TE this left a forward request queued. The arm now keeps the independent inner-packet TTL result and recycles/continues when the packet would expire but no TE was built, matching the fail-closed contract without changing buildable-TE or non-expiring paths.

## Change

- In `tests_gre_local_delivery.rs`, all three `*_reads_inner_ttl_5615` cells now expect `prebuilt_te_count == 0` and an empty total forward queue. The outer TTL=64 premise, reachability counters, session/flow-cache seed premises, and session-miss no-install assertion remain pinned. Comments identify the #14642 contract and clarify that suppression hides the TE builder's own TTL read.
- In `poll_descriptor/mod.rs`, session-hit TTL handling distinguishes an expiring packet from a non-expiring packet even when the TE builder returns `None`. An expiring, suppressed/unbuildable reply recycles the descriptor and skips later forward processing.

## Verification

- RED before the change: all three cells failed their old `prebuilt_te_count == 1` assertion with an actual count of 0.
- GREEN after the change and after mutant restoration: each of the three fully qualified tests passed (1 passed; 0 failed each).
- Full GRE local-delivery module: 63 passed; 0 failed.
- Corrected mutant: temporarily removed both the `can_generate_icmp_error_reply` tunnel flag guard and the independent v4 builder guard. All three tests failed with `prebuilt_te_count` left 1, right 0. Removing only the first guard is insufficient because the v4 builder independently suppresses the TE. Both guards were restored, and the three exact tests passed again.

## Risk

Only TTL/hop-limit-expired session hits whose TE cannot be built now recycle before the forward queue instead of falling through. Built-TE replies and non-expiring session hits retain their existing paths. No product change is made to the GRE decapsulation flag or TE suppression gates.
