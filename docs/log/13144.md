# #13144 — align stamped host-inbound overrides with runtime resolution

- **Source**: deep-review finding D2-13, validated by three-way adversarial research.
- **Files**: `pkg/config/host_inbound_dhcp_scope_6519.go`,
  `pkg/config/host_inbound_st0_stamp_13144_test.go`,
  `pkg/config/poisoned_zone_host_inbound_12834_test.go`.

## Why

On the current base, `ResolveInterfaceHostInbound` already uses the shared
`InterfaceUnitRefKeys` expansion and fans a bare `st0` override down to a
#7949 bind-interface-only `st0.0`. The per-zone precomputed override stamp,
which feeds `ZoneConfig.InterfaceHostInboundEffective`, still fanned down only
to configured units, so diagnostics fell back to zone-level services instead.
The stamp also ignored zone/interface quarantine, allowing diagnostics to expose
contested overrides that runtime resolution rejects.

## What

Use the shared `InterfaceUnitRefKeys` expansion when stamping bare overrides,
including materialized secure-tunnel units, and apply the same excluded-zone,
contested-interface, and cross-zone owner guards as runtime resolution. Add
regressions for bind-interface-only `st0` fan-down and contested-unit parity;
update the poisoned-zone regression to assert that contested ownership stays
fail-closed for the healthy zone's stamped view too.

## Validation

- Regression tests on pristine `origin/master` fail: runtime correctly resolves
  `st0.0` to `[ping]`, but the stamp returns zone-level `[ssh]`; the contested
  interface stamp likewise reports the losing zone's `[ping]` override.
- Targeted regressions and related poisoned-zone tests:
  `go test ./pkg/config/ -run 'Test(BareSt0OverrideFansDownToBindOnlyUnit13144|ContestedUnitOverrideAbsentFromStampedView13144|PoisonedZoneStampedOverrideAbsent12834|PoisonedZoneBareHostInboundDoesNotDisplaceHealthyOwner12834|NonPoisonedZoneBareHostInboundStillResolves12834)$' -count=1`: PASS.
- Targeted regressions repeated 10 times:
  `go test ./pkg/config/ -run 'Test(BareSt0OverrideFansDownToBindOnlyUnit13144|ContestedUnitOverrideAbsentFromStampedView13144)$' -count=10`: PASS.
- `go vet ./pkg/config/...`: PASS.
- `GOMAXPROCS=4 go test ./pkg/config/ -count=1 -timeout=30m -parallel=8`: PASS
  (`883.167s`).

## Risk

The stamped per-zone view now fails closed for excluded zones and contested or
foreign-owned interface keys, matching the runtime resolver. No runtime policy
resolution behavior is changed.
