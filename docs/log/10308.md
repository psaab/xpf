# #10308 management/control zone-name exemption

## Scope

A security-zone label is operator-controlled metadata. It is not the identity of a
`vrf-mgmt` lifeline. The Go ingress predicate, ingress map/RSS allowlist, Rust
planning mirror, and config advisory now use interface identity for lifelines:
`fxp*`, `fab*`, `em*`, and `lo0`. A data NIC in a zone named `mgmt` or `control`
remains on the policy-adjudicated userspace path. Strict commit emits a warning
naming the zone and member; canonical lifeline members remain quiet. The daemon
apply path continues to derive `vrf-mgmt` membership from the interface-name
class.

## Revert guards

The focused Go and Rust tests are fail-on-revert cells: restoring the old
`mgmt`/`control` zone-name arms makes the data-NIC assertions fail, while the
lifeline controls continue to require the interface-name classes. The config
probe also fails if the commit-time warning is removed, renamed without the
required context, or emitted for canonical lifelines.
