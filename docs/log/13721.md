# Issue #13721

## Change

Bound P-MECH source-selector detection to the main routing table. The selector scanner now passes an `RT_TABLE_MAIN` request (`rtmsg.Table` plus `RTA_TABLE`) through a strict-check netlink socket, rather than dumping all route families/tables and filtering non-main routes in userspace. Locked capture-authority refreshes reuse a previously stamped route inventory only when config identity, tunnel identities, and FIB generation are unchanged; otherwise they fail closed without performing netlink I/O under `Manager.mu`. FIB-bump stamping also avoids an under-lock fallback dump when its unlocked prefetch no longer matches.

- Current-master runtime regression on `52e29404e`: `TestPMechLockedCaptureRefreshDoesNotDumpRoutes13721` failed as intended because the locked refresh performed one route dump. The corresponding fixed-branch tests pass.

## Residual risk

A locked refresh with changed config/tunnel identities or a changed FIB generation temporarily withholds P-MECH authority until an unlocked full build or FIB prefetch replaces the inventory. This is fail-closed and avoids route dumps under the manager lock.
