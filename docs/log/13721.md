# Issue #13721

## Change

Bound P-MECH source-selector detection to the main routing table. The check now uses a strict-check netlink socket and an `RT_TABLE_MAIN` request (`rtmsg.Table` plus `RTA_TABLE`) rather than dumping every route family/table and discarding non-main results in userspace. Existing detection of `rtm_src_len` and `RTA_SRC` remains intact. Added regression coverage for the request scope and for the route-prefetch call path.

## Residual risk

The P-MECH main-table route stream itself is still performed by its existing caller; this change specifically removes the additional unfiltered all-table/all-family selector dump. The bounded selector scan can still run from locked refresh paths, but its work is restricted to the main table rather than every VRF/table.
