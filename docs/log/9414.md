## Remedy

1. **SNMP**: `snmpInertKnobWarnings` gains a `v3` arm (the complement, by position:
   child `Name()`, the elided `v3 <kw>` / `v3 usm <kw>` on the node's own Keys, and
   the elided `usm <kw>` child), plus `engine-id`, `name`, `arp`,
   `filter-duplicates`, `nonvolatile`, `proxy`.
2. **syslog**: each skip arm in `compileSystem` records `(kind, keyword)` AT the
   skip; after the walk the recorder renders one advisory per pair. There is no
   second list: a modifier later wired into the runtime moves out of its arm and
   stops being reported. This also makes the host arm's #4303 comment ("see the S-5
   advisory path") true for the first time.
3. **Accept, never reject** (#1960): every row committed clean before.
4. **Keywords only**: no engine ID, user name, password, regex or destination name
   is rendered. The cells assert it with distinctive values, after the first run
   showed an ordinary destination name (`messages`) collides with advisory prose.

5. **The destination arms read a flat-set chain whole.** One flat-set line can
   carry several destination statements (`set system syslog host X
   allow-duplicates exclude-hostname`), which `SetPath` builds as a NESTED chain,
   and the arms read only the first statement. That loss predates #9414 and was
   invisible while every skipped modifier was inert; the advisory made it
   observable, and the whole-tree #8939 ratchet reported six NEWLY LOSING syslog
   rows. The arms now call `hoistAndSplitRun8939`, the #8939 remedy.
   **The first wiring was wrong, and the same ratchet caught it**: passed the full
   destination schema, `file <f> archive [files | no-world-readable | size]` moved
   from walked to `differs`. The hoist now uses the destination schema WITHOUT its
   `<facility> <severity>` wildcard (`syslogDestinationHoistSchema9414`), and M17
   below puts the wildcard back: KILLED by #8939 ratchet, ChainIsReadWhole (1 subtests). A facility pair nested after
   another statement on the same line is left as authored, exactly as before (not
   hoisted, and not fixed).
