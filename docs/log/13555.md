# Issue #13555: Gate BGP BFD peers on the local AS

## Why

`generateProtocols` omits the `router bgp` section unless `LocalAS > 0`, but
BGP BFD peers were accumulated whenever a BGP config was non-nil. A tolerant
load with an absent local AS could therefore render a BFD peer for a BGP
instance that FRR never received.

## What

Gate BGP BFD peer accumulation with the same `bgp != nil && bgp.LocalAS > 0`
predicate as the `router bgp` renderer. Add a regression with LocalAS zero and
a BFD-enabled peer, plus a valid-AS positive control.

## Validation

The regression failed before the fix because it observed a rendered `bfd`
stanza and peer with LocalAS zero. After the fix, `go test ./pkg/frr
-run '^TestBGPBFDNotRenderedWhenLocalASZero13555$' -count=1` passed and
`go build ./...` passed. `go test ./pkg/frr` ran but three existing tests that
launch FRR failed with `privs_init: could not setgroups, Operation not
permitted` in this environment.

## Risk

BGP BFD peers are intentionally omitted when the corresponding BGP router
section is omitted. OSPF/OSPFv3/IS-IS interface BFD rendering is unchanged.
