# #16125 — FRR verbatim protocol extraction

## What

`generateProtocolsCluster15158` (1,391 lines in one function) is split
into contiguous verbatim per-protocol renderers, one file each:

- `protocols_render_ospf.go` — `renderOSPF16125` (OSPFv2 + trailing
  virtual-link stanza)
- `protocols_render_ospfv3.go` — `renderOSPFv316125`
- `protocols_render_bgp.go` — `renderBGP16125` (the `router bgp`
  stanza only)
- `protocols_render_rip.go` — `renderRIP16125`
- `protocols_render_isis.go` — `renderISIS16125` (including its
  deliberate auth precompute before any emission)
- `protocols_render_bgp_bfd.go` — `accumulateBGPBFDPeers16125`, the
  deferred BGP BFD-peer accumulation

The caller keeps, in the historical order: BFD-accumulator setup,
VRF-suffix sanitising, the BGP valid-neighbor pre-pass (#5518 — the
single exclusion set shared by the declaration loop, the
address-family activation loop and the BFD accumulator; it must stay
between OSPFv3 and BGP emission), and the local-vs-shared BFD tail.
No invented shared helpers: `authTokenOrOmit` (#9050) and the
cluster/QNH redistribute helpers already existed and are called
unchanged. The only non-verbatim adaptation is the builder pointer
(`&b` → `b`) at the extracted functions' own call sites.

## Byte-identity gate (W1.12 grown first)

`pkg/frr/testdata/golden16125/` holds 12 complete
`buildManagedSection` renders — OSPF, OSPFv3, BGP, denied-malformed
BGP/RIP/IS-IS auth, RIP-MD5, IS-IS, all-protocols shared-BFD,
VRF-scoped all-protocols, cluster-mode and QNH — first captured from
the pre-extraction renderer on origin/master and verified
byte-identical after the extraction (`diff -r` clean).
`TestProtocolsRenderGolden16125` compares every render byte-for-byte
without needing vtysh; swapping the OSPF/OSPFv3 call order in the
caller fails it (verified), as does a single appended golden byte.

The same corpus grows the real-FRR oracle
`TestRenderedRoutingConfigAcceptedByFRR11417` (W1.12, #16206): the 8
fixtures carrying a top-level stanza run through vtysh with the
existing sentinel + invalid-keyword controls, and the test logs the
runs-vs-skips denominator (8/12 golden fixtures vtysh-validated, 4
golden-only, plus 3 hand-authored cases). CI now installs `frr` in
the Go job so the oracle runs instead of skipping there.
