# #16815: complete simple captured Junos default applications

- **Timestamp**: 2026-10-25
- **Why**: Missing predefined names made policies citing `junos-mail`,
  `junos-echo`, `junos-lpr`, `junos-ymsg`, etc. fail strict commit.
  `junos-snmp-agentx` lacked its captured 7560-second idle timeout and
  inherited the global TCP timeout instead.
- **What**: Added 17 single-term applications and four synthetic YMSG
  members, plus the set-only `junos-ymsg` bundle. Preserved the capture's
  UDP-only `junos-echo`/`junos-uucp` and UDP/111 `junos-nfs` semantics;
  these are not guesses from similarly named services. AgentX and the
  new `junos-wxcontrol` both carry `InactivityTimeout: 7560` through the
  existing userspace policy serializer. New RealAudio retains its RTSP
  ALG annotation; implementing additional ALG behavior is not in scope.
- **Provenance**: The issue-cited [Junos OS 12.1X44-D35.5 capture](https://www.51sec.org/2014/09/21/juniper-junos-pre-defined-applications-and-application-sets-details/)
  (2014-09-21) contains 159 applications and 23 sets. The checked-in JSON
  fixture transcribes every application body and set membership, with
  whitespace normalized. Tests compare protocol/port tuples, explicit
  timeouts, multi-term order, and supported set memberships to the live
  predefined tables, not another hand-built subset of new names.
  Of 75 previously absent capture names, 18 are added. The remaining
  57 (UUID/RPC-program-number applications and dependent sets, plus
  protocol-255 `junos-persistent-nat` with transport-port constraints)
  stay absent rather than being widened or partially implemented.
  `docs/feature-gaps.md` documents the complete omitted inventory.
- **Files**: `pkg/config/predefined.go`,
  `pkg/config/predefined_16815_test.go`,
  `pkg/config/testdata/junos-defaults-12.1X44-D35.5.json`,
  `pkg/dataplane/userspace/predefined_16815_test.go`,
  `docs/feature-gaps.md`, and this log.
