# #13971: emit close reasons in RT_FLOW SESSION_CLOSE

## Change

The event-stream session-close encoder left payload byte `[134]` at zero, and
Go decodes zero as `N/A`. Expiry now preserves the removed session's TCP close
class on its `SessionDelta`; the RT_FLOW projection maps RST to `TCP RST`, FIN
CLOSING/TIME_WAIT to `TCP FIN`, and other closes to `idle Timeout`. The encoder
writes the reason byte consumed by Go's existing `closeReasonName` mapping.
