# #18666: reject unconsumed suffixes after pure keyword leaves

- **Timestamp**: 2026-11-07
- **Why**: The operational gate left words after a leaf to its handler. Leaf
  handlers could ignore the suffix and return success after silently dropping
  the requested output format. The same defect affected
  `show version extra | display xml` and glued `show version |display xml`.
- **Action**: `cmdtree.ValidateOperationalGate` rejects an unconsumed suffix
  after a pure keyword leaf. A separated bare output pipe returns a
  modifier-specific syntax error; an extra trailing word or glued pipe returns
  an unknown-command error, with the existing spacing hint for glued pipes.
  The gate locates a leaf prefix in the full word list while preserving
  childless `AcceptsArgs` handlers. Census of both console handlers found one
  pure leaf consuming a trailing selector: `show class-of-service interface`;
  `OptionalSelector` admits exactly one selector and still rejects pipes or a
  second suffix. Valid `Options` re-entry such as
  `show security flow session summary zone trust` remains handler-owned. Both
  CLI dispatchers refuse before rendering or RPC dispatch. Implemented
  `| match`/`| count` filters remain peeled before the gate.
