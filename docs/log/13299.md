# Export forwarding health and count pending UMEM queues (#13299)

- **Issue/source**: #13299, deep-review finding D5-10. Prometheus did not
  expose the canonical `fwdstatus` signals, sampler `/proc/self/stat` failures
  silently discarded samples, and userspace buffer utilization omitted frames
  parked in worker-local pending queues.
- **Change**: `Sampler.sample` now increments a synchronized cumulative read
  error count on `/proc/self/stat` failures and publishes it through
  `SamplerSnapshot` and `ForwardingStatus`. `Build` includes pending fill,
  prepared-TX, local-TX, and recycle queues in UMEM utilization without
  double-counting them against the in-flight aggregate. The API server receives
  the daemon's shared sampler and exports
  daemon/worker CPU windows, heap/buffer utilization, stale-data state, and
  sampler errors as Prometheus metrics. The existing userspace status snapshot
  remains the source for the forwarding state/buffer calculation; only the
  sampler is shared between CLI, gRPC, and REST.
- **Regression tests**: `pkg/fwdstatus/forwarding_health_13299_test.go`
  checks the pending-fill utilization and sampler error count;
  `pkg/api/metrics_fwdstatus_13299_test.go` verifies forwarding health and
  sampler error metric families are emitted.
- **RED evidence**: On pristine `origin/master` (`f59c739af`), the pending-queue
  regression failed: `BufferPercent=0`, expected `92.7734375` for 3800/4096
  pending fill frames. The first attempt to combine sampler assertions with this
  test failed to compile because the needed error-count fields were absent;
  the buffer regression was then isolated and produced the behavior-specific
  failure above.
- **GREEN evidence**: `go test ./pkg/fwdstatus/ ./pkg/api/ -count=1` passed.
  `go build ./...`, `go vet ./pkg/fwdstatus/ ./pkg/api/ ./pkg/daemon/`, and
  focused changed-call-site daemon tests passed; `gofmt -l` and
  `git diff --check` were clean. The complete test command including
  `pkg/daemon` exceeded its 360s deadline after the `fwdstatus` and `api`
  packages passed; the changed daemon tests passed separately.
- **Risk**: Prometheus forwarding health uses the existing canonical `Build`
  calculation at scrape time. Binding occupancy is clamped to 100% by the
  established formatter/build contract. Metrics are omitted where the source
  reports unknown rather than publishing a false zero.
