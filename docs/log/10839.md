# 10839 — counter resets are invalid monitor windows

`monitoriface` now distinguishes a decreasing cumulative counter from an idle
window. Affected rates and deltas render as `n/a`, and only the counter that
reset is re-baselined to its new value. Subsequent windows report deltas from
that baseline; unaffected counters retain their existing baselines. Traffic
summary totals are marked `n/a` when a reset makes their aggregate incomplete.
