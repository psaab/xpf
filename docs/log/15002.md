# Issue #15002 — Tolerant-path NAT/policy shapes no longer hard-fail the Go dataplane pre-pass (A08-03)

- **Timestamp**: 2026-10-18
- **Action**: Shapes that `pkg/config` strict gates reject and the tolerant
  load / HA peer-sync path (`CompileConfigLenient`) downgrades to a warning
  still returned hard errors from the Go dataplane compilers, so the
  #4960 validate-before-mutate pre-pass (`validateBeforeMutate`) aborted
  the whole apply before any host mutation — while the warning text (and
  the userspace snapshot builders) promised a scoped skip. Fixed by
  warn-and-skip on the validation pass (`isValidationPass(dp)`) at each
  cited site; the real (non-validation) pass keeps every hard rejection
  verbatim, so a strict apply never silently accepts these shapes.
  - `pkg/dataplane/compiler_nat.go`:
    - SNAT rule naming a missing source pool (#5626): userspace builder
      ships `pool_unusable=missing_pool` (fail-closed) — skip the rule.
    - DNAT rule naming a missing pool (#5626): builder drops the rule via
      `DestinationNATRuleExcludedReason` — skip the rule.
    - DNAT pool address that is a network prefix, not a host (#3450):
      same builder drop — skip the rule.
    - Static NAT rule with mixed address families (#13922): the Rust
      table keys each side by its own family so the pair never matches —
      skip the rule (no counter ID assigned on this arm).
    - NAT64 rule-set: parse the prefix through the #8667 normaliser
      (`config.NormaliseNAT64PrefixForSnapshot`); an unparseable,
      non-/96, or non-IPv6 prefix, a missing source pool, or a pool with
      no valid NAT64 host addresses (#14679) skips the rule-set — the
      Rust loader's scoped skip (#3888) / empty-pool install agrees.
  - `pkg/dataplane/compiler.go`: policy zone-pair naming an undefined
    from/to zone (#2401): skip the zone-pair (its `policySetID` stays
  - NOT changed: `pkg/config` strict/lenient gates (strict still rejects
    every shape above; lenient still warns), the userspace snapshot
    builders, and every non-validation-pass compiler behaviour.
    Sibling overlap recorded: #15000 (merged while this lane was in
    flight) added the strict NAT64 undefined-pool gate and made
    `compileNAT64WithStaging` warn-skip a missing pool on BOTH passes;
    the #15002 NAT64 validation arm runs first and is consistent with
    it (same skip, plus the prefix and unusable-pool arms #15000 left
    hard). The NAT64 missing-pool regression cell is kept as the
    end-to-end (lenient-compile + pre-pass) shape alongside #15000's
    direct compiler cells.

- **Risk**: On a tolerant apply the pre-pass no longer pre-empts the
  userspace helper's scoped rejections for these shapes: a dangling
  zone-pair now reaches the helper, which refuses the whole snapshot
  (previous-good retained) instead of the Go pre-pass aborting first —
  same fail-closed outcome, one layer later. All other shapes keep
  their pre-mutation rejection. No wire, snapshot, or config-format
  change.
