# Issue #15230 — ha: fix cohort — flow-export availability isolation (A46-02, A46-05)

## Why

- **A46-02:** `dialCollectors` fails a whole template group on one dial
  error, `NewExporter`/`NewIPFIXExporter` propagate it, and the daemon
  reconcile returned on the first constructor error, keeping the old
  bundle (or publishing empty). One collector whose warn-only
  source-address is not yet local (HA-VIP-on-secondary) therefore
  stopped NetFlow/IPFIX for every collector of every sampling instance
  and froze the previously running export config, retried only every
  30 s as a whole-family failure (`xpf_flowexport_build_failed`, #9166).
- **A46-05:** `BuildSamplingZones` OR-ed unit flags into a per-zone
  `SamplingDir`, and `ShouldExport(inZone, outZone, isIPv6)` took no
  interface, although the record carries Ingress/EgressIfindex. An
  unsampled interface's flows were exported whenever another interface
  in the same zone was sampled — wider export scope than configured.

## What

- `pkg/daemon/daemon_flowexport.go`: reconcile (v9 + IPFIX) builds each
  template group independently. Groups that build are published with
  the new config; only the failing group is marked failed
  (`flowFailedGroups`/`ipfixFailedGroups`, surfaced via
  `Daemon.FlowExportFailedGroups()` as `family\x00instance` keys),
  family `BuildFailed`/`FlowExportError` stay set, and the family hash
  is not recorded so the existing 30 s retry / next commit retries the
  failed group. A failed group with a previously running exporter keeps
  that exporter (per-group #3742). Live generations are tracked
  (`flowGens`/`ipfixGens`); a partial swap never closes a retained
  group, and teardown joins every generation through `joinWithBudget`
  (#9035 shape preserved, still AST-pinned).
- `pkg/flowexport/manager.go`: `BuildSamplingZones` additionally records
  per-interface selections `IfacesV4`/`IfacesV6` keyed by authored unit
  ref. New `ShouldExportIface(in, out, isIPv6, inIface, outIface)` /
  `FlowDirectionIface` require the record's own ingress (input) or
  egress (output) interface to be sampled when per-interface data
  exists for the family; denial happens before the 1-in-N counter and
  counts as zone-filtered. A record naming no interface keeps zone
  semantics (legacy producers/fixtures). Hand-built configs without
  per-interface data keep exact zone semantics via `ShouldExport`.
- `pkg/daemon/daemon_flowexport.go` callbacks pass
  `rec.IngressIface`/`rec.EgressIface`; `pkg/logging` resolves
  `EgressIface` from `EgressIfindex` alongside the existing ingress
  resolution (`EventRecord.EgressIface`).
- `pkg/flowexport/README.md`: #15230 section supersedes the stale
  "reconcile still returns on the first constructor error" note.

NOT changed: `dialCollectors` still fails its own group on a dial
error; collector exclusion (#8163), per-family sampling (#14608),
instance isolation (#2462), and family fan-out (#6811) are untouched.

## Risk

- A record that names an interface (non-empty resolved name) is now
  strictly per-interface; configs that relied on zone-mate sampling
  will see those flows denied — the configured contract.
- Partial generations can keep an old exporter process-alive while
  unpublished (mixed generation); it receives no records via the
  bundle and is closed at teardown/removal.
