# 14415 — NAT rule packed `match` compiles to an unconstrained / vanished rule (DR14-H2)

- **Timestamp**: 2026-10-16
- **Mechanism**: `rule r1 match source-address 10.0.0.0/24 { then { ... } }`
  parses as one rule node with the match packed into `Keys` and only `then`
  in `Children`. `compileNATSource` / `compileNATDestination` /
  `compileNATStatic` read the match only via `FindChildren("match")`
  (Children-only), so the packed match was never seen: `matchAuthored`
  stayed false (disarming the #8430 empty-match gate and the #9874
  lenient fail-closed marker), SNAT compiled unconstrained, and DNAT
  published no entry — silently deleting a `destination-nat off`
  exemption so later translate rules fired.
- **Fix (reader-side fallback, per issue spec)**: each NAT rule reader now
  expands the rule node via `packedBody(ruleNode, schemaForPath(... rule))`
  and reads `match`/`then` from the expanded node. The primary
  normalize-admission (`"rule match"` in `compactNormalizeInScope`) was
  measured and rejected for this shape: `splitPackedStatements8768`
  returns the tail whole (NAT `rule` does not set `packedStatements`),
  so the fold attached the braced `then` body under the synthesized
  `match` node and the #9877 check then recorded `then` as an unknown
  match leaf. Root cause in `packedBodyChildren` (`pkg/config/compact_tail.go`):
  when the deepest packed node is a leaf (the match value), its
  leaf-body guard returned `node.Children` unexpanded, dropping the
  packed run. The guard now returns the synthesized roots plus the real
  children as siblings when every real child names a declared child of
  the container and repeats no synthesized root head — preserving the
  #6818 leaf case (`transport protocol tcp { protocol tls; }` still
  declines, pinned by `TestPackedTailAttachesOnlyWhereTheGrammarPermitsABody_6818`).
  Fully-packed `rule r1 match ... then ...;` (no braced body) now also
  compiles constrained, matching the braced spelling.
- **Regression**: `pkg/config/compiler_nat_packed_match_dr14h2_test.go` —
  SNAT packed (SourceAddresses + matchAuthored), DNAT `off` packed +
  braced (destination, Off, installed per
  `DestinationNATRuleExcludedReason`), DNAT pool packed, scope-only
  control (stays legitimate/unconstrained), fully-packed control.
  RED on `origin/master` (packed cells compile empty/unconstrained),
  GREEN after the fix. Neighbours (`compiler_nat_dnat_off_3844_test.go`,
  off-shadow/#9874/#9877 suites) stay green.
