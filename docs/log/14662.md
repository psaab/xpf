# #14662 - VRF-blind interface-NAT local exclusion set and flat interface_nat maps

- **Timestamp**: 2026-10-17
- **Action**: Scoped `nat_translated_local_exclusions` (rst.rs) by the owning
  interface's canonical connected table; keyed `interface_nat_v4/v6`
  (types/forwarding.rs) as `addr -> (table -> ifindex)` and resolved
  `interface_nat_local_resolution` (forwarding/nat.rs) through the resolving
  table with a borrowed `&str` lookup (no per-packet allocation).
  `populate_interfaces` (forwarding_build/interfaces.rs) now checks the
  exclusion for the interface's own table and counts an interface-NAT
  registration as a local-delivery target, so a NAT-diverted unzoned
  interface arms the #5659 empty-zone sentinel. `flowless_base_resolution`
  (poll_descriptor/flowless_verdict.rs) now runs
  `enforce_ha_resolution_snapshot` on a local hit (and on the
  Untranslatable local return), not only on a FIB miss.
- **Validation**: On rebased `origin/master` 8653903746: 3 new regressions
  pass (`cargo test --bins 14662`: 3 passed); the 35 related
  #12085/#12086/flowless/sentinel cells pass. Regressions
  `same_ip_two_vrfs_one_nat_keeps_per_table_local_state_14662` and
  `unzoned_nat_diverted_interface_arms_5659_sentinel_14662`
  (forwarding/tests.rs) and
  `flowless_interface_nat_local_hit_is_ha_gated_14662`
  (poll_descriptor/flowless_verdict_tests.rs) exercise the exact pre-fix
  mechanism: flat exclusion diverts both VRFs; flat ifindex is
  last-write-wins; diverted unzoned row arms no sentinel; flowless local
  hit skips HA. RED-on-revert was established by the prior lane against
  the pre-fix base; the mechanism assertions are unchanged across the
  rebase (production hunks identical, unrelated base drift dropped).
- **Risk**: `interface_nat_tables_*` ownership maps are unchanged and still
  drive FIB/leak/IPsec ownership predicates; only the ifindex source is
  now per-table. Go's warning-only `interfaceModeSNATExcludedAddresses`
  mirror is a documented safe superset for commit-time warnings and is
  unaffected.
