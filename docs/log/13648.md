# #13648 — Enforce PBR deny terms on per-packet session hits

- **Timestamp**: 2026-10-15
- **Action**: Added established-session regressions for inet/inet6 PBR discard
  and reject terms combined with a per-packet DSCP predicate. Updated the
  per-packet input-filter session-hit evaluator to preserve routing-instance
  deny verdicts after the ordinary non-routing walk accepts/defer-matches.
  `userspace-dp/src/afxdp/poll_descriptor/filter.rs` and
  `userspace-dp/src/afxdp/poll_descriptor/filter_revalidation_7212_tests.rs`.
- **Validation**: The unmodified session-hit arm REDs:
  `per_packet_shape_preserves_pbr_discard_on_hit_13648` fails with `Accept`
  instead of `Discard`. Post-fix, that regression passes for IPv4/IPv6;
  `cargo test --manifest-path userspace-dp/Cargo.toml --bin
  xpf-userspace-dp filter_revalidation_7212_tests` passes 61 tests.
  `cargo build --manifest-path userspace-dp/Cargo.toml --bin
  xpf-userspace-dp` succeeds (pre-existing warnings).

- **Follow-up**: Changed the per-packet session-hit branch to derive the PBR
  verdict before counted evaluation. A PBR deny is replayed only through the
  routing-aware counted walk, which owns both preceding fall-through counters
  and the deny term; ordinary counted evaluation runs only when the PBR walk
  does not deny. Added a matched `next-term; count` regression to assert the
  fall-through and PBR counters each increment once.
- **Validation**: Restoring the merged implementation makes the new regression
  fail with the preceding fall-through counter at 2 rather than 1. With the
  counter-order fix, `cargo test --manifest-path userspace-dp/Cargo.toml --bin
  xpf-userspace-dp filter_revalidation_7212_tests` passes all 61 tests and
  `cargo build --manifest-path userspace-dp/Cargo.toml --bin
  xpf-userspace-dp` succeeds (pre-existing warnings).
