# #13273 - Bridge userspace interface counters to telemetry

- **Timestamp**: 2026-10-15
- **Action**: The userspace manager now sums RX/TX packet and byte counters across helper bindings for each ifindex, and the published legacy adapter delegates interface-counter reads to that helper-backed view. Missing helper status returns an error rather than an authoritative zero. Prometheus now increments `xpf_interface_counter_read_errors_total` when a configured interface cannot be resolved in the kernel.
