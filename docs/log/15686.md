# Issue #15686: prime-retry uses authoritative bulk sync on userspace adapter

- **Timestamp**: 2026-10-19
- **Action**: `startSessionSyncPrimeRetry` no longer invokes the legacy `ExportAllSessionsViaEventStream` on the userspace dataplane. That export pushes unframed, non-owner-filtered Open deltas through the incremental event stream, so it produces no `BulkStart`/`BulkEnd`, no `BulkAck`, never sets `syncPeerBulkPrimed`, and never discharges `ColdPrimeOwedWithoutPendingBulk` — the retry loop burned all attempts and exhausted with the peer unprimed. `bulkSyncViaEventStreamOrFallback` (name retained for its call site/tests) now delegates to the new exported `cluster.SessionSync.DoBulkSync`, the authoritative `doBulkSync` window: `BulkStart` + `BulkSnapshotSource` (table-truth `userspaceBulkSnapshot`, owner-RG filtered) or store walk + `BulkEnd`, failing closed on a snapshot-source error. Its matching `BulkAck` discharges the cold-prime debt and fires `OnBulkSyncAckReceived` → `syncPeerBulkPrimed`. Added `syncPrimeRetryIntervalsForTest` so the regression fires the first attempt without the production 10s sleep.
- **Regression**: `TestStartSessionSyncPrimeRetryUsesAuthoritativeBulkSyncOnUserspaceAdapter` in `pkg/daemon/userspace_sync_test.go` publishes a fake dataplane implementing both `userspaceEventStreamExporter` and `BulkSnapshotSource` (`primeRetryDualExporterDP`), wires `BulkSnapshotSource=d.userspaceBulkSnapshot` on a real connected loopback `SessionSync` pair that owes a cold prime, fires `startSessionSyncPrimeRetry`, and asserts: a pending BulkAck exists, `ExportAllSessionsViaEventStream` was never called, `ExportOwnerRGSessionsPaged` was called, `BulkSyncs>0`, `ColdPrimeOwedWithoutPendingBulk()` is false while the bulk is pending, and `syncPeerBulkPrimed` sets on BulkAck.
- **RED evidence**: on pre-fix code the retry type-asserts `userspaceEventStreamExporter` first and returns nil on success, so `eventStreamCalls==1`, `ownerRGCalls==0`, no pending BulkAck is recorded and the cold-prime debt stays owed — the test's pending-BulkAck assertion fails. [INFERENCE: RED was derived by code inspection of the pre-fix branch at `daemon_ha_sync.go:348-355`, not by a separate pre-fix test run in this lane.]
