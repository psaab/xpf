# 10300 — zeroize firewall logs and report the covered scope

- **Date**: 2026-09-18
- **Action**: extend the shared factory-reset wipe to erase xpf-owned firewall-log surfaces and make the gRPC/console receipt explicit about what is and is not covered.
- **Files**: `pkg/grpcapi/server_diag_zeroize_firewall_logs_10300.go`, `pkg/grpcapi/zeroize_firewall_logs_10300_test.go`, `pkg/grpcapi/server_diag_system_action.go`, `pkg/cli/cli_request_system.go`, plus existing zeroize test seams.

## Defect

`request system zeroize` erased configuration state but did not erase the local logs that described the prior tenant's sessions, policy decisions, and flow traces. The old success receipt only said `Configuration erased`, so it implied a stronger reset than the implementation delivered.

## Wipe scope

The shared wipe now snapshots configured names immediately before the gated wipe closure runs, then removes:

- `/var/log/xpf/security.log` and recognized numeric/date/compressed generations;
- the dedicated `/var/log/xpf-flow-trace` namespace;
- the configured persistent flow-trace basename under `/var/log` and its recognized generations;
- each valid `system syslog file <name>` basename under `/var/log` and its recognized generations;
- xpf-owned `/etc/rsyslog.d/10-xpf-*.conf` selectors, so a restart cannot recreate prior destinations.

The implementation validates syslog basenames with `config.ValidateSyslogFileName`, refuses rsyslog output symlinks, attests hardlinks across static logs, configured outputs, flow-trace entries, and drop-ins, and returns typed reset errors instead of claiming success when bytes can survive through another name. Unrelated host log files remain untouched. Journald copies and the remote collector are intentionally outside this local wipe and are stated in the receipt.

The inventory is captured inside both the gRPC `ZeroizeFn` closure and the console `factoryResetFn` closure. This closes the apply-gate race where a commit waiting for the gate could add a new destination after an earlier snapshot.
