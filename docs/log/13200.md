# #13200 — remove dead CLI helpers and sort screen-drop details

- **Finding:** Deep-review finding D10-04 identified three obsolete helpers in
  `cmd/cli`: `showFlowStatistics` was no longer dispatched, while
  `validatePolicyZoneSelectors` duplicated `parsePolicyShowQuery` and
  `showPoliciesBrief` only wrapped the filtered implementation. The live
  `show security statistics detail` renderer also ranged over the
  `ScreenDropDetails` map, so repeated invocations could print counters in
  different orders.
- **Fix:** Remove the unused flow-statistics renderer and redundant selector
  and brief wrappers. Update selector and policy-renderer tests to exercise the
  shared parser and filtered renderer directly. Sort screen-drop names before
  rendering their counts.
- **Regression:** `cmd/cli/show_security_stats_order_13200_test.go` checks that
  multiple detailed-statistics renderings list the screen-drop reasons in
  lexicographic order.
- **RED:** With the regression test added on pristine `origin/master`
  (`dd607606a`) before the source fix, `go test ./cmd/cli -run
  '^TestShowStatisticsSortsScreenDropDetails_13200$' -count=1` failed: output
  began `udp-flood, tcp-no-flag, spoof, ...` instead of sorted order.
- **GREEN:** The focused statistics, selector, and brief-policy regressions
  passed. `go build ./cmd/cli` and `go vet ./cmd/cli/...` passed. Full
  `go test ./cmd/cli/...` was attempted and failed only at the existing
  `TestTreeIsGofmtClean` check, which reports unrelated
  `pkg/config/compact_scope_blind_pairs_8852_test.go` as not gofmt-clean.
- **Scope:** No CLI output values or RPC behavior changed; screen-drop detail
  rows are now ordered deterministically. No unrelated package cleanup was
  included.
