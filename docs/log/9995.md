# #9995 — address-only NAT pools reported fake port utilization

- **Timestamp**: 2026-09-17
- **Action**: Read the issue and traced source-pool utilization through the CLI
  summary/detail renderers, REST and gRPC stats builders, and Prometheus
  collectors. `PortNoTranslation` preserves the source port, so its
  `PortLow`/`PortHigh` fields are irrelevant and allocator `UsedPorts == 0` is
  not a port-utilization measurement. The configuration contract is explicit
  in `pkg/config/types_security.go:1198-1205`.
- **File(s)**: `pkg/cli/cli_show_nat.go`, `pkg/api/nat.go`,
  `pkg/grpcapi/server_nat.go`, `pkg/api/metrics_nat.go`

- **Timestamp**: 2026-09-17
- **Action**: Added fail-on-revert coverage for an address-only pool alongside
  a normal PAT control. CLI summary/detail now render port range, allocated,
  available, used, and utilization as `NOT APPLICABLE`; REST and gRPC return
  zero numeric port fields with `Utilization: "NOT APPLICABLE"`; Prometheus
  omits the port capacity and usage series for a valid address-only pool
  because it has no string N/A value, while a refused pool retains its
  existing `total=0` refusal signal.
