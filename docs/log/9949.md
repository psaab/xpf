# #9949 — ICMP type policy bypass on Owner session hits

Work log for issue #9949.

## Why

`SessionKey` intentionally does not include ICMP type, so an established Owner
hit can find a session admitted by one type and forward a different type using
the cached decision. A type-constrained policy must still be consulted for the
packet when its verdict can depend on ICMP type. The existing Foreign authority
path and the GATE1b revalidation behavior must remain unchanged.

## What

- Added an Owner-only ICMP type verdict helper in
  `userspace-dp/src/afxdp/poll_descriptor/session_hit_authority.rs`.
- Wired the helper after input-filter handling and before the existing Owner
  zone-policy revalidation in `poll_descriptor/mod.rs`.
- Type-dependent Owner packets are evaluated with the packet's ICMP type; a
  denied packet is recycled and counted through the existing `policy_deny`
  debug counter without tearing down the live session. Foreign, fabric,
  reverse, and LocalDelivery paths retain their existing authority handling.
- Added a real descriptor regression in
  `tests_policy_revocation_8356.rs`: type 8 is admitted through a miss and
  forwards, type 13 hits the same typeless Owner session and is denied, a type
  13 packet from the permitted Foreign dmz path still forwards, and a later
  type 8 Owner packet still forwards while the session remains installed.

The regression driver intentionally passes an empty HA map. This test covers
ordinary standalone forwarding; `txn_ha_state()` marks only unrelated
redundancy groups active while the fixture interfaces use the default group,
which changes admission to an HA-inactive result. Keeping HA out of this
non-HA policy test makes the session miss/install and Owner-hit behavior
deterministic without changing production HA logic.

## Validation

- RED on the pre-wiring dispatch: real type-8 miss/admission succeeded, then
  type 13 hit the same session and forwarded (`tx = 1` where the regression
  requires `tx = 0`).
- GREEN focused regression: `cargo test
  a_denied_icmp_type_cannot_ride_a_permitted_owner_session_9949 -- --nocapture`
  — 1 passed (13 suites, 6430 filtered).
- GREEN affected policy-revalidation module: `cargo test
  tests_policy_revocation_8356 -- --nocapture` — 65 passed (13 suites, 6366
  filtered).
