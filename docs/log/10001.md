# Issue #10001 — gRPC show-routes next-table rows and exclusion reasons

- **Issue:** `routing-instances-detail` on the gRPC surface handled discard, reject, and next-hop statics, but a configured `next-table` static has no `NextHops` and therefore emitted no row. The renderer also never consulted `config.StaticRouteExclusions`, so tolerant-config rows had no refusal reason. Installation behavior is unchanged.
- **Context read:** Read the complete #10001 body and all comments before implementation. The issue had no comments; no scope withdrawal, narrowing, shipped notice, or contradiction was present.
- **What:** The gRPC instance-detail renderer now computes `StaticRouteExclusions` once per config, emits each configured `next-table` row, and prints the matching `NOT INSTALLED` reason. The local CLI twin was already present and remains unchanged. Added a direct renderer regression plus a real tolerant `Store.SyncApply` CLI/gRPC agreement cell on one config.
