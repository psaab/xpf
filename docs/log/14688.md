# #14688 — RBAC bypass via post-dynamic sibling traversal and repeated-key overwrite

## Mechanism
- `Canonicalize` left `current` at a dynamic node's Children after its
  value, so sibling keywords resolved after the positional value:
  `show interfaces ge-0/0/0 terse|queue|statistics|tunnel`,
  `show security zones trust terse`. Handlers ignored the smuggled token
  (local `showInterfaces` used `args[0]`/last-token checks; zones via
  SplitModifiers) — judged string ≠ executed command, defeating
  exact-anchored denies (`^show interfaces ge-0/0/0$`).
- `ParseCoSNameTypeArgs` overwrote on repeated keys: bare positional
  counted as name, then explicit `name` overwrote it
  (`public-cls name secret-cls` → `secret-cls`), defeating prefix allows
  (`^show class-of-service classifier public-cls.*`). Canonicalize also
  accepted both spellings, and `name public-cls type dscp` ordering via
  value-leaf children.

## Fix
- `pkg/cmdtree/tree.go`: new `Node.ModifierOnly` (honoured only in
  Canonicalize) marked on interfaces `terse`/`statistics`/`tunnel`/`queue`
  and zones `terse` — keywords whose handlers take no selector.
  `detail`/`extensive` (interfaces) and zones `detail` honour a selector
  and stay valid after a value.
- `pkg/cmdtree/canonicalize.go`: track dynamic value parent; refuse
  ModifierOnly after a value (including when the value itself spells
  the keyword, via pre-check), refuse duplicate `name`/`type` filter
  keys (bare counts as name), and allow a second filter key after the
  first key's value via the parent's children (tree models `name`/`type`
  as siblings, not nested).
- `pkg/cmdtree/cos_filter_topic.go`: `ParseCoSNameTypeArgs` rejects
  duplicate `name`/`type` (bare counts as name); stale "keyword
  overrides bare" tests updated.
- `pkg/cli/cli_show_interfaces.go`: strict `SplitModifiersAt` dispatch —
  one modifier, no Extra/Ambiguous, selector rejected for
  terse/statistics/tunnel, honoured for detail/extensive/queue/summary.
- `cmd/cli/show_interfaces.go`: reject selector for `terse`/`statistics`.
- Zones (both surfaces): reject >1 modifier.
