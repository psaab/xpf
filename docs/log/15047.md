# #15047 — generic vrrp-group without `preempt` compiled Preempt=false

- **Timestamp**: 2026-10-18
- **Action**: Default generic `vrrp-group` Preempt to true (Junos / RFC 5798 Preempt_Mode default) in `parseVRRPGroups`' constructor, and parse the new `no-preempt` leaf (schema + both compiler arms + packed-run delimiter) to clear it. Previously the Go zero value silently disabled tracking-driven failover: `track.go` only lowers the advertised priority, and `instance_rx.go` resets the master-down timer on every advert when `!getPreempt()`, so a backup never took over from a track-demoted master.
- **Base**: `origin/master` `192c7455ba`.
- **Files**: `pkg/config/compiler_interfaces.go`, `pkg/config/schema_interfaces.go`, `pkg/config/types_interfaces.go`, `pkg/config/vrrp_preempt_default_15047_test.go`, `pkg/config/testdata/spelling_gate_members_7484.txt`, `docs/config-schema.md`, `docs/log/15047.md`.
- **Scope**: RETH collection unchanged — `CollectRethInstances` still takes preempt only from explicit chassis `redundancy-group <id> preempt` (`rg.Preempt`, default false per cluster semantics). Hand-built `VRRPGroup{}` literals in other packages are unaffected (compiler is the only production constructor).
