# #10070 additive-wire literal guard drift

Issue: psaab/xpf#10070. Lane branch: `fix/10070-cosceil`.

## Context

The #7689 guard counts exhaustive additive-wire struct literals (literals without a
`..Default::default()` update tail) across the whole userspace crate. The issue
was originally observed as `NeighborSnapshot` 29 against a ceiling of 26. On the
current baseline, the same ratchet had drifted in three rows:

- `DestinationNATRuleSnapshot`: 4 exhaustive literals, ceiling 3.
- `FabricSnapshot`: 8 exhaustive literals, ceiling 7.
- `NeighborSnapshot`: 40 exhaustive literals, ceiling 26.

The excess sites are test fixtures and helpers, not production construction sites.
Each fixture must remain because it supplies the gateway, translated endpoint,
pool endpoint, fragment-resolution witness, policy-resolution witness, or fabric
identity that its named regression exercises. The new tail is runtime-neutral for
all current fields: every current field remains explicitly supplied, while any
future additive field will take its `Default` instead of creating another
exhaustive-literal debt site.

## Fix

No ceiling was raised. All 16 excess exhaustive forms now carry an update tail,
which preserves the existing ratchet ceilings (3, 7, and 26) and removes the
sprawl the guard is intended to catch.

Per-literal sites and why each fixture remains:

- `afxdp/tests_9782.rs:105` — PAT pool snapshot's direct next-hop neighbor.
- `afxdp/tests_9782.rs:352` — collider flow's destination neighbor.
- `afxdp/tests_9782.rs:468` — untranslated control flow's destination neighbor.
- `afxdp/tests_9950.rs:238` — DNAT rule needed to establish the pure-DNAT path.
- `afxdp/tests_9950.rs:270` — DNAT test's WAN gateway neighbor.
- `afxdp/tests_9950.rs:281` — DNAT test's translated internal-host neighbor.
- `afxdp/tests_9950.rs:464` — pool-SNAT test's WAN gateway neighbor.
- `afxdp/tests_9950.rs:475` — pool-SNAT test's translated internal-host neighbor.
- `afxdp/tests_9950.rs:490` — pool-SNAT test's untranslated pool-address witness.
- `afxdp/tests_9950.rs:682` — post-cache reply test's WAN gateway neighbor.
- `afxdp/tests_9950.rs:693` — post-cache reply test's translated internal-host neighbor.
- `afxdp/tests_9950.rs:704` — post-cache reply test's pool-address witness.
- `afxdp/tests_9950.rs:1068` — IPv6 overlap test's neighbor, required to reach
  forwarding rather than fail at `MissingNeighbor`.
- `afxdp/tests_nat64_tunnel.rs:1216` — #9957 reverse-fragment neighbor, required
  to reach `ForwardCandidate` and install the association.
- `afxdp/tests_policy_revocation_8356.rs:779` — #9949 WAN neighbor, required to
  resolve the ICMP policy-type split.
- `server/tests.rs:5078` — #9803 fabric identity closure, required to prove a
  plan change forces the next-apply rebind.

The sibling ceiling table in `cos_literal_guard_7689.rs` was audited at the same
time. No other row drifted after these fixture tails were added.
