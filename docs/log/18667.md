# #18667: remote configuration `show` accepts glued pipes and hides scoped misses

- **Timestamp**: 2026-11-06
  - **Action**: Refused a `TokenPipe` in remote config-mode `show` when it is
    byte-adjacent to neighboring text, using `lex.Position()` and the raw
    source bytes. A bare pipe with spacing remains accepted. The refusal uses
    the existing operational hint wording: `separate the pipe with spaces`.
    The shared config lexer is unchanged.
  - Scoped `configuration path not found` responses now return errors for
    operational `show configuration <path>`, candidate-mode `show <path>`,
    and `show system rollback <N> <path> | display ...`. Since `cli -c` exits
    1 on handler errors, consumers can distinguish absence from a successful
    empty render.
  - Updated the failover-clock NTP probe to recognize a path-not-found result
    even though the CLI now exits nonzero for that absent stanza. Generic CLI
    failures remain `unknown`. The self-test stub returns nonzero for both an
    absent stanza and an unreadable configuration, and asserts the three-state
    present/absent/unknown distinction.
  - **Files**: `cmd/cli/shared.go`, `cmd/cli/show.go`,

- **Timestamp**: 2026-11-06 (fold)
  - **Action**: Treat the comment-terminated byte immediately before a pipe as
    adjacency, even though the lexer skips the comment. The correction hint
    now adds whitespace only at the pipe's raw span, preserving whitespace
    inside quoted path values.
  - The DHCP failover snapshot helper maps only the explicit
    `configuration path not found: system services dhcp-local-server` result
    to an empty stanza. Both initial snapshots and provisioning continue for
    that absent stanza; any other CLI failure remains unreadable and fatal.
    Cleanup uses the same helper, so an unreadable read cannot masquerade as
    an empty original snapshot.
  - **Caller sweep**: no matching caller was found under `scripts/`. In
    `test/incus/`, the remaining direct `cli -c` scoped display-set reads are
    fail-closed preconditions: the class-of-service render is queried only
    when the committed fixture requires a line, chassis-cluster configuration
    is required for DHCP restoration and the private-RG attestation, and
    zones/interfaces must be readable before the host-inbound matrix.
    `cc-rollback-functional.sh` and `wire-*` readers use interactive CLI input,
    not `cli -c`, so they do not consume the new command-mode exit status;
    their required policy/zone evidence is checked before a measurement, while
    optional snapshots remain output-based. Whole-config readers are unscoped.
    The DHCP local-server subtree is the supported absent stanza and is
    migrated above.
