# #18667: remote configuration `show` accepts glued pipes and hides scoped misses

- **Timestamp**: 2026-11-06
  - **Action**: Refused a `TokenPipe` in remote config-mode `show` when it is
    byte-adjacent to a neighboring token, using lexer positions to compare
    source spans. A bare pipe with spacing remains accepted. The refusal uses
    the existing operational hint wording: `separate the pipe with spaces`.
    The shared config lexer is unchanged.
  - Scoped `configuration path not found` responses now return errors for
    operational `show configuration <path>`, candidate-mode `show <path>`,
    and `show system rollback <N> <path> | display ...`. Since `cli -c` exits
    1 on handler errors, consumers can distinguish absence from a successful
    empty render.
  - Updated the failover-clock NTP probe to recognize a path-not-found result
    even though the CLI now exits nonzero for that absent stanza. Generic CLI
    failures remain `unknown`. The self-test stub returns nonzero for both an
    absent stanza and an unreadable configuration, and asserts the three-state
    present/absent/unknown distinction.
  - **Files**: `cmd/cli/shared.go`, `cmd/cli/show.go`,
    `cmd/cli/show_system.go`, `cmd/cli/config_show_18667_test.go`,
    `test/incus/failover-clock-lib.sh`,
    `test/incus/failover-clock-selftest.sh`
  - **RED evidence**: At the base, the new `-run '18667'` cells failed because
    the glued rows returned nil and scoped operational, candidate and rollback
    path misses returned nil. A mutation disabling the adjacency refusal made
    all five glued-pipe rows fail again, including the required hint checks.
