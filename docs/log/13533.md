# #13533 — merge scheduler-map blocks and enforce queue bijection across CoS roots

- **Action**: Preserve all scheduler-map entries across repeated named blocks and reject cross-root forwarding-class queue conflicts.

## Red before

The regression tests added for #13533 fail against pristine `origin/master`: two `scheduler-maps { SM-A { ... } SM-A { ... } }` blocks leave only the second block's entry, and separate `class-of-service` roots can both bind queue 0 to different forwarding classes without a compile error. The controls ensure distinct scheduler-map names remain separate and repeated identical FC-to-queue assignments remain accepted.

## Change

- The scheduler-map compiler now finds or creates the map by its authored name and appends/overwrites entries by forwarding-class key. This preserves disjoint entries across split blocks and separate CoS roots while retaining existing same-key last-write behavior.
- Forwarding-class queue compilation compares each assignment against the already-compiled shared FC map, in addition to the existing per-root queue/FC bijection checks. A queue cannot be owned by another FC across roots, and an FC cannot change queue across roots; identical reapplication remains idempotent.
- Regression coverage exercises same-root and cross-root split scheduler maps, distinct map names, queue-owner conflicts, FC-to-multiple-queue conflicts, and valid disjoint/idempotent assignments.

## Validation

- RED: `go test ./pkg/config -run 'Test(SplitSchedulerMap|DistinctSchedulerMaps|CrossRoot).*13533' -count=1` on pristine `origin/master` failed both split-map merge cases and both cross-root FC/queue conflict cases. The distinct-name control and valid idempotent reapplication passed.
- GREEN: the focused regression command passed on the implementation. `go vet ./pkg/config` and `gofmt -l pkg/config/compiler_class_of_service.go pkg/config/cos_scheduler_map_split_13533_test.go` completed cleanly.
- Full package: `go test ./pkg/config -count=1` did not pass: `TestConfiguredIPv6Prefixes10856` failed an order expectation, and the package run timed out after ten minutes in `TestSpellingGateMembersAreRecorded7484`'s spelling differential gate.

## Risk

Configs that previously supplied conflicting FC/queue ownership in separate `class-of-service` roots now fail compilation rather than leaving shared model state dependent on root order. Valid repeated assignments and distinct queue mappings are preserved.
