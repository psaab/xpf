# #14593 — External `.network` with empty effective `[Match]` treated as match-all

## Defect
`FindExternallyManaged` (`pkg/networkd/networkd.go`) turned any file with a
`[Match]` section and no surviving `Name=`/`MACAddress=` predicate into a
`matchAll` rule: a bare empty `[Match]`, a `Name=` reset clearing the last
predicate, or a `MACAddress=` whose words are all unparseable exempted every
NIC from unmanaged bring-down — `Matches`/`MatchesForApply` returned true,
`Apply` wrote no `10-xpf-<nic>.network` always-down unit, and the compiler
left the interface untouched. systemd 262 ignores such files ("No valid
settings found in the [Match] section, ignoring file. To match all
interfaces, add Name=*"), so one malformed root-written file silently
disabled the box-wide "unconfigured NIC is down" posture.

## Fix
- Removed the `matchAll` synthesis: a rule is retained only when it has a
  valid `Name=` or `MACAddress=` predicate. Explicit `Name=*` still matches
  all (it is a real Name predicate through `externalPatternListMatches`).
- A `MACAddress=` assignment with no parseable word and no valid `Name=`
  yet marks the rule `unsupported` (systemd has no valid setting from it);
  the rule is dropped unless a later line adds a valid predicate. An
  invalid MAC beside a valid `Name=` stays inert, as on master (the
  existing "invalid MAC word dropped" case keeps passing).
- Deleted the now-dead `matchAll` field and its short-circuit in `matches`.

NOT changed: unknown-key conservatism (`MatchesForApply` still preserves
when a supported predicate matches alongside unknown keys), MAC/Name
parsing forms, and the 20-byte IB-address question (still unvalidated
against systemd, as noted on the issue).

## Tests
New `pkg/networkd/empty_match_14593_test.go`
(`TestEmptyEffectiveMatchIsIgnored14593`): bare empty `[Match]`, `Name=`
reset, only-invalid MAC, invalid-MAC-after-reset, and empty `MACAddress=`
bodies each assert `Matches=false`, `MatchesForApply=false`, and that
`Apply` writes `10-xpf-eth0.network` with `ActivationPolicy=always-down`;
controls assert `Name=*` still matches all and suppresses the unit, and
`Name=eth0` still matches. Flipped the pinned
`external_match_12135_test.go` "empty Name resets to empty Match" case
from `want: true` to `want: false`.
