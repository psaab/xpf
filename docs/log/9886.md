## The defect, executed both halves on base `15be546a1`

`Manager.Apply` with `Name: "ge 0"` returned nil and wrote
`10-xpf-ge 0.{link,network}` containing raw `Name=ge 0` — two
whitespace-separated fields systemd reads as two glob patterns, claiming
devices other than the intended one while the intended device gets none.
Upstream, `CompileConfigLenient` on `interfaces "ge\n0"` returned nil with
compiled name `"ge 0"` and only the #1798 sanitize warning: the lenient scrub
maps the control byte to a space — the sink's separator — manufacturing the
second pattern. The predicate expressing the refusal
(`interfaceNameRendersAsOnePattern`) existed with zero production callers.

## Refusal is the only safe posture — and loud refusal at that

The repo already argues in-source that no substitution is safe here
(`validate_interface_name.go`, "strictly worse than rendering raw"). The one
alternative the comments do not name is quoting (`Name="ge 0"`): systemd would
read it as a single pattern matching a device literally named `ge 0`, which
cannot exist (kernel `dev_valid_name` rejects all whitespace) — fail-closed
for cross-claims, but SILENT. The belt refuses instead: no file, loud error,
commit fails. Same reasoning as #9494's confinement refusal, one layer up the
name's meaning.

## The belt fires before `expected`, not beside #9494

`Apply` builds the `expected` set and sweeps stale files before the write
loop, so a write-loop refusal would pin a previously rendered poisoned unit in
`expected` and keep it on disk forever, still claiming devices. The belt sits
in the pre-`expected` filter loop (after the unmanaged+external skip, which is
never rendered and must never trip it), giving a refused name exactly
deleted-interface semantics: its stale units are swept AND the commit fails.
#9494 stays in the write loop — a slash-name cannot be a filename, so it has
no stale-poison case. A refused name that is also protected keeps its files
(lifeline wins) while still failing the commit; a slash-plus-space name is
refused exactly once, here. OriginalName is out of scope (kernel-derived,
inherently one pattern); leading-dash argv is #9885's lane.

## The lenient path drops, not errors (adjudicated deviation)

The issue prescribes a HARD error on the lenient path. Plan review killed
that element with executable mechanics: `SyncApply` rejects on lenient
compile error, and the repo's own comments state that rejection alarm-loops
against a pre-gate primary — while every semantic gate on lenient downgrades,
drops (#5834, CoS) or quarantines, with zero hard-error precedents. A
scrubbed-only hard-error middle path was weighed and rejected too: it still
loops pre-#1798 skew (defeating the #1798 pre-scrub's stated purpose), needs
invasive scrub-provenance tracking, invents a novel severity shape, and would
make one never-usable member a permanent commit blocker. So the gate is the
#5834 shape — strict arm hard-errors (a backstop behind the schema walk, live
via direct `CompileConfig`), lenient arm drops the member with a loud warning
naming #9886, the #1798 breadcrumb, and the remedy — placed post-expansion so
range members and apply-groups-inherited members are ordinary children, and
covering `bridge-domains` (same sink via `br-`+name). Drop viability holds:
the #4515 existence gate downgrades on lenient, so refs to a dropped member
warn instead of re-failing the compile. The deviation is surfaced in the
issue thread, the gate comment, and the PR.

## The predicate splits ASCII, not `strings.Fields`

Go `Fields` splits NBSP/NEL, which the kernel accepts and systemd treats
atomically — a verbatim relocation would refuse working pre-gate names,
violating the brief's own #6564 rationale. The shared predicate refuses
non-empty + no ASCII whitespace: exactly the set no kernel device name can
contain, a conservative superset of systemd's split set. `\v\f` stay refused
(loud beats systemd's silent no-match, and no real device can carry them);
glob metacharacters pass (they ARE one pattern) — render-side glob refusal is
the filed follow-up #10089, which also owns the strict-path
`bridge-domains "ge*"` hole this lane found.

## Parent-review fold (GPT NEEDS-MAJOR + SPARK NEEDS-MINOR)

- **Second .link writer guarded.** `writeLinkFile` (positional, device-map,
  and bootstrap callers) interpolated target and OriginalName raw; the
  device-map path writes the .link BEFORE the kernel rename, so a tolerated
  poisoned logical name landed on disk. The guard refuses render-unsafe
  target/OriginalName before any mutation (path not even built), surfacing
  on the existing #5842/#4956 error channels while the rename proceeds
  without a .link rather than stranding the NIC mid-pass.
- **Device-map identities gated.** The compile gate now also prunes
  `chassis device-map interface` entries, mirroring the compiler's three
  instance shapes exactly (bracket fan-out, Keys[1], flat-set children) —
  including dropping a fan-out node whose every instance is pruned, without
  which its props would recompile as phantom instances.
- **Fabric refs stripped, not just dropped at source.** The dataplane emits
  bond-member rows without a kernel-existence check, so a surviving
  `member-interfaces "ge 0"` resurrected the dropped identity as a
  refused-but-partially-applied row. The gate strips render-unsafe values
  across all five member-interfaces spellings (mirroring plainListValues'
  recursion, grandchild quirk included); the strict arm IS the commit error
  here — the schema has no validator on these values, a strict-path hole
  this fold closes. Proved end-to-end by a compile→model dataplane test
  asserting no poisoned row is emitted.
- **Full C0/DEL render refusal.** The belt predicate covered only ASCII
  whitespace; remaining controls passed and were pinned passing. Render
  callers now check `rendersafe.SafeInterfaceName` (one pattern AND
  control-free) — a deliberate split from the grammar predicate, whose
  control acceptance is now documented as slot-count truth, not render
  policy. The belt also covers OriginalName (a match list too), first-hazard
  wins. Accepted exotic, documented in code: a hand-crafted control-byte
  kernel name arrives as an unmanaged row and fails loudly until renamed.
- **Test safety + non-vacuity.** Belt tests redirect procfs via
  `rpFilterFixture` (+ debt reset), since stubbed successful reloads reach
  the real sysctl writer; refused fixtures now include bond/bridge shapes
