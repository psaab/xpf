# #16146 — compiler evictions (chassis first) + NAT predicate unification

- **Timestamp**: 2026-10-22
- **Action**: evicted the lodger compilers out of `compiler_system.go`
  in-package (function-level, unchanged call graph): chassis cluster
  compiler into the existing `compiler_chassis.go`, SNMP into
  `compiler_system_snmp.go`, DDNS into `compiler_system_ddns.go`, and
  schedulers into `compiler_system_schedulers.go`. `compileSystem`
  itself was not stanza-decomposed (deferred per the issue). Unified
  the NAT undefined-zone predicate: `natUndefinedZoneFindings` is now
  the single walk; the strict error, the per-field offender list
  (`natUndefinedZoneOffenders`, source from→to then destination from),
  and the per-rule-set tolerant skip-set are projections of it. The
  skip-set key changed from `"kind\x00name"` strings to the struct
  `NATRuleSetRef{Kind,Name}`, updating `Config.LenientNATUndefinedZoneRuleSets`,
  its config caller, and both `pkg/dataplane/compiler_nat.go` consumers.
  Zone membership is a direct `cfg.Security.Zones` lookup — no
  intermediate zones map, and the skip projection builds no offender
  strings. No by-kind split of `compiler_validate_strict_nat.go`.
