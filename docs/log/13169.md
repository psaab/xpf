# Issue #13169: Reject undefined deny schedulers and preserve policy rejection causes

The D4-13 finding identified two related holes in userspace policy rejection. `buildOneRuleSnapshot` only poisoned undefined-scheduler DENY/REJECT rules when the config had already been marked `LenientContentDropped`; a programmatically constructed or partial config could publish the scheduled deny as inactive, allowing traffic to fall through. Rejection reporting also treated the generic unsupported-application wire carrier as an actual bad application and used early continues/strict guards that lost malformed-zone-pair and unknown-security-policy child causes when causes co-occurred.

The builder now detects undefined scheduler references on every DENY/REJECT rule and poisons its application terms so the helper rejects the full snapshot. The rejection collector attributes that sentinel to the scheduler, suppresses a generic-only carrier when scheduler/zone/shape metadata explains it, and reports malformed zone-pair and unknown-child metadata independently alongside any other causes. No change was made to PERMIT scheduler handling or the wire schema.

Regression evidence: the new `TestD413*` tests failed on pristine master `ab0498643b401c1bbf1ce60471d2a05c63d93756`: unflagged DENY and REJECT snapshots had `Inactive=true` with no rejection reason; flagged undefined-scheduler rules reported the bogus application token; and combined malformed-shape/unknown-child/address cases lost causes. After the fix, `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test -count=1 -run '^TestD413' ./pkg/dataplane/userspace` passed.

Validation:

- `gofmt` on all changed Go files and `git diff --check` passed.
- `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test -count=1 ./pkg/dataplane/userspace/...` failed in the fix worktree (the `format` subpackage passed). The userspace package also failed on pristine master with the same existing unrelated failures: `TestContractSnapshotGolden9821`, `TestSnapshotShapeIsPinnedToProtocolVersion8892`, several host-interface/zone tests, and many Unix-socket tests failing with `bind/connect: invalid argument` under the long `/var/worktrees/.cache/go-tmp` paths. No D4-13 regression failed after the fix.
