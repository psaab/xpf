# Issue #17089: WG control-thread spawn inputs captured field-by-field

- **Timestamp**: 2026-10-27
- **Action**: consolidated the WG control-thread spawn captures into a
  single `WgSpawnInputs` value (`userspace-dp/src/afxdp/types/runtime.rs`).
  `Coordinator::wg_spawn_inputs` (`tunnel_supervision.rs`) is the ONLY
  builder; `spawn_one_wg_control_thread` destructures that one value into
  `wg_control_loop`, and `WgControlEntry` stores a clone as its single
  `spawned: Option<WgSpawnInputs>` field. The six-arm `else if` stale-prune
  ladder and the per-field `spawned_*` / `engine_ptr` entry fields are
  deleted; the prune is now `match wg_spawn_inputs(id) { None =>
  "removed", Some(now) if now != entry.spawned =>
  now.diff_reason(&entry.spawned), _ => keep }`, preserving the exact
  historical reason strings and precedence (`engine_changed`,
  `attachment_changed`, `outer_mtu_changed`,
  `outer_bind_device_changed`, `kernel_transport_changed`,
  `peer_config_changed`). Engine identity uses `Arc::ptr_eq` on the held
  `Arc<WgEngine>` instead of a bare `usize` address, closing the
  tombstone ABA exposure noted in the issue. `listen_port`,
  `endpoint_hosts`, and `preferred_v6` — previously captured with no
  prune arm and covered only implicitly through engine identity — are
  now first-class captured fields. `peer_config` is retained in the
  capture per the acceptance (see #17094 for its reachability question).
  Identical spawn behaviour: same `wg_control_loop` arguments, same
  backoff, tombstone, publication, and stop/join paths.
- **Guard**: `every_wg_control_loop_capture_is_in_spawn_inputs_17089`
  (the #6961 pattern) parses `wg_control_loop`'s parameter list and
  `WgSpawnInputs`' field list from source and fails when a by-value
  parameter is neither a `WgSpawnInputs` field nor on the named
  live-Arc allowlist (shared Arcs/channels that cannot go stale).
  Fold: the same cell now also parses the hand-written
  `PartialEq::eq` and `diff_reason` bodies in `types/runtime.rs` and
  requires every field name in BOTH (the final `else` arm is pinned
  as the struct-last field's reason) — a field whose `eq` conjunct
  is forgotten compiles and would silently never prune.
  `wg_spawn_inputs_diff_reason_names_each_field_17089` pins per-field
  divergence → equality flip + historical reason string.
- **Docs**: `coordinator/README.md` "Aux tunnel threads" now describes
  the single-capture restart condition instead of listing prune arms.
