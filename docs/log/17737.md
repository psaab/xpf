## Change

The detail renderer's session join now includes the 5-tuple protocol and the routing domain from each session value. Lease scopes are compared in the helper's routing-domain wire representation (default scope 0 is the stated-default marker 1), matching the Rust display exporter's per-lease `active_flows` identity. The shared session walker now exposes keys to consumers that need them, while the existing value-only adapter keeps source/destination renderers on the same cancellation and scan-error path. Pre-#16647 rows without protocol/scope retain endpoint-only counts; that fallback map is allocated only when such rows are present.

The regression covers TCP and UDP leases sharing one translated IPv4 endpoint (one session each => each row prints `Current sessions: 1`), same-protocol leases in distinct routing scopes, the same protocol distinction on IPv6, and an unchanged two-session single-lease control.
