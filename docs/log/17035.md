# #17035 — SSOT-copy cleanups in pkg/frr (R4-Q42-06)

- **Timestamp**: 2026-10-27
- **Action**: Replaced two retyped render-belt predicates in pkg/frr with
  delegations to their exported `pkg/config` SSOTs, and rewrote the #9050
  parity test to be exhaustive. Pure code-motion, no behavior change on
  any non-empty input. Disjoint from sibling #17029 (pkg/routing +
  pkg/cmdtree vocabulary tables), which is untouched.
  - `frrAuthTokenUnsafe` (pkg/frr/auth_token_9050.go): body was a byte-for-byte
    copy of `config.frrTokenUnsafeIndex`'s set (`' '`, `'\t'`, `< 0x20`,
    `0x7f`). Now `return !config.FRRSingleToken(s)` — the SSOT whose doc
    says it is "exported so pkg/frr and the commit gate agree" (#9493).
    Sole caller `authTokenOrOmit` only reaches it with a non-empty
    resolved secret (`resolvedAuthSecret` returns ok=false for `""`), so
    the empty-string difference (copy admitted `""`, SSOT rejects it) is
    unreachable in production; the rewritten test pins parity there too.
  - `validBGPNeighborAddress` (pkg/frr/render_validate.go): body re-ran
    `netip.ParseAddr` + zone check. Now
    `return config.ValidBGPNeighborAddress(s)`. The SSOT adds an explicit
    empty check and a TrimSpace check that `ParseAddr` already implies,
    so the accept set is identical (verified over witnesses including
    `""`, `" "`, padded/tab/newline-wrapped addresses, prefixes, zones,
    hostnames).
  - `validFRRInterfaceOperand`: verified ALREADY delegating to
    `config.FRRInterfaceOperand` on current origin/master (hoisted by
    #17684, commit 6a37c97194 after the issue's 2026-10-25 verification
    revision). No change; not a divergent site. Its copy character set
    (`<= 0x20`) was also semantically equal to the SSOT gate set.
  - `TestAuthTokenSetMatchesTheCommitGate9050` (auth_token_9050_test.go):
    was a frozen 7-byte list that never called the gate. Now iterates all
    256 bytes in `a<byte>b` plus `""`, asserting
    `frrAuthTokenUnsafe(s) == !config.FRRSingleToken(s)` on every one,
    retaining the over-rejection witnesses (ordinary printable secrets).
  - New `TestBGPNeighborAddressMatchesCommitGate17035`
    (bgp_neighbor_address_15184_test.go): witness parity of
    `validBGPNeighborAddress` against `config.ValidBGPNeighborAddress`.
