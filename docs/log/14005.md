# 14005 — Cover ICMP timestamp requests in type-blind reverse-policy regression

## Boundary

Issue #13940's acceptance covered both reverse echo requests (type 8) and
reverse timestamp requests (type 13) under a type-blind policy. The original
regression exercised only echo requests. The session-hit implementation uses
one reverse-request path for both types; this follow-up adds the missing cell
without changing dataplane behavior.

## Change

Extend the type-blind reverse ICMP test to send type 13 through the same live
query session. Assert it is dropped by the reverse-policy default deny, and
retain the type-0 reply-coasting control.
