# 10387 — Refuse vacuous userspace drain during cold-prime retry wait

## Diagnosis

A full-disconnect reconnect arms `SessionSync.needColdPrime`. If the authoritative
bulk source fails before a `BulkStart` is queued, there is no generation-matching
`pendingBulkOwed` or pending outbound bulk acknowledgement. The userspace
demotion path could nevertheless write an ordered `Barrier` and accept its
`BarrierAck`; that ack only proves the peer processed the marker, not that the
peer received the missing cold-prime table.

The generic ordered barrier is used by other cluster paths and remains policy
neutral. The demotion path therefore performs its readiness precheck before the
barrier, while a demotion-specific barrier admission rechecks the same predicate
under the bulk-send serialization lock. A replacement bulk cannot clear and
re-prime between that recheck and the marker admission.

## Changes

- Restored/exported `SessionSync.ColdPrimeOwedWithoutPendingBulk`, using the
  generation-stamped `pendingBulkOwed` debt rather than sticky
  `outboundBulkAcked`. The predicate rechecks the debt generation after sampling
  pending state and fails closed during repeated generation churn.
- Kept the userspace demotion gate before the barrier. The new
  `WaitForPeerBarrierAfterColdPrimeGate` path repeats the predicate while
  holding `bulkSendMu`, snapshots the debt generation before the predicate,
  rejects a re-arm before marker admission, and rejects a re-arm observed after
  the barrier acknowledgement. Plain `WaitForPeerBarrier` remains the original
  generic queue-and-ACK primitive.
- Serialized survivor clear-plus-replacement bulk under `bulkSendMu`, so the
  replacement `BulkStart` cannot overtake a demotion marker that passed the
  qualifying-pending check.
- Added a write-start watermark for the gated marker path. The barrier releases
  its admission lock once the sender owns `bulkStartMu`/`writeMu` for the marker,
  preserving the held-write causal test while retaining wire ordering.
- Discharged cold-prime debt before publishing barrier-fence clearance on a
  `BulkAck`, so a gated barrier cannot observe fence clearance with an owed
  debt and no qualifying bulk.
- Added generation-race, survivor-overtaking, and generation-rearm regressions;
  retained controls for primed and current-generation-pending demotions.
