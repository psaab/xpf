- **Timestamp**: 2026-10-24
  - **Action**: #16539 (R3-B17-04) — the shipped root installer no longer
    creates the developer scratch tree on customer hosts.
    `validate_archive_key` in `scripts/dist/install.sh` did
    `mkdir -p /var/worktrees/.cache/tmpdir` and templated its temporary
    GnuPG home under that tree whenever `TMPDIR` was unset, which is
    always the case under `curl … | sudo sh`; the tree was left behind
    (only the key home was removed) and the install aborted when that
    path could not be created. It now uses `mktemp -d -t
    xpf-archive-key-check.XXXXXX`, which honours `TMPDIR` when set and
    otherwise falls back to `/tmp`. `scripts/dist/install.sh` is exempt
    from `scripts/scratch-pinning-selftest.sh` (removed from its audited
    FILES list, exemption documented in the header): #14833 pins repo
    build/test scratch, not shipped customer-host tooling.
    NOT changed: `scripts/dist/selftest.sh` and every other audited
    build/test script keep their /var/worktrees pins.
  - **File(s)**: `scripts/dist/install.sh`,
    `scripts/dist/test_install_keyring_atomic_12142.py`,
    `scripts/scratch-pinning-selftest.sh`, `debian/changelog`,
