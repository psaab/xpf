## Implementation details

- `ipsecCaptureAuthorityRevision` increments on every active-runtime
  publication, restore, and shutdown clear.
- Restore and committed publication hold the affected runtime authority lock
  across the capture pointer update and revision increment.
- Reconcile snapshots the runtime and revision, then rechecks both while
  holding that runtime's authority lock before announcing.
- The daemon publication mutex serializes overlapping restore/commit/shutdown
  transitions before sampling the current runtime, preventing opposite
  old→new/new→old transitions from taking authority locks in ABBA order.
- The daemon test seam uses a small reinject submitter fake so the race cell
  can deterministically pause between sampling and authority locking; a
  concurrent publication cell also passes under `-race`.
