- **Timestamp**: 2026-10-28
  - **Action**: Fixed #17700 in the persistent NAT table. `LookupScoped` now
    returns a detached binding copy and deep-copies `PermittedRemotes`, matching
    the table's other snapshot accessors and preventing callers from mutating
    or racing against live table state. Legacy `Lookup` still matches the

    protocol-less legacy row) rather than returning whichever map entry is
    visited first. All table accessors share one copy helper for the scalar and
    grant fields.
