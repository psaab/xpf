# Issues #10496 + #10497 — serial gate and struct calibration floor

## Scope

This pair fixes two independent gates that jointly blocked the default test
signal. `make test` now invokes `test-go` and `test-rust` serially in one
recipe, continues to the Rust leg after a Go failure, and exits nonzero if
either submake failed. A repo-wide canary protects the target shape,
per-leg failure capture, and trailing failure exit.

The #6937 struct calibration now scans four hermetic Go source fixtures in a
`TempDir`, rather than drifting live production structs. The fixtures pin the
21-type/25-field over-floor role, 19-type/32-field under-floor role, the
inclusive 20-type boundary, and an 11-type/120-field aggregate false-positive
shape. No dataplane runtime code or Rust fixture code changed. #10504 remains
the owner of its Rust fixture/MAC failures and should consume this lane rather
than reimplementing either fix.
