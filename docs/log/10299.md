- **Action**: Persist each canonical text rollback slot's `HistoryEntry.Timestamp` and `Comment` in a durable `.configdb/rollback-meta.json` sidecar, hash- and file-identity-bound (device/inode/mtime) to the exact slot bytes; retain mtime/empty-comment fallback for legacy or mismatched metadata.

rewrite identical config bytes with a new comment. The
`TestRollbackSlotMetadataRejectsStaleManifestForDuplicateBytes_10299` cell
models a crash after that slot rewrite but before the sidecar rename and
passes:
