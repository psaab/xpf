# #17127 — owner-RG export continuation tests enter through a tokenless legacy path; the five #9856 v2 refusal arms are untested (R4-Q05-03)

- **Timestamp**: 2026-10-27
- **Issue**: #17127 (R4-Q05-03)
- **Base**: `origin/master 16db8c584e`

## Defect (STEP-0, verified at base)

Live on `16db8c584e`. `Coordinator::kick_owner_rg_export(owner_rgs, max, continuation: bool)`
(`userspace-dp/src/afxdp/ha/export.rs:39-46`) forwarded to
`kick_owner_rg_export_inner(.., continuation, None)`, so the #9856 token check at
`export.rs:114-120` (`if let Some((expected_incarnation, expected_sequence)) = expected_token`)
was skipped for every legacy caller. Production never sends a tokenless continuation —
`server/handlers/export.rs:24-30` passes literal `false` to the legacy entry and routes
every paged request to `kick_owner_rg_export_v2` — so the only `continuation=true`
callers were two Rust paging cells (`ha_tests.rs:6123`, `:6298` in the issue's numbering;
`:6123`/`:6298` at base). Grep at base: each of the five refusal strings
(`is unsupported`, `requires nonzero`, `must not carry a continuation token`,
`no open window`, `token mismatch`) had exactly one hit, its definition; no test asserted
any of them. The only token-carrying continuation test was the happy path
(`server/tests.rs` `export_owner_rg_sessions_reports_more_and_a_continuation_pages_the_window`).

## Fix

- `userspace-dp/src/afxdp/ha/export.rs`: new `pub(crate) enum ExportKick { Fresh, Continue { incarnation: u64, sequence: u64 } }`.
  `kick_owner_rg_export_inner` now takes `ExportKick`; the `Continue` arm binds the token
  non-optionally, so a tokenless continuation cannot be expressed and
  `expected_token: Option<(u64, u64)>` no longer exists. `kick_owner_rg_export_v2` maps its
  validated `(continuation, incarnation, sequence)` triple onto `ExportKick` (same five
  refusal arms, same messages, same order — the page-1-with-token arm still fires before
  the BUSY arm). The legacy entry is replaced by
  `kick_owner_rg_export_unpaged(&self, owner_rgs, max)` (always `Fresh`); no shim or alias
  for the old name/signature remains.
- Callers migrated: `server/handlers/export.rs` (legacy branch now calls
  `kick_owner_rg_export_unpaged`, behaviour identical — it already passed `false`);
  `afxdp/coordinator/tests.rs` (2 sites) and `afxdp/ha_tests.rs` fresh kicks (empty-set,
  enqueue-ack, uncapped, exact-fit, queue-full 15950) to `kick_owner_rg_export_unpaged`.
- The two tokenless paging cells now enter through `kick_owner_rg_export_v2` with page 1's
  token (`wait.token()`): `owner_rg_export_pages_a_capped_window_without_rekicking_the_workers`
  (page 1 also via v2) and `owner_rg_export_exact_cap_with_lagging_ack_reports_more`
  (terminal probe).
- Five new named cells in `ha_tests.rs`, one per refusal arm, each asserting `Err` with the
  arm's message, `export_seq` unchanged, and the open window untouched (a valid
  continuation still drains the 2-entry remainder to `more=false` and leaves the buffer
  empty): `owner_rg_export_v2_refuses_unsupported_protocol_version_17127`,
  `owner_rg_export_v2_refuses_zero_token_continuation_17127` (all three zero shapes),
  `owner_rg_export_v2_refuses_page1_with_token_17127` (all three token shapes),
  `owner_rg_export_v2_refuses_continuation_with_no_open_window_17127` (plus: a fresh kick
  still proceeds afterwards), `owner_rg_export_v2_refuses_token_mismatch_17127` (both
  fields). Shared fixture helpers `open_capped_window_17127` /
  `assert_window_untouched_17127` keep the four window-opening cells to one copy of the
  setup/assertion shape.
- Stale naming updated: `docs/session-sync-architecture.md` locked-phase entry,
  `afxdp/mod.rs` and `afxdp/ha/counter_query.rs` comments, `OwnerRgExportWait` doc link.
  Historical logs (`_Log.md`, `docs/log/9629-*`, `issues/pr-history.md`) are records and
  were left as written.

## Risk

Low. Production behaviour is unchanged: the handler's legacy branch already passed
`continuation=false`, and `kick_owner_rg_export_v2`'s validation order and messages are
untouched — `_inner` only loses the `None` token case that production could not reach.
The sole API change is internal (`pub` → crate-internal callers only, all in
`userspace-dp`); the Go wire protocol, `SessionExportRequest`, and paging version are
unchanged. Residual: the five cells cover the coordinator-level arms; the control-socket
surface for refusals is still exercised only via the happy path in `server/tests.rs`
(unchanged from before — the handler folds any `Err` into `response.error` verbatim).
