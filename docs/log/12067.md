## Change

- Kept the #12067 schema checks for route-filter children and compact `from` runs. The packed scanner now reuses `splitPolicyTermFromRun11779`, so value positions follow the compiler's schema arity and a `route-filter`-named prefix-list, community, or as-path remains a reference. Removed the dead `upto` branches.
- Added a strict compiled-config gate for `upto` with `UptoLen == 0`, which catches missing or malformed lengths even when a term-line `Keys` tail bypasses schema descent. `parsePolicyTermInlineKeys` now records a bare term-line `route-filter` in `UnknownFrom`, so it cannot compile into a match-all permit.
- Added CheckText and Store regressions for the bare head, missing `upto` length, then-first/body/group/packed variants, plus valid `/24`, V1/V2/V3 value-reference controls, braced/quoted controls, quoted-head behavior, and quote/bracket provenance.
