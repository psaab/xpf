## Red before

The R1 parent/head comparison identifies the three committed PR regressions as RED on the actual parent `83b5c9553` and GREEN on the folded head:

- `TestCatalogAndStrictGateCoverEveryNATApplicationListValue12224`: the disabled-AppID catalog exposed only the scalar/first application.
- `TestNATAppRef_DestSecondBadSpec_RejectsAtCommit12224`: strict commit validation did not reject a malformed second DNAT application.
- `TestDNATSecondProtocollessApplicationDoesNotEmitProtoAny12224`: a portless protocol-less member in a DNAT list added an empty-protocol, port-zero wildcard row.

The parent/head probes also found two tolerant-path boundaries. A later dangling app or broken application-set member did not abort `validateBeforeMutate` on the parent, but is now visible to the all-value catalog and aborts the `validate applications` phase. An `off` exemption with a protocol-less application carrying destination-port 8080 had parent rows for tcp/22, tcp/8080, and udp/8080; suppressing that member on the original PR head lost the 8080 exemptions. The original PR head also dropped a protocol-less-only translate rule, disagreeing with the #6534 show predicate.

## Change

- The strict application-spec walk and disabled-AppID catalog traverse every `NATMatch.ApplicationList()` value.
- DNAT suppresses a protocol-less application term only on translate rules, so an empty protocol cannot turn a portless app into a wildcard. Valid terms in a mixed list remain. A protocol-less-only translate list falls through to the existing #3434 never-match sentinel instead of dropping the rule.
- DNAT `off` exemptions preserve the prior ported protocol-less behavior, including tcp/8080 and udp/8080 rows. SNAT remains unchanged and keeps its existing `natProtoNever` sentinel.
- Regressions pin the two tolerant apply-abort cases, off-exemption rows, protocol-less application-set members in mixed and alone lists, the protocol-less-only #3434 row, and builder/show agreement (#6534).
- The AppID README continues to describe the plural NAT reference walk.
