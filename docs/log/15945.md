# Issue #15945 — event/syslog defects (H22-01, H22-02)

- **H22-01 (eventengine):** `evaluateEventMode` computed
  `matched := withinMatches(...)` during cooldown, discarded it
  (`_ = matched`), and parked every event with `ThenCommands` as a
  deferred edge; `drainDeferred` replayed the parked action at cooldown
  expiry with no re-evaluation. A sub-threshold (`trigger on 3`, count
  1), over-ceiling (`trigger until N` exceeded), or already-latched
  sustained event therefore fired the remediation once even though it
  never crossed. Fix (both halves, per the triage fix direction):
  evaluate-time — `if !matched { continue }` before the defer branch,
  so only a genuine crossing parks; drain-time — `drainDeferred`
  re-evaluates `withinMatches` against the live policy/runtime (and
  requires the parked semantic revision to still match) before
  enqueue, and only latches the authorizing generation. The stronger
  "stale policies replayed" arm remains mitigated by `staleReason`
  (worker commit-time backstop, unchanged) and is regression-guarded
  by the removed-policy cell.
- **H22-02 (logging):** `formatSDSyslogLine` fallbacks emitted only
  two NILVALUE dashes (`RT_FLOW - - <body>`, `xpf - - <body>`),
  placing the body in the RFC 5424 STRUCTURED-DATA slot, where strict
  parsers (rsyslog `pmrfc5424`, syslog-ng `syslog-protocol`) misparse
  or drop the record. Fix: third NILVALUE dash on both fallbacks
  (`RT_FLOW - - - ...`, `xpf - - - ...`), `FILTER_LOG` gets
  `MSGID=FILTER_LOG` with NILVALUE SD and the flat body as MSG, and
  `SCREEN_DROP` gains the Junos screen SD arm cited from the Graylog
  Juniper SRX content pack (Junos OS 17.4+ sd-syslog):
  `RT_IDS - RT_SCREEN_TCP [junos@2636.1.1.1.2.40 attack-name="..."
  source-address="..." ... action="drop"]`, rendered as MSGID
  `RT_SCREEN_DROP` (Junos's per-category TCP/IP split cannot be
  derived from the wire record's free-form check name). No Junos SD
  reference was found for firewall-filter logs, so no `FILTER_LOG`
  SD params are invented. Session lines are byte-unchanged.
- **RED:** new `engine_deferred_unmatched_15945_test.go` cells fail
  pre-fix (`PendingDeferred=1, want 0` for latched in-cooldown events);
  new `sd_syslog_nilvalue_15945_test.go` fails pre-fix with the
  STRUCTURED-DATA slot carrying the flat body. Both verified by
  stashing the fix.
