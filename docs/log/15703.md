# Issue #15703: `security log stream` facility validator rejects Junos facility names

- **Timestamp**: 2026-10-19
- **Problem**: `syslogFacilities` in `pkg/config/schema_security.go` listed only the BSD spellings (`auth`, `change-log`, `daemon`, `kern`, `local0`–`local7`, `syslog`, `user`), so strict commit (`SchemaValidate`) rejected the eight documented Junos facility names that `pkg/logging.ParseFacilityChecked` (#6830) already maps to wire facilities: `authorization`, `kernel`, `firewall`, `dfc`, `pfe`, `conflict-log`, `interactive-commands`, `ftp`. A valid Junos stanza such as `set security log stream s facility authorization` failed commit-check with `invalid value "authorization" (expected one of: auth, change-log, daemon, kern, local0, ...)` even though the runtime would have emitted it under the correct facility.
- **Fix**: Added exactly those eight names to `syslogFacilities` (now sorted: `auth`, `authorization`, `change-log`, `conflict-log`, `daemon`, `dfc`, `firewall`, `ftp`, `interactive-commands`, `kern`, `kernel`, `local0`–`local7`, `pfe`, `syslog`, `user`) and updated the header comment to cite `ParseFacilityChecked` (#6830). Also refreshed the four stale comments in `pkg/daemon/daemon_system.go`, `pkg/cli/apply.go`, `pkg/daemon/syslog_selector_render_5797_test.go`, and `pkg/cli/syslog_facility_checked_6829_test.go` that enumerated the old list; their operative claim (no `any` on this surface) is unchanged.
- **Not added**: `any` (the system-syslog wildcard; a stream carries a numeric facility, so it stays rejected) and `ntp` (#6830: Junos documents no configurable `ntp` facility, so it stays rejected rather than silently remapping to `local0`). Typos (`locl0`, `authh`, `kernelx`) still fail strict commit naming the value.
- **Regression**: `pkg/config/security_log_facility_junos_15703_test.go` — each of the eight names commits via `SchemaValidate` in both flat-set and hierarchical spellings, compiles verbatim (`Streams["s"].Facility` equals the authored name), is reported known by `logging.ParseFacilityChecked`, and compiles leniently (`CompileConfigLenient`, the #1960 tolerant path) with the name intact. The fourteen pre-existing names still commit; `any`/`ntp`/typos still reject.
