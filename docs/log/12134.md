# Issue #12134: Bound inherited RA lifetimes

- **Timestamp**: 2026-10-08
- **Action**: `buildRA` clamps the configured Router Lifetime once before deriving inherited RDNSS/PREF64 lifetimes. The header and RDNSS now use that same bounded source; inherited PREF64 lifetimes above RFC 8781's 65528-second wire maximum saturate to the maximum and emit one warning per sender. The schema and sender share the exported `RAPREF64MaxLifetimeSeconds` bound. Explicit PREF64 lifetimes retain the existing schema/prune defense.
- **Regression**: `TestBuildRA_12134_InheritedLifetimesAreBounded` marshal-decodes Router Lifetime, RDNSS, and PREF64 for default lifetimes 65532–65535 and tolerant-ingress `2^32`, and verifies saturation/warn-once behavior.

The defect was present on the pinned base.
