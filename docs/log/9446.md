## Instrument

`measureSpellingBound9446` works on one census site (`collectCompactSites`):

1. It renders five spellings of the site's statement:
   - A: `family inet { <rest> { stmt } }`
   - B: `family inet { <rest> stmt }` (omitted when nothing sits between the family and the leaf, where it is A)
   - C: `family inet <rest> stmt`
   - D: `family { inet <rest> stmt }`
   - E: `family { inet { <rest> { stmt } } }`
2. It runs production's `normalizeCompactStanzasWithScope` with a predicate that records each (container, head) question about the site's own tail, then defers to `compactNormalizeInScope`.
3. It compiles each spelling and compares the result with the fully braced control. It also checks that the control differs from a baseline without the statement, so the site is observable.

Two separate runs produced identical signatures for all 29 entries.
