- **Date**: 2026-10-15
- **Issue**: #13706
- **Why**: The hand-written `IfReq` ABI represented only a 16-byte `sockaddr`-sized union arm. Linux `struct ifreq` also contains `struct ifmap`, which is 24 bytes on 64-bit systems; passing the resulting 32-byte request to ioctl under-allocates the kernel ABI buffer.
- **What**: Added the missing C-layout `IfMap` member to the `Ifru` union and pinned `IfReq`/`Ifru` size and alignment in the slowpath tests. No ioctl behavior or sibling ABI implementation changed.
- **RED-before**: `slowpath::tests::ifreq_layout_matches_kernel_ifreq` failed on the unmodified definition: `IfReq` was 32 bytes, expected 40. The host C probe for `<net/if.h>` reported `sizeof(struct ifreq)=40`, `sizeof(struct ifmap)=24`, union offset 16, and alignment 8.
