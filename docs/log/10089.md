# #10089 — networkd renders single-pattern glob interface names raw

- **Timestamp**: 2026-09-17
- **Action**: refuse ASCII shell-style glob metacharacters (`*`, `?`, `[`, `]`) in render-side interface names and `[Match] OriginalName=` values before writers mutate files; report the offending token and #10089. Add the missing strict bridge-domain glob gate, which reaches the same `[Match] Name=` sink as `br-<name>`.
- **Files**: `pkg/rendersafe/rendersafe.go`, `pkg/rendersafe/rendersafe_test.go`, `pkg/networkd/networkd.go`, `pkg/networkd/refuse_glob_name_10089_test.go`, `pkg/daemon/linksetup.go`, `pkg/daemon/linksetup_glob_10089_test.go`, `pkg/daemon/daemon_reth.go`, `pkg/daemon/reth_link_glob_10089_test.go`, `pkg/config/schema_validators_bridge_domain_9494.go`, `pkg/config/bridge_domain_glob_10089_test.go`.

## Defect

The #9886 predicate answers the narrower question “does this value occupy exactly one whitespace-separated systemd match slot?” A value such as `ge*` does, so it passed `SafeInterfaceName` and was rendered as raw `Name=ge*`. systemd interprets that one slot as a shell-style glob and the unit claimed every matching device while `Apply` returned success. The strict bridge-domain validator had the same hole: `bridge-domains ge*` committed and the dataplane rendered `Name=br-ge*`.

## Fix and scope boundary

`rendersafe.FirstGlobMetacharacter` reports the first ASCII glob token. The `networkd.Apply` pre-`expected` belt keeps #9886's whitespace/control refusal unchanged, then refuses a glob-bearing `ifc.Name` or `ifc.OriginalName` with an error naming the token and `#10089`. Because the refusal happens before `expected`, stale poisoned `10-xpf-*` units are swept like a deleted interface. Valid siblings remain byte-identical. `daemon.writeLinkFile` and the direct RETH repair writer apply the same #10089 guard to `[Match] OriginalName=` before building the path or content; their `[Link] Name=` targets remain literal, non-match syntax.

`RendersAsOnePattern` and `SafeInterfaceName` intentionally continue to pass globs; they describe the #9886 slot-count/control property, not the separate literal-pattern policy. The strict bridge-domain validator uses the same token classifier and reports the `br-`-prefixed `[Match] Name=` sink. Whitespace remains in #9886/#9494's error scopes, with regression coverage.
