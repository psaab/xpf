# #16662 — Packed hierarchical `time-wait-state session-timeout N;` / `time-wait-state session-ageout;` pass strict commit and compile to nothing (R3-N08-06)

- **Timestamp**: 2026-10-25
- **Context**: #15753 added the `time-wait-state` knobs and #15946 wired
  them to the dataplane, but the compiler loop in
  `pkg/config/compiler_security_flow.go` iterated only
  `twNode.Children`. The hierarchical parser packs
  `time-wait-state session-timeout 120;` onto `twNode.Keys[1:]` with no
  Children, so the packed spelling passed `SchemaValidate` / strict
  commit, `show` displayed the authored text, and
  `TimeWaitStateSessionTimeout` stayed 0 / `TimeWaitStateSessionAgeout`
  stayed false — the helper kept its default close-window handling.
  The same drop hit `apply-to-half-close-state` and its deprecated
  alias, and multi-leaf packed runs.
- **Fix**: the time-wait-state loop now reads
  `expandFlatRun(packedBodyChildren(twNode, refFlowTimeWaitState.resolve()), refFlowTimeWaitState.resolve())`.
  `packedBodyChildren` expands the packed tail against the
  time-wait-state schema (returning Children unchanged for the braced
  spelling, allocation-free on that path) and `expandFlatRun` splits a
  packed run carrying several leaves into one node per leaf. A new
  static `refFlowTimeWaitState` SchemaRef (audited by
  `TestSchemaRefsResolve`, init-panicking on a dead path per #16147)
  replaces a stringly path lookup. Because the compiler now reads the
  packed tail, the schema node opts into `packedTail` validation (the
  #6821 bidirectional contract: the gate validates the same expansion
  the compiler descends), and `walkSchemaNode` rejects a declined
  packed tail under a closed-world container — without that pairing,
  an out-of-range packed `session-timeout` or a near-miss packed leaf
  validated clean while the braced spelling rejected. The flat
  `set ... time-wait-state ...` shape (`tcp-session time-wait-state
  ...` packed onto the tcp-session node) remains out of scope: it was
  already dropped at base and belongs to the #8939 tcp-session
  container shape, not this per-site fix.
