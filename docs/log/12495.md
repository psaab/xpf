- **Timestamp**: 2026-10-14
  - **Action**: read the issue, parent #12201, PR #12416, and the #6934
    measurement log. Established the attribution problem the lab leg must
    solve: after an RG failover BOTH the becomeMaster unsolicited-NA burst
    and the daemon RA stream (SLLA for the stable RETH link-local, #6934
    measured first-new-master RA 0.58 s after the failover command) can
    repair the LAN host's gateway neighbor entry, so a transit probe alone
    cannot attribute recovery to the burst. The discriminator is the GLOBAL
    VIP's neighbor entry: an RA's SLLA rewrites only the entry for the RA's
    own source address, while a global unicast's entry is rewritable only
    by an override NA (or the host's own re-resolution, which the wire
    timeline rules in or out).
