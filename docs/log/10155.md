# Issue #10155 — classify networkd rp_filter writer

## Why

`TestNoDirectOsWriteFile` found the direct `os.WriteFile` at
`pkg/networkd/networkd.go:717`. The existing allowlist entry named the outer
`restoreSlowPathRPFilter` loop, but #9637 moved the write into the
`restoreSlowPathRPFilterOn` leaf helper.

## What

The write is a `BestEffortKernelKnob`: it writes the procfs `rp_filter` knob,
where rename-based fsatomic writers are impossible by construction. The
receiver-aware canary allowlist now names the leaf helper that actually owns
the direct write and documents the #9637 split. The two #9725 daemon entries
are unchanged.
