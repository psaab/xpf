## Change

The Rust encoder and Go decoder already agree on the frame contract: after the ingress identity, open frames carry a two-byte policy-rule-ID length, optional rule-ID bytes, then a one-byte TCP handshake state. For the empty-rule-ID fixtures, the post-domain suffix is 21 bytes, not 18; the keyed-tunnel common prefix ends 33 bytes from frame end. The #9412 shared golden also pins the empty rule-ID prefix plus handshake state. The failures came from test reads predating that three-byte suffix, not a production encoder defect.

Updated the affected assertions in `userspace-dp/src/event_stream/codec/codec_tests.rs` to account for the empty rule-ID prefix and handshake byte, including the variable rule-ID test and install-table tail indexes. `session_sync.rs` and the Go decoder remain unchanged.
