## Design (MEDIUM tier; brief + adjudication on the issue)

Go-only, no wire/Rust: Rust cannot re-derive a dropped leaf from a snapshot
(the leaf left no trace), so any tombstone must originate in Go — and a
Go-side warned-skip is the identical dataplane outcome (rule absent from the
table) with no coupling to sibling lane #9874's merge order.

1. **Record**: new `default:` arms in the 3 match switches append `m.Name()`
   to new exported `json:"-"` fields `NATRule.UnknownMatchLeaves` /
   `StaticNATRule.UnknownMatchLeaves` (mirrors `Policy.UnknownChildren`;
   first-seen deduped; verdict = non-empty).
2. **Gate**: new `validateNATUnknownMatchLeavesStrict` wired into
   `runUniformGatesNAT` on shared `lenientDestNATAddresses`, BEFORE the
   #8430 gate (precise cause beats generic effect); #8430 suppresses rules
   carrying unknown leaves (one mistake, one warning); the message states
   the disposition (not-installed vs widened-exemption, total vs partial).
3. **Poison = Go warned-skip**: extend
   `DestinationNATRuleExcludedReason`/`StaticNATRuleExcludedReason` (builders
   + natshow already share them); new `SourceNATRuleExcludedReason` + skip in
   `buildSourceNATSnapshotsWithFeeds` + composition into
   `SourceNATRuleNotInstalledReason` (before the pool-mode gate) +
   `pkg/natshow/source.go` annotation (before the pool gate; hits line gated
   on the verdict per #8185); #6812 charge walk excludes marked rules before
   `seen`-marking, reusing the builder predicate.
4. **Exemptions install warned** (keyable): skipping an `off` rule would
   translate traffic the operator exempted. Unkeyable DNAT exemptions
   (destination was the dropped dimension) skip AND report. NPTv6 rules
   record and skip too (unknown-leaf clause precedes the `IsNPTv6` early
   return — a typo'd scope leaf must not evade the #5818 drop).
5. Mechanical: `#6534` showaudit census row, `#6812` axis-sweep
   `fixtureConstantAxes` registration (collector reflects all fields).

Two blind plan reviews, both APPROVE-WITH-CHANGES, no KILL. They caught the
NPTv6 hole, the unkeyable-`off` renderer lie, the walk `seen` placement, the
interface-mode annotation gates, the census/sweep registries, and the
skip-vs-`Unavailable` residual (accepted: fall-through to a later VALID
rule's authored match, warned at load — strictly safer than silent widened
translation; wire unification with #9874's bit is a follow-up).

## Parent review fold (GPT + SPARK convergent, 6 items)

1. **Compact escape (GPT-1).** Brace-elided unknown leaves never unfold (the
   normalizer folds only schema-modeled heads) and the loops read Children
   only — a compact typo beside a surviving valid block compiled silent and
   constrained. Fixed by recording unmodeled packed heads
   (`len(Keys)>1` + schema-backed `natMatchLeafKnown`, the same map the
   normalizer consults — no drift, declined valid folds untouched) in all 3
   compilers. Pinned by per-direction spelling-equivalence cells
   (compact ≡ braced marker + warning + verdict) plus compact-typo-only.
2. **NPTv6 preflight (GPT-2 + SPARK-M1).** `compileNPTv6` and
   `NPTv6OverlapConflict` derived inclusion from scope-only, so a marked
   rule with an invalid prefix (or overlapping a healthy one) hard-failed
   the whole apply although the snapshot omits it. Both sites now consult
   `StaticNATRuleExcludedReason`. Pinned by marked bad-prefix tripwire +
   marked-overlap (both seen positions, predicate + compile level);
   verified red-on-revert.
3. **Disposition truth (GPT-3).** Warnings contradicted reality: total-loss
   source exemptions DROP (Rust checks the poison before `off`), and
   unkeyable dest exemptions skip. Gate messages are now a kind-aware
   disposition matrix reporting the actual outcome; exemption oracles assert
   the tombstone marker, not just row+Off.
4. **Enumeration (GPT-4).** The gate returned the first offender, leaving
   later marked rules (skipped or widened) silent. Lenient now warns per
   DISTINCT marked rule (pointer-deduped for scope-expanded sharing);
   strict keeps first-error (delegates to enumerator[0], same-first by
   construction). Pinned by multi-offender (distinct keywords) + shared-
   pointer dedupe cells.
5. **Dest hits gating (Spark m-2).** Mirrored the source #8185 shape in the
   dest renderer (hoisted verdict + gated hits read) with a no-hits-line
   cell; skipped dest rules print no counter.
6. **Overlap ruling (Spark m-3): DISARM-WINS** — supersedes the skip-wins
   adjudication above. Both-markers source rules ship the #9874 tombstone
   (deny: drop + stop) instead of skipping (fall-through): unknown intent
   fails closed. `SourceNATRuleExcludedReason` yields when
   `LenientMatchDropped` is set; note-site precedence falls through to the
   ADMITTED note; cross-cells rewritten (tombstone row + marker,
   ADMITTED-wins, drop-disposition warning text). Destination unchanged
   (same skip outcome, #9874 first-cause text). Rationale recorded here and
   at the predicate + builder + gate.
