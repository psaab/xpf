# #10673 — Do not treat a known ICMP type mismatch as flowless L4-need

- **Timestamp**: 2026-09-25
- **Action**: An ICMP type/code constraint is an L4-need for fragment-deny overlap only while the packet's ICMP type is unknown. A known type that misses a constrained deny is a definite application mismatch and must not shadow a later permit; unknown-type fail-closed behavior remains unchanged.
