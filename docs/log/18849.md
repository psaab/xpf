# #18849 — compile brace-elided AppID presence

- **Timestamp**: 2026-11-05

## Why

The parser keeps `services application-identification { … }` packed on the
`services` node as `Keys=["services", "application-identification"]`. The
compact normalizer declines attaching the elided body to this complete
zero-argument flag leaf (`children: nil`, `declineLeafBody14343`).
Consequently, `compileServices` found no `application-identification` child
and silently compiled AppID as disabled, while the braced
`services { application-identification { … } }` spelling enabled it.

## What

- `compileServices` now checks the packed second key for
  `application-identification` as well as the existing braced child lookup,
  matching the packed-presence handling used by `dhcpRelayV4Node9411`.
- Left `TestAdmittedPairsCompileLikeBraced8879` unchanged.

## Action

Have `compileServices` inspect the packed second key for the zero-argument
AppID presence flag, while retaining the existing braced-child lookup.

## File(s)

- `pkg/config/compiler_services.go`
- `docs/log/18849.md`

GOTMPDIR=/wtgt TMPDIR=/var/worktrees/.cache/tmpdir` through

  `services_application-identification`; it requires the elided and braced
  forms to compile to `appid=true`.
- The four `TestServicesUTM*16079` tests pass.
- `TestCompactBlockEquivalenceInventory2419` and
  `TestCompactBlockCensusReport2419` pass.
- Full `go test ./pkg/config -count=1` was not green: it reported failures in

  `TestResolveSyslogSourceAddrForCollector_KernelLoopback15078`, and other
  config tests, then timed out after 10 minutes while
  `TestTheUnobservedBucketIsClassified_8690` was still running its census.
- **Fail-on-revert**: restoring the original child-only lookup while leaving
  the rest of the compiler unchanged makes the AppID elision cell fail with
  `elided compiles to "appid=false" but braced compiles to "appid=true"`.
- Post-normalizer probe confirmed that the braced and elided ASTs remain
  structurally distinct and that the elided node reaches `compileServices`
  with the packed second key intact.

## Risk

The added read is limited to the exact second-key presence flag. Braced child
handling and all other packed `services` tails are unchanged.
