# Issue #10024 — guarded operator rollback

## Implementation

- Added `xpfd upgrade --rollback` for standalone nodes and `xpfd upgrade --rollback --rolling` for HA nodes.
- Added the side-effect-free `xpfd --capability-check` envelope-reader probe.
- Added pre-STOP restorability, snapshot, and envelope compatibility refusal gates.
- Operator rollback restores the current version's preflight config-DB snapshot, retains the failed DB at `.configdb.old`, flips the versioned runtime, starts the target, and requires the target helper-health gate.
- HA rollback performs preflight before peer checks, demotion, strong drain, rollback, sync re-establishment, and per-redundancy-group rejoin confirmation.
- Documented the command and refuse-with-guidance policy in `docs/in-place-upgrade.md`.
