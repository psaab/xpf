# Preserve complete junos-host application resolution (#13133)

- **Issue**: #13133, source finding D2-01 (deep-review; validated by the three-way research gate).
- **Cause**: `junosHostResolveApplications` expanded a mixed direct+term application's implicit set before checking `MixedDirectTermApps`, so the resolver treated only generated term members as a complete deny match. `junosHostReduceApp` also accepted only transport/ICMP names and numeric protocols; valid named IP protocols therefore made the entire zone projection unrepresentable.
- **Change**: Reject mixed direct+term applications before implicit-set expansion and when they occur in nested sets, preserving app-before-set name precedence. Reduce the IANA protocol names accepted by the strict application protocol gate (`gre`, `ipip`, `ospf`, `igmp`, `pim`, `sctp`, `vrrp`, `egp`, `ipv6`, plus supported Junos aliases) to their protocol numbers. Keep ESP/AH and other exempt tuples on the existing fail-closed IPsec/ident ownership path.
- **Regression coverage** (`pkg/config/junos_host_deny_resolve_13133_test.go`): tolerant mixed direct+term application, nested set reference, named protocol-number resolution, AH/ESP exemption controls, and an end-to-end `junos-gre` plus SSH deny projection proving one valid protocol no longer withdraws sibling enforcement.
- **RED evidence**: On pristine `origin/master` at `55ab81ef0` with only the new regression test, `GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/config/ -run TestJunosHostResolveApplications13133 -count=1` failed: the mixed app was accepted, named IP protocols were refused, and `junos-gre` withdrew the zone program.
- **Validation**: Focused regression passed after the fix; `go build ./...` and `gofmt` on both changed Go files passed. The default `go test ./pkg/config/... -count=1` exceeded its 10-minute timeout in `TestSchemaSpellingDifferentialGate` during concurrent bcrypt work; `go test ./pkg/config/... -count=1 -timeout=30m` then passed (`ok ... 894.277s`). `git diff --check` passed.
- **Blast radius / risk**: Change is confined to the control-plane junos-host application projection. Unsupported/mixed application references continue to refuse the entire affected zone program; the fix does not weaken fail-closed handling or alter userspace policy compilation.
