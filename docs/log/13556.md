# Issue #13556: Preserve ingress ifindex in decoded flow events

## Why

`DecodeRawEventRecord` reads the wire ingress ifindex from `[128:132]` into
`rawEvent.IngressIfindex` but did not copy it into the returned `EventRecord`.
The production userspace eventstream routes the RT_FLOW payload through that
decoder; the daemon's NetFlow and IPFIX close callbacks copy
`EventRecord.IngressIfindex` into `SessionCloseData.InIf`, which supplies
NetFlow v9 IN_SNMP / IPFIX ingressInterface (IE 10). The dropped assignment
therefore exported ingress interface zero for decoded SESSION_CLOSE records.
The direct ring-buffer `logEvent` path already preserves the value.

## What

Assign `evt.IngressIfindex` in the `DecodeRawEventRecord` `EventRecord` literal.
Add `TestDecodeRawEventCarriesIngressIfindex13556`, which writes a nonzero
little-endian ifindex to `[128:132]` on a SESSION_CLOSE wire frame and asserts
that the decoded record retains it. Extend
`TestEventStreamSessionCloseRTFlowRoutesToRawCallback` to send the same field
through the production eventstream frame decoder and assert the resulting
record retains it. Scope is limited to the missing decoder assignment and
these regression assertions.

## Validation

On pristine master `5fba34bd2`,
`GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/logging -run '^TestDecodeRawEventCarriesIngressIfindex13556$' -count=1`
failed as expected: `rec.IngressIfindex = 0x00000000, want 0x0a0b0c0d`.

After the fix, the same focused command passed. Reverting only the assignment
reproduced the same assertion failure; restoring the assignment passed again.
`GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/.cache/go-tmp go test ./pkg/logging -count=1` passed (`6.887s`).
`GOCACHE=/var/worktrees/.cache/go-build GOTMPDIR=/var/worktrees/t13556 go test ./pkg/daemon ./pkg/dataplane/userspace -run 'TestSessionCloseRawEventDrivesFlowExport|TestEventStreamSessionCloseRTFlowRoutesToRawCallback' -count=1` passed both packages. The eventstream test sends the nonzero ingress index in the production frame and confirms it remains in the decoded record. `gofmt -l pkg/logging/ringbuf.go pkg/logging/binary_test.go pkg/dataplane/userspace/eventstream_test.go` produced no output.

An attempted full `pkg/dataplane/userspace` suite failed on unrelated existing
failures, including Unix socket `bind: invalid argument` under the long
`/var/worktrees/.cache/go-tmp` temporary paths, contract snapshot golden drift,
and unrelated interface/snapshot assertions. The focused eventstream and daemon
flow export tests passed with a shorter temp path.

## Risk

No wire format or live ring-buffer behavior changes. Decode-only event records
now preserve the ingress ifindex already present in the payload.
