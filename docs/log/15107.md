# #15107 — `clear firewall all` must clear the helper's filter counters (A64-03)

- **Timestamp**: 2026-10-18
  - **Action**: `LegacyDataPlaneAdapter` had no `ClearFilterCounters`, so the
    embedded bpfShim method was promoted and zeroed the retired-eBPF
    `filter_counters` array while the CLI printed "Firewall filter counters
    cleared". Added `Manager.ClearFilterCounters` (bpfShim leg + new
    `clear_filter_counters` IPC), the adapter override, and the
    `clearHelperFilterCountersLocked` leg in `ClearAllCounters`. Helper side:
    new `clear_filter_counters` control arm resets every `FilterTermCounter`
    in place and every per-colour policer counter; the filter coalescer
    gained the #3448 generation guard so a pre-clear pending batch is
    discarded instead of resurrecting the cleared totals, and resets use
    the #3782 observe-then-`fetch_sub` discipline so post-clear increments
    survive. This is the residual filter member of the #6566 census
    (#2218 NAT, #3651 zone, #6566 policy were already fixed).
