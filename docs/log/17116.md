# #17116 — Single-source the synced-import outcome wire contract

- **Timestamp**: 2026-10-27
  - **Action**: Consolidated the `SyncedImportOutcome` ->
    `ControlResponse.error` encoding into one exhaustive
    `SyncedImportOutcome::wire_error()` in
    `userspace-dp/src/afxdp/ha/session_import.rs`, with an explicit class
    per variant (Ok / Repair / TerminalRefusal / RetryableRefusal for
    `RejectedGateBusy` / Bare for `RejectedMirrorPublish`) documented on
    the encoder and a `pub const ALL: [Self; 11]` plus `variant_name()`
    so a new variant fails to compile until it has a wire class. Wire
    bytes are unchanged. `apply_synced_import_outcome` in
    `server/handlers/sync_session.rs` is now
    `if let Some(e) = outcome.wire_error() { response.ok = false;
    response.error = e; }`, and the unknown-routing-domain refusal routes
    through the same encoder; the handler's `reason ==
    "mirror-write-failed"` string special case and its
    `SYNCED_IMPORT_REPAIR_PREFIX` import are gone.
    `SYNCED_KEY_INCOMPLETE_REFUSED_PREFIX` in
    `server/helpers/session_sync.rs` is now built in const context from
    `SYNCED_IMPORT_REFUSED_PREFIX` (no second literal of the prefix;
    `grep -rn '"synced-import-refused:' userspace-dp/src` = 1 and
    `grep -n '== "mirror-write-failed"' userspace-dp/src` = 0). The old
    repair-only fixture `synced_import_repair_11360.json` was extended
    into `pkg/dataplane/userspace/testdata/synced_import_wire.json`, one
    row per variant `{variant, ok, error, go_class}`; the Rust test
    `synced_import_wire_fixture_covers_every_outcome_17116` iterates
    `ALL` and pins the exact `ok`/`error` bytes per row, and Go's
    `TestSyncedImportWireClassifierMatchesRustEncoder17116` drives
    `requestSessionSyncResponseLocked`'s classifier (via
    `requestSessionSyncResponse` over a scripted helper socket) over the
    same rows, asserting the recorded `go_class`. The formatting-regex
    test `TestMirrorWriteFailedWireAgreement10788` (which pinned the
    handler's string compare by regex) is deleted, and the stale comment
    at `control_work_deadline_9344.go:58` citing the deleted
    syncedImportRefusedPrefix agreement test now cites the shared wire
    fixture instead. `refusal_reason` is `pub(crate)` (consumed only by
    `wire_error` and token-distinctness tests); `repair_reason` stays
    public.
