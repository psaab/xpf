# #12651 — smoke attestation VOID when checkout moves past deployed SHA

- **Timestamp**: 2026-10-13
- **Action**: added `make cluster-deploy-and-gate` to build before entering the cluster lock, then deploy and invoke the selected smoke gate in one locked wave. Because the cluster lock does not lock Git operations, the runner compares the deploy-time checkout identity immediately before the gate and refuses to run it if checkout moved. Exact manifest identity remains required.
- **Validation**: deploy-lib selftest simulates a checkout commit during deployment and verifies the gate is not invoked; an unchanged checkout reaches the gate.
- **Risk**: CLUSTER_GATE defaults to test-connectivity; other gates pass CLUSTER_GATE=<gate>.
