# #14337 — policymatch FeedPublicationDebt over-taint + nil-IP excluded-empty fail-open

## Defect
- `ruleMatchesWithMemo` (pkg/policymatch/policymatch.go) evaluated source then
  destination addresses — each `resolvePolicyAddressToken` noting debt into the
  query-global `addressMemo.consultedPublicationDebt` — *before* `matchApp`, with
  no rollback on a miss. `Match`'s deferred override then replaced an otherwise
  successful result wholesale with `{FeedPublicationDebt:true, Action:Deny}`,
  wiping matched/`HostInbound` context. An earlier rule eliminated on a static
  dimension (wrong application, wrong other-side address) but naming a
  debt-bearing feed therefore poisoned unrelated traffic's simulator verdict
  (operator `match-policies`/`test policy`, REST, gRPC, daemon reauth surfaces).
- `matchAddrWithMemo: if ip == nil { return true }` short-circuited before
  resolving tokens: an omitted-IP query against a `*-address-excluded` side over
  a defined-but-empty feed matched (`Matched:true, Permit, Debt:false`) where
  the same query with a concrete IP failed closed, and no debt was recorded.
- `isBookName`/`expandBookNameWithMemo` did not consult
  `cfg.Security.DynamicAddress.AddressBindings` when the token was absent from
  the overlay (nor unqualify zone-local tokens), so a declared binding could be
  parsed as a free-form literal instead of an (empty) book name. The live path
  for an absent-overlay binding is whole-snapshot `ContentRejected` (verified),
  so this leg is defence-in-depth parity with the snapshot builder, which
  treats declared bindings as names via `dynamicAddressLookupName`.

## Fix (pkg/policymatch/policymatch.go only)
- Per-rule debt scoping: `ruleMatchesWithMemo` now checks scheduler, then
  `matchApp`, then evaluates each address side in a child memo
  (`addressExpansionMemo.ruleScope/commitTo/adoptCache`; the resolved-prefix
  cache stays shared). Debt commits only when decisive: the failing side's own
  debt, or both sides on a match. Debt from a side that already passed, from an
  app/scheduler-eliminated rule, or from a destination never reached, is
  discarded (cache still adopted). `isSkippedFragDenyWithMemo` uses the same
  scoping for its L3-overlap probe (commit only on overlap).
- Nil-IP: non-excluded sides keep unspecified-tuple semantics; excluded sides
  resolve tokens, record debt, and fail closed when empty across both families
  (a bare empty excluded list with no tokens still matches, preserving prior
  empty-list behaviour).
- `isBookName` returns true for a declared `AddressBindings` entry (zone-local
  unqualified); `expandBookNameWithMemo`/`noteFeedPublicationDebt` unqualify
  zone-local names before overlay/binding/debt lookups.

  debt never consulted when the source side eliminates the rule.
