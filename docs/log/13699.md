# Keep SYN-ACK misses from arming SYN-cookie mode (#13699)

- **Issue**: #13699, deep-review Finding D14-20 (High).
- **Cause**: `syn_ack_flood_drop_on_new_flow` sent session-miss SYN-ACK packets through `syn_flood_gate` with the real cookie-codec availability. Once the shared aggregate crossed its attack threshold, that gate armed `syn_cookie_active_until_secs` even though the SYN-ACK path dropped instead of sending a challenge. The active window then disabled the per-source SYN sketch for subsequent initial SYNs and changed session-miss cookie-ACK handling.
- **Change**: Added an explicit cookie-activation eligibility input to `syn_flood_gate`. The ordinary initial-SYN path allows activation as before; the SYN-ACK miss path still meters and aggregate-drops an over-threshold packet but cannot arm cookie mode.
- **Regression coverage** (`userspace-dp/src/screen/tests.rs`): a SYN-ACK miss burst crosses the aggregate attack threshold but does not set the active deadline; after its aggregate window expires, a distinct initial-SYN source still trips the per-source sketch. A guarded-twin case confirms an ordinary initial-SYN flood still arms cookie mode. Existing SYN-ACK aggregate-drop coverage remains intact.
- **RED evidence**: With the new eligibility guard disabled, `cargo test --manifest-path userspace-dp/Cargo.toml syn_ack_miss_flood_does_not_latch_syn_cookie_active_13699 -- --nocapture` failed at `syn_cookie_active_until_for_test`: actual deadline `164`, expected `0`.
- **Validation**: The focused regression passed (1 test), and the complete rebased `screen::tests` module passed (`271 passed`). The rebased full crate suite included the final regression and reported `8104 passed, 7 failed, 8 ignored`; a full suite on the exact master parent reported `8103 passed, 7 failed, 8 ignored`. All seven failures were identical baseline failures: `f035_parked_fragment_overlap_is_rechecked_on_retry_10659`, `gre_decap_inner_icmp_echo_denied_by_host_inbound_reads_inner_type`, `gre_decap_session_hit_host_inbound_reads_inner_icmp_type_5615`, `c3_forward_control_survives_full_window_per_permit_shape_10591`, `worker_loop_orders_expiry_teardown_before_poll_10419`, `test_empty_excluded_destination_fails_closed_v6`, and `additive_wire_exhaustive_literals_only_ever_decrease_7689`. The temporary test-only import workaround used on the earlier base was removed and is not part of this change.
