- **Timestamp**: 2026-09-12
- **Action**: Cause, in `mergeNodes` (`pkg/config/ast_groups.go`).
  1. A group container with no same-keyed destination is appended wholesale.
     The subtree is never recursed into, so a wildcard-keyed node inside it is
     never matched and lands as a literal instance name.
  2. A group container merges into the FIRST same-keyed destination and stops,
     so a level the operator spread over two blocks receives the group in only
     one of them.
- **Action**: Change, in `pkg/config/group_container_wildcard_9802.go` (new)
  with two edits to the container branch.
  - **Prune.** A wildcard-keyed node in an adopted subtree matched nothing by
    construction, so it is dropped before the #6767 charge, and a container
    whose whole body was wildcard-keyed is not adopted at all.
  - **Prune scope, measured.** The discriminator is the node's SHAPE, not the
    schema: a zone's `interfaces` member slot is declared as a wildcard child
    WITH children, exactly like a dynamic instance name. A schema-shape
    predicate therefore pruned `interfaces { <ge-*>; }` inside an adopted zone,
    and the strict refusal that names the token turned into a clean commit.
    Only a wildcard CONTAINER, or a wildcard leaf carrying an instance name
    (two or more keys), is dropped; a single-key wildcard leaf is a member and
    is left to the compiler's reference check (#9423).
  - **Routing.** A group container's wildcard-keyed children go to every
    same-keyed destination container, each clone charged as the wildcard branch
    charges its fan-out; the rest go to the first container that already holds
    a match for one of them, else the first, as before. Splitting the body is
    what keeps a concrete block from being duplicated across stanzas.
