## Lane 1 — `TestRoutingDomainOffsets9546`

- **Timestamp:** 2026-11-05
- **Action:** Reordered the sync-only `NatScopeIfindex` field to follow on-map `RoutingDomain` in both wide session structs. Regenerated the two #9752 JSON goldens whose tests compare the exact `json.Marshal` output; field values are unchanged.
- **File(s):** `pkg/dataplane/types.go`, `pkg/dataplane/userspace/testdata/installed_val_9752.json`, `pkg/dataplane/userspace/testdata/synced_val_9752.json`, `docs/log/18847.md`.

### Why

At `origin/master` `3964e0ced7f2893c5c45005002726c10c3f76c5c`, `NatScopeIfindex` preceded `RoutingDomain` in both wide structs. The pinned on-map offsets remain v4 144 and v6 192, while the wide offsets were 148 and 196. `NatScopeIfindex` is Go-local/sync-only, not part of the BPF ABI; it must not push the on-map routing-domain field out of the shared prefix.

### What

Moved `NatScopeIfindex` immediately after `RoutingDomain` in `SessionValue` and `SessionValueV6`. The C/Rust mirror structs, 144/192 routing-domain pins, and tests were not changed. `pkg/cluster/sync_protocol.go` writes and reads `RoutingDomain` explicitly at its existing length-gated trailing wire slot, so the HA wire layout is unaffected.

The fixtures use named JSON properties, but the existing #9752 chain tests compare their bytes directly with `json.Marshal` output. Moving the Go fields changes that serialized property order, so both generated goldens were refreshed through their existing producer tests. The installed and synced values themselves did not change.
