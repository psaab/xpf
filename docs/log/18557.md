# #18557 — NAT64 path errors use expected-zone RELATED admission

- **Why**: Both NAT64 ICMP-error directions translated Time Exceeded and
  Destination Unreachable but marked only PMTUD as RELATED. Under default
  deny, expected-zone errors were sent through the reverse zone-policy pair
  and dropped.
- **What**: Both NAT64 arms now use `outer_is_related_path_error`, preserving
  the direction-derived arrival-zone checks. Supported path errors are
  RELATED only from the quoted session's expected zone. Added four default-
  deny delivery cells (Time Exceeded and Destination Unreachable, v4→v6 and
  v6→v4), retained #9948 wrong-zone denial, and retargeted #14123/#14316 gate
  cells to untrusted wrong-zone arrivals.
