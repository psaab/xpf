# #17112 — `pkg/zonecounters`' the false linkage claim rationale is false

- **Timestamp**: 2026-10-27
  - **STEP-0 — defect live on current origin/master?** Yes, at `a5b58f5fd6`.
    `pkg/zonecounters/zonecounters.go:4-12` claimed the #1451
    retirement-boundary canary "deliberately keeps cmd/cli free of root
    pkg/dataplane: the remote cli speaks gRPC and must not link the
    dataplane", and `docs/log/6895.md:39-40` repeated it. Measured on the
    same tree: `go list -deps ./cmd/cli` contains `pkg/dataplane`,
    `pkg/dataplane/userspace`, `pkg/nftables`, `pkg/routing`, `pkg/ipsec`,
    `pkg/logging`, `pkg/networkd` and `pkg/configstore` (36 psaab packages
    total). Shortest chains: `cmd/cli -> pkg/dataplane/userspace ->
    pkg/dataplane` (and likewise to nftables/routing/ipsec/logging/
    configstore/networkd), plus `cmd/cli -> pkg/monitoriface` and
    `cmd/cli -> pkg/policymatch`, both of which import
    `pkg/dataplane/userspace`; policymatch also imports root
    `pkg/dataplane` directly (`zone_detail_summary.go:9`), and `pkg/diagcmd`
    pulls in `pkg/routing` on its own. The canary
    (`TestOperatorPackagesOnlyUseDocumentedLegacyDataplaneImports`) only
    allowlists per-file direct imports and skips the whole `pkg/dataplane`
    tree, so it never saw any of this.
  - **Fix direction chosen: Option B.** The issue offers A (move the five
    argv parsers and `*Usage` constants to a dependency-free
    `pkg/dataplane/userspace/cliargs`, move the `ProcessStatus` value types
    monitoriface renders to a types-only subpackage, cut policymatch's
    root-dataplane edge — explicitly noted as q45 scope — and pin an empty
    `go list -deps` closure) or B (delete the false sentences; acceptance:
    `rg` for the retired phrase returns 0). B was implemented. A is
    a multi-package refactor whose policymatch part belongs to another
    finding's scope and whose `ProcessStatus` split touches ~550 reference
    sites; doing it under this Low-severity doc finding would be the
    wrong-scope fix the issue's own gate verdict (COHORT — "the cost is a
    misleading rationale and an unguarded coupling... limited to that")
    argues against. The unguarded coupling is now documented as unguarded,
    in the package doc itself, rather than disguised as a boundary.
  - **What changed.**
    - `pkg/zonecounters/zonecounters.go`: the false rationale is replaced
      with the true one — the leaf exists so the three surfaces share the
      wording without an extra direct import of root `pkg/dataplane`; that

      "already links pkg/dataplane, nftables, routing, ipsec, logging,
      networkd and configstore transitively... Nothing keeps the remote
      CLI free of the dataplane at link time".
    - `docs/log/6895.md`: the same sentence corrected in place with an
