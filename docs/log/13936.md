# Issue #13936 — reject IPv6 units below the minimum link MTU

IPv6 requires a link MTU of at least 1280 bytes. A unit could previously
commit an effective MTU below that minimum, including when a low `family inet
mtu` was folded into the unit MTU; networkd then applied the low link MTU and
the kernel removed the unit's IPv6 addresses.

The strict commit gate now rejects IPv6-bearing units when their effective
configured MTU is below 1280. It covers static IPv6 addresses, DHCPv6, and
IPv6 family presence, including `family inet mtu` min-folds and the
interface-level MTU fallback. IPv4-only units retain their existing MTU
range, exactly 1280 remains valid, and tolerant loads warn rather than
blocking boot of persisted configuration.
