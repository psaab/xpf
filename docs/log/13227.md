# Issue #13227: remove legacy all-RG HA hooks

Source finding D4-09 identified five daemon wrappers with no production
callers. The two legacy service hooks were unsafe: `applyRethServices` applied
RA and DHCP across all RGs without snapshot-based per-RG authority, while
`clearRethServices` provided a global clear. Production transitions already use
the per-RG hooks.

Removed both all-RG hooks and the three obsolete convenience wrappers
(`isAnyRethInstanceMaster`, `desiredClusterDHCPConfig`, and
`filterDHCPConfigForMasterRGs`). Migrated tests to the RG state predicate and
the explicit master-snapshot APIs; no compatibility wrappers remain. Added an
AST regression guard for all five declarations. Updated comments/docs that
referred to the removed convenience APIs.
