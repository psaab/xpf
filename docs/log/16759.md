# Issue #16759: IPsec traffic-selector chained after other VPN leaves in one set run is silently dropped

- **Timestamp**: 2026-10-25
  - **Action**: `compileIPsec` and `validateIPsecTrafficSelectorsStrict` read `traffic-selector` only as a direct child of the VPN node. A selector chained after `gateway`/`ipsec-policy`/`bind-interface` in one flat `set` command is nested inside the packed run (synthesized by `expandIPsecVPNRun9088` as `Keys=[traffic-selector ts1 local-ip <l> remote-ip <r>]` with no children, because the schema declares `traffic-selector` with children so `expandFlatRun` cannot descend into it), so both readers saw nothing: the typed VPN compiled with zero selectors, `EffectiveTrafficSelectors` widened the route-based SA to `0.0.0.0/0,::/0` on both sides, and the #4098 injection / #5692 duplicate / #12507 padding gates were bypassed for the dropped values while `show configuration` still displayed the selector. Added `trafficSelectorInstances16759` (`pkg/config/compiler_ipsec_trafficselector_run_16759.go`), the single run-aware discovery shared by the compiler and the validator: it collects direct braced/split instances and reconstructs chained/compact-tail segments into a normalized `[traffic-selector <name>]` node whose `local-ip`/`remote-ip` flat tail is split at those keywords, so callers segment leaves with the existing `ipsecTrafficSelectorSchema8939()` exactly as for the direct spelling (preserving #12507 canonicalization, #5692 value counting, and last-wins accumulation). Both `compileIPsec` (compiler_ipsec.go) and `validateIPsecTrafficSelectorsStrict` (compiler_ipsec_trafficselector.go) now iterate it.
  - **File(s)**: `pkg/config/compiler_ipsec_trafficselector_run_16759.go` (new), `pkg/config/compiler_ipsec.go`, `pkg/config/compiler_ipsec_trafficselector.go`, `pkg/config/compiler_ipsec_ts_chained_16759_test.go` (new), `debian/changelog`, `docs/log/16759.md`
  - **Validation**: New `TestIPsecChainedTrafficSelectorCompiles16759` (chained-full, chained-bind-only, selector-in-own-run, split and braced controls, #12507 `/08` canonicalization) and `TestIPsecChainedTrafficSelectorValidated16759` (strict #4098 reject of chained `local-ip not-a-prefix`, lenient #4098 warning with selector kept, #5692 duplicate-in-run reject, two chained named selectors accumulating) — all PASS with the fix. RED on revert (fix files removed, tests kept): chained cells fail with `TrafficSelectors=map[]`, the strict invalid chained value is accepted, and the lenient #4098 warning is absent.
