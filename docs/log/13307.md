- **Date**: 2026-10-15
- **Issue**: #13307
- **Why**: `ExportConfig.ShouldExport` silently rejected zone-ineligible flows and sampled out eligible flows without observable counts; the fail-closed empty zone map introduced for #11433 could therefore reject every session while exporter build/write health looked healthy. Excluded `flow-server` stanzas were also silently skipped by `collectInstanceVersionCollectors`.
- **What**: Added shared per-instance atomic sampling outcome counters (eligible evaluated, selected, zone-filtered) and an active-config per-family excluded-flow-server count using the same version-resolution and `FlowServerExcludedReason` predicates as collector selection. Exclusions now appear in build state and Prometheus even when every flow-server is excluded and no exporter group survives. Added regressions for sampling decisions, empty-map fail-closed visibility, zero-group all-excluded configuration, and metric emission.
- **RED-before**: On pristine master `98d56af14`, the regression failed to compile because `ExportConfig.SamplingStats` and exclusion-count visibility did not exist.
- **Validation**: `go test -count=1 ./pkg/flowexport/... ./pkg/api/...` passed. Focused daemon build-state tests (`TestBuildStateReportsExcludedFlowServers13307`, `TestBuildStatesDistinguishTheThreeCases9166`, `TestBothFamiliesAreAlwaysReported9166`) passed. `go vet ./...` and `go build ./...` passed. Full `./pkg/daemon/...` had four unrelated Unix-domain socket bind failures (`bind: invalid argument`) caused by the long `GOTMPDIR` paths; focused daemon tests passed.
- **Risk**: Sampling metrics become visible to Prometheus with bounded protocol/instance cardinality; excluded stanza count is a per-family gauge. Existing dashboards may need to add these metric families.
