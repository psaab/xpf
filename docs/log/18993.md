# #18993: classify glued compare pipes by adjacency

## Decision

A compare pipe on operational `show configuration` is glued when the raw `|`
byte touches non-space text on either side. This includes `configuration| compare`,
`system| compare`, `|compare`, and `system|compare`; the comment-closing bytes
before a pipe count as adjacent text under the #18667 raw-byte rule. Spaced
`| compare` remains the valid compare syntax. Refuse glued compare before
configuration path lookup (local) or pipe splitting/RPC (remote).
