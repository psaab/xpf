# #18993: classify glued compare pipes by adjacency

## Decision

A compare pipe on operational `show configuration` is glued when the raw `|`
byte touches non-space text on either side. This includes `configuration| compare`,
`system| compare`, `|compare`, `system|compare`, and `|/*x*/compare`: the
config lexer skips the inline block comment after `|`, but the pipe is still
byte-adjacent to its opener and the comment is adjacent to `compare`. Comment
closing bytes before a pipe likewise count as adjacent text under the #18667
raw-byte rule. Spaced `| compare` remains the valid compare syntax. Refuse
glued compare before configuration path lookup (local) or pipe splitting/RPC
(remote).
