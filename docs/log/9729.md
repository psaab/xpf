## Change

- **Both scripts:**
  - `rg0_primary_node <query-node>` reads the RG0 row and prints nothing when it is unreadable. It never defaults to fw0, because a silent default asked of a rebooting node would pass a missing promotion.
  - Roles are `PRIMARY` and `STANDBY`.
  - After rebooting the primary, the survivor must report itself RG0 primary before any post-failover assertion runs.
  - The summary is the canonical `<name> test: <n> passed, <n> failed`.
- **`persistent-nat-failover.sh`:** the stale status block is replaced, citing #8573/#8621 and the role bug.
- **`dhcp-lease-failover.sh`:**
  - `REBOOT_WAIT` now waits after the reboot;
  - the v6 lease and v6 header are asserted only with `DHCP_V6=1`;
  - the header states what is automated ((a)/(b) for v4) and what is not (IA_PD, (c)).
- **Makefile:** both recipes run through `harness-result.sh --adapter ha-smoke`, like the other HA gates.
- **`HARNESSES.unreached`:** both entries removed; the census now counts them as reached.
