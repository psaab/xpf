# Preserve Junos-host physical exemptions for distinct unit-0 netdevs (#12976)

- **Issue**: #12976.
- **Cause**: For a distinct unit-0 netdev, `junosHostZoneExemptNetdevs` attempted the physical row via `addRow`, but `addRow` accepted rows only when `zoneByIface[name]` matched the zone. After #12839 stopped fan-up from ordinary unit refs to the physical base, a zone referencing VLAN unit 0 no longer had the bare physical name in `zoneByIface`; `addRow` therefore discarded the physical row's IKE and ident-reset verdicts even though that row remains a distinct ingress carrier.
- **Change**: When unit 0 is distinct from the physical netdev and belongs to the zone, include the physical row's effective host-inbound verdict using the zone's unit-0 ownership, without restoring physical-base ownership in `junosHostZoneByInterface`. Preserve the same-netdev unit-0 rule: unit 0 remains authoritative and the redundant physical row is omitted. An explicitly owned physical row remains available when unit 0 does not belong to the target zone.
- **Regression coverage**: Existing `TestJunosHostCollapse12838VlanUnit0BaseRowKept` asserts physical plus VLAN ingress and physical-row IKE/ident-reset exemptions. The same-netdev `TestJunosHostCollapse12838*` controls and #12839 tagged-unit ownership / trunk-coverage tests remain guardrails.
- **RED evidence**: Before the change, `go test ./pkg/config -run '^TestJunosHostCollapse12838VlanUnit0BaseRowKept$' -count=1 -v` failed with `distinct VLAN netdev: ike=[] ident=[], want both [ge-0-0-1] (base row kept)`.
- **Validation**: `go test ./pkg/config -run '^TestJunosHostCollapse12838' -count=1` passed; `go test ./pkg/config -run 'TestJunosHost(UnitRefDoesNotOwnBase12839|.*Trunk|CrossZone)' -count=1 -v` passed including `TestJunosHostUnitRefDoesNotOwnBase12839`, `TestJunosHostMultiZoneTrunkNoFalseUnscopable12839`, and `TestJunosHostCrossZoneAmbiguousTrunkKeepsWarning`; `go test ./pkg/config -run 'TestJunosHost' -count=1` passed; `go vet ./pkg/config/` and `git diff --check` passed.
- **Risk**: The change affects only Junos-host exemption metadata for distinct unit-0 netdevs. Same-netdev collapsed unit-0 override semantics and #12839 unit-reference ownership remain unchanged.
