- **Timestamp**: 2026-10-18
  - **Action**: Management DNS policy rules are now scoped by protocol and port to DNS traffic only (#14971, D31-03). `mgmtDNSRulePairs` previously built a single protocol- and port-agnostic lookup/shadow pair (`iif lo` + exact destination, priorities 2500/2501) for every management-DHCP nameserver, so all locally originated host traffic to that IP — SSH, NTP, monitoring, any non-DNS service — was hijacked into management table 999 or blackholed by the unreachable shadow whenever table 999 had no route. Each nameserver now gets two scoped pairs: UDP (2500 lookup / 2501 shadow) and TCP (2502 / 2503), each carrying `FRA_IP_PROTO` and destination-port range 53–53, with no source-port constraint (resolver ephemeral source ports vary; TCP retries and truncated-response fallback are covered by the TCP pair). `managedMgmtDNSRule`/`mgmtDNSRuleSelectorsExact` validate proto and dport against the priority's expected protocol; legacy unscoped or wrong-proto/port rules at the reserved priorities are classified `invalid`, deleted exactly by reconcile, and poison readiness for every protocol of that destination. `mgmtDNSRuleReadiness` publishes a nameserver only when all four scoped rules are present exactly once, so partial (UDP-only) installs fail closed. The kernel dump decoder's `FRA_IP_PROTO` case now accepts the kernel's 1-byte u8 encoding (previously it required 4 bytes and only ever saw synthetic fixtures, so live scoped rules failed to decode). Priorities 2502/2503 were free (VRF miss terminator at 2000, PBR band at 29000) and are guarded by the existing compile-time ordering assertions extended to the TCP shadow.

  - **Risk**: Host DNS over UDP/TCP 53 to management nameservers keeps its table-999 steering with fail-closed shadows; non-DNS traffic to the same IPs now follows main-table routing as it did before any management lease existed. On upgrade, the first reconcile deletes legacy unscoped pairs and installs scoped pairs (shadow before lookup, per protocol); a nameserver is withheld from the resolver until all four scoped rules are present. DNS transports other than UDP/TCP 53 (e.g. DoT 853, DoH 443) were never steered by design of the resolver drop-in (plain nameserver entries) and are unaffected.
