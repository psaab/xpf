# #13718 — keep interface-SNAT overlap quarantine eligible

## Why

The runtime overlap detector fed the snapshot-builder's `PoolUnusable`
quarantine, but accepted interface rows the dataplane would never register as
interface-SNAT egresses. It also treated a `LenientMatchDropped` interface-mode
rule as an active translator. Either false candidate could quarantine an
otherwise usable source-NAT pool and blackhole new outbound flows.

## What

- Reuse `interfaceSnapshotCanBeSNATEgress` in the snapshot overlap candidate
  walk, matching the registration eligibility gate for materialized, enabled,
  zoned, non-lifeline interfaces.
- Exclude interface-mode rules marked `LenientMatchDropped`.
- Add regressions for admin-disabled, unmaterialized, unzoned, loopback,
  management, and poisoned rules. Set the shared WAN fixture's ifindex to a
  materialized value so the valid-overlap control reflects a real egress.
- Not changed: pool/address comparison semantics, scope matching, or the
  existing drain/quarantine behavior for valid overlaps.

## Validation

- RED: before the implementation change,
  `go test ./pkg/dataplane/userspace -run
  '^TestInterfaceSNATPoolOverlapIgnoresIneligibleEgresses$' -count=1` failed
  in all six new cases, reporting false overlaps.
- GREEN: `go test ./pkg/dataplane/userspace -run
  'Test(InterfaceSNATPoolOverlap|InterfaceSNATEgressScopeMatrix|BuilderDetectsOverlapEndToEnd|BuilderQuarantinesTheOverlappingPool)'
  -count=1` passed.
- Full suite: `go test ./pkg/dataplane/userspace -count=1` compiled and ran,
  but failed in unrelated package tests, including UNIX-socket path-length
  errors, contract/snapshot goldens, and Junos host-ingress parity assertions.
  The overlap-specific tests and both builder overlap controls passed in the
  focused run above.

## Risk

The shared eligibility helper intentionally means future changes to interface-
SNAT registration eligibility are reflected by this detector as well. Valid
runtime overlaps continue to quarantine pools and use the existing drain path.
