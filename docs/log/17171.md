## Change

- `EraseFileForReset(path string) error` in
  `pkg/configstore/factory_reset.go` (after `CollectHardlinkedFiles`):
  Lstat; absent → nil; symlink → `FactoryResetSymlinkError`;
  non-regular → refusal; hardlinked → `FactoryResetHardlinkError`
  (fail BEFORE unlink, census evidence preserved);
  `os.Remove` (absent tolerated). It is the single-file, no-RemoveAll
  form of the reset-erase discipline `wipeRemovePath` (RemoveAll-
  capable, directory-aware) cannot offer, exported from the package
  that already owns `CollectHardlinkedFiles`, `SymlinkTarget`,
  `FactoryResetHardlinkError` and `FactoryResetSymlinkError` and is
  imported by every caller. Signature adjusted from the issue's
  sketch (`SweepCrashTemps` takes no `prefix` argument): every caller
  already supplies its prefix via `fmt.Errorf("<pkg>: %w", err)`, so
  an embedded prefix parameter would have double-prefixed; wrapping
  keeps asserted prefixes and `errors.As` typing intact.
- `SweepCrashTemps(list func() ([]string, error)) error` lists via the
  caller's own `ListCrashTemps`/`ListShrinkHistoryCrashTemps` (the
  per-package match rule that also backs post-sweep verification) and
  erases each member through `EraseFileForReset`, joining failures.
- Routed through the primitive: `removeStateTempDead` (both
  `SweepStaleStateTemps` and `SweepStaleStateTempsIncludingLegacy`
  share it, so the dead-writer sweep can no longer unlink a link on
  either path); `ddns.EraseStateIfEmpty` canonical +
  `ddns.sweepCrashTemps`; `ipsec.EraseConnStateIfEmpty` canonical +
  `ipsec.sweepCrashTemps` (each wrapped `"<pkg>: %w"` so the typed
  hardlink/symlink errors survive and no asserted prefix is lost);
  `feeds.EraseShrinkHistoryCrashTemps` crash temps;
  `factoryreset.SweepHelperState` canonical (its historic symlink /
  hardlink spellings preserved via `errors.As`);
  `daemon.eraseKeaLeasesForReset` (historic "symlinked Kea lease"
  wording preserved; parent dirs synced only when the lease file
  existed before the erase).
- `wipeRemovePath` (wipe_seal_10769.go): a regular file delegates to
  `EraseFileForReset` and only the parent sync stays in the seal leg;
  symlinks / directories / non-regulars keep the historic path
  (symlink refusal message unchanged, directory RemoveAll, escaping-
  interior-link warning). Semantics per input class are identical to
  the pre-fold hand-rolled sequence.
- `daemon_apply_reset.go:345` now cites `wipeRemovePath` (a346e74df8,
  #16138, renamed `zeroizeRemovePath` → `wipeRemovePath`);
  `grep -rn zeroizeRemovePath pkg` is empty.
- Not routable through the primitive: directory/sweep sites that
  deliberately unlink links by name and refuse only hardlinks
  (`wipeClearTmpDir`, `wipeClearRunUtmpDir`-style tmp/run legs —
  documented FHS tmp semantics in wipe_seal_10769.go), Rotate/reset
  writers (hostname/resolv/hosts/machine-id — not unlinks), and
  `configstore.FactoryResetConfigDirWithSync`'s hardlink pre-census
  over trees (different shape, stays).
- **Fold (Rev18209Opus, head 2073417b3e):** F1 — the "preserved
  verbatim" claim was overstated: only the Kea/helper symlink
  sentences had been mapped. The primitive now tags its non-typed
  failure classes with exported sentinels (`ErrEraseInspect`,
  `ErrEraseNonRegular`, `ErrEraseInspectLinks`, `ErrEraseRemove`) and
  every routed caller with a historic spelling maps each class back
  to its verbatim pre-primitive string (Kea hardlink/inspect/
  hardlink-inspect/remove, helper inspect/hardlink-inspect/remove,
  ddns/ipsec canonical + per-temp, feeds per-temp, userspace
  hardlink/inspect-links, seal-leg hardlink/inspect-links/remove);
  symlink temp sentences now wrap the typed refusal inside the
  historic wording so `errors.As` still finds it. Classes the old
  code had no spelling for (non-regular at Kea/helper, userspace
  symlink) keep the prefixed primitive wording — no historic string
  is invented. F2 — `SweepCrashTempsWithListError` splits the list
  failure out so ddns/ipsec/feeds return it unwrapped (their list
  functions already embed the prefix): exactly one `"<pkg>: "`.
  F3 — `TestEraseFileForResetTable17171/non-regular FIFO refused`
  covers the primitive's FIFO arm (sentinel + verbatim refusal +
  FIFO retained), `TestEraseKeaLeasesForResetParity17171`'s symlink
  subtest is renamed to state the plain-message contract it asserts
  (plus a hardlink-wording sibling), and per-package HistoricWording
  cells pin the F1/F2 contracts at ddns/ipsec/feeds.

## Risk

Bounded to reset/boot erase paths; no production behavior change for
regular files and absent paths (verified per entry point). Direction
is strictly fail-closed: the helper temp sweep now refuses symlinks
and non-regular files where it previously unlinked links silently.
Error wording is preserved verbatim wherever the pre-primitive code
had a spelling (all Kea/helper/ddns/ipsec/feeds/userspace/seal
classes, mapped from the primitive's typed/sentinel classes by the
fold); genuinely new classes (non-regular refusals, the userspace
symlink refusal) carry the prefixed primitive wording and invent no
historic string. List failures carry exactly one `"<pkg>: "` prefix.
`wipeRemovePath`'s regular-file arm is byte-for-byte the old sequence
minus the seal leg's own sync, which is retained. Out-of-scope
residual: directory-level tmp/run legs still unlink symlinks by name
on purpose (FHS tmp contract, documented at wipe_seal_10769.go:561),
and no other duplicated single-file copy remains outside the
typed-error census users in `configstore` itself
(`FactoryResetConfigDirWithSync` pre-census), which erase trees, not
single files.
