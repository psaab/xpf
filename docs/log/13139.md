# #13139 — remove skipped GRE tunnel ownership completely

- **Source**: deep-review finding D2-08, validated by three-way adversarial research.
- **Files**: `pkg/config/compiler_validate_strict_tunnel_ri_target_12520.go`,
  `pkg/config/routing_instance_member_devices.go`,
  `pkg/config/compiler_tunnel_ri_target_12520_test.go`.

## Why

Tolerant quarantine could clear a colliding interface-level GRE tunnel while
leaving its tunnel-less unit active, preserving addresses without encapsulation.
Separately, the interface tunnel routing-instance claim was retained when unit 0
had its own routing-instance override on the same Linux device, causing a false
`#11060` dual-owner rejection and potentially rejecting a valid effective
`#12520` target.

## What

When an interface-level GRE tunnel is skipped, also remove its units which
inherited it; preserve independently-tunneled units. Only emit the interface
target claim when the interface-level tunnel is still inherited by a unit (or
the interface is unitless), so unit tunnel overrides own their configured
routing-instance claims. Regression coverage includes skipped interface-level
GRE with an inheriting addressed unit and independent tunneled sibling, strict
and tolerant unit-0 target overrides, distinct per-unit devices, and an
inheriting sibling.

## Validation

- Pristine `origin/master` RED: `go test ./pkg/config/ -run 'TestSkippedInterfaceGREDeletesInheritingUnits13139|TestUnitTunnelRIShadowsInterfaceLevelClaim13139' -count=1` failed both regressions (orphan unit survived; false `#11060` conflict).
- Focused post-fix regressions: GREEN.
- Full `go test ./pkg/config/ -count=1 -timeout 30m`: GREEN (`885.824s`).
- `go vet ./pkg/config/`: exit 0.
- `gofmt -l` on the three changed Go files: no output.

## Risk

Only units inheriting an interface tunnel are removed when that interface tunnel
is skipped. Explicitly-tunneled units remain unchanged. Claim traversal remains
sorted and only suppresses a shadowed interface claim; per-unit target claims
and inherited interface claims remain represented.
