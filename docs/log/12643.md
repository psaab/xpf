# Issue #12643 — reject weekday all-day plus complete window in every merged shape

## Decision

Reject at strict commit validation. A weekday override stores one window, and the runtime checks `Exclude`, then `AllDay`, before its time bounds. Combining `all-day` with a complete start/stop pair therefore enforces all day; the time restriction is not effective. Treating a one-statement or merged shape differently from the already-rejected split shapes would make commit behavior depend on whether flat `set`, `load merge`, or group inheritance happened to coalesce the AST.

This deliberately changes the previous #10006/#11641/#12238 acceptance of one weekday statement containing `all-day` plus a complete pair. It does not change daily window behavior, `exclude` plus a time window, all-day-only, window-only, or all-day with a partial pair. Strict compilation rejects the contradiction; tolerant load/peer-sync warns and retains the existing union window so old stored configs can still load.

## What

- Extended the effective-node scheduler window validator to reject any weekday whose all-day contribution and complete start/stop pair coexist, whether in one node or multiple statements.
- Kept validation before node-local compilation; it inspects both effective node views so a node cannot commit a contradiction contributed only by its peer's group.
- Added W3 flat-set, W5 group-inherited, load-merge, single-statement, and GR6 peer-only regressions, plus controls for all-day-only, window-only, partial bounds, distinct weekdays, and matching peer groups.
- Updated the #10006 equality-warning test to build the explicitly mixed typed state directly: that input is no longer a strict-compile shape.
- Updated scheduler documentation to record the semantic decision and compatibility boundary.

## Validation

- `go test ./pkg/config -run '(?i)sched|12238|12239|8939|10006|11641|11358|11681|5825|3849|12643' -count=1` passed.
- `go test ./pkg/configstore -run 'Scheduler.*(12238|12643)' -count=1` passed.
- Full `go test ./pkg/config ./pkg/configstore ./pkg/scheduler/... -count=1` did not complete cleanly: `pkg/config` reported unrelated existing test failures (including #8662, #9027/#9029, #10826, and #11312) and timed out during `TestSlotEscapeSweep`; `pkg/configstore` also timed out after 10 minutes while emitting unrelated tests, and initially exposed an outdated #12238 load-path expectation that was updated for #12643. `pkg/scheduler` passed.
- `go build ./...` passed.

## Risk / residual

Existing committed configurations that combine weekday all-day with a complete time window still compile tolerantly with a warning and preserve their prior all-day runtime behavior. Their next strict commit (including an unrelated change) is rejected until all-day or the complete time window is removed. Existing `exclude`-plus-window behavior is unchanged because exclude already makes the day closed.
