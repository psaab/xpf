# #15719 — Canonicalize repeated-option overwrite and mid-walk value-skip RBAC bypasses

- **Timestamp**: 2026-10-19
  - **Action**: Implemented ONLY the #15719 mechanism in
    `pkg/cmdtree/canonicalize.go`:
    - Track seen option keywords by node identity whenever an
      `Options:true` node is entered; a second resolution of the same
      option (exact or abbreviated, e.g. `effective eff`) returns
      `CanonicalUnknown`. A multi-token option subtree child
      (`sort-by bytes`) completes its option instead of being marked.
    - Before resolving child keywords, gate a pending value slot
      (typed leaf, `RequiresValue` dynamic, unfilled placeholder at
      the current level, or a dynamic slot whose next token is an
      exact/seen option keyword): a word that is a child keyword, the
      next option, the slot's own keyword, or a child of a pending
      placeholder-with-children is refused instead of skipping the
      value (`from-zone to-zone`, `table table`, `zone sort-by`,
      `zone zone`, `flows flows`, `limit limit`).
    - Do not resume the option list inside a multi-token option
      subtree (`sort-by`), and refuse a line ending inside one.
    - Preserved neighbouring lawful spellings (controls in the tests):
      a dynamic value that abbreviates a keyword (`opts zone fl`),
      optional-dynamic child keywords (`show interfaces queue <name>`,
      `show security zones trust detail`), placeholder-with-children
      values (`show route 10.0.0.0/8 exact`, `flows limit 10`,
      `flows all`, `flows 10`), and every #9505 option-order form.
      `ping count 5` is deliberately NOT a Canonicalize refusal: under
      an Options node the `<host>` placeholder is optional for the
      walk (#14687) and `ParsePingOptions` rejects `count` as target.
  - **Action**: Downstream agreement (unrestricted classes bypass the
    gate and reach the parsers directly):
    - `pkg/cli/session_filter.go`: `parseSessionFilterMode` rejects a
      repeated option keyword (`duplicate session filter %q`) on both
      show and clear paths, like `ParsePingOptions` /
      `ParseCoSNameTypeArgs`.
    - `pkg/cli/cli_show.go`: `show firewall filter` rejects repeated
      `effective` / `family` tokens (new `firewallArgCount` helper);
      previously `firewallArgsHaveWord` ignored a duplicate
      `effective` and `firewallFamilyArg` kept the first `family`.
