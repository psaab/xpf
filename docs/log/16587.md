# #16587: peer fabric realized as a local empty bond

- **Timestamp**: 2026-10-24
- **Action**: With the shipped HA config each node created a slave-less,
  admin-UP bond named after the peer's fabric (`fab1` on node0, `fab0` on
  node1): the daemon passed every `len(FabricMembers)>0` interface to
  `ApplyBonds`, and the bond manager skipped only
  `LocalFabricMember != ""`, which is also empty for the peer's fab.
  Neither fabric stale sweep reaps it (both delete only IPVLAN links), so
  the phantom netdev was zoned into `control` and queued for XDP attach.
  Fixed at the bond manager, the only layer that can reap what it
  creates: `bondManager.shouldBond` now bonds in a chassis cluster only
  when at least two fabric members are local (slot maps to this node via
  `config.InterfaceSlot`/`SlotToNodeID`, unparseable slots counting as
  local); zero local members is the peer's fab and exactly one is the
  vSRX IPVLAN mode. Outside a cluster the #9872 standalone multi-member
  shape still bonds, and plain `Apply` (no cluster identity) is
  unchanged. `ApplyCluster`/`Manager.ApplyClusterBonds` carry the
  cluster identity from `applyInterfaceReconcile`
  (`cfg.Chassis.Cluster`), so a tracked ghost leaving the desired set is
  deleted by the existing differential delete pass, and — armed only on
  the daemon's first reconcile (`Daemon.bondGhostReapDone`) — an
  untracked slave-less kernel bond left by a pre-fix binary is reaped;
  bonds carrying members and same-name foreign non-bond links are never
  touched by the reap.
- **File(s)**: `pkg/routing/bond.go`, `pkg/routing/routing.go`,
  `pkg/routing/bond_peer_fabric_16587_test.go`,
  `pkg/daemon/daemon_apply_interfaces.go`, `pkg/daemon/daemon.go`,
  `pkg/daemon/bond_peer_fabric_16587_test.go`, `docs/log/16587.md`.
- **Validation**: New routing tests pin no bond on either node for the
  per-node shipped shape, the standalone and dual-local positive
  controls, the tracked reap, and the untracked upgrade reap (including
  member-carrying and foreign-link negative controls); new daemon tests
  pin the same through `applyInterfaceReconcile` plus first-apply-only
  reap arming. Targeted suites green — see PR body for counts.
- **Residual**: The dataplane planner (#9872) and networkd model builder
  treat "members with no local member" as the bond shape and are
  unchanged: in a cluster a remote-only fab reference still resolves to
  the fab name itself, but no such netdev is now created, so the zone
  loop takes its existing "not found, skipping" path. A ghost bond
  created and later given members by an external actor before the first
  post-upgrade reconcile is deliberately not reaped.
