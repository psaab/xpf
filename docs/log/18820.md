## Charge-ownership correction

The initial accepted-only miss-path skip conflated filter acceptance with policer ownership. The tunnel prewalk uses `DeferToTxSelection`; the predictor-false named-VRF path does not run the inline routing-bearing meter, so a secondary listener can be accepted and later resolve to `LocalDelivery` through PBR without an outer charge. The routing-bearing result now carries `policer_metered`, set only when a runtime meter is invoked; the accepted tunnel outcome preserves this fact separately from its acceptance/PBR semantics. The miss path skips only when that charge fact is true.

The named-VRF regression seals an allowed inner packet for the secondary listener, stamps outer CE, and asserts the WG ECN-illegal fallback occurred, the underlay counter ran once, and the LocalDelivery policer charged exactly once.

**Validation**: The named-VRF test failed before the ownership correction (`green_packets` 0, expected 1), then passed after it. Focused tests passed: the named-VRF regression, `poll_loop_wg_outer_ce_over_not_ect_counts_underlay_once_12289`, all 9 `miss_local_policer_15949_tests`, and all 10 `poll_descriptor_structure_13081_tests`. Forcing the charge bit false kept the predictor-false named-VRF test at 1 charge, while the original predictor-true #12289 regression failed at 2 charges (expected 1). Conversely, incorrectly marking every accepted outer as charged made the named-VRF test fail with 0 charges.
