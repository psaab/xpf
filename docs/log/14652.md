# #14652 — Native GRE decap: IPv6 AH-sighted refusal (residual)

## Defect (residual only)
Fragment half already fixed by #14645 (#14827): `stage_native_gre_decap`
(poll_stages.rs) reassembles outer-fragmented GRE via `gre_reassembly`
before decap. Residual: `try_native_gre_decap_from_frame_with_input_filter`
(gre.rs) gated only on `meta.protocol == PROTO_GRE`. The XDP walker
advances past an IPv6 Authentication Header to GRE, so an unverified
AH-wrapped GRE frame was decapsulated at stage 6 before screen
(stage 10) / stage-11 `PROTO_AH` drop (#10729) ever saw the outer
packet, while non-GRE AH transit is dropped.

## Fix
In `try_native_gre_decap_from_frame_with_input_filter`, right after the
`PROTO_GRE` gate, return `None` when
`ipv6_ah_sighted(frame, meta.addr_family, meta.l3_offset)` (the canonical
helper from `frame/inspect.rs`, re-exported via `frame::*` / `super::*`).
Returning `None` is a refusal, not a drop: `stage_native_gre_decap`
returns `NotGre(meta)` and the outer frame continues on the ordinary
path for stage-10/11 adjudication. No fragment guard added here —
redundant with #14645 reassembly. IPv4 unaffected (`ipv6_ah_sighted`
returns false for non-v6).
