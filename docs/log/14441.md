# #14441 — Elided `redundant-ether-options redundancy-group <n>;` dropped (DR18-H5)

## Defect
`compileInterfaces` (`pkg/config/compiler_interfaces.go`) read the RETH
group via `reoNode.FindChild("redundancy-group")` only. The brace-elided
hierarchical spelling

```text
interfaces { reth0 { redundant-ether-options redundancy-group 1; unit 0 { ... } } }
```

parses as one node `Keys=[redundant-ether-options redundancy-group 1]`
with no Children, so `FindChild` found nothing and `RedundancyGroup`
stayed 0 with no error or warning on strict or lenient paths. Every
downstream consumer decides `isReth`/`isVRRPReth` by
`RedundancyGroup > 0` (`pkg/dataplane/compiler_iface.go`), so the reth
read as an ordinary interface on both cluster nodes: its service address
was installed as a plain static address on both nodes (the duplicate-
address condition #6782 exists to prevent, without #6782's suppression
firing because the dropped token was valid), with no RETH mastership or
failover. The #6782 pre-walk gate (`validateRethRedundancyGroupTokensAST`)
mirrored the same Children-only read, so an unusable elided token
(`0`/`abc`/`256`) likewise escaped the strict reject and lenient
suppression.

## Fix
- `pkg/config/flat_run_residue_9792.go`: new
  `redundantEtherOptionsSchema9792()` resolver
  (`interfaces xpfname redundant-ether-options`), pinned non-nil with its
  `redundancy-group` leaf in `TestFlatRunResidueSchemasResolve9792`.
- `pkg/config/compiler_interfaces.go`: the reth reader now expands the
  reo node with `expandResolvingRun9792` (lenient packed-run shape) and
  `packedBody` (hierarchical elided shape) before `FindChild`, exactly as
  the gigether-options / aggregated-ether-options siblings above it do.
  Braced and flat-set spellings return their real children unchanged.
- `pkg/config/compiler_reth_rg_token.go`: the #6782 gate applies the same
  two expansions, preserving its "mirrors compileInterfaces EXACTLY"
  invariant for the elided spelling.

NOT changed: the #6782 Atoi-discard + `rethRGTokenProblem` classification,
address suppression, and every other interface reader.

## Tests
- `TestElidedRedundantEtherOptionsCompilesGroup14441` (in
  `compiler_reth_rg_token_6782_test.go`): elided hierarchical, braced
  hierarchical, and flat-set spellings all compile `RedundancyGroup=1`
  with addresses kept, on strict (`CompileConfig`) and lenient
  (`CompileConfigLenient`) paths.
- `TestElidedRedundantEtherOptionsBadTokenGated14441`: elided `0`, `abc`,
  `256` are rejected at commit naming `reth0`, and on lenient warn
  (#6782) + suppress the reth addresses.
