# #16720 — #16050 flock cell chmodded pre-existing temp ancestors to 0755

- **Timestamp**: 2026-10-25
  - **Action**: `TestUnprivilegedCannotFlockUpgradeLock16050`
    (pkg/upgrade/lock) walked from `t.TempDir()` to `/` with only
    `/`, `/tmp`, `.` as stop words, chmodding every ancestor to
    0755. Under any GOTMPDIR/TMPDIR other than /tmp — including
    /var/tmp/<id> and nested roots — it rewrote pre-existing
    shared directories it does not own (0775 -> 0755 demonstrated
    on a private mirror) and then failed with EPERM on the first
    root-owned ancestor (/var/tmp). Run as root it would have
    stripped sticky/world-write from e.g. /var/worktrees (1777).
    Fix: chmod only the test-owned directories — the per-test
    MkdirTemp root and its 001/ subdir that t.TempDir() creates —
    via `openTestOwnedAncestors(root, base)`, which refuses a base
    not strictly under root. The cell now snapshots the permission
    bits of the entire pre-existing ancestor chain (parent of the
    temp root up to `/`) before any chmod and asserts in a defer
    that none changed, so the acceptance case
    `GOTMPDIR=/var/tmp/x/y` is self-verifying in-cell: the cell
    passes and /var/tmp/x and /var/tmp/x/y keep their modes. No
    skip was added: if a pre-existing ancestor is not traversable
    by nobody, the root-arm control probe fails loudly, which is
    the correct signal rather than rewriting host state. The
    #16050 gate itself is unchanged (control probe on loosened
    0755/0644 must succeed; tightened 0750/0600 probe must fail).
    NOT changed: production lock code (lock.go modes 0750/0600
    already correct); no other test's TempDir handling.
  - **File(s)**: `pkg/upgrade/lock/lock_test.go`,
    `docs/log/16720.md`
  - **Validation**: RED on pristine master
    (GOTMPDIR=/var/tmp/xpf16720x/y, 0775 ancestors):
    `chmod /var/tmp: operation not permitted` FAIL and both
    ancestors rewritten 0775 -> 0755. Post-fix same setup: cell
    PASS, ancestors still 0775, /var/tmp still 1777. Root arm
    via sudo with same GOTMPDIR: PASS, modes unchanged. Full
    package `go test ./pkg/upgrade/lock/ -count=1` PASS under
    default /tmp, under GOTMPDIR=/wtgt (Makefile pin), and under
    the nested /var/tmp root. `go vet` clean, `gofmt` clean.
  - **Residual**: If a future GOTMPDIR is nested under a 0700
    root-owned directory, the root-arm nobody control probe will
    fail loudly (by design — the test no longer fixes up host
    permissions); operators running the suite as root under such
    a root will see that failure instead of silent host mutation.
