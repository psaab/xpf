# #13201 — fail closed on diagnostic CLI option errors

Base: `origin/master` at `dd607606a`.

## Finding

The D10-05 report identifies divergent diagnostic-option loops: remote
`handleTraceroute` ignored unknown, duplicate, and valueless selectors;
local `pkg/cli` ping/traceroute ignored unrecognized and trailing tokens; and
both remote and local `test security-zone` accepted malformed selectors and
comma/equal delimiters that corrupt its topic.

The source report's executed base probe demonstrated the security-zone issue:
`interface ge-0/0/0,injected=1 bogus interface` returned nil and emitted a
`test-zone:interface=ge-0/0/0,injected=1` topic. Its traceroute trace showed a
misspelled `sourcce` plus a valueless `routing-instance` silently issuing a
default-route traceroute.

## Change

`pkg/diagcmd` now owns parsing for ping, traceroute, and test security-zone
selectors. Parsing rejects unknown and duplicate options, missing or
selector-as-value arguments, nonnumeric ping count/size, and unsafe comma/equal
interface values. Both `cmd/cli` and `pkg/cli` use those parsers; valid ping
and traceroute arguments retain their existing RPC/argv construction.

## Validation

- RED on unchanged master: adding regression tests for the missing shared
  parsers failed to compile (`undefined: ParsePingOptions`,
  `ParseTracerouteOptions`, `ParseTestInterface`). This establishes the
  regression contract was absent before the fix; the source report also
  includes the executed behavior probes above.
- GREEN: `go test ./pkg/diagcmd ./pkg/cli` passed.
- GREEN: `go test -skip '^TestTreeIsGofmtClean$' ./cmd/cli` passed.
- Full `go test ./cmd/cli` ran; its only failure was the existing
  `TestTreeIsGofmtClean`, which reports 10 pre-existing unformatted files,
  including `pkg/config/compact_scope_blind_pairs_8852_test.go` (unchanged).
- `go build ./...` passed.
- `go vet ./...` passed.

## Risk

Malformed selector strings that were previously ignored are now errors, and
security-zone interface names containing comma or equals are rejected because
the current daemon topic format cannot represent them unambiguously.
