# #14653 — `make selftest` omits two hermetic `--selftest` verdict cores; the #7296 census cannot detect a never-registered `--selftest`-arm script

## Defect

`scripts/run-selftests.sh` §4 registered six wire `--selftest` verdict
cores (#9531 pattern), but two more hermetic cores were reached only by
hand via `make test-wire-nat-frag-needed-lib` (Makefile, `--selftest`,
13 cells) and `make test-t12-g2-9506-lib` (`--selftest`, 105 cells):

- `test/incus/wire-nat-frag-needed.sh` (#12809, NAT ICMP frag-needed
  translation verdicts over `wire-gate-lib.sh`)
- `test/incus/t12-g2-9506.sh` (#9506, T12/G2 hermetic predicate cells)

Both arms are hermetic (no incus/sudo/network in the `--selftest` path).
`scripts/selftest-census.sh` reported OK regardless: its discovery is
filename globs (`*-selftest.sh` etc.), which neither name matches, and
its §4 odd-name check compares the runner against a hand-kept `ODD_SET`
literal — so a script whose hermetic core hides behind a `--selftest)`
case arm was invisible unless a human remembered to declare it. That is
the #7296 "NOTHING NOTICED" shape one level down.

## Fix

- `scripts/run-selftests.sh`: register both legs in §4 next to the six
  existing wire cores:
  `run_bash test/incus/wire-nat-frag-needed.sh --selftest` and
  `run_bash test/incus/t12-g2-9506.sh --selftest`.
- `scripts/selftest-census.sh`:
  - `ODD_SET` grows from 8 to 10 (the two new odd names); header,
    falsifiability and odd-names prose updated to match.
  - New §2b arm scan: `grep -rl --include='*.sh' -- '--selftest)' test
    scripts` discovers every shell script carrying a `--selftest)` case
    arm on disk; each must have a `run_bash/run_shell <path> --selftest`
    registration in the runner (comments stripped), else the census
    FAILs naming it. An empty scan FAILs instead of sweeping nothing.
    The census itself is excluded exactly as §1 excludes the runner
    (its own comments/matcher name the arm). `ODD_SET` stays the
    exemption declaration, enforced both directions by §2: declaring
    without registering is stale, registering without declaring is
    extra — so no arm script can be quietly exempted.
- `test/incus/selftest-census-selftest.sh`: fixture updated (10 odd
  names; real `--selftest)` arm files for the eight test/incus arm
  scripts, built via concatenation so this file does not itself carry
  the literal arm) plus four new cells:
  - 6b: dropping both #14653 registrations FAILs naming both files
    (the issue's acceptance check, pre-fix runner shape).
  - 6c: a brand-new never-registered arm script FAILs naming it.
  - 6d: control A — dropping `wire-zone-matrix.sh --selftest` still
    FAILs naming it (required surviving control).
  - 6e: twin of 6c — a new arm script registered in §4 but not
    declared in the odd set still FAILs naming it.
