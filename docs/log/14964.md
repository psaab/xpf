# Issue #14964 — Preserve zone and SNAT quarantines on snapshot rebuilds

## Why

The full build (`builder.go`) ends with both fail-closed quarantines:
`quarantineCollidingZones` drops StableZoneID-colliding, poisoned, and
reserved zones and unzones their interfaces, while
`reportInterfaceSNATPoolOverlaps` (#7717) marks a source-NAT pool unusable
when its address coincides with a live interface-mode SNAT egress address.

Two snapshot-rebuild paths rebuilt the interface rows without preserving
that pair:

- `RefreshInterfaceRowsForLink` re-ran `quarantineCollidingZones` on an
  already-reduced `next.Zones`, so it returned no collisions, flipped
  `ZoneSetValidated` back to `true`, and left a stale retained snapshot
  capable of publishing `zone_set_validated=true`. Rust treats that flag
  as proof of a populated collision-free set and derives removed-zone
  sessions for purge / stale-replay fencing from it.
- Neither `RefreshInterfaceRowsForLink` nor
  `rebuildDerivedSectionsAfterRevalidate` re-ran
  `reportInterfaceSNATPoolOverlaps`, so a publish that had lost the #7717
  flag could ship the overlapping pool usable again. Two NAT allocators
  could then mint the same external `(address, port)` identity.

## What

- `manager_link_refresh.go`: detach `next.SourceNAT`, re-run
  `quarantineCollidingZones` and recompute `ZoneSetValidated`, then run
  `reportInterfaceSNATPoolOverlaps(&next)` before the content-hash check,
  diagnostics recording, and publish. The alias detachment prevents a
  no-change refresh from mutating the retained snapshot.
- `apply_snapshot_identity_9520.go`: in
  `rebuildDerivedSectionsAfterRevalidate`, detach `snap.SourceNAT`, keep
  the existing zone quarantine and validation recomputation, and run
  `reportInterfaceSNATPoolOverlaps(snap)` so the apply-time rebuild
  converges to the same quarantined state as the full build.
- Regression tests in `link_refresh_snat_quarantine_14964_test.go` cover:
  SNAT overlap preservation through link refresh, SNAT overlap preservation
  through apply-time derived rebuild, the retained-slice alias guard, the
  z174/z214 zone-collision control, and the clean-zone validated control.

## Validation

- `go test ./pkg/dataplane/userspace -run 'TestInterfaceLinkRefresh(PreservesSNATOverlapQuarantine|ZoneQuarantineControl)|TestRebuildDerivedSectionsPreservesSNATOverlapQuarantine|TestInterfaceLinkRefreshCleanZoneStaysValidated' -count=1` — RED on the new tests before the fix, GREEN after.
- Adjacent suites for link refresh, SNAT overlap, zone quarantine, and
  apply-time rebuild pass. Full-package result is recorded in the PR.

## Risk

The reporter is the production #7717 function and keeps its existing
counters and log behavior. Zone quarantine remains idempotent on reduced
snapshots. The extra SourceNAT copy is one slice per refresh/rebuild and
prevents retained-state mutation. No Rust or wire changes.
