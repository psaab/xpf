# Issue #13700 — keep failed SYN-cookie ACKs from starving valid handshakes

## Why

The standby and flood-active session-miss paths charged a zone-wide token
bucket before checking the cookie MAC. Anyone able to send epoch-matching
spoofed ACKs could exhaust that shared budget and cause legitimate returning
clients in the same zone to be rejected.

## What

Keep the existing separate active and standby buckets, but charge them only
after cookie validation fails. Valid ACKs now reach the MAC check regardless
of the failed-attempt budget; active failures retain the distinct
`ActiveBudgetExceeded` verdict after exhaustion. Add standby and active
regressions that exhaust the corresponding budget with invalid MACs and then
assert a valid ACK still validates. Update existing limiter-parity tests for
the new accounting semantics.

## Validation

- RED-on-revert: `syn_cookie_standby_failed_macs_do_not_starve_valid_ack_13700`
  failed as expected when the old pre-MAC zone-wide charge was temporarily
  restored: the valid ACK was refused after the invalid-ACK burst.
- GREEN: the same focused regression passed (1 passed); all SYN-cookie tests
  passed (`cargo test syn_cookie_ -- --test-threads=1`, 117 passed, 8075
  filtered), and the complete screen test module passed
  (`cargo test screen::tests:: -- --test-threads=1`, 260 passed, 7932
  filtered). Test execution temporarily gated the existing test-only
  `purge_translated_synced_hit` import with `#[cfg(test)]` in
  `session_glue/mod.rs` to work around the current-master unresolved-import
  build defect; that unrelated edit was restored and is not in this PR.
- Package-wide `cargo fmt --check` reports pre-existing formatting
  differences in many unrelated files; the formatter's reported differences
  did not include the changed validation/test regions.

## Risk

Failed-MAC accounting no longer lets spoofed ACKs spend the legitimate
handshake budget. MAC computation now precedes the failed-attempt accounting,
so this change does not use the existing bucket to cap the cost of each
plausible-epoch invalid ACK; the 5-bit epoch prefilter and existing wire
format remain unchanged. Per-source sharding is outside this issue's
narrowed acceptance.
