- **Timestamp**: 2026-09-11 06:14 PDT
- **Action**: Fix, as a third commit on the branch, applied by a checked patch script.
  - A restart never shortens a grace in progress. `RestartHeartbeat` reads, under `m.mu`, the running
    receiver's grace end (`startedAt + seenThenLostGrace()`) and passes it to
    `startHeartbeat(..., restartSeed, inheritedHold)`.
  - `armRestart(lastSeen, inheritedHold)` stores the grace end, and `checkTimeout` holds while either
    the restart grace or `inheritedHold` is running.
  - #9751's debt carries the hold (`hbRestartOwedHold`), so a failed boot-time restart keeps it
    through the retry. `StopHeartbeat` and a published start clear it.
  - A steady-state commit restarts a receiver whose boot grace ended long ago, so it still holds for
    only 5s.
