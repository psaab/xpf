# PR #12599 — pin privileged Go scans to text output

## Why

`test-memlock-guards` and `test-shim-run` verify their selected Go tests by
scanning `go test -v` output for plain-text `=== RUN` records. Inherited
`GOFLAGS=-json` changes those records to JSON events, so the by-name scans
falsely report that the tests did not run.

## What

Both Makefile invocations explicitly pass `-json=false`, overriding inherited
`GOFLAGS` while leaving the name-based coverage checks intact. A registered,
hermetic self-test invokes both actual Makefile targets under
`GOFLAGS=-json` with a fake `go`; the fake requires `-json=false` in its argv,
exits 23 if absent, and otherwise emits canned RUN records derived from the
same registry and source files the targets census. It unsets `GO` to ensure
that the fixture's executable is used.

## Validation

- `sh test/incus/make-guard-probes-selftest.sh` — PASS (4/4): both targets
  accepted the argv probe under `GOFLAGS=-json`, and both rejected a fake
  `go` exiting 23 when the argument is absent.
- `sudo -n env GOFLAGS=-json GOCACHE=/tmp/xpf-gocache-12599 make test-shim-run` —
  PASS; all named shim tests ran and passed with inherited JSON output requested.
- `sudo -n env GOCACHE=/tmp/xpf-gocache-12599 make test-shim-run` — PASS
  with plain environment settings.
- `sudo -n env GOFLAGS=-json GOCACHE=/tmp/xpf-gocache-12599 make test-memlock-guards`
  — the target completed with exit 2 after the Go suite reported
  `pkg/dataplane/userspace` failure; the by-name census reported four
  registered tests not run. Same failures and four absent names occur in
  the plain environment and on master — pre-existing privileged-suite
  failures (tracked in #12784), not a -json effect. (`TestReconcileDisposableCollectionPinMigratesArrayToPerCPUArray`,
  `TestReconcileDisposableCollectionPinNoOpOnRealEmbeddedSpec`,
  `TestVerifyEmbeddedUserspaceShim`, `TestVerifyUserspaceShimShrinkEquivalence`).
- Mutant check (removed `-json=false` from `test-shim-run`): the same probe
  exited 1 and reported `-json=false missing from go argv`; restoring the pin
  returned the probe to 4/4 PASS.
- `sh scripts/selftest-census.sh` — PASS: 52 discovered shell self-tests
  are registered; all 85 discovered Python files have `__main__` guards.
- `sh -n test/incus/make-guard-probes-selftest.sh scripts/run-selftests.sh` —
  PASS.

## Risk

Only test-harness output formatting is pinned. The real test filters,
privilege requirements, and by-name census behavior are unchanged. The fake
Go tests do not build Go packages or load BPF programs.
