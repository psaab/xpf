# Issues #10319, #10320, #10321

## #10319 — atomic flood-sketch admission

- RED: temporarily restored the pre-fix `TokenBucket` charge-all/AND implementation and ran:
  `cargo test -p xpf-userspace-dp flood_sketch_sustained_over_threshold_trips -- --nocapture`
  Result: failure; the phase-staggered IP sketch admitted 1600 packets at 2x threshold (`artifact://42113`).
- GREEN: restored the all-row prepare/commit implementation and reran the same focused test. Result: `1 passed`, 6578 filtered (`artifact://42416`).
- Change: all four selected rows refill/probe before any token is consumed; a packet is admitted only when every selected flood row has a token, and then every row consumes one. IP and IP+port paths share the same transaction.

## #10320 — embedded ICMP TTL/hop-limit handling

- RED: with the builder TTL/hop-limit checks and poll terminal-drop handling temporarily removed, the explicit TTL=1 poll cell failed:
  `cargo test -p xpf-userspace-dp poll_descriptor_same_family_reversal_ttl_one_is_dropped_10320 -- --nocapture`
  Result: panic because the matched reversal did not return `EmbeddedIcmpReversal::Dropped` (`artifact://42176`).
- GREEN: restored explicit terminal drop before builder dispatch and ran the isolated poll cell. Result: `1 passed`, 6578 filtered (`artifact://42407`).
- GREEN builder controls: IPv4 same-family decrement/drop/fabric guard passed (`artifact://42414`); IPv6 same-family decrement/drop/fabric guard passed (`artifact://42415`).
- Change: normal ingress drops outer TTL/hop-limit <= 1 before any embedded builder; values above one decrement in all four same-family and outbound-SNAT builders. `FABRIC_INGRESS_FLAG` preserves the peer-decremented value and skips the expiry check/decrement.

## #10321 — sport-53 DNS query session tracking

- RED: before QR/datagarm validation, the new fail-on-revert cell failed because a sport-53 QR=0 packet was admitted to the unsolicited-reply fast path (`artifact://42232`).
- GREEN: the hardened query/truncated/reply cell passed:
  `cargo test -p xpf-userspace-dp dns_query_from_port_53_requires_session_tracking_10321 -- --nocapture`
  Result: `1 passed`, 6578 filtered (`artifact://42403`).
- Change: the fast path now requires source port 53, no address/port NAT rewrites, no NAT64/NPTv6, a complete UDP header, UDP length >= 20 and within the frame, and DNS QR=1. QR=0 or truncated packets retain normal session installation, including reverse admission.
