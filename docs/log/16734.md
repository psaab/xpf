# #16734 — RG ip-monitoring demoted node never re-measures as secondary (R3-A21-01, #15038 residual)

## Defect

#15038 made a probe that cannot be sent from a non-primary **not
completed** and left the dampening state untouched. That is neutral
only for a node that never measured. A node that measured a target
DOWN while primary (weight 0 → demoted to secondary) afterwards holds
no VIP and — because no `secondary-ip-address` is installed, or none
is configured at all — cannot measure the target at all: every probe
is not-completed, so `pollCycle`'s `continue` left `st.down=true` and
the installed ip debt frozen for the life of the process. After the
upstream recovered the demoted node stayed at weight 0; losing the
new primary then left the RG ownerless (`electSingleNode` only
promotes when `localWeight > 0`), and an outage long enough to demote
both nodes left zero owners at once. Recovery required an xpfd
restart or removing the RG/ip-monitoring.

## Fix

`pkg/cluster/monitor.go` only — no config-model, election, or
dataplane change, and no new allocation on the probe path:

- `probeSourceFor` now also reports `canMeasure`. It is false in
  exactly one shape: a bound target (`interface <unit>`) on a node
  that is not primary for the RG and has no `secondary-ip-address`.
  Primary, unbound (legacy), and secondary-with-address probes stay
  measurable. `ipProbeTask` carries the flag from the Phase-1
  snapshot to Phase 3.
- In `pollCycle` Phase 3, a not-completed probe for an unmeasurable
  target calls the new `releaseIPTargetState`, which drops that
  target's dampened `ipState` entry (under `mon.mu`, no manager call,
  preserving the #6550 lock order). The following
  `reconcileRGIPDebts` then derives an empty desired set and removes
  the installed debt via `SetMonitorWeight`, restoring weight 255 and
  promotability. Measurable not-completed probes (cycle-deadline or
  Stop aborts, transient dial/bind/send failures on a node that
  holds a source) keep the exact #15038/#5301 neutral treatment, so
  real DOWN debt is never cleared by an abort — no fail-open.
- Documented boundary: a configured `secondary-ip-address` is
  treated as held (measurable). xpf does not install that address;
  making the secondary genuinely measure with it is a separate
  feature (the vsrx-parity compile/validate dimension), not this fix.

## Regression tests

- `TestIPMonitorDemotedNodeReleasesFrozenDebt16734` — va21 survivor
  twin: node0 measures DOWN while primary and demotes (weight 0),
  becomes unmeasurable as secondary, upstream recovers, frozen debt
  releases (weight 255, no MonitorFails), and after peer loss
  `electSingleNode` promotes it.
- `TestIPMonitorDemotedGlobalThresholdReleases16734` — the issue's
  exact global-threshold/global-weight 255 config: no-secondary row
  releases the aggregate debt; with-secondary row pins the
  measurable/neutral boundary.
- `TestIPMonitorMeasurableAbortStaysNeutral16734` — guard against
  over-clearing: primary and secondary-with-address nodes keep a
  measured DOWN debt across not-completed probes.
- `TestIPMonitorBothDemotedRecoverOneOwner16734` — both nodes demote
  in turn during one outage; both recover promotable weight and the
  peer-loss survivor promotes.
