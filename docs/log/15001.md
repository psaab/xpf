# #15001 — NAT undefined zone: strict reject, tolerant skip (A08-04)

- **Timestamp**: 2026-10-18 (`fix/15001-campaign`)
- **Change**: An undefined source-NAT `from-zone`/`to-zone` or destination-NAT `from-zone` was only a `ValidateConfig` warning, yet dataplane `compileNAT` (run in the #4960 validate-before-mutate pre-pass) hard-errored and aborted every apply. Now `validateNATUndefinedZoneStrict` in `pkg/config/compiler_validate_strict_nat.go` rejects strict commit naming rule-set and zone, wired dead-last in `runUniformGates` (after `runUniformGatesUnknownSecurityPoliciesChild12217` ordering preserved by appending before it) with `opts.lenientNATUndefinedZone` so no established first-error slot is stolen — the large corpus of NAT fixtures that use zone names without defining zones keeps reporting its own gate first. Tolerant compile warns per offender and records rule-sets in `cfg.LenientNATUndefinedZoneRuleSets` (`json:"-"`); `pkg/dataplane/compiler_nat.go` `compileNAT` skips exactly those rule-sets with `compileWarn` so healthy siblings still apply. A config without the record (hand-built / JSON-round-tripped) still fails closed in `compileNAT` (#12525/#14679 preserved). Static NAT has no dataplane zone error and stays warn-only. The subsumed source/destination warn loops in `compiler_validate_warn.go` were removed (static loop kept).
- **Files**: `pkg/config/compiler_validate_strict_nat.go`, `pkg/config/compiler_uniformgates.go`, `pkg/config/compiler_opts.go`, `pkg/config/types.go`, `pkg/config/compiler_validate_warn.go`, `pkg/dataplane/compiler_nat.go`, tests `pkg/config/nat_undefined_zone_15001_test.go`, `pkg/dataplane/compiler_nat_undefined_zone_15001_test.go`, updated `pkg/config/destination_nat_zone_test.go` (#12245 superseded for source/destination) and `pkg/config/compiler_nat_scope_3079_test.go` (defines its zones), `docs/log/15001.md`.
