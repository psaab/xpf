# Issue #12239 — reject unknown scheduler weekdays and window leaves

## Why

The time-range scheduler schema accepted unknown children. `compileSchedulers` only records the seven recognized weekday names, so a misspelled weekday such as `modnay` was silently discarded. A scheduled deny with that as its only window therefore had no window and never became active.

## What

The named `scheduler <name>` schema node now opts into closed-world validation. The existing inherited schema walk rejects unknown weekdays and unknown day-window leaves during strict schema validation, and the diagnostic includes the scheduler name. The compiler and the no-window runtime behavior are unchanged. The schema-instance ratchet moves `/schedulers/scheduler` from blind to armed.
