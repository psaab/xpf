# #16548: brace-elided wildcard group statement compiled as phantom OSPF interface `<*>`

- **Timestamp**: 2026-10-24
- **Action**: Split a packed group leaf whose identity span carries a
  wildcard key at that span before the leaf arm of `mergeNodes`
  (`packedWildcardLeafBraced16548` in
  `pkg/config/group_merge_packed_wildcard_16548.go`, routed from
  `pkg/config/ast_groups.go`). `interface <*> authentication md5 1 key K;`
  parses as one leaf packing the wildcard identity and its whole body;
  the leaf arm had no wildcard check (the only `keysContainWildcard`
  check sat after it, on the container path), so the leaf was adopted
  literally and compiled an OSPF interface named `<*>` carrying the md5
  key while the real interfaces stayed unauthenticated behind only the
  indirect #9405 advisory. The split rebuilds the braced container
  (`interface <*>` + the schema-expanded tail, or the #12530 unmodelled
  tail), so both spellings take the same wildcard branch: the body fans
  out to every matching destination and a pattern matching nothing
  invents nothing (#9423). Admission mirrors
  `wildcardInstanceNode9802`: the wildcard must sit inside the identity
  span (`consumeNodeKeys`, so compound keys count) of a
  container-shaped schema child — including dynamic instance levels
  whose own wildcard schema is the instance schema (`interfaces`) — so
  a wildcard in a value or MEMBER position (`interfaces <ge-*>;`,
  `description "<*>";`) keeps its existing loud refusal or ordinary
  leaf handling, and an identity-only packed leaf (nothing to fan out)
  keeps the existing path. Binding a BARE destination leaf
  (`interface ge-0/0/0.0;`) is the sibling #16543 question and stays
  equal for both spellings: after this fix the packed template at
  least invents no phantom there. One nuance found while testing: the
  zone packed spelling (`security-zone <*> tcp-rst;`) is folded by the
  #8662 compact normalizer before expansion on the strict
  `CompileConfig` channel, so its regression cell exercises the raw
  `ExpandGroups` channel, where the split is the only phantom guard.
  Added `pkg/config/group_merge_packed_wildcard_16548_test.go`:
  packed-equals-braced OSPF md5 fan-out, `<ge-*>` subset selection,
  no-match invents nothing, packed `<ge-*>` interface descriptions,
  raw-expansion zone tcp-rst, zone-member refusal preserved, and
  inline-auth precedence parity with the braced control.
