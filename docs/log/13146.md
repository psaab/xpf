# #13146 Close VLAN-map AST coverage gaps

## Finding

D2-15 in the deep-review zone-enforcement source report found that the
`#6178` unsupported VLAN rewrite gate did not inspect peeled logical-unit AST
nodes (`unit { 0 { ... } }`). `compileInterfaces` accepts that shape through
`namedInstances`, but the gate only visited the outer `unit` node and therefore
accepted a strict commit even though the `input-vlan-map`/`output-vlan-map`
rewrite was silently dropped. A second bypass occurred when both per-node
group expansions failed: unlike `CompileConfig`, the gate did not inspect the
raw tree it would compile as fallback.

Repeated findings for the same interface/unit also discarded later rendered
statements rather than unioning them into the existing finding.

## Fix

`collectVLANMapFromInterfacesNode` now uses the same `namedInstances` helper
as interface compilation, so both packed and peeled unit spellings are
inspected. Same-key findings append their statements. The per-node collector
reports expansion success; if neither node view can expand, the validator
scans top-level raw `interfaces` roots, matching the compile path's raw-tree
fallback. Strict rejection and lenient warning behavior are otherwise
unchanged.
