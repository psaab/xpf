    `distribute-list prefix xpf-rip-<inst>-grp-<n>[-v6] out <if>`:
    each chain's accepted prefix set is computed in evaluation
    order (first terminal wins, #5277; reject terms render as
    earlier deny entries, prefix-lists/from prefix-list/route
    filters honoured) and emitted as top-level ip/ipv6
    prefix-lists before `router rip`. Chains not expressible as
    finite prefix sets (bare protocol token like `static`, or an
    accepting term with non-prefix conditions) fail closed:
    deny-all list (`deny 0.0.0.0/0 le 32` / `deny ::/0 le 128`)
    plus a loud warning — never a leak of the union. The strict
    gate `validateRIPGroupExportStrict` rejects the one
    inexpressible-by-construction shape (an interface in two
    groups with differing export chains; order-sensitive
    comparison) globally and per routing-instance; lenient warns
    (#1960) and the renderer withholds contested interfaces.

    names so bindings match enrolled interfaces. Group-less RIP
    renders byte-identical legacy output. Probe in both stanza
