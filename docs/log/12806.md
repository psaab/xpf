# Issue #12806 — parallelize schema spelling probes

## Why

`TestSchemaSpellingDifferentialGate` ran about 14.5 minutes according to the issue report, exceeding Go's default 10-minute package-test timeout. Its exhaustive spelling comparisons can therefore panic a normal package run before it completes.

## What

The gate now runs its six independent spelling probes concurrently. All spellings, values, compile/parse calls, determinism checks, and verdicts remain in place. The effective-path cache is protected while probes share it. No timeout was changed and no corpus was reduced.

## Validation

- The issue report records a 14.5-minute pre-fix run. The optimized targeted gate passed in 215.75 seconds initially, and passed again after the mutation check was restored in 169.611 seconds (`go test ./pkg/config -run '^TestSchemaSpellingDifferentialGate$' -count=1 -timeout 15m`). Both runs retained 1199 enumerated and 788 compared leaves.
- Mutating the A-hier-bracket two-value form to duplicate its first value made the gate fail in 174.13 seconds with 13 unexpected shape-dependent-drop findings.
- `go vet ./pkg/config`, `gofmt -l pkg/config/schema_spelling_differential_gate_test.go`, and `git diff --check` passed.
- `go test -race ./pkg/config -run '^TestSchemaSpellingDifferentialGate$' -count=1 -timeout 15m` timed out after 15 minutes; no race-test result was established.
- `go test ./pkg/config -count=1 -timeout 15m` completed in 405.752 seconds but failed on existing inventory census, API-auth expiry, packed routing-instance, and slot-escape tests. The spelling gate did not time out; the test run completed within the timeout.

## Risk

The probes share the package compiler concurrently; the gate's only mutable cache is synchronized. The serial compiler path is unchanged. Race-instrumented runtime was not established.
