# #18822 — coordinator local-selector fixtures

## Why

Commit `9db06f3dd2` (#14079) added the local destination-selector projection and zone-policy gate to decrypted IPsec adjudication. The coordinator regression fixtures still used remote addresses as packet destinations and published empty destination projections, so their positive control legs failed at D22 with `d22_destination_outside_selector` (reason 45).

## What

- Extended the coordinator P-MECH fixture with a non-tunnel `192.0.2.0/24` main route via ifindex 20 and matching tunnel-row `destination_prefixes`.
- Seeded matching local-LAN forwarding routes, zones, and permit policy for the direct coordinator fixtures; moved positive packet destinations to `192.0.2.1`.
- Updated the coherent-refresh snapshot with the local route, permit default, and interface egress zone. Seeded its pre-refresh neighbor state identically so the test continues to isolate view-pair publication and retains its existing generation assertions.
- In the duplicate-if_id test, kept the ambiguous `st0`/`st1` packet unchanged and used the local destination only for the unambiguous `st2` control leg.
- Updated the slow-path-MTU fixture's inventory and forwarding state with the same local selector route, destination, zone seeds, and permit policy. No production code changed.

## Validation

- RED before fixture changes: all four named coordinator cells denied at `d22_destination_outside_selector` (reason 45). The broad `coordinator::` filter also reported an unrelated existing `status_mapping_6961_tests::every_runtime_atomic_is_bound_or_knowingly_off_wire_6961` failure.
- GREEN: each of the four named cells passed; `afxdp::coordinator::tests::` passed 213 tests; `afxdp::coordinator::reconcile::snapshot::slow_path_mtu_tests::` passed 7 tests (all with `--test-threads=1`).
- Mutant: clearing the shared helper's `destination_prefixes` made both the join test and duplicate test's `st2` control leg fail at `d22_tunnel_inventory_invalid` (reason 52). Restoring the selector fixture made both targeted tests pass again.

## Risk

Test and fixture changes only. The fixture now expresses the independent local route/selector and policy conditions required by the intended D22/D15 gates; inconsistent or absent selector projections remain fail-closed.

The coherent-refresh fixture now routes `192.0.2.0/24` through a non-tunnel ifindex-20 interface and matching neighbor; the pre-refresh forwarding fixture carries the same neighbor. The regression asserts `192.0.2.1` resolves through egress ifindex 20 before adjudication.

- Mutant control: clearing the shared helper's `destination_prefixes` made the cell deny at `d22_tunnel_inventory_invalid` (reason 52); restoring the projection made the cell pass.
