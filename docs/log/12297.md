# Issue #12297 — bind tagged management VLAN devices to vrf-mgmt

## Why

Management VRF membership covered configured parent names only. A tagged unit such as `fxp0.100` is a separate kernel link, so it remained in the default VRF: the published management set omitted it, `BindInterfaceToVRF` bound only the named link, and its networkd model had no `VRFName`.

## What

- `managementVRFIfaceSet` now adds configured VLAN-unit Linux device keys for tagged management parents, preserving the existing base keys and excluding non-management VLANs.
- `BindInterfaceToVRF` binds VLAN descendants of a management parent to `vrf-mgmt`, avoids redundant master changes, and returns link-list/bind failures to the existing authoritative post-networkd error path.
- Networkd models for management VLAN parents and their children now carry `VRFName=vrf-mgmt`.
- Added regression coverage for management-set expansion, networkd model membership, recursive VLAN binding, non-VLAN child exclusion, and idempotence. Updated the reassertion rationale to match the binder's master check.

## Validation

- STEP-0 on clean base `a714c90d472a3c3d98a3799831cfef3ec311a61c`: three throwaway regression probes failed as expected: `fxp0.100` absent from the management set; VLAN model `VRFName` empty; VLAN child `MasterIndex=0` after binding `fxp0`.
- GREEN: `TestManagementVRFVLANUnits12297`, `TestManagementVRFVLANNetworkdModels12297`, and `TestBindManagementVLANDescendants12297` passed. The routing test also verifies nested VLAN traversal, non-VLAN exclusion, and no repeated `LinkSetMaster` calls; link-list failure propagation is covered.
- `gofmt -l` on touched Go files: no output.
- `go build ./...`: passed.
- Full package suites: `pkg/daemon`, `pkg/routing`, and `pkg/networkd` passed. `go test ./pkg/dataplane -count=1` had the same three failures on this branch and clean base: `TestMapZoneInterfaceDottedFakeLink9821`, `TestOperatorPackagesOnlyUseDocumentedLegacyDataplaneImports`, and `TestHAWatchdogClaimsUseTheHelperLease10791`.
- `go test ./pkg/config -count=1` reported census, API-auth expiry, forwarding-instance, and slot-escape gate failures, then timed out after 10 minutes in `TestSchemaSpellingDifferentialGate`; the clean-base run reproduced the same failures and timeout.

## Risk

The management rebind now enumerates links to find VLAN descendants. Enumeration or child-binding failures are returned through the existing post-networkd, fail-closed commit path; the pre-networkd bind remains best-effort. No live-cluster mutation was performed.
